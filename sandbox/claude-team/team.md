# Claudeのチーム（お遊び）

会話の中でClaudeが組んでいるチーム（2026-10-07〜）。原典とは関係のない遊びで、設定資料の根拠にはしない。実機を参照しやすいように、全員古代種で組む。

## コンセプト
- 全員が古代種なので、全員が『オールドタイプ』（防護ポテンシャルを無視）を持つ。“バウンス”の『三点防護』、『耐えろ互換』、「装甲」「障壁」系など、「B」で増える守りを誰が殴っても貫く、**防護殺し**のチーム。
- 立ち位置は「B」中位の上の方。全員が『撃』『先』『第三階梯』をそろえると上位の入り口（367の天花の物差し）。

## トレーナー
- 資質: **指示A／能力B／育成C／統率C**（標準型の指示型）。
  - 育成はBDで借りる（育成A+のBDなら実質A）。統率はSPで借りる（『エンチャンター』を1つ追加任命）。『固有』は借りられないので能力をBにした。
  - 統率Cなので、手持ちは全員要「統率」C以下（準伝級は使えない）。
- 『固有』『**古き牙は鎧を穿つ**』: 味方が『指令』を受けた時、T終了時まで相手の「防/特防」の上昇（強化）を無視する。『オールドタイプ』（防護を抜く）と合わせて、相手の守りの手段をほぼ全部抜く。指令のTだけなので「B」相当の強さ。
- 専用は4つ（能力Bなので4つと見た）: メタグロス『強化貫通』、ハッサム『必中追尾』、トゲキッス『ペースメーカー』、ミミッキュ『先行とんぼ』。

- 技: じしん、あくび、ふきとばし、なまける
- 体力A／攻A／防A+／特攻C+／特防C+／速D+（実機の108/112/118/68/72/47に『ポケパワー』の+補正込み）

## ハッサム（キラー）
- Lv115、むし/はがね。特性: テクニシャン。持ち物: こだわりハチマキ
- 技: バレットパンチ、とんぼがえり、はたきおとす、ばかぢから
- 体力C+／攻A+／防B+／特攻C-／特防C+／速C+（実機の70/130/100/55/80/65に『ポケパワー』の+補正込み）

| 分類 | ポテンシャル | 効果 |
| --- | --- | --- |
| 役割 | 『エースキラーα』 | 『エース』に与えるダメージを1.5倍、『エース』の「防/特防」の上昇（強化）を無視 |
| 分類 | 『オールドタイプ』 | 防護ポテンシャルを無視 |
| 異名 | 『名工』 | 自身の特性「テクニシャン」の対象を「威力：70」以下の技まで広げる |
| 種属 | 『赤鋏虫の強襲』 | 場に出て最初に繰り出す攻撃技の威力を強化（1.2倍）する |
| 種属 | 『赤鋏虫の装甲』 | 相手の「必中技」のダメージを緩和（0.67倍）する |
| 種属 | 『赤鋏虫の凱旋』 | 相手を倒した時、味方と任意交代する |
| 属 | 『ポケパワー』 | 全種族値に+補正 |

| 対〇 | 『対炎耐性』 | 「炎」技のダメージを半減（4倍弱点が2倍まで下がる） |
| 対〇 | 『対飛反撃』 | 敵陣に「飛」ポケモンがいる時、低確率で一番最後に追加行動を得る |
| 汎用 | 『戦闘続行』 | 低確率で、受けた技のダメージを自身の行動後に持ち越す |
| 付随 | 『チャレンジ』 | 敵陣に『エース』がいる時に場に出ると、T終了時まで優先度+1 |

- ねらい: “バウンス”狩り（交代際の「おいうち」、ひこう持ちの“バウンス”に『対飛反撃』）。「装甲」で、一番メジャーな専用『必中追尾』を受け止める。相手のエースがいれば『チャレンジ』で優先度+1、バレットパンチ（+1）と合わせて一番速く届き、『エースキラーα』が乗る。倒したら「凱旋」で下がり、こだわりの縛りもリセット。
- 異名『名工』で、「とんぼがえり」（70）と「はたきおとす」（65）もテクニシャンの1.5倍の対象になる。とんぼがえりは105相当で殴って下がれ、はたきおとすは持ち物ありの1.5倍も重なる。
- 注意: 相手の「剛性」（威力50以下を無効）には、バレットパンチ（40）が止められる。

## この先の予定
- **ミミッキュを『ベテラン』に**: まず試合で『異名』を得て、そこから『ベテラン』へ。自前の専用を持てるので、トレーナーの専用の4つ目（今は『先行とんぼ』）が空き、アーマーガアの『三点防護』かカバルドンに回せる。「タイム」も本人の分と合わせて2回になる。属の『ポケパワー』は『悪癖』に切り替わる。
  - 『悪癖』の案: 「化けの皮の繕い」（ばけのかわが剥がれた次のTは、皮を繕うのに夢中で技を選べない）。

## 弱点
- 『尾獣のチャクラ』のような『オールドタイプ』の無効化で、チームの売りが消える。
- 古代種は素で600を超えるものが少なく、現代種の怪物（ライナーやヤマト級）と正面から殴り合うと地力で負ける。
