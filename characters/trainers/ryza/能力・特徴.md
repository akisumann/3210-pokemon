# 能力・特徴

- ブリーダー: プロチームで、トレーナー以外にポケモンの育成を担うスタッフ → [根拠](根拠/能力・特徴_01_ブリーダー.md)
- ブリーダーとして他人のポケモンを育てるときは「育成」が1ランク下がる（誰でもそうなる） → [根拠](根拠/能力・特徴_02_ブリーダーとして他人のポケモンを育て.md)
- 育成の方向性: 王道ではなく、チーム全体の戦力を平均化する方向で育てる → [根拠](根拠/能力・特徴_03_育成の方向性.md)
- 育成の考え方: 「育成は魔法じゃない、鍛錬」（042） → [根拠](根拠/能力・特徴_04_育成の考え方育成は魔法じゃない鍛錬0.md)
- BDの裁量: 注文以外は裁量が大きく、アイディアは最後に自分がまとめる。レベルは試合で稼いでもらい、「育成」は何体かずつ（510, 519） → [根拠](根拠/能力・特徴_14_BDの裁量.md)
- ジムの門下生なので、プロリーグの基本的なことは知っていて、ジムで情報も集められる → [根拠](根拠/能力・特徴_05_ジムの門下生なのでプロリーグの基本的.md)
- ジムの門下生は、一定の実力を認められるとジム勝利時の配布わざマシンをもらえる。ライザも「エナジーボール」を持っていて、カズマに貸した（「貸しただけだからね？」）（出典: 042）
- 地下大洞窟によく潜り、発掘したアイテムを売っている。炭鉱では「よろいのかせき」を掘り当てた（出典: 009, 019）
