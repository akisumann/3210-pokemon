# リュカ（《山小屋グランバニア》の監督）: チームはフタバ杯の⑤《山小屋グランバニア》（319の正式データで確定）

↑ [リュカ（《山小屋グランバニア》の監督）](../../others-b-05.md#リュカ山小屋グランバニアの監督)

- チームはフタバ杯の⑤《山小屋グランバニア》（PC操作）。308の話の流れ（オーナーの安室が「ここでぶつかるか《探検堂ミラクルズ》……その次は《学園バンチョーズ》」と言い、鳴上も《山小屋グランバニア》を相手に挙げる）と、306の''カフェ山小屋''の監督（『金冠サイズ』の古代種を仲間に欲しがっていた）が前ぶれで、317で《山小屋グランバニア》として勝負を仕掛けてきた。319の正式データ（パーティ名《山小屋グランバニア》、監督名：リュカ）で確定。チームはヨスガの中規模戦で準優勝した。（出典: 306, 307, 308, 316, 317, 319）
