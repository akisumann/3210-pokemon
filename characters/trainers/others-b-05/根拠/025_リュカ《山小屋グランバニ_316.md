# リュカ（《山小屋グランバニア》の監督）: 316

↑ [リュカ（《山小屋グランバニア》の監督）](../../others-b-05.md#リュカ山小屋グランバニアの監督)

- **316**: フタバ杯で《学園バンチョーズ》に勝ち（「メガシンカ」を司る『原始天賦』と雷雲の伝説で、途中から圧殺）、ミラクルズと決勝を争う（どちらもヨスガ・クロガネの''中規模戦''で準優勝）。チームは''古代種''統一で、''事実上ほぼ「育成/統率」を複合する、今大会最高練度のチーム''（System）。推定Lv115〜125。『天賦エース』で実質「育成/統率：A」だが、純正の「統率」ではないので『PT』と『エキスパンション』は付与されていない（ライザ）。固有は『**今日から君も友達だよっ！**』（PT全員が「技能拡張：なかまづくり」（相手の特性を自分と同じに変える）を出せる）。もう1体の『絆』持ちは、見た目の割にヤマトに匹敵しそうな火力の『アヴェンジャー』（『三角』っぽいものを持っていた。ライザ）。奏にも直接対決で勝った。天花いわく、''妙に「指示」が鋭くなる瞬間がある''ので、SPの喫茶店の店長（安室）がデータ解析のようなサポート効果を持っているかもしれない（ライザ）。（出典: 316）
