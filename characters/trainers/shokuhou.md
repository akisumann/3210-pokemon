# 食蜂操祈

> 《園生クインビーズ》の監督。「統率／能力」の複合資質を持つ、今年のナンバーワンルーキー。スクールの「女王蜂」で、メガシンカするスピアーを『エース』にしている。チャンピオンのホーネットの従妹。カズマを「地味くん」と呼び、プロ初の黒星をつけたライバル。第一節最後の中規模大会の最終戦でカズマに負けた。第三節では第二『固有』『女王蜂の下す号令』で「能力：AA」になり、キッサキ杯中規模大会の全勝同士の再戦（中盤戦）でまたカズマに負けた（435）。

枝（`shokuhou/` の中）には一行の要約だけを書き、中身は各行の先の根拠（`shokuhou/根拠/`）にある。

| 枝 | ひとこと |
| --- | --- |
| [概要](shokuhou/概要.md) | スクール出身、チャンピオンの従妹。《園生クインビーズ》 |
| [現在の状態](shokuhou/現在の状態.md) | ハクタイ杯中規模大会で優勝し、凛にも勝った |
| [トレーナーとして](shokuhou/トレーナーとして.md) | 追加行動の『固有』と3つの「しれい」。エースはスピアー |
| [性格](shokuhou/性格.md) | 余裕たっぷりでつかみどころがない。負けても折れない |
| [人間関係](shokuhou/人間関係.md) | 「地味くん」カズマ、従姉のホーネット、相棒スピアー |
| [歩み](shokuhou/歩み.md) | 015の写真から484まで、章ごと |
| [元ネタ](shokuhou/元ネタ.md) | 『とある科学の超電磁砲』の食蜂操祈 |

話ごとの細かい出来事は [詳しい歩み](shokuhou-history.md)。
