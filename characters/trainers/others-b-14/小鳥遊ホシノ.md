# シンオウのほかのチームと関係者 ／ 小鳥遊ホシノ（《図書館アーカイブス》の監督、昨年度シンオウ5位）

- ミオ図書館のチーム《**図書館アーカイブス**》の監督（「どうも～、シンオウ5位の《図書館アーカイブス》の監督さんで～す♪」）。202で地下おじさんと探検堂に来て、行方不明と聞いていた前ブレーンのオシュトルを見つけた。オシュトルの全盛期は自分と同格クラスだったと言う（エネルともバチバチやり合っていたと言ったのはカズマ）。書類仕事ができる人が足りず、オシュトルを図書館に誘った（「まぁ多分馬車ウマの如く使われると思うけど」）が断られ、目の前で探検堂に取られて「ちょっと待てや！！！！」「あんたはもっとえり好みして自分を高く売れや！！！！！！！！！」。カズマとは面識がある（「前もしたね、自己紹介」）。（出典: 202）

- 334: 作者が改めて「昨年シンオウ5位」と補足（ほぼ名前だけ出ている状態で、上位勢と本格的に絡むのはこれから）。334のフリーイベントの候補にも「おじさんを自称するロリ」として挙がった（選ばれなかった）。（出典: 334）

- **389（ミオ図書館）**: ミオ図書館の司書のような立場で、カズマとリザードンの本探しを手伝った。今もオーナー（探検堂）と地下の探索で世話になっている。入場料代わりに『ベテラン』（オシュトル）を欲しがり、「『天賦エース』とヤバイ『ベテラン』は別腹」。「能力」型で、『天賦』込みでほとんど「複合」型（詩音）。''ヨスガ杯''を見に行って、カズマを警戒するつもり。（出典: 389）
  - **チーム**: 「みず」タイプの**楯無**（''ウンディーネ''。アルトマーレ出身。ホシノの「統率」まで上げている相棒）。『二枚看板』は''古代種''の**ルギア**（ジョウト）。「深度：4」で群れと別行動をしていた個体を捕獲したもので、『伝承』で自前の『専用』を持ってきていて、''うずまき島''を展開する（クロロ）。楯無も''アイツ''（『二枚看板』のルギアか。推測）も「でんき」が苦手（ホシノ）。SPは**園崎詩音**（「園崎のヤバイ方」。「SPとして後でシメとく」）。（出典: 389）
  - 推測: 楯無は『IS〈インフィニット・ストラトス〉』の更識楯無（水を操る）、詩音は『ひぐらしのなく頃に』の園崎詩音。

- **394・399（ヨスガ杯観戦）**: 389で言っていたとおり、''ヨスガ杯''を観戦した。394の《鮮血カズィクルベイ》戦で、リザードンがメガシンカして天候を「晴れ」にし、敵陣を「火の海」にしたところで「…………………………うせやろ？」。399の《探求バブミーズ》戦で、観客が元''タワータイクーン''のオシュトルの登場にざわつくなか、「――――――ついに出て来たかぁ、オシュトル………ヤバいとこにヤバイのが入ったもんだこりゃ」（389では、オシュトルについて「ってことは、ついに出てくるって感じかな～」と言っていた）。（出典: 389, 394, 399）

- **550**: スクールが偶に招くプロのチームとして、今回はホシノ（《図書館アーカイブス》）も呼ばれている（千束「今回はホシノ先輩も呼ばれてるし」）。千束はカズマに、スクールでホシノたちほかのチームの監督と会えれば交流してみたらと勧めた。（出典: 550）

- **553（スクールの控え室）**: スクールに呼ばれてカズマたちと会った（楯無が同行）。組み合わせ表を見て「うへへ～、おじさんにも見せて見せて………オェッ」。「C」も上の方はだいぶおかしい、何割かは君らのせいで、エキシビションを導入した運営も（モニカやワイスもエキシビションに到達して負けた）。修（「ハッサムくん」）も有望で、来年もルーキー勢がなかなかと噂（今年はもうなんか色々ぶっ壊れすぎるだけ）。ミラクルズの授業を「盗み聞きしに行きてぇなぁ」。楯無: 「A」も戦々恐々で、開幕の「A/B」混成ランク大会から大荒れになりそう。ライザに「バンチョーくんと相性良いんだっけ？BD的な意味で」。（出典: 553）
- **594（交流戦の最終日）**: 先発戦の少しあとに、グリーン戦の会場の廊下へ。五条（エンジュのジムリーダー）に「うっせぇんですけど、ジョウトのジムリーダーの問題児筆頭」「アンタジョウトに行く度に問題行動の噂増えてるんですけど、その辺どう思うんすか」（AA内「おじさんでもアンタはダメな大人だと思ってるからね」、五条「スクールの修学旅行の時の尊敬の眼差しは？」）。メアリに勝った五条のことを「ウチのコンテストのプリンセスボコってブーイングで傷心ウザがらみすんのやめよ？」。前日に白石に直接負けた（「マジで煉獄さんよりもレベル上だったし」）。（出典: 594）
- **600〜602（ミオ杯）**: 第四節の最初のミオ杯中規模大会に《図書館アーカイブス》【H】で出る（昨年5位、「能力」型。優勝候補筆頭）。カズマの最終戦の相手（602）。アスランの話: 「能力：A+」、“神秘による護り”（味方を場に出して自陣を「しんぴのまもり」にし、状態異常もほぼシャットアウト）と、“それを応用した『玉座』の力”（“「ばつぐん」技の威力半減”。チャンプの「ダーク」技の「ばつぐん」とある意味対極。本人いわく「神秘による力のちょっとした応用だよ、うへ～」）。カズマ: トレーナーの『固有』由来なので『たえろ！』と同じくほぼ『三角効果』でしか抜けない、『オールドタイプ』も『エキスパ（闘）』も無駄、下手なサブウェポンより一致等倍の方がマシ。「統率」はウンディーネの『天賦』で「A」まで上がる。『二枚看板』はジョウトの伝説のポケモンのルギアで、『専用』で「異界」を展開し、「うずまきのおうぎ」も使う。ジョウト方面とも個人的なつながりがある。（出典: 600, 602）
- **604（ミオ杯の開幕戦当日）**: アイスの食べ過ぎでお腹を押さえて自販機を探していたのを、アスランに「俺たちのことは早くも威嚇しているんだ」と読まれる。詩音いわく、ホシノの「神秘」を超えて状態異常にできる毒物はそうそうないが、それに油断してちょいちょいお腹を壊す（作者の注「この夏の一幕（めちゃくちゃお腹壊した）」）。グリーンには交流戦で「正面から等倍で押し切られた」。カズマに「少なくとも今のキミに負けるつもりはないよ、負けておじさんの胸を借りて泣くことを許してあげよう」。最近ユニと話が合う友達になった。アスランの「そんな胸もないくせに」とダージリンの「張る胸がなければ知りませんがっ」に「上等だオラァっ、やってやろうじゃねぇかこの野郎！！！！！！！！！！」。詩音「このおじさん多分五強で一番メンタル弱いです」。（出典: 604）
- **616（ミオ杯の決勝）**: 6戦全勝で優勝。ミラクルズとの決勝は「2-0」（作者: 現時点ではオート敗北。ホシノとはリベンジ戦でPC操作が発生する）。「ウンディーネ」の『天賦の才』とジョウトの古代の「禁伝」が主力で、両翼の2体はメリュジーヌと同等以上の「190」レベル超え、平均は「185」クラス。固有『神秘の集いし青の玉座』（自陣が「しんぴのまもり」の時、味方が受ける「こうかばつぐん」の技の威力を半減する）と『夢を集めし神秘の護り』（味方を繰り出す時、自陣を5Tの間「しんぴのまもり」状態にできる）。決勝ではルギア（特性「マルチスケイル」、「とくせいガード」）が、ホシノの「能力」を起点とした『島のヌシ』の付与と『第四階梯』の権能で、《異界/うずまき島》から「うずまきのおうぎ」を開帳してガッシュを倒し、更識楯無が「らんすいりゅう」でヤマトを倒した。『エース』は「みず/こおり」で、『天賦』による「追加任命」を持つ実質の「複合」型。試合中は詩音が解説した（「ジョウトでも大きさは随一、「シロガネ山」にくらべりゃマシでしょう？ねぇ、ルーキー」）。（出典: 616）
  - 内心「これで「4-2」、だけどこっからもまだまだ怖いのがいるんだよなぁ」。試合後「他のチーム相手はどこも「4-0」以上だったんだけどなぁ……あ～、疲れた…………」、「ステロ」を早めに除去できたのが大きい。「今日は条件がこっち有利なタイミングでぶつかりましたしね、問題は次かなって」。大規模戦では、場合によってはリーグ勢の陥落の可能性すらある、このペースは想定外。「あれで『エンペラー』や『異界のヌシ』がいないのはまだマシだけどね……」「おじさんは勝ち逃げしたいです」。楯無: 次は今日の編成よりもウチに対策を講じてくる、四天王のあたりだって他人事じゃない、いっそリヴァイアサンでも探しに行く？（出典: 616）
- **617（フリーイベントの当選）**: フリーイベント「実はホシノおじさんには「釣りキチ助平」というあだ名が……？」が選ばれた。作者: 子供の頃の夢は「カイオーガを釣ること」とふざけて言い出しそうなおじさん、ホエールウォッチングと称してみずぎのおねえさんを観察する釣り人。（出典: 617）
- **618（釣りキチ助平）**: 噂の“釣りキチ助平”の正体。久々の休みにアングラーモードでミオの港に来て、双眼鏡でみずぎのおねえさんたち（エミヤのジムの門下生）を見ていた（「ホエルコウォッチング（意味深）」「なんすか、おじさんがおっぱい好きじゃなんかダメなんすか（開き直り）」）。釣りキチ三兵の仲間で、Cいわく三兵の中で一番の小物、ミオ杯ではヤマトに釘付けだった。今一番興味のある胸の持ち主は「新条アカネ！！！！！！！！！！！」（カズマが見せたアカネの水着写真で邪念が消えた。写真の出所を聞こうとした）。夢はガノトトス、いずれはカイオーガかリヴァイアサンかナバルデウス。カエルを餌にガノトトスを釣り上げたが、近海を荒らしていた『天賦の才』の「近海の主」で、エミヤが捕獲して街に渡すことに（「なんでおじさんの初ガノトトスがこんなことになるんだよ」「釣ったのは私ですみたいな感じでちょっと扱い大きくしてくれれば」）。カズマに町長へスケベ行為を告げ口され、お説教された。（出典: 618）
- **723（スクールの図書館で）**: 図書館に頼まれた資料を届けに来てお昼寝、カズマと会う（「授業やってる時間に何やってんの、スクールで不審者が出たって通報して良い？」）。今度のコトブキ杯も残りの出場候補のチェックに見に行く。マサゴ杯にも出る（竜胆に「参加したら私のホエルコ触っていいぞ」と言われて）。作者: 自称「スクール卒業生の常識枠」、近年のスクール卒業生では昨年の戦績が一番上（シンオウ5位）、「ついにおじさんの真面目なイベント」。カズマに後輩（白野）の先輩になる悩みを相談され、「キミは来年まだプロ2年生で先輩1年生」「肩肘張ってちゃダメダメぇ」「案外楽になるよ？後輩に頼れるようになると」「自分のダメなとこ認めて素直に頼ってくれる先輩って、後輩からしたら嬉しい」「いきなり距離感とかスタンスを変えると相手も周囲も戸惑う」「そういう風に感じるってのも成長の証」（飲食禁止の図書館でアイスを食べながら）。相談は初回タダ、次回からガリガリくん前払い（電話なら釣りをしながら）。「ナギサ杯の優勝とリーグ出場おめでとね？それに、マサゴ杯でも負けないから、よろしく」「キミは私にもその先輩ってヤツにもなれないからね～！自分なりの先輩になりなよ～」。在学中からの秘密のウォッチングスポットに誘う（3回バレた場所で「みがわり」にするつもり。今は教師が見張る囮スポット。自分も先輩に「みがわり」にされた過去）。カズマ: 後輩から結構慕われてたりしない？ →「ひ～み～つ～～～（アヘアヘアヘ）」。（出典: 723）
