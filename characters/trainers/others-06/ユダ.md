# ホウエン地方（交流戦） ／ ユダ（《釜炎ダイナーズ》のSP）

- **571**: 《釜炎ダイナーズ》のSP（AA内「あんたもそう思うだろ？漢方屋の薬膳ジジイ」）。屋台で「うむ、一ミリも列を乱すことなく並ぶが良い………どうした鈴、おぬしも手伝わんかね？」。スタジアムで、カズマのSPの操祈を見て「ふむ、ずいぶん人気のチームのようで……む、1ミリも遅刻せず来おったな？監督とSP」。（心の声）ジャンは「ヒールとしてのマイクパフォーマンスはホウエン最凶………天才じゃったか！！！！」。（出典: 571）
- **572〜573（カズマとのバトル）**: サポート効果《**一ミリ狂わぬ包丁捌き**》（ユダのサポート効果。味方の繰り出す技の命中率を強化（1.1倍）する。T開始時、低確率で味方の状態異常を治癒する）。「さぁ、見せて貰うぞ………君たちのフルコースを！！！」。鈴音を「薬膳を通した毒や病への復讐者と化したワシの心を受け継ぐ者」と呼ぶ。カズマの『固有』に「むぅ、中々器用な真似を」、ロトムに「つまり、おそらく『タイトエンド』」「なんという粘り腰、そして『タイトエンド』………まさか、あやつ………天才じゃったか！！！？」、オシュトルの一撃に「マズイ、これはグルメ界の――――」、ヤマトに「『キラー』か、『チェイサー』……「持ち物」か、いやまさか………？」。（出典: 572, 573）
