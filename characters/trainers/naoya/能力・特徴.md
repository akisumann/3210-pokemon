# 能力・特徴

- 『エース』の玉藻の前と『**愛の絆**』を結んでいて、玉藻が場にいる間は指示**AA+**。「タイム」は374から3回
  - 『エース』の玉藻の前と『**愛の絆**』を結んでいて、玉藻が場にいる間は指示**AA+**。「タイム」は、いつでも使える1回と、玉藻がいる時だけの1回で2回。374からは『ベテラン』のマタムネが貸す1回も足して、合計3回（綾乃「『絆』持ちに『ベテラン』と合わせて3回も使ってくんじゃねぇよ！！！！！！」）。（出典: 099, 101, 374, 381）
- **指示A+（597でAA-に成長）の鋭さ**が最大の武器。統率は低いので、従えられるポケモンが限られる（呪い・霊・死のポケモンには統率が1ランク上がる）。チームのタイプは偏っている（ベルファスト談）。（出典: 021, 096）
- 観戦でも、先輩の『固有』が受け出しにも効くことや、BBが「第二階梯」に到達していることを見抜いていた（出典: 093）
- 「指示」型の『固有』に多い、『指令』に連動するタイプ。『熟達狙撃指令』『熟達回避指令』も含めて最大8回加速できる。上から急所を狙って殴るのが基本（カズマ談）（出典: 100）
- チームは「ゴースト」持ちが主力。統率D+なので、「+」要素（呪い・霊・死）のポケモンで固めている（出典: 100, 101）
- 377で、主力2体（玉藻の前・ブラックサレナ）の図鑑と推定「能力：B+」が先に見えた
  - **377で分かった主力2体**: 練習試合の前に、カズマたちが直哉のチームのデータを確認した。直哉（とダージリン）は第二節の最後のほうまで大会に出ていて調子も良かったので、主力の2体は手をつけていないと読み、レベルは「120〜125」と予測した。特に活躍していてデータが取れていた主力2体、『エース』**玉藻の前**と、『追加任命』の『アヴェンジャー』**ブラックサレナ**の図鑑が先に見えた（カズマ（AA内）「まぁ、得に活躍しててデータ取れた2体だしレベルは「125」やろ（適当）」）。玉藻の特性「わざわいのおふだ」はベルゼブモンと似た系統で、実家からパクった秘伝のお札を「育成」にぶち込んだもの。直哉は2つめの『固有』を得て、推定「能力：B+」に上がった（カズマ「『固有』の出力で言えば「能力」型に匹敵してやがるな」）。381の正式データでも2体ともLv125で、図鑑は持ち物が足された以外は同じだった。2体の中身は、各選手の行（[玉藻の前](#玉藻の前-)、[ブラックサレナ](#ブラックサレナ)）を見る。（出典: 377, 381）
- 今の手持ち（381の練習試合の正式データ）:
  - 玉藻の前 ♀: Lv125のエスパーで『不動のエース』。特性わざわいのおふだ。もとは直哉の侍女で、異名『女狐』 → [玉藻の前 ♀](#玉藻の前-)
  - マタムネ ♂: Lv120のゴースト／くさ。『ベテラン』で「タイム」を貸す、ジバニャン種の『変種』 → [マタムネ ♂](#マタムネ-)
  - ブラックサレナ: Lv125のゴースト／はがね。『追加任命』の『アヴェンジャー』で、異名『亡霊』 → [ブラックサレナ](#ブラックサレナ)
  - ジゼル・ジュエル（ジジ）♂: Lv120のどく／フェアリー。『エースアシストβ』で、特性ひとでなし。女の子のふりをしている → [ジゼル・ジュエル（ジジ）♂](#ジゼルジュエルジジ)
  - マンハッタンカフェ ♀: Lv120のゴースト／あく。『エースキラーα』で、異名『猟犬』 → [マンハッタンカフェ ♀](#マンハッタンカフェ-)
  - タナトス: Lv120のゴースト。『先発』の『狩人』で、「しにがみのかま」を持つ → [タナトス](#タナトス)
- 104の時点（トバリ杯）の手持ちはLv60〜65で、今はいないジバニャンとノロイダーもいた → [104の時点の手持ち（トバリ杯）](#104の時点の手持ちトバリ杯)
- 種属ポテンシャルは、104では6体とも1つずつ（第一階梯）、381では3つが3体・2つが3体
  - **104の時点**では、手持ちは6体とも種属ポテンシャルが1つずつ（第一階梯）で、『役割』持ちは4体（指示型なので4つまで）。021にいたスカルグレイモン（体力B前後（90〜105）△）は、トバリ杯では出てこなかった。（出典: 021, 104）
  - **381の練習試合**では、玉藻の前（『良妻狐の〜』）・マタムネ（『猫又霊の〜』）・ブラックサレナ（『黒百合の〜』）が3つ（第三階梯）、ジゼル（『滅却師の〜』）・カフェ（『霊馬娘の〜』）・タナトス（『愚死神の〜』）が2つ（第二階梯）。『役割』は基本の4つ（『不動のエース』『エースアシストβ』『エースキラーα』『狩人』）に、『ベテラン』のマタムネと、SPゆらの『追加任命』の『アヴェンジャー』のブラックサレナが加わって、6体とも持っている。（出典: 158, 377, 381）
