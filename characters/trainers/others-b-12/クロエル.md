# マサゴ杯中規模大会（第三節）で戦ったチーム ／ クロエル（《灰翼エグリゴリ》の監督）

- カンナギタウンの「**能力**」型チーム《**灰翼エグリゴリ**》の監督で、マサゴ杯の出場チーム（③、PC操作）。“上位”のチーム（夜宵）。スポンサーは“シンオウ神話”にまつわる教会だったが、今は“腐れ天使”（クロエル）のわがまま放題（エウリュアレ。以前はブリジットの孤児院ともつながりがあった）。マサゴ杯の初戦でミラクルズに負けた（458〜461）。（出典: 454, 456, 458〜461）

- **トレーナーステータス**（461の正式データ）: 指示**B**／育成C／統率B-／能力**A+**。SPは神父の**モズグス**（サポート効果《**恐怖の異端審問場**》: 相手が「いちゃもん」状態になった時、低確率で相手のデータを解析する。稀にT終了時まで相手を「いちゃもん」状態にする）。456・459の反映では、カヲルの「キミだって「指示：B」のトレーナーなわけだしね」から指示B、ユベルの『魔精霊の渇愛』（トレーナーが「能力：A」以上の時に『愛の絆』。456）とルシフェルの『失墜』（トレーナーが「能力：A」以上の時に「霊」技を「溜め」なしで。459でカズマが図鑑で調べて初めて出た）から能力A以上と読んでいたが、正式データで確定した。（出典: 456, 458, 459, 461）

- 元神父に拾われた娘で、自分を天の遣いだと言う“電波”（ヴィルヘルム）。天使みたいな変なコスの“半ケツ天使”（ヴィルヘルム「恥ずかしくねぇのか、女以前に人間として………」、マルフォイ「でも美人だしあのコスチュームエロいし半ケツだしボクは好きだよ」、脹相「お兄ちゃんはこんな破廉恥なの許しませんよ！！！」）。作者: 「能力」型の自称天の遣いの怪しい女。ヴィルヘルムは以前負けたことがあって嫌っている（455）。（出典: 454, 455）

- 一人称「ボク」（「いやぁ、天使たるボクはやっぱり大変だよねっ」）。クロエルは（教会の信者に）自分を信仰させていて、カヲルとユベルは信者の対応をしている。ベレスは、信仰させているのも半分はクロエルの「能力」というか話術に近いと見ている（「ぶっちゃけ詐術って言っても納得するけど、こいつの「能力」」）。（出典: 456）

- 固有『**残酷なる天使の遊戯**』: 味方が場に出た時、3Tの間相手を「いちゃもん」状態にする。固有『**酷薄なる堕天の詐術**』: 相手が「いちゃもん」状態の時、相手ポケモンに発生する能力変化の「±」を反転する。相手の『トップバッター』、同時出しなら『エース』『アヴェンジャー』の能力上げも下げに変わる（カヲル）。こちらが相手の能力を下げる扱いになるので、《マサゴスタジアム》のフィールド効果（「水」「地」が相手からの能力減少を無効化）で差し引きゼロにされうる。対策は先発の「メンタルハーブ」（「いちゃもん」を消す）など。逆に「リーフストーム」「オーバーヒート」の能力下げは上げに変わる（カズマ）。ミラクルズでは、マックイーンの「まけんき」との相性が悪い（456）。天花「かなりいやらしい手合い」、ルサルカ「どっちかってぇと東堂あたりと似たタイプ」。（出典: 456）

- **458〜461（マサゴ杯の初戦）**: 先発にイノケンティウスを出し、クロエルの『固有』（『残酷なる天使の遊戯』）の「いちゃもん」で始め、『トップバッター』の反応がないのを見て「手練手管で色々やるチームって噂通り」。
  - T1のベルゼブモンの『全開特攻指令』の「じゃあくなほのお」を、ベレスへの交代と『灰教師の紋章』で無効化し、ベレスの『ベテラン』の「タイム」と専用『魔を断ち斬る天帝の剣』（『必中追尾』）でヤマトを倒した。
  - しかしカズマは揺らがず（クロエル「この程度じゃゆらいでくれないか、格下だったらこの2ターンで慌ててくれるんだけどねぇ」「………むかつく、全部ボクの思い通りって迷えるメリープになってくれればカワイイのに………」）。
  - ガッシュには「メンタルハーブ」で「いちゃもん」を消され（「ちぃ……そいつが「メンタルハーブ」か………！！！」）、ユベルが『戦闘続行』の「はめつのひかり」でガッシュと相打ちになったが、ルサルカの「いやしのねがい」（「――――――――――は……？」）、イカルガの「かげふみ」、ベルゼブモンの回避で押しつぶされた。
  - 終盤には「こいつの『固有』と『PT』、サポートって言うよりかき回すのに特化してやがるよホント」「手持ちが強ければ強いほど力を発揮するタイプだな……！！」「こいつらマジで頭おかしいんじゃねぇの！！！！？」。
  - 461の『酷薄なる堕天の詐術』は、ルシフェルの「いばる」をイカルガの「攻」-2に、ベルゼブモンの『グッドラック』の特攻+1を-1に反転した（後者で「だっしゅつパック」が発動）。
  - ルサルカを見て「……こいつ、ボクと同じ手合いって感じかも」（460）。
  - 作者: 選手の水準もそれなりに高い半ケツ天使、でもそれなりじゃウチには勝てない（461）。（出典: 458, 459, 460, 461）

- 479: カズマのフリーイベントの安価（3D8）で「クロエルがなんかやってきた、すいませんウチはアルセウス教（？）なんです」が選ばれた（作者「自称天使の布教活動」）。483で描かれた。中身は同じ枝の「[483（“グレゴリ教”の勧誘）](根拠/009_クロエル《灰翼エグリゴリ_483“グレゴリ教”の勧.md)」。（出典: 479, 483）

- **483（“グレゴリ教”の勧誘）**: カヲルと探検堂に来て「どうも～、我が“グレゴリ教”の勧誘に参りました～っ！」。
  - マサゴ杯のバトル中から、カズマに変な気配というか“残り香”を感じ（「ぶっちゃけボクはうっとりするような香りかなって思うけどね」）、（自称）“天の御遣い”の自分と通ずるところがあると見た（「キミ、もしかしてなんか変わった出生とかない？」）。
  - 一番強いのはエールで、キャラ被りでアイデンティティを脅かすのでぶっ潰したく、マサゴの大会にエントリーしたのもそれが半分（そしたら出て来た【H】チーム（東堂）は変態で、もう二度と戦いたくない）。
  - 話題性抜群のカズマを眷属にして版図拡大を狙い、アルセウスを祀る教会の対象を自分に変えたい（「今なら洗剤も付いてくる」）。
  - 自分の「能力」は既存の宗派を乗っ取るのに使える（集団に対して、同調圧力やサクラでじっくり浸透させる）。
  - 乗っ取った教会の元の名前は「ムナンチョ・ヘペトナス教会」で、“グレゴリ教”に改めた（拾って育ててくれた神父さんには感謝している）。
  - 運営は真面目にモズグスに任せている（クロエル）。
  - 教会ではウタのチャリティー・ソングを使っている（「お金もかからないし楽で良いんだよね♪」）。
  - カヲルがウタのファンクラブに入っていると知って「お前、宗教の掛け持ちとか許されると思うなよ！！！！！！」「ボクの教義にズブズブに沈んでくれないとやだやだやだ！！！！！」、カズマにウタの幻滅する情報を求め（「優しいけど天然気味のお兄ちゃんが知らない間に下宿先で女つくってたみたいで」妹的にムカつく）。
  - 「じだんだ」を踏み、「よくもやってくれやがったな、おぼえてろよっ」と「すてゼリフ」を残して去った（半ケツ姿で布教していた）。
  - 作者: 『天賦エース』（狂信者）が手持ちに布教を完了させ「あとはお前だけだ」状態のクロエル。（出典: 483）

- 推測: クロエル本人の元ネタは不明。チーム名の「エグリゴリ」は堕天使の一団（グリゴリ）、固有の『残酷なる天使の遊戯』は『新世紀エヴァンゲリオン』の主題歌「残酷な天使のテーゼ」のもじりか。454の「元神父」は、483でクロエルが「拾ってくれた神父さん？育ててくれたことは感謝してるよ♪」と言う神父のことと読める（推測）。クロエルが乗っ取った教会（元の名前は「ムナンチョ・ヘペトナス教会」、今は“グレゴリ教”）の神父で、今は“元”神父になった（推測）。今も神父として教会の運営を任されているモズグス（456で「我が君クロエルさま」と呼ぶ。458でサポート効果が表示された）と同じ人かどうかは不明。（出典: 454, 456, 458, 483）
