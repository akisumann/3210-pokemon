# トレーナーとして

↑ [エール・モフス](../ail.md)

- **トレーナーステータス**: 指示B／育成C+／統率C／能力**A+**（068、144の公開データ。変わっていない）（出典: 068, 144）
- 資質は「**能力**」型。自分で「技」を使える（「エールの一撃」で空を飛ぶタツマキを撃ち落とした）。バッジ3つを取って、ようやく使いこなせるようになってきた（出典: 032）
- ダンジョン出身のヌシ（統率B以上が必要）は仲間にしにくい。タツマキ（要統率B-）が従っているのは、「能力：A」以上のトレーナーには必要な統率が1ランク下がるから（出典: 036, 050）
- 第一『固有』『授けられし裁きの権能』: パーティ全員が「技能拡張：さばきのつぶて」を出せる → [根拠](根拠/トレーナーとして_04_第一固有授けられし裁きの権能.md)
- 第二『固有』『降り注ぐ裁きの魔力』: 「さばきのつぶて」に好きなタイプを1つ足す → [根拠](根拠/トレーナーとして_05_第二固有降り注ぐ裁きの魔力.md)
- 第三『固有』が目覚めかけている（422で感覚が研ぎ澄まされていると言い、457で「いよいよ目覚めそう」） → [根拠](根拠/トレーナーとして_10_第三固有が目覚めかけている.md)
- はまれば強いが安定感に欠ける（アバン）。タイプが偏っている自覚がある（出典: 067, 142）
- 『熟達指令』の教え方がうまい（「今までよりちょっと多めに、かつ長めに力を込める」）。『全開指令』は上位互換ではなく、居座りなら『熟達』が使いやすいと言う（出典: 051, 152）
- 研究所の助手なので知識が豊富で、ダンジョン深度2の仕組み、四式、エキスパンションなどをカズマに教えた（出典: 033, 034）
- ギンガ団のサターンに、フィールドを作る力の気配を感じ取られている → [根拠](根拠/トレーナーとして_09_ギンガ団のサターンカイトがエールに.md)
