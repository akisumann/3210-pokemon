# ハクタイ杯大規模大会で戦ったチーム ／ イレイナ（《波止場ウィッチクラフト》の監督）

- ミオシティの''波止場の宿''の一人娘（跡取り娘）で、《波止場ウィッチクラフト》（「B」中位の「能力」型チーム）の監督。エルザいわく人間性はダメダメの腹黒女で、船に密航しようとしては捕まっている（331）。**ハクタイ杯大規模戦の初日**の相手（同じ日に《真砂ブギウギ》とも当たる）。（出典: 331, 335）

- 335: 宿に泊まる紫が''アローラから来た''と知って「さぁ、この私にアローラのことを色々教えてくださいっ！やっぱエッチなところなんですかっ！！！？」。アローラ行きの船に密航する計画を立てようとする。他チームの店に来ただけでスパイ扱いはしない（「天一でバイトしてて近くの次郎に入ったら企業スパイになります？」）。紫・黒子・白野に夕食を奢ってアローラの話を聞くことに。黒子の新たな友人（？）。（出典: 335）

- 『エース』は''ブラック・マジシャン・ガール''（「ブラック・マジシャン」種の『天賦の才』、「エスパー/あく」。イレイナいわく『魔女っ子』で、魔法少女のような純粋さが消えない）。宿でモーモーミルクを運んできて、白野に「チップを頂ければ触っても良いですよ？」。「あのヨスガの変態チーム」を成敗したことがあるらしい（あっちの『エース』のロリが「一緒にすんなっ」と叫んでいた）。（出典: 335）

- 339（バトルビデオ）: 『固有』は2つ。『**西風に乗る魔女の箒**』（先行。味方が繰り出す「超」技に「とんぼ」効果を付与する）と『**旅路を巡る腹黒魔女**』（「とんぼ」技で味方が交代する時、相手の任意の能力を下げる）。「エスパー」メインの「とんぼ」による超高回転パーティ（ルサルカ）。古参の『アシスト』**ポップ**（特性「ムードメーカー」: 場を離れる時、味方の任意の能力を上げる。専用『勇気を示す使徒の紋章』: 味方の『エース』を発動させる『ペースメーカー』）。ブラック・マジシャン・ガールは特性「サイコメイカー」（場に出た時、5Tの間「サイコフィールド」）、専用『黒・魔・導・爆・裂・破』（『強化追尾』。@0/1）で「サイコブースト」。師匠（ブラック・マジシャン）は『ベテラン』になって『天賦』の資格を失い、ガールが『天賦』を継いだ。「サイコフィールド」だとマックイーンの「しんそく」やヤマトの「であいがしら」が封じられる。頼光の『鬼殺し』は、「魔法使い」「魔女」メインのこちらに刺さるかもしれない（ルサルカ）。（出典: 339）

- 340（直前ミーティング）: 推定「統率：B」前後（『天賦』込み）、「指示」は主力2体がいても「A」には届かず、チームのLvは105～120（ガブリアス）。イレイナ本人の「指示」はそれほど際立っていない。受け役を兼ねた設置除去もいる。
  - 『エース』**ブラック・マジシャン・ガール**（Lv120、エスパー/あく、特性「サイコメイカー」。技: サイコブースト、あくのはどう、ブラストバーン、マジカルシャイン、めいそう、あまえる。体力B（95〜105。「B」ランクの中ほど）△／攻D+／防C／特攻A+／特防A+（A-）／速B-。『不動のエース』、『天賦の才』、『魔女っ子』（「イレイナ」がトレーナーの時、自身の「特防」の種族値をトレーナーの「能力」と同ランクまで上げる）、『魔女娘の魔力』（「サイコフィールド」の時、相手の攻撃以外のダメージを受けない）『魔女娘の結界』（「サイコフィールド」の時、相手の「おいうち」効果の付与された技を無効化）『魔女娘の効果』、『デュエルモンスター』、『魂の絆』、『後の先』、『対虫』3つ、『気合い』、『カウントアーツ』、専用『黒・魔・導・爆・裂・破』（1/試/先行。「おいうち」効果と「必中」、「おいうち」効果の発動時に技のダメージ2倍））。
    - カズマ「相手の『エース』さんほぼほぼ『必中追尾』や『チェイサー』無効ってことですよねこれ」。
    - ガッシュは「エレキメイカー」で塗り替えれば2つ潰せ、『バオウ』なら貫ける（問題は「優先度技の無効化」）。
  - 『アシストβ』**ポップ**（Lv115、ほのお/エスパー、特性「ムードメーカー」。技: マジカルフレイム、サイコキネシス、れいとうビーム、もえつきる、ミラーコート、トリック、せいちょう、ちょうはつ。体力C（65〜85）○／攻C／防D／特攻A／特防B-／速B。『エースアシストβ』、『お調子者』（「イレイナ」がトレーナーの時、指示+1）、『魔導士の助言』（1/試 「ここぞ！」で「タイム」）『魔導士の呪文』『魔導士の勇気』、『シャハルの鏡』（1/試/自動 相手の「変化技」を反射）、『先の先』、『対悪』3つ、『気合い』、『リターンキュア』、専用『勇気を示す使徒の紋章』（場を離れる時、味方の『エース』を発動させる））。カズマ「サポート特化かと思いきや、意外と真っ向勝負も出来る性能してやがる」。（出典: 340）

- 345（大規模大会の初日2試合目、《六曜ミステリーズ》戦に勝利）: 作者いわく「能力：A+」で、『天賦』込みで「統率：B」のチーム（このランクなら従えられる『ヌシ』も出てくる）。ニャルマーの''キャル''（体力B（90〜100。「B」ランクの中ほど）○）が「しっぽをまく」で下がるたびに『旅路を巡る腹黒魔女』で相手の能力を下げ、元''こうてつ島''の「深度：2」の『ヌシ』の''タラスク''（みず/ドラゴン、波止場の宿の看板ペット、『海獣竜の重量』（1/試で自陣の設置技を除去）、体力AA+前後（160〜190。『怪甲』込み）○）で受け、ミオジムからレギュラーに上り詰めた''アールカンバー''（体力B（95〜105。「B」ランクの中ほど）○）もいる。『装填』持ちの『先発』とポップ、ブラック・マジシャン・ガールで序盤から流れを作った。相手の《六曜ミステリーズ》（六道骸）は、『エース』と相手の『エースキラーβ』の相性が最悪で、「指示」はどちらも「C」くらい（紫）。（出典: 345）

- **ハクタイ杯大規模大会の初日2戦目**（346〜347。カズマ戦、負け）: SPは**リシェル**（《ゆうべはおたのしみでしたね》。店番のバイト代をまだもらっていないと叫ぶ）。
  - 先発**アールカンバー**（はがね/エスパー、特性「フィルター」。イカルガと同じ「幻晶騎士」の種族に、属『マギウスエンジン』（『熟達指令』を『全開指令』に変える）、専用『波止場を守る純白の騎士』（能力が上がると「迎撃」状態＝受けたダメージの1/2を反動で返す））はガブリアスに倒された。
  - 『追加任命』は『アヴェンジャー』の**キャル**（ニャルマー。宿の食料庫を漁って捕まったのが縁。特性「けんかうり」、異名『猫又』、専用『魔力解放・グリムバースト』（場に出て2T目の技2倍）。「ねこだまし」から2T目に撃つつもりだったが「こどもだまし」で止められた）。
  - **リネット・ビショップ**（「リーネ」。宿屋のバイトの面接に来た子で、BDに見せたら選手としても採用。専用『間隙を射貫く空戦魔女』（交代で出ると相手の持ち物を「ねらいのまと」に）、種族『空魔女の追撃』『空魔女の狙撃』で「ヘッドショット」。作者いわく『役割』も持たないくせに脅威的な強さの『専用』を引っさげてきたバイト志望さんで、本体火力は並以下、体力C前後（60〜85）△）。
  - **タラスク**（属『モンスターシェル』、異名『怪甲』、種族『海獣竜の甲羅』、ゴツゴツメット、専用『刃を通さぬ竜の盾よ』（ダメージ半減で必ず耐える））。
  - リシェルいわく、イレイナは『固有』の質がしょぼいと言われたことがあり、選手の『専用』の威力を重視するようになった背景があるかも。
  - 天花は魔女という部分と本人の気質で強力な『専用』が生まれたパターンと推測。
  - カズマとマックイーンの煽りに「こいつら人間性最低ですよ」。（出典: 346）
  - 347: タラスクは倒れ、キャルは『魔猫娘の秘密』（捨てずにいた仮面で解析を無効にして「混乱」）やタスキで粘ってマックイーンを倒したが、リネット、ガブリアスと相打ちのポップ、キャルが続けて倒れ、最後は『エース』のブラック・マジシャン・ガールがルサルカの『ストーキング』に捕まり、ガッシュに倒されて負け。正式データは**指示C／育成B／統率B（C）／能力A+**、SPは**リシェル・ブロンクス**。作者いわく、東堂が「統率」殺しなら、イレイナはむしろ「統率」のタフネスを苦手とするタイプ。（出典: 347）

- 368（焼き肉会）: 奢りにつられて来たら男性陣ばかりで「なんなんですかねこの人間性を下から集めたような地獄の男性陣」。カズマには女性陣の最下位にランクされている。2日目を丸々立て直せなかった。「''その単純なマシーンのギアを止められないのが一番どうしようもなくなる''」。手持ちのポップも同席（「もうやりたくない（小並感）」）。作者「どんどん不憫なポジになってる気がする」。（出典: 367, 368）
- **608（ミオ杯の観客席）**: 地元ミオの【H】チームとして観戦（「悔しいやら嬉しいやらですが」）。エドも抽選漏れした結果でガッツポーズしていた。ミラクルズに「エッグイですねぇ、もう二度とあんなのと戦いたくねぇっすわ（サイコソーダｸﾞﾞﾋﾞｰ）」。第三節でダージリンにも負けている。（出典: 608）
