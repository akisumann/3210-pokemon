# 錦木千束（《七つ星リコリス》監督）: 推測: 『リコリス・リコイル』の錦木千束（「喫茶リコリコ」、不殺主義）

↑ [錦木千束（《七つ星リコリス》監督）](../../others-c.md#錦木千束七つ星リコリス監督)

- 推測: 『リコリス・リコイル』の錦木千束（「喫茶リコリコ」、不殺主義）。サムスは『メトロイド』、エイラは『ストライクウィッチーズ』のエイラ・イルマタル・ユーティライネン、ロビンフッドは『Fate』シリーズのロビンフッド（『サーヴァント』、「顔のない王」も原作の宝具）、ミカエルは『機動天使エンジェリックレイヤー』か（元ネタははっきりしない）、コマンドウルフは『ゾイド』、ガーンズバックは『フルメタル・パニック！』のM9ガーンズバック（『ECS』も原作の装備）。
