# 左門（《召喚サモナーズ》の監督）: 234で監督は左門と確定

↑ [左門（《召喚サモナーズ》の監督）](../../others-c.md#左門召喚サモナーズの監督)

- **234で監督は左門と確定**（「統率」型チーム《召喚サモナーズ》）。チームの半数は「あく」タイプで、『エース』は''レッド・デーモンズ''、『二枚看板』は**パワー**（''悪魔''、「ちのやり」、『ヴァンピリック』（体力が回復した時、相手の体力を1/8ドレイン））。ほかに**才人**（モモを口説く）。「むし」はキライ。「B」ではまだ優勝なし。カズマのダンジョンアタック成功の煽りでななつぼしを奢らせ（「お前を殺して奪い取る（迫真）」）、エレンの企画でカズマたちと練習試合（テレビ）をすることに。「「統率」型同士」でカズマと波長が合う（モモ）。（出典: 234）
