# 一条武丸（《人力ハードラック》監督）: 237

↑ [一条武丸（《人力ハードラック》監督）](../../others-c.md#一条武丸人力ハードラック監督)

- **237**: ハクタイの《サイクルショップじんりき》で、ベルゼブモンのバイク（''愛機''）を整備した。ベルゼブモンが「ひきにげ」を覚えていると聞いて、メンテとパーツ代を''奢り''に（ベルゼブモン「カズマ、この人良い人だな」）。バイク好きは大体悪い奴＝ツレだと、''サイクリングロード''の案内も約束した（System: ベルゼブモンの人界で最初の友達）。今は「C」で、最近ブリジットに勝って優勝し、第二節の昇格もありうる。手持ちに**ゴールドシップ**（「ウマ娘」。マックイーンに絡む、メタ発言の多いキャラの濃い子）。「C」は「深度：2」、「B」は「深度：3」くらいのざっくり感（武丸）。ハクタイの都市チームは「B」中位の「統率」型で、早ければ近いうちにカズマとぶつかる、と教えた。（出典: 237）
