# 左門（《召喚サモナーズ》の監督）: 239（天花の分析）

↑ [左門（《召喚サモナーズ》の監督）](../../others-c.md#左門召喚サモナーズの監督)

- **239（天花の分析）**: 本名は**左門召介**。スポンサーの意向もあって3体が「あく」。『エース』は''レッド・デーモンズ・ドラゴン''（「あく/ドラゴン」の高種族値の''デュエルモンスター''種。異名『悪魔竜』＝左門がトレーナーの時、『エキスパンション（悪）』として扱う）。「C」からの主力に、『二枚看板』**パワー**（「フェアリー/あく」の敵性種、『ヴァンピリック』は「ドレイン」の回復でも発動。「きゅうけつ」や「たべのこし」も候補）と、『アヴェンジャー』**平賀才人**（「ノーマル」の速攻型物理アタッカー）。どちらも高種族値の怪物ではない。レベルは高くても95が上限で、90未満もいる見込み。トレーナーは「統率：A+」でカズマと同じ。（出典: 239）
