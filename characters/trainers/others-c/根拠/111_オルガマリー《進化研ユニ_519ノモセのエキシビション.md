# オルガマリー（《進化研ユニバース》のBD兼SP）: 519（ノモセのエキシビション）

- **519（ノモセのエキシビション）**: トバリ杯の2日後、ノモセスタジアムの“中規模大会”のエキシビションで、エールの《進化研ユニバース》がジムリーダーのロビンマスクと戦い、「2-0」で勝った場にいた。エールの第三『固有』『遙かなる裁きの神域』のフィールドを見て、内心「（“四天王”の朝比奈さみだれと並ぶ、「能力：AA+」……あの女王蜂よりさらに上………　尋常じゃないフィールドの力だけど……やはり相手にも作用してしまうのはどうしようもない…）」。勝ってカズマに自慢しに行くというエールに「あっちはプラス四天王も降して「A」昇格が確定（仮）してる相手だけどね」「しっかし相変わらずなついてるわねアンタ………」。四天王を狙う場所を「コトブキあたりで！！！」と雑に決めたエールに（AA内）「何を雑に答えてんのよ、アンタ！！！！」。（出典: 519）
