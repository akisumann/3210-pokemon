# 花開院ゆら（直哉のSP）: 158では直哉のSP候補で、196の時点ではSP。『追加任命』は『**アヴェンジャー**』、サポート効果は《ジョウトから来た陰陽娘》

↑ [花開院ゆら（直哉のSP）](../../others-c.md#花開院ゆら直哉のsp)

- 158の時点では直哉のSP候補で、『追加任命』は『**アヴェンジャー**』。直哉（「ウチの自称SP候補」）も玉藻も認めたくない。協会からの内々の連絡（「B」昇格内定と、直哉の『全開指令』禁止）を直哉に伝え、「ほな、楽しんで来たらええわ～」と電話を切った。「このクズ………（ボソッ）」。（出典: 158）
- 196の時点ではSPになっていた（カズマが直哉に「でもお前のSPって幼なじみの女の子がなったんじゃなかった？」）。350では直哉が「我がSPのゆら=サン」と呼んでいて、379〜381のカズマとの練習試合では、直哉のチーム《呪相カースメーカー》のSP（SP名：花開院ゆら）としてサポート効果《**ジョウトから来た陰陽娘**》（T終了時、低確率で相手を2Tの間「かなしばり」状態にする）が表示された。（出典: 196, 350, 379, 381）
