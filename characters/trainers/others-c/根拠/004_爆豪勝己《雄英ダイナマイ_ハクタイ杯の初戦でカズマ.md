# 爆豪勝己（《雄英ダイナマイツ》監督）: ハクタイ杯の初戦でカズマに負けた（3体残し）

↑ [爆豪勝己（《雄英ダイナマイツ》監督）](../../others-c.md#爆豪勝己雄英ダイナマイツ監督)

- ハクタイ杯の初戦でカズマに負けた（3体残し）。「あの2体（ガブリアスとルサルカ）に手札を削られ過ぎだ」。自分でも「速攻メインになりがち」なのを課題に思っている。《茶房グロリアーナ》にはダージリンの『固有』で速攻を封じられ、0-3で敗れた（グロリアーナは3体残し）。（出典: 074, 075, 076）
