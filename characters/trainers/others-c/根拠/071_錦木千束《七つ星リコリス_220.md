# 錦木千束（《七つ星リコリス》監督）: 220

↑ [錦木千束（《七つ星リコリス》監督）](../../others-c.md#錦木千束七つ星リコリス監督)

- **220**: レストランななつぼしでカズマと白野（スクールの後輩）を接客し、同じ席で昼休憩をとる（その間は手持ちのサムスとロビンフッドが店を回している、と千束「今はサムスとロビンが頑張ってるよ（適当）」）。エイラは''進化''して『異名』『**回避**』（1/試/このポテンシャルを『かわせ！』として扱う）を得た。千束の『固有』は『あたれ！』でも発動し、エイラは「みらいよち」状態だと『たえろ！』と同じタイミングで『かわせ！』『よけろ！』を使える。舐めてかかってきた相手を「みらいよち」とのコンボで倒した（最終的に「タスキ」まで使わされた）。ただ「B」ではまだ2位と3位が一回ずつ（エイラ「「B」はやはりキツイ」）。次はどこのジムにするか考え中。白野の相談相手（推しとの関係）になり、最後はカズマたちに「出禁にされる前に、さっさとお金払ってご退出くださいお客様（ﾆｺｯ）」。（出典: 220）
