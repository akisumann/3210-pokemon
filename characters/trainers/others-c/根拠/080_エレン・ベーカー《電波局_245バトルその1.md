# エレン・ベーカー（《電波局ニューホライゾン》監督）: 245（バトルその1）

↑ [エレン・ベーカー（《電波局ニューホライゾン》監督）](../../others-c.md#エレンベーカー電波局ニューホライゾン監督)

- **245（バトルその1）**: SPテリーマンのサポート効果は《イッシュ仕込みのテキサスブロンコ》（味方が怯まない）。図鑑で出た手持ちのデータ（出典: 245）:
  - **ウォーグル**（先発。ノーマル/ひこう、特性「まけんき」、きあいのタスキ。技: あばれる、ゴッドバード、ばかぢから、おいかぜ。体力B（実機100）△／攻A+。『トップバッター』『オールドタイプ』、種属『勇猛鷲の襲撃』『勇猛鷲の風切』（攻+2以上で「飛」技の溜めなし）『勇猛鷲の神風』、『ポケパワー』、『対氷回避』『対氷耐性』『対氷迫撃』、『ド根性』、『スターター』）。ロトムの「ほうでん」2発で倒れた。
  - **ホライゾン・アリアダスト**（「ホラ子」。ノーマル/エスパー、特性「アップロード」（相手の攻と特攻を比べて特防か防が上がる）。技: はかいこうせん、サイコキネシス、オーバーヒート、メガトンパンチ、ドわすれ。特攻AA。『エースキラーα』、異名『水平線』（威力150以上の技が当たると自陣の設置技を除去）、種属『自動人形の制御』『自動人形の嫉妬』『自動人形の忘却』、属『リピ・カタスリプシ』、『対の先』、『対虫回避』『対虫耐性』『対虫反撃』、『ド根性』、『アンブッシュ』）。露出ゼロの「PTAに配慮した正義のユニフォーム」（エレン）。特防+4まで積んだが、ルサルカの急所の「ちのやり」で倒れた。
  - **ハープ・ノート**（『エースアシスト』。でんき/ゴースト。「ゆうたいりだつ」（特/霊/70、命中後に交代する「とんぼ」技）、「オーバードライブ」などの「音」技）。『**ブラザーバンド**』（『絆』を持つ味方に、自分の『アシスト』が必ず発動）で、クリーブランドに『アシストβ』を渡す。エレン「（ミラクルズの『絆』を）ちょっと参考にさせてもらいマシタヨ？」。
  - **クリーブランド**（『ベテラン』。みず、えんごしゃげき。技: なみのり、れいとうビーム、アンカーショット、ほうでん、クイックターン、あらいながす。特攻A。『姉貴』、種属『巡洋艦の偵察』『巡洋艦の対空』『巡洋艦の帰還』（「おいうち」効果を受けない）、属『金銭欲』、『魂の絆』、『対の先』、『対電回避』『対電耐性』『対電反撃』、『ド根性』、『アドバイス』）。「タイム」と『アドバイス』でベルゼブモンを解析し、『もどれ！』で逃げた。
  - **キャプテン・アメリカ**（『エース』。かくとう、特性「おおきなたて」（全体技を無効）。技: クロスチョップ、シールドチャージ（物/鋼/70、優先度-3、「まもる」貫通、自分と相手の「防」で計算）、ロケットずつき、スターアサルト、キングシールド。攻A・防AA+（A+）。『不動のエース』、異名『スーパーヒーロー』、種属『超英雄の鍛錬』（育成A以上で防の種族値AA+）『超英雄の剛盾』（相手の攻が下がった時に持ち物を破壊）『超英雄の装填』、属『マーベル・コミック』、『魂の絆』、『後の先』、『対飛回避』『対飛耐性』『対飛迫撃』、『気合い』、『スラッグアーツ』）。「なんで『天賦』＆『タイトエンド』に「深度；3」の『ヌシ』が増えてるんだこのチーム………」。
  - **ハープ・ノート**の図鑑（246）: でんき/ゴースト、特性「**はんきょう**」（自分の「音」技が「まもる」等を貫通）、のどスプレー。技: オーバードライブ、ゆうたいりだつ、ようせいのうた、うたかたのアリア、シグナルビーム、でんじは、メロメロ。特攻B+・特防A。『エースアシストβ』、種属『電波歌姫の歌声』『電波歌姫の音波』『電波歌姫の楽譜』、属『ブラザーバンド』、『先の先』、『対悪回避』『対悪耐性』『対悪反撃』、『気合い』、『リターンヒール』。専用『**電波局より飛び交うシグナル**』（『ペースメーカー』型）でキャップの『エース』を発動させた。モモに「どうせアンタもおんなじような性根なんでしょ………ほらっ、本心をさらけ出せっ！！！！」。
  - キャプテン・アメリカは246で、ラムのみ、専用、『たえろ！』まで使ってガッシュ@1・ルサルカを倒したが、イカルガの「じばく」で倒れた（「………もっと、きちんとした大舞台でのリベンジを挑みたかったものだよ」）。
  - **ムック**: 6体のうちの1体（245の時点ではまだ場に出ていない。データは247の項）。試合の最初のカットインで「このムックが成敗して差し上げますぞー！！！」。
  - チーム全員がPT『ホライゾンテキスト』を持つ。
