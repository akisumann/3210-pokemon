# 左門（《召喚サモナーズ》の監督）: 240（テレビ撮影）

↑ [左門（《召喚サモナーズ》の監督）](../../others-c.md#左門召喚サモナーズの監督)

- **240（テレビ撮影）**: エレン先生の番組に「はぐれ悪魔超人コンビ」として、''男の娘''の**秀吉**（のちにSPと分かる。「なんでワシはこんな恰好をさせられとるんじゃ？」）と登場（目的は「キッズに''男の娘''性癖を植え付ける」）。台本は「登場から仲間割れまでアドリブ」。固有『**捧げられる悪魔の生け贄**』（味方が死に出しで出た時、味方の任意の能力を上げる）、PT『**悪魔召喚サークル**』（死に出しで出た時、相手の能力をランダムに下げる）。第一節の時点の専用は、レッド・デーモンズ・ドラゴンの『天地鳴動せし王者の鼓動』（『三角効果』型）と平賀才人の『神の左手ガンダールヴ』（『必中追尾』型）。「指示：C」なので『全開指令』はない。（出典: 240）
