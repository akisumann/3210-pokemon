# 錦木千束（《七つ星リコリス》監督）: コトブキ杯中規模大会の初戦でミラクルズに0-3で負けた

↑ [錦木千束（《七つ星リコリス》監督）](../../others-c.md#錦木千束七つ星リコリス監督)

- **コトブキ杯中規模大会の初戦でミラクルズに0-3で負けた**。序盤から『もどれ！』『かわせ！』『たえろ！』を切って『固有』で削り、エイラの「みらいよち」やロビンの『先行とんぼ』で4-4まで食らいついたが、ルサルカの『ストーキング』で『エース』のサムスを縛られ、ガッシュに押し切られた（「こりゃつっよいわ」）。ダージリンと直哉は「どこかで『四式』をケチっていたら、もっと押し込まれていた」「ここまでやってようやく五分」と評した。（出典: 136, 137）
