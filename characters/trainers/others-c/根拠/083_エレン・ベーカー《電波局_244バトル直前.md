# エレン・ベーカー（《電波局ニューホライゾン》監督）: 244（バトル直前）

- **244（バトル直前）**: キッズを泣かせたカズマとマックイーンの前に、「正義のヒロイン（真）」として登場（「正義の名の下に処刑してあげマース！！！！！」）。固有『**さぁ、リピートアフターミー！**』（PT全員が「技能拡張：アンコール」を使える）、PT『**ホライゾンテキスト**』（1/試/自動、相手からの「メンタル効果」を無効化）。「育成」型だが「そだてや」も使い、キャップ（キャプテン・アメリカ）と「兄貴姉貴」（クリーブランド）をLv100、ほかのメンバーもLv95まで上げてきた。テリーマン（SP）とキッズの応援つき。手持ち（出典: 244）:
  - **キャプテン・アメリカ**（『エース』）: 「キングシールド」でキッズをかばう。専用『**星条旗よ、永遠なれ！**』（『強化貫通』型。「闘」技1.5倍、「まもる」貫通）。エレンに''アロガントスパーク''の解放を許可される。
  - **ホライゾン・アリアダスト**（『エースキラーα』）: 専用『**大罪武装・焦がれの全域**』（『三角効果』型）。前回の負けは「ドわすれ」した。どちらもタイプ一致の「反動技」を持っていた（カズマ）。
  - **クリーブランド**（『ベテラン』。「姉貴」）: 特性「**えんごしゃげき**」（味方と交代して場に出た時、相手の体力を1/4減らす。瀕死にはできない）、異名『**姉貴**』（トレーナーが女性の時、自分に『魂の絆』を付与。マックイーン「つまり、百合ビッチ…………っ！！！」）、『**金銭欲**』（T終了時、中確率で持ち物が「わざマシン：ネコにこばん」に変わる。自分の意志では変えられない（作者））。ギャラは3割増し。作者いわく相手方の「ニャースポジ」。
  - **ハープ・ノート**: 良い感じのBGM担当。
