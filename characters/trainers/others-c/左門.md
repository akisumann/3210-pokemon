# 第一節で戦ったチームの監督・スタッフ ／ 左門（《召喚サモナーズ》の監督）

- コトブキ杯中規模大会に出た「統率：A+」の純「統率」型チームの監督。4戦目でミラクルズに負けた（ダイジェスト。お互いに『トップバッター』『アヴェンジャー』『二枚看板』がぶつかり、終盤にライナーが相手の『エース』を粉砕）。（出典: 130, 141）

- **241（練習試合その1）**: チームは「B」ランク。SPは**木下秀吉**（サポート効果《カスと悪魔と召喚獣》＝味方が交代して場に出た時、低確率で能力がランダムに上がる）。「指示」は『熟達指令』と『かわせ！』『たえろ！』を使う。パワーの『たえろ！』は「罰」として切らなかった。手持ちで出たのは次の2体。（出典: 241）
  - **ジャミラス**（Lv不明♂、ほのお/あく。特性「あくまのつばさ」（体力が満タンの時、必ず耐える。宙に浮かび上がる）、持ち物不明。技: ねっぷう、デッドラッシュ（物/悪/120/100、命中後に防・特防-1）、ちゅうがえり、おいうち、おにび、ちょうはつ。体力A（110〜120）△／攻C+／防C／特攻A+／特防B／速B-。ポテンシャル: 『トップバッター』、『**高地のヌシ**』（「飛」技半減。モモの見立てでは「2層」の『ヌシ』）、『鳥魔王の演説』（先発・死に出しで相手を挑発）、『鳥魔王の旋回』、『ドラゴンクエスト』、『対水回避』『対水耐性』、『ド根性』、『スターター』、『エキスパンション（炎）』、PT『悪魔召喚サークル』）。「しもふりにく」が好き（「作ろう！！毎日''しもふりにく''を食べられる世界！！！！！」）。見た目は鳥なのに「ひこう」ではない。
  - **パワー**（『二枚看板』、フェアリー/あく、体力D〜A-（44〜110）△。特性「たんじゅん」、たべのこし。技: ムーンフォースなど。種族『血魔人の生命』（1/試、体力満タンの時に物理0.67倍）、属『ヴァンピリック』、専用『**ワシは死んどらんが？死ぬのはお前じゃが？**』（ダメージを半減して踏ん張る））。ガブリアスを倒し、モモに倒された。PADが落ちた。

- **243（練習試合の決着、試合後の正式データ）**: トレーナーステータスは指示C／育成C+／統率**A+**／能力B-。
  - 手持ちの公開データ: **レッド・デーモンズ・ドラゴン**（『不動のエース』、Lv95♂、あく/ドラゴン、体力A〜（127〜）△、プレッシャー（場に出た時、相手の速を下げる）、だっしゅつパック。技: もえあがるいかり、りゅうせいぐん、だいもんじ、はかいこうせん、ソウルビート。特攻AA。異名『悪魔竜』、種族『赤魔竜の紅炎』『赤魔竜の破壊』、属『デュエルモンスター』、『魂の絆』、『スラッグアーツ』）、**パワー**（Lv90♀、フェアリー/あく、たんじゅん、たべのこし。技: ムーンフォース、バークアウト、ちのやり、きゅうけつ、いちゃもん。特防A。『固有種』、『血魔人の生命』『血魔人の血液』、『ヴァンピリック』、『ツートップ』）、**平賀才人**（Lv95♂、ノーマル、こんじょう、きあいのタスキ。技: なぎはらう、まほうのけん、からたけわり、でんこうせっか、ふるいたてる、まもる。攻A。異名『使い魔』（左門がトレーナーの時、特防の種族値+1）、『平民騎の魔剣』『平民騎の乱舞』、属『デルフリンガー』、『リベンジキュア』）、**コダール**（Lv90♂、エスパー/どく、はがねつかい、ひかりのねんど。技: サイコキネシス、ベノムショック、ラスターカノン、あくのはどう、リフレクター、どくどく。防A-・特攻A。『スカウター』、『水銀機の力場』『水銀機の障壁』、『アームスレイブ』）、**デミウルゴス**（Lv85、レッドカード）、**ジャミラス**（Lv85♂、あつぞこブーツ）。

  - コダールはヤマトとモモを倒し、「ここから怒濤の4枚抜きだっ！！！！！！」と息巻いたが、ベルゼブモンに『スカウター』で返され、マックイーンの「しんそく」2発でコダールとレッド・デーモンズが倒れて負け。

- **242（練習試合その2）**: 『熟達指令』のほか、「まもる」や『たえろ！』で粘る。ほかに出た手持ち（出典: 242）:

- **240（テレビ撮影）**: エレン先生の番組に「はぐれ悪魔超人コンビ」として、''男の娘''の**秀吉**（のちにSPと分かる。「なんでワシはこんな恰好をさせられとるんじゃ？」）と登場（目的は「キッズに''男の娘''性癖を植え付ける」）。台本は「登場から仲間割れまでアドリブ」。固有『**捧げられる悪魔の生け贄**』（味方が死に出しで出た時、味方の任意の能力を上げる）、PT『**悪魔召喚サークル**』（死に出しで出た時、相手の能力をランダムに下げる）。第一節の時点の専用は、レッド・デーモンズ・ドラゴンの『天地鳴動せし王者の鼓動』（『三角効果』型）と平賀才人の『神の左手ガンダールヴ』（『必中追尾』型）。「指示：C」なので『全開指令』はない。（出典: 240）

- **239（天花の分析）**: 本名は**左門召介**。スポンサーの意向もあって3体が「あく」。『エース』は''レッド・デーモンズ・ドラゴン''（「あく/ドラゴン」の高種族値の''デュエルモンスター''種。異名『悪魔竜』＝左門がトレーナーの時、『エキスパンション（悪）』として扱う）。「C」からの主力に、『二枚看板』**パワー**（「フェアリー/あく」の敵性種、『ヴァンピリック』は「ドレイン」の回復でも発動。「きゅうけつ」や「たべのこし」も候補）と、『アヴェンジャー』**平賀才人**（「ノーマル」の速攻型物理アタッカー）。どちらも高種族値の怪物ではない。レベルは高くても95が上限で、90未満もいる見込み。トレーナーは「統率：A+」でカズマと同じ。（出典: 239）

- **234で監督は左門と確定**（「統率」型チーム《召喚サモナーズ》）。チームの半数は「あく」タイプで、『エース』は''レッド・デーモンズ''、『二枚看板』は**パワー**（''悪魔''、「ちのやり」、『ヴァンピリック』（体力が回復した時、相手の体力を1/8ドレイン））。ほかに**才人**（モモを口説く）。「むし」はキライ。「B」ではまだ優勝なし。カズマのダンジョンアタック成功の煽りでななつぼしを奢らせ（「お前を殺して奪い取る（迫真）」）、エレンの企画でカズマたちと練習試合（テレビ）をすることに。「「統率」型同士」でカズマと波長が合う（モモ）。（出典: 234）

- 152のお疲れ様会（各チームのトレーナーとポケモン1体）にいた**左門**が監督、**才人**がポケモン（234で確定）。左門は「指示」がBに届かず（「「指示：B」以上の奴らなんか全員死ねばいいんだ！」）、全開指令を知らないカズマを「シンジラレナ～イ！」と汚い高音で煽った。才人は「ウチみたいな「統率」型」と言い、美少女の多さに喜んでいた。名前からすると、左門は『左門くんはサモナー』の左門召介、才人は『ゼロの使い魔』の平賀才人（召喚された使い魔）で、チーム名の「サモナーズ」とも合う。（出典: 152）
