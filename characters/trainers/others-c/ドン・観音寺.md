# 第一節で戦ったチームの監督・スタッフ ／ ドン・観音寺（《墓守バッドスピリッツ》監督）

- ズイタウンの南のダンジョン「ロストタワー」周辺の霊園をスポンサーにするCランクのチーム《墓守バッドスピリッツ》の監督。テレビにも出ている有名人（ガッシュはファン）。派手な格好で「ボハハハハ！」と高笑いする。メアリの知り合い。（出典: 121）

- トレーナーステータスは **指示C／育成C／統率AA-／能力B-**（125で公開）。統率のマイナスはトレーナーの精神性と、『アヴェンジャー』が……とサンズ談。第一節でのB昇格を狙っていて、Bに上がったら「そだてや」（ズイタウン）の初回半額を使うつもり。（出典: 121, 125, 126）

- カズマから「良からぬ気配」（バッド・スピリット）を感じたが、正体はわからなかった（オクタヴィアいわく「女難の相」）。テンガン山の方からも気配を感じ、来店から10分で去った。練習試合の日には、地下大洞窟で「異様なスメル」を感じた（正体は不明）。（出典: 121, 123）

- 固有ポテンシャル『**スメルズ・ライク・バッド・スピリッツ！**』: 味方の『役割』の発動時、相手のタイプに「霊」を付与できる（霊感が作用した「能力」）。PT『**キャノンボール**』: 敵陣に「霊」ポケモンがいる時、だん・ボール技に「おいうち」効果をつける。（出典: 122, 125）

- 124〜125の練習試合でカズマに負けた（カズマ側は2体残し）。天花からは「粒ぞろいだが、単機の戦力頼み。『交代』も考えていい」と言われ、本人も「『役割』の発動に交代は欠かせない、不利対面からの切り返しも」と認めた。統率型同士だと差がはっきり出た。（出典: 126）
