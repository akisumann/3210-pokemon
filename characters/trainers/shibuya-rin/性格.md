# 性格

- **面倒見がよく、教え方がうまい**（アカネより上）。カズマにタイプ・特性・持ち物、プロになる条件、ダンジョンのことなどを教えた（出典: 002, 003, 006）
- **口が悪く、意地っ張り**。典型的なツンデレ（出典: 003）
- **お化けが大の苦手**。森の洋館への挑戦は「0勝151敗」。週に一度は泣いて帰ってきて、夜中のトイレにティファニアについて来てもらう（出典: 003, 004）
- 森の洋館（ミラクルズの「ひみつきち」）には相変わらず近づけない
  - 森の洋館（ミラクルズの「ひみつきち」）には相変わらず近づけない。メアリの「なぞのばしょ」を初めて見た時は発狂しそうになった（「あれ絶対変なとこにつながってる」）。去年のジムリーダー対抗戦でも、メアリ戦での動揺がすごかった（モモ談）。（出典: 128, 130）
- **部屋が汚い**。自分では「アカネとは格が違う」と思っているが、ルサルカ判定で女子力6。冷蔵庫は空、戸締まりも適当（出典: 006, 025）
- System いわく「マーズの親友は所詮同類」（出典: 003）
- 実家に帰ると母に掃除を甘えてしまうタイプ
  - 実家に帰ると母に掃除を甘えてしまうタイプ。カズマに部屋の掃除を頼み込み、「私はアカネの次にダメな女でございます」と深々と頭を下げた（カズマいわく「同レベル」）。実家（親）はソノオタウン（ルサルカ談）。（出典: 043, 130）
- シアに片付けを手伝ってもらうのは、プライドが許さなかった（出典: 085）
- カズマのデートの誘いをかなり意識したが、「やたらと言わない方がいい」と釘を刺す
  - カズマに「デート行こうぜ」と言われてかなり意識した（デート意識度1D100:73）が、「そういうのあんまりやたらと言わない方がいい」「アカネとかライザを誘ったら喜んでついてくるかも」と釘を刺した。デートは最低でも割り勘。（出典: 043）
- ジム生にはとても慕われていて、恋愛相談も受ける（本人は彼氏募集中（笑））
  - ジム生にはとても慕われていて、恋愛相談も受ける（本人は彼氏募集中（笑））。ジム生いわく「ダメなとこ必死に隠せてるつもりなのもポイント高い」。8人のジムリーダーの中で一番残念という疑惑もある（ティファニア談）。（出典: 085）
- モモいわく、凛はアカネやライザの電話を楽しそうに受けていて、本当にイヤなら普通に言う（出典: 160）
- 占いの本を持っている（カズマの資質もそれで判定した）（出典: 003）
- お酒に弱い: 酒の強さ19/100（484のダイス。500で作者がエネルの17と比べた）
  - **お酒に弱い**: 酒の強さは19/100。484の「しぶりんお疲れ様でした」会の【お酒の強さ】のダイス（1D100:19）で、500で作者が「【悲報】神エネル、しぶりん（19/100）に負ける」と書いて、凛の値と分かった（エネルは17）。484の打ち上げでは開始30分後に酔ってハイになり、二次会のあともハシゴして朝方に帰った（翌日は「酒と記憶が残る女しぶりん」（作者））。500では、モモが「渋谷の方の凛ちゃんに言いますよ、おんなじ名前の女の子をお持ち帰りしようとしたって脚色して」とカズマを脅し、501では遠坂凛の酔いっぷりに「なんで私はいっつもリンって名前の女に苦労させられるんだよ」とぼやいた。（出典: 484, 500, 501）
