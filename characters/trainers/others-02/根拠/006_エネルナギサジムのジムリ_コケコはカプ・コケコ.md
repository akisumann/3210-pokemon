# エネル（ナギサジムのジムリーダー）: 154の「コケコ」はアローラの守り神カプ・コケコで、エネルが捕まえていた（476, 489で判明）

↑ [エネル（ナギサジムのジムリーダー）](../../others-02.md#エネルナギサジムのジムリーダー)

- 154でエネルが口にした「コケコ」（ロトムの希少さは「''コケコ''と同等以上やもしれん」）は、ポケモン原作のカプ・コケコ（アローラの守り神）のことだった。154でエネルが連れていた、アローラで捕まえた「超がつくほど珍しい古代種」もこれと読める。（出典: 154）
- 326では、メアリが「''カプ・コケコ''って名前が挙がった」とはっきり名前を出し、ガッシュは「黙っておいた方が良い」と言い、カズマは「アローラの守り神から目をそらすためにも」エネルは7番目くらいの予定、とはぐらかした。（出典: 326）
- 476でオシュトルが、身を隠す直前にエネルから「アローラでイイモン捕まえた」と聞き、それが「カプ・コケコ」という「準伝」級だと話した。489のナギサジム戦で、エネルの手持ちとして実際に出てきた（Lv145、性別なし、でんき/フェアリー。詳しくは [487〜489の根拠](019_エネルナギサジムのジムリ_487〜489ナギサジム.md)）。（出典: 476, 489）
