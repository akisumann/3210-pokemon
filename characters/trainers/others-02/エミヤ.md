# ジムリーダー ／ エミヤ（ミオジムのジムリーダー、はがね）

- ミオシティのジムリーダー。「**はがね**」統一の「**万能**」型の男性トレーナーで、かなりのマッチョ（ロビンマスクいわく見せ筋）。シンオウのジムリーダーでは**最古参**で、「一番安定したジムリーダー」と呼ばれ、ジムリーダーの中では「**オカン**」ポジション。モモは「エミヤさん」と呼んでいる。（出典: 130）

- **326（エルザとメアリの話）**: 名前は**エミヤ**。
  - シンオウ唯一の「万能」型ジムリーダーで、戦歴も長く、''全資質が「B+」の、所謂オール「B+」''（''資質の平均値なら地方トップクラス''。資質を開花させた「万能」のステージ）。
  - 「万能」型なら目標にする人物（以前5つめのジム戦で挑んできた、奏の同期の「万能」型も口にしていた）。
  - ロビンマスクに勝つなど下馬評をひっくり返すが、攻撃の相性以外でも不利なイングリッドにはフルボッコにされる。
  - 『固有』は2つで、どちらも「技能拡張」ありきの''外部要素が強い『固有』''（エルザ「ならばそれを準備するのが腕というもの」）: 『**投影する刃金の剣**』（味方が「技能拡張」で繰り出す技の威力を1.5倍）、『**展開する円環の盾**』（相手が「技能拡張」で繰り出す技の威力を半減。アリスいわく''「ばつぐん」を等倍で受けられる''程度とも言える）。
  - 『エース』は**エルザ・スカーレット**（はがね/フェアリー）。
  - コスプレ衣装でコンテスト巡りが趣味で、ヨスガに偶に来ては5部門全部に違う衣装で出て、散財している（エミヤには''破廉恥じゃない？''と言われた）。
  - 「''君らに負けてはいられない''って張り切っていたぞ？」。
  - 『二枚看板』は**マスラオ**で、特性は「**にとうりゅう**」（自身の「攻（特攻）」を「特攻（攻）」と同ランクまで上げる。2割で攻撃を回避する）＝完全な両刀型（メアリ「右も左も必殺級のパンチが飛んでくる」）。
  - エルザ「どうせ私とマスラオのデータを抜かれないとはこっちも考えてないしな、それではジム戦で会おう」。（出典: 326）

- **327（ジム戦の前）**: ミオジムで、眼帯の女性**ヘファイストス**（「光栄至極………ってなもんじゃないの？エミヤ」）とエミヤ、エルザが迎える。エミヤ「君たちの評判を知る以上、きちんとそれに応えられるメンバーを選出するのもジムリーダーの務め」。ほかの所属: 「むし/はがね」の『アヴェンジャー』**三世村正**（「なんかあっちエロゲ出身っぽいヤツがなんか言ってるけどどうする？」、体力A前後（100〜140）○）、「はがね/ひこう」の『キラー』、港町の防衛も任されるので''艦娘''も所属している。イカルガの読みでは、『エース』『二枚看板』『アヴェンジャー』がそろうので、「統率：B+」でどれかを任命している可能性が高い。ジムバッジは''マインバッジ''。（出典: 327）

- **328（ジム戦）**: 戦闘準備は1D3:1で>>643（ガッシュ（いのちのたま）、マックイーン（じゃくてんほけん）、ルサルカ（しんぴのしずく）、ロトム（だっしゅつパック）、ベルゼブモン（こだわりスカーフ）、ガブリアス（レッドカード）、先発ガブリアス、『全開』）。
  - ヘファイストスのサポート効果は《刀匠の造りし鋼の剣》（「けん」「つるぎ」等の技1.2倍）。
  - 先発は**ライガーゼロ**（はがね、特性「いかくのキバ」（場に出た時に相手の攻ダウン。「かみつく」「キバ」等の技1.5倍）。技: アイアンヘッド、かみくだく、ドリルライナー、かみなりのキバ、つめとぎ、みきり。体力B前後（90〜105）△／攻B／防C／特攻C+／特防C-／速A+。『狩人』、『零機獣の威嚇』『零機獣の鋭牙』、『ゾイド』、『対闘回避／耐性』、『ド根性』、『狩人薬』。持ち物はきあいのタスキ）。
  - ガブリアスの「レッドカード」で三世村正が引っ張り出され（「ちょっと待って、まだ私甲冑着てないんだけど」）、「ドリルダイブ」で大きなダメージ@1（エミヤ「等倍で村正を半分以上持って行くか………エネルと私への天敵だな、コイツ」）。
  - ライガーゼロはマックイーンの「うまのり」をタスキで耐え、ガブの「さめはだ」で倒れた。
  - **セルレギオス**（はがね/ひこう、『エースキラーγ』、異名『**裂刃**』（「スケイルショット」が最大まで命中）、『千刃竜の刃鱗』（「スケイルショット」で倒した時に敵陣に「まきびし」）、ゴツゴツメット、体力A前後（105〜135）○）がガブリアスを倒した。
  - マックイーンの「しんそく」に『もどれ！』で**マスラオ**を出す（「「ステルスロック」だと？そんなもの怖がる私ではないわぁっ！！！！！」、『モビルスーツ』に着替えてステロを無視）。
  - エミヤ「キミが藤ねぇなわけがないっ！！！！！！」（マックイーンを見て）。（出典: 328）

- **329〜331（ジム戦の決着）**: マスラオはベルゼブモンと撃ち合ってこれを倒したが、マックイーンの「オーラぐるま」に倒れた。
  - 大鳳（みず/はがね、体力B〜A（100〜135）○）は交代で出てベルゼブモンに倒され、村正は『磁剱冑の磁気』でマックイーンの「じゃくてんほけん」を「じしゃく」に変え、「しんぴのつるぎ」でマックイーンを倒したが、ガッシュの「でんげきは」に倒れた。
  - エルザは『剣の女王』と「はいすいのじん」、わざマシンの「ギアソーサー」でロトムを、『ティターニア』の「しんぴのつるぎ」でルサルカを倒したが、最後にガッシュに倒され、ミラクルズの勝ち（エミヤ「見事、その強さ………確かに見せてもらったよ」）。
  - 正式データは**指示B+／育成B+／統率B+／能力B+**。
  - 手持ちはライガーゼロ、セルレギオス（『千刃竜』3つ、『モンスターハンター』）、マスラオ（かくとう/はがね、専用『天地を別つ一対の剣』）、三世村正（むし/はがね、異名『電磁刀』、属『ニトロプラス』、専用『ツルギの理ここに在り』）、大鳳（『エースアシストγ』、『装甲空母』2つ）、エルザ（はがね/フェアリー、専用『我が剣に集え、兵たちよ』）。
  - 331でエルザ「「スチールソード」よりも『固有』に耐性貫通がつくから偶に使うんだよ、6つめ以降は」、''「B」の上位''には「A」に匹敵する実力者もいる、と忠告。（出典: 329, 330, 331）
  - 『エース』**エルザ・スカーレット**（Lv120♀、はがね/フェアリー、特性「おおたちまわり」（自身の「攻」の種族値を1ランク上げ、2割で攻撃を回避）。技: スチールソード、まほうのけん、せいなるつるぎ、つばめがえし、つるぎでまもる、はいすいのじん。体力B〜A（95〜130）△／攻AA（A）／防C／特攻B／特防B+／速C）。ポテンシャル: 『不動のエース』、『剣の女王』（「エミヤ」がトレーナーの時、自身の持ち物のわざマシンを消費しない）、『緋剣姫の千剣』（持ち物がわざマシンの時、「技能拡張」の技がタイプ耐性を貫通）・『緋剣姫の魔鎧』（持ち物がわざマシンの時、相手の「攻」の上昇を無視）・『緋剣姫の剣舞』（「けん」「つるぎ」等の技で倒した時、攻+1）、『ティターニア』（1/試/自動。「しんぴのつるぎ」を出す時、「特攻」を最も高い種族値と同ランクに）、『愛の絆』、『対の先』、『対炎回避／耐性／反撃』、『気合い』、『スラッグアーツ』。専用『**我が剣に集え、兵たちよ**』（PTに参加している時、自身を含む味方全員が技能拡張「しんぴのつるぎ」を出せる）。
