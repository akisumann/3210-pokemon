# 先輩（さすらいの先輩）

> カズマに初めてトレーナー戦を教えた、噛ませ犬オーラ全開の「万能型」の監督。本当にいい人。第一節では《随牧スペリオール》を率いてCランクの三本の指に入り、ノモセ杯の決勝でカズマたちを0-3で下した。

## 概要
| 項目 | 内容 |
| --- | --- |
| 呼び名 | 本名は名乗らない。「人は俺のことをさすらいの''先輩''と呼ぶ」。カズマを「後輩」と呼ぶ（出典: 010, 092） |
| チーム | 《**随牧スペリオール**》。スポンサーはズイタウン。「スペリオール」は「目上の」のニュアンスでつけた名前（出典: 092） |
| ランク | C（プロ3年目。今年一気に頭角を現した）（出典: 010, 092） |
| 資質 | 指示B／育成B／統率B／能力B の「**万能型**」（出典: 011） |
| バッジ | 4つ（ダイス【1D8:4】）（出典: 010） |
| 初登場 | 010 |

## 現在の状態（092時点）
- 《随牧スペリオール》は、今季すでに小規模大会を3回優勝し、Cランクでも三本の指に入ると言われる（推測: マサゴタウンの大会で決勝でエールを破った優勝も、その1つ）。（出典: 062, 092）
- ノモセ杯の決勝でカズマたちと当たり、0-3で勝って優勝。手持ちは全員Lv70〜80で、「育成」型クラスの練度。『専用』は1つ。「今のお前らよりは少なくとも俺たちの方がレベルは上だぜ」。（出典: 092）
- カズマたちにとって、第一節の中規模大会で《園生クインビーズ》と並ぶ目標のチームになった。（出典: 092）

## 性格
- 神々しいまでの「**噛ませ犬オーラ**」をまとっている。ルサルカでさえ「噛ませ犬オーラでまったく歯が立たない」と言うほど。（出典: 010）
- かませ犬オーラはすごいが、**本当にいい人**。何の縁もないカズマたちに、ポテンシャル、資質、敵性種、統率などを丁寧に教えた。（出典: 011）
- トレーナー論は「ポケモンがどれだけ成長できるかはトレーナーしだい」「負けても楽しめるのがポケモンバトル」。「トレーナー同士、目が合ったらポケモンバトル」という言葉が大好き。（出典: 011, 013）
- 目標は「Bランクに昇格して、スポンサーのギャラとメディア出演を増やす」こと。（出典: 013）

## 能力・特徴
- **万能型**: どの資質もAに届かない器用貧乏（自称）。図鑑の備考は、指示「平均より上。でも油断や慢心が友達」、育成「学校にいる普通に優秀な先輩」、統率「かませオーラさえなければもっと人望ありそう」、能力「このかませオーラから出力されるものは一体……？」。（出典: 011）
- ノモセ杯では、要所でカズマの「指示」を外し、正面からの強襲でリードを作った。4つの資質のうち、統率ではカズマが明確に上だが、残り3つではカズマが遅れを取っている。「質を数で押しつぶされる」。（出典: 092）
- 主力3体に『固有』ポテンシャルを搭載している、と原典にある（「※上記は原文表記」とされていて、意味ははっきりしない）。（出典: 092）
