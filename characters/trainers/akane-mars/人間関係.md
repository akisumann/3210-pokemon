# 人間関係

- カズマ: 拾った元家政夫 → [根拠](根拠/人間関係_01_カズマ.md)
- [ゼットン](../../pokemon/zetton.md): エース。長い付き合いだが、ゼットンはカズマとルサルカの家事に胃袋をつかまれ、カズマ側につくことが多い。カズマについて行こうとしたので「しばくぞ」（出典: 001, 005, 038）
- [渋谷凛](../shibuya-rin.md): 親友（「しぶりん」）。同類。298ごろPVのポジションで煽り合ってキン肉バスターを食らった（304）。310でカズマを''管理''する''タッグ結成''
- [ルサルカ](../../pokemon/rusalka.md): カズマをめぐって険悪。「変態ペチャパイ女」と呼ぶが、料理はおかわりして食べる。187では『汚部屋のヌシ』と呼ばれた
- [出雲天花](../tenka.md): ミラクルズのSP。187でマーズ宅の掃除を手伝った。ギンガ団のスカウトを断った人
- [ティファニア](../../pokemon/tiffania.md): 「アカネちゃん」と呼ばれる仲（出典: 003）
- ジュピター（コーネリア）: 同じ三将星 → [根拠](根拠/人間関係_07_ジュピターコーネリア.md)
- 朝比奈さみだれ（その他のトレーナー）: 四天王。159の決勝で勝った相手で、ビルによく来る → [根拠](根拠/人間関係_08_朝比奈さみだれその他のトレーナー.md)
- アシュロン: ボス（アダム）の『エンペラー』で元『テンガンのヌシ』 → [根拠](根拠/人間関係_09_アシュロン.md)
- ギンガ団の社員A・B: アカネをいじり倒す部下。後日しばかれた。479でも「そこの自販機でいっすか？」とお茶出しを雑に扱った
- クーデリア・藍那・バーンスタイン（[その他のトレーナー](../others.md)）: 《銀河団アンタレス》のSP。アカネの女子力に「怖いのは貴方達の女子力なんですよね」。偶に家の手伝いに行くが力及ばず（479）
- 「ボス」: 「ボス以外の相手なら（電話に）出るつもりない」と言っている。ギンガ団の社長アダム（アカギ）のことと思われる（補足: ユーザーより。「多分そう」）。（出典: 000, 001, 002, 003, 005, 019）
