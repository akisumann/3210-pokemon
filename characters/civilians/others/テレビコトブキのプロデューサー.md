# 街の人・報道 ／ テレビコトブキのプロデューサー（PVプロジェクト''GOTCHA！''）

- マフラーに裸足の敏腕P。ウタを主軸にテレビコトブキが作っている、シンオウプロリーグのプロモーションビデオ''GOTCHA！''の担当。シンオウ想いで、地味と言われるシンオウを売り出すため「利用出来そうなものはなんでも利用したい」。（出典: 255）

- 255: ウタが持ってきたカズマのアイディア（「トレーナーがポケモンと走るシルエット」、ジムリラッシュ、開幕で線路を歩く4人組など）に食いつき、''探検堂''に乗り込んで協力を要請（ダイス）。カズマとPV談義で意気投合し（「――――――――――ええやんっ！！！！！」）、「アイディアの提案」役として巻き込んだ。報酬は小切手を置いていき、スタッフロールにも名前を入れる。ウタに教えた歌のうちポケモン主題歌のいくつかを、ウタのカバーとしてチャリティーソング（収益は寄付）で出す。カズマにはPVに「若い多くのトレーナーの中の1人」として出てほしい（出演オッケーと思い込んで根回しを始めた）。（出典: 255）

- 307: ''ギンガ団''の総帥が長期のイッシュ出張になり、PVの撮影計画に悩む（「''エイチ湖''………いや、そんな妥協を許して良いのか……っ！？」）。キッサキジムリーダー（シア）にも翌日エイチ湖に来てもらって相談するつもり。「カズマ氏だったら''テンガン山''でも平気でOKくれるか？」「彼も私と同じ''ロマン''を求める同志な気はする」。彼のこだわりもあって、カズマたちの撮影は少し遅れ気味。（出典: 307）

- 309: エイチ湖で、シアに「''吹雪の雪山''感が弱い」「''テンガン山''の「深度：3」で撮影すべきなのでは？」（シア「頭湧いてんのか、マスコミ」）。「今からシンオウの伝説を作ろうってテンションなんだよこっちはっ」「妥協したくないんだよっ」。カズマがメリュジーヌの承諾を取ってきたが、撮影はカズマたち以外は最低限になり、ロトムとベルゼブモンが撮った映像だけを受け取ることに。（出典: 309）

- **412（ブリーダー番組の出演依頼）**: カズマを「Pくん」と呼ばれる仲（カズマいわく''テンガン山''でメスガキ騒動で怒られる遠因になった人。PVの完成版はもう少し先）。
  - 先日のヨスガ杯は現地で見た。
  - 電話で、自分の企画した深夜枠のテレビ番組''ブリーダーさん、いらっしゃ～い''（仮）への出演を依頼した（「プロのバトル、その場を彩る選手に監督、そしてサポーター！！！！」「それまでの準備で重要な役割を持つ''縁の下の力持ち''………彼らなくしてプロリーグは語れまい！！」）。
  - 監督とBDのセット4組（4つの資質のチームごと）、「B」の''中位〜上位''でそろえ、視聴率がよければ次回以降は「A」や「C」も。
  - スクールのエルメロイ校長からの打診を受けた企画で、実はテレビコトブキのアバンと2人で持ってきた話。
  - ゲストは''そだてや''の沖野、司会進行はウタを呼ぼうかと考えている（「こうなったら予算かけまくってやろうかな（こんらん）」）。
  - 話題性込みで「統率」枠はまずカズマと考えていて、カズマに推薦されたエールのチームも入れ（内心「よっしゃ、候補の一角が芋づる式に釣れたわ」）、残り2チームは「真面目側」にする。
  - 世間ではミラクルズのBDは''多分頭おかしいヤツなんだろうな''と思われていると教えた。
  - カズマから送られたライザの写真に「なんや、この脚は…………っ（戦慄）」、放映したらまた''探検堂''が話題になるかも、ついでにカズマのアレコレを暴露してくれると嬉しい、と考えた。（出典: 412）

- **417（収録）**: 台本のない収録が超人レスリングになり、お偉いさんに詰められたが、誰かの「これで放送してみない？」で放送され、一部の層（ほぼ「育成」型）にバカ受け。アンケートや署名で、月一くらいのプロの監督・BD・SPによるレスリング番組として続くことになった。（出典: 417）

- **444（PV完成版の修羅場とFilm Red）**: PV完成版の現場は修羅場を超えた修羅場で、もうすぐ完成。帰そうとしたスタッフが「おうちに帰して」と鳴きながら戻ってくる。カズマに情報を止めていたのは、スタッフが主犯（？）のカズマに会いたがり、巻き込んだら最低三日は帰さないつもりだから。ウタの短編ドラマ（PVのトレーナー役が異様に受けて決まりそう。カントーからもカイバーマンというペンネームのお便り）に「なんか面白いアイディアとかない？」とカズマに振り、二人で主人公まわりを詰めた（ヒコザルを提案。夢の中に誘うポケモンの影の電波を受信）。メアリ嬢の『固有』のイメージがライバル役にまんまなので出演オファーを考え、内心でPVと連動した企画の一部（“ジム巡り”、“古代種”、キッサキなどシンオウの地を発信）として動くつもりで、スタッフの反応次第で上に掛け合う。System: PVを発端とするシンオウ全体のプロモーション活動が、このテレビ局を爆心地にさらなる連動と広がりを見せる。（出典: 444）

- **477（ドラマPVへ）**: PVの完成後、スタッフはウタ主演の連動ドラマのPV作成に移った（カズマのエキシビション勝利の報でまた火がついた）。ウタの話の再現では、「お前らさっさと帰れや！！！来週からだっつってんだろうが！！！！！！」「これ以上私を上のお偉いさんから目をつけられる真似をするんじゃねーぞ！！！！！」と言いつつ急遽「タウリン」を買い込み、「お前らはさっさと帰って寝ろ、その間にカズマをここに呼ぶんだよ！！！」。スタッフA〜Eは「おめーが一番帰るつもりねぇだろうが」「こちとらPVでボツになったシーンがいくつもあるんだ、じゃあそっちに流用してやろうじゃねぇか！！！！」「私らには全然会わせる気配がないくせに」と反発。PVに関わる部署の約9割（1D10:9）が“ミラクル団”入りしていて、スタッフ一同カズマのファンになっている（ウタ）。プロデューサーは加入していない「後方彼氏面」（プリン）。カズマからもっとネタを絞ってこいとウタに言っている。ドラマのパートナー（ヒコザル）に「もう一声何か欲しい」。（出典: 477）

- **491（ドラマと「グラシデアの花」）**: 凛にドラマのオファーが翌日ハクタイ上層部から来る件で、リアルタイムで「グラシデアの花」をそのドラマに思いきり使っていくことを上と企んでいる（作者の※注）。このあと、ウタの方につけることを提案するカズマと、メアリの方が似合うと言うPくんとで、夜通しの通話バトルになる（作者の※注）。（出典: 491）

- **502（ウタのライブ、ドラマとラジオ）**: 朝3時まで連れ回されたカズマを朝から“拉致”し（探検堂に電話したら、ナギサジムに泊まったと聞いた）、チケットが要ることを忘れていたカズマとレヴィの分の席も用意していた（「ぶっちゃけ、どうせこんなことだろうと思っていてね」）。

  - プロデューサーなのに一般席にいるのは、隙あらばカズマを口説くため（お偉いさんとつまらない話をするより有意義）。
  - ステージにゲストで出ている「ウマ娘」のオペラオー（コンテストのマスターランクで話題のポケモン）は、ウタがカズマからぶっこ抜いたアイディアを流用してドラマに出てもらう子で、引っ張ってきたのはメアリ。

- **502（地方対抗交流戦）**: プロジェクトの企画の一つとして、第三節が終わったあとに開く“地方対抗交流戦”の開催地がシンオウに先日決まった。

  - 他地方からはプロチームがメインで、ランカーやジムリーダー（2人も来れば多い方）、四天王も各数人ずつ。
  - シンオウ側のジムリーダーも全面的に参戦する予定で、四天王vs四天王、ジムリーダーvsジムリーダーもありうる（メアリ）。

  - 海外から来るトレーナーをシンオウ勢が迎え撃つ形で、他地方へのアピールにしたい。

  - カントーの四天王筆頭（ワタル）は来ることを（勝手に）宣言している。

  - カズマ: 第四節（シーズンのラスト）の前にまた大規模なイベント。（出典: 502）
