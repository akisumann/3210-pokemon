# クシャルダオラ（クシャル）: 519（BBQで餌付けされる）

- **519（BBQで餌付けされる）**: 518のフリーイベントの安価で「森の中、パシられるクシャルくんをBBQで餌付けする男」が選ばれた（作者「そして餌付けされるクシャルくん、お前古龍だぞ……」）。トバリ杯の打ち上げのあと、カズマがマックイーン・ライナー・ヤマトを“ボディー・ガード”に、残った肉とスイーツとBBQセットを持ってテンガン山の近くの森へ行き、ついてきたライザとクシャルダオラを餌付けした（「なんじゃあ、このボディー・ガードどもは………」。内心「いざとなったら「ふぶき」で目くらましして逃走してやろっと」）。
- **『メッセンジャー』**: カズマ（AA内）「安心しろ、こいつの『役割』は『メッセンジャー』だから」。「深度：4」の『テンガンのヌシ』（ごす）のメッセンジャー（ライザ「なんで街の近くにそんな奴がおるねん」）。
- **格**: カズマが「友好種」の『変種』では？と言うと、ライザは要「統率：C」以下の古龍なんていたら争奪戦がエラいことになる、「敵性種」は基本的に「B」以上で、こいつはどう考えても「A」と答えた。「ドラゴン/はがね/ひこう」（ライザ（AA内）「しぶりん殺し極まったタイプしてるし……」）。ヤマト: レベルは「140」ほどで、単機ならどうとでも料理できる。ライザ: 「140」は去年までなら「B」の最上位チームでも即戦力のはずで、凛も今のレベル帯に驚いている。決勝で戦ったバハムート、ディアウス・ピター、アカムトルムも本来はこいつと同じ要「統率：A」の怪物（ライザ）。
- **街に攻め込まない**: ライザに街に被害を及ぼさないかと聞かれ、「へっ、誰がオープニングで俺をストレス発散で焼いた女の街に攻め込むかっ」（000でアカネのゼットンに八つ当たりで倒されたことと読める。アカネはハクタイのギンガハクタイビルにいる。推測）。ライザ（AA内）「えっ、誰だよ「深度：4」まで行ってそんなことする奴」。
- **下っ端根性**: その『ヌシ』が捕まったら付いてくるのかと聞くマックイーンに「ふざけるなっ、なんで仮にごすが捕まった後も俺がパシられにゃならんのだっ」（AA内「古龍ってのはなぁ、もっと自由であるべきなんだっ」）、その時は次の『テンガンのヌシ』となるべく下剋上をかます（ヤマト「ボクも力を貸してやるぜっ」、ライナー「お前じゃムリだろ（断定）」、マックイーン「お前が自前で『エンペラー』になれるような素養があるなら考えてやっても良いですわ」）。明日にでも「深度：4」に来ないか、仲間に最低でも50は声をかけて入り口まで迎えに行く、と誘い（カズマ「いきなり物量で殺しに来るのはルールで禁止っすよね？」、AA内「「異界」はルール無用だろ」）、カズマは挑戦は第四節の後半、少なくとも凛に勝ってから（リーグ出場権を得てからかも）と答えた（「そんな……それまで俺にごすのお気に入りのオモチャでいろって言うんスか！！？」）。ごすには二重の意味で舐められまくりで、抱き枕にされたりする（AA内「もう朝からベットベトっすよ、へへっ」）。ライザに「なんかの拍子にウチに入っても上手くやってけそうなキャラ」と言われて「きっさまぁ―――――っ、このワシを愚弄するかぁ――――――――――っ」（要「A」並感）。
- **人界と異界の話**: チームでアイディアを出し合わないのかと聞き、ライザの“独裁”の話に「はぇ～、人界の群れも大変なんすねぇ……あっ、そこの肉プリーズミー（ﾓｯﾁｬﾓｯﾁｬ）」。ライナーは物わかりとコミュ力込みで優秀そうと言い、ライザは人間だったら助手にしたいと言った（AA内「怖いこと言わないで？」）。「異界」が「深度：3」までより強いのは、領域を『ヌシ』が完全に支配していることと、フィールド自体の特大のエネルギーのためと話し、人間のフィールドに上書きされても『異界のヌシ』は出ればまた塗り替える、と説明した（→ [world/dungeon.md](../../../../world/dungeon.md)）。作者「クシャル君、どこに行っても「統率」さえ足りればすぐなじめそうなキャラしてやがんなお前なぁ」。（出典: 000, 518, 519）
