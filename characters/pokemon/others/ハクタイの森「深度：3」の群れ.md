# 野生・ダンジョンのポケモン ／ ハクタイの森「深度：3」の群れ

- 『ヌシ』ベルゼブモン（233でカズマの手持ちに → [beelzemon.md](../beelzemon.md)、体力AA（140〜165）◎）、元『ヌシ』でまとめ役のリース、サン（''狼王の血筋''、体力C前後（65〜85）△）、エスピナス（体力A〜AA（115〜150）○）、ティレルビートル（体力C+〜B（75〜105）○）、バサギリ（体力70（C）＋補正◎）。230〜232のダンジョンアタックの相手。詳しくは [world/dungeon.md](../../../world/dungeon.md)。（出典: 227, 230, 232）

（出典: 227, 230, 232, 233）

- **リース**（体力C前後（65〜85）△）: 群れの元『ヌシ』で、ベルゼブモンに下剋上されたが、ベルゼブモンが抜けたので今はまた『ヌシ』（System いわくベルゼブモンの''先代および後任''という三代目火影的な立ち位置。『野生の親玉』で「特防」を上げる）。''アマゾネス''種で、要「統率：B」。種族は基本''だったら私を倒して攫ってみろ！！''というタイプで、本人も「私を倒して従えるトレーナーがいれば、すぐに会いにいけるんですけどねぇ～」。ベルゼブモンを「弟」と呼んで溺愛する（自称''お姉ちゃん''。「お姉ちゃん大好きっ」作戦）。熱くなると強さの足りない挑戦者をしばいてしまい（逃げ帰ったチームのケガの半分はリースのせい、サン）、戦闘力とは別に群れの連中からはベルゼブモンより恐れられている（ベルゼブモンがストッパー側だった可能性がある。群れの匿名Sさん「機嫌が良いときは優しいけど、そうじゃないと私よりむしろ''もののけ姫''……」）。（出典: 227, 233, 411）
  - 411（409のフリーイベントの3D8の8）: ベルゼブモンが顔を出さないので、「ベルゼブモン」「お姉ちゃん」「弟」を書き連ねた怨念のような手紙をカズマに送り、ハクタイの森の「深度：1」の隠れた''抜け道''でベルゼブモン・カズマ・リザードンに会った（「おね……私は寂しかったですよ！！！！」）。今は''かつての部下にお願いをして''（パシられ役その2の緑茶）定期的に人界の情報を集めていて、調べているのはベルゼブモンたちの活躍と、舐めた連中（仮）を処す準備。''定例報告''で聞いた「''砕蜂のいるチームも、なんだかキッサキの大会を狙ってる''」をカズマに教えた。ベルゼブモンの『黒銃』には「私にむかって「じゃあくなほのお」だけはホントやめてくださいね？」。リザードンを「いっそ弟にしちゃいたい」。「ホントに定期的に来ないと私また''ご機嫌斜め''になりますからね！！！！」。（出典: 411）
  - 推測: 群れの匿名Sさんは、サン（『何処より来たるもののけ姫』の持ち主）と思われる。

（出典: 227, 233, 409, 411）

- **552（ベルゼブモンの里帰り）**: ベルゼブモンが森に帰って報告と顔見せをした。リース「欠乏していたオトウトニウムが急速に体内を駆け巡るっっ！」、サン「群れの一員として恥ずかしい」。
  - 群れのレベルは、ベルゼブモンが率いていた頃より上がっている。ベルゼブモンが抜けたあと「しゃあっ、好機っ」と突っ込んで来た奴らを何組か返り討ちにした（やべぇ窮地もあった。リース「姉として弟の帰る場所は守らねばならんのです」）。
  - リース: ベルゼブモンの方がよほどレベルが上がっていて、このダンジョンの「深度：4」でも雑兵では相手にならない、ミラクルズの力はすでに「深度：3」を大きく超えている。サン: 「群れ」相手でも結構やれるが、「森神様」にはまず無理。
  - 「深度：4」について（リース・サン・ベルゼブモン）: 強力な「異界」による絶対野生有利のフィールド効果、複数の強力な『迷宮』ポテンシャル、全員が『野生』の役割に『専用』互換を持ち、それぞれ4度の『勅命』と『号令』。群れは最低でも『第三階梯』、『ヌシ』や側近には『第四階梯』もいて、『異界のヌシ』は「おうぎ」を操る『野生の親玉』。
  - リース: 魔王虫“ベルゼブブ”の近縁種であるベルゼブモンの力はまだ途上、『特権』を含めれば「600」は明確に超えていた、時間はかかったが「そろそろ」。「元々貴方は、最初から優等生でしたが」（ちょっと誇らしげ）。ベルゼブモンが帰ろうとすると「お姉ちゃんと弟の感動の再会からのハグやキッスは！？」、サン「私が押えておくからはやく帰れ、元『ヌシ』」。サン（心の声）「人界って、やっぱ怖いとこなのか………？」。（出典: 552）
- **732（リースの手紙と『ハクタイのヌシ』）**: リースが手紙（代筆と配達はロビン・フッド。千束のとこの選手で元ハクタイ「深度：2」の住人）で「深度：1」の一角に弟（ベルゼブモン）とトレーナーを呼ぶ。寂しくて「群れ」に訓練を強要したり外敵を退けたり（1敗）。捕まりかけたこともあるが、そのトレーナーはリースよりエスピナスの方が性癖に合っていた。『ハクタイのヌシ』柱間と参謀の扉間が分身で同行し、扉間から『ヌシ』として強くイヤらしい「群れ」の戦い方を教わっていて、弟子に誘われる。「私ではもう今の貴方達に手も足もでないですし……っていうか『ヌシ』様方よりも上って……」。ジムの凛の手持ちになるなら、せめて本人に倒されてからじゃないと『ヌシ』の示しが付かない。ベルゼブモンはリースのところにお泊まり。→ [ハクタイの森「深度：4」の『ヌシ』と参謀](ハクタイの森「深度：4」の『ヌシ』と参謀.md)（出典: 732）
