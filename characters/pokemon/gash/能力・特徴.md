# 能力・特徴

↑ [ガッシュ](../gash.md)

- 中位以上の「統率」型や『天賦エース』のチームも『ヌシ』級を持ちうるので、「種族値で明確に上回っていたこれまでから、少しずつそのアドバンテージも薄れて行くであろうな」と見ている。（出典: 238）
- クチバのジムリーダーのラクサスに珍しがられて可愛がられた → [根拠](根拠/能力・特徴_02_290クチバのジムリーダーのラクサス.md)
- サンダーの羽の兆し: 羽を持って力をためると、雷が漏れ出てバチバチする → [根拠](根拠/能力・特徴_03_サンダーの羽の兆し.md)
- カズマにとってのガッシュ: 「ガッシュと出会って、俺のポケモントレーナーは始まった」 → [根拠](根拠/能力・特徴_04_カズマにとってのガッシュ.md)
- プロでは見ない種族: ガッシュ種はそもそもプロで見ないポケモン → [根拠](根拠/能力・特徴_05_プロでは見ない種族.md)
- 「王を目指す種族」なので、『エース』以外の適性がない: そのせいで、トレーナーに断られ続けていた → [根拠](根拠/能力・特徴_06_王を目指す種族なのでエース以外の適性.md)
- 『エース』のポテンシャルが一番「らしい」ポケモン。ジム巡りから今まで、チームの切り札として最後に出て決めることが多い。（出典: 011, 017, 024, 032）
- 友好種で、原作的に成長要素が強い（ザク談）。（出典: 011）
- 持ち物や特性の知識があり、カズマに教えることも多い。シンオウチャンピオンのホーネットを一目で見抜いた。リーグの順位など、プロの事情にも詳しい。（出典: 002, 011, 038, 039）
- 『絆』の付与を進化の条件にする種族（「きずな進化」）の一例（アダム談）。099で実際に進化した。（出典: 083, 099）
- 進化してからも「もっと大きな雷の力が私には眠っているのではないか」という感覚がある → [根拠](根拠/能力・特徴_11_進化してからももっと大きな雷の力が私.md)
- ガッシュ種はシンオウでは珍しく、「でんき」好きのエネルはガッシュ種を「カワイイ」と思っている。（出典: 039）
- コンテストの才能はかっこよさ83、たくましさ64（コンテストの育成はしていない）。（出典: 183）
- ジョウトでも「ガッシュ」種を『エース』にするチームは見ない。“スズの塔”の「深度：4」の金髪の「亜人」が「ガッシュ」の『金冠』ではないか、という都市伝説がある（遠坂） → [根拠](根拠/能力・特徴_14_ジョウトのスズの塔の噂.md)
