# 能力・特徴

- 中位以上の「統率」型や『天賦エース』のチームも『ヌシ』級を持ちうるので、「種族値で明確に上回っていたこれまでから、少しずつそのアドバンテージも薄れて行くであろうな」と見ている（出典: 238）
- クチバのジムリーダーのラクサスに珍しがられて可愛がられた
  - 290: クチバのジムリーダーのラクサスに、''進化した原種のガッシュ''の『エース』を珍しがられて可愛がられ、カントーのジムリーダーの合い言葉''自分の信じた道を征け''を贈られた。むじん発電所の『ヌシ』''紫電の雷帝''もガッシュ種らしい（赤司）。System「扱い的にガッシュは''単独ないしチームリーダーしか受け付けないハルウララ''みたいなもん」。（出典: 290）
- サンダーの羽の兆し: 羽を持って力をためると、雷が漏れ出てバチバチする
  - **''サンダーの羽''の兆し**（304）: まだ本格的な「育成」前だが、ガッシュが羽を持って力を蓄えると''漏れ出た雷が地面を伝ってすっげぇバチバチ''する。アカネとアドルフいわく、それは''アドルフと同じ''もの（推測: アドルフの特性「エレキメイカー」のようなもの）。関連する『種族』ポテンシャルを習得する可能性もある（アドルフ）。''進化''した「ガッシュ」種は、なかなかの潜在能力・容量を秘めているのかもしれない（アドルフ）。（出典: 304）
- カズマにとってのガッシュ: 「ガッシュと出会って、俺のポケモントレーナーは始まった」
  - **カズマにとってのガッシュ**（304）: 「''ガッシュと出会って、俺のポケモントレーナーは始まった''」「最初はピカチュウみたいだって理由だったけど……もう俺の隣に立つのはアイツじゃなきゃイヤだ」「皆に会えたスタート地点は、紛れもない''アイツ''」。ルサルカいわく「私たちが認めた唯一の''大将''」。ゼットンは以前からの知り合いで、カズマに会うまでは諦めていた部分が大きかったと、引き合わせたことに礼を言った。（出典: 304）
- プロでは見ない種族: ガッシュ種はそもそもプロで見ないポケモン
  - **プロでは見ない種族**: ガッシュ種はそもそもプロで見ないポケモン。要「統率」もC（補足: ユーザーより）。統率A+のカズマがこれを『エース』に据えていることが、統率型から見たチームの「邪道」さの一つ（→ [教科書の統率型](../../../world/trainer-stats.md)）。
  （出典: 279, 282, 290, 495）
- 「王を目指す種族」なので、『エース』以外の適性がない: そのせいで、トレーナーに断られ続けていた
  - **「王を目指す種族」なので、『エース』以外の適性がない**。そのせいで、トレーナーに断られ続けていた。シンオウのプロリーグでガッシュ種を使うトレーナーはいない。最初からいれば、ガッシュ中心にチームを組める。（出典: 002）
    - 注: ポテンシャルは潜在能力の形で、個体の資質に左右される（ザク、011。ザクはここで「今の『エース』はこの中だとその金髪の小僧が一番''らしい''」とも言っている）。『エース』しか出てこないのは、「王を目指す種族」というガッシュの性質がそのまま形になっているから（補足: ユーザーより。→ [ポテンシャル](../../../world/potentials.md)）。
    - 注: 断られていたのは、プロを目指すトレーナーなら普通にやる判断（ゼットンは顔を見ただけで察し、本人も「しょうがないのだ」と理由には納得している。002。プロはトレーナーの中でも一握り、369）。290のSystemの「単独ないしチームリーダーしか受け付けないハルウララ」は、''『エース』しかできないうえに弱い''という意味（補足: ユーザーより）。
    - 注: 最初期（005、Lv20）は特攻A・攻B・防C・特防C-・速C、合計種族値500ちょい。序盤としては普通のライン（補足: ユーザーより）。ただ、『エース』が普通のラインでは微妙（補足: ユーザーより）。『エース』は元の数値に上乗せする役なので、600族や『ヌシ』級（メリュジーヌは合計種族値700が見える、007）との差は開く（推測）。
    - 注: 『エース』の座の取り合いはプロでは普通（ロータスとスピアー、054。座が取れなければ移籍で取りに行く、300・303）（補足: ユーザーより）。ほかの選手は別の『役割』や移籍に逃げられるが、ガッシュは『エース』の座を失うと行き場がない（推測）。本人も「私のようなここでしか生きて行けない者」（303）、「カズマの『エース』以外を任じられたこととか想像出来ない」（300）と言っている。
  （出典: 002, 007, 290, 300, 303, 369）
- 『エース』のポテンシャルが一番「らしい」ポケモン。ジム巡りから今まで、チームの切り札として最後に出て決めることが多い（出典: 011, 017, 024, 032）
- 友好種で、原作的に成長要素が強い（ザク談）（出典: 011）
- 持ち物や特性の知識があり、カズマに教えることも多い。シンオウチャンピオンのホーネットを一目で見抜いた。リーグの順位など、プロの事情にも詳しい（出典: 002, 011, 038, 039）
- 『絆』の付与を進化の条件にする種族（「きずな進化」）の一例（アダム談）。099で実際に進化した（出典: 083, 099）
- 進化してからも「もっと大きな雷の力が私には眠っているのではないか」という感覚がある
  - 進化してからも「もっと大きな雷の力が私には眠っているのではないか」という感覚がある。メリュジーヌにも「雷の龍」のような大きな力と、「おうぎ」に匹敵するかもしれない「力の結晶」が中に眠っていると言われた。337のPV撮影のあとには「――――――キミに秘められた「まおうのいかずち」とでも呼ぶ力は、まだまだ先みたいだね」と言われた。本人も「“まだ先の力”があるのは私も自覚はあるのだがな」（315）。（出典: 113, 134, 315, 337）
- ガッシュ種はシンオウでは珍しく、「でんき」好きのエネルはガッシュ種を「カワイイ」と思っている（出典: 039）
- コンテストの才能はかっこよさ83、たくましさ64（コンテストの育成はしていない）（出典: 183）
- ジョウトでも「ガッシュ」種を『エース』にするチームは見ない。“スズの塔”の「深度：4」の金髪の「亜人」が「ガッシュ」の『金冠』ではないか、という都市伝説がある（遠坂）
  - ジョウトでも「ガッシュ」種を『エース』にするチームは見ない（遠坂は見たことがない）。“スズの塔”の「異界」で目撃されたポケモンが「ガッシュ」ではないか、という都市伝説がある（ジョウトの遠坂凛）。495で遠坂が内心「ジョウトでもそんなチーム見たことないけど……いや、そういえば“スズの塔”の噂で…………」、498でも内心「“スズの塔”の「異界」での目撃情報があるポケモン……「ガッシュ」じゃないかとは都市伝説があるけども」。練習試合のあと、遠坂は「ジョウトに帰ったら周りにも伝えとくわ……「ガッシュ」を『エース』にしたチームには気をつけろ、ってね」「こりゃ、“スズの塔”の噂も信憑性を帯びて来たかもしれんわ……まぁ私は命が惜しいし行かないけども」と言った（500）。501の飲み会では、ジョウト屈指の歴史を持つダンジョン“スズの塔”の「深度：4」にいる金髪の「亜人」が「ガッシュ」の『金冠』ではないかという噂がある、と話した（都市伝説で、『ヌシ』かどうかまでは知らない）。カズマは「まぁ機会があれば行ってみたい気はするな」。（出典: 495, 498, 500, 501）
