# 能力・特徴

↑ [メジロマックイーン](../mcqueen.md)

- 種族のプロでの立ち位置: メジロマックイーンは育成型向けだが、メイン級ではない（補足: ユーザーより） → [根拠](根拠/能力・特徴_01_種族のプロでの立ち位置.md)
- **ジム巡りではチームの『先発』**。すばやさAA-と高い体力を活かして、先発で相手を1体以上倒すのが仕事だった。プロでは『二枚看板』として前半〜中盤で暴れる。小細工なしの高速アタッカー（カズマ）。（出典: 013, 014, 027, 030, 032, 042）
- 『芦馬娘の凱旋』は、ライザと一緒に走り込んで身についた「相手を倒して即撤退」。先発以外でも縦横無尽に暴れる役目（出典: 042）
- 懐刀: ガッシュとルサルカが「右腕と左腕」なら、マックイーンは「懐刀」 → [根拠](根拠/能力・特徴_04_懐刀.md)
- 凝った『専用』は「能力」型の領分なので、長所を素直に伸ばす形が現実的（カズマ） → [根拠](根拠/能力・特徴_05_凝った専用は能力型の領分なので長所を.md)
- 『エキスパンション（ノ）』でタイプ一致の技の火力が大きく上がる。メアリが以前「統率型なら一番向いていそうなのは…」と口ごもったのは、この『二枚看板』のことではないかとカズマは考えている。（出典: 025, 035, 037, 040, 042）
- 「そだてや」の最初の1体: 「そだてや・スピカ」に預けられ、まとめて変わった → [根拠](根拠/能力・特徴_07_そだてやの最初の1体.md)
- 場の空気を作る才能があり、『エース』向きのセンスもあるかもしれない（カズマ談）。カズマいわく「おもしろさ部門があったら、ウチでも屈指」。作者いわく「チーム一のムードメーカーはこの深窓の令嬢」。（出典: 027, 040, 162）
- 知識は意外とある（シンオウの伝説種、四大精霊など）。買収が得意（「メジロ家奥義その1」）（出典: 014, 032）
- コンテスト: 「うつくしさ」と「かっこよさ」のノーマルランクで優勝 → [根拠](根拠/能力・特徴_10_コンテスト.md)
- 対怪獣として有名になりつつある（補足: ユーザーより）。大型で硬い相手を正面から落とす → [根拠](根拠/能力・特徴_11_対怪獣として有名になりつつある.md)
- 今のスキルツリーと立ち位置: 倒れたときに『継承』で能力を渡すのが活きる → [根拠](根拠/能力・特徴_12_今のスキルツリーと立ち位置.md)
- 「一発は耐える高速アタッカー」: 重い一撃も満タンなら一発は耐える（補足: ユーザーより） → [根拠](根拠/能力・特徴_13_一発は耐える高速アタッカー.md)
