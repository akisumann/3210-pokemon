## 概要

- 種族: ヒトカゲ → **リザードン**（355）。専用ポテンシャルで**メガリザードン**（Y）に「メガシンカ」する（371〜）（出典: 280, 355, 371）
- 『天賦』: 『**原始天賦**』（古代種の『天賦』。「リザードン」種の頂点） → [根拠](charizard/根拠/概要_02_天賦.md)
- 性別: ♂（出典: 281）
- 出会った場所: カントー、ナナシマの1の島・ともしび山の麓（ウタへのお土産として捕まえた）（出典: 279, 280）
- 仲間になった話: 280（ウタに「お前が、持ってろ！」と譲られた）
- 進化した話: 355（そだてやでの「育成」中にリザードンに）
- 「育成」: ズイの''そだてや''（沖野とスズカ）。332に預けられ、374で合流（出典: 332, 374）
- 『役割』: なし（『すっぴん』。『タイプ：ワイルド』で独自の専用ポテンシャルを持つ）（出典: 332, 371, 374）
- 呼び方: ゼットンを「ゼットンねーちゃん」、アカネを「ダメ人間のおねーちゃん」、スズカを「スズカねーちゃん」「スズカねーさん」（出典: 282, 374, 382）
- 年齢: 生まれたてで捕まえた。チームで一番若いとみられる（455） → [根拠](charizard/根拠/概要_10_年齢.md)

## 性格

- 無邪気で遊び好き（「人間って面倒だよね、なんでそんな服なんてもの着てるの？」）。モンスターボールの外でよく遊ばせてもらうのが条件（281）。図太い（アカネ「アンタに似て図太そう」）（282）。（出典: 281, 282）
- 自信家で、責任より権限が欲しい。一人称は「ミー」「オイラ」「俺」と定まらない → [根拠](charizard/根拠/性格_02_自信家で責任より権限が欲しいよくわか.md)
- 口癖は『まだまだだね』（371, 374）。「すっぴん」を誇りにしている（『やはり「♂」たる者、裸百貫で断崖に向かって立つ獅子でなければならぬ…………』）（出典: 371, 374, 386）
- 知らない人にはついていかないが、自分を高みへ導いてくれそうな人は大事にする → [根拠](charizard/根拠/性格_04_知らない人にはついていかない煉獄のス.md)
- スズカいわく、『天賦』の学習能力と意欲は目を見張るもので、「すっぴん」を目標にここまで高い意欲を保つ選手は初めて（出典: 355）

## 能力・特徴

- 『すっぴん』の育成: 『役割』を持たない条件でポテンシャルが強まる、邪道な育成 → [根拠](charizard/根拠/能力・特徴_01_すっぴんの育成.md)
- メガシンカ: 専用『天衣無縫の焔の翼』でT開始時に「メガリザードン」（Y）になる → [根拠](charizard/根拠/能力・特徴_02_メガシンカ.md)
- 晴れと「火の海」の影響: 主役になれるが、味方への影響はガッシュより大きい → [根拠](charizard/根拠/能力・特徴_03_晴れと火の海の影響.md)
- チームでの位置: 『エース』や『二枚看板』も話に出たが、『すっぴん』に落ち着いた → [根拠](charizard/根拠/能力・特徴_04_チームでの位置.md)
- 『チェイサー』と勘違いされる: 『役割』が出ないので読み違えられ、交代を牽制できる（補足: ユーザーより） → [根拠](charizard/根拠/能力・特徴_05_チェイサーと勘違いされる.md)
- 『天賦』の「強い炎の気配」で、四天王の煉獄を釣った（302, 303）。カズマは「はがね」が多い相手にも刺さると見ている（382）（出典: 302, 303, 382）
