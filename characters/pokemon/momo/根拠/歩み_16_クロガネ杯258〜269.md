# クロガネ杯（258〜269）

- **クロガネ杯（258〜269）**: チームはスマッシュ、アンブラハンズ、クロスユナイト、ネプテューヌ、クラッシャーズに勝ち、最終戦で《百代ファンタジーズ》に負けて**準優勝**（5勝1敗）。モモは初戦の《百貨店スマッシュ》戦には出ていない。2戦目の《博物館アンブラハンズ》戦では、死に出しでメドゥーサの「いかさまダイス」を『桃王女の芳香』で「おおきなキノコ」にすり替え、「ばらぞの」と『クォーターロゼット』の「リーフストーム」で倒した。ゴモラに倒れたが、『エンチャンター』でヤマトにつないだ（264）。3戦目の《飛脚クロスユナイト》戦で最後にカエルを倒して決着。Lv96→98→100（265）。

（出典: 258, 264, 265, 269）
