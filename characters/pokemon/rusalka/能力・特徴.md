# 能力・特徴

↑ [ルサルカ](../rusalka.md)

- 料理と家事: 料理が得意で、チームの炊事担当。ポフィンも手作りする。アカネの家でも炊事と女物の洗濯をしていて、ゼットンの胃袋をつかんだ（出典: 004, 005, 010, 022）
- **チームのブレーン**: 情報収集や推測が得意（情報源は洋館の砂嵐まみれのテレビと週刊誌）。カズマいわく「唯一のブレーン」。チームの参謀を自称し、カズマと一緒にチーム名《探検堂ミラクルズ》を決めた。（出典: 005, 029, 041, 042）
- 搦め手のバトル: 相手を崩したり縛ったりして、『アシスト』でガッシュにつなぐ → [根拠](根拠/能力・特徴_03_搦め手のバトル.md)
- ルサルカ種の性質 → [根拠](根拠/能力・特徴_04_ルサルカ種の性質.md)
- ルサルカ種の本質: 夢魔に近く、色香と幻覚で惑わして相手の精力をいただく → [根拠](根拠/能力・特徴_05_ルサルカ種の本質.md)
- 育成指南書: 「ルサルカ」種が人に対して愛を取るか、餌と見なすかで方向性が決まる（出典: 091）
- 異性からの愛を受けると、『アシスト』特化型（『エースアシスト』の効果をほかの『役割』にも広げる）に伸びた前例がある（ダージリンの資料、凛の育成書）。098で本当にそうなった（『水魔女の魔術』）（出典: 090, 098）
- 『アシスト』と『キラー』の両方の適性を持つのは珍しい（シアに「邪道『アシスト』」、イカルガに「邪道魔女」と言われた）（出典: 109, 112）
- 第一節「C」最高峰の『アシスト』で、統率型のチームなのにほぼスタメン → [根拠](根拠/能力・特徴_09_第一節C最高峰のアシスト玉藻で統率型.md)
