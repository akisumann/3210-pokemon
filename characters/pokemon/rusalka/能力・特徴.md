# 能力・特徴

- 料理と家事: 料理が得意で、チームの炊事担当。ポフィンも手作りする。アカネの家でも炊事と女物の洗濯をしていて、ゼットンの胃袋をつかんだ（出典: 004, 005, 010, 022）
- **チームのブレーン**: 情報収集や推測が得意（情報源は洋館の砂嵐まみれのテレビと週刊誌）。カズマいわく「唯一のブレーン」。チームの参謀を自称し、カズマと一緒にチーム名《探検堂ミラクルズ》を決めた。（出典: 005, 029, 041, 042）
- 搦め手のバトル: 相手を崩したり縛ったりして、『アシスト』でガッシュにつなぐ
  - **搦め手のバトル**: 「のろい」「おにび」「くろいまなざし」「ねこだまし」で相手を崩し、『エースアシスト』でガッシュにつなぐのが得意パターン。のろわれボディで相手の主力技を封じたこともある。（出典: 017, 024, 027, 030）第一節の育成（071）から493までは「かげふみ」で縛り、『もどれ！』や「すてゼリフ」（〜265。266の進化で外れた）で下がりながら『アシストα』を配り、専用『魔女の与える鉄槌』で相手の『エース』の前に飛び出す。（出典: 071, 115, 136, 266）494からは「かげふみ」の代わりに特性「けいやく」と『水魔女の地星』で縛る。（出典: 494）
- ルサルカ種の性質
  - **ルサルカ種の性質**（メアリ談）:
    - トレーナーとの関係しだいで、『アシスト』向き（「ヒロインルート」）と『キラー』向き（「敵幹部ルート」）の二つの方向に分かれる。今のなつき具合からすると『アシスト』の方向。
    - もともと種族値自慢のポケモンではないが、潜在能力はある。「育成」しだい。
    - 種族として持つ渇望は「**愛**」。愛情を持って接すれば応えようとする。
  （出典: 025）
- ルサルカ種の本質: 夢魔に近く、色香と幻覚で惑わして相手の精力をいただく
  - **ルサルカ種の本質**（本人談）: 夢魔に近く、色香と幻覚で惑わして相手の精力をいただく。幻覚で見た目を盛ることもできる。『キラー』や『アヴェンジャー』方面に伸びていたら、そういう面をガチガチに発揮していたかもしれない。カズマと出会ったので、相手を拘束・妨害して味方へつなぐ方向に伸びた。『エンチャンター』の適性はない。（出典: 090）
- 育成指南書: 「ルサルカ」種が人に対して愛を取るか、餌と見なすかで方向性が決まる（出典: 091）
- 異性からの愛を受けると、『アシスト』特化型（『エースアシスト』の効果をほかの『役割』にも広げる）に伸びた前例がある（ダージリンの資料、凛の育成書）。098で本当にそうなった（『水魔女の魔術』）（出典: 090, 098）
- 『アシスト』と『キラー』の両方の適性を持つのは珍しい（シアに「邪道『アシスト』」、イカルガに「邪道魔女」と言われた）（出典: 109, 112）
- 第一節「C」最高峰の『アシスト』で、統率型のチームなのにほぼスタメン
  - 第一節「C」最高峰の『アシスト』（玉藻）で、統率型のチームなのにほぼスタメン（直哉「なんで「統率」型の『アシスト』がほぼスタメン状態になってるんですか」）。『異名』の冗談の候補の『愛人』『ビッチ』には「私は一途な女だもん！！！！！！！」。本人は『良妻』とかを狙っていたが、ついたのは『妖婦』（269でアティが「『愛馬』、『魔獣』、そして『妖婦』」と挙げた。補足: ユーザーより）。（出典: 115, 166, 189, 269）
