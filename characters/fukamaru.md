# フカマル

カズマの5体目の手持ちポケモン。ウラヤマの「じまんのうらにわ」で出会った。（出典: 029）

- **ドラゴン／じめん**タイプ。古代種。第29話の時点で**Lv5**なので、まだバトルには出せない（マスコットポジション）。（出典: 029）
- 小さなサメのような見た目。笑い声は「シャーッハッハッ」。（出典: 029）
- 中身はヤクザ気質。「大昔に王の座についた種族の末裔として、この時代に覇を唱えたい」「フェアリーのおやつとなめた口をきく奴を、妖精ごと沈めてやりたい」。（出典: 029）
- ライナーは「遥かな昔、英雄か悪魔かと称えられた無双の魔獣の気配がする」と感じた。（出典: 029）
- ルサルカを「姐さん」、ライナーを「アニキ」と呼ぶ。ルサルカは「自分より合計種族値が低い舎弟ができた」と喜んで加入に賛成した。（出典: 029, 032）
- 特性は「さめはだ」（ウラヤマが頬ずりすると頬が削れた）。（出典: 031）
- 推測: 原作どおりなら、将来はガブリアスに進化する（「英雄か悪魔か」「王の座についた種族」はガブリアスが強すぎた時代を指すと思われる）。
