# ガラル安価旅（文字だけのゲーム）

スレ（シンオウの物語）に出たポケモンのデータで、ガラルのジムチャレンジを旅するゲーム。人物はガラル本来の人と、名前と性格を借りた他作品のキャラ。ストーリーはオリジナル（ユーザーと決めた、2026-10-31）。

- 遊ぶ: `galar.html`（`data.js`・`items.js`・`battle.js`・`galar.js` を読み込む）
- データを作り直す: `python3 game/tools/build_data.py`（原典の図鑑ブロック → 種族、`world/hp-estimates-*.md` → 体力、`game/data/moves_std.tsv` と `world/moves*.md` → 技）
- 能力値はスレの決まり（体力以外は種族値＋5、体力は＋60、レベル差は高い側の5つの能力に1につき1%。体力は旅の間持ち越すのでレベル差を掛けない）
- 技の数値: スレ独自の技は資料の表、ほかは本家の数値。どちらにもない一部は推測（画面に「数値は推測」と出る）
- 特性は主なものだけ実装。ほかは図鑑の説明を出し、「効果はまだ入れていません」と表示する
- 第1版はターフタウンのジム（ヤロー）まで。ダイマックスはまだない
