# ルールブック（第1版）

原典の世界で、自分のチームを組んでバトルを遊ぶためのルール。ダメージ計算は [damage-calc.html](damage-calc.html)（公開ページ: https://claude.ai/artifact/4fJQj7Djhx89o2UkZELKsR ）。舞台は「C」ランクの終盤。決めごとの経緯は [notes/game-design.md](../notes/game-design.md)、細かい仕様の根拠は [world/battle-rules.md](../world/battle-rules.md) と [world/pro-trainer.md](../world/pro-trainer.md)。

遊べる最小版は [battle.html](battle.html)（公開ページ: https://claude.ai/artifact/UrANGHHpqSN2n2WmMQUCNv ）。3vs3、例のチーム2組、技は約50種、『役割』は『不動のエース』『二枚看板』『エースアシストα』『エースキラーα』と先発系だけ。

---

## 1. トレーナーを作る
1. **資質**: 「A・B・C・C」を、指示・育成・統率・能力にダイスで割り当てる。
   - 1D4でAの資質（1指示・2育成・3統率・4能力）→ 残り3つから1D3でBの資質 → 残り2つがC。
   - Aになった資質が「〇〇型」。「+」「-」は今は付けない。
2. **『固有』**: 1つ（「能力」がAでも1つ）。
   - 型はAの資質で決まる。統率型は味方の『役割』の発動時、指示型は『指令』・「タイム」・四式を使った時、育成型は技能拡張か鍛えた技の強化、能力型は「場に出た時」のような広い条件。
   - 強さは「能力」のランクで決まる（Cは条件付きで控えめ、Aは広い条件で強い）。
   - 効果は自由に作る。希望を言えば、原典の同じ型・同じ出力の『固有』を参考に案を出す。目安: 統率型・能力Cで「味方の『役割』の発動時、T終了時まで全体の場を「エレキフィールド」にする」くらい。
3. **資質ごとの見返り**

| 資質 | C | B | A |
| --- | --- | --- | --- |
| 指示 | 図鑑1回。『熟達指令』と四式 | 図鑑2回。『全開指令』（試合前に全開か熟達かを一括で選ぶ） | 図鑑3回。指令ごとに全開・熟達を分けて選べる（混成習得）。狙撃・回避の指令。「タイム」1回 |
| 育成 | 手持ちLv70。全員が第一階梯（種属1つ） | Lv75。3体が第二階梯（種属2つ） | Lv80。全員が第二階梯 |
| 統率 | 『役割』は基本の4つ（『エース』『アシスト』『キラー』『先発』）。『絆』1体 | ＋『追加役割』を1つだけ1体に任命できる | 『役割』9つ（＋『二枚看板』『アヴェンジャー』『エンチャンター』『チェイサー』『スカウター』『トップバッター』）。『PT』1つ。『エキスパンション』。『絆』2体 |
| 能力 | 『固有』は条件付きで控えめ。『専用』3体まで | 『固有』強め。『専用』4〜5体 | 『固有』は広い条件で強い。『専用』6体 |

- 『全開指令』は、原典では「B」ランクから解禁だが、このゲームでは舞台が「C」の終盤でも**特別に使える**（指示型のため）。
- 「指示」の差1つにつき、高い方に常に急所ランク+1（世界の法則）。
- 『あたれ！』（攻撃技1回を必中）は指示AAから。指示Aでも『絆』持ちが場にいれば使える。

## 2. 手持ちを作る（6体）
1. **合計種族値**: 450・500・500・550・550・600の6体（体力を含む6つの合計）。
2. **ランクで各能力を決める**: 図鑑の文字ランクを種族値に直す。

| ランク | 種族値 | 「+」 | 「-」 | 素のランク |
| --- | --- | --- | --- | --- |
| S | 200超えのどこか | | | |
| AAA | 170〜195 | 195 | 170 | 中央あたりからランダム |
| AA | 140〜165 | 165 | 140 | 〃 |
| A | 110〜135 | 135 | 110 | 115〜130あたり |
| B | 90〜105 | 105 | 90 | 95か100 |
| C | 60〜85 | 85 | 60 | 65〜80あたり |
| D | 40〜55 | 55 | 40 | 〃 |
| E | 1〜35 | 35 | 1 | 〃 |

   - 体力は図鑑に出ない（マスクデータ）。見た目や種族のイメージで、耐久が高くなさそうならC、まあまあB、ちゃんとあるA、それ以上は凄そうなもの。
3. **レベル**: 育成のランクで全員同じ（C70・B75・A80）。『エース』も同じ。
4. **能力値の式**（個体値・努力値・性格補正なし）
   - 体力: 種族値×2×Lv/100＋Lv＋10
   - それ以外: 種族値×2×Lv/100＋5
5. **ポテンシャル**（図鑑の欄はこの順に並べる: 『役割』→分類→異名→ヌシ→種属→属→絆→汎用→特権→PT→専用）
   - 全員: 『役割』（ない子もいる）、種属1つ（育成で2つ）、属1つ、汎用1つ（『気合い』『ド根性』『戦闘続行』など）。
   - 統率A: 『エキスパンション』（特権の枠）、『PT』、『絆』。
   - 能力のランクに応じて『専用』。
   - 異名は、ついてもチームに1〜2体。
   - 「C」ではまだ『先』、付随、『対〇』はない。
6. **持ち物**: 「もちものセット」（第八世代基準の持ち物ひととおり）から1体1つ。
7. **レギュレーション**（協会）: 「みちづれ」を持つのは1チーム1体まで。選出する6体の中で、種属の効果をかぶらせない。同じ『専用』を持つポケモンは同じバトルに出せない。

## 3. 試合の前に
- 形式はプロの基本の **6vs6**（練習では2vs2や3vs3も）。
- 決めること: 先発、それぞれの持ち物、（指示Bなら）『全開』か『熟達』か、（指示Aなら）指令ごとの『全開』『熟達』。
- 試合の最初に、両チームのサポート効果が表示される。

## 4. ターンの流れ
1. **ターン開始時**: 「T開始時」の効果を処理する。
2. **指示を出す**（両者同時）
   - 場のポケモンの「技」か「交代」を1つ。
   - それに加えて、六令（『指令』）を1つ、四式を1つまで（同時に使える）。
   - 図鑑（回数は指示のランク）: 指示を出す前に、相手の場のポケモンのデータを解析できる。
   - 「タイム」（指示A以上）: その時に分かっている情報で、場の選手と相談できる。「指示」が終わった直後に発動する。
3. **先行するもの**: 六令・『全開指令』・『かわせ！』『よけろ！』・『あたれ！』は先行して発動する。『たえろ！』は相手の攻撃を見てから選ぶ。
4. **行動順**: 交代が先、次に優先度の高い順、同じ優先度なら「速」の高い順。「とんぼ」と「おいうち」がかち合ったら「おいうち」が先。『もどれ！』の交代は相手の行動のあと。
5. **技の処理**: 実機（第五世代）のダメージ式。
   - 倍率（ランクの上昇、強化、威力の倍率）は全て掛け算。
   - 急所は第五世代までの仕様（最大C+4でも1/2）、ダメージ2倍。急所は相手のランクの上昇も強化も無視する。
   - 2つのタイプを持つ攻撃は、ダメージが多くなる方の相性で判定する。
6. **ターン終了時**: 「T終了時」の効果を処理する。
7. **倒れたら**: 次のポケモンを出す（死に出し）。

- **同じタイミングで起動する効果の順**: 素早い方から。1体の中は「特性 → 『役割』 → ポテンシャル欄の上から順」。ただし『ストーキング』の交代はお互いの『役割』より先、など個別に決まっているものはそちら。

## 5. 「ここぞ！」
- 自陣が残り3体になったら、自陣が「ここぞ！」（6vs6。3vs3なら残り1体）。
- お互いの『エース』が場で対面したら、両方の場が「ここぞ！」。
- 条件がそろった瞬間に始まり、崩れた瞬間に終わる。

## 6. 表示
- 体力は数字で見せない。1発のダメージを、**最大体力**に対する割合で言葉にする。

| 言葉 | 最大体力の |
| --- | --- |
| 微々たるダメージ | 1割未満 |
| 小さなダメージ | 1〜2割 |
| まずまずのダメージ | 2〜3割 |
| 大きなダメージ | 3.5〜6割 |
| 深刻なダメージ | 6〜8割 |
| 特大のダメージ | 7〜10割 |
| 極大のダメージ | 10割前後〜 |
| 測定不能のダメージ | 10割を大きく超える |
| 皮一枚のダメージ | 残りを削り切るが体力1で残る |

- 「＠2」は「同じダメージをあと2発受けたら倒れる」の目安。

## 8. 相手
- 相手トレーナーは、自分の型（作戦）を持って、それを通しに来る。「指示」のランクで変わるのは、使える道具、型が崩れたときの立て直し、こちらに漏れるヒントの量。→ [world/opponent-ai.md](../world/opponent-ai.md)
