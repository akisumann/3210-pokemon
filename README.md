# 3210-pokemon

貼り付けられた話（原典）を保存し、そこから世界観・設定資料を整理していくリポジトリ。

## 構成

| ディレクトリ | 内容 |
| --- | --- |
| `source/` | 原典。貼られた文章を**一字一句そのまま**保存する（編集禁止） |
| `world/` | 世界観（地理・歴史・社会・用語など） |
| `characters/` | 登場人物・ポケモンの設定 |
| `story/` | 各話あらすじ・ダイス判定記録 |
| `index.md` | 設定資料の索引・未確定事項・矛盾メモ |

## ルール

- 原典は `source/NNN_タイトル.txt`（連番、時系列順）に追加のみ。後から書き換えない。時系列で前に入る話は、既存の番号を変えず空いている番号（000など）を使う。
- 設定資料には、根拠となる原典を `（出典: source/001.md）` の形で記す。
- 原典に書かれていない推測は「推測」と明記して区別する。
- 原典同士で矛盾があれば削除せず `index.md` の矛盾メモに残す。
- 矛盾メモに書くのは、原典同士が本当に両立しない場合だけにする。次のようなものは矛盾として扱わない。
  - 作中の人物の認識と事実のずれ（例: 世間では「アルセウスを見た人はいない」と言われているが、カズマは会っている）。
  - 後の話で詳しく説明されたこと。
  - 言い方や描写の違い、場面による口調の差。
  - 文の主語があいまいなだけのもの（文脈から自然に読んで、その読みで書く）。
