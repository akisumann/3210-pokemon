### 「〇〇が発動した時」の連鎖の例（推測を含む）

1. 先発の2体が場に出る → 両者の「場に出た時」系が速い順に動く（特性 → 『役割』（『トップバッター』など） → ポテンシャル）。
2. それが全部終わってから、「『先発』が発動した時」の『スターター』（全能力1.05倍）や、「味方の『役割』の発動時」のカズマの固有『この素晴らしい仲間に祝福を！』（特性を「きょううん」に変える）が、速い順に動く。
3. さらにそれが終わってから、「特性が「きょううん」に変化した時」の『グッドラック』（能力がランダムに上がる）が動く。
- 102で、相手の特性「プレッシャー」でガブリアスの「速」が下がってから『トップバッター』が動き、カズマの『固有』の「きょううん」では防げなかったのも、この順番で説明がつく（推測）。

## 『役割』の発動タイミング

- 「場に出たとき」系は、場に出たときに発動する。
- 『エースアシスト』『エンチャンター』は、**後続が場に出た瞬間**に発動する。通常交代や「しっぽをまく」なら、そのターン、交代した瞬間にカズマの『固有』も発動する。
- ただし、ターン終了時に交代する能力（『輪廻』『旋回』など）の場合、後続が場に出るのは次のターンの開始時。
- 『チェイサー』は、「おいうち」効果が発動したときに発動する。
- 特性の発動は『役割』より早い: 。102では、タナトスの特性「プレッシャー」でガブリアスの「速」が下がっ… → [根拠](turn-order/根拠/006_役割の発動タイミング_特性の発動は役割より早い.md)
- 『ストーキング』による交代は、お互いの『役割』の発動より先に発動する → [根拠](turn-order/根拠/007_役割の発動タイミング_ストーキングによる交代は.md)

## 迷いやすいところ

- 死に出しは次のT開始時: 倒れたポケモンの代わりが出るのは次のTの開始時 → [根拠](turn-order/根拠/019_迷いやすいところ_死に出しは次のT開始時.md)
- 特性のコピー: 「かがくのちから」などで特性をコピーしたら、**コピーした特性がその時点… → [根拠](turn-order/根拠/020_迷いやすいところ_特性のコピー.md)
- **トレーナー側の動きは同時**: 通常交代、『指令』など、トレーナーが出す指示の処理は両者で完全に同時。両者が同じTに交代しても、どちらが先に入れ替わるということはない。（補足: ユーザーより）
- 「タイム」は指示の途中: 指示の最中に時を止めて相談するイメージなので、「タイム」のあとで指示や『… → [根拠](turn-order/根拠/021_迷いやすいところ_タイムは指示の途中.md)
- **『指令』の効きかた**: 「あばれる」状態中は『指令』を受け付けない（「げきりん」を出す時の六令は可、四式は不可）。（出典: 317）
- **通常交代とそれ以外**: 「通常交代」は指示の交代（『もどれ！』を含む）だけ。「とんぼ」技、ポテンシャルによる交代、「レッドカード」などの強制交代は入らない。（出典: 135）
- **7体目の選手**: 『獣化』で味方を「瀕死」にして出てくるのは、『輪廻』『旋回』のタイミングとほぼ同じ処理（段階7）で、無条件に相手の四式・六令を透かせない。（出典: 375）
