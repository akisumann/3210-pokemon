# バトルの処理順（1ターンの流れ）

バトルのルール処理を、タイミングの順に並べたもの。**処理順（同じタイミングで動くものの順番、1ターンの流れ、『役割』の発動タイミング）のルールはここに集約している**。技・特性・持ち物などのルールそのものは [battle-rules.md](battle-rules.md) にあり、ここでは「いつ・どの順で動くか」だけをまとめる。ポテンシャルは「いつ起きるか（タイミング）」「何が条件か」「何が起きるか」の3つでできているので、試合前に両チームのポテンシャル・『固有』・SP・フィールド効果をこの表のタイミングに振り分けておき、各ターンは順に進めて条件を満たしたものを拾えば、見落としなく追える（ユーザーとの会話で整理した考え方）。

確かさの印: ○＝原典か補足で確定、△＝原典の例から読み取ったもの・はっきりしないもの（推測）。

## 同じタイミングで動くものの順番（共通のルール）
| 順 | ルール | 確かさ | 出典 |
| --- | --- | --- | --- |
| 0 | **すでに場に残っているもの（設置技など）が最優先**。ポケモンが場に出た時は、「ステルスロック」「ひばしら」「ばらぞの」などの設置技のダメージ・効果が、特性や『役割』より先に入る。設置技で倒れたら、そのポケモンの特性や『役割』（『トップバッター』『アヴェンジャー』など）は**発動しない** | ○ | 補足: ユーザーより |
| 1 | お互いのポケモンが同じタイミングで条件を満たしたら、**素早い方から**処理する。この「速さ」は、ランクや強化（『全開指令』の2倍、麻痺など）を**込みにした今の速さ**（補足: ユーザーより）。素早さも同じならランダム（行動順も同じ。優先度も素早さも同じならランダム） | ○ | 補足: ユーザーより |
| 2 | 1体の中では、**データの最上段から**: 特性 → 『役割』 → ポテンシャル欄の上から順（分類 → 異名 → ヌシ → 種属 → 属 → 絆 → 先 → 対〇 → 汎用 → 付随 → 特権 → PT → 専用）。ポテンシャルの並びは [potential-list.md](potential-list.md) の14分類（役割・分類・異名・ヌシ・種属・属・絆・先・対〇・汎用・付随・特権・PT・専用）と同じ順。『特権』は統率型の手持ちの『エキスパンション』や、深度3のヌシの『ヌシの特権』（異名とヌシの前後はまだはっきりしない） | ○ | 102、補足: ユーザーより |
| 3 | 個別に決まっているものはそれに従う（『ストーキング』の交代はお互いの『役割』より先、など） | ○ | battle-rules.md |
| 4 | **「〇〇が発動した時、〜」系（何かの発動をきっかけにするもの）は、ワンテンポ遅れる**。その瞬間の処理（速い順の動き）が全部終わってから、改めて速い順に発動する。例: 速い方の『役割』発動 → 遅い方の『役割』発動 → 速い方の『役割』に関連して発動するもの（→ 遅い方の『役割』に関連して発動するもの）。きっかけがさらに次のきっかけになるときも、同じように一段ずつ遅れる | ○ | 補足: ユーザーより |

### 「〇〇が発動した時」の連鎖の例（推測を含む）
1. 先発の2体が場に出る → 両者の「場に出た時」系が速い順に動く（特性 → 『役割』（『トップバッター』など） → ポテンシャル）。
2. それが全部終わってから、「『先発』が発動した時」の『スターター』（全能力1.05倍）や、「味方の『役割』の発動時」のカズマの固有『この素晴らしい仲間に祝福を！』（特性を「きょううん」に変える）が、速い順に動く。
3. さらにそれが終わってから、「特性が「きょううん」に変化した時」の『グッドラック』（能力がランダムに上がる）が動く。
- 102で、相手の特性「プレッシャー」でガブリアスの「速」が下がってから『トップバッター』が動き、カズマの『固有』の「きょううん」では防げなかったのも、この順番で説明がつく（推測）。

## 『役割』の発動タイミング
- 「場に出たとき」系は、場に出たときに発動する。
- 『エースアシスト』『エンチャンター』は、**後続が場に出た瞬間**に発動する。通常交代や「しっぽをまく」なら、そのターン、交代した瞬間にカズマの『固有』も発動する。
- ただし、ターン終了時に交代する能力（『輪廻』『旋回』など）の場合、後続が場に出るのは次のターンの開始時。
- 『チェイサー』は、「おいうち」効果が発動したときに発動する。
- **特性の発動は『役割』より早い**（共通のルール2の順番どおり）。102では、タナトスの特性「プレッシャー」でガブリアスの「速」が下がってから『トップバッター』が発動したので、カズマの『固有』で相手を「きょううん」にしても防げなかった。（出典: 102）
- 『ストーキング』による交代は、お互いの『役割』の発動より先に発動する。設置技の効果は、『ストーキング』より前に発動する（補足: ユーザーより。→ [battle-rules.md](battle-rules.md) の『ストーキング』）。

| 2a. 「タイム」（指示の途中） | 「タイム」は**指示を選んでいる途中**に起きる（指示の最中に時を止めて、場の選手と相談するイメージ。補足: ユーザーより）。なので「タイム」のあとでも指示や『指令』を出せる。まだ誰も動いていないので、交代を指示するつもりでも、この時点で場にいるのは交代前のポケモン（「タイム」で動く効果はそのポケモンに入る）。同じTに両者が使うと読みは相殺 | 『ベテラン』の『役割』と『アドバイス』の解析、直哉の『たどり着く時胞月宮殿』、玉藻・オシュトルの専用 | ○ | 117, 200, 245, 374、補足: ユーザーより |
| 2b. 図鑑（指示の途中） | 図鑑も「タイム」と同じく、指示を選んでいる途中に使い、使ったら指示の途中の状態に戻る。なので図鑑を使ったTも、技・交代・『指令』は普通に出せる（補足: ユーザーより）。抜けるのは使った瞬間の姿のデータだけ | 1試合1回 | ○ | 212、補足: ユーザーより |

| 4. 「一番最初に」の追加行動 | 交代と『指令』の直後、優先度を無視して誰よりも早く出る（「ねこだまし」「まもる」より早い） | 『スピアナイト』『リザードナイトY』などの4の倍数Tの追加行動 | ○ | 145, 371, 374 |

## 迷いやすいところ
- **死に出しは次のT開始時**: 倒れたポケモンの代わりが出るのは次のTの開始時。倒れたTのT終了時に相手を対象にする効果は、相手がいないので意味がない。一方『凱旋』系の交代は「相手を倒した」ことに関連して動くので、攻撃し合っているフェイズの途中で起きる。ただし下がるのはその瞬間で、後続が出るのは次のT開始時（相手の死に出しと同時）。そのTの残りの間、その枠は空になる。なので『凱旋』でも、「先に場で待ち構える」もの（『エイヴィヒカイト』など）は相手の死に出しに間に合わない（137と同じ）。また、『凱旋』『旋回』『輪廻』で下がったあとに出てくる後続は**死に出しではない**ので、『アヴェンジャー』や「かがくのちから」などの死に出し系は発動しない。（補足: ユーザーより）
- **特性のコピー**: 「かがくのちから」などで特性をコピーしたら、**コピーした特性がその時点で発動できる条件を満たしていれば発動する**、と扱う。たとえば死に出しで「ふくつのたて」（場に出た時、「防」が上がる）や「ひでり」をコピーすれば、その登場で発動する。「コピーして、発動できるなら発動する」までが「かがくのちから」という1つの特性の処理なので、**ワンテンポ遅れない**（共通のルール4の「〇〇が発動した時」には当たらず、特性の順番でそのまま動く）。（補足: ユーザーより）一方、『禍斑鳩の術式』（「かがくのちから」の発動時に体力を1/4回復）は「かがくのちから」の発動をきっかけにするので、ワンテンポ遅れる。（補足: ユーザーより）
- **トレーナー側の動きは同時**: 通常交代、『指令』など、トレーナーが出す指示の処理は両者で完全に同時。両者が同じTに交代しても、どちらが先に入れ替わるということはない。（補足: ユーザーより）
- **「タイム」は指示の途中**: 指示の最中に時を止めて相談するイメージなので、「タイム」のあとで指示や『指令』を出せる（補足: ユーザーより）。交代を指示したTの「タイム」の効果は、交代前のポケモンに入る。（出典: 200）
- **『指令』の効きかた**: 「あばれる」状態中は『指令』を受け付けない（「げきりん」を出す時の六令は可、四式は不可）。（出典: 317）
- **通常交代とそれ以外**: 「通常交代」は指示の交代（『もどれ！』を含む）だけ。「とんぼ」技、ポテンシャルによる交代、「レッドカード」などの強制交代は入らない。（出典: 135）
- **7体目の選手**: 『獣化』で味方を「瀕死」にして出てくるのは、『輪廻』『旋回』のタイミングとほぼ同じ処理（段階7）で、無条件に相手の四式・六令を透かせない。（出典: 375）
- **T終了時の中の順番**（ユーザーの見立て。補足: ユーザーより）:
  1. 毒・火傷・「アクアリング」など、T終了時のダメージや回復（実機と同じく順番が決まっているものが多い）。同じものは速い順。
  2. スタジアムのフィールド効果（ほかよりは遅め。314のライナー「フィールド効果の発動は、『輪廻』なんかを除けば最後の最後」）。
  3. 『輪廻』『旋回』などのT終了時の交代。その手のダメージや回復が全部終わってから発動する（後続は次のT開始時に出る）。
- **「込みの速さ」はその瞬間の速さ**（補足: ユーザーより）: 比べるのは、その処理の時点ですでにかかっているものだけ。たとえば特性「ひでり」は『二枚看板』（『役割』）より先に動くので、場に出た時の順番を決める段階では『二枚看板』の速さの強化はまだ当てにできない。一方、『パンプアップ』のように種族値そのものを上げるもの（戦闘の外の、ふだんの時点で上がっているもの）は、最初から計算に入る。
- **最後の1体同士が同時に倒れたら**: 実機どおり（補足: ユーザーより）。このスレの技の処理は第五世代までの実機が基準なので、たとえば「だいばくはつ」「じばく」のような自分も倒れる技は使った側の負け、反動技（「すてみタックル」など）の反動で両方倒れたら使った側の勝ち、になると見られる（実機の仕様の当てはめ。推測）。
- **追加行動と追加攻撃**: 追加行動は技を選べる（効果文に条件があればその範囲で。『リザードナイトY』なら「炎/飛」技）。追加攻撃は、直前に出したのと同じ技をもう一度繰り出す。（battle-rules.md、補足: ユーザーより）
- **メガシンカは遅め**: 「メガシンカ」をする『専用』（『天衣無縫の焔の翼』「T開始時、自身を「メガシンカ」させることが出来る」など）は、データの並びで下の方（専用）にあるので、同じタイミングの中では遅めに動く（ユーザーの見立て。補足: ユーザーより）。メガシンカでつく種属・特性（『超炎龍の覚醒』や特性「ひでり」）は、メガシンカしたあとで動く。
- **すぐ出る交代と、次のT開始時に出る交代**: 「とんぼ」技の交代は**その場ですぐ出る**（相手の攻撃も考えて使うものなので、交代先がその場で相手の攻撃を受ける）。『凱旋』の後続は、相手も倒れていていないので、次のT開始時に出ても困らない。（補足: ユーザーより）
- **「場に出て〇T目」の数え方**: 場に着地したTを1T目、その次のTを2T目と数える。Tの途中で通常交代や「とんぼ」技で出てきても、そのTが1T目。死に出し（次のT開始時に出る）なら、出てきたそのTが1T目。（補足: ユーザーより。『禍斑鳩の旋回』「場に出て2Ｔ目のＴ終了時」など）
- **怯み**: 実機と同じく、怯んだポケモンはそのT中の攻撃がだいたい止まる（通常の行動だけでなく、「一番最後に」の追加行動なども、おおむね止まる）。（補足: ユーザーより）
- **麻痺などの行動不能の判定**: 技を出す直前の判定は、追加行動や追加攻撃のときにも毎回入る。（補足: ユーザーより）
- **ポテンシャルの細かい扱い**（補足: ユーザーより）:
  - 「1/試/自動」は条件を満たしたら必ず発動する。「自動」のない「1/試」（『ベテラン』など）は、トレーナーが使うタイミングを選べる。
  - メガシンカ同士が向かい合うと、『メガシンカ』の「相手の『オールドタイプ』を無効化する」でお互いに打ち消し合い、どちらの『オールドタイプ』も効かなくなる。
  - 「場を離れる時」系（『エンチャンター』など）は、倒れて場を離れる時にも発動する。
  - 「相手を倒した時」系（『凱旋』『氷狼娘の勝鬨』など）は、攻撃で倒した時だけ。毒・火傷・設置技・相手の反動などで倒れた場合は発動しない。
  - 交代して場を離れると、ランクの上昇も強化（『二枚看板』の1.33倍など）もリセットされる。場に出直したら『役割』などは再発動する。
  - 「1/試」と書かれていない『固有』（カズマの『この素晴らしい仲間に祝福を！』など）は、条件を満たすたびに何回でも発動する。
  - 天候などの「@5T」は、変わったそのTを1T目と数える（場に出た時の数え方と同じ）。
  - 「火の海」（『超炎龍の獄炎』で敵陣にかかる）は、T終了時系のダメージ。実機のキョダイゴクエンの「残り火」のようなもので、原典でも「「炎」タイプ以外のポケモンがT終了時に1/8のダメージを受ける状態」と出ている（クッパの『大王亀の爆炎』、267, 268）。
  - **フィールドのかち合い**: トレーナーの『固有』で張るフィールド（《夢幻漆黒空間/シャルノス》《電撃領域／サンダーコロッセオ》など）がかち合ったら、『固有』の強い方、いわゆるトレーナーの「能力」が強い方が制する。スタジアムのフィールド効果は、『固有』のフィールドが張られると上書きされる。（補足: ユーザーより）
  - **「必ず」は強い**: 交代封じ（「かげふみ」など）と「必ず交代できる」（天花のSP《戦場に舞う天御鳥命》、『エキスパンション（霊）』など）がかち合ったら、「必ず」の方が勝つ。必ずだから。（補足: ユーザーより）
  - 『ド根性』（中確率で相手の攻撃以外のダメージを無視）は、「ステルスロック」などの設置技や毒・火傷のダメージも無視できるが、自分の代償（『歴戦の古傷』の反動、反動技、「いのちのたま」など）は無視できないらしい。
- **天候のかち合い**: 同じタイミングで天候を変えるものが重なったら、速い順に処理するので**遅い方が勝つ**（最後に変えた天候が残る）。また、「ひでり」のように一度天候を展開するだけのものより、「そのポケモンが場にいる限り雨になり続ける」のような**場にいる間ずっと天候を固定するもの**の方が強い（ボルトロスの専用『雷鳴轟く暴風雨』など）。（補足: ユーザーより）
- 原典でこの表と違う処理が出てきたら、ここに書き足す（『ストーキング』の交代はお互いの『役割』より先、など、個別に決まっているものはそれに従う）。
- 「こうかばつぐん」「こうかいまひとつ」にする効果の倍率は [battle-rules.md](battle-rules.md) の「タイプ」、図鑑で抜けるデータの範囲は同じく「ポケモン図鑑」。
