## ステータスのランク

図鑑の文字ランクは、種族値のおおよその範囲を表す。同じランクの中では「-」が下寄り、「+」が上寄り。ステータス画面の5つと、マスクデータの体力に使う（作者、012で最初に示された）。
| ランク | 種族値 |
| --- | --- |
| S | 200〜 |
| AAA | 170〜195（-〜+） |
| AA | 140〜165（-〜+） |
| A | 110〜135（-〜+） |
| B | 90〜105（-〜+） |
| C | 60〜85（-〜+） |
| D | 40〜55（-〜+） |
| E | 1〜35（-〜+） |
- 「+」はその幅の最大値、「-」は最小値で固定: 。例: B+ は105、B- は90 → [根拠](battle-rules/根拠/001_ステータスのランク_+はその幅の最大値-は最.md)
- 「+」「-」のない素のランクは、幅の中央あたりの値をテキトーにランダム: で決める（補足: ユーザーより） → [根拠](battle-rules/根拠/002_ステータスのランク_+-のない素のランクは幅.md)
- S は200を超えたどこか（210でも220でも。補足: ユーザーより）。決まった値はなく、そのポケモンごとに200超えの値を置く。
- 能力ランク（「攻+1」など）は、1段階上がると1.5倍。（出典: 011）
- 種族値の補正の大きさ → [根拠](battle-rules/根拠/003_ステータスのランク_種族値の補正の大きさ.md)

### ゲームで回すときの能力値の式（補足: ユーザーより）

- 実機の式で、**個体値と努力値はなし**。
  - 体力以外: 種族値×2×Lv/100＋5
  - 体力: 種族値×2×Lv/100＋Lv＋10
- 種族値は上のランクから決める（+は最大値、-は最小値、素は中央あたりからランダム、Sは200超え）。
- 性格による補正は、原典に出てこないので入れない（推測）。
- 体力（マスクデータ）のランクの決め方: 原典で分からないポケモンは、見た目や種族のイメージで決める → [根拠](battle-rules/根拠/004_ゲームで回すときの能力値_体力マスクデータのランク.md)
- 体力の見せ方: ゲーム中、プレイヤーには体力の数値を見せず、スレと同じく「大きなダメージ… → [根拠](battle-rules/根拠/005_ゲームで回すときの能力値_体力の見せ方.md)

## 能力の「上昇」と「強化」（補足: ユーザーより）

- **上昇**: ランクの変化。「攻を上げた」は+1、「ぐーんと上げた」は+2で、1段階で1.5倍（上の能力ランク）。状態表示では「攻+2」のように書く。
- **強化**: 倍率。『二枚看板』の全1.33倍、『全開指令』の2倍、『スターター』の1.05倍、『タイトエンドγ』の1.1倍など。状態表示では「全1.33倍」「速2倍」のように書く。
- 効果文に「上昇（強化）」と並べて書かれているものは、両方に作用する（例: 『ギガントマキア』「相… → [根拠](battle-rules/根拠/006_能力の上昇と強化補足ユー_効果文に上昇強化と並べて.md)
- 片方だけが書かれているものは、その片方だけに作用する → [根拠](battle-rules/根拠/007_能力の上昇と強化補足ユー_片方だけが書かれているも.md)
- 下げる側も同じで、「下げる」はランクの低下、「低下（0.75倍）」のように倍率が書かれているのは… → [根拠](battle-rules/根拠/008_能力の上昇と強化補足ユー_下げる側も同じで下げるは.md)
- 急所は、相手のランクの上昇だけでなく倍率の強化も無視する（出典: 030）。
- 能力変化の「±」の反転: 相手の『トップバッター』や、同時出しなら『エース』『アヴェンジャー』の能… → [根拠](battle-rules/根拠/009_能力の上昇と強化補足ユー_能力変化の±の反転.md)
- 重なったときは全て掛け算: 。ランクの上昇と強化（例: 攻+1の1.5倍×『二枚看板』1.33倍＝約… → [根拠](battle-rules/根拠/010_能力の上昇と強化補足ユー_重なったときは全て掛け算.md)
- 同一のポテンシャルによる倍率強化は重ね掛けできない: 操祈の第二『固有』『女王蜂の下す号令』（味方の『役割』の発動時、2Tの間… → [根拠](battle-rules/根拠/011_能力の上昇と強化補足ユー_同一のポテンシャルによる.md)
- **「命中」「回避」のランク**は、ほかの能力と上がり幅が少し違い、+1でおよそ4/3（約1.33倍）（ガッシュ）。（出典: 164）

## レベル差

- レベルが10違うと、全能力におよそ1割の差があると考えてよい（目安） → [根拠](battle-rules/根拠/012_レベル差_レベルが10違うと全能力.md)
- ただし、Cランクあたりではチーム間のレベル差はせいぜい10程度なので、実際にはそこまで気にしなくてもよい。育成型の強みも含め、Cランクではどの資質もまだ真価を発揮していない。

## 急所（クリティカル）

- 急所率は**第五世代までの仕様**で、最大（C+4）でも確率は1/2。その分、急所のダメージは**2倍**（012で最初に示されたスレの注意事項）。（出典: 012, 034, 071）
- このスレの急所は、ランクだけでなく「**倍率強化**」も無視する。（出典: 030）
- 急所ランクごとの確率:
| 急所ランク | 確率 |
| --- | --- |
| C+0 | 1/16（6.25％） |
| C+1 | 1/8（12.5％） |
| C+2 | 1/4（25％） |
| C+3 | 1/3（33.3％） |
| C+4 | 1/2（50％）。ランクはここまでしか上がらず、確率も50％が上限（補足: ユーザーより） |
- バッジ3つクラス以上（資質の影響が出始めるプロ資格持ちのステージ）では、相手との「指示」ランク差1つにつき、高い方に常に急所ランク+1がつく。（出典: 045）
- **確定急所の技**（「ちのやり」など）は、自分の「特攻」の低下を無視して攻撃できる。（出典: 175）
- クリティカル倍率: 急所のダメージは基本2倍だが、特性「**スナイパー**」はクリティカル倍… → [根拠](battle-rules/根拠/013_急所クリティカル_クリティカル倍率.md)
- 急所に当たるのを見てから『たえろ！』を出すことはできない（天花）。（出典: 200）
- 急所率（「C」）には「-」のランクがない: ので、特性「あまのじゃく」などでも「±」が反転せず、「たんじゅん」の対象… → [根拠](battle-rules/根拠/014_急所クリティカル_急所率Cには-のランクが.md)

## 確率の目安（補足: ユーザーより）

原典のポテンシャルや効果の文に出てくる確率の言い方と、そのおおよその値。原典には数字は書かれていない。
| 原典の言い方 | 確率 | 例 |
| --- | --- | --- |
| 中確率 | 50％ | 『リターンキュア』『リターンヒール』、『エキスパンション（水）』、『桃王女の計画』 |
| 低確率 | 12.5％（1/8） | 『絆』のポテンシャルの再発動、コトブキスタジアムのフィールド効果、『百合剣士の剣技』 |
| 稀に | 6.25％（1/16） | 『気合い』、天花のサポート効果の「テレポート」の追加行動 |
- 低確率（1/8）と稀に（1/16）は、ゲームで回すときはこの値で固定する（補足: ユーザーより）。低確率は急所ランクC+1、稀には急所ランクC+0と同じ値。
- 「1割」「2割」のように原典に割合が書かれているものは、その数字のまま（ヴォルデモートの「1割：呪い」、「たちさばき」の2割など）。
- 『気合い』（「稀に気合いで相手の攻撃を耐える → [根拠](battle-rules/根拠/015_確率の目安補足ユーザーよ_気合い稀に気合いで相手の.md)
- 《バトルフロンティア》のフィールド効果（「ここぞ！」で発動率が上がる）で、実際にどれだけ上がるかはまだわからない。

## 「ここぞ！」という場面

1. 「3vs3」のときは、味方が残り1体になると自陣が「ここぞ！」。（6vs6では残り3体。出典: 021, 024, 045, 046）
2. お互いの『エース』が場で対面すると、互いの場が「ここぞ！」。
- 「ここぞ！」は、上の条件が満たされている間だけ続く（「ここぞ！」の原則どおり → [根拠](battle-rules/根拠/022_ここぞ！という場面_ここぞ！は上の条件が満た.md)
- 「ここぞ！」の原則には、始まりと終わりのタイミングがきっちりある（補足: ユーザーより） → [根拠](battle-rules/根拠/023_ここぞ！という場面_ここぞ！の原則には始まり.md)
- ガッシュの異名『友情』（味方と交代して場に出た時、『エース』が必ず発動する）は、「ここぞ！」の*… → [根拠](battle-rules/根拠/024_ここぞ！という場面_ガッシュの異名友情味方と.md)
- 先に『ペースメーカー』（味方の『エース』を発動させる専用）で『エース』が一度発動していれば、その… → [根拠](battle-rules/根拠/025_ここぞ！という場面_先にペースメーカー味方の.md)
- だっしゅつパックなどの強制交代で出直しても、『エース』がもう一度発動する“おかわり”はない（モモ）。（出典: 200）

## 防護

「防護」とは、このスレでは相手の攻撃技のダメージを緩和したり無効にしたりするもの。次の3つが含まれる。
1. ダメージの緩和や無効化
2. 「攻」「特攻」の上昇（強化）の無視
3. 「必ず耐える」系（『気合い』のような「稀に耐える」ものも含む。117でカタクリの『気合い』がガッシュの『バオウ・ザケルガ』に貫通された。出典: 117、補足: ユーザーより）
- 『固有』ポテンシャルによるダメージの緩和や、四式の『たえろ！』は**トレーナーの**防護ポテンシャル。なので『オールドタイプ』や『エキスパンション（闘）』（出典: 062）では貫通できない。
- スタジアムのフィールド効果によるダメージの緩和（《ハクタイスタジアム》の『オールドタイプ』0.85倍など）は、フィールド効果なので「あらゆる方法で貫かれない」（ライザ）。（出典: 073）
- 「宙に浮かび上がる」ことで得る「地面」技の無効化は防護に当たらない（下の「宙に浮かび上がる」を参照）。
- 『スーパーヒーロー』（キャプテン・アメリカ）の「「まもる」等が貫通（解除）されない」は**防護ではない**ので、『三角効果』でも抜けない。『強化貫通』ならぶち抜ける（作者）。（出典: 245）
- 急所に当たると相手の能力の上昇（強化）は無視されるが、**防護は急所（クリティカル）では抜けない**（出典: 068）。
- ポケモン自身が持つ防護ポテンシャル（ハンニバルの『アラガミ』の「亜人」の技の低確率半減や、サンズ… → [根拠](battle-rules/根拠/027_防護_ポケモン自身が持つ防護ポ.md)
- 『闘争本能』（低確率で攻撃技を無効化。ポケモン自身の防護ポテンシャル）は、『エキスパンション（闘）』（防護ポテンシャルの無視）で打ち砕かれた。（出典: 232）
- 攻撃を無効にする特性（「しらはどり」など）は「**防護特性**」と呼ばれる（ムラサメライガーの『… → [根拠](battle-rules/根拠/028_防護_攻撃を無効にする特性しら.md)
- 『対〇回避』（命中率の低下）は、『オールドタイプ』でも消えなかった → [根拠](battle-rules/根拠/029_防護_対〇回避命中率の低下はオ.md)

### 三角効果

- 専用ポテンシャルの型の一つ（「攻」か「特攻」がAA以上で使える。出典: 066）。相手ポケモンの「まもる」などの技、特性、相手ポケモンと相手トレーナーの防護ポテンシャルを無効にする。
- トレーナーの防護ポテンシャルには、四式の『たえろ！』が当たる。
- 能力の上昇・強化を貫通する効果はない。
- 「**こらえる**」「**みがわり**」は、『三角効果』を受けない数少ない防御手段（他は「まもる… → [根拠](battle-rules/根拠/030_三角効果_こらえるみがわりは三角効.md)
- 〇〇指令による「防」「特防」の強化は、トレーナーの防護ポテンシャルに当たらないので、三角効果では貫通されない。
- 持ち物の「**とくせいガード**」を持っていれば、三角効果からも特性を守れる（144でガッシュの… → [根拠](battle-rules/根拠/031_三角効果_持ち物のとくせいガードを.md)

## 『指令』

- **1Tに出せる数**: 六令は1Tに1回、四式も1Tに1回。六令1つと四式1つを同じTに同時に出すことはできる。（補足: ユーザーより）
- 四式が効く範囲: 四式（『かわせ！』『よけろ！』など）が効くのは1回の攻撃だけ → [根拠](battle-rules/根拠/032_指令_四式が効く範囲.md)
- 「あばれる」状態（「げきりん」など）のポケモンは指示を受け付けないので、『指令』も効かない（→ 下の「状態変化」の「あばれる」状態）。
- 「『指令』を受けたとき〜」系のポテンシャル（『サーヴァント』など）が発動するのは六令（『〜指令』… → [根拠](battle-rules/根拠/033_指令_指令を受けたとき〜系のポ.md)
- 逆に「自分の『四式』が発動したとき〜」系（ブリジットの『トリックプレイ』、錦木千束の『不殺主義の… → [根拠](battle-rules/根拠/034_指令_逆に自分の四式が発動した.md)
- 『四式』が発動しても、対応する手段で突破された時（『かわせ！』『よけろ！』には必中、『もどれ！』… → [根拠](battle-rules/根拠/035_指令_四式が発動しても対応する.md)
- 『たえろ！』は、急所でも何でも、相手の技のダメージを必ず耐える（体力1で残る）（補足: ユーザー… → [根拠](battle-rules/根拠/036_指令_たえろ！は急所でも何でも.md)
- 『全開回復指令』は行動をスキップするので、『たえろ！』も使えない。満タンに戻したところに、通常攻撃、低確率の追加行動、「呪い」の3段で倒されることもある。（出典: 169）
- 急所に当たるのを見てから『たえろ！』を出すことはできない（上の「急所」。出典: 200）。

## 交代

- 「**通常交代**」は、指示の時に出す交代コマンド（『もどれ！』も含む）のこと。「とんぼ」技、ポテンシャルによる交代、「レッドカード」などの強制交代は含まない。（出典: 135）
- 交代が出る時機（「とんぼ」技はその場ですぐ出る、『凱旋』『輪廻』『旋回』の後続は次のT開始時、死に出しは次のT開始時）は [turn-order.md](turn-order.md)。
- 『旋回』のように倒したあと交代する場合でも、お互いが同時に次のポケモンを出す状況（相手を倒した時… → [根拠](battle-rules/根拠/037_交代_旋回のように倒したあと交.md)
- 強制交代: で場に出たり離れたりしたときは、「場に出たとき」「場を離れたとき」のポテ… → [根拠](battle-rules/根拠/038_交代_強制交代.md)
- 『野生』のポテンシャルを持たないので、群れのポケモンにも強制交代は効く（カズマ）。（出典: 231）
- 天花のサポート効果で、交代阻害（「くろいまなざし」「しめつける」など）は基本的に無視できる → [根拠](battle-rules/根拠/039_交代_天花のサポート効果で交代.md)
- **強制交代を受けない**効果（《夢幻漆黒空間/シャルノス》、種属の『〜の重量』など）でも、強制交代しないだけで「ハウル」のダメージなどは通る（カズマ、404）。（出典: 404）
- 交代封じと「必ず交代できる」がかち合ったら「必ず」の方が勝つ（[turn-order.md](turn-order.md)。補足: ユーザーより）。「だっしゅつパック」による自動交代は下の「持ち物」。

## 妙手（タイム）

- 「指示：A」以上のトレーナーが使える。

- 使いどころは「前半から中盤にかけて鋭い一手を差し込む」か「後半戦でデータが集まったところで、詰みや逆転の手を打つ」のどちらか。（出典: 098）

### 『ストーキング』

- 専用ポテンシャルの型の一つ → [根拠](battle-rules/根拠/092_ストーキング_専用ポテンシャルの型の一.md)
- 以下は、原典に出る前にユーザーから聞いていた仕様（補足: ユーザーより）。
- 『ストーキング』による交代は、お互いの『役割』の発動より先に発動する。
- 設置技の効果は、『ストーキング』より前に発動する → [根拠](battle-rules/根拠/093_ストーキング_設置技の効果はストーキン.md)
- 「ものまねハーブ」は『ストーキング』のときでも発動する（二節〜三節の幕間以降）。

### 『戦闘続行』

- 『戦闘続行』は、ダメージを持ち越して相手に死なば諸共で特攻するもの（397、天花） → [根拠](battle-rules/根拠/094_戦闘続行_戦闘続行はダメージを持ち.md)

### 『オールドタイプ』が効かない場合

- 『金冠サイズ』のポケモンには『オールドタイプ』が効果を発揮しない（カズマ「『金冠サイズ』ってこと… → [根拠](battle-rules/根拠/095_オールドタイプが効かない_金冠サイズのポケモンには.md)
- メガシンカ同士が向かい合うと、『メガシンカ』の「相手の『オールドタイプ』を無効化する」でお互いに… → [根拠](battle-rules/根拠/096_オールドタイプが効かない_メガシンカ同士が向かい合.md)

### 『メガシンカ』

- 「メガシンカ」の仕組みは species.md の「メガシンカ」を正とする → [根拠](battle-rules/根拠/097_メガシンカ_メガシンカの仕組みはsp.md)

## 持ち物

- 持ち物の効果は、基本的に実機と同じ。ただし、スレでの仕様変更やポテンシャルとの兼ね合いで勝手が違うこともある。
- 「わざマシン」も「もちもの」に分類される（[pokemon.md](pokemon.md) の「わざマシン」）。

### もちものセット

- カズマの最初の持ち物は、アカネとゼットンの餞別の「**もちものセット**」（第八世代基準のバトル… → [根拠](battle-rules/根拠/098_もちものセット_カズマの最初の持ち物はア.md)
- 121の通達: 新しい持ち物のリストと、一部の技の分類の変更（「けん」「つるぎ」技の範囲は上の「… → [根拠](battle-rules/根拠/099_もちものセット_121の通達新しい持ち物.md)
- 一部の古代種だけに効く持ち物: 「ふといホネ」（ガラガラ）、「でんきだま」、「ながネギ」など → [根拠](battle-rules/根拠/100_もちものセット_一部の古代種だけに効く持.md)

### 個別の持ち物の仕様

- **こだわりハチマキ**: 自分の「防」の値でダメージを計算する技には効果がない。
- こだわりスカーフ: 技が固定されても、交代すれば解除されて別の技を選び直せる → [根拠](battle-rules/根拠/101_個別の持ち物の仕様_こだわりスカーフ.md)
- **こだわりと技能拡張**: 「技能拡張」を使っても「こだわり」には縛られない。ただし、一度でも覚えている技を使えば、「技能拡張」も使えなくなる。
- **とつげきチョッキ**: 急所で貫通される。
- きれいなぬけがら: 「かげふみ」などで通常交代を封じられても、ぬるっとした動きで離脱して交代… → [根拠](battle-rules/根拠/102_個別の持ち物の仕様_きれいなぬけがら.md)
- **ゴツゴツメット**は、クロコダインの『獣王鰐の戦斧』（威力120以上の技が命中した時、相手の持ち物を破壊）で壊された（465）。
- **ひかりのねんど、あついいわ、しめったいわなど**: ポテンシャルには効果がない（技と特性だけ）。
- クリアチャーム: 相手からの能力の減少を無効にする → [根拠](battle-rules/根拠/103_個別の持ち物の仕様_クリアチャーム.md)
- だっしゅつパック: 自分の能力が下がると自動で交代する（BBの「リーフストーム」の特攻ダウン… → [根拠](battle-rules/根拠/104_個別の持ち物の仕様_だっしゅつパック.md)
- レッドカード: 持ち主が攻撃を受けたあと場に残っていないと発動しない（作者「「瀕死」でも… → [根拠](battle-rules/根拠/105_個別の持ち物の仕様_レッドカード.md)
- とくせいガード: 124〜125の練習試合で初めて実戦に出た → [根拠](battle-rules/根拠/106_個別の持ち物の仕様_とくせいガード.md)
- ものまねハーブ: 登場時に能力が上がる『トップバッター』や『エース』と対面すると要注意 → [根拠](battle-rules/根拠/107_個別の持ち物の仕様_ものまねハーブ.md)
- 持ち物を壊す・変える効果: 持ち物が効果を出す前に壊したり変えたりする → [根拠](battle-rules/根拠/108_個別の持ち物の仕様_持ち物を壊す・変える効果.md)
- プレート: 「なげつける」でプレートを投げると威力90 → [根拠](battle-rules/根拠/109_個別の持ち物の仕様_プレート.md)
- 特性「きんちょうかん」を持つ相手の前では、きのみやわざマシンなど消費する持ち物が使えない → [根拠](battle-rules/根拠/110_個別の持ち物の仕様_特性きんちょうかんを持つ.md)

### 作中に出た持ち物（ジム巡り〜練習試合のころ）

- きあいのハチマキ、オボンの実、ノーマルジュエル、きょうせいギプス → [根拠](battle-rules/根拠/111_作中に出た持ち物ジム巡り_きあいのハチマキオボンの.md)
- それ以降の各試合の持ち物は [バトル記録](../story/battles.md) と各キャラのファイル。
- 持ち物がどのくらい使われているかの集計（相手チームとカズマのチームを分けたもの）は [持ち物の使われ方](items-usage.md)。

## 特性

### 特性の決まり

- **タイプによる特性の無効は第五世代仕様**。「ゴースト」タイプも「かげふみ」で交代を縛れる。（出典: 071）
- 能力を下げられた時の特性（「まけんき」「クリアボディ」など）は実機よりパワーアップしている:
  - 「**まけんき**」: 相手に能力を減少・低下させられた時、自分の「攻」がぐーんと上がる → [根拠](battle-rules/根拠/112_特性の決まり_まけんき相手に能力を減少.md)
  - 「**クリアボディ**」: 相手からの能力減少（低下）を無効にする（実機よりパワーアップ） → [根拠](battle-rules/根拠/113_特性の決まり_クリアボディ相手からの能.md)
  - 「火傷」「麻痺」などの**状態異常による能力の低下は**、「まけんき」や「クリアボディ」の対象外… → [根拠](battle-rules/根拠/114_特性の決まり_火傷麻痺などの状態異常に.md)
- 「いかく」と「まけんき」: カズマの固有で、相手の「いかく」と味方の「まけんき」を両方1Tだけ「きょ… → [根拠](battle-rules/根拠/115_特性の決まり_いかくとまけんき.md)
- 特性のコピー（「かがくのちから」など）や、特性と『役割』の順番は [turn-order.md](turn-order.md)。特性を『三角効果』から守る「とくせいガード」は上の「持ち物」。
- 第九世代の特性（「おうごんのからだ」「ふくつのたて」など）の特集本の話は、上の「技の処理」の「第九世代の技・特性」。

## 協会のレギュレーション

- 「みちづれ」を持つポケモンは、1チームに1体まで。（出典: 122）
- 『輪廻』や『旋回』を持つポケモンは、レギュレーションで自前の「まもる」を持てない → [根拠](battle-rules/根拠/126_協会のレギュレーション_輪廻や旋回を持つポケモン.md)
- 完全な受け構築（受け続けて勝つチーム）は、技なども含めてレギュレーションで禁止されていると思われ… → [根拠](battle-rules/根拠/127_協会のレギュレーション_完全な受け構築受け続けて.md)
- 原典で明言はされていないが、種属ポテンシャル（「〇〇の〇〇」）は、効果を被らせてはいけないという… → [根拠](battle-rules/根拠/128_協会のレギュレーション_原典で明言はされていない.md)
- 確定急所の攻撃技: クリティカル倍率3倍の『超究武神覇斬』を持つ《神羅ソルジャーズ》は、確定… → [根拠](battle-rules/根拠/129_協会のレギュレーション_確定急所の攻撃技.md)
- 協会が勧める「もちものセット」は上の「持ち物」。

## 【H】（ホーム）補正

- 大会の勝敗が同点のときは、地元チーム（【H】）が上位。それ以外の場合は、直接対決の勝者が上位。（出典: 061）

## 読者の安価の決まり方（補足: ユーザーより）

- カズマ側の行動は読者の安価で決まる → [根拠](battle-rules/根拠/133_読者の安価の決まり方補足_カズマ側の行動は読者の安.md)
- 「下3」は安価のレスから3つ目のレスを採用する、掲示板の安価の普通の決まり（多数決ではない） → [根拠](battle-rules/根拠/134_読者の安価の決まり方補足_下3は安価のレスから3つ.md)

- 一方で、何が起きてもとりあえず場を荒らせればいい手は、結果がランダムでもリスクとは見なされず、わ… → [根拠](battle-rules/根拠/135_読者の安価の決まり方補足_一方で何が起きてもとりあ.md)
