# バトルの細かい仕様

ユーザーから教わった、スレのバトルの仕様をまとめたもの。この節の内容はすべて（補足: ユーザーより）。原典でまだ出ていない用語（原典未登場）も含む。

## ステータスのランク
図鑑の文字ランクは、種族値のおおよその範囲を表す。同じランクの中では「-」が下寄り、「+」が上寄り。

| ランク | 種族値 |
| --- | --- |
| S | 200〜 |
| AAA | 170〜195（-〜+） |
| AA | 140〜165（-〜+） |
| A | 110〜135（-〜+） |
| B | 90〜105（-〜+） |
| C | 60〜85（-〜+） |
| D | 40〜55（-〜+） |
| E | 1〜35（-〜+） |

- 能力ランク（「攻+1」など）は、1段階上がると1.5倍。（出典: 011）
- **種族値の補正の大きさ**（補足: ユーザーより）:
  - 『ポケパワー』のような「種族値に+補正を得る」効果は、「+」「-」の刻みで1つ上がる（B→B+、B+→A-）。
  - 「種族値を1ランク上げる」効果は、文字のランクが1つ上がる（B→A）。例: サムスの『賞金稼ぎのパワードスーツ』（C→B、A→AA）、ガッシュの『金雷児の王気』（特攻の種族値を1ランク上げる）。『金冠サイズ』の体力補正は「約2ランク」（モモ談）。

## レベル差
- レベルが10違うと、全能力におよそ1割の差があると考えてよい（目安）。
  - 例: Lv60とLv50なら、Lv60側の全能力がおよそ1.1倍。
- ただし、Cランクあたりではチーム間のレベル差はせいぜい10程度なので、実際にはそこまで気にしなくてもよい。育成型の強みも含め、Cランクではどの資質もまだ真価を発揮していない。

## 急所（クリティカル）
- 急所率は**第五世代までの仕様**。急所のダメージは**2倍**。（出典: 034, 071）
- このスレの急所は、ランクだけでなく「**倍率強化**」も無視する。（出典: 030）
- 急所ランクごとの確率:

| 急所ランク | 確率 |
| --- | --- |
| C+0 | 1/16（6.25％） |
| C+1 | 1/8（12.5％） |
| C+2 | 1/4（25％） |
| C+3 | 1/3（33.3％） |
| C+4 | 1/2（50％）。ランクはここまでしか上がらず、確率も50％が上限（補足: ユーザーより） |

- 相手との「指示」ランク差1つにつき、高い方に常に急所ランク+1がつく。

## 確率の目安（補足: ユーザーより）
原典のポテンシャルや効果の文に出てくる確率の言い方と、そのおおよその値。原典には数字は書かれていない。

| 原典の言い方 | 確率 | 例 |
| --- | --- | --- |
| 中確率 | 50％ | 『リターンキュア』『リターンヒール』、『エキスパンション（水）』、『桃王女の計画』 |
| 低確率 | たぶん12.5％（1/8） | 『絆』のポテンシャルの再発動、コトブキスタジアムのフィールド効果、『百合剣士の剣技』 |
| 稀に | たぶん6.25％（1/16） | 『気合い』、天花のサポート効果の「テレポート」の追加行動 |

- 低確率と稀には、ユーザーも「多分」と言っているので、目安として扱う。低確率は急所ランクC+1、稀には急所ランクC+0と同じ値。
- 「1割」「2割」のように原典に割合が書かれているものは、その数字のまま（ヴォルデモートの「1割：呪い」、「たちさばき」の2割など）。
- 『気合い』（「稀に気合いで相手の攻撃を耐える。残り体力が多いと発動しにくい」）の発動率は、たぶん残り体力の割合（％）で決まり、体力100％（満タン）なら発動率0％（補足: ユーザーより）。体力が減るほど発動しやすくなる。こういう「満タンだと発動しにくい」ものの最大は、たぶん「稀に」の6.25％より高く、12.5％くらいとするとちょうどいい（補足: ユーザーより）。
- 《バトルフロンティア》のフィールド効果（「ここぞ！」で発動率が上がる）で、実際にどれだけ上がるかはまだわからない。

## タイプ
- タイプの特徴は第五世代準拠。「でんき」も麻痺し、「ゴースト」にも「くろいまなざし」が効く。（出典: 034）
- **複合タイプの技**（原作の「フライングプレス」のようなもの）: 持っているタイプのうち、最もダメージが多くなる相性で判定する。どちらか片方が条件を満たせば、タイプ一致の倍率も持ち物の効果も乗る。特性などで無効にされる場合は、片方が条件を満たせば無効になる。
- **相手のタイプ耐性を貫通する効果**: 最終的な相性が等倍になる。例: この効果のついた「電」技を、じめん・ドラゴン・じめん／ひこう・ドラゴン／ひこうに打つと、どれも等倍。
- **「ダーク」タイプ**: 通常では存在しえない特殊なポケモン・技のタイプ。「ダーク」以外のすべてに「ばつぐん」を取れて（050, 122）、「ダーク」以外の技を半減で受けられる（187、前にメアリから聞いた話として、カズマ）。人間なら高位の「能力」型が一発撃てるかどうか、というレベル（050）。メアリは《シャルノス》を展開している時だけ、単発の「技能拡張」で「ダーク」技を出せる（122）。何者にも染まらぬ“黒”のタイプ（天花）で、ギンガ団の力でも詳細を解明しきれていない（アカネ）。使い手として、今代のエーテル財団会長ルザミーネ（現役時代）と現シンオウチャンプがいる（天花）。アカギはルザミーネを「あの女マジで頭おかしい」と評していた。隕石にでもくっついていたのか、はアカネの愚痴で確定ではない。（出典: 050, 122, 187）

## 「ここぞ！」という場面
1. 「3vs3」のときは、味方が残り1体になると自陣が「ここぞ！」。（6vs6では残り3体。出典: 045, 046）
2. お互いの『エース』が場で対面すると、互いの場が「ここぞ！」。
- 「ここぞ！」は、上の条件が満たされている間だけ続く（「ここぞ！」の原則どおり。補足: ユーザーより）。
  - 2の『エース』同士の対面で入った「ここぞ！」は、どちらかの『エース』が場を離れると終わる。214では、うてながレジーナを引っ込めた時に、まだ4体残っていたカズマ側は「自陣が「ここぞ！」という場面でなくなり、『不動のエース』が焼失した」。
  - 1の残り体数で入った「ここぞ！」は、交代しても体数が戻らないので続く。214のうてな側（残り3体）や、マックイーンが倒れて残り3体になったカズマ側がこれ。
  - 1と2の両方が当てはまっていれば、2が終わっても1の「ここぞ！」は残る。（出典: 213, 214）
- 「ここぞ！」の原則には、始まりと終わりのタイミングがきっちりある（補足: ユーザーより）。条件が満たされた瞬間に始まり（「〜になったことで、〜が「ここぞ！」という場面になった！」）、条件が崩れた瞬間に終わる（「〜が「ここぞ！」という場面でなくなり〜」）。
- ガッシュの異名『友情』（味方と交代して場に出た時、『エース』が必ず発動する）は、「ここぞ！」の**発動だけ**を行う。終わる時の処理は普通に効く（補足: ユーザーより）。200では、『友情』で起動していたガッシュが相手の『エース』（ウィリアム）を倒した時、「全体の場が「ここぞ！」という場面でなくなったことで、ガッシュの『エース』が消え去った！」。（出典: 200）
- 先に『ペースメーカー』（味方の『エース』を発動させる専用）で『エース』が一度発動していれば、そのあと「ここぞ！」の場面になっても『エース』は再び発動しない（「「ここぞ！」でワンモア」はない。キャプテン・アメリカ）。（出典: 246）

## 『役割』の発動タイミング
- 「場に出たとき」系は、場に出たときに発動する。
- 『エースアシスト』『エンチャンター』は、**後続が場に出た瞬間**に発動する。通常交代や「しっぽをまく」なら、そのターン、交代した瞬間にカズマの『固有』も発動する。
- ただし、ターン終了時に交代する能力（『輪廻』『旋回』など）の場合、後続が場に出るのは次のターンの開始時。
- 『チェイサー』は、「おいうち」効果が発動したときに発動する。
- **特性の発動は『役割』より早い**。102では、タナトスの特性「プレッシャー」でガブリアスの「速」が下がってから『トップバッター』が発動したので、カズマの『固有』で相手を「きょううん」にしても防げなかった。（出典: 102）

## 防護
「防護」とは、このスレでは相手の攻撃技のダメージを緩和したり無効にしたりするもの。次の3つが含まれる。
1. ダメージの緩和や無効化
2. 「攻」「特攻」の上昇（強化）の無視
3. 「必ず耐える」系（『気合い』のような「稀に耐える」ものも含む。117でカタクリの『気合い』がガッシュの『バオウ・ザケルガ』に貫通された。出典: 117、補足: ユーザーより）

- 『固有』ポテンシャルによるダメージの緩和や、四式の『たえろ！』は**トレーナーの**防護ポテンシャル。なので『オールドタイプ』や『エキスパンション（闘）』（出典: 062）では貫通できない。
- 「宙に浮かび上がる」ことで得る「地面」技の無効化は防護に当たらない（下の「宙に浮かび上がる」を参照）。
- 『スーパーヒーロー』（キャプテン・アメリカ）の「「まもる」等が貫通（解除）されない」は**防護ではない**ので、『三角効果』でも抜けない。『強化貫通』ならぶち抜ける（作者）。（出典: 245）
- 急所に当たると相手の能力の上昇（強化）は無視されるが、**防護は急所（クリティカル）では抜けない**（出典: 068）。
- ポケモン自身が持つ防護ポテンシャル（ハンニバルの『アラガミ』の「亜人」の技の低確率半減や、サンズの防御型の『専用』『陽気な髑髏は悪夢と踊る』など）は、『オールドタイプ』や『エキスパンション（闘）』（「闘」技の時）で貫通される。125では、ヤマトの「からたけわり」に『アラガミ』の半減が一度表示されたが、『エキスパンション（闘）』で無視できるとして直後に訂正された。（出典: 125）

### 三角効果
- 専用ポテンシャルの型の一つ（「攻」か「特攻」がAA以上で使える。出典: 066）。相手ポケモンの「まもる」などの技、特性、相手ポケモンと相手トレーナーの防護ポテンシャルを無効にする。
- トレーナーの防護ポテンシャルには、四式の『たえろ！』が当たる。
- 能力の上昇・強化を貫通する効果はない。
- 〇〇指令による「防」「特防」の強化は、トレーナーの防護ポテンシャルに当たらないので、三角効果では貫通されない。
- 持ち物の「**とくせいガード**」を持っていれば、三角効果からも特性を守れる（144でガッシュの「きあい」が残り、ラハールの急所の一撃を体力1で耐えた。「「もちもの」の力までは、貫けまい！！」）。（出典: 144）

## 『指令』
- 「あばれる」状態のポケモンは指示を受け付けないので、『指令』も効かない。
  - 「げきりん」を出す＋六令 → 「あばれる」状態になる前の『指令』なので可能。
  - 「げきりん」を出す＋四式 → 「あばれる」状態中の『指令』になるので不可能。
  - 「げきりん」の途中＋六令 → 『指令』を含む指示を出せないので不可能。
- 「『指令』を受けたとき〜」系のポテンシャル（『サーヴァント』など）が発動するのは六令（『〜指令』）だけ。四式では発動しない。『サーヴァント』は093でBBが持っていて、原典でも同じ注記があった。（出典: 093）
- 逆に「自分の『四式』が発動したとき〜」系（ブリジットの『トリックプレイ』、錦木千束の『不殺主義の彼岸花』など）は、六令では発動しない。また『かわせ！』『よけろ！』が実際に発動しなければ無効（必中技に当たった場合も無効）。『もどれ！』は、相手の「おいうち」などで攻撃が成立した場合に『四式』の処理との兼ね合いが出る。（出典: 131）
- 『四式』が発動しても、対応する手段で突破された時（『かわせ！』『よけろ！』には必中、『もどれ！』には「おいうち」、『たえろ！』には防護貫通）は、『四式』をきっかけにするポテンシャル（千束の『固有』など）は発動しない。トレーナーの『たえろ！』を正面から抜けるのは『三角効果』くらい。（出典: 135）
- 『たえろ！』は、急所でも何でも、相手の技のダメージを必ず耐える（体力1で残る）（補足: ユーザーより）。止められるのは、防護ポテンシャルを無視する手段で突破された時（上の項目）だけ。
- 「**通常交代**」は、指示の時に出す交代コマンド（『もどれ！』も含む）のこと。「とんぼ」技、ポテンシャルによる交代、「レッドカード」などの強制交代は含まない。（出典: 135）
- 『旋回』のように倒したあと交代する場合でも、お互いが同時に次のポケモンを出す状況（相手を倒した時）では、ルサルカの『エイヴィヒカイト』のように「先に場で待ち構える」必要のあるものは発動しない（『凱旋』と同じ）。（出典: 137）
- 「**だっしゅつパック**」: 自分の能力が下がると自動で交代する（BBの「リーフストーム」の特攻ダウンで発動）。「かげふみ」や『チェイサー』のような通常交代を狙う対策をかわせる。（出典: 140）
- 「**クリアチャーム**」は、相手の特性「ぼうえいせん」による能力低下も防いだ。（出典: 140）
- 設置技「**ひばしら**」（変化・炎・敵陣）: 場に出た相手に体力の1/8の「炎」ダメージを与える。（出典: 139, 140）
- 「**きょけんとつげき**」を使うと、そのあと相手の技が「必中」になり、威力が2倍になる（クロコダインが使ったあと、ヤマトの「アイスブレード」が必中・2倍で入った）。（出典: 139）
- 「**あばれる**」（物理・ノーマル・威力150）: 2Tの間あばれる状態になり、そのあと混乱する。（出典: 140）
- 特性「おそれしらず」（体力1/2以下で攻2倍）、「けいやく」（場に出た時、相手の特性を「けいやく」に変える）、「クイックドロウ」（同じ優先度の技で3割先に動く）、「てったいせん」（交代する時、相手の速をがくっと下げる）。（出典: 136, 137, 140, 141）
- 「グラスフィールド」の回復は実機どおりで、宙に浮いているポケモン（ひこうタイプの瑞鶴など）には入らない（補足: ユーザーより）。（出典: 140）
- ルサルカの『エイヴィヒカイト』は、「死に出し」で出てきた相手の体力をドレインする（139でザクに発動）。（出典: 139）
- 「**はたきおとす**」は持ち物を壊してからダメージを与えるので、「きあいのタスキ」は発動する前に壊れる（137のエイラ）。（出典: 137）
- 第二節に向けて出た技（153〜157）:
  - 「**スタンガード**」（変化・電・自分。優先度+4の「まもる」系で、連続で出すと失敗しやすい）: 相手の直接技を防ぐと、相手を麻痺させる。「でんじは」と同じでじめんタイプは麻痺しないが、「ちくでん」「ひらいしん」は無視する（技を当てたわけではないので）。ロトムの特性にも通る。（出典: 154）
  - 「**うまのり**」（物理・闘・単体・100・命中85・接触）: 命中後に味方と任意交代する「とんぼ」技（原文で接触を×から○に訂正）。「**しょうりのまい**」（変化・闘・自分）: 攻・防・速を上げる「踊り」技（実機の第9世代の技）。（出典: 153）
  - 「**ちのやり**」（特殊・水・単体・50・命中100・非接触）: 必ず急所に当たる。「**くさかり**」（変化・草・自陣）: 自陣の設置物を解除する。「しっとのほのお」「かみなりあらし」「なまける」も名前が出た。（出典: 154, 155）
- 特性「**おうごんのからだ**」: 相手からの変化技を無効にする（「こわいかお」「どくどく」「ちょうはつ」「くろいまなざし」、相手がこちらを対象にする「のろい」など）。設置技や、自分が対象でないもの、「みちづれ」「こころのめ」のような使った側への状態変化は防げない。サイヤ人などが持つ特性で、ガッシュ種にも適性があるらしい。（出典: 154）
- 特性「**まけんき**」: 相手に能力を減少・低下させられた時、自分の「攻」がぐーんと上がる。（出典: 153）
- 158〜162で出た技:
  - 「**ほしくだき**」（物理・地・単体・200・命中100・接触）: 「リフレクター」などの技を解除する。さみだれの固有『惑星を砕く一撃』の技能拡張で、実戦では「まもる」も突破した（効果の全文は非公開）。（出典: 159）
  - 「**だいじしん**」（物理・地・複数・110・命中95・非接触）: 相手の防護特性を無視する。エレン・イェーガー（さみだれ）の技。（出典: 159）
  - 「**しんそく**」はノーマル技なので、ゴーストタイプには通らない（マックイーンは「きもったま」から「まけんき」に変えたため）。ノーマルとゴーストは互いに無効なので、その時は積みや回復に使えばいい（沖野）。（出典: 161）
  - 「**なげつける**」でプレートを投げると威力90。「ノーマル」のプレートは、沖野の知る限り存在しない（はるか昔には「ノーマル」や「あらゆるタイプに変化するプレート」もあったと聞く）。（出典: 161）
  - ほかに、「かぜのつるぎ」（ランスロット・アルビオン）、「かみなりあらし」（アドルフ）、「Vジェネレート」（ゼットン）、「どくづき」「ぶちかまし」「フレアドライブ」「DDラリアット」「ゴールドラッシュ」（ミラクルズ）が使われた。凛がカズマに「ちきゅうなげ」をした（160）。（出典: 158, 159, 162）
- 『メガシンカ』: さみだれ（「能力」型）のハガネールが「進化を超えろ、"メガシンカ"！！」でメガハガネールになり、『超鉄蛇の覚醒』でT終了時まで全能力値1.5倍になった。（出典: 159）

## 妙手（タイム）
- 「指示：A」以上のトレーナーが使える。
- バトル中に1回だけ、場にいる選手と相談できる。（出典: 098）
- そのときトレーナーがわかっている情報で出せる最善手を出す。図鑑も使っていない先発の1ターン目に使っても、データがなければ何もわからない。（出典: 098）
- 使いどころは「前半から中盤にかけて鋭い一手を差し込む」か「後半戦でデータが集まったところで、詰みや逆転の手を打つ」のどちらか。（出典: 098）
- 「指示：A」で1回。そこから1ランク上がるごとに1回増える。ここでの「1ランク」はA→AA→AAAのような段階のことで、「+」「-」は数えない（直哉は指示A+で1回、『絆』でAA+になると2回）。『絆』で「指示」が上がっている場合は、その『絆』のポケモンが場にいる時だけ増えた分が使える。（出典: 098, 101）相手も同じで、イングリッド（指示AA）はカタクリ（『魂の絆』）が場にいる間は「タイム」が1回増える。（補足: ユーザーより）
- カズマはガッシュかルサルカ（『絆』）が場にいる間だけ使える。（出典: 098, 101）140からは、異名『愛馬』で自分に『魂の絆』が付くマックイーンが場にいる間も使える（213のT10で、マックイーンが場にいる時に使った）。（出典: 140, 213）
- 両方のトレーナーが同じターンに「タイム」を使うと、互いの読みが相殺されて、「指示」のランクの差はほとんど関係なくなる（お互い同じ条件になる）。117のカズマとイングリッドがこれで、カズマは「相手の動きが読み切れねぇ」と感じた。（出典: 117。「だいたいあってる」と補足: ユーザーより）
- 「タイム」は、同時でない限り、トレーナーの「指示」が終わった直後に発動する。なので交代を指示しても、「タイム」の時点で場にいるのは交代前のポケモンで、「タイム」で発動する効果（デンリュウの『灯電獣の発電』『アドバイス』など）はそのポケモンに入る（ロトム）。（出典: 200）
- 特殊役割『ベテラン』は、1試合1回、「指示」に関係なくトレーナーに「タイム」を使わせられる（ベルナデッタは指示C）。（出典: 200）
- 『ベテラン』による「タイム」は表示される（天花）。『ベテラン』の『役割』は「タイム」の使用時に発動するので、お互いが動き出す瞬間に「タイム」と解析の有無が分かる。付随の『アドバイス』で、そのとき相手のデータを解析できる（245のクリーブランド。『スカウター』とは解析のタイミングが違う）。（出典: 245）

## 読者の安価の決まり方（補足: ユーザーより）
- カズマ側の行動は読者の安価で決まる。読者は指示安価の数ターン前から議論を重ねていて、指示安価は結論を出すだけの場になっている。戦闘準備の前には、相手の固有のタイプの予想や、持ち物・指令を入れたダメージ計算までしている（例: コトブキ杯のユニバース戦の前、2時間以上の議論でヤマトのマジュのみを決めた）。原典には議論が残らず、決まった安価と結果だけが残るので、原典の結果から読み筋を推し量ると取り違えやすい。
- 選ばれやすいのは、全体的に丸い選択肢。リスクが大きくリターンもある手は採用されにくく、安全策でも失敗が起こりうる手（命中不安など）は嫌われやすい。
- 一方で、何が起きてもとりあえず場を荒らせればいい手は、結果がランダムでもリスクとは見なされず、わりと採用される（例: ガブリアスのレッドカード。ナギサ杯のサンダーズ戦など）。どう転んでも損をしない運任せは、外れたら困る運任せとは別に扱われている。
- 「おまじない」（急所を防ぐ）は、一手損してでも、そのあとの読みを安定させる効果が大きい。毎ターン「急所かもしれない」と考えずに済むので、議論がぶれにくくなる（補足: ユーザーより）。213の《縁マジアベーゼ》戦（急所に寄せた指示型の相手）で、モモが『全開防御指令』と合わせて先に貼った。
- カズマの「指示：B-」は、この協議制の安価で勘違いやミスが出たり、意見が割れたりすることを、カズマのミスとして落とし込んだもの（→ [pro-trainer.md](pro-trainer.md)）。

## 技の処理
- 行動の順番が決まってから、技を出す直前に「麻痺」などの行動不能の判定がある。これは基本的に実機と同じで、「せんせいのツメ」が発動して先に動けたのに麻痺で動けない、ということも起こる（補足: ユーザーより）。214では、レジーナが『後の先』で先に動き、専用『魔法少女の黒い衝動』の発動まで表示されたあと、麻痺で動けなかった。（出典: 214）
- **2つのタイプを持つ攻撃**（「フライングプレス」や、エールの第二『固有』を乗せた「さばきのつぶて」など）は、2つのタイプのうちダメージが多くなる方の相性で判定する。どちらかのタイプが条件を満たせば、タイプ一致の倍率や持ち物（プレートなど）の効果も乗る。（出典: 114）
- 技の処理は、基本的に原作（第五世代まで）のポケモンと同じ。原典に独自の表示があるものだけ、そちらに従う（補足: ユーザーより）。例: 「ほろびのうた」は、原典の技の説明では「場にいる全員の「死のカウント」を「4」にする」（104のカフェのデータ）。
- **「とんぼ」技と「おいうち」技がかち合ったとき**: 「速」や優先度をすべて無視して、「おいうち」側が先制する。『チェイサー』なら、その瞬間に『役割』が発動する。（出典: 085）
- **ドレイン技**: 自分の体力が満タンのときは回復が発動しない。
- **「キングシールド」**（変/鋼/自、優先度+4。「まもる」等の技で、連続で出すと失敗しやすい。相手の「直接技」を無効化した時、相手の「攻」を下げる）: 「まもる」系の技として扱う（作者）。下げる効果は「まけんき」の対象になる。（出典: 245, 247）
- **「けがわでまもる」**（変/ノ/自、優先度+4。「まもる」等の技。相手の「直接技」を無効化した時、自分の「防」が上がる）。ムックの技。（出典: 247）
- **「ロックオン」と「まもる」**: 技「ロックオン」も「まもる」で防げる（技の対象は相手で、状態変化は自分にかかる。「こころのめ」も同じ）。なので相手の「まもる」に合わせてスカすことはできない。「ロックオン」状態は交代で解除される。（出典: 245）
- **「みらいよち」類**: 原作と違って状態変化になっているので、交代で解除できる。次のターンでの実質的な連続攻撃のようなもの。（出典: 113）
  - 「みらいよち」状態…次のターンの最後に、相手に「みらいよち」によるダメージを与える。「まもる」を貫通する。ダメージは、「みらいよち」状態にしたときに場にいたポケモンの「特攻」で判定する。（出典: 113）
  - 使った側の持ち物、特性、ランク補正、ポテンシャルは影響しない。技として出した場合以外（『固有』や『専用』など）は、タイプ一致の補正も入らない。（出典: 113）
- **追加攻撃と追加行動**: 追加攻撃は同じ攻撃を続けて出すこと。追加行動は異なる行動もできること。
  - 食蜂の『固有』の「こうげきしれい」の追加行動は、味方の「通常行動」にしか反応しない（天花談）。通常攻撃が外れても、追加の「こうげきしれい」は別に当たる。（出典: 145, 146）
  - メガスピアーの『スピアナイト』の「一番最初に」の追加行動は、『指令』や交代の直後に、優先度を無視して誰よりも早く出る。「ねこだまし」や「まもる」より早い。この追加行動では「おいうち」は選べないと見られていて、『もどれ！』なら確実にかわせる（マックイーン談）。（出典: 145, 147）
- **全能力値の上昇（強化）**: 基本的に攻撃・防御・特攻・特防・素早さの5つ（体力は入らない。『二枚看板』の1.33倍や「さいごのとりで」の1.5倍も同じ）。「任意」や「ランダム」の能力上昇は、回避・命中・急所ランクを含むこともある。

## フィールド形成（《電撃領域／サンダーコロッセオ》）（出典: 189, 190, 191）
- トレーナーの『固有』で、スタジアムのフィールド効果を別のフィールドに上書きすることを“**フィールド形成**”と呼ぶ。条件は「能力：A」以上か、「統率：AA」＆「能力：B」相当の出力（玉藻）。「C」ではほぼ見られず、「B」から万丈目のような例が出てくる。（出典: 189, 190）
- 《電撃領域／サンダーコロッセオ》（万丈目の『雷鳴轟く決闘領域』）: 3の倍数のT、場にいる全員が一番最後に「かみなり」の追加行動を得る。「かみなり」は素早さの順に出す。そのTに「まもる」や『全開回復指令』などで別の行動をしていたり、「あばれる」「こだわり」などでほかの技が出せなかったりすると不発。（出典: 190）
- フィールドの「かみなり」も「次に繰り出す技」に数えられる。ルサルカの『水魔女の呪縛』（相手が次に出す技の優先度-1）は、T12のフィールドの「かみなり」で消費された（万丈目「単発式の妨害札なら無駄撃ちさせれば良い。カードゲームの常識」）。（出典: 191）
- 相手の「かみなり」は地面タイプには無効で、地面タイプ側も自分の「かみなり」を撃てる（T3でガブリアスがマニューラを倒した）。（出典: 191）

## 宙に浮かび上がる
- 特性やポテンシャルでつく効果。状態変化の扱いに近い。発動するときはメッセージに表示される。
- この効果による「地面」技の無効化は防護に当たらない。防護特性や防護ポテンシャルを無視する効果でも貫通されない。
- 特性「ふゆう」は実機と違い、場に出ると表示される。特性「かたやぶり」などでも無視されない。
- そのほかの仕様は、ポケモンwikiの「地面にいる」を参照。

## 持ち物
- 持ち物の効果は、基本的に実機と同じ。ただし、スレでの仕様変更やポテンシャルとの兼ね合いで勝手が違うこともある。
- **こだわりハチマキ**: 自分の「防」の値でダメージを計算する技には効果がない。
- **とつげきチョッキ**: 急所で貫通される。
- **ひかりのねんど、あついいわ、しめったいわなど**: ポテンシャルには効果がない（技と特性だけ）。
- **クリアチャーム**: 相手からの能力の減少を無効にする。低下は無効にしない。実機と同じで、実機よりパワーアップしている特性「クリアボディ」「まけんき」とは対応範囲が違う。
- **持ち物を壊す・変える効果**: 持ち物が効果を出す前に壊したり変えたりする。攻撃技なら「きあいのタスキ」や「ボコのみ」なども貫通して攻撃できる。
- **こだわりと技能拡張**: 「技能拡張」を使っても「こだわり」には縛られない。ただし、一度でも覚えている技を使えば、「技能拡張」も使えなくなる。

- 大会の勝敗が同点のときは、地元チーム（【H】）が上位。それ以外の場合は、直接対決の勝者が上位。（出典: 061）

## ダメージ表示の目安（推測）
原典の「〇〇のダメージ」という表示と、作中の台詞から読み取ったおおよその目安。1発で受けたダメージが、最大体力のどのくらいかを表していると思われる。（推測）
- ユーザーいわく、完全な正解ではないが大きく間違ってもいない。今後、数字は多少上下する。（補足: ユーザーより）

| 表示 | 目安（満タンから1発） | 根拠 |

| 微々たるダメージ | 1割未満 | 「ねこだまし」や、いまひとつの弱い技、半減された不一致技で出る（046, 048, 057, 124） |

- 目安は、原典の「〇〇のダメージ」の直後の「＠」と、その話で初めてダメージを受けたポケモン（ほぼ満タン）の組み合わせを数えて見直した。＠Nは「あと何発で倒れるか」なので、満タンから受けた1発の割合が、＠2なら3.3〜5割、＠1なら5割以上とわかる。ステルスロックや『固有』の削りを先に受けていたものは、なるべく数えていない。（推測。ユーザーに「精査してみて」と言われて見直した）
- 隣の言葉の範囲は少し重なる（「大きな」の上のほうと「深刻な」、「深刻な」と「特大の」）。補正の細かい差や、作者の手計算の幅があるためと思われる。
- 143〜147の計算での確認（推測）: 満タンから受けた場面は、上の目安とよく合う。
  - 「小さな」: シンリュウの「りゅうせいぐん」（壁で半減）→ルサルカが計算で15〜21%、本文でも「2割しか効いてない」（143）。「こうげきしれい」（半減）→ガブリアスが18〜25%（146）。
  - 「大きな」: ドダイトスの「さばきのつぶて」→マジュのみのヤマトが42〜61%、シンリュウの「さばきのつぶて」→壁のモモが46〜64%で、どちらも本文で「半分以上」（143）。メガスピアーの急所「ドリルライナー」→ヤマトが46〜63%、リオハートの「かえんほうしゃ」→イカルガが40〜57%で「＠1〜2」（147）。
  - 「特大」と「大きな」: ウルゥル＆サラァナの「さばきのつぶて」→マックイーンが62〜92%で「特大＠1」、威力半減の追加攻撃が32〜47%で「大きな」、2発で倒れた（143）。
  - 「極大」: ラハールの急所の「さばきのつぶて」→ガッシュが157〜222%（144）。
- **体力が減っている相手への表示は、最大体力ではなく「そのときの残り体力」に対する割合で決まっているように見える**（推測）。147では、残り4割前後のガッシュへのリオハートの「かえんほうしゃ」（最大体力の29〜42%）が「深刻な＠1」、残り2〜3割のルサルカへの急所の「こうげきしれい」（最大体力の12〜17%）も「深刻な＠1」だった。どちらも最大体力に対してなら「まずまず」か「小さな」くらいだが、残り体力に対してなら大半を削っている。上の表は満タンからの目安なので、減っている相手には、残り体力を満タンとみなして当てはめるとよさそう。（出典: 147）
  - ユーザーいわく、残り体力に対する割合になっている時もあれば、そうでない時もあり、決まったルールかどうかは分からない（補足: ユーザーより）。なので、減っている相手への表示から体力を逆算するときは、どちらの読みもありうるものとして幅を持たせる。
  - 最大体力に対する割合で出ている例: 191で、体力1のジェノブレイカーへのマックイーンの「しんそく」（いまひとつ）は「まずまずのダメージ」で、そのまま倒れた。残り体力に対してなら10割なので、この場面は最大体力に対する割合で表示されている。（出典: 191）
- 191〜194（「B」ランクの試合）での確認: 満タンから受けた場面は、上の目安と合っている。
  - 「大きな」: ガブリアスの「げきりん」（いまひとつ）→ジェノブレイカー「＠1〜2」（191）、ヤマトの「アイスブレード」→アームド・ドラゴン「＠1」（191）、ブルースの「スチールソード」→ガブリアス「＠1」（193）、プリンツ・オイゲンの「てっぽうみず」→ライナーと、ライナーの「ロックスタンプ」→プリンツ・オイゲンがどちらも「＠2」（194）。
  - 「深刻な」: ヤマトの『エースアシストα』込みの「からたけわり」→ベジータ「＠1」（191）。
  - 「特大の」: ジェノブレイカーの「ほうでん」→マックイーン「＠1」（191）、ガブリアスの「ドラゴンハウル」→ブルース「＠1」（193）、ギャラドスの「じしん」（アスカの固有で1.33倍）→ルサルカ「＠1」（193）。満タンから一撃で倒れた例もある（ガッシュの「10まんボルト」→ラギアクルス、191）。
  - 「微々たる」: モモの「こどもだまし」→フランケンシュタイン（191）、紅蓮の「せいなるほのお」→ライナー（194。いわで半減、『エースキラーβ』で半減、『全開防御指令』で防御2倍。計算で最大体力の4%前後）。
  - 「測定不能の」: ライナーの「ロックスタンプ」→紅蓮（194。『全開防御指令』で2倍の防御で計算、4倍、『エースアシストα』で2倍。ヨロギのみと『対岩耐性』を越えて、計算で最大体力の4倍近く）。

- 「＠2」「＠1」は、同じダメージをあと何発受けたら倒れるかの目安。（出典: 013）
- 擬似バトルをするときは、上のステータスのランクを種族値に置き換え、第五世代の原作のダメージ式で計算し、この目安で表示を決める。細かい部分は、原典のダメージ量と照らし合わせて調整する。

## 「けん」「つるぎ」技の範囲
- このスレ独自の裁定で、「ストーンエッジ」「きょけんとつげき」「みずしゅりけん」なども「けん」「つるぎ」技として数える（実機の特性「きれあじ」の対象ではないが、このスレではその影響を受ける）。第一節の改訂で「きりさく」「エアスラッシュ」も「けん」「つるぎ」技に入った。（出典: 193, 206）
