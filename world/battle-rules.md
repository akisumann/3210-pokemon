## ステータスのランク
図鑑の文字ランクは、種族値のおおよその範囲を表す。同じランクの中では「-」が下寄り、「+」が上寄り。ステータス画面の5つと、マスクデータの体力に使う（作者、012で最初に示された）。

| ランク | 種族値 |
| --- | --- |
| S | 200〜 |
| AAA | 170〜195（-〜+） |
| AA | 140〜165（-〜+） |
| A | 110〜135（-〜+） |
| B | 90〜105（-〜+） |
| C | 60〜85（-〜+） |
| D | 40〜55（-〜+） |
| E | 1〜35（-〜+） |

- **「+」はその幅の最大値、「-」は最小値で固定**（補足: ユーザーより）。例: B+ は105、B- は90。A+ は135、A- は110、AA+ は165、AA- は140、C+ は85、C- は60。
- **「+」「-」のない素のランクは、幅の中央あたりの値をテキトーにランダム**で決める（補足: ユーザーより）。両端（+と-の値）を除いた中ほど、例えばB なら95か100、A なら115〜130、C なら65〜80あたり（5刻み。刻みと範囲はゲーム用の目安）。
- S は200を超えたどこか（210でも220でも。補足: ユーザーより）。決まった値はなく、そのポケモンごとに200超えの値を置く。

- 能力ランク（「攻+1」など）は、1段階上がると1.5倍。（出典: 011）
- **種族値の補正の大きさ**（補足: ユーザーより）:
  - 『ポケパワー』のような「種族値に+補正を得る」効果は、「+」「-」の刻みで1つ上がる（B→B+、B+→A-）。
  - 「種族値を1ランク上げる」効果は、文字のランクが1つ上がる（B→A）。例: サムスの『賞金稼ぎのパワードスーツ』（C→B、A→AA）、ガッシュの『金雷児の王気』（特攻の種族値を1ランク上げる）。『金冠サイズ』の体力補正は「約2ランク」（モモ談）。

### ゲームで回すときの能力値の式（補足: ユーザーより）
- 実機の式で、**個体値と努力値はなし**。
  - 体力以外: 種族値×2×Lv/100＋5
  - 体力: 種族値×2×Lv/100＋Lv＋10
- 種族値は上のランクから決める（+は最大値、-は最小値、素は中央あたりからランダム、Sは200超え）。
- 性格による補正は、原典に出てこないので入れない（推測）。
- **体力（マスクデータ）のランクの決め方**（補足: ユーザーより）: 原典で分からないポケモンは、見た目や種族のイメージで決める。耐久が高くなさそうなのは **C** あたり、まあまあありそうなのは **B**、ちゃんとありそうなのは **A**、それ以上はそれだけ凄そうなもの（AA〜。古龍や『ヌシ』級など）。原典や逆算（[hp-estimates.md](hp-estimates.md)）で分かっているものはそちらを使う。
- **体力の見せ方**（補足: ユーザーより）: ゲーム中、プレイヤーには体力の数値を見せず、スレと同じく「大きなダメージ」などの言葉と「＠2」（あと何発）の印で見せる（[hp-estimates.md](hp-estimates.md#ダメージ表示の目安推測) の「ダメージ表示の目安」）。

## 能力の「上昇」と「強化」（補足: ユーザーより）
- **上昇**: ランクの変化。「攻を上げた」は+1、「ぐーんと上げた」は+2で、1段階で1.5倍（上の能力ランク）。状態表示では「攻+2」のように書く。
- **強化**: 倍率。『二枚看板』の全1.33倍、『全開指令』の2倍、『スターター』の1.05倍、『タイトエンドγ』の1.1倍など。状態表示では「全1.33倍」「速2倍」のように書く。
- 効果文に「上昇（強化）」と並べて書かれているものは、両方に作用する（例: 『ギガントマキア』「相手の攻/避の上昇（強化）を無視」、『エースキラーβ』「『エース』の攻/特攻の上昇（強化）を無視」、「せいなるつるぎ」）。
- 片方だけが書かれているものは、その片方だけに作用する。例: 『幻晶騎士の銃剣』は「攻（特攻）が上がった時」なので、ランクの上昇にだけ反応し、『全開指令』の強化では発動しない（253のオシュトル）。『盾従者の防衛』は「攻の上昇（強化）を無視」なので両方。
- 下げる側も同じで、「下げる」はランクの低下、「低下（0.75倍）」のように倍率が書かれているのは倍率の低下（「わざわいのたま」の特防0.75倍など）。「まけんき」は、ランクを下げられた時だけでなく、「わざわいのたま」のような倍率の低下でも発動する（下の「特性」を参照）。
- 急所は、相手のランクの上昇だけでなく倍率の強化も無視する（出典: 030）。
- **重なったときは全て掛け算**（補足: ユーザーより）。ランクの上昇と強化（例: 攻+1の1.5倍×『二枚看板』1.33倍＝約2倍）、強化同士（『二枚看板』1.33倍×『全開指令』2倍＝2.66倍）、技の威力の強化同士（『魔王虫の銃弾』1.5倍×「ノーマルジュエル」1.3倍＝1.95倍）のどれも掛け算。
- **同一のポテンシャルによる倍率強化は重ね掛けできない**（412、エール）: 操祈の第二『固有』『女王蜂の下す号令』（味方の『役割』の発動時、2Tの間味方の「防/特防」1.33倍）は、『エンチャンター』と『二枚看板』の『役割』が同時に発動しても1.33倍が2回かかることはない。''「防/特防」+1のようなランク上げ''なら重ね掛け（二回使える）になるが、その場合はレギュで縛られるはず。違うポテンシャル同士の強化は上のとおり掛け算。（出典: 412）
  - 理由（補足: ユーザーより）: 禁止のルールというより処理の性質。1.33倍のような倍率強化は、そのポテンシャルが味方に効いている状態を作る処理なので、すでに同じポテンシャルが効いている味方にもう一度かけても、その状態が続くだけで新しく付かない（重ねる意味がない。「きょううん」の相手をもう一度「きょううん」にしても何も増えない、火傷の相手をもう一度火傷にできないのと同じ）。「〇〇状態」という作中の用語があるわけではなく、あくまでそういう処理という説明。ランク上げは値を足す処理なので重ねられる。別のポテンシャルの倍率とは重なる（『女王蜂の下す号令』の1.33倍と『二枚看板』の1.33倍は重なる）。
- **「命中」「回避」のランク**は、ほかの能力と上がり幅が少し違い、+1でおよそ4/3（約1.33倍）（ガッシュ）。（出典: 164）

## レベル差
- レベルが10違うと、全能力におよそ1割の差があると考えてよい（目安）。
  - 例: Lv60とLv50なら、Lv60側の全能力がおよそ1.1倍。
  - 体力と防御（特防）がそれぞれ上がるので、耐久は掛け算になる。レベル30差（全能力およそ1.3倍）なら、受けだけで約1.69倍の耐久（補足: ユーザーより）。攻撃の1.3倍も合わせると、殴り合いの差は約2.2倍（推測）。例: 白石（「育成：AAA」）と戦う真冬は、バトルの度にレベル30ほどの差を見せつけられる（283）。
- ただし、Cランクあたりではチーム間のレベル差はせいぜい10程度なので、実際にはそこまで気にしなくてもよい。育成型の強みも含め、Cランクではどの資質もまだ真価を発揮していない。

## 急所（クリティカル）
- 急所率は**第五世代までの仕様**で、最大（C+4）でも確率は1/2。その分、急所のダメージは**2倍**（012で最初に示されたスレの注意事項）。（出典: 012, 034, 071）
- このスレの急所は、ランクだけでなく「**倍率強化**」も無視する。（出典: 030）
- 急所ランクごとの確率:

| 急所ランク | 確率 |
| --- | --- |
| C+0 | 1/16（6.25％） |
| C+1 | 1/8（12.5％） |
| C+2 | 1/4（25％） |
| C+3 | 1/3（33.3％） |
| C+4 | 1/2（50％）。ランクはここまでしか上がらず、確率も50％が上限（補足: ユーザーより） |

- 相手との「指示」ランク差1つにつき、高い方に常に急所ランク+1がつく。
- **確定急所の技**（「ちのやり」など）は、自分の「特攻」の低下を無視して攻撃できる。（出典: 175）
- **クリティカル倍率**: 急所のダメージは基本2倍だが、特性「**スナイパー**」はクリティカル倍率が3倍になる（カズマ）。クラウドの固有『超究武神覇斬』は味方全員のクリティカル倍率を3倍にする（ライザ「1体の特性で済む「スナイパー」と、全員がクリティカル3倍のこれじゃ圧力が全然違う」）。401〜403の表示は「きゅうしょにあたった！（「特防」：無視/クリティカル倍率3倍）」。確定急所の攻撃技のレギュレーションは下の「協会のレギュレーション」。（出典: 400, 401, 402）
- 急所に当たるのを見てから『たえろ！』を出すことはできない（天花）。（出典: 200）

## 確率の目安（補足: ユーザーより）
原典のポテンシャルや効果の文に出てくる確率の言い方と、そのおおよその値。原典には数字は書かれていない。

| 原典の言い方 | 確率 | 例 |
| --- | --- | --- |
| 中確率 | 50％ | 『リターンキュア』『リターンヒール』、『エキスパンション（水）』、『桃王女の計画』 |
| 低確率 | 12.5％（1/8） | 『絆』のポテンシャルの再発動、コトブキスタジアムのフィールド効果、『百合剣士の剣技』 |
| 稀に | 6.25％（1/16） | 『気合い』、天花のサポート効果の「テレポート」の追加行動 |

- 低確率（1/8）と稀に（1/16）は、ゲームで回すときはこの値で固定する（補足: ユーザーより）。低確率は急所ランクC+1、稀には急所ランクC+0と同じ値。
- 「1割」「2割」のように原典に割合が書かれているものは、その数字のまま（ヴォルデモートの「1割：呪い」、「たちさばき」の2割など）。
- 『気合い』（「稀に気合いで相手の攻撃を耐える。残り体力が多いと発動しにくい」）の発動率は、たぶん残り体力の割合（％）で決まり、体力100％（満タン）なら発動率0％（補足: ユーザーより）。体力が減るほど発動しやすくなる。こういう「満タンだと発動しにくい」ものの最大は、たぶん「稀に」の6.25％より高く、12.5％くらいとするとちょうどいい（補足: ユーザーより）。ゲームで回すときの式は「発動率＝12.5％×（1−残り体力の割合）」（満タンで0％、残り50％で6.25％、残り10％で11.25％。補足: ユーザーより）。
- 《バトルフロンティア》のフィールド効果（「ここぞ！」で発動率が上がる）で、実際にどれだけ上がるかはまだわからない。

## タイプ
- タイプの特徴は第五世代準拠。「でんき」も麻痺し、「ゴースト」にも「くろいまなざし」が効く。（出典: 034）
- **複合タイプの技**（原作の「フライングプレス」、エールの第二『固有』を乗せた「さばきのつぶて」、「じゃあくなほのお」（悪（炎））など。[moves.md](moves.md) の「炎（地）」のような表記の技）: 持っているタイプのうち、最もダメージが多くなる相性で判定する。どちらか片方が条件を満たせば、タイプ一致の倍率も持ち物（プレートなど）の効果も乗る。特性などで無効にされる場合は、片方が条件を満たせば無効になる。（出典: 114, 227）
- **「こうかばつぐん」「こうかいまひとつ」になる効果・特定の相手に「ばつぐん」になる技**（「シンクロノイズ」「フリーズドライ」、『氷狼娘の凍剣』など）: 一律で「ばつぐん」は2倍、「いまひとつ」は0.5倍になる。計算すると4倍（や0.25倍）になる組み合わせでも、2倍（0.5倍）（「こおり」と「かくとう」の両方に抜群でも4倍にはならない）。逆に、条件を満たせばほかのタイプ相性を無視して2倍になる（「あく」タイプでも、同じタイプがあれば無効にできず2倍。天花）。（出典: 223。補足: ユーザーより）例: 373の『氷狼娘の凍剣』（「氷」技が「炎」「水」に「ばつぐん」）は、オシュトル（じめん/みず）にも4倍ではなく2倍（オシュトル「某に対して4倍になるわけではない」）。『エキスパンション（鋼）』（「悪」「霊」技が「こうかいまひとつ」）も0.5倍。
- **相手のタイプ耐性を貫通する効果**: 最終的な相性が等倍になる。例: この効果のついた「電」技を、じめん・ドラゴン・じめん／ひこう・ドラゴン／ひこうに打つと、どれも等倍。
  - 「いまひとつ」（や無効）が等倍になるだけで、「ばつぐん」にはならない。複合タイプの片方の半減だけを消して「ばつぐん」にする処理ではない（補足: ユーザーより）。例: 『氷狼娘の覇気』の「せいなるつるぎ」（かくとう）を「どく/いわ」のメドゥーサに打っても、等倍のまま（264）。
- **「闇」タイプ**（257）: 「闇」タイプ技は18種すべてのタイプに「ばつぐん」を取れる（ルサルカ）。帝督の専用は256では「ダーク」、257では「闇」と表示されていて、同じものと思われる（推測）。404のメアリの「しっこくのやみ」も、技のデータではタイプが「闇」で、効果に「「ダーク」技」と書かれている。（出典: 256, 257, 404）
- **「ダーク」タイプ**: 通常では存在しえない特殊なポケモン・技のタイプ。「ダーク」以外のすべてに「ばつぐん」を取れて（050, 122）、「ダーク」以外の技を半減で受けられる（187、前にメアリから聞いた話として、カズマ）。人間なら高位の「能力」型が一発撃てるかどうか、というレベル（050）。メアリは《シャルノス》を展開している時だけ、単発の「技能拡張」で「ダーク」技を出せる（122）。これが第三『固有』『全てを飲み込む漆黒の闇』（1/試）で、PT全員が「しっこくのやみ」（特/闇/複/150/-/×/「ダーク」技。「必中」技。交代する相手に2倍の威力で命中する）を出せる。「チャンピオンも持ってる「ダーク」の力、その一端」で、単発だが脅威度は絶大。これの関係でメアリの手持ちは『強化追尾』を持てない（ギャリー、404）。408ではアリスが使い、イカルガを一撃で倒した。『絆』での再発動の対象外（カズマ、408）。何者にも染まらぬ“黒”のタイプ（天花）で、ギンガ団の力でも詳細を解明しきれていない（アカネ）。使い手として、今代のエーテル財団会長ルザミーネ（現役時代）と現シンオウチャンプがいる（天花）。アカギはルザミーネを「あの女マジで頭おかしい」と評していた。隕石にでもくっついていたのか、はアカネの愚痴で確定ではない。（出典: 050, 122, 187, 404, 408）

## 「ここぞ！」という場面
1. 「3vs3」のときは、味方が残り1体になると自陣が「ここぞ！」。（6vs6では残り3体。出典: 045, 046）
2. お互いの『エース』が場で対面すると、互いの場が「ここぞ！」。
- 「ここぞ！」は、上の条件が満たされている間だけ続く（「ここぞ！」の原則どおり。補足: ユーザーより）。
  - 2の『エース』同士の対面で入った「ここぞ！」は、どちらかの『エース』が場を離れると終わる。214では、うてながレジーナを引っ込めた時に、まだ4体残っていたカズマ側は「自陣が「ここぞ！」という場面でなくなり、『不動のエース』が焼失した」。
  - 1の残り体数で入った「ここぞ！」は、交代しても体数が戻らないので続く。214のうてな側（残り3体）や、マックイーンが倒れて残り3体になったカズマ側がこれ。
  - 1と2の両方が当てはまっていれば、2が終わっても1の「ここぞ！」は残る。（出典: 213, 214）
- 「ここぞ！」の原則には、始まりと終わりのタイミングがきっちりある（補足: ユーザーより）。条件が満たされた瞬間に始まり（「〜になったことで、〜が「ここぞ！」という場面になった！」）、条件が崩れた瞬間に終わる（「〜が「ここぞ！」という場面でなくなり〜」）。
- ガッシュの異名『友情』（味方と交代して場に出た時、『エース』が必ず発動する）は、「ここぞ！」の**発動だけ**を行う。終わる時の処理は普通に効く（補足: ユーザーより）。200では、『友情』で起動していたガッシュが相手の『エース』（ウィリアム）を倒した時、「全体の場が「ここぞ！」という場面でなくなったことで、ガッシュの『エース』が消え去った！」。（出典: 200）
- 先に『ペースメーカー』（味方の『エース』を発動させる専用）で『エース』が一度発動していれば、そのあと「ここぞ！」の場面になっても『エース』は再び発動しない（「「ここぞ！」でワンモア」はない。キャプテン・アメリカ）。（出典: 246）
- だっしゅつパックなどの強制交代で出直しても、『エース』がもう一度発動する“おかわり”はない（モモ）。（出典: 200）

## 処理順（要約）
処理順のルール（同じタイミングで動くものの順番、1ターンの流れ、『役割』の発動タイミング、天候・フィールドのかち合い、死に出し、特性のコピーなど）は [turn-order.md](turn-order.md) に集約した。要点だけ:
- 場に出た時は、すでに場に残っている設置技が最優先 → お互いのポケモンは**素早い方から**（その瞬間の、ランク・強化込みの速さ）→ 1体の中は**特性 → 『役割』 → ポテンシャル欄の上から順**（図鑑の並び: 分類 → 異名 → ヌシ → 種属 → 属 → 絆 → 先 → 対〇 → 汎用 → 付随 → 特権 → PT → 専用）。特性は『役割』より早い（102）。
- 「〇〇が発動した時、〜」系はワンテンポ遅れる。
- トレーナー側の動き（通常交代・『指令』）は両者で完全に同時。死に出しは次のT開始時。
- スタジアムのフィールド効果は、T終了時の最後の最後（下の「フィールド」）。
（補足: ユーザーより。出典: 102）

## 防護
「防護」とは、このスレでは相手の攻撃技のダメージを緩和したり無効にしたりするもの。次の3つが含まれる。
1. ダメージの緩和や無効化
2. 「攻」「特攻」の上昇（強化）の無視
3. 「必ず耐える」系（『気合い』のような「稀に耐える」ものも含む。117でカタクリの『気合い』がガッシュの『バオウ・ザケルガ』に貫通された。出典: 117、補足: ユーザーより）

- 『固有』ポテンシャルによるダメージの緩和や、四式の『たえろ！』は**トレーナーの**防護ポテンシャル。なので『オールドタイプ』や『エキスパンション（闘）』（出典: 062）では貫通できない。
- 「宙に浮かび上がる」ことで得る「地面」技の無効化は防護に当たらない（下の「宙に浮かび上がる」を参照）。
- 『スーパーヒーロー』（キャプテン・アメリカ）の「「まもる」等が貫通（解除）されない」は**防護ではない**ので、『三角効果』でも抜けない。『強化貫通』ならぶち抜ける（作者）。（出典: 245）
- 急所に当たると相手の能力の上昇（強化）は無視されるが、**防護は急所（クリティカル）では抜けない**（出典: 068）。
- ポケモン自身が持つ防護ポテンシャル（ハンニバルの『アラガミ』の「亜人」の技の低確率半減や、サンズの防御型の『専用』『陽気な髑髏は悪夢と踊る』など）は、『オールドタイプ』や『エキスパンション（闘）』（「闘」技の時）で貫通される。125では、ヤマトの「からたけわり」に『アラガミ』の半減が一度表示されたが、『エキスパンション（闘）』で無視できるとして直後に訂正された。（出典: 125）
- 『闘争本能』（低確率で攻撃技を無効化。ポケモン自身の防護ポテンシャル）は、『エキスパンション（闘）』（防護ポテンシャルの無視）で打ち砕かれた。（出典: 232）
- 攻撃を無効にする特性（「しらはどり」など）は「**防護特性**」と呼ばれる（ムラサメライガーの『村雨機の大刀』: 自身の「C」が「+2」以上の時、「けん」「つるぎ」等が相手の防護特性を無視する。カズマ「こいつ、「しらはどり」を抜いてくるポテンシャル持ちか」）。（出典: 403）
- 『対〇回避』（命中率の低下）は、『オールドタイプ』でも消えなかった。403では、オシュトルの『仮面の者』（『オールドタイプ』扱い）がムラサメライガーの『対地耐性』を貫通したが、同じ「だいちのつるぎ」に『対地回避』の「命中0.85倍」は表示された。推測: 命中を下げるものは防護（ダメージの緩和・無効化など）に当たらない。（出典: 403）

### 三角効果
- 専用ポテンシャルの型の一つ（「攻」か「特攻」がAA以上で使える。出典: 066）。相手ポケモンの「まもる」などの技、特性、相手ポケモンと相手トレーナーの防護ポテンシャルを無効にする。
- トレーナーの防護ポテンシャルには、四式の『たえろ！』が当たる。
- 能力の上昇・強化を貫通する効果はない。
- 〇〇指令による「防」「特防」の強化は、トレーナーの防護ポテンシャルに当たらないので、三角効果では貫通されない。
- 持ち物の「**とくせいガード**」を持っていれば、三角効果からも特性を守れる（144でガッシュの「きあい」が残り、ラハールの急所の一撃を体力1で耐えた。「「もちもの」の力までは、貫けまい！！」）。（出典: 144）

## 『指令』
- **1Tに出せる数**: 六令は1Tに1回、四式も1Tに1回。六令1つと四式1つを同じTに同時に出すことはできる。（補足: ユーザーより）
- **四式が効く範囲**: 四式（『かわせ！』『よけろ！』など）が効くのは1回の攻撃だけ。374のライザの「「かえんだん」で『よけろ！』を使わせてその上からもっぱつ「かえんだん」」は、これを利用した形（『リザードナイトY』の最速の追加行動で四式を使わせ、通常の行動で当てる）。（補足: ユーザーより）
- 「あばれる」状態（「げきりん」など）のポケモンは指示を受け付けないので、『指令』も効かない（→ 下の「状態変化」の「あばれる」状態）。
- 「『指令』を受けたとき〜」系のポテンシャル（『サーヴァント』など）が発動するのは六令（『〜指令』）だけ。四式では発動しない。『サーヴァント』は093でBBが持っていて、原典でも同じ注記があった。（出典: 093）
- 逆に「自分の『四式』が発動したとき〜」系（ブリジットの『トリックプレイ』、錦木千束の『不殺主義の彼岸花』など）は、六令では発動しない。また『かわせ！』『よけろ！』が実際に発動しなければ無効（必中技に当たった場合も無効）。『もどれ！』は、相手の「おいうち」などで攻撃が成立した場合に『四式』の処理との兼ね合いが出る。（出典: 131）
- 『四式』が発動しても、対応する手段で突破された時（『かわせ！』『よけろ！』には必中、『もどれ！』には「おいうち」、『たえろ！』には防護貫通）は、『四式』をきっかけにするポテンシャル（千束の『固有』など）は発動しない。トレーナーの『たえろ！』を正面から抜けるのは『三角効果』くらい。（出典: 135）
- 『たえろ！』は、急所でも何でも、相手の技のダメージを必ず耐える（体力1で残る）（補足: ユーザーより）。止められるのは、防護ポテンシャルを無視する手段で突破された時（上の項目）だけ。
- 『全開回復指令』は行動をスキップするので、『たえろ！』も使えない。満タンに戻したところに、通常攻撃、低確率の追加行動、「呪い」の3段で倒されることもある。（出典: 169）
- 急所に当たるのを見てから『たえろ！』を出すことはできない（上の「急所」。出典: 200）。

## 交代
- 「**通常交代**」は、指示の時に出す交代コマンド（『もどれ！』も含む）のこと。「とんぼ」技、ポテンシャルによる交代、「レッドカード」などの強制交代は含まない。（出典: 135）
- 交代が出る時機（「とんぼ」技はその場ですぐ出る、『凱旋』『輪廻』『旋回』の後続は次のT開始時、死に出しは次のT開始時）は [turn-order.md](turn-order.md)。
- 『旋回』のように倒したあと交代する場合でも、お互いが同時に次のポケモンを出す状況（相手を倒した時）では、ルサルカの『エイヴィヒカイト』のように「先に場で待ち構える」必要のあるものは発動しない（『凱旋』と同じ）。（出典: 137）『エイヴィヒカイト』は、「死に出し」で出てきた相手の体力をドレインする（139でザクに発動）。（出典: 139）
- **強制交代**で場に出たり離れたりしたときは、「場に出たとき」「場を離れたとき」のポテンシャルや特性は発動しない（出典: 045）。「レッドカード」などで場に出たときは、『二枚看板』は発動しない（176のマックイーン）。（出典: 176）
- 『野生』のポテンシャルを持たないので、群れのポケモンにも強制交代は効く（カズマ）。（出典: 231）
- 天花のサポート効果で、交代阻害（「くろいまなざし」「しめつける」など）は基本的に無視できる。「テレポート」の追加行動は稀。（出典: 164）この「テレポート」の追加行動は、「とんぼ」技での交代のように扱われる。『エンチャンター』、『アシスト』、カズマの『固有』からの『グッドラック』など、交代や交代先で発動する効果はふつうにつながる。（出典: 169）
- **強制交代を受けない**効果（《夢幻漆黒空間/シャルノス》、種属の『〜の重量』など）でも、強制交代しないだけで「ハウル」のダメージなどは通る（カズマ、404）。（出典: 404）
- 交代封じと「必ず交代できる」がかち合ったら「必ず」の方が勝つ（[turn-order.md](turn-order.md)。補足: ユーザーより）。「だっしゅつパック」による自動交代は下の「持ち物」。

## 妙手（タイム）
- 「指示：A」以上のトレーナーが使える。
- バトル中に1回だけ、場にいる選手と相談できる。（出典: 098）
- そのときトレーナーがわかっている情報で出せる最善手を出す。図鑑も使っていない先発の1ターン目に使っても、データがなければ何もわからない。（出典: 098）
- 使いどころは「前半から中盤にかけて鋭い一手を差し込む」か「後半戦でデータが集まったところで、詰みや逆転の手を打つ」のどちらか。（出典: 098）
- 「指示：A」で1回。そこから1ランク上がるごとに1回増える。ここでの「1ランク」はA→AA→AAAのような段階のことで、「+」「-」は数えない（直哉は指示A+で1回、『絆』でAA+になると2回）。『絆』で「指示」が上がっている場合は、その『絆』のポケモンが場にいる時だけ増えた分が使える。（出典: 098, 101）相手も同じで、イングリッド（指示AA）はカタクリ（『魂の絆』）が場にいる間は「タイム」が1回増える。（補足: ユーザーより）
- カズマはガッシュかルサルカ（『絆』）が場にいる間だけ使える。（出典: 098, 101）140からは、異名『愛馬』で自分に『魂の絆』が付くマックイーンが場にいる間も使える（213のT10で、マックイーンが場にいる時に使った）。（出典: 140, 213）
- 両方のトレーナーが同じターンに「タイム」を使うと、互いの読みが相殺されて、「指示」のランクの差はほとんど関係なくなる（お互い同じ条件になる）。117のカズマとイングリッドがこれで、カズマは「相手の動きが読み切れねぇ」と感じた。（出典: 117。「だいたいあってる」と補足: ユーザーより）
- 「タイム」は、**指示を選んでいる途中**に起きる（指示の最中に時を止めて相談するイメージ。なので「タイム」のあとでも指示や『指令』を出せる。補足: ユーザーより）。原典の言い方では、同時でない限り、トレーナーの「指示」が終わった直後に発動する。なので交代を指示しても、「タイム」の時点で場にいるのは交代前のポケモンで、「タイム」で発動する効果（デンリュウの『灯電獣の発電』『アドバイス』など）はそのポケモンに入る（ロトム）。（出典: 200）
- 特殊役割『ベテラン』は、1試合1回、「指示」に関係なくトレーナーに「タイム」を使わせられる（ベルナデッタは指示C）。（出典: 200）
- 『ベテラン』による「タイム」は表示される（天花）。『ベテラン』の『役割』は「タイム」の使用時に発動するので、お互いが動き出す瞬間に「タイム」と解析の有無が分かる。付随の『アドバイス』で、そのとき相手のデータを解析できる（245のクリーブランド。『スカウター』とは解析のタイミングが違う）。（出典: 245）

## ポケモン図鑑（解析）
- 「ポケモン図鑑」（1試合1回の解析）は、カズマだけでなく相手のトレーナーも誰もが使う（補足: ユーザーより）。図鑑は「タイム」と同じく、指示を選んでいる途中に使い、使ったら指示の途中に戻る（そのTの技・交代・『指令』は普通に出せる。補足: ユーザーより）。
- 図鑑で抜けるのは、使ったその瞬間の姿のデータだけ。メガシンカする個体に使っても、メガシンカの前ならメガシンカ前の分、メガシンカの後ならメガシンカ後の分しか分からない（補足: ユーザーより）。
- 212では、うてなが初手で図鑑を使い、シェオルドレッドの『囁魔女の情報』（相手のデータを解析した時に毒にする）が発動した。うてなの固有『魔法少女にあこがれて』（「タイム」で♀を解析）とは別枠。（出典: 212, 213）
- 『スカウター』の『役割』の発動は、相手のデータの解析に成功した時の1回だけ。解析を無効化されたら不発になる（何回も使えるわけではない）。『チェイサー』も「おいうち」を無視されれば不発（オシュトル）。（出典: 239）
- **バトルの外からの解析はできない**（400、スネーク）: ''バトルで相対する相手が得られる情報と、それ以外にゃ大きな隔たりがある''。客席からの解析は運営が妨害している。バトルビデオなどから推測するのにも時間がかかるので、それまでのデータにない選手（オシュトル）のデータを大会中に抜くのは無理。毎試合出てくる『エース』や『二枚看板』なら当日に情報を立て直せる見込みは大きいが、選手を入れ替えるチームが相手だとそれも難しい（クラウド）。（出典: 400）
- **解析の無効化**（401〜403）: 『ECS』（1/試/自動。ファルケ）のような解析無効のポテンシャルに当たると、図鑑は「1/試（済）」になり、その試合ではもう使えない（カズマ「よくも「図鑑」を無駄撃ちさせてくれやがったなぁ」、403）。常時の解析無効（スネークの『傭兵蛇の防諜』）を持つ選手は、事前の情報もほとんど取れなかった（天花、402）。逆に『諜報蛇』（トレーナーが「指示：A」以上の時、相手によって自身のデータ解析が無効化されない）のように、自分の解析を守るポテンシャルもある。（出典: 401, 402, 403）
- 相手が図鑑を使ったことは表示されない様子。401では、クラウドが先にガブリアスへ図鑑を使っていたので、スネークの「タイム」で『アドバイス』が発動せず、スネークは「『アドバイス』が発動しなかったことに気づかれりゃ、こいつに「図鑑」切ったのはバレるか」と思った。**図鑑を使った相手には『アドバイス』は使えない**（補足: ユーザーより）。解析が重なるので発動しない。そのため、『ベテラン』の「タイム」で『アドバイス』が出なかったら、相手はその選手に先に図鑑を使っていた、と読める（情報が漏れる）。（出典: 401）

## 相手の手持ちが見える範囲
- バトル中に相手の6体がすべて分かるのは、相手が6体目を出した時だけ。バトル開始時には、相手の選出は何も見えていない。（補足: ユーザーより）
- そのため、バトル開始時に効果を選ぶ能力（エールの第一『固有』『降り注ぐ裁きの魔力』のタイプ選び）は、事前の偵察や相手の傾向から予想して決め打ちすることになる。143ではエールが「闘」を選び、ヤマトとマックイーンに刺さった（カズマは「ヤマトとお前に刺さる「かくとう」タイプを『固有』で選んだのかもな」、ヤマトは「想定内」）。（出典: 143。「予想して決め打ち」は補足からの推測）

## 技の処理
- 技そのものの効果（このスレ独自の技、原作と効果が違う技、原典で説明の出た技と使われ方）は [moves.md](moves.md) に統合した（補足: ユーザーより）。ここには処理のルールだけを置く。
- 技の処理は、基本的に原作（第五世代まで）のポケモンと同じ。原典に独自の表示があるものだけ、そちらに従う（補足: ユーザーより）。例: 「ほろびのうた」は、原典の技の説明では「場にいる全員の「死のカウント」を「4」にする」（104のカフェのデータ）。

### 行動不能の判定
- 行動の順番が決まってから、技を出す直前に「麻痺」などの行動不能の判定がある。この判定は、追加行動や追加攻撃のときにも毎回入る（補足: ユーザーより）。これは基本的に実機と同じで、「せんせいのツメ」が発動して先に動けたのに麻痺で動けない、ということも起こる（補足: ユーザーより）。214では、レジーナが『後の先』で先に動き、専用『魔法少女の黒い衝動』の発動まで表示されたあと、麻痺で動けなかった。（出典: 214）
- 怯みも実機と同じく、そのT中の攻撃（追加行動もおおむね）が止まる（[turn-order.md](turn-order.md)。補足: ユーザーより）。

### 「とんぼ」技と「おいうち」技
- **「とんぼ」技と「おいうち」技がかち合ったとき**: 「速」や優先度をすべて無視して、「おいうち」側が先制する。『チェイサー』なら、その瞬間に『役割』が発動する。（出典: 085）
  - 345（ライザ、黒子）: 「とんぼ」で交代が発生する前に攻撃されるので、ライナーの『鎧巨人の守護』のような避難（味方と交代して出る時に「おいうち」効果を無効化）は効かない（あくまで''味方との交代時''に限られる）。''常に相手の「おいうち」の影響を受けない''『エキスパンション（悪）』などは別。味方を「おいうち」から逃がすポテンシャル持ちは少なそう（白野）。（出典: 345）

### 「まもる」系の技
- **「キングシールド」**（相手の「直接技」を無効化した時、相手の「攻」を下げる）は「まもる」系の技として扱う（作者）。下げる効果は「まけんき」の対象になる。（出典: 245, 247）同じ系統に「けがわでまもる」（ムック、247）、「スタンガード」、「つるぎでまもる」などがある（→ [moves.md](moves.md)）。
- 「まもる」を使ったあとに追加行動が発生しても、次の技は出せない（「まもる」してから追加行動で攻撃、はできない）。（出典: 164）
- 「**のろい**」（ゴーストの）は攻撃技ではないので「まもる」を貫通する。「まもる」自体は成功しても、相手の技を無効にしていないので『○○の吹戻』『○○薬』のような「まもる等で相手の技を無効化した時」のポテンシャルは発動しない。（出典: 175）
- **「ロックオン」と「まもる」**: 技「ロックオン」も「まもる」で防げる（技の対象は相手で、状態変化は自分にかかる。「こころのめ」も同じ）。なので相手の「まもる」に合わせてスカすことはできない。（出典: 245）
- 特性「すりぬけ」は、自分の「変化技」が相手の「まもる」などを貫通する（下の「特性」）。

### 必中と「ロックオン」
- 「**ロックオン**」状態の相手の技は「必中」になる（「じゃあくなほのお」「ヘドロばくだん」）。ベルゼブモンは技「ロックオン」でも自分を「ロックオン」状態にできる（230では「逃げられる気がまるでしなかった」（ガッシュ）。効果の詳しい表示はまだ）。「ロックオン」状態は交代で解除される。（出典: 230, 232, 245）
- 「きょけんとつげき」を使うと、そのあと相手の技が「必中」になり、威力が2倍になる（→ [moves.md](moves.md)。出典: 139）。
- 必中の「ドラゴンハウル」の前では、『ヌシの勅命』（回避）も意味をなさなかった（勅命を1回消費）。（出典: 231）
- 「宙に浮いている相手に命中する」効果は、下の「フィールド形成」を参照。

### 「単体技」と「全体技」
- 自分や相手1体に効果を及ぼす範囲の技が「単体技」、それ以外の複数の相手（や味方を巻き込む場合を含む）が「全体技」。技の範囲が「単」なら単体攻撃技、「複」（相手全体）や「全」（味方を含む全体）なら全体攻撃技。ダブルバトルではないので、味方を巻き込むかは関係ない（オシュトル、白野）。相手の「全体技」を無効化する特性に「おおきなたて」がある（下の「特性」）。（出典: 239）

### 追加攻撃と追加行動
- **追加攻撃と追加行動**: 追加攻撃は同じ技を続けて繰り出すこと。追加行動は技を選べる（異なる行動もできる。効果文に「「炎/飛」技による」などの条件があればその範囲で）。（補足: ユーザーより）
  - 食蜂の『固有』の「こうげきしれい」の追加行動は、味方の「通常行動」にしか反応しない（天花談）。通常攻撃が外れても、追加の「こうげきしれい」は別に当たる。（出典: 145, 146）
  - メガスピアーの『スピアナイト』の「一番最初に」の追加行動は、『指令』や交代の直後に、優先度を無視して誰よりも早く出る。「ねこだまし」や「まもる」より早い。この追加行動では「おいうち」は選べないと見られていて、『もどれ！』なら確実にかわせる（マックイーン談）。（出典: 145, 147）

### 全能力値の上昇（強化）
- 基本的に攻撃・防御・特攻・特防・素早さの5つ（体力は入らない。『二枚看板』の1.33倍や「さいごのとりで」の1.5倍も同じ）。「任意」や「ランダム」の能力上昇は、回避・命中・急所ランクを含むこともある。

### 「みらいよち」類
- **「みらいよち」類**: 原作と違って状態変化になっているので、交代で解除できる。次のターンでの実質的な連続攻撃のようなもの。（出典: 113）
  - 「みらいよち」状態…次のターンの最後に、相手に「みらいよち」によるダメージを与える。「まもる」を貫通する。ダメージは、「みらいよち」状態にしたときに場にいたポケモンの「特攻」で判定する。（出典: 113）
  - 使った側の持ち物、特性、ランク補正、ポテンシャルは影響しない。技として出した場合以外（『固有』や『専用』など）は、タイプ一致の補正も入らない。（出典: 113）
  - 「**はめつのねがい**」状態（404〜408）: 技「はめつのねがい」（特/鋼/単/140/100/×/「まもる」貫通。「みらいよち」の類型）で入る状態。メアリのバーヴァン・シーは専用『破滅を誘う呪詛の厄災』で場に出た時に相手をこの状態にし、相手が「はめつのねがい」状態の時に働く種属（『呪騎士の慟哭』（「霊」技の「溜め」なし）、『呪騎士の呪詛』（相手の「回復」を「ダメージ」に変換））と組み合わせる。「みらいよち」と同じく交代で外れる（407で天花のサポートの「テレポート」でライナーが下がり、バーヴァン・シー「この野郎、私の「はめつのねがい」を」）。出すタイミングによっては不発になる（406のギャリー「''トリ子''の「はめつのねがい」は、タイミング上不発になる」）。（出典: 404, 406, 407, 408）

### ドレイン技
- 自分の体力が満タンのときは回復が発動しない。

### 威力を条件にした軽減
- **威力を条件にした軽減は元の威力で判定する**（313、System の※注釈）: 『巨塊』（「威力：100」以上の技を0.75倍）は、「眠り」で威力2倍になった「ひゃっきやこう」には効かなかった（「基本的に軽減は元威力を参照のため、『巨塊』の軽減対象に入らず」）。（出典: 313）

### 技能拡張

### 第九世代の技・特性

## 設置技
- 場に出た時、すでに場に残っている設置技のダメージ・効果は、特性や『役割』より先に入る（設置技で倒れたら特性や『役割』は発動しない。→ [turn-order.md](turn-order.md)。補足: ユーザーより）。『ストーキング』より前にも発動する。
- 「**ばらぞの**」（変化・草・敵陣の設置技）: 場に出た相手の体力を1/8ドレインする。「炎」「草」タイプが場に出ると解除される。「まきびし」「どくびし」とは共存できるが、「ステルスロック」とは同じ系統の設置技で、後から「ばらぞの」を出すと「ステルスロック」は消える。（出典: 109）
- 「**ひばしら**」（場に出た相手に体力の1/8の「炎」ダメージ。出典: 139, 140）で交代先が受けるダメージは「炎」の相性で変わる（草のモモは1/4）。（出典: 200）
- **対地設置技**（「じらいげん」「きらい」など）: 「対地」は「まきびし」のように、宙に浮いたポケモンには刺さらないという意味（天花）。（出典: 176, 177）
- 特性「ふゆう」のポケモンには「特性『ふゆう』により、設置技のダメージを受けない」と表示される（176のサザンドラ）。（出典: 176, 177）
- **自陣の設置物の解除**: 「くさかり」（草。自陣の「ひばしら」も除去できる。出典: 200）、「やきはらう」（炎。176で自陣の「ステルスロック」を除去）、「あらいながす」（水）。技のデータは [moves.md](moves.md)。

## フィールド
- ポテンシャルの効果で、場に「**《異界/テンガン山》**」のようなフィールドが展開されることがある。（出典: 007）
- フィールド同士のかち合い（『固有』のフィールド同士はトレーナーの「能力」が強い方、スタジアムのフィールド効果は『固有』のフィールドに上書きされる）は [turn-order.md](turn-order.md)（補足: ユーザーより）。

### スタジアムのフィールド効果
- **スタジアムのフィールド効果は、T終了時の最後の最後に発動する**（ライナー。『輪廻』のようなものを除く）。（出典: 314）T終了時の中は、毒・火傷・「アクアリング」などのダメージや回復 → スタジアムのフィールド効果 → 『輪廻』『旋回』などの交代、の順と見られる（ユーザーの見立て。補足: ユーザーより）。→ [turn-order.md](turn-order.md)
- バトルルーレットのランダムな能力変化をうまく利用するには、多少の能力低下を受けても押し切れる“ポケモンの自力の差”が要る（カズマ）。（出典: 178）

### フィールド形成（出典: 189, 190, 191）
- トレーナーの『固有』で、スタジアムのフィールド効果を別のフィールドに上書きすることを“**フィールド形成**”と呼ぶ。条件は「能力：A」以上か、「統率：AA」＆「能力：B」相当の出力（玉藻）。「C」ではほぼ見られず、「B」から万丈目のような例が出てくる。（出典: 189, 190）
- **後出しが有利**（285、レナ）: フィールド形成は、同時発動を除いて原則''後出しが有利''。ダンジョンのフィールド（''異界''でも）は、後から来たトレーナーが上書きできる。ただし''異界のヌシ''は場に出るだけで上書きし直してくる（引っ込めば元に戻る）ので、ヌシに対しては相手優位が揺るがない。例外は同じフィールド形成のトレーナー同士くらい。（出典: 285）
- **《緋想天/ワンダフルヘブン》**（292、天子の固有『荒々しくも母なる大地よ』）: 「統率」によるフィールド形成。場にいる全てのポケモンが宙に浮かび上がり、「地」「岩」「鋼」タイプは設置技の影響を受けない。「統率」のフィールド形成は『PT』のコンボのトリガーになる（天花）。天子のチームは『カナメファンネル』（宙に浮く相手に「地」技が命中）で一方的に「地」技を当てる。
- **「宙に浮いている相手に命中する」効果**（292、天花・白石）: 「ふゆう」や「ふうせん」、フィールドで浮いている相手なら、単にそれを無視してタイプ相性を参照する。「飛」タイプ相手には、タイプ耐性貫通扱いで等倍で命中する。（出典: 292）「**サウザンアロー**」（「地」の物理技。宙に浮いている相手にも命中して「うちおとす」状態にする）も、このスレの仕様上「飛」タイプに対して耐性貫通扱いで、イカルガやリザードンの「飛」の耐性を貫通して等倍になる（404の※注釈、天花）。（出典: 404）
- **《夢幻漆黒空間/シャルノス》**（メアリの第二『固有』『夢幻に誘う漆黒のシャルノス』。又の名を''なぞのばしょ''）: フィールド効果は「場にいるすべてのポケモンが強制交代を受けない。先発、死に出し、通常交代以外でポケモンが場に出た時、「死のカウント」を「4」にする。」（404で公開。122では「？？？」だった）。''強制的な脱出は許されず、正規外の侵入者には恐怖のカウント''（ギャリー）。メアリ側にも適用される。「とんぼ」技・ポテンシャルでの交代・「テレポート」などで出たポケモン（「非正規の手段で''なぞのばしょ''に侵入した」）がカウントを受ける（406のゲンガー、407のバーヴァン・シー、ベルゼブモン）。カウントを加速させるポテンシャルはギャリーも知らない（404）。405の試合開始時（先発が出たあと）に発動し、《ヨスガスタジアム》を塗り替えた（System「『フィールド形成』の力により、全体の場が《夢幻漆黒空間/シャルノス》へと塗り替えられた！」）。第三『固有』「しっこくのやみ」はこのフィールドの時だけ使える（上の「タイプ」）。（出典: 122, 404, 405, 406, 407）
- 《電撃領域／サンダーコロッセオ》（万丈目の『雷鳴轟く決闘領域』）: 3の倍数のT、場にいる全員が一番最後に「かみなり」の追加行動を得る。「かみなり」は素早さの順に出す。そのTに「まもる」や『全開回復指令』などで別の行動をしていたり、「あばれる」「こだわり」などでほかの技が出せなかったりすると不発。（出典: 190）
- フィールドの「かみなり」も「次に繰り出す技」に数えられる。ルサルカの『水魔女の呪縛』（相手が次に出す技の優先度-1）は、T12のフィールドの「かみなり」で消費された（万丈目「単発式の妨害札なら無駄撃ちさせれば良い。カードゲームの常識」）。（出典: 191）
- 相手の「かみなり」は地面タイプには無効で、地面タイプ側も自分の「かみなり」を撃てる（T3でガブリアスがマニューラを倒した）。（出典: 191）

### 「あばれる」状態
- 「あばれる」「げきりん」「だいふんげき」「はなびらのまい」などで入る。「あばれる」状態は2Tの間攻撃し続け、その間トレーナーの指示を受け付けず、『たえろ！』なども使えない（天花。「げきりん」を使う時の注意）。そのあと「混乱」状態になる（技のデータは [moves.md](moves.md)）。（出典: 140, 164, 191）
- 「あばれる」状態のポケモンは指示を受け付けないので、『指令』も効かない。
  - 「げきりん」を出す＋六令 → 「あばれる」状態になる前の『指令』なので可能。
  - 「げきりん」を出す＋四式 → 「あばれる」状態中の『指令』になるので不可能。
  - 「げきりん」の途中＋六令 → 『指令』を含む指示を出せないので不可能。
- このスレでは、「あばれる」状態は2Tを完遂しないと「混乱」にならない（マリルリのメタ発言）。317では、2T目の「げきりん」が「フェアリー」のマリルリに無効になって「あばれる」状態が解け、混乱しなかった。（出典: 317）

### T制限付きの状態異常
- **T制限付きの状態異常は「混乱」を除いて、交代するとT制限が消えて自然には治らなくなる**（天花）。ターン数に制限のある状態異常（「@1T」など）は、交代するとカウントがなくなり、そのまま続いてしまう。（出典: 045, 263）

### そのほかの状態
- 「**呪い**」状態: T終了時に体力の1/4のダメージ（169のヤマト）。（出典: 169）
- 「**テレキネシス**」状態（164のモモの『桃王女の計画』で出る）: こちらの技が必中になり、相手が宙に浮く。「じめん」技は相手に当たらなくなる。（出典: 164）
- 「**死のカウント**」: 「ほろびのうた」（場にいる全員の「死のカウント」を「4」にする）や、ポテンシャル（『災厄嬢の破滅』『超災獣の終末』（224, 308）、メアリのアリスの『死悪魔の宣告』『ねぇ、死んでくれる？』、フィールド《夢幻漆黒空間/シャルノス》（404〜408））で付く。Tごとの状態表示に「「死のカウント」@4」のように出て、T経過で1ずつ減る（319「ライナーの「死のカウント」が進行した！@3T」、406〜408）。0になると倒れると見られる（「ほろびのうた」と同じ。推測）。「死のカウント」が発生している相手に働くポテンシャルも多い（『告災』『超災獣の相剋』、アリスの『死悪魔の友達』『死悪魔の狂喜』『マハムドオン』など）。場に出てしばらくしてからカウントが付く時は、経過したぶん減った値で付く（406「場に出たから1ターンが経過したゲンガーの「死のカウント」が「3」になった！」。407ではベルゼブモンのカウントが「「4」に、あっ「3」に、いや「2」になった！」で、カズマ「カウント減少はないって聞いた」、メアリ「トリ子と同じターンに出てくりゃ、そりゃこうもなる」）。「「4」Tもあれば十分」（ライザ、404）なので、カウント自体より、それを条件にした相手の『エース』の強化が怖い（カズマ、404）。（出典: 104, 224, 308, 319, 404, 406, 407, 408）
- 「**くろいまなざし**」状態（404〜408のメアリ）: 通常交代ができなくなる。メアリの第一『固有』『魔に魅入られし黄金の乙女』は、味方を繰り出すたびに相手を3Tの間この状態にする。''どちらかのポケモンが場を離れれば消える''が（カズマ、405）、''選手が交代する度に張り直される''（カズマ、404）。扱いとしてはベルゼブモンの「ロックオン」に近い（カズマ、404）。天花のサポート効果（味方が必ず交代できる）で完全に無視でき（天花、404）、対策には『エキスパンション（霊）』や「きれいなぬけがら」の優先度が上がる（天花、405）。「とんぼ」やポテンシャルでの交代はできるが、《シャルノス》の下ではその交代先に「死のカウント」が付く（カズマ、404）。（出典: 404, 405）
- 「**しめつける**」状態: 405のコカライアの『縛蜥蜴の呪縛』（2Tの間）は、実質的に相手に1/8の時間差ダメージで、2T目は先に解除される（カズマ）。（出典: 405）
- 「**しめつける**」状態や「くろいまなざし」状態の基本の仕様は [pokemon.md](pokemon.md) の「状態」。「みらいよち」状態は上の「技の処理」。

### 宙に浮かび上がる
- 特性やポテンシャルでつく効果。状態変化の扱いに近い。発動するときはメッセージに表示される。
- この効果による「地面」技の無効化は防護に当たらない。防護特性や防護ポテンシャルを無視する効果でも貫通されない。
- 特性「ふゆう」は実機と違い、場に出ると表示される。特性「かたやぶり」などでも無視されない。
- そのほかの仕様は、ポケモンwikiの「地面にいる」を参照。

## ポテンシャルの個別の仕様
ポテンシャルの効果の原文は [potential-list.md](potential-list.md)。ここでは、バトルの処理として説明が出たものだけを置く。

### 『ストーキング』
- 専用ポテンシャルの型の一つ。原典では112で初めて出た（「○○○専用ポテンシャル。『エース』が場に出た時、味方と任意交代して場に出ることが出来る」）。『キラー』『チェイサー』が覚えることが多い。（出典: 112）
- 以下は、原典に出る前にユーザーから聞いていた仕様（補足: ユーザーより）。
- 『ストーキング』による交代は、お互いの『役割』の発動より先に発動する。
- 設置技の効果は、『ストーキング』より前に発動する。
- 「ものまねハーブ」は『ストーキング』のときでも発動する（二節〜三節の幕間以降）。

### 『戦闘続行』
- 『戦闘続行』は、ダメージを持ち越して相手に''死なば諸共で特攻する''もの（397、天花）。発動した時点で落ちると考えてよく、技のダメージ直後にツケを払わされる（「ドレイン」や『勝鬨』で生き残るような虫の良い話はない）。完全に守りに入った時（「ミルクのみ」を飲もうとした時など）に発動したのは見たことがない。攻めの姿勢なら、「ばらぞの」や「やどりぎ」のような変化技を繰り出す可能性はある（カズマ）。（出典: 397）

### 『オールドタイプ』が効かない場合
- 『金冠サイズ』のポケモンには『オールドタイプ』が効果を発揮しない（カズマ「『金冠サイズ』ってことは、あのデカぶつに対して『オールドタイプ』は効果を発揮しねぇってことだし」。スサノ-Oの『巨塊』『超重荒神の剛性』について）。理由は説明されていない（『固有種』だからか。推測）。（出典: 311）
- メガシンカ同士が向かい合うと、『メガシンカ』の「相手の『オールドタイプ』を無効化する」でお互いに打ち消し合う（[turn-order.md](turn-order.md)。補足: ユーザーより）。トレーナーの防護ポテンシャルは『オールドタイプ』では貫通できない（上の「防護」）。

### 『メガシンカ』
- 「メガシンカ」の仕組みは [species.md](species.md) の「メガシンカ」を正とする。例: さみだれ（「能力」型）のハガネールが「進化を超えろ、"メガシンカ"！！」でメガハガネールになり、『超鉄蛇の覚醒』でT終了時まで全能力値1.5倍になった。（出典: 159）

## 持ち物
- 持ち物の効果は、基本的に実機と同じ。ただし、スレでの仕様変更やポテンシャルとの兼ね合いで勝手が違うこともある。
- 「わざマシン」も「もちもの」に分類される（[pokemon.md](pokemon.md) の「わざマシン」）。

### もちものセット
- カズマの最初の持ち物は、アカネとゼットンの餞別の「**もちものセット**」（第八世代基準のバトルに使える持ち物が一通り入ったセット。「ジュエル」も第八世代基準なので「ノーマル」以外は過去のもの）。協会が「これだけは持っておきましょう」と勧めているもので、割と高価だが、ひとつあれば最低限の公平性が担保される（ルサルカ）。プロリーグが広まった影響もある。「ポケモン図鑑」もバトル中に使えるアイテム（1/試、指示を出す前に相手の場のポケモンのデータを解析できる）。（出典: 012）
- 121の通達: 新しい持ち物のリストと、一部の技の分類の変更（「けん」「つるぎ」技の範囲は上の「技の処理」）。同じ話でカズマは「**もちものセットVer.2**」（第九世代基準のバトルに使える持ち物が一通り入ったセット）を手に入れた。新しい持ち物も、ほかの持ち物と同じく実機どおりの性能。（出典: 121）
- **一部の''古代種''だけに効く持ち物**（399、オシュトル）: 「ふといホネ」（ガラガラ）、「でんきだま」、「ながネギ」など。ガラガラは「ふといホネ」の時に働く種属『骨殻獣の〜』を持つ。（出典: 399）

### 個別の持ち物の仕様
- **こだわりハチマキ**: 自分の「防」の値でダメージを計算する技には効果がない。
- **こだわりスカーフ**: 技が固定されても、交代すれば解除されて別の技を選び直せる。ロトムは交代を重ねて「ボルトチェンジ」「ポルターガイスト」「エアスラッシュ」を使い分けた。スカーフは技を続けて変えないことや速さから見抜かれやすい（ベルナデッタ）。天花は「トリック」で相手にこだわりを押しつける使い方も挙げた。（出典: 200, 201）
- **こだわりと技能拡張**: 「技能拡張」を使っても「こだわり」には縛られない。ただし、一度でも覚えている技を使えば、「技能拡張」も使えなくなる。
- **とつげきチョッキ**: 急所で貫通される。
- **ひかりのねんど、あついいわ、しめったいわなど**: ポテンシャルには効果がない（技と特性だけ）。
- **クリアチャーム**: 相手からの能力の減少を無効にする。低下は無効にしない。実機と同じで、実機よりパワーアップしている特性「クリアボディ」「まけんき」とは対応範囲が違う。相手の特性「ぼうえいせん」による能力低下も防いだ。（出典: 140）
- **だっしゅつパック**: 自分の能力が下がると自動で交代する（BBの「リーフストーム」の特攻ダウンで発動）。「かげふみ」や『チェイサー』のような通常交代を狙う対策をかわせる。（出典: 140）
- **とくせいガード**: 124〜125の練習試合で初めて実戦に出た。サンズの「とくせいガード」は、カズマの『固有』による特性の変更を無効にした。特性が要のポケモンにとっては特性を変えられるのは死活問題なので有効だが、そうでなければ1ターンの「きょううん」と引き換えに持ち物の枠を使わせたことにもなる（天花談）。（出典: 124, 125）『三角効果』からも特性を守れる（144のガッシュ。上の「三角効果」）。（出典: 144）
- **ものまねハーブ**（相手のランク上昇をまねる）: 登場時に能力が上がる『トップバッター』や『エース』と対面すると要注意。1回きりで、使われたことは最初にわかる。対策は強制交代（レッドカード、ふきとばし、ほえる）、きあいのタスキ、ポテンシャルなど。『エース』に使うには同時に場に出る必要がある（『凱旋』『輪廻』『旋回』の死に出しなら大丈夫、ルサルカの『ストーキング』だと一度相手をどかす必要がある）。（出典: 121）
  - 124〜125で、ガブリアスの「ものまねハーブ」はミカルゲの『トップバッター』の特攻+2をそのままコピーした（『トップバッター』は上げる能力を選べるので、事前情報や組み合わせがよくないと狙いにくい）。（出典: 124, 125）199では、ヤマトがジークヴルムの『トップバッター』の防+2をコピーした。（出典: 199）
  - 二節〜三節の幕間以降は、『ストーキング』のときでも発動する（下の『ストーキング』。補足: ユーザーより）。
- **持ち物を壊す・変える効果**: 持ち物が効果を出す前に壊したり変えたりする。攻撃技なら「きあいのタスキ」や「ボコのみ」なども貫通して攻撃できる。「**はたきおとす**」は持ち物を壊してからダメージを与えるので、「きあいのタスキ」は発動する前に壊れる（137のエイラ）。（出典: 137）
- **プレート**: 「なげつける」でプレートを投げると威力90。「ノーマル」のプレートは、沖野の知る限り存在しない（はるか昔には「ノーマル」や「あらゆるタイプに変化するプレート」もあったと聞く）。（出典: 161）
  - 「**まっさらプレート**」（167）: 「ノーマル」タイプに反応する新しいプレート。163でエールの枕元に突然現れ、ナナカマド研究所が調べて協会に登録・使用許可を取った（オルガマリー「「シルクのスカーフ」と大して変わんない」。正式な数値は未表示）。今までは「ノーマル」以外の17種しか確認されておらず、カズマはそれを全部もちものセットで持っている。「なげつける」なら威力90くらいの重さ。わざマシン化できるかは別問題。ミラクルズがテスター兼サンプルとして持ち、次戦から使える。（出典: 163, 167）
- 特性「きんちょうかん」を持つ相手の前では、きのみやわざマシンなど消費する持ち物が使えない。（出典: 024）

## 特性
### 特性の決まり
- **タイプによる特性の無効は第五世代仕様**。「ゴースト」タイプも「かげふみ」で交代を縛れる。（出典: 071）
- **能力を下げられた時の特性（「まけんき」「クリアボディ」など）は実機よりパワーアップしている**:
  - 「**まけんき**」: 相手に能力を減少・低下させられた時、自分の「攻」がぐーんと上がる（出典: 153）。実機と違い、「わざわいのたま」などによる能力の低下（倍率の低下）も対象。1回の減少（低下）につき1回発動する（複数の能力が下がっても1回）。『役割』『エンペラー』（原典未登場）による任意の能力の減少と、全能力値の低下は別にカウントされ、2回発動する。「キングシールド」の「攻」を下げる効果も対象（上の「まもる」系の技）。
  - 「**クリアボディ**」: 相手からの能力減少（低下）を無効にする（実機よりパワーアップ）。ただしフィールド効果は防げない。（出典: 056, 057）持ち物の「クリアチャーム」とは対応範囲が違う（上の「持ち物」）。
  - 「火傷」「麻痺」などの**状態異常による能力の低下は**、「まけんき」や「クリアボディ」の対象外（エレン）。（出典: 245）
- **「いかく」と「まけんき」**（193）: カズマの固有で、相手の「いかく」と味方の「まけんき」を両方1Tだけ「きょううん」にすると、特性が戻った時に「いかく」が再発動し、それに「まけんき」が反応する（差し引き攻+1）。普通なら相手の「いかく」の再発動を許すだけだが、「まけんき」持ちなら強化のきっかけに変えられる（天花「もはや裏技の領域だよ、こんなの………」）。（出典: 193）401では、相手のスネークの特性「いかくしゃげき」を1Tだけ「きょううん」にしたので、戻った時に「いかくしゃげき」が再発動し、マックイーンの「まけんき」が反応した。（出典: 401）
- 特性のコピー（「かがくのちから」など）や、特性と『役割』の順番は [turn-order.md](turn-order.md)。特性を『三角効果』から守る「とくせいガード」は上の「持ち物」。
- 第九世代の特性（「おうごんのからだ」「ふくつのたて」など）の特集本の話は、上の「技の処理」の「第九世代の技・特性」。

## 協会のレギュレーション
- 「みちづれ」を持つポケモンは、1チームに1体まで。（出典: 122）
- 『輪廻』や『旋回』を持つポケモンは、レギュレーションで自前の「まもる」を持てない。ただし、ほかのポケモンの能力で似たようなことをするのは可能（天花。カズィクルベイのクロナの「ニードルガード」は、『旋回』持ちのクロバットの次善の生け贄役）。（出典: 394）
- 完全な受け構築（受け続けて勝つチーム）は、技なども含めてレギュレーションで禁止されていると思われる（補足: ユーザーより。ユーザーの見立て）。実際、原典のバトルは守りを貫く手段（『三角効果』、防護無視、急所、『全開指令』など）が多く、受けより手札の切り合いになる。
- 原典で明言はされていないが、種属ポテンシャル（「〇〇の〇〇」）は、効果を被らせてはいけないというレギュレーションがあるらしい。対象は手持ち全体ではなく、おそらく試合の選出時（その試合に出す6体の中）。（補足: ユーザーより。「おそらく選出時」もユーザーの見立て）
  - カズマの手持ちの「任意交代」系の種属が、『芦馬娘の凱旋』（倒した時）、『桃王女の領域』（ドレインした時）、『幻晶騎士の旋回』（場に出て2T目）と、きっかけだけ全部ずらしてあるのはこのため（補足: ユーザーより）。
- **確定急所の攻撃技**（400、カズマの見立て）: クリティカル倍率3倍の『超究武神覇斬』を持つ《神羅ソルジャーズ》は、''確定で急所に当たる攻撃技''についてレギュレーションをかけられているらしい（カズマ「そらこんなん確定急所技とかレギュ食らうわ……」、401）。''ポテンシャルとか変化技でのクリティカル''が対象かは分からない（カズマ）。実際には、ポテンシャル（スネークの『傭兵蛇の射撃』。「タイム」の時に「だん」「ボール」技が確定急所）による確定急所は401・402で使われた。（出典: 400, 401, 402）
- 協会が勧める「もちものセット」は上の「持ち物」。

- 大会の勝敗が同点のときは、地元チーム（【H】）が上位。それ以外の場合は、直接対決の勝者が上位。（出典: 061）

## 本文の表記
- 作者が処理を間違えて、数ターンあとに訂正して特殊裁定になることが稀にある（259のベルゼブモンの『気合い』が最初。今後も稀に起きる。補足: ユーザーより）。原典の表示と訂正が食い違うときは、訂正後を正として書く。
- 試合の最序盤、両チームのサポート効果の表示の間に、相手チームの6体のうちの1体（その試合のメンバー）の台詞がカットインで入る（全ての試合でこの位置。241のコダール、245のムック）（補足: ユーザーより）。
- 原典のバトルの表示では、火傷の半減などの補正の表記が、ちょくちょく省かれることがある（補足: ユーザーより）。表示がなくても、条件がそろっていれば補正はかかっているものとして読む。
- やることが分かりきっているTは、処理が重くなりすぎないよう、作者が安価を取らずに安定行動で進めることがある。1試合に1〜2回はあり、そのTは状態表示と指示安価が出ないまま次のTへ進む（例: 209のT9。死に出しのマックイーンがそのまま「しんそく」）（補足: ユーザーより）。表示の抜けや数え間違いとして扱わない。

## 読者の安価の決まり方（補足: ユーザーより）
- カズマ側の行動は読者の安価で決まる。読者は指示安価の数ターン前から議論を重ねていて、指示安価は結論を出すだけの場になっている。戦闘準備の前には、相手の固有のタイプの予想や、持ち物・指令を入れたダメージ計算までしている（例: コトブキ杯のユニバース戦の前、2時間以上の議論でヤマトのマジュのみを決めた）。原典には議論が残らず、決まった安価と結果だけが残るので、原典の結果から読み筋を推し量ると取り違えやすい。
- 選ばれやすいのは、全体的に丸い選択肢。リスクが大きくリターンもある手は採用されにくく、安全策でも失敗が起こりうる手（命中不安など）は嫌われやすい。
- 一方で、何が起きてもとりあえず場を荒らせればいい手は、結果がランダムでもリスクとは見なされず、わりと採用される（例: ガブリアスのレッドカード。ナギサ杯のサンダーズ戦など）。どう転んでも損をしない運任せは、外れたら困る運任せとは別に扱われている。
- 「おまじない」（急所を防ぐ）は、一手損してでも、そのあとの読みを安定させる効果が大きい。毎ターン「急所かもしれない」と考えずに済むので、議論がぶれにくくなる（補足: ユーザーより）。213の《縁マジアベーゼ》戦（急所に寄せた指示型の相手）で、モモが『全開防御指令』と合わせて先に貼った。
- カズマの「指示：B-」は、この協議制の安価で勘違いやミスが出たり、意見が割れたりすることを、カズマのミスとして落とし込んだもの（→ [trainer-stats.md](trainer-stats.md)）。
