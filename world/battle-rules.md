# バトルの細かい仕様

ユーザーから教わった、スレのバトルの仕様をまとめたもの。この節の内容はすべて（補足: ユーザーより）。原典でまだ出ていない用語（原典未登場）も含む。

## ステータスのランク
図鑑の文字ランクは、種族値のおおよその範囲を表す。同じランクの中では「-」が下寄り、「+」が上寄り。

| ランク | 種族値 |
| --- | --- |
| S | 200〜 |
| AAA | 170〜195（-〜+） |
| AA | 140〜165（-〜+） |
| A | 110〜135（-〜+） |
| B | 90〜105（-〜+） |
| C | 60〜85（-〜+） |
| D | 40〜55（-〜+） |
| E | 1〜35（-〜+） |

- 能力ランク（「攻+1」など）は、1段階上がると1.5倍。（出典: 011）
- **種族値の補正の大きさ**（補足: ユーザーより）:
  - 『ポケパワー』のような「種族値に+補正を得る」効果は、「+」「-」の刻みで1つ上がる（B→B+、B+→A-）。
  - 「種族値を1ランク上げる」効果は、文字のランクが1つ上がる（B→A）。例: サムスの『賞金稼ぎのパワードスーツ』（C→B、A→AA）、ガッシュの『金雷児の王気』（特攻の種族値を1ランク上げる）。『金冠サイズ』の体力補正は「約2ランク」（モモ談）。

## レベル差
- レベルが10違うと、全能力におよそ1割の差があると考えてよい（目安）。
  - 例: Lv60とLv50なら、Lv60側の全能力がおよそ1.1倍。
- ただし、Cランクあたりではチーム間のレベル差はせいぜい10程度なので、実際にはそこまで気にしなくてもよい。育成型の強みも含め、Cランクではどの資質もまだ真価を発揮していない。

## 急所（クリティカル）
- 急所率は**第五世代までの仕様**。急所のダメージは**2倍**。
- このスレの急所は、ランクだけでなく「**倍率強化**」も無視する。
- 急所ランクごとの確率:

| 急所ランク | 確率 |
| --- | --- |
| C+0 | 1/16（6.25％） |
| C+1 | 1/8（12.5％） |
| C+2 | 1/4（25％） |
| C+3 | 1/3（33.3％） |
| C+4 | 1/2（50％）。ランクはここまでしか上がらず、確率も50％が上限（補足: ユーザーより） |

- 相手との「指示」ランク差1つにつき、高い方に常に急所ランク+1がつく。

## タイプ
- タイプの特徴は第五世代準拠。「でんき」も麻痺し、「ゴースト」にも「くろいまなざし」が効く。
- **複合タイプの技**（原作の「フライングプレス」のようなもの）: 持っているタイプのうち、最もダメージが多くなる相性で判定する。どちらか片方が条件を満たせば、タイプ一致の倍率も持ち物の効果も乗る。特性などで無効にされる場合は、片方が条件を満たせば無効になる。
- **相手のタイプ耐性を貫通する効果**: 最終的な相性が等倍になる。例: この効果のついた「電」技を、じめん・ドラゴン・じめん／ひこう・ドラゴン／ひこうに打つと、どれも等倍。

## 「ここぞ！」という場面
1. 「3vs3」のときは、味方が残り1体になると自陣が「ここぞ！」。（6vs6では残り3体。出典: 045, 046）
2. お互いの『エース』が場で対面すると、互いの場が「ここぞ！」。

## 『役割』の発動タイミング
- 「場に出たとき」系は、場に出たときに発動する。
- 『エースアシスト』『エンチャンター』は、**後続が場に出た瞬間**に発動する。通常交代や「しっぽをまく」なら、そのターン、交代した瞬間にカズマの『固有』も発動する。
- ただし、ターン終了時に交代する能力（『輪廻』『旋回』など）の場合、後続が場に出るのは次のターンの開始時。
- 『チェイサー』は、「おいうち」効果が発動したときに発動する。
- **特性の発動は『役割』より早い**。102では、タナトスの特性「プレッシャー」でガブリアスの「速」が下がってから『トップバッター』が発動したので、カズマの『固有』で相手を「きょううん」にしても防げなかった。（出典: 102）

## 防護
「防護」とは、このスレでは相手の攻撃技のダメージを緩和したり無効にしたりするもの。次の3つが含まれる。
1. ダメージの緩和や無効化
2. 「攻」「特攻」の上昇（強化）の無視
3. 「必ず耐える」系

- 『固有』ポテンシャルによるダメージの緩和や、四式の『たえろ！』は**トレーナーの**防護ポテンシャル。なので『オールドタイプ』や『エキスパンション（闘）』（出典: 062）では貫通できない。
- 「宙に浮かび上がる」ことで得る「地面」技の無効化は防護に当たらない（下の「宙に浮かび上がる」を参照）。
- 急所に当たると相手の能力の上昇（強化）は無視されるが、**防護は急所（クリティカル）では抜けない**（出典: 068）。
- ポケモン自身が持つ防護ポテンシャル（ハンニバルの『アラガミ』の「亜人」の技の低確率半減や、サンズの防御型の『専用』『陽気な髑髏は悪夢と踊る』など）は、『オールドタイプ』や『エキスパンション（闘）』（「闘」技の時）で貫通される。125では、ヤマトの「からたけわり」に『アラガミ』の半減が一度表示されたが、『エキスパンション（闘）』で無視できるとして直後に訂正された。（出典: 125）

### 三角効果
- 専用ポテンシャルの型の一つ（「攻」か「特攻」がAA以上で使える。出典: 066）。相手ポケモンの「まもる」などの技、特性、相手ポケモンと相手トレーナーの防護ポテンシャルを無効にする。
- トレーナーの防護ポテンシャルには、四式の『たえろ！』が当たる。
- 能力の上昇・強化を貫通する効果はない。
- 〇〇指令による「防」「特防」の強化は、トレーナーの防護ポテンシャルに当たらないので、三角効果では貫通されない。
- 持ち物の「**とくせいガード**」を持っていれば、三角効果からも特性を守れる（144でガッシュの「きあい」が残り、ラハールの急所の一撃を体力1で耐えた。「「もちもの」の力までは、貫けまい！！」）。（出典: 144）

## 『指令』
- 「あばれる」状態のポケモンは指示を受け付けないので、『指令』も効かない。
  - 「げきりん」を出す＋六令 → 「あばれる」状態になる前の『指令』なので可能。
  - 「げきりん」を出す＋四式 → 「あばれる」状態中の『指令』になるので不可能。
  - 「げきりん」の途中＋六令 → 『指令』を含む指示を出せないので不可能。
- 「『指令』を受けたとき〜」系のポテンシャル（『サーヴァント』など）が発動するのは六令（『〜指令』）だけ。四式では発動しない。『サーヴァント』は093でBBが持っていて、原典でも同じ注記があった。（出典: 093）
- 逆に「自分の『四式』が発動したとき〜」系（ブリジットの『トリックプレイ』、錦木千束の『不殺主義の彼岸花』など）は、六令では発動しない。また『かわせ！』『よけろ！』が実際に発動しなければ無効（必中技に当たった場合も無効）。『もどれ！』は、相手の「おいうち」などで攻撃が成立した場合に『四式』の処理との兼ね合いが出る。（出典: 131）
- 『四式』が発動しても、対応する手段で突破された時（『かわせ！』『よけろ！』には必中、『もどれ！』には「おいうち」、『たえろ！』には防護貫通）は、『四式』をきっかけにするポテンシャル（千束の『固有』など）は発動しない。トレーナーの『たえろ！』を正面から抜けるのは『三角効果』くらい。（出典: 135）
- 「**通常交代**」は、指示の時に出す交代コマンド（『もどれ！』も含む）のこと。「とんぼ」技、ポテンシャルによる交代、「レッドカード」などの強制交代は含まない。（出典: 135）
- 『旋回』のように倒したあと交代する場合でも、お互いが同時に次のポケモンを出す状況（相手を倒した時）では、ルサルカの『エイヴィヒカイト』のように「先に場で待ち構える」必要のあるものは発動しない（『凱旋』と同じ）。（出典: 137）
- 「**だっしゅつパック**」: 自分の能力が下がると自動で交代する（BBの「リーフストーム」の特攻ダウンで発動）。「かげふみ」や『チェイサー』のような通常交代を狙う対策をかわせる。（出典: 140）
- 「**クリアチャーム**」は、相手の特性「ぼうえいせん」による能力低下も防いだ。（出典: 140）
- 設置技「**ひばしら**」（変化・炎・敵陣）: 場に出た相手に体力の1/8の「炎」ダメージを与える。（出典: 139, 140）
- 「**きょけんとつげき**」を使うと、そのあと相手の技が「必中」になり、威力が2倍になる（クロコダインが使ったあと、ヤマトの「アイスブレード」が必中・2倍で入った）。（出典: 139）
- 「**あばれる**」（物理・ノーマル・威力150）: 2Tの間あばれる状態になり、そのあと混乱する。（出典: 140）
- 特性「おそれしらず」（体力1/2以下で攻2倍）、「けいやく」（場に出た時、相手の特性を「けいやく」に変える）、「クイックドロウ」（同じ優先度の技で3割先に動く）、「てったいせん」（交代する時、相手の速をがくっと下げる）。（出典: 136, 137, 140, 141）
- 「グラスフィールド」の回復は実機どおりで、宙に浮いているポケモン（ひこうタイプの瑞鶴など）には入らない（補足: ユーザーより）。（出典: 140）
- ルサルカの『エイヴィヒカイト』は、「死に出し」で出てきた相手の体力をドレインする（139でザクに発動）。（出典: 139）
- 「**はたきおとす**」は持ち物を壊してからダメージを与えるので、「きあいのタスキ」は発動する前に壊れる（137のエイラ）。

## 妙手（タイム）
- 「指示：A」以上のトレーナーが使える。
- バトル中に1回だけ、場にいる選手と相談できる。
- そのときトレーナーがわかっている情報で出せる最善手を出す。図鑑も使っていない先発の1ターン目に使っても、データがなければ何もわからない。
- 使いどころは「前半から中盤にかけて鋭い一手を差し込む」か「後半戦でデータが集まったところで、詰みや逆転の手を打つ」のどちらか。
- 「指示：A」で1回。そこから1ランク上がるごとに1回増える。ここでの「1ランク」はA→AA→AAAのような段階のことで、「+」「-」は数えない（直哉は指示A+で1回、『絆』でAA+になると2回）。『絆』で「指示」が上がっている場合は、その『絆』のポケモンが場にいる時だけ増えた分が使える。（出典: 098, 101）
- カズマはガッシュかルサルカ（『絆』）が場にいる間だけ使える。（出典: 098, 101）

## 本文の表記
- 原典のバトルの表示では、火傷の半減などの補正の表記が、ちょくちょく省かれることがある（補足: ユーザーより）。表示がなくても、条件がそろっていれば補正はかかっているものとして読む。

## 協会のレギュレーション
- 「みちづれ」を持つポケモンは、1チームに1体まで。（出典: 122）
- 121の通達: 新しい持ち物のリストと、一部の技の分類の変更。
  - 「**けん**」「**つるぎ**」等の技に、「つばめがえし」「エアスラッシュ」「シザークロス」なども含まれるようになった。それらの威力を1.5倍にする特性「**きれあじ**」も出た。スレ独自の裁定で、「つじぎり」「ストーンエッジ」「みずしゅりけん」なども引き続き「けん」「つるぎ」技の仲間。（出典: 121）
  - 124〜125の練習試合で、新しい持ち物が初めて実戦に出た。「ものまねハーブ」（ガブリアス）はミカルゲの『トップバッター』の特攻+2をそのままコピーした（『トップバッター』は上げる能力を選べるので、事前情報や組み合わせがよくないと狙いにくい）。「**とくせいガード**」（サンズ）は、カズマの『固有』による特性の変更を無効にした。特性が要のポケモンにとっては特性を変えられるのは死活問題なので有効だが、そうでなければ1ターンの「きょううん」と引き換えに持ち物の枠を使わせたことにもなる（天花談）。（出典: 124, 125）
  - 新しい持ち物も、ほかの持ち物と同じく実機どおりの性能。「**ものまねハーブ**」（相手のランク上昇をまねる）は、登場時に能力が上がる『トップバッター』や『エース』と対面すると要注意。1回きりで、使われたことは最初にわかる。対策は強制交代（レッドカード、ふきとばし、ほえる）、きあいのタスキ、ポテンシャルなど。『エース』に使うには同時に場に出る必要がある（『凱旋』『輪廻』『旋回』の死に出しなら大丈夫、ルサルカの『ストーキング』だと一度相手をどかす必要がある）。（出典: 121）
- 新しく見つかった技や特性（「デカハンマー」「おうごんのからだ」「しろのいななき」「ふくつのたて」など、第9世代のもの）の特集本も出ている。（出典: 122）

## 技の処理
- **2つのタイプを持つ攻撃**（「フライングプレス」や、エールの第二『固有』を乗せた「さばきのつぶて」など）は、2つのタイプのうちダメージが多くなる方の相性で判定する。どちらかのタイプが条件を満たせば、タイプ一致の倍率や持ち物（プレートなど）の効果も乗る。（出典: 114）
- 技の処理は、基本的に原作（第五世代まで）のポケモンと同じ。原典に独自の表示があるものだけ、そちらに従う（補足: ユーザーより）。例: 「ほろびのうた」は、原典の技の説明では「場にいる全員の「死のカウント」を「4」にする」（104のカフェのデータ）。
- **「とんぼ」技と「おいうち」技がかち合ったとき**: 「速」や優先度をすべて無視して、「おいうち」側が先制する。『チェイサー』なら、その瞬間に『役割』が発動する。
- **ドレイン技**: 自分の体力が満タンのときは回復が発動しない。
- **「みらいよち」類**: 原作と違って状態変化になっているので、交代で解除できる。次のターンでの実質的な連続攻撃のようなもの。
  - 「みらいよち」状態…次のターンの最後に、相手に「みらいよち」によるダメージを与える。「まもる」を貫通する。ダメージは、「みらいよち」状態にしたときに場にいたポケモンの「特攻」で判定する。
  - 使った側の持ち物、特性、ランク補正、ポテンシャルは影響しない。技として出した場合以外（『固有』や『専用』など）は、タイプ一致の補正も入らない。
- **追加攻撃と追加行動**: 追加攻撃は同じ攻撃を続けて出すこと。追加行動は異なる行動もできること。
  - 食蜂の『固有』の「こうげきしれい」の追加行動は、味方の「通常行動」にしか反応しない（天花談）。通常攻撃が外れても、追加の「こうげきしれい」は別に当たる。（出典: 145, 146）
  - メガスピアーの『スピアナイト』の「一番最初に」の追加行動は、『指令』や交代の直後に、優先度を無視して誰よりも早く出る。「ねこだまし」や「まもる」より早い。この追加行動では「おいうち」は選べないと見られていて、『もどれ！』なら確実にかわせる（マックイーン談）。（出典: 145, 147）
- **全能力値の上昇（強化）**: 基本的に攻撃・防御・特攻・特防・素早さの5つ（体力は入らない。『二枚看板』の1.33倍や「さいごのとりで」の1.5倍も同じ）。「任意」や「ランダム」の能力上昇は、回避・命中・急所ランクを含むこともある。

## 『ストーキング』
- 専用ポテンシャルの型の一つ。原典では112で初めて出た（「○○○専用ポテンシャル。『エース』が場に出た時、味方と任意交代して場に出ることが出来る」）。『キラー』『チェイサー』が覚えることが多い。（出典: 112）
- 以下は、原典に出る前にユーザーから聞いていた仕様（補足: ユーザーより）。
- 『ストーキング』による交代は、お互いの『役割』の発動より先に発動する。
- 設置技の効果は、『ストーキング』より前に発動する。
- 「ものまねハーブ」は『ストーキング』のときでも発動する（二節〜三節の幕間以降）。

## オリジナルの状態変化
| 状態 | 効果 |
| --- | --- |
| 加熱 | 「炎」技の威力が1度だけ2倍になる。「充電」の「炎」版。技「**かねつ**」（変化・炎・自分。自分を「加熱」状態にして「特防」を上げる）で入る（出典: 125） |
| 冷却 | 「氷」技の威力が1度だけ2倍になる |
| 迎撃 | 相手の技に1/2の反動ダメージをつける |
| はいすいのじん | 通常交代ができない。「はいすいのじん」を出しても失敗する |
| 充電 | 「電」技の威力が2倍になる（出典: 045） |

- 「**ダーク**」タイプ: 通常では存在しえない特殊なポケモン・技のタイプ。「闇」技は「ダーク」タイプ以外の全タイプに「こうかばつぐん」になる。メアリは《シャルノス》を展開している時だけ、単発の「技能拡張」で「ダーク」技を出せる。（出典: 122）

- 「**ばらぞの**」（変化・草・敵陣の設置技）: 場に出た相手の体力を1/8ドレインする。「炎」「草」タイプが場に出ると解除される。「まきびし」「どくびし」とは共存できるが、「ステルスロック」とは同じ系統の設置技で、後から「ばらぞの」を出すと「ステルスロック」は消える。（出典: 109）

## 宙に浮かび上がる
- 特性やポテンシャルでつく効果。状態変化の扱いに近い。発動するときはメッセージに表示される。
- この効果による「地面」技の無効化は防護に当たらない。防護特性や防護ポテンシャルを無視する効果でも貫通されない。
- 特性「ふゆう」は実機と違い、場に出ると表示される。特性「かたやぶり」などでも無視されない。
- そのほかの仕様は、ポケモンwikiの「地面にいる」を参照。

## 持ち物
- 持ち物の効果は、基本的に実機と同じ。ただし、スレでの仕様変更やポテンシャルとの兼ね合いで勝手が違うこともある。
- **こだわりハチマキ**: 自分の「防」の値でダメージを計算する技には効果がない。
- **とつげきチョッキ**: 急所で貫通される。
- **ひかりのねんど、あついいわ、しめったいわなど**: ポテンシャルには効果がない（技と特性だけ）。
- **クリアチャーム**: 相手からの能力の減少を無効にする。低下は無効にしない。実機と同じで、実機よりパワーアップしている特性「クリアボディ」「まけんき」とは対応範囲が違う。
- **持ち物を壊す・変える効果**: 持ち物が効果を出す前に壊したり変えたりする。攻撃技なら「きあいのタスキ」や「ボコのみ」なども貫通して攻撃できる。
- **こだわりと技能拡張**: 「技能拡張」を使っても「こだわり」には縛られない。ただし、一度でも覚えている技を使えば、「技能拡張」も使えなくなる。

## 特性
- 「**まけんき**」など: 実機と違い、「わざわいのたま」などによる能力の低下も対象。1回の減少（低下）につき1回発動する（複数の能力が下がっても1回）。『役割』『エンペラー』（原典未登場）による任意の能力の減少と、全能力値の低下は別にカウントされ、2回発動する。
- **タイプによる特性の無効は第五世代仕様**。「ゴースト」タイプも「かげふみ」で交代を縛れる。（出典: 071）
- 「**クリアボディ**」: 相手からの能力減少（低下）を無効にする（実機よりパワーアップ）。ただしフィールド効果は防げない。（出典: 056, 057）
- 「**けいやく**」: 場に出た時、相手の特性を「けいやく」に変える。ターン制限はない（カズマの『固有』の「きょううん」は1Tで戻るのと違う）。キュゥべえの専用と組むと、相手のタイプも「エスパー」単になる。（出典: 144）
- 「**トリコロール**」: 「炎」「氷」「電」技を無効にする。かなりレアな特性（ライザ談）。森の洋館のロトムが持つ。（出典: 128）
- 原典で説明の出た特性（124〜125）: 「**さいごのとりで**」（最後の1体の時、自分の全能力値を強化（1.5倍）する。最後以外だと半減する）、「**すりぬけ**」（自分の「変化技」が相手の「まもる」などを貫通する。実機とは説明が違う）、「**ぼうじん**」（「霰」「砂嵐」のダメージを無視し、「〜こな」などの技を無効にする）。（出典: 124, 125）

## 【H】（ホーム）補正
- 大会の勝敗が同点のときは、地元チーム（【H】）が上位。それ以外の場合は、直接対決の勝者が上位。

- 逆算のやり方（推測）: この世界には**個体値も努力値もない**ものとして計算する（補足: ユーザーより）。
  - 能力値 = 種族値×2×Lv/100＋5、体力 = 種族値×2×Lv/100＋Lv＋10（性格補正なし）。
  - 攻撃側と防御側のランクを、上の「ステータスのランク」の幅（例: Cなら60〜85）のまま使う。第五世代のダメージ式（乱数0.85〜1）で計算する。
  - そのダメージが「ダメージ表示の目安」の割合に収まる体力の種族値を、場面ごとに出して重ねた。
- 使ったのは、攻撃側の図鑑データ（ランクとLv）が原典に出ていて、技・倍率・能力変化が本文で分かる場面だけ。
- 被弾の場面が「大きな」「まずまず」ばかりだと、下限しか決まらない（体力が高いほど、ダメージの割合は小さくなるので）。「皮一枚」や「特大」で倒れた場面があると、上限も決まる。
- 検算: 同じやり方で、マックイーン（A）とライナー（AA以上）の場面を計算すると、原典どおりの範囲に入る。ただし、048のポリゴンZ→ライナーの場面だけはずれる。
- 099でカズマが「（チームの）半数が「体力：A」以上」と言っていて、ライナー（AA）、ガブリアス（AA-）、マックイーン（A）、ヤマト（A）の4体と合う。（出典: 099）
- ルサルカの逆算（C）が1段階低く出たのは、次の2つの見落としが重なったため。
  - **027 ホワイトスネイクの「だましうち」**（上限を81に決めていた場面）: ルサルカは直前に『防御指令』（防+1）を受けていた。ただしルサルカは「猛毒」状態で、攻撃の直前に『毒白蛇の暗躍』（相手が毒・猛毒の時、自分の「毒」技が相手の「防」の上昇を無視）が表示されている。表示どおり防+1が無視されたとすると、最初の計算（防+1なし）と同じになり、上限は81。B-（90）だと計算上のダメージは18〜33%で、「大きなダメージ」の目安（30〜50%）の下の端にかろうじて届く程度。この場面は「目安の境目」にあたり、少しのずれで上限が動く。
    - メアリの「一致抜群**でも**落ちなかった」は、「仮に一致抜群だったとしても落ちなかった」という意味で、実際はタイプ一致ではない（補足: ユーザーより）。図鑑でもホワイトスネイクは「どく」単タイプ。
    - 「だましうち」は「あく」技なので、本来『毒白蛇の暗躍』（「毒」技だけが対象）は効かず、防+1が残るはず。その場合、計算上のダメージは「大きな」に届かない。この場面は作者の処理のちょっとしたミスと思われる（補足: ユーザーより）ので、逆算からは外した。
  - **048 ティアナの「サイコキネシス」**（下限を決める場面）: 『不動のエース』（「ここぞ！」で攻/防/特攻/特防/速+1）が発動したあとの一撃だったのに、最初は入れていなかった。入れ直すと下限が85に上がる。
- 『エース』のバフは、027のホワイトスネイク（1.33倍）と030のランスロット（1.33倍）には入れてあった。032のスクレイドは「ここぞ！」になる前、056のキルアは『エース』ではないので入らない。
- 火傷の物理半減は、027のホワイトスネイクと030のランスロット（どちらも本文に「火傷：半減」の表示あり）には入れてあった。032のウンディーネの「クイックターン」も、直前に「おにび」で火傷していたのに入れていなかった（本文の表示は「雨：技1.5倍」だけ。原典では、こういう補正の表記がちょくちょく省かれることがある（補足: ユーザーより））。入れ直すとこの場面が許す範囲は広がるが、全体の結果（85〜127）は変わらない。
- 1場面だけで上限や下限が決まるときは、その場面の見落とし（『指令』、『エース』のバフ、火傷など）に気をつける。
- はじめに個体値31として計算したときは、どれも1段階ほど低く出て、合わない場面も多かった。個体値・努力値なしにすると、ほぼすべての場面が一致する。

## ダメージ表示の目安（推測）
原典の「〇〇のダメージ」という表示と、作中の台詞から読み取ったおおよその目安。1発で受けたダメージが、最大体力のどのくらいかを表していると思われる。（推測）
- ユーザーいわく、完全な正解ではないが大きく間違ってもいない。今後、数字は多少上下する。（補足: ユーザーより）

| 表示 | 目安（満タンから1発） | 根拠 |
| --- | --- | --- |
| 微々たるダメージ | 1割未満 | 「ねこだまし」や、いまひとつの弱い技、半減された不一致技で出る（046, 048, 057, 124） |
| 小さなダメージ | 1〜2割 | エンジェウーモンに「2割も行かない」（056）。瑞鶴の『三点防護』で強化を全部消された攻撃（139, 140） |
| まずまずのダメージ | 2〜3割（1.5〜3.5割の幅） | 「こいつもさっきの奴も3割行かない手応え」（056）。ライナーはステルスロック（1/8）＋まずまず2発で「体力も4割斬ってる」（056。1発1.5割前後）が、024では「まずまず」2発で「半分以上もってかれた」（1発2.5割以上）。満タンからの＠は2〜3 |

- 目安は、原典の「〇〇のダメージ」の直後の「＠」と、その話で初めてダメージを受けたポケモン（ほぼ満タン）の組み合わせを数えて見直した。＠Nは「あと何発で倒れるか」なので、満タンから受けた1発の割合が、＠2なら3.3〜5割、＠1なら5割以上とわかる。ステルスロックや『固有』の削りを先に受けていたものは、なるべく数えていない。（推測。ユーザーに「精査してみて」と言われて見直した）
- 隣の言葉の範囲は少し重なる（「大きな」の上のほうと「深刻な」、「深刻な」と「特大の」）。補正の細かい差や、作者の手計算の幅があるためと思われる。
- 143〜147の計算での確認（推測）: 満タンから受けた場面は、上の目安とよく合う。
  - 「小さな」: シンリュウの「りゅうせいぐん」（壁で半減）→ルサルカが計算で15〜21%、本文でも「2割しか効いてない」（143）。「こうげきしれい」（半減）→ガブリアスが18〜25%（146）。
  - 「大きな」: ドダイトスの「さばきのつぶて」→マジュのみのヤマトが42〜61%、シンリュウの「さばきのつぶて」→壁のモモが46〜64%で、どちらも本文で「半分以上」（143）。メガスピアーの急所「ドリルライナー」→ヤマトが46〜63%、リオハートの「かえんほうしゃ」→イカルガが40〜57%で「＠1〜2」（147）。
  - 「特大」と「大きな」: ウルゥル＆サラァナの「さばきのつぶて」→マックイーンが62〜92%で「特大＠1」、威力半減の追加攻撃が32〜47%で「大きな」、2発で倒れた（143）。
  - 「極大」: ラハールの急所の「さばきのつぶて」→ガッシュが157〜222%（144）。
- **体力が減っている相手への表示は、最大体力ではなく「そのときの残り体力」に対する割合で決まっているように見える**（推測）。147では、残り4割前後のガッシュへのリオハートの「かえんほうしゃ」（最大体力の29〜42%）が「深刻な＠1」、残り2〜3割のルサルカへの急所の「こうげきしれい」（最大体力の12〜17%）も「深刻な＠1」だった。どちらも最大体力に対してなら「まずまず」か「小さな」くらいだが、残り体力に対してなら大半を削っている。上の表は満タンからの目安なので、減っている相手には、残り体力を満タンとみなして当てはめるとよさそう。（出典: 147）

- 「＠2」「＠1」は、同じダメージをあと何発受けたら倒れるかの目安。（出典: 013）
- 擬似バトルをするときは、上のステータスのランクを種族値に置き換え、第五世代の原作のダメージ式で計算し、この目安で表示を決める。細かい部分は、原典のダメージ量と照らし合わせて調整する。
