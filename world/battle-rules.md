## ステータスのランク

→ [詳しい中身](battle-rules/ステータスのランク.md)

図鑑の文字ランクは、種族値のおおよその範囲を表す。同じランクの中では「-」が下寄り、「+」が上寄り。ステータス画面の5つと、マスクデータの体力に使う（作者、012で最初に示された）。
| ランク | 種族値 |
| --- | --- |
| S | 200〜 |
| AAA | 170〜195（-〜+） |
| AA | 140〜165（-〜+） |
| A | 110〜135（-〜+） |
| B | 90〜105（-〜+） |
| C | 60〜85（-〜+） |
| D | 40〜55（-〜+） |
| E | 1〜35（-〜+） |
- **「+」はその幅の最大値、「-」は最小値で固定**（補足: ユーザーより）。例: B+ は105、B- は90。A+ は135、A- は110、AA+ は165、AA- は140、C+ は85、C- は60（出典: 012）
- 「+」「-」のない素のランクは、幅の中ほどの値をランダムに決める（補足: ユーザーより）
- S は200を超えたどこか（210でも220でも。補足: ユーザーより）。決まった値はなく、そのポケモンごとに200超えの値を置く。
- 能力ランク（「攻+1」など）は、1段階上がると1.5倍。（出典: 011）
- 種族値の補正: 「+補正」は+-の刻みで1つ、「1ランク上げる」は文字で1つ上がる

### ゲームで回すときの能力値の式（補足: ユーザーより）

- 実機の式で、**個体値と努力値はなし**。「×2」と「Lv/100」はない（レベルは関係しない。補足: ユーザーより、2026-10-24）。
  - 体力以外: 種族値＋5
  - 体力: 種族値＋60（補足: ユーザーより、2026-10-24。カズマの手持ちが受けた22場面で確かめると、合う幅は＋47〜69で、＋60はその中。[計算方法の検証](hp-estimates-kazuma-notes.md)）
  - ダメージの式は原作（第五世代）のまま。式の頭のレベルの項（2×Lv/5＋2）は、レベルにかかわらず22（Lv50にあたる）で固定。乱数は0.85〜1.00。
  - レベル差は、高い側の全能力（体力もふくむ）に、1につき1%を掛ける（10違えば1割増し。補足: ユーザーより）。
- 種族値は上のランクから決める（+は最大値、-は最小値、素は中央あたりからランダム、Sは200超え）。
  - 素のランクは、余程うがった見方をしない限り、そのランクの真ん中くらいと見てよい（Cなら70〜75くらい。補足: ユーザーより）。逆算でもこの値を使う。
- 性格による補正は、原典に出てこないので入れない（推測）。
- 体力（マスクデータ）のランクの決め方: 原典で分からないポケモンは、見た目や種族のイメージで決める
- 体力の見せ方: 数値は見せず、「大きなダメージ」などの言葉と「＠2」の印で見せる

## 能力の「上昇」と「強化」（補足: ユーザーより）

→ [詳しい中身](battle-rules/能力の「上昇」と「強化」.md)

- **上昇**: ランクの変化。「攻を上げた」は+1、「ぐーんと上げた」は+2で、1段階で1.5倍（上の能力ランク）。状態表示では「攻+2」のように書く。
- **強化**: 倍率。『二枚看板』の全1.33倍、『全開指令』の2倍、『スターター』の1.05倍、『タイトエンドγ』の1.1倍など。状態表示では「全1.33倍」「速2倍」のように書く。
- 「上昇（強化）」と並べて書かれた効果は、ランクと倍率の両方に作用する
- 片方だけが書かれているものは、その片方だけに作用する
- 下げる側も同じ。「下げる」はランク、「低下（0.75倍）」は倍率の低下
- 急所は、相手のランクの上昇だけでなく倍率の強化も無視する（出典: 030）。
- 「±」の反転（クロエルの固有）: 相手の能力上げが下げに変わり、減少無効で防げる
- 重なったときは全て掛け算（例: 攻+1の1.5倍×『二枚看板』1.33倍＝約2倍）
- 『全開防御指令』などの「防」の強化は、「ロックスタンプ」「アクアスタンプ」のように自分の「防」で攻撃する技にも乗る（補足: ユーザーより）
- 「ひっくりかえす」は、「せいしんりょく」（相手によって「攻」が下がらない）があっても「攻」を反転させる（補足: ユーザーより。545のエレン）
- 同じポテンシャルの倍率強化は重ね掛けできない（ランク上げなら重なる）
- **「命中」「回避」のランク**は、ほかの能力と上がり幅が少し違い、+1でおよそ4/3（約1.33倍）（ガッシュ）。（出典: 164）

## レベル差

→ [詳しい中身](battle-rules/レベル差.md)

- レベルが10違うと、全能力におよそ1割の差があると考えてよい（目安）
- 逆算ではレベルを能力値の計算に使わず、同じレベルとして計算してレベル差の割合だけ掛ける（補足: ユーザーより）
- ただし、Cランクあたりではチーム間のレベル差はせいぜい10程度なので、実際にはそこまで気にしなくてもよい。育成型の強みも含め、Cランクではどの資質もまだ真価を発揮していない。

## 急所（クリティカル）

→ [詳しい中身](battle-rules/急所.md)

- 急所率は**第五世代までの仕様**で、最大（C+4）でも確率は1/2。その分、急所のダメージは**2倍**（012で最初に示されたスレの注意事項）。（出典: 012, 034, 071）
- このスレの急所は、ランクだけでなく「**倍率強化**」も無視する。（出典: 030）
- 急所ランクごとの確率:
| 急所ランク | 確率 |
| --- | --- |
| C+0 | 1/16（6.25％） |
| C+1 | 1/8（12.5％） |
| C+2 | 1/4（25％） |
| C+3 | 1/3（33.3％） |
| C+4 | 1/2（50％）。ランクはここまでしか上がらず、確率も50％が上限（補足: ユーザーより） |
- バッジ3つクラス以上（資質の影響が出始めるプロ資格持ちのステージ）では、相手との「指示」ランク差1つにつき、高い方に常に急所ランク+1がつく。（出典: 045）
- **確定急所の技**（「ちのやり」など）は、自分の「特攻」の低下を無視して攻撃できる。（出典: 175）
- クリティカル倍率: 急所は基本2倍、特性「スナイパー」などでは3倍
- 急所に当たるのを見てから『たえろ！』を出すことはできない（天花）。（出典: 200）
- 急所率（「C」）には「-」がないので、「あまのじゃく」などでも反転しない

## 確率の目安（補足: ユーザーより）

→ [詳しい中身](battle-rules/確率の目安.md)

原典のポテンシャルや効果の文に出てくる確率の言い方と、そのおおよその値。原典には数字は書かれていない。
| 原典の言い方 | 確率 | 例 |
| --- | --- | --- |
| 中確率 | 50％ | 『リターンキュア』『リターンヒール』、『エキスパンション（水）』、『桃王女の計画』 |
| 低確率 | 12.5％（1/8） | 『絆』のポテンシャルの再発動、コトブキスタジアムのフィールド効果、『百合剣士の剣技』 |
| 稀に | 6.25％（1/16） | 『気合い』、天花のサポート効果の「テレポート」の追加行動 |
- 低確率（1/8）と稀に（1/16）は、ゲームで回すときはこの値で固定する（補足: ユーザーより）。低確率は急所ランクC+1、稀には急所ランクC+0と同じ値。
- 「1割」「2割」のように原典に割合が書かれているものは、その数字のまま（ヴォルデモートの「1割：呪い」、「たちさばき」の2割など）。
- 『気合い』（稀に攻撃を耐える）: 満タンで0％、減るほど上がり最大12.5％くらい
- 《バトルフロンティア》のフィールド効果（「ここぞ！」で発動率が上がる）で、実際にどれだけ上がるかはまだわからない。
- クライマックスリーグの会場《シンオウリーグスタジアム》も「ここぞ！」でポテンシャルの発動率が上がる（764。対象と対象外は [フィールド効果](pro-league/フィールド効果.md)）。

## タイプ

→ [詳しい中身](battle-rules/タイプ.md)

- タイプの特徴は第五世代準拠。「でんき」も麻痺し、「ゴースト」にも「くろいまなざし」が効く。（出典: 034）
- タイプ一致の倍率は1.5倍。「一致倍率2倍」はこの1.5倍が2倍になる意味
- 複合タイプの技: いちばんダメージが多くなる相性で判定し、一致も片方で乗る
- ばつぐん・いまひとつにする効果は一律で2倍・0.5倍（4倍にはならない。補足: ユーザーより）
- 相手のタイプ耐性を貫通する効果: 最終的な相性が等倍になる（出典: 493）
- 「闇」タイプ: 「闇」タイプ技は18種すべてのタイプに「ばつぐん」を取れる（ルサルカ）
- 「ダーク」タイプ: 通常では存在しえない特殊なポケモン・技のタイプ

## 「ここぞ！」という場面

→ [詳しい中身](battle-rules/「ここぞ！」という場面.md)

1. 「3vs3」のときは、味方が残り1体になると自陣が「ここぞ！」。（6vs6では残り3体。出典: 021, 024, 045, 046）
2. お互いの『エース』が場で対面すると、互いの場が「ここぞ！」。
- 「ここぞ！」は、上の条件が満たされている間だけ続く
- 「ここぞ！」の原則には、始まりと終わりのタイミングがきっちりある（補足: ユーザーより）
- ガッシュの異名『友情』は「ここぞ！」の発動だけを行い、終わる処理は普通に効く
- 先に『ペースメーカー』で『エース』が発動していれば、「ここぞ！」で再発動はしない
- 『獣化』の7体目がまだ参戦していないチームも、6体のうち残り3体で「ここぞ！」になる（508。カズマ「お前が出て来ても結局残り3体には変わらんが」）。（出典: 508, 509）
- だっしゅつパックなどの強制交代で出直しても、『エース』がもう一度発動する“おかわり”はない（モモ）。（出典: 200）

## 処理順（要約）

→ [詳しい中身](battle-rules/処理順.md)

処理順のルール（同じタイミングで動くものの順番、1ターンの流れ、『役割』の発動タイミング、天候・フィールドのかち合い、死に出し、特性のコピーなど）は [turn-order.md](turn-order.md) に集約した。要点だけ:

## 防護

→ [詳しい中身](battle-rules/防護.md)

「防護」とは、このスレでは相手の攻撃技のダメージを緩和したり無効にしたりするもの。次の3つが含まれる。
1. ダメージの緩和や無効化
2. 「攻」「特攻」の上昇（強化）の無視
3. 「必ず耐える」系（『気合い』のような「稀に耐える」ものも含む。117でカタクリの『気合い』がガッシュの『バオウ・ザケルガ』に貫通された。出典: 117、補足: ユーザーより）
- 『固有』ポテンシャルによるダメージの緩和や、四式の『たえろ！』は**トレーナーの**防護ポテンシャル。なので『オールドタイプ』や『エキスパンション（闘）』（出典: 062）では貫通できない。
- スタジアムのフィールド効果によるダメージの緩和（《ハクタイスタジアム》の『オールドタイプ』0.85倍など）は、フィールド効果なので「あらゆる方法で貫かれない」（ライザ）。（出典: 073）
- 「宙に浮かび上がる」ことで得る「地面」技の無効化は防護に当たらない（下の「宙に浮かび上がる」を参照）。
- 『スーパーヒーロー』（キャプテン・アメリカ）の「「まもる」等が貫通（解除）されない」は**防護ではない**ので、『三角効果』でも抜けない。『強化貫通』ならぶち抜ける（作者）。（出典: 245）
- 急所に当たると相手の能力の上昇（強化）は無視されるが、**防護は急所（クリティカル）では抜けない**（出典: 068）。
- ポケモン自身の防護ポテンシャルは、『オールドタイプ』などで貫通される
- 『闘争本能』（低確率で攻撃技を無効化。ポケモン自身の防護ポテンシャル）は、『エキスパンション（闘）』（防護ポテンシャルの無視）で打ち砕かれた。（出典: 232）
- 攻撃を無効にする特性（「しらはどり」など）は「防護特性」と呼ばれる
- 『対〇回避』（命中率の低下）は、『オールドタイプ』でも消えなかった

### 三角効果

- 専用ポテンシャルの型の一つ（「攻」か「特攻」がAA以上で使える。出典: 066）。相手ポケモンの「まもる」などの技、特性、相手ポケモンと相手トレーナーの防護ポテンシャルを無効にする。
- トレーナーの防護ポテンシャルには、四式の『たえろ！』が当たる。
- 能力の上昇・強化を貫通する効果はない。
- 「こらえる」「みがわり」は、『三角効果』を受けない数少ない防御手段
- 〇〇指令による「防」「特防」の強化は、トレーナーの防護ポテンシャルに当たらないので、三角効果では貫通されない。
- 持ち物の「**とくせいガード**」を持っていれば、三角効果からも特性を守れる（144でガッシュの「きあい」が残り、ラハールの急所の一撃を体力1で耐えた。「「もちもの」の力までは、貫けまい！！」）。（出典: 144）

## 『指令』

→ [詳しい中身](battle-rules/『指令』.md)

- **1Tに出せる数**: 六令は1Tに1回、四式も1Tに1回。六令1つと四式1つを同じTに同時に出すことはできる。（補足: ユーザーより）
- 四式が効く範囲: 四式（『かわせ！』『よけろ！』など）が効くのは1回の攻撃だけ
- 「あばれる」状態（「げきりん」など）のポケモンは指示を受け付けないので、『指令』も効かない（→ 下の「状態変化」の「あばれる」状態）。
- 「『指令』を受けたとき〜」系のポテンシャル（『サーヴァント』など）が発動するのは六令（『〜指令』）だけ。四式では発動しない。『サーヴァント』は093でBBが持っていて、原典でも同じ注記があった。（出典: 093）
- 「自分の『四式』が発動したとき〜」系は六令では出ず、四式が実際に発動した時だけ
- 四式が必中・「おいうち」・防護貫通で突破されたら、四式きっかけのポテンシャルは出ない
- 『たえろ！』は、相手の技のダメージを半減し、急所でも何でも必ず耐える（倒れる分でも体力1で残る。補足: ユーザーより。出典: 034）
- 『全開回復指令』は行動をスキップするので、『たえろ！』も使えない。満タンに戻したところに、通常攻撃、低確率の追加行動、「呪い」の3段で倒されることもある。（出典: 169）
- 急所に当たるのを見てから『たえろ！』を出すことはできない（上の「急所」。出典: 200）。

## 交代

→ [詳しい中身](battle-rules/交代.md)

- 「**通常交代**」は、指示の時に出す交代コマンド（『もどれ！』も含む）のこと。「とんぼ」技、ポテンシャルによる交代、「レッドカード」などの強制交代は含まない。（出典: 135）
- 交代が出る時機（「とんぼ」技はその場ですぐ出る、『凱旋』『輪廻』『旋回』の後続は次のT開始時、死に出しは次のT開始時）は [turn-order.md](turn-order.md)。
- 倒して同時に次を出す時は、『エイヴィヒカイト』など待ち構える系は発動しない
- 強制交代で出入りした時は、「場に出たとき」「場を離れたとき」系が発動しない
- 『野生』のポテンシャルを持たないので、群れのポケモンにも強制交代は効く（カズマ）。（出典: 231）
- 天花のサポート効果で、交代阻害（「くろいまなざし」「しめつける」など）は基本的に無視できる
- **強制交代を受けない**効果（《夢幻漆黒空間/シャルノス》、種属の『〜の重量』など）でも、強制交代しないだけで「ハウル」のダメージなどは通る（カズマ、404）。（出典: 404）
- 交代封じと「必ず交代できる」がかち合ったら「必ず」の方が勝つ（[turn-order.md](turn-order.md)。補足: ユーザーより。489で天花のサポート効果の「テレポート」が《異界/もどりの洞窟》を抜けた。出典: 489）。「だっしゅつパック」による自動交代は下の「持ち物」。

## 妙手（タイム）

→ [詳しい中身](battle-rules/妙手.md)

- 「指示：A」以上のトレーナーが使える。
- バトル中に、使える回数だけ（「指示：A」で1回。下の項目）、場にいる選手と相談できる。（出典: 098）
- そのときトレーナーがわかっている情報で出せる最善手を出す。図鑑も使っていない先発の1ターン目に使っても、データがなければ何もわからない。（出典: 098）
- 使いどころは「前半から中盤にかけて鋭い一手を差し込む」か「後半戦でデータが集まったところで、詰みや逆転の手を打つ」のどちらか。（出典: 098）
- 「指示：A」で1回
- カズマはガッシュかルサルカ（『絆』）が場にいる間だけ使える。140からは、異名『愛馬』で自分に『魂の絆』が付くマックイーンが場にいる間も使える（213のT10で、マックイーンが場にいる時に使った）（出典: 098, 101, 140, 213）
- 両者が同じターンに「タイム」を使うと読みが相殺され、「指示」のランク差はほぼ消える
- 「タイム」は指示を選んでいる途中に起きるので、あとでも指示や『指令』を出せる
- 特殊役割『ベテラン』は、1試合1回、「指示」に関係なくトレーナーに「タイム」を使わせられる（ベルナデッタは指示C）。（出典: 200）
- 「タイム」を使ったことは相手には分からず、推測するしかない（『ベテラン』の「タイム」は、「タイム」に連動して付随の『アドバイス』のポテンシャルが発動するので露見するだけで、それで『役割』も分かる。カズマは固有の「きょううん」が『役割』に連動するので、それでも『役割』が分かる。補足: ユーザーより）
- 『ベテラン』による「タイム」は表示される（天花）

## ポケモン図鑑（解析）

→ [詳しい中身](battle-rules/ポケモン図鑑.md)

- 「ポケモン図鑑」（1試合1回の解析）は、相手のトレーナーも誰もが使う
- 図鑑で抜けるのは、使ったその瞬間の姿のデータだけ。メガシンカする個体に使っても、メガシンカの前ならメガシンカ前の分、メガシンカの後ならメガシンカ後の分しか分からない（補足: ユーザーより）。
- 212では、うてなが初手で図鑑を使い、シェオルドレッドの『囁魔女の情報』（相手のデータを解析した時に毒にする）が発動した。うてなの固有『魔法少女にあこがれて』（「タイム」で♀を解析）とは別枠。（出典: 212, 213）
- 『スカウター』の『役割』の発動は、相手のデータの解析に成功した時の1回だけ。解析を無効化されたら不発になる（何回も使えるわけではない）。『チェイサー』も「おいうち」を無視されれば不発（オシュトル）。（出典: 239）
- バトルの外からの解析はできない（客席からの解析は運営が妨害している）
- 解析の無効化: 『ECS』などに当たると図鑑は使用済みになり、その試合はもう使えない
- 相手が図鑑を使ったことは表示されない。図鑑を使った相手に『アドバイス』は出ない

## 技の処理

→ [詳しい中身](battle-rules/技の処理.md)

- 技そのものの効果（このスレ独自の技、原作と効果が違う技、原典で説明の出た技と使われ方）は [moves.md](moves.md) に統合した（補足: ユーザーより）。ここには処理のルールだけを置く。
- 技の処理は、基本的に原作（第五世代まで）のポケモンと同じ

### 行動不能の判定

- 行動の順番が決まってから、技を出す直前に「麻痺」などの行動不能の判定がある
- 怯みも実機と同じく、そのT中の攻撃（追加行動もおおむね）が止まる（[turn-order.md](turn-order.md)。補足: ユーザーより）。

### 「とんぼ」技と「おいうち」技

- 「とんぼ」技と「おいうち」技がかち合ったとき: 「速」や優先度をすべて無視して、「おいうち」側が先制する

### 「まもる」系の技

- 「キングシールド」は「まもる」系の技として扱う（作者）
- 「まもる」を使ったあとに追加行動が発生しても、次の技は出せない（「まもる」してから追加行動で攻撃、はできない）。（出典: 164）
- 「のろい」（ゴーストの）は攻撃技ではないので「まもる」を貫通する
- **「ロックオン」と「まもる」**: 技「ロックオン」も「まもる」で防げる（技の対象は相手で、状態変化は自分にかかる。「こころのめ」も同じ）。なので相手の「まもる」に合わせてスカすことはできない。（出典: 245）
- 特性「すりぬけ」は、自分の「変化技」が相手の「まもる」などを貫通する（下の「特性」）。

### 必中と「ロックオン」

- 「ロックオン」状態の相手の技は「必中」になる（「じゃあくなほのお」など）
- 「きょけんとつげき」を使うと、そのあと相手の技が「必中」になり、威力が2倍になる（→ [moves.md](moves.md)。出典: 139）。
- 必中の「ドラゴンハウル」の前では、『ヌシの勅命』（回避）も意味をなさなかった（勅命を1回消費）。（出典: 231）
- 「宙に浮いている相手に命中する」効果は、下の「フィールド形成」を参照。

### 「単体技」と「全体技」

- 範囲が自分や相手1体なら「単体技」、それ以外は「全体技」

### 追加攻撃と追加行動

- 追加攻撃は同じ技をもう一度繰り出すこと、追加行動は技を選べる

### 全能力値の上昇（強化）

- 全能力値は攻撃・防御・特攻・特防・素早さの5つで、体力は入らない

### 「みらいよち」類

- 「みらいよち」類: 原作と違って状態変化になっているので、交代で解除できる

### ドレイン技

- 自分の体力が満タンのときは回復が発動しない。

### 威力を条件にした軽減

- 威力を条件にした軽減は元の威力で判定する（「眠り」で2倍の技に『巨塊』は効かない）

### 技能拡張

- 技能拡張は「わざマシン」を持たせて出すこともできる（魔理沙の「マジカルシャイン」。『スペルカード』で優先度+1）。（出典: 170）「こだわり」との関係は下の「持ち物」。
- トレーナー側の「能力」として「技能拡張」を持つ人もいる（白石蔵ノ介など）

### 「けん」「つるぎ」技の範囲

- 121の通達で、「けん」「つるぎ」等の技に「つばめがえし」「エアスラッシュ」「シザークロス」なども含まれるようになった。それらの威力を1.5倍にする特性「**きれあじ**」も出た。（出典: 121）
- このスレ独自に、「つじぎり」「ストーンエッジ」なども「けん」「つるぎ」技に数える

### 第九世代の技・特性

- 第九世代の新しい技や特性（「デカハンマー」など）の特集本も出ている

## 設置技

→ [詳しい中身](battle-rules/設置技.md)

- 場に出た時は設置技が特性や『役割』より先に入り、それで倒れたら特性なども出ない
- 「ばらぞの」: 草の敵陣設置技。場に出た相手の体力を1/8ドレインする
- 「**ひばしら**」（場に出た相手に体力の1/8の「炎」ダメージ。出典: 139, 140）で交代先が受けるダメージは「炎」の相性で変わる（草のモモは1/4）。（出典: 200）
- **対地設置技**（「じらいげん」「きらい」など）: 「対地」は「まきびし」のように、宙に浮いたポケモンには刺さらないという意味（天花）。（出典: 176, 177）
- 特性「ふゆう」のポケモンには「特性『ふゆう』により、設置技のダメージを受けない」と表示される（176のサザンドラ）。（出典: 176, 177）
- 自陣の設置物の解除: 「くさかり」（草）・「やきはらう」（炎）・「あらいながす」（水）

## フィールド

→ [詳しい中身](battle-rules/フィールド.md)

- ポテンシャルの効果で、場に「**《異界/テンガン山》**」のようなフィールドが展開されることがある。（出典: 007）
- 《異界/もどりの洞窟》の交代の制限: 『野生』『ヌシ』以外のポケモンは通常交代以外で交代できなくなる（天花の「必ず交代できる」は抜けた。489）
- フィールド同士のかち合い（『固有』のフィールド同士はトレーナーの「能力」が強い方、スタジアムのフィールド効果は『固有』のフィールドに上書きされる）は [turn-order.md](turn-order.md)（補足: ユーザーより）（出典: 404, 405）

### スタジアムのフィールド効果

- T終了時に動くスタジアムのフィールド効果は、T終了時の最後の最後に発動する（『輪廻』などを除く）
- 《マサゴスタジアム》: 場にいる「水」「地」タイプは相手からの能力減少を無効にする
- バトルルーレットのランダムな能力変化をうまく利用するには、多少の能力低下を受けても押し切れる“ポケモンの自力の差”が要る（カズマ）。（出典: 178）

### フィールド形成（出典: 189, 190, 191）

- 『固有』でスタジアムのフィールド効果を上書きすることを「フィールド形成」と呼ぶ
- 後出しが有利: フィールド形成は、同時発動を除いて原則後出しが有利（「後出しの原則」）。『異界のヌシ』は上書きされても出ればまた塗り替える。塗り替えても相手が恩恵にあずかることもある（519）
- 《緋想天/ワンダフルヘブン》: 「統率」によるフィールド形成
- 「宙に浮いている相手に命中する」効果: 浮きを無視し、「飛」タイプにも等倍で当たる
- 《夢幻漆黒空間/シャルノス》: 強制交代を受けず、変則的に場に出ると「死のカウント」4
- 《電撃領域／サンダーコロッセオ》: 3の倍数のT、全員が一番最後に「かみなり」を撃つ
- フィールドの「かみなり」も「次に繰り出す技」に数えられる
- 《幻想古代時空/ルドラサウム》: エールの第三『固有』。「プレート」持ちに『オールドタイプ』と全能力1.15倍、稀に「さばきのつぶて」の追加行動。相手にも作用する（519）
- 相手の「かみなり」は地面タイプには無効で、地面タイプ側も自分の「かみなり」を撃てる（T3でガブリアスがマニューラを倒した）。（出典: 191）

### 技・特性のフィールド

- 「グラスフィールド」の回復は実機どおりで、宙に浮いているポケモン（ひこうタイプの瑞鶴など）には入らない（補足: ユーザーより）。（出典: 140）
- 特性「エレキメイカー」は、場に出た時、5Tの間、全体の場を「エレキフィールド」にする（「電」技1.3倍。下の「特性」）。（出典: 159）

### オリジナルの状態変化

| 火の海 | 「炎」タイプ以外のポケモンがT終了時に1/8のダメージを受ける。クッパの『大王亀の爆炎』で2T（出たTは事実上不発で、実質は次の1T）（天花。出典: 267） |
| 迎撃 | 相手の技のダメージに1/2の反動ダメージをつける。一度攻撃技を受けるとそこで切れる（アールカンバー。出典: 346） |

| 状態 | 効果 |
| --- | --- |

### 「あばれる」状態

- 「あばれる」「げきりん」「だいふんげき」「はなびらのまい」などで入る
- 「あばれる」状態のポケモンは指示を受け付けないので、『指令』も効かない
- このスレでは、「あばれる」状態は2Tを完遂しないと「混乱」にならない（マリルリのメタ発言）
- 450では、2T目の「げきりん」が『かわせ！』で回避されて「あばれる」状態から解き放たれた（「混乱」の表示はない）。（出典: 450）

### T制限付きの状態異常

- T制限付きの状態異常（「混乱」を除く）は、交代するとカウントが消えて治らなくなる

### そのほかの状態

- 「**呪い**」状態: T終了時に体力の1/4のダメージ（169のヤマト）。（出典: 169）
- 「眠気」状態: 《ズイスタジアム》の効果で入り、次のT終了時に眠る
- 「テレキネシス」状態: こちらの技が必中になり、相手が宙に浮く
- 「死のカウント」: 「ほろびのうた」などで付き、T経過で1ずつ減る
- 「くろいまなざし」状態（メアリ）: 通常交代ができなくなる
- 「**しめつける**」状態: 405のコカライアの『縛蜥蜴の呪縛』（2Tの間）は、実質的に相手に1/8の時間差ダメージで、2T目は先に解除される（カズマ）。（出典: 405）
- 「**しめつける**」状態や「くろいまなざし」状態の基本の仕様は [pokemon.md](pokemon.md) の「状態」。「みらいよち」状態は上の「技の処理」。

### 宙に浮かび上がる

- 特性やポテンシャルでつく効果。状態変化の扱いに近い。発動するときはメッセージに表示される。
- この効果による「地面」技の無効化は防護に当たらない。防護特性や防護ポテンシャルを無視する効果でも貫通されない。
- 特性「ふゆう」は実機と違い、場に出ると表示される。特性「かたやぶり」などでも無視されない。
- そのほかの仕様は、ポケモンwikiの「地面にいる」を参照。

## ポテンシャルの個別の仕様

### 『ストーキング』

- 専用ポテンシャルの型の一つ。原典では112で初めて出た（「○○○専用ポテンシャル。『エース』が場に出た時、味方と任意交代して場に出ることが出来る」）。『キラー』『チェイサー』が覚えることが多い。（出典: 112）

- 『金冠サイズ』のポケモンには『オールドタイプ』が効かない（311）
- メガシンカ同士が向かい合うと、お互いの『オールドタイプ』無効化で打ち消し合う

### 『メガシンカ』

- 「メガシンカ」の仕組みは species.md の「メガシンカ」を正とする

## 持ち物

→ [詳しい中身](battle-rules/持ち物.md)

- 持ち物の効果は、基本的に実機と同じ。ただし、スレでの仕様変更やポテンシャルとの兼ね合いで勝手が違うこともある。
- 「わざマシン」も「もちもの」に分類される（[pokemon.md](pokemon.md) の「わざマシン」）。
- **同じ持ち物はチームで1つまで**（1種類1個。補足: ユーザーより）。マントやタスキを誰に持たせるかが、戦闘準備の読み合いになる。

### もちものセット

- カズマの最初の持ち物は、アカネとゼットンの餞別の「もちものセット」（第八世代基準）
- 121の通達: 新しい持ち物と技の分類変更。カズマは「もちものセットVer.2」を入手
- **一部の''古代種''だけに効く持ち物**（399、オシュトル）: 「ふといホネ」（ガラガラ）、「でんきだま」、「ながネギ」など。ガラガラは「ふといホネ」の時に働く種属『骨殻獣の〜』を持つ。（出典: 399）

### 個別の持ち物の仕様

- **こだわりハチマキ**: 自分の「防」の値でダメージを計算する技には効果がない。
- こだわりスカーフ: 技が固定されても、交代すれば解除されて別の技を選び直せる
- **こだわりと技能拡張**: 「技能拡張」を使っても「こだわり」には縛られない。ただし、一度でも覚えている技を使えば、「技能拡張」も使えなくなる。
- **とつげきチョッキ**: 急所で貫通される。
- きれいなぬけがら: 「かげふみ」などで交代を封じられても、離脱して交代できる
- **ゴツゴツメット**は、クロコダインの『獣王鰐の戦斧』（威力120以上の技が命中した時、相手の持ち物を破壊）で壊された。（出典: 465）
- **ひかりのねんど、あついいわ、しめったいわなど**: ポテンシャルには効果がない（技と特性だけ）。
- クリアチャーム: 相手からの能力の減少を無効にする
- だっしゅつパック: 自分の能力が下がると自動で交代する
- レッドカード: 持ち主が攻撃を受けたあと場に残っていないと発動しない（瀕死でも出ない）
- とくせいガード: 124〜125の練習試合で初めて実戦に出た
- ものまねハーブ: 登場時に能力が上がる『トップバッター』や『エース』と対面すると要注意
- 持ち物を壊す・変える効果: 持ち物が効果を出す前に壊したり変えたりする。場に出た時に相手の持ち物を「技マシン：ゆびをふる」に変える専用もある（507）
- プレート: 「なげつける」でプレートを投げると威力90
- 特性「きんちょうかん」を持つ相手の前では、きのみやわざマシンなど消費する持ち物が使えない

### 作中に出た持ち物（ジム巡り〜練習試合のころ）

- きあいのハチマキ、オボンの実、ノーマルジュエル、きょうせいギプス
- それ以降の各試合の持ち物は [バトル記録](../story/battles.md) と各キャラのファイル。
- 持ち物がどのくらい使われているかの集計（相手チームとカズマのチームを分けたもの）は [持ち物の使われ方](items-usage.md)。

## 特性

→ [詳しい中身](battle-rules/特性.md)

### 特性の決まり

- **タイプによる特性の無効は第五世代仕様**。「ゴースト」タイプも「かげふみ」で交代を縛れる。（出典: 071）
- 能力を下げられた時の特性（「まけんき」「クリアボディ」など）は実機よりパワーアップしている:
  - 「まけんき」: 相手に能力を減少・低下させられた時、自分の「攻」がぐーんと上がる
  - 「クリアボディ」: 相手からの能力減少（低下）を無効にする（実機よりパワーアップ）
  - 「火傷」「麻痺」などの**状態異常による能力の低下は**、「まけんき」や「クリアボディ」の対象外（エレン）。（出典: 245）
- 「いかく」と「まけんき」: 両方を1T「きょううん」にすると、戻った時に「まけんき」が反応
- 特性のコピー（「かがくのちから」など）や、特性と『役割』の順番は [turn-order.md](turn-order.md)。特性を『三角効果』から守る「とくせいガード」は上の「持ち物」。
- 第九世代の特性（「おうごんのからだ」「ふくつのたて」など）の特集本の話は、上の「技の処理」の「第九世代の技・特性」。

## 協会のレギュレーション

→ [詳しい中身](battle-rules/協会のレギュレーション.md)

- 「みちづれ」を持つポケモンは、1チームに1体まで。（出典: 122）また、相手が最後の1体の時は「みちづれ」を使えないのが全体の原則のレギュ（作者。ルサルカの『水魔女の心中』の話で。出典: 525）
- 『輪廻』や『旋回』を持つポケモンは、レギュレーションで自前の「まもる」を持てない
- 完全な受け構築は、レギュレーションで禁止されていると思われる（ユーザーの見立て）
- 種属ポテンシャル（「〇〇の〇〇」）は、効果を被らせてはいけないらしい（補足: ユーザーより）
- 確定急所の攻撃技: 《神羅ソルジャーズ》はこれにレギュレーションがかかっているらしい
- 協会が勧める「もちものセット」は上の「持ち物」。

## 【H】（ホーム）補正

- 大会の勝敗が同点のときは、地元チーム（【H】）が上位。それ以外の場合は、直接対決の勝者が上位。（出典: 061）

## 本文の表記

→ [詳しい中身](battle-rules/本文の表記.md)

- 作者が処理を間違え、数ターンあとに訂正して特殊裁定になることが稀にある。その場で巻き戻してやり直すこともある（516）
- 試合の最序盤、サポート効果の表示の間に、相手チームの1体の台詞がカットインで入る
- 原典のバトルの表示では、火傷の半減などの補正の表記が、ちょくちょく省かれることがある（補足: ユーザーより）。表示がなくても、条件がそろっていれば補正はかかっているものとして読む。
- やることが分かりきっているTは、作者が安価を取らずに安定行動で進めることがある

## 読者の安価の決まり方（補足: ユーザーより）

→ [詳しい中身](battle-rules/読者の安価の決まり方.md)

- カズマ側の行動は読者の安価で決まる
- 「下3」は安価のレスから3つ目のレスを採用する、掲示板の安価の普通の決まり（多数決ではない）
- 選ばれやすいのは、全体的に丸い選択肢。リスクが大きくリターンもある手は採用されにくく、安全策でも失敗が起こりうる手（命中不安など）は嫌われやすい。
- どう転んでも場を荒らせる運任せの手は、リスクと見なされず、わりと採用される
- 「おまじない」（急所を防ぐ）は、一手損してでも、そのあとの読みを安定させる効果が大きい
- カズマの「指示：B-」は、この協議制の安価で勘違いやミスが出たり、意見が割れたりすることを、カズマのミスとして落とし込んだもの（→ [trainer-stats.md](trainer-stats.md)）。
