# 地方ごとのまとめ

シンオウとほかの地方について、分かっていることを地方ごとに集めた入口のページ。細かいことはリンク先のファイルに任せ、ここには地方の単位で見た要点だけを置く。

## 八大地方と各地方のイメージ

- 世界には「**八大地方**」があり、シンオウはその一つ。世界で一番栄えた地方というわけではないが、なぜかそう呼ばれている。（出典: 002）
- どの地方が八大なのかは、原典ではまだはっきりしない（シンオウとカントー以外は不明）。→ [未確定事項](../open-questions.md)
- プロデューサーの見た各地方のイメージ。シンオウは地味だがリーグは強い → [根拠](regions/根拠/001_八大地方と各地方のイメー_テレビコトブキのプロデュ.md)
- 各地方には、その地方を代表する大企業（地方最大企業）がある: カントーのシルフカンパニー、アローラのエーテル財団、ホウエンのデボン、シンオウのギンガ団。（出典: 274）
- 地方ごとの伝説の違いは地方の特色で、地方の格差やバトルの優劣につながるものではない（天花） → [根拠](regions/根拠/002_八大地方と各地方のイメー_地方ごとの伝説の違いは地.md)
- ジムリーダーの''地方対抗ジムリーダー交流戦''がある（カントーは基本強い）。（出典: 276）
- 第三節のあと、シンオウで''地方対抗交流戦''。カントー・イッシュ・ガラルは参加、アローラは難航（502） → [根拠](pro-league/根拠/129_地方対抗交流戦502_来る顔ぶれと地方ごとの状況.md)
- 関連資料: 地名・施設、伝説、リーグ制度、ダンジョン、ほかの地方の人物 → [根拠](regions/根拠/003_八大地方と各地方のイメー_関連placesmd地名.md)

## シンオウ地方

物語の舞台。ここは地方の単位の要点だけにする。
- 特色・イメージ:
  - アルセウスの「お膝元」。霊峰テンガン山が地方を東西に分ける。（出典: 000, 001）→ [places.md](places.md)
  - ほかの地方より地味で、地方内にも分断がある（キッサキは陸の孤島で豪雪地帯）。（出典: 255）大きな悩みの一つは''交通の便''（天花）。（出典: 297）
  - 天花いわく、シンオウはどちらかというとアローラ側（田舎）のグループ。''試される大地''とも呼ばれる。（出典: 297, 298）
  - 地下には地方全域をつなぐ「**地下大洞窟**」がある。（出典: 009, 094）→ [dungeon.md](dungeon.md)
  - 超古代の名は''ヒスイ''。リージョンフォームのようなポケモンの化石や痕跡も見つかっている（フリット）。（出典: 299）
  - 地方最大企業はギンガ団で、宇宙エネルギー開発では全地方で最高峰。（出典: 274）→ [ginga-dan.md](ginga-dan.md)
- 伝説・神話:
  - シンオウの伝説種は3体のドラゴンと、万物を司る創造神（マックイーン） → [根拠](regions/根拠/010_シンオウ地方_シンオウの伝説種は3体の.md)
  - 創造神アルセウスを今の時代に見た人はいないとされる（カズマは会っている） → [根拠](regions/根拠/011_シンオウ地方_創造神アルセウスは神話の.md)
  - 神話は時間・空間・物質と、スケールが大きく格が高いイメージ。''伝説や幻''と呼ばれるランクの''古代種''が多いイメージもある（天花）。（出典: 391）
  - 湖の3体: シンジ湖のエムリット（感情）と、リッシ湖・エイチ湖の意思と知恵 → [根拠](regions/根拠/013_シンオウ地方_湖の3体シンジ湖に感情を.md)
  - 序盤のジム戦に必ず出る「十八竜」（ドラゴンタイプの一群）→ [species.md](species.md) の「十八竜」（出典: 014）
  - キッサキ神殿には「巨人の始祖」とも言われる怪物の伝説がある（ライザ）。（出典: 216）
- リーグ:
  - チャンピオンは**ホーネット**（3連覇中、カンナギタウンのチームの監督）。先代チャンピオンはギンガ団社長の**アダム・ヴァイスハウプト**（アカギ）。（出典: 000, 005, 044）
  - 四天王はリーグ所有の4チーム: 煉獄（ほのお）、さみだれ（地）、クロロ（むし）、アムロ（超） → [根拠](regions/根拠/017_シンオウ地方_四天王ポケモンリーグ所有.md)
  - 昨季の本戦（シンオウの現5強）: 1位ホーネット、2位煉獄、3位ジュピター、4位テレビコトブキのチーム（アバン）、5位ミオ図書館のチーム（小鳥遊ホシノ）。（出典: 005, 039, 094）
  - ジムリーダー8人。エネル、ロビンマスク、イングリッドが「シンオウ三強」 → [根拠](regions/根拠/019_シンオウ地方_ジムリーダー8人ハクタイ.md)
  - 『異界のヌシ』の持ち主（アカギ、エネル、ジュピター、クロロなど）→ [dungeon.md](dungeon.md) の「異界」（出典: 391）
  - プロトレーナーの文化はガラル発祥で、その影響が大きい。（出典: 001, 165）
  - バトルの祭典''バトルフロンティア''（ファイトエリア）があり、ほかの地方のチームも来る。（出典: 161）→ [pro-league.md](pro-league.md)
- ダンジョン・名所:
  - 最大のダンジョンはテンガン山。深度5があるのはシンオウでここだけ → [根拠](regions/根拠/023_シンオウ地方_最大のダンジョンはテンガ.md)
- カズマとの関わり:
  - カズマはアルセウスにテンガン山へ落とされ、シンオウで暮らしている。→ [kazuma.md](../characters/trainers/kazuma.md)（出典: 000, 001）

## カントー地方

- 特色・イメージ:
  - 「**はじまりの地方**」。八大地方の筆頭とも言える。（出典: 002）
  - 観光地に大都市ヤマブキとタマムシ、サファリパーク、オツキミ山、ナナシマなど（ウタ）。（出典: 271）
  - ヤマブキに全地方でも最上位の超巨大企業''シルフカンパニー''の本社がある（いくつかの強豪チームを持つ）。（出典: 274）
  - 伝説の名を襲名する儀礼がある → [根拠](regions/根拠/028_カントー地方_伝説の名を襲名する儀礼が.md)
  - 伝説のトレーナーへのリスペクトが強く、ジムリーダーや四天王の権威もシンオウより強いかもしれない（ライザ）。全国でも常に強豪と呼ばれる地方。（出典: 276）
  - むしタイプの苦難の歴史の始まりの地（クロロ）。''トキワの森のスピアー''の本がある。（出典: 389）
  - ピカチュウは''古代種''扱いで、トキワの森の「深度：1」に生息している。（出典: 002, 275）
- 伝説・神話:
  - サンダー、ファイヤー、フリーザーと、幻のミュウ（すべてのポケモンの祖とも） → [根拠](regions/根拠/032_カントー地方_サンダーファイヤーフリー.md)
  - ''ミュウツー''は人の叡智と欲望が生み出した古代の怪物で、''151匹のうち、いつしか秘匿された存在''（作者の地の文）。四天王の真冬すら知らない。（出典: 278）
  - フリーザーは四天王の桐須真冬の手持ち。ファイヤーの伝説はともしび山とチャンピオンロードに残る。（出典: 277, 278）→ [species.md](species.md)
- リーグ:
  - ''セキエイ高原''がポケモンリーグ協会本部（聖地にしてバトルの殿堂）。四天王とチャンピオンの制度はカントーから各地方に伝わった。（出典: 276, 287）
  - チャンピオン（''レッド''）は**赤司**。（出典: 275, 276, 290）
  - 四天王は「氷」「闘」「霊」「龍」。筆頭は龍王ワタル（海馬瀬人） → [根拠](regions/根拠/037_カントー地方_四天王は初代にちなんだ氷.md)
  - 筆頭のワタルは、シンオウの地方対抗交流戦に来ると（勝手に）宣言している。（出典: 502）
  - ジムリーダーにトキワの白石（グリーン、カントー最強）、ラクサス、竜宮レナ → [根拠](regions/根拠/038_カントー地方_ジムリーダートキワの白石.md)
  - 「B」中位に白石の元門下生、天子の《常盤ヘブンアース》。（出典: 291）
  - → [others.md](../characters/trainers/others.md) のカントー地方
- ダンジョン・名所:
  - 「深度：5」の【終局封鎖異界''ハナダの洞窟''】（''地獄の穴''。「深度：4」と「深度：5」しかない、全国的に異質なダンジョン）。（出典: 278, 282）
  - ほかに深度4のチャンピオンロード、むじん発電所、ともしび山、アスカナ遺跡など → [根拠](regions/根拠/042_カントー地方_ほかにチャンピオンロード.md)
  - 街・名所はクチバ、ヤマブキ、トキワ、ハナダ、シオン、ナナシマなど → [根拠](regions/根拠/043_カントー地方_街・名所クチバサントアン.md)
- カズマとの関わり:
  - カズマはカントー好き（初代勢で、魂の故郷はカントー）。（補足: ユーザーより）
  - 271〜295でアカネのカントー出張にくっついて旅行した → [根拠](regions/根拠/045_カントー地方_271〜295でアカネの.md)
  - ともしび山の『原始天賦』のヒトカゲが11体目の手持ちになった（今はリザードン） → [根拠](regions/根拠/046_カントー地方_ともしび山の原始天賦のヒ.md)
  - 帰りの船でマサラタウンのことを思い出して絶叫し、アローラでも落ち込んでいた（推測: 行きそびれたことを悔やんでいる）。（出典: 295, 296）

## ジョウト地方

- 特色・イメージ:
  - 「独自の文化を築くジョウト」。（出典: 255）
  - 有名なポケモン競技「**ポケスロン**」がある。（出典: 053）
  - 虎柄の野球チーム「**エレブーズ**」がある。（出典: 010）
  - エンジュシティには、ポケモンバトルもしない名家（禪院家）がある。（出典: 021）
  - 水の都''アルトマーレ''は有名な観光スポット。ほかに''シント遺跡''、キキョウシティのスクール。（出典: 273, 389）
- 伝説・神話:
  - ''古代種''の**ルギア**（ホシノの『二枚看板』）はジョウトの''うずまき島''を展開する。（出典: 389）
  - ''アサギの灯台''と縁のある古代種の末裔がいる（ベルナデッタのデンリュウ）。（出典: 197）
  - アサギの灯台のチーム《灯台カレイドスコープ》（ジョウトの「B」）と練習試合で勝ち、賭けで「キングシールド」を得た → [根拠](regions/根拠/055_ジョウト地方_アサギシティの“アサギの.md)
- リーグ:
  - カントーの四天王とのつながりが深い（初代ワタルはジョウト出身で四天王の筆頭）。カントー四天王のBDやSPには''チョウジタウン''の出身者が多い。（出典: 276）
  - 今のワタルもフスベシティの''りゅうの穴''の修練場で修行した。（出典: 286）
- ダンジョン・名所:
  - 「深度：5」の【白亜銀嶺領域''シロガネ山''】（「地獄につながっている」とも。「深度：1」の時点から環境がヤバい）。（出典: 099, 278, 282）
  - キキョウシティの近くの''リザフィックバレー''は、リザードン使いの聖地（過去に何度も『天賦』のリザードンを輩出）。（出典: 281, 389）
  - ''うずまき島''、''スリバチ山''（修行の場）。（出典: 316, 389）→ [places.md](places.md)
  - “スズの塔”: ジョウト屈指の歴史を持つダンジョン。「深度：4」の金髪の「亜人」に噂（501） → [根拠](dungeon/根拠/091_ジョウトのダンジョン_スズの塔.md)
- カズマとの関わり:
  - 同期の禪院直哉はエンジュの名家の出身。→ [naoya.md](../characters/trainers/naoya.md)（出典: 020, 021）
  - エールは273〜322にジョウトへ修行に行った。→ [ail.md](../characters/trainers/ail.md)（出典: 273, 322）
  - 白石はレッドとの戦いのためにリザフィックバレーで修行した。カズマもリザードンのためにミオ図書館でリザフィックバレーを調べた。（出典: 281, 389）
  - カズマはナナシマやジョウトのことは知らない。（補足: ユーザーより）

## ホウエン地方

- 特色・イメージ:
  - 「自然豊かなホウエン」。（出典: 255）
  - 海が多く、「KAN-SEN」種や「艦娘」種がたくさんいる。（出典: 030）
  - ポケモンのお菓子「**ポロック**」がある。（出典: 010）
  - 自分だけの秘密基地を作る「**ひみつきち**」の文化がある（カズマは森の洋館をひみつきちにした）。（出典: 127, 128）
  - 地方最大企業は''デボン''。（出典: 274）
- 伝説・神話:
  - ''グラードンの爪''（ホウエンの"伝説"の肉体の一部とされる）がエニシダのコレクションにあり、ライナーがボディビル大会で手に入れた。（出典: 172）
- ダンジョン・名所:
  - 「深度：5」の有名所に''かいてい洞窟''（超古代ポケモンが生息した海底火山）。「深度：4」の『ヌシ』もヤバいらしい。（出典: 282）

## イッシュ地方

- 特色・イメージ:

  - 「カセット」は大昔にイッシュで開発されたと言われる（天花）。（出典: 355, 357）
  - サザンドラはイッシュ原産の''古代種''（600族）。（出典: 172）
  - 推測: 大昔にどこかの地方にあった、ポケモンの''解放活動''の団体（シア）は、原作のプラズマ団か。（出典: 225）
- ダンジョン・名所:
  - ヤグルマの森（深度2のヌシだったドボルベルクは、今はカタリナの手持ち） → [根拠](regions/根拠/077_イッシュ地方_ヤグルマの森深度：2のヌ.md)
- リーグ:
  - 「B」ルーキーにジークの《双龍ファフニール》（第一節はイッシュの「C」） → [根拠](regions/根拠/078_イッシュ地方_Bルーキーにジークの《双.md)
- カズマとの関わり:
  - バトルフロンティアでジークの《双龍ファフニール》と練習試合をして4-0で勝った。（出典: 172, 177）

## アローラ地方

- 特色・イメージ:
  - 「南の楽園アローラ」。''4つの自然島と巨大な人工島''からなる南国の観光地。（出典: 255, 296）
  - 大昔から''ライドポケモン''（リザードン、ケンタロスなど）の文化が残る。（出典: 296）
  - 流行は他の地方より遅れていて、お年寄りが自然破壊を嫌うので工場や企業の誘致は進まない。''インター・ネット後進地方''。（出典: 297, 301）
  - 地方最大企業は''エーテル財団''（総帥は今代の''ルザミーネ''）。ウルトラホール（かつて生まれた時空の歪み。今も稀に観測される）を研究している。（出典: 119, 274, 299）
  - ''リージョンフォーム''の研究の地（初代''ナリヤ・オーキド''が研究のために来た）。アローラのナッシー（''ナッシー・アイランド''）など。（出典: 298, 299）
  - ''ヌシ''という言葉はアローラ発祥という説もある。（出典: 297）
- 伝説・神話:
  - ''太陽と月の伝説''と''4つの島の守り神''（カプ）。（出典: 391）
  - 守り神はアーカラ島がカプ・テテフ、メレメレ島がカプ・コケコ（今はエネルの手持ち） → [根拠](regions/根拠/093_アローラ地方_アーカラ島はカプ・テテフ.md)
  - クロロの手持ちに''ウルトラビースト''がいる（推測: アローラ由来か）。（出典: 389）
- リーグ:
  - 人口の問題で規模が小さく、風習が強い。本拠地は''ラナキラマウンテン''のてっぺん。リーグはエーテル財団の拠出が大きい。''島巡り''の風習も残る。（出典: 290, 296）
  - 四天王は各島の''島キング''・''島クイーン''（「闘」「岩」「飛」「地」）。今は4人中3人が島クイーンで、アーカラ島の**ボア・ハンコック**が「岩」。（出典: 297, 298）
  - ジムリーダーの代わりにキャプテンが8人（「ノ」「水」「炎」「草」「電」「霊」「妖」「虫」） → [根拠](regions/根拠/097_アローラ地方_ジムリーダーの代わりにキ.md)
  - エーテル財団の《神代エーテリオンズ》が昨年アローラ2位。（出典: 187）
  - シンオウの地方対抗交流戦への参加は難航しそう（プロデューサー。価値観の問題なども）。（出典: 502）
  - → [others.md](../characters/trainers/others.md) のアローラ地方
- ダンジョン・名所:
  - 「深度：5」まである''ポニの大峡谷''（ポニ島。「深度：4」を2つ持つらしい）。（出典: 282, 297）
