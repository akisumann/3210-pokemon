# 迷いやすいところ: 「込みの速さ」はその瞬間の速さ

- **「込みの速さ」はその瞬間の速さ**（補足: ユーザーより）: 比べるのは、その処理の時点ですでにかかっているものだけ。たとえば特性「ひでり」は『二枚看板』（『役割』）より先に動くので、場に出た時の順番を決める段階では『二枚看板』の速さの強化はまだ当てにできない。一方、『パンプアップ』のように種族値そのものを上げるもの（戦闘の外の、ふだんの時点で上がっているもの）は、最初から計算に入る。

- 原典の System 表示の順番は、これと合わないことがある（ユーザーより、2026-10-22: 作者はゲームによほど影響しない限り、表示の順番をあまり気にしない）。表示の順番は処理順の根拠にしない。「ひでり」と『二枚看板』は、363では「ひでり」が先、269・365では『二枚看板』が先に表示されている。
