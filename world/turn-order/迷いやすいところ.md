# 迷いやすいところ

- **死に出しは次のT開始時**: 倒れたポケモンの代わりが出るのは次のTの開始時。倒れたTのT終了時に相手を対象にする効果は、相手がいないので意味がない。一方『凱旋』系の交代は「相手を倒した」ことに関連して動くので、攻撃し合っているフェイズの途中で起きる。ただし下がるのはその瞬間で、後続が出るのは次のT開始時（相手の死に出しと同時）。そのTの残りの間、その枠は空になる。なので『凱旋』でも、「先に場で待ち構える」もの（『エイヴィヒカイト』など）は相手の死に出しに間に合わない（137と同じ）。また、『凱旋』『旋回』『輪廻』で下がったあとに出てくる後続は**死に出しではない**ので、『アヴェンジャー』や「かがくのちから」などの死に出し系は発動しない。（補足: ユーザーより）

（出典: 137, 374）

- **特性のコピー**: 「かがくのちから」などで特性をコピーしたら、**コピーした特性がその時点で発動できる条件を満たしていれば発動する**、と扱う。たとえば死に出しで「ふくつのたて」（場に出た時、「防」が上がる）や「ひでり」をコピーすれば、その登場で発動する。「コピーして、発動できるなら発動する」までが「かがくのちから」という1つの特性の処理なので、**ワンテンポ遅れない**（共通のルール4の「〇〇が発動した時」には当たらず、特性の順番でそのまま動く）。（補足: ユーザーより）一方、『禍斑鳩の術式』（「かがくのちから」の発動時に体力を1/4回復）は「かがくのちから」の発動をきっかけにするので、ワンテンポ遅れる。（補足: ユーザーより）

（出典: 360, 397, 420）

- **「タイム」は指示の途中**: 指示の最中に時を止めて相談するイメージなので、「タイム」のあとで指示や『指令』を出せる（補足: ユーザーより）。交代を指示したTの「タイム」の効果は、交代前のポケモンに入る。（出典: 200）

- **T終了時の中の順番**（ユーザーの見立て。補足: ユーザーより）:
  1. 毒・火傷・「アクアリング」など、T終了時のダメージや回復（実機と同じく順番が決まっているものが多い）。同じものは速い順。
  2. T終了時に動くスタジアムのフィールド効果（《フタバスタジアム》の回復など。T開始時のものや常時のものは別。ほかよりは遅め。314のライナー「フィールド効果の発動は、『輪廻』なんかを除けば最後の最後」）。
  3. 『輪廻』『旋回』などのT終了時の交代。その手のダメージや回復が全部終わってから発動する（後続は次のT開始時に出る）。

（出典: 311, 314）

- **「込みの速さ」はその瞬間の速さ**（補足: ユーザーより）: 比べるのは、その処理の時点ですでにかかっているものだけ。たとえば特性「ひでり」は『二枚看板』（『役割』）より先に動くので、場に出た時の順番を決める段階では『二枚看板』の速さの強化はまだ当てにできない。一方、『パンプアップ』のように種族値そのものを上げるもの（戦闘の外の、ふだんの時点で上がっているもの）は、最初から計算に入る。

- 原典の System 表示の順番は、これと合わないことがある（ユーザーより、2026-10-22: 作者はゲームによほど影響しない限り、表示の順番をあまり気にしない）。表示の順番は処理順の根拠にしない。「ひでり」と『二枚看板』は、363では「ひでり」が先、269・365では『二枚看板』が先に表示されている。

- **最後の1体同士が同時に倒れたら**: 実機どおり（補足: ユーザーより）。このスレの技の処理は第五世代までの実機が基準なので、たとえば「だいばくはつ」「じばく」のような自分も倒れる技は使った側の負け、反動技（「すてみタックル」など）の反動で両方倒れたら使った側の勝ち、になると見られる（実機の仕様の当てはめ。推測）。

- **追加行動と追加攻撃**: 追加行動は技を選べる（効果文に条件があればその範囲で。『リザードナイトY』なら「炎/飛」技）。追加攻撃は、直前に出したのと同じ技をもう一度繰り出す。（battle-rules.md、補足: ユーザーより）

（出典: 124, 371）

- **メガシンカは遅め**: 「メガシンカ」をする『専用』（『天衣無縫の焔の翼』「T開始時、自身を「メガシンカ」させることが出来る」など）は、データの並びで下の方（専用）にあるので、同じタイミングの中では遅めに動く（ユーザーの見立て。補足: ユーザーより）。メガシンカでつく種属・特性（『超炎龍の覚醒』や特性「ひでり」）は、メガシンカしたあとで動く。

（出典: 371, 384, 419）

- **すぐ出る交代と、次のT開始時に出る交代**: 「とんぼ」技の交代は**その場ですぐ出る**（相手の攻撃も考えて使うものなので、交代先がその場で相手の攻撃を受ける）。『凱旋』の後続は、相手も倒れていていないので、次のT開始時に出ても困らない。（補足: ユーザーより）

- **「場に出て〇T目」の数え方**: 場に着地したTを1T目、その次のTを2T目と数える。Tの途中で通常交代や「とんぼ」技で出てきても、そのTが1T目。死に出し（次のT開始時に出る）なら、出てきたそのTが1T目。（補足: ユーザーより。『禍斑鳩の旋回』「場に出て2Ｔ目のＴ終了時」など）

（出典: 056, 374）

- **ポテンシャルの細かい扱い**（補足: ユーザーより）:
  - 「1/試/自動」は条件を満たしたら必ず発動する。「自動」のない「1/試」（『ベテラン』など）は、トレーナーが使うタイミングを選べる。
  - メガシンカ同士が向かい合うと、『メガシンカ』の「相手の『オールドタイプ』を無効化する」でお互いに打ち消し合い、どちらの『オールドタイプ』も効かなくなる。
  - 「場を離れる時」系（『エンチャンター』など）は、倒れて場を離れる時にも発動する。
  - 「相手を倒した時」系（『凱旋』『氷狼娘の勝鬨』など）は、攻撃で倒した時だけ。毒・火傷・設置技・相手の反動などで倒れた場合は発動しない。
  - 交代して場を離れると、ランクの上昇も強化（『二枚看板』の1.33倍など）もリセットされる。場に出直したら『役割』などは再発動する。
  - 「1/試」と書かれていない『固有』（カズマの『この素晴らしい仲間に祝福を！』など）は、条件を満たすたびに何回でも発動する。
  - 天候などの「@5T」は、変わったそのTを1T目と数える（場に出た時の数え方と同じ）。
  - 「火の海」（『超炎龍の獄炎』で敵陣にかかる）は、T終了時系のダメージ。実機のキョダイゴクエンの「残り火」のようなもので、原典でも「「炎」タイプ以外のポケモンがT終了時に1/8のダメージを受ける状態」と出ている（クッパの『大王亀の爆炎』、267, 268）。
  - **フィールドのかち合い**: トレーナーの『固有』で張るフィールド（《夢幻漆黒空間/シャルノス》《電撃領域／サンダーコロッセオ》など）がかち合ったら、『固有』の強い方、いわゆるトレーナーの「能力」が強い方が制する。スタジアムのフィールド効果は、『固有』のフィールドが張られると上書きされる。（補足: ユーザーより）
  - **「必ず」は強い**: 交代封じ（「かげふみ」など）と「必ず交代できる」（天花のSP《戦場に舞う天御鳥命》、『エキスパンション（霊）』など）がかち合ったら、「必ず」の方が勝つ。必ずだから。（補足: ユーザーより）実戦の例: 489で天花のサポート効果《戦場に舞う天御鳥命》の「テレポート」が《異界/もどりの洞窟》の交代制限を抜けた（出典: 489）。
  - 『ド根性』（中確率で相手の攻撃以外のダメージを無視）は、「ステルスロック」などの設置技や毒・火傷のダメージも無視できるが、自分の代償（『歴戦の古傷』の反動、反動技、「いのちのたま」など）は無視できないらしい。

（出典: 268, 489）

- **天候のかち合い**: 同じタイミングで天候を変えるものが重なったら、速い順に処理するので**遅い方が勝つ**（最後に変えた天候が残る）。また、「ひでり」のように一度天候を展開するだけのものより、「そのポケモンが場にいる限り雨になり続ける」のような**場にいる間ずっと天候を固定するもの**の方が強い（ボルトロスの専用『雷鳴轟く暴風雨』など）。（補足: ユーザーより）

（出典: 308, 317）
