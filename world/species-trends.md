# 種族ごとの傾向（AIの集計）

原典の図鑑に出た個体を種族（系統）ごとに集め、種族値・タイプ・技・役割・育ち方の傾向をAIがまとめたもの（2026-10-13〜14の会話で、ユーザーの頼みで作った）。個体の数は資料に出てきた分だけで、世界の中の数ではない。傾向の「N体中M体」は、根拠の表の各個体の最後の図鑑で数えたもの。「まとめ」と、比較表の「相性のいい型」「一言」は推測。体力は図鑑に出ないので `hp-estimates*.md` の推定。種族そのものの設定は [種族・系統](species.md)。

## 種族ごと

- ウマ娘: 速さA〜AA+、防C前後の物理型（特殊の攻撃技はない）。しんそくの適性があり、育成と相性がいい → [根拠](species-trends/根拠/01_ウマ娘.md)
- ストライクウィッチーズ: 5体ともひこうの速い特殊型（ミーナは属が別だが「ウィッチーズ」種と呼ばれる）。3体は属で「おいうち」を受けない。防D以下が5体中3体（芳佳B、ミーナC）で、5体とも交代の仕掛けを持つ → [根拠](species-trends/根拠/02_ストライクウィッチーズ.md)
- ゾイド: 9体中7体がはがね（シールドライガーはでんき単）。速B以上の高速型5体と防A-以上の重装型4体に分かれ、新人から「B」まで全層にいる → [根拠](species-trends/根拠/03_ゾイド.md)
- デュエルモンスターズ: ドラゴン・はがねが多く（19体中11体）、遅めの高火力（防まで硬いのは19体中7体）。看板の7体は全員が異名と専用持ち → [根拠](species-trends/根拠/04_デュエルモンスターズ.md)
- モンハン: 体力と防が高く遅い大型。ドラゴンが最多。種族で『チェイサー』の適性があるとされ、要統率は大抵B以上（古龍はA） → [根拠](species-trends/根拠/05_モンハン.md)
- デジモン: 11体中9体は攻か特攻がA-以上（ケルビモンは両方A）で、体力は推定B前後以上。解析がらみが11体中9体で、『スカウター』は3体。主力は統率・育成型の下 → [根拠](species-trends/根拠/06_デジモン.md)
- 深海棲艦: 3体ともみず。ヲ級・レ級は攻A+以上の物理型、駆逐棲姫は特防型。種属は死がらみが多い。要統率A（図鑑は3体だけ） → [根拠](species-trends/根拠/07_深海棲艦.md)
- 艦娘・KAN-SEN: 10体ともみずで、7体が支援の役割。空母は防A以上の“バウンス”、駆逐艦は速A帯。はがね技が10体中9体 → [根拠](species-trends/根拠/08_艦娘.md)
- ロボット系: ガンダム・AS・KMFほか35体。物理寄り（25体）で、属は作品ごとに違う。属で指示を補うのは35体中5体だけ → [根拠](species-trends/根拠/09_ロボット.md)
- サーヴァント: 種族値はばらばら。22体中15体が相手の上昇を無視し、『サーヴァント』は指令で1試合1回伸びる → [根拠](species-trends/根拠/10_サーヴァント.md)
- 十八竜: 16体（近縁種2を含む）とも「〇〇/ドラゴン」かドラゴン単。防が特防より高い（11体）・速C+以下（10体）が中心で、AA帯の値はほぼない。対〇（11体）はどれも自分の弱点向け → [根拠](species-trends/根拠/11_十八竜.md)
- アラガミ: 7体とも攻か特攻の片方だけA-以上（物理3・特殊4）。属で「亜人」の技を低確率で半減する。『エース』『二枚看板』はおらず（ピターは『エンペラー』）、使い手6人は全員統率型 → [根拠](species-trends/根拠/12_アラガミ.md)
- 古代種（実機のポケモン）: 種族値は実機どおり（推測）で、技は4枠（46体中44体）。Lv70以上の37体中32体は『ポケパワー』・メガシンカ・伝承で全種族値を底上げ → [根拠](species-trends/根拠/13_古代種.md)

## 全体の見立て（推測）

- 要統率の低い強い種族はある（デジモンの多く、友好種、古代種の大半（統率Cで従う。出典: 011）。ゾイドのブレードライガーも要統率Cで、ウマ娘のマックイーンも要統率C（補足: ユーザーより））。統率型の強みは、モンハン・深海棲艦・アラガミ・古龍のような格が一段上の種族も使える上限の高さの方（アラガミの使い手は6人とも統率型）。
- 資料で数が少なく見える種族でも、世界の中では数が多いもの（スライム系、スペルカード持ちなど）がある（補足: ユーザーより）。
- 1チームに1体ずつ混ぜる種族もある。十八竜とアラガミは、図鑑のどのチームでも1体だけ。古代種も、資料には46体と多いが今は現代種より少なく、統一でなければ6体に1体いれば良い方と言われる（出典: 416）。
