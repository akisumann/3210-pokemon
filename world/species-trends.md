# 種族ごとの傾向（AIの集計）

## 種族ごと

- ウマ娘: 速さA〜AA、防C前後の物理型。しんそくの適性、育成と相性がいい → [根拠](species-trends/根拠/01_ウマ娘.md)
- ストライクウィッチーズ: 浮いた速い特殊型で、「おいうち」を受けない。防Dと脆い → [根拠](species-trends/根拠/02_ストライクウィッチーズ.md)
- ゾイド: ほぼ全員はがね。高速のライガー型と重装型の2系統。統率Cで全層にいる → [根拠](species-trends/根拠/03_ゾイド.md)
- デュエルモンスターズ: 竜と機械の重い高火力。エース・二枚看板に置かれやすい → [根拠](species-trends/根拠/04_デュエルモンスターズ.md)
- モンハン: 体力が高く重い。『チェイサー』が多く、要統率は高め → [根拠](species-trends/根拠/05_モンハン.md)
- デジモン: 片方に尖った火力と、解析・射撃。『スカウター』が多く、指示型向き → [根拠](species-trends/根拠/06_デジモン.md)
- 深海棲艦: 水の重量級で、「死」がらみの種属。要統率A（図鑑は3体だけ） → [根拠](species-trends/根拠/07_深海棲艦.md)
- 艦娘・KAN-SEN: 水の支援艦。空母は“バウンス”、「あらいながす」をほぼ全員が持つ → [根拠](species-trends/根拠/08_艦娘.md)
- ロボット系: ガンダム・AS・KMFなど。属が作品ごとに違う弱点を埋め、指示を補うものが多い → [根拠](species-trends/根拠/09_ロボット.md)
- サーヴァント: 一点特化。『サーヴァント』は指令で伸び、クラスの属は相手の上昇を無視する → [根拠](species-trends/根拠/10_サーヴァント.md)

## 全体の見立て（推測）

- 要統率の低い強い種族は多い（ゾイド、デジモンの多く、ウマ娘、友好種）。統率型の強みは、モンハン・深海棲艦・古龍のような格が一段上の種族も使える上限の高さの方。
- 資料で数が少なく見える種族でも、世界の中では数が多いもの（スライム系、スペルカード持ちなど）がある（補足: ユーザーより）。
