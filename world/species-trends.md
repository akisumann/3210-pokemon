# 種族ごとの傾向（AIの集計）

原典の図鑑に出た個体を種族（系統）ごとに集め、種族値・タイプ・技・役割・育ち方の傾向をAIがまとめたもの（2026-10-13〜14の会話で、ユーザーの頼みで作った）。個体の数は資料に出てきた分だけで、世界の中の数ではない。傾向の「N体中M体」は、根拠の表の各個体の最後の図鑑で数えたもの。「まとめ」と、比較表の「相性のいい型」「一言」は推測。体力は図鑑に出ないので `hp-estimates*.md` の推定。表に入れるかは、属ポテンシャルではなく、その個体が何者か（元ネタの作品・種族）で決める（属は手がかりの1つ。ユーザーより）。種族そのものの設定は [種族・系統](species.md)。

## 種族ごと

- ウマ娘: 速さA〜AA+、防C前後の物理型（特殊の攻撃技はない）。しんそくの適性があり、育成と相性がいい → [詳しい中身](species-trends/ウマ娘.md)
- ストライクウィッチーズ: 5体ともひこうの速い特殊型（ミーナは属が別だが「ウィッチーズ」種と呼ばれる）。3体は属で「おいうち」を受けない。防D以下が5体中3体（芳佳B、ミーナC）で、5体とも交代の仕掛けを持つ → [詳しい中身](species-trends/ストライクウィッチーズ.md)
- ゾイド: 9体中7体がはがね（シールドライガーはでんき単）。速B以上の高速型5体と防A-以上の重装型4体に分かれ、新人から「B」まで全層にいる → [詳しい中身](species-trends/ゾイド.md)
- デュエルモンスターズ: 24体（属『デュエルモンスター』のない、野生のトリオン（蟲惑魔）と『ベテラン』のゴヨウ・ガーディアンを含む）。ドラゴン・はがねが多く（24体中11体）、遅めの高火力（防まで硬いのは24体中9体）。看板の7体は全員が異名と専用持ち → [詳しい中身](species-trends/デュエルモンスターズ.md)
- モンハン: 体力と防が高く遅い大型。ドラゴンが最多。種族で『チェイサー』の適性があるとされ、要統率は大抵B以上（古龍はA） → [詳しい中身](species-trends/モンハン.md)
- デジモン: 11体中9体は攻か特攻がA-以上（ケルビモンは両方A）で、体力は推定B前後以上。解析がらみが11体中9体で、『スカウター』は3体。主力は統率・育成型の下 → [詳しい中身](species-trends/デジモン.md)
- 深海棲艦: 3体ともみず。ヲ級・レ級は攻A+以上の物理型、駆逐棲姫は特防型。種属は死がらみが多い。要統率A（図鑑は3体だけ） → [詳しい中身](species-trends/深海棲艦.md)
- 艦娘・KAN-SEN: 10体ともみずで、7体が支援の役割。空母は防A以上の“バウンス”、駆逐艦は速A帯。はがね技が10体中9体 → [詳しい中身](species-trends/艦娘.md)
- ロボット系: ガンダム・AS・KMFほか34体。物理寄り（24体）で、属は作品ごとに違う。属で指示を補うのは34体中5体だけ → [詳しい中身](species-trends/ロボット.md)
- MS系: ロボット系から分けたガンダムとほかのMS（11体）。種属が「〇〇頑」（ガンダム、6体）と「〇〇機」（ほかのMS、4体）に分かれ、「頑」は『不動のエース』と「ここぞ！」の種属が多い（補足: ユーザーより、分け方の見立て） → [詳しい中身](species-trends/MS.md)
- AS系とKMF系: ロボット系から分けたアームスレイブ（6体）とナイトメアフレーム（6体）（補足: ユーザーより） → [AS系](species-trends/AS.md)、[KMF系](species-trends/KMF.md)
- ナイツ＆マジック系: ロボット系から分けた3体（イカルガ、アールカンバー、ゴルドリーオ）。はがねかエスパーの物理寄りで、属の名前が原作の用語（補足: ユーザーより） → [詳しい中身](species-trends/ナイツ＆マジック.md)
- サーヴァント: 種族値はばらばら。27体中17体が相手の上昇を無視し、『サーヴァント』は指令で1試合1回伸びる → [詳しい中身](species-trends/サーヴァント.md)
- 十八竜: 17体（近縁種2と、図鑑に属の行がないノモセジムのスクレイドを含む）とも「〇〇/ドラゴン」かドラゴン単。防が特防より高い（12体）・速C+以下（10体）が中心で、AA帯の値はほぼない。対〇（11体）はどれも自分の弱点向け → [詳しい中身](species/十八竜.md)
- アラガミ: 8体中7体が攻か特攻の片方だけA-以上（物理3・特殊4。外れるのはLv27のサリエル）。属（図鑑に属の行がある7体）で「亜人」の技を低確率で半減する。『エース』『二枚看板』はおらず（ピターは『エンペラー』）、プロリーグの使い手6人は全員統率型（ジム巡りのころのメアリは能力型） → [詳しい中身](species/そのほかの「〇〇種」.md)
- ヒーロー系: 「〇英雄」の種属を持つ6体（キャプテン・アメリカ、タツマキ、蛙吹梅雨、緑谷出久、ミルコ、ベル・クラネル）。作品はばらばらで、作中の名付けで括った（補足: ユーザーより）。「ここぞ！」や追い詰められてから強くなるポテンシャルと、能力ダウン・状態異常への強さが目立つ → [ヒーロー](species-trends/ヒーロー.md)
- 仮面ライダー: 4体（クウガ、電王、1号、フォーゼ）。4体とも属『マスクドライダー』（「おいうち」効果の技を半減）と速B。物理の中速アタッカーで、キックと「とんぼ」技が多い → [詳しい中身](species-trends/仮面ライダー.md)
- キン肉マン: 5体（レオパルドン、パイレートマン、スーパーフェニックス、ソルジャー、ウォーズマン）。5体ともかくとうの物理型で、『エースキラー』3体と『アンブッシュ』『チャレンジ』で相手の『エース』を狙う。3体が属『ゆでタマゴ』 → [詳しい中身](species-trends/キン肉マン.md)
- 東方: 4体（犬走椛、霧雨魔理沙、霊烏路空、黒谷ヤマメ）。4体とも♀で特殊寄りが多く、3体が属『スペルカード』（「技能拡張」の技を1回だけ優先度+1）。サリエルはアラガミとして外した → [詳しい中身](species-trends/東方.md)
- ドラクエ: 9体（スライム系3、『ダイの大冒険』4、ジャミラス、世界樹のエグドラシル）。目印は『スライムゼリー』と属『ドラゴンクエスト』。スライム系は硬めの繋ぎ役、ダイの勢は大物が『エースキラーβ』、小柄な2人が『エースアシストβ』 → [詳しい中身](species-trends/ドラクエ.md)
- ペルソナ: 6体（タナトス、アルセーヌ、ジャックフロスト、イザナギ、アリス、ツキヨミ）。ペルソナの4体は性別なし（悪魔のジャックフロストとアリスにはある）。防が低く打たれ弱いが、先発・登場時に仕事をする形が多い。アイギスはロボット側 → [詳しい中身](species-trends/ペルソナ.md)
- 巨人: 3体（ライナー、アニ、エレン）。体力は最低AAで、攻・防がA帯、特攻・特防C、遅い。3体とも相手の避の上昇を無視して自分の避が下がる形（『タイタン』『ギガントマキア』『鎧巨人の進撃』）を持つ → [詳しい中身](species-trends/巨人.md)
- ロックマン系: 『X』『エグゼ』『流星』『ZX』の6体（ペンギーゴ、ブルース、パンドラ、ハープ・ノート、フォルテ、ゴスペル）。原典で種族とは呼ばれず、元ネタでまとめた（補足: ユーザーより）。特殊寄りの搦め手と支援が多く、属の名前にシリーズの用語が入る → [詳しい中身](species-trends/ロックマン.md)
- 古代種（実機のポケモン）: 種族値は実機どおり（推測）で、技は4枠（51体中49体）。Lv70以上の42体中37体は『ポケパワー』・メガシンカ・伝承で全種族値を底上げ → [詳しい中身](species/時代区分：古代種と現代種.md)

## 全体の見立て（推測）

- 要統率の低い強い種族はある（デジモンの多く、友好種、古代種の大半（統率Cで従う。出典: 011）。ゾイドのブレードライガーも要統率Cで、ウマ娘のマックイーンも要統率C（補足: ユーザーより））。統率型の強みは、モンハン・深海棲艦・アラガミ・古龍のような格が一段上の種族も使える上限の高さの方（プロリーグのアラガミの使い手は6人とも統率型。能力型のメアリのサリエルは、トレーナーステータスがまだ試合に影響しないジム巡りのころのLv27。出典: 024）。
- 資料で数が少なく見える種族でも、世界の中では数が多いもの（スライム系、スペルカード持ちなど）がある（補足: ユーザーより）。
- 1チームに1体ずつ混ぜる種族もある。十八竜とアラガミは、図鑑のどのチームでも1体だけ。古代種も、資料には51体と多いが今は現代種より少なく、統一でなければ6体に1体いれば良い方と言われる（出典: 416）。
- 速さと硬さは両立しにくい。速い種族は打たれ弱く（ウマ娘、ウィッチーズ、ロックマンの小兵）、体力・防の高い種族は遅い（モンハン、巨人、キン肉マン、デュエルモンスターズ）。両方を持つのは古龍・『天賦の才』・『固有種』の看板級くらい。
- 物理寄りが多く、大型の物理種族は特防がC止まり（サーヴァント27体中18体、ロボット34体中24体、モンハン26体中19体が物理寄り。モンハン・巨人・キン肉マンの特防はほぼC）。ただし、これは今の資料で数の多い種族がたまたまそちら寄りなだけで、特防の高いポケモンも結構いる（補足: ユーザーより。ニトクリスAAA-、アビゲイルAA、パンドラ・ハープ・ノート・ジャックフロストA、ナナ・テスカトリA-など）。世界全体が特防の手薄な物理寄り、とは言わない。
- 体の大きさと扱うトレーナーの型が対応する。体力の高い大型・敵性種（モンハン、巨人、深海棲艦、古龍）は統率型の主力、搦め手で小回りの効く種族（サーヴァント、仮面ライダー、ペルソナ）は指示型に多い。「育成：A」以上で攻をAA+にする鍛錬系の種属が、種族をまたいで出る（ディノバルド、ゴア・マガラ、スライムナイト、ゴルドリーオ）。
- 「積み」と「追撃」への対策が種族の標準装備。相手の能力の上昇を無視するもの（サーヴァントのクラスの属、巨人の回避の無視、キン肉マン『不死鳥の技術』など）と、「おいうち」への対策（仮面ライダー『マスクドライダー』、ウィッチーズの属、マックイーン『エレガンス・ライン』など）が、いろいろな種族に入っている。
- 育ち方の段階は種族に関係なく共通。種属は低Lvで1〜2個、Lv110以上で3個、Lv155前後の『第四階梯』で4個。対〇の3点はLv110以上、異名はLv115前後から。
- 属は「種族の印」になっている。元ネタごとに決まった属があり（『モンスターハンター（G）』『サーヴァント』『ゆでタマゴ』『マスクドライダー』『スペルカード』『スライムゼリー』など）、新しい個体の出どころは属でだいたい分かる。
