# ポテンシャル一覧

作中に出たポテンシャルを分類ごとに並べた一覧。仕組みの説明は [potentials.md](potentials.md)。

- **効果**は原典の【表示】の文をそのまま写している（全角スペースだけ詰めた）。
- 持ち主のポテンシャルが変わったり消えたりしても、**行は消さない**。持ち主の欄に「（〜037）」のように持っていた期間を書く。今持っているものは期間を書かないか「（042〜）」とする。
- **初出**は、その効果文が最初に出た話の番号。
- 図鑑のポテンシャル欄は、**早見表の分類の順番どおりに並んでいる**（役割→分類→ヌシ→異名→種属→属→絆→先→対〇→汎用→付随→特権→PT→専用。ヌシと異名の前後はまだ確かめられていない）。分類に迷ったら、図鑑での並び順で判断する。（補足: ユーザーより）
- 分類はユーザーから聞いたもの（補足: ユーザーより）。117時点で、絆（093）、PT（096、育成型は105）、異名（113）の実物が出た。付随は161で出た（ツートップなど）。先は184で出た（対の先など）、ほかの分類にもまだ出ていないものがいくつもある（補足: ユーザーより）。どの分類に入るかが原典やユーザーの話ではっきりしないものは「分類がまだはっきりしないもの」に入れる。

| 種属ポテンシャル | 「〇〇の〇〇」の形のもの（3つくらい並んでいる）。育成で一番変えやすい。数で階梯が決まる（2つで第二階梯） | 金雷児の魔本、水魔女の足引→束縛、芦馬娘の疾駆→凱旋 |

| 絆ポテンシャル | トレーナーとの一定以上の繋がりで、トレーナーから付与されるもの（083で仕組みの説明） | 愛の絆（BB、ルサルカ、玉藻の前）、魂の絆（ガッシュ） |
| 先ポテンシャル | ときどき先制できる。通称『先』（184） | 先の先、対の先、後の先（184） |
| 対〇ポテンシャル | 弱点を補うもの。育成の質によって増えたり上位互換になったりする。名前がそのまま『対〇』の形になる（補足: ユーザーより） | 対闘回避、対闘耐性など |
| 汎用ポテンシャル | 数種類の中から選ぶもの | 気合い、ド根性、戦闘続行 |
| 付随ポテンシャル | 『役割』に付随するもの | ツートップ、スラッグアーツ、アンブッシュ（161） |
| 特権ポテンシャル | 『エキスパンション』など | エキスパンション |
| PTポテンシャル | 統率型か育成型（育成A+以上）のトレーナーの手持ちが持つもの（グッドラックなど）。トレーナーの『固有』の発動に連動し、チーム全員が同じか近いものを持つ（083で仕組みの説明） | ブリティッシュタンク、グッドラック、ノウブルアーツ（育成型） |
| 専用ポテンシャル | トレーナーがつける必殺技のようなもの。「能力」によって付与される強力なポテンシャル（カズマ談） | 突撃するお菓子の妖精（モッフル） |

- 上の14分類はポケモンが持つもの（ヌシポテンシャルは、最初に聞いた13分類に後から加わったもの（補足: ユーザーより））。**トレーナー自身が持つものは固有ポテンシャル**と呼ぶ（補足: ユーザーより）。トレーナーが使う『指令』（六令・四式）は、原典では「トレーナーポテンシャル『指令』」と呼ばれていて、『固有』とは別のものとして説明されている（出典: 026, 041）。『指令』は固有ポテンシャルには含まれない（補足: ユーザーより）。

## 異名ポテンシャル

- 専用ポテンシャルは、トレーナーの「能力」を利用して手持ちに付与するもの。数は「能力」のランクに比例（C=3体、A=6体）。1体1つ、同じ『専用』は同じバトルに同時に出せない。代表的な型は『必中追尾』と『三角効果』。仕組みの詳細は [potentials.md](potentials.md#専用ポテンシャル)。（出典: 058, 066）
- 112で出た専用のひな形: 『**ペースメーカー**』（「○○○専用ポテンシャル。場を離れる時、味方の『エース』を発動させる。」。『アシスト』が持つことが多い。「ここぞ！」でなくても『エース』を発動でき、『エース』を遊撃させる型）、『**ストーキング**』（「○○○専用ポテンシャル。『エース』が場に出た時、味方と任意交代して場に出ることが出来る。」。『キラー』『チェイサー』が覚えることが多い）。ルサルカの『専用』の候補。（出典: 112）
- 専用には、誰でも使える汎用的な専用（『必中追尾』『三角効果』などの代表的な型）と、「能力」型だけが使える一回り強い専用（『強化追尾』『大三角』など）の2種類がある。トレーナーの資質としては「能力」型だけで、ポケモン側の例外として『天賦の才』や『4層のヌシ』も使える。（補足: ユーザーより）

- 『先行とんぼ』型のひな形は「○○専用ポテンシャル。1/試/先行 自身の攻撃技に「とんぼ」効果を付与し、技の優先度を+1する。」（出典: 073）

## 傾向（推測）
これまでの図鑑データから読み取った傾向。原典にはっきり書かれたことではないので、話が進んだら確かめて書き直す。

- **育成型は数が多い**: 育成A+のハイランダーの手持ちは7〜8個、育成Aの一条武丸の手持ちも6〜7個。種属を2つ持ち、対〇を「回避」「耐性」の2つ組で持つ。（出典: 060）育成型はポテンシャルを上等なものにしやすい。たとえば「〇〇の〇〇」という名前のもの（種属など）のような、ほんのり強めのものを付けやすい。ただしあくまで傾向（補足: ユーザーより）。
- **統率型の手持ちは『エキスパンション』つき**（これは原典で確かめられた）: 『エキスパンション』は「統率」の才で、それぞれのタイプの力を「統率」で拡大したポテンシャル（034。→ [potentials.md](potentials.md#エキスパンション統率の才)）。カズマの手持ちと同じく、統率型のダージリンの手持ちも最後に『エキスパンション』（特権）を持っている。（出典: 034, 076, 077）
- **欄の型**: Lv40〜55のポケモンは、役割（0〜1）→分類（0〜1）→ヌシ（ヌシだけ）→種属（ほぼ1）→属（0〜1）→汎用（ほぼ1）→特権（統率型の手持ちの『エキスパンション』。のちに、深度3のヌシは同じ枠に『ヌシの特権』を持つと分かった（156））の順で、3〜6個持つことが多い。専用ポテンシャルは1行空けて最後に出る。（出典: 042, 046, 048, 057）
- **『役割』なしの2体**: 選出の中で同じ『役割』は被らせられず、統率型でないトレーナーは『役割』が4種類しかない。なので今のところ、6体のうち『役割』持ちは4体までで、残り2体は『役割』なしになることが多い。ただし、この先いろいろな要素で増えていく（補足: ユーザーより）。実際に（レヴィ: ケンプファー、ロクショウ／修: ポリゴンZ、ネルスキュラ／ブリジット: エンジェウーモン、エルレイド／エール: ウルゥル＆サラァナ、シンリュウ／爆豪: ダーク・ダイブ・ボンバー、バーストタートル／武丸: ゴーストライダー、ドンカラス）。統率型のカズマやダージリンのチームは全員に『役割』がある。（出典: 044, 046, 048, 057, 068, 075, 077, 088）
- **分類と古代種**: 『オールドタイプ』を持つのは原作のポケモン（古代種）だけ。それを打ち消す『適応種』『変種』『ハーフ』があり、他作品由来のポケモンが原作ポケモンの強さに対抗する仕組みに見える。（出典: 039, 052, 055）
- **属は元ネタの作品やジャンルの名前**: モビルスーツ、メダルロボット、デジタルモンスター、モンスターハンター、KMF、スタンド、シンフォギア、バトルシップ、ハンターライセンス、デュエルモンスター、ファイナルファンタジーなど。原作ポケモンの属は、ゲームの仕様にちなんだ名前（エレキブースター、あやしいパッチ、デルタフォース）。
- **同じ系統の属は効果の形がそろう**: 『プリティーダービー』『バトルシップ』『シンフォギア』は、どれも「1/試 技〇〇を繰り出す。この時、自身の攻（特攻）を最も高い種族値と同ランクにする」。「〇〇種」ごとにひな形があるのかもしれない。（出典: 042, 045, 057）
- **種属は「元ネタの特徴＋効果の種類」**: 「金雷児の魔本」「雷牙竜の電波」「青騎士の剛剣」のように、前半が元ネタのキャラや種族、後半が効果の種類。効果は「〇〇の時〜」という条件つきが多い。育成で入れ替わった例（水魔女の足引→束縛、芦馬娘の疾駆→凱旋）もここに集中している。
- **汎用と『役割』**: 『エース』を持つポケモンは、今のところ全員が『気合い』（ガッシュ、ティアナ、ブルー・ナイト、モッフル、ドサイドン、ラハール、ベル・クラネル、ミステリア、玉藻の前、ホワイトスネイク、ランスロット、スクレイド）。支援役には『ド根性』、居座る前線役には『戦闘続行』が多い印象。『エース』と『気合い』の組み合わせが仕様なのかは分からず、今後は別の汎用を持つ『エース』も出てくるかもしれない（補足: ユーザーより）。
