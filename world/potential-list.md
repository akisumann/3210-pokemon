# ポテンシャル一覧

作中に出たポテンシャルを分類ごとに並べた一覧。仕組みの説明は [potentials.md](potentials.md)。

- **効果**は原典の【表示】の文をそのまま写している（全角スペースだけ詰めた）。
- 持ち主のポテンシャルが変わったり消えたりしても、**行は消さない**。持ち主の欄に「（〜037）」のように持っていた期間を書く。今持っているものは期間を書かないか「（042〜）」とする。
- **初出**は、その効果文が最初に出た話の番号。
- 分類はユーザーから聞いたもの（補足: ユーザーより）。042時点では、まだ半分も出ていない。どの分類に入るかが原典やユーザーの話ではっきりしないものは「分類がまだはっきりしないもの」に入れる。

## 分類の早見表（補足: ユーザーより）
| 分類 | 内容 | 042までに出た例 |
| --- | --- | --- |
| 役割ポテンシャル | 『エース』などの『役割』 | エース、不動のエース、二枚看板など |
| 分類ポテンシャル | 種族より幅広い分類（古代種、ハーフなど）でつくもの。一般的なポケモンにはないことが多い | オールドタイプ |
| 異名ポテンシャル | 勝手に名付けられる二つ名。育成などでは変えられない | （まだ不明） |

| 属ポテンシャル | 1つの種族が持ちやすいもの（サーヴァント、プリティーダービーなど）。カタカナの名前のものはおおむねこれ | プリティーダービー、ザグルゼム、ナハツェーラー、ゴーレム、エーテルリアクタ、リューノブレード |
| 絆ポテンシャル | 絆があるかどうか | （まだ出ていない） |
| 先ポテンシャル | ときどき先制できる | （まだ出ていない） |
| 対〇ポテンシャル | 弱点を補うもの。育成の質によって増えたり上位互換になったりする | （まだ出ていない） |
| 汎用ポテンシャル | 数種類の中から選ぶもの | 気合い、ド根性、戦闘続行 |
| 付随ポテンシャル | 『役割』に付随するもの | （まだ出ていない） |
| 特権ポテンシャル | 『エキスパンション』やヌシの特権など | エキスパンション、野生の親玉、〇〇のヌシ |
| PTポテンシャル | 統率型か育成型のトレーナーの手持ちが持つもの（グッドラックなど） | （まだ出ていない） |
| 専用ポテンシャル | トレーナーがつける必殺技のようなもの | （まだ出ていない） |

- 上の13分類はポケモンが持つもの。**トレーナー自身が持つものは固有ポテンシャル**と呼ぶ（補足: ユーザーより）。トレーナーが使う『指令』（六令・四式）は、原典では「トレーナーポテンシャル『指令』」と呼ばれていて、『固有』とは別のものとして説明されている（出典: 026, 041）。『指令』は固有ポテンシャルには含まれない（補足: ユーザーより）。
