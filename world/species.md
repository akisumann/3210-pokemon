# ポケモンの種族・系統

## 時代区分：古代種と現代種

- 古代種: 「古代」と呼ばれる時代に見つかったポケモンをまとめた呼び名 → [根拠](species/根拠/001_時代区分：古代種と現代種_古代種.md)
- **現代**: ある時期に新種のポケモンが爆発的に見つかった。そこから先の時代を「現代」と呼ぶ。（出典: 003）
- 現代種: 現代に入ってから見つかったポケモン → [根拠](species/根拠/002_時代区分：古代種と現代種_現代種.md)
- **古代種は、実際のゲーム（実機）に出てくるポケモンのこと**（スレ内の用語）。テンガン山の1層でも、ゴルバット、イワーク、イシツブテ、ゴーリキーなど古代種が多く出た。（出典: 007）
- 実機に出てこない、ほかの作品が元ネタのポケモンは現代種にあたる → [根拠](species/根拠/003_時代区分：古代種と現代種_実機に出てこないほかの作.md)
- 古代種は『オールドタイプ』（『オールドタイプ』を持たないポケモンの防護ポテンシャルを無視する）を持つ。（出典: 039）
- ビークインはシンオウ原産の古代種で、「こうげきしれい」など3つの技の発祥 → [根拠](species/根拠/004_時代区分：古代種と現代種_ビークイン.md)
- 古代種ならではの強化法『ポケパワー』は、自分の全種族値に+補正を得る → [根拠](species/根拠/005_時代区分：古代種と現代種_古代種ならではの強化法と.md)
- 今は古代種の方が少なく、6体の中に1体いれば良い方 → [根拠](species/根拠/006_時代区分：古代種と現代種_今は古代種の方が少ない.md)
- 古代種は**技幅が4枠**と狭い（ガブリアス談）。多くの選択肢を持たせるより、高い種族値で正面突破する形になりやすい。（出典: 084）
- 古代種の中でも猛威をふるった種族がいる → [根拠](species/根拠/007_時代区分：古代種と現代種_古代種の中でも猛威をふる.md)
- 「600族」と呼ばれる種族値の高い古代種がいる → [根拠](species/根拠/008_時代区分：古代種と現代種_600族と呼ばれる種族値.md)

- 『金冠サイズ』は、大きさの代わりに速さが多少落ちることが多い → [根拠](species/根拠/019_天賦の才と金冠サイズ_金冠サイズと速さ.md)

- 『天賦の才』と『金冠サイズ』は、どちらも『ハーフ』や『固有種』と同じ**分類ポテンシャル**（補足: ユーザーより）。
- どちらも各種族に1体だけ → [根拠](species/根拠/020_天賦の才と金冠サイズ_どちらも各種族に1体だけ.md)
- 185では、ブリジットのバーゲスト（アルトリア/ガウェイン）が『金冠サイズ』で非常に大柄。（出典: 185）
- 456では、《切鋒ブリザード》（ワイス）の『エース』雪泉が「**雪女**」種の『金冠サイズ』（ルサルカ）。図鑑はまだ出ていない。（出典: 456）

## 亜人

- 「亜人」のタマゴは、''タマゴが出来るまでの期間''・''タマゴを生むまでの期間''・''タマゴが孵るまでの期間''の3つのうち2つが比較的長いという研究結果がある（先代）。タマゴも個体差が大きい。（出典: 303）
- 人間そっくりの姿をしたポケモンを「亜人」と呼ぶ（スレ内の用語） → [根拠](species/根拠/025_亜人_人間そっくりの姿をしたポ.md)
- **亜人態と龍形態**（336）: 『異界のヌシ』のキーラは''亜人態''になって挨拶する。メリュジーヌは''龍形態''でも現れるが、キーラいわく「あっちのガキは単にかっこつけであの姿なだけ」。（出典: 336）
- 亜人かどうかで効き目が変わるポテンシャルがある（『モンスターハンター』など） → [根拠](species/根拠/026_亜人_モンハン種の属ポテンシャ.md)

## 敵性種と友好種

- **敵性種**: 人間に牙をむくような生態を持つポケモンの総称。人間の血が好物だったり、積極的に人間を狙って攻撃したりする。例: ルサルカ（若い男の生命エネルギーが好物）。（出典: 004）
- **友好種**: 敵性種の反対。人間を守ったり、人間と特に仲良くしたりするポケモン。例: ガッシュ種。（出典: 004）
- 敵性種／友好種は、人を襲うかどうかの大雑把な危険性の目安 → [根拠](species/根拠/041_敵性種と友好種_大雑把な危険性のカテゴリ.md)
- 敵性種でも、ルサルカのように人間の手持ちになれる。（出典: 004）
- 「ルサルカ」種の本質は、夢魔に近い → [根拠](species/根拠/042_敵性種と友好種_ルサルカ種の本質は夢魔に.md)
- 敵性種は、ステータスが比較的高いことが多い（全部ではない。ルサルカはその傾向に当てはまらない）。上位種はとても強い。（出典: 011）
- 敵性種は、トレーナーの「統率」に関係なく、最初は襲いかかってくるのが普通。仲間にするには、まず倒して降伏させるか捕獲する必要がある。（出典: 011）
- 「**巨人**」種: 敵性種。「体」（体力）の種族値にすぐれ、最低ラインが「AA」ランク。例: ライナー・ブラウン。（出典: 019）
- 「**デジタルモンスター**」種: かなりの数のポケモンが統率Cライン。例: スカルグレイモン。（出典: 021）
- 「**KMF（ナイトメアフレーム）**」種: 例: ランスロット（原種はノーマル）。（出典: 029）
- 「KAN-SEN」種、「艦娘」種: 海の多いホウエンに多く、シンオウでは珍しい → [根拠](species/根拠/043_敵性種と友好種_KAN-SEN種艦娘種海.md)
- 「四大精霊」: イフリート、ウンディーネ、ドワーフ、エルフの4種族 → [根拠](species/根拠/044_敵性種と友好種_四大精霊十八竜に匹敵する.md)
- 「シスターズ」種: エネルの手持ちのミサカワースト。『金冠サイズ』 → [根拠](species/根拠/045_敵性種と友好種_シスターズ種エネルの手持.md)
- 「ウマ娘」種: マックイーンなど。「育成」と相性がいいと言われる → [根拠](species/根拠/046_敵性種と友好種_ウマ娘種例メジロマックイ.md)
- 「バハムート」種: 要「統率：A」の怪物級の種族。メリュジーヌがその『天賦』 → [根拠](species/根拠/047_敵性種と友好種_バハムート種陸のベヒーモ.md)
- 「**ウィッチーズ**」種: 例: エイラ（千束の『キラー』。属ポテンシャル『ストライクウィッチーズ』）。（出典: 135, 137）

## 伝説のポケモン

### 要「統率」と伝説

- 古代種の大半は「**統率：C**」があれば従う。（出典: 011）
- 要「統率」の例: ルサルカ、ライナー、イカルガは要B。ガブリアスは要C。友好種のガッシュとマックイーンも要C（補足: ユーザーより）。タツマキは要B-。（出典: 050, 052）
- 要「統率：A」で有名なのは、モンハン・アラガミ・深海棲艦や三魔獣など → [根拠](species/根拠/073_要統率と伝説_要統率：Aで有名なものモ.md)
- ポケモン側の「-」: 気の合わなさの「-」を、ポケモン側が持つ選手もいる → [根拠](species/根拠/074_要統率と伝説_ポケモン側の-.md)
- 伝説は別で、準伝は「統率：B」、禁伝は「統率：A」が必要 → [根拠](species/根拠/075_要統率と伝説_伝説に語られるポケモンは.md)
- 「統率：A」があれば、理論上はどのポケモンも従えられる。（出典: 011）
- 準伝と禁伝: どちらも全員が『伝承』を持ち、『天賦の才』並みのキャパシティがある → [根拠](species/根拠/076_要統率と伝説_準伝と禁伝.md)
- 伝説は「統率：A」なら従えられるが、出会えること自体がとても稀 → [根拠](species/根拠/077_要統率と伝説_伝説と出会える運.md)
- 古代の伝説種でも、''準伝''クラスは「深度：3」から報告例がある（フリーザー）。（出典: 278）
- “準伝”級も『伝承』を持ち、その専用で『野生ポケモン』になる例がある → [根拠](species/根拠/078_要統率と伝説_準伝・禁伝と伝承野生ポケ.md)
- エンテイの図鑑（471）: 役割は『野生ポケモン』、種属は『炎聖獣の伝承』 → [根拠](species/根拠/079_要統率と伝説_エンテイの図鑑.md)
- フレイザード: 煉獄の『エースキラーβ』で、この個体だけの『固有種』 → [根拠](species/根拠/080_要統率と伝説_フレイザード.md)
- テイルレッド: 煉獄の先発。ジータのところのポケモンと同じ種族かもしれない → [根拠](species/根拠/081_要統率と伝説_テイルレッド.md)
- カプ・コケコ: エネルの手持ちの『伝承』持ちで、アローラ出身の“準伝”級 → [根拠](species/根拠/082_要統率と伝説_カプ・コケコ.md)
