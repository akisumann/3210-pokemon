# ポケモンの種族・系統

## 時代区分：古代種と現代種
- **古代種**: 「古代」と呼ばれる時代に見つかったポケモンをまとめた呼び名。その時代ははるか昔で、数はとても多い。（出典: 002, 003）
  - **ピカチュウ**は古代種の中でも古株中の古株。「**始祖**」の一角に数えられるほどで、古代種の「長老」と呼ばれる。（出典: 003）
  - ピカチュウはシンオウではとても珍しく、ゼットンも会ったことがない。（出典: 002）
- **現代**: ある時期に新種のポケモンが爆発的に見つかった。そこから先の時代を「現代」と呼ぶ。（出典: 003）
- **現代種**: 現代に入ってから見つかったポケモン。ガッシュも現代種。（出典: 003）
  - 今でも毎日のように新しいポケモンが見つかっている。151匹からどれだけ増えたのか、ジムリーダーの凜にもわからない。（出典: 003）
- **古代種は、実際のゲーム（実機）に出てくるポケモンのこと**（スレ内の用語）。テンガン山の1層でも、ゴルバット、イワーク、イシツブテ、ゴーリキーなど古代種が多く出た。（出典: 007）
- 推測: ゼットンやガッシュのように、ほかの作品が元ネタのポケモンが現代種にあたると思われる。
- 古代種は『オールドタイプ』（防護ポテンシャルを無視する）を持つ。（出典: 039）
- 古代種の中でも猛威をふるった種族がいる。ガブリアスの系統は「**古代の暴君**」と呼ばれ、昔シンオウで無双したチャンピオンが使っていた。今は数がかなり減っていて、ガバイトを見かけるのも久しぶり（ゲンドウ、ホーネット談）。（出典: 039）

- 「600族」と呼ばれる種族値の高い古代種がいる。ケンプファーは例外を除けば古代種屈指（凜談）。（出典: 045）ほぼ進化したそのままのガブリアスでも、Cランクではみんながびびる「種族値の壁」になっている。種族値そのものの高さは、工夫だけでは埋めづらい強み。（出典: 071）

## 『天賦の才』と『金冠サイズ』
- 『**天賦の才**』: その種族の中で「最優」とされる1体。種族のくくりは、「ガッシュ」種や「ルサルカ」種のような狭いものから、「ウマ娘」種や「巨人」種のような広いものまである。（出典: 071）
- 『**金冠サイズ**』: その種族で最大の体格・体力を持つ1体。（出典: 071）
- どちらも**各種族に1体だけ**。上位ランクだけにいるわけではなく、今年デビューしたCランクのチームが連れている可能性もある。例: 凜の手持ちのティファニアは「エルフ」種の『金冠サイズ』。（出典: 071）

## 種族値と育成
- 「育成」で種族値に少し手を入れることはできる（マックイーンは「防」「特防」「速」が少しずつ伸びた）。「ウマ娘」種は「育成」と相性がいいらしい。ただし高位の育成型でも、原形がなくなるような種族値上げは無理。（出典: 070）
- 一発でどかーんと強くなれるのは「育成」型の特権（ルサルカ）。（出典: 069）
- トレーナーの資質はなかなか上がらないが、ポケモンの種族値は、進化などで時折グイッと大きく上がる（補足: ユーザーより）。例: フカマル→ガバイト→ガブリアス（600族）。（出典: 029, 037, 042）

## 亜人
- **人間そっくりの姿をしたポケモン**を「**亜人**」と呼ぶ（スレ内の用語）。ルサルカ、メリュジーヌ、ゼットンなど。カズマの手持ちでは、ガブリアスとイカルガ以外はみな亜人。（出典: 007, 048）
- モンハン種の属ポテンシャル『モンスターハンター』は「亜人」に対して急所に当たりやすくなり、モッフルの『マスコットキャラ』は「亜人」の「攻」の上昇を無視する。亜人かどうかで効き目が変わるポテンシャルがある。（出典: 048, 057）

## 適応種
- 古代種から進化した現代種を『**適応種**』と呼び、分類ポテンシャル『適応種』（例: 「古代種『ヒメグマ』の進化系。『オールドタイプ』を無効化する」）を持つ。例: モッフル（ヒメグマから進化）、アイシー・ペンギーゴ（デリバードから進化）。（出典: 055, 057, 060）

## 固有種
- その種族が1体しかいないものは、分類ポテンシャル『**固有種**』を持ち、『オールドタイプ』を無効化する。例: ウルゥル＆サラァナ（「ウルゥル＆サラァナ」種はこの個体だけ）。（出典: 068）

## そのほかの「〇〇種」
- 「**アームスレイブ**」（AS）種: サベージ。属ポテンシャル『アームスレイブ』を持つ。（出典: 058, 059）

## 変種
- 原種とは異なる生態を持つものを『**変種**』と呼び、分類ポテンシャル『変種』を持つ。『オールドタイプ』を無効化する。例: ヤマト（フェンリル種の変種。原種は大きな狼の姿だが、ヤマトは亜人体）。（出典: 052）
- 人間とポケモンの混血（ハーフ）も、分類ポテンシャル『ハーフ』（「人間と〇〇〇の混血の『変種』」。自分と同じタイプの技のダメージを半減）を持つ。プロリーグではちょいちょい見かける。（出典: 052）
- 『変種』は原種を調べても育ち方がわからず、育成が難しい（ライザ談）。（出典: 052）

## 敵性種と友好種
- **敵性種**: 人間に牙をむくような生態を持つポケモンの総称。人間の血が好物だったり、積極的に人間を狙って攻撃したりする。例: ルサルカ（若い男の生命エネルギーが好物）。（出典: 004）
- **友好種**: 敵性種の反対。人間を守ったり、人間と特に仲良くしたりするポケモン。例: ガッシュ種。（出典: 004）
- 敵性種でも、ルサルカのように人間の手持ちになれる。（出典: 004）
- 敵性種は、ステータスが比較的高いことが多い（全部ではない。ルサルカはその傾向に当てはまらない）。上位種はとても強い。（出典: 011）
- 敵性種は、トレーナーの「統率」に関係なく、最初は襲いかかってくるのが普通。仲間にするには、まず倒して降伏させるか捕獲する必要がある。（出典: 011）
- 「**巨人**」種: 敵性種。「体」（体力）の種族値にすぐれ、最低ラインが「AA」ランク。例: ライナー・ブラウン。（出典: 019）
- 「**デジタルモンスター**」種: かなりの数のポケモンが統率Cライン。例: スカルグレイモン。（出典: 021）
- 「**KMF（ナイトメアフレーム）**」種: 例: ランスロット（原種はノーマル）。（出典: 029）
- 「**KAN-SEN**」種、「**艦娘**」種: 海の多いホウエンにはたくさんいる。シンオウでは珍しい。例: ベルファスト。（出典: 030）
- 「**四大精霊**」: 十八竜に匹敵する歴史を持つ四大元素の一角。例: ウンディーネ（みず／ノーマル）。（出典: 032）
- 「**ウマ娘**」種: 例: メジロマックイーン、マンハッタンカフェ。（出典: 020）
- ほかの系統: 「**ゾイド**」種（例: ブレードライガー。はがねタイプの高速アタッカーで、統率Cで使える）。（出典: 014）
- モンハン種の下位種の例: イャンクック（ひこう／ほのお）。（出典: 012）
- 敵性種の主な種族:（出典: 007, 011）
  | 種族 | 特徴 |
  | --- | --- |
  | **モンハン**種 | ドラゴンタイプが多く、種類が豊富。大型ポケモンが並ぶ。たいていは統率B以上が必要。「統率型」のトレーナーに一番向いている |
  | ┗ **古龍** | モンハン種の上位。ダンジョンの深部にすみ、自然現象をも操ると言われる屈指の強豪。プロのBランクでもごくわずか、Cランクにはいない |
  | **アラガミ**種 | 強力な種族。上位は古龍に追随するものもいる。「亜人」に強い。オウガテイルはその下位種 |
  | 深海棲艦 | 名前だけ登場 |
  | 蟲惑魔 | むしタイプを持つと思われる。例: トリオン（むし／じめん） |
  | 使徒 | 名前だけ登場 |
  | 吸血鬼 | 名前だけ登場 |
- 推測: 元ネタはそれぞれ『モンスターハンター』『GOD EATER』『艦隊これくしょん』『新世紀エヴァンゲリオン』など。000のクシャルダオラは、原作では古龍にあたる。
- 友好種の例: ガッシュ、メジロマックイーン。どちらも原作的に成長要素が強い（ザク談）。（出典: 011）

## 十八竜
- ドラゴンタイプを持つポケモンの一群。序盤のジム戦で必ず出てくる。→ [pro-trainer.md](pro-trainer.md)（出典: 014, 015）
- 例: トライノス（いわ／ドラゴン）。（出典: 015, 017）

## シンオウの伝説種
- シンオウ地方の伝説種は、**3体のドラゴンと、万物を司る創造神**（マックイーン談）。（出典: 014）
  - 推測: 原作のディアルガ、パルキア、ギラティナとアルセウス。

## 伝説のポケモンと統率
- 古代種の大半は「**統率：C**」があれば従う。（出典: 011）
- 要「統率」の例: ルサルカ、ライナー、イカルガは要B。ガブリアスは要C。友好種のガッシュとマックイーンはそれ以下。タツマキは要B-。（出典: 050, 052）
- 要「統率：A」で有名なもの: モンハン、アラガミ、深海棲艦などの敵性種（ふつうは最低でも深度3クラス）、大地のベヒーモス、大海のリヴァイアサン、氷の魔狼フェンリル、虫の王ベルゼブブ。キリン（古龍）も要A。（出典: 045, 052）
- 伝説に語られるポケモンは別。（出典: 011）
  - **準伝**（例: サンダー、ファイヤー、フリーザー）: 「**統率：B**」が必要。
  - **禁伝**（例: ミュウツー）: 「**統率：A**」が必要。
- 「統率：A」があれば、理論上はどのポケモンも従えられる。（出典: 011）

- **アルセウス**: 神話で語られる、シンオウ地方の創造神とされるポケモン。今の時代にその姿を見た人間は一人もいないと言われている。（出典: 003）
