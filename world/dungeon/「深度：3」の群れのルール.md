# 「深度：3」の群れのルール

- 『ヌシ』は野生版の『指令』を使う: 『**ヌシの号令**』（x/試/先行/Ｔ終了時まで味方の任意の能力を2倍にする）と『**ヌシの勅命**』（x/試/先行/味方に相手の攻撃を回避させる）。**使用回数は深度に比例**し、「深度：3」なら3回ずつ。『四式』＆『六令』と違って同時には使えない。ほかの「深度：2」でも、群れ次第で使ってくることがある。

（出典: 218）

- 『固有』と『専用』の野生版もある。『**野生**』ポテンシャル＝『専用』の野生版（「深度：3」から群れの全員が持つ）。『**迷宮**』ポテンシャル＝『固有』の野生版（「深度：3」なら群れに1個。効果は『ヌシ』次第で変わる）。シアやメアリですら5つ目のジム戦では『専用』は3つまでなので、全員が『専用』持ちの群れは格が違う。

（出典: 218）

- 「深度：3」の群れに属さないポケモンは、練度も強さも劣る。群れはダンジョンの階層の中枢で、野生の精鋭部隊（アカネが「4層」でストレス発散していた群れに入っていない相手とは桁が違う）。侵入者に対してお行儀がいいわけでもない。

（出典: 218）

## 群れとの戦い方（230。先代とオシュトルの助言）

- 『ヌシの号令』『ヌシの勅命』は『四式』『六令』を上回る代物で、『号令』は実質『全開攻撃』3回のようにも使える。リソースの取捨選択が人界とまるで違う。相手も人間側の『指令』に慣れている（「B」ランカーを返り討ちにしてきた）。

（出典: 230）

- 『指令』を出すのはあくまで『ヌシ』で、『ヌシ』が瀕死になっても使ってくる。戦況を見渡す役目もあるので、『ヌシ』が場に出てくるのはまず後半戦（いきなり出てきたケースは確認されていない）。たどり着けるかどうかも戦いのうち。

（出典: 230）

- 負ければ軍門に降るのは、野生のルールに身を委ねて守っているから（どうしてそうなるかは未解明）。（出典: 230）
  - この決まりは序盤から一貫している: 011で先輩が「まずは倒して降伏させるか捕獲する必要がある」、ガッシュが「敵を倒し、軍門に降らせ、さらに力を増やす……統率型の王道」。010のマックイーン（ルサルカに捕まって荷物持ちに）も、445で本人が「負けた者は軍門に降らねばなりませんし」と言っていて、同じ掟による加入。004のルサルカは負けてから自分で押しかけた。（出典: 004, 010, 011, 445）

## ハクタイの森「深度：3」の群れ（218〜229で下調べ、230で対面、232でカズマたちが勝利）

- **232でダンジョンアタック成功**。233でベルゼブモンが軍門に降り、カズマの手持ちになった（群れに勝つと周囲の野生ポケモンも森に隠れた）。元『ヌシ』のリースが『ヌシ』に戻るはず（サン）で、411のSystemでもリースはベルゼブモンの''先代および後任''（今の『ヌシ』）。リースはかつての部下（緑茶）に頼んで人界の情報を集めていて、舐めた連中（仮）が来れば返り討ちにするつもり。System: 強さ以外にもリスクがあるのが''ダンジョンアタック''で、安全策で強くなれるならその方がよい。経過と公開されたデータは [story/battles.md](../../story/battles.md)。群れはLv95〜100（『ヌシ』ベルゼブモンとリースがLv100）。（出典: 232, 411）

（出典: 232, 233, 411）

- 『ヌシ』**ベルゼブモン**（特性「わざわいのたま」。野生ポテンシャル『強者を射貫く魔王の眼光』（場に出た時、自身を「ロックオン」状態にできる）、『魔王虫の照準』（相手を解析した時に「ロックオン」）。寡黙。「この森にいる以上は………俺の眼から、逃げられると思うな」）。対面前から場に出てガッシュに照準を合わせ、天花のサポート効果で止められ、リースにたしなめられた。（出典: 230）

- **リース**（元『ヌシ』で、今は群れの''まとめ役''。話の分かる穏やかな女性）、**サン**（''狼王の血筋''、特性「いかくのキバ」、野生ポテンシャル『何処より来たるもののけ姫』（味方が場に出て2T目の終了時に交代して出られる））、**エスピナス**（''棘竜''、「どく/くさ」の''モンハン''種。基本大人しいが眠りを妨げると怒る。野生ポテンシャル『眠れる密林の棘竜』）、**ティレルビートル**、**バサギリ**。（出典: 230）

- 迷宮ポテンシャルは『**生命と叡智に満ちし深緑**』（味方が相手の体力をドレインした時に相手を解析する。『野生』『ヌシ』以外に無効化されない＝解析無効も貫通）。森の草木が侵入者の生命を感じ取り、侵入探知にもなる。カズマと天花は、『スカウター』との相性は抜群と見た（「―――――――欲しいッスね」「うん、欲しいね」）。（出典: 230）

- 218の時点では、森の魔王''ベルゼブブ''（→ [species.md](../species.md) の伝説の節）が3層の『ヌシ』になったという噂だったが、実際には「**ベルゼブブとは似ても似つかない「亜人」の『ヌシ』**」らしいと分かっていた。中位〜下位の「B」ランカー複数をはねのけたのは事実で（欲にかられて突っ込んだチームがズタボロで逃げ帰った。死人は出ていない）、『森のヌシ』（「草」「虫」技のダメージ半減）と『ヌシの特権』を持つはず、レベルは今のカズマならそこまで離れていない、という凛の見立てだった。「むし」や『森のヌシ』の群れは「くさ」使いの凛には相性が悪いが、ダンジョンとしては「ほのお」「ひこう」など弱点は多い。カズマは『ヌシ』を手持ちの『スカウター』にできれば戦力になると前向きで、逃げ帰る手段は天花のSP「テレポート」とたんけんセット（ライザ）。（出典: 218）

- 227: 砕蜂（「深度：2」の元『ヌシ』）の話。
  - 今の『ヌシ』ベルゼブモン（「ベルゼブモン」種の『固有種』。「むし/あく」と聞いた気がする。種族値は群れで一番。銃を使う）は、トレーナーに敗れたのではなく**下剋上**で''代替わり''した。
  - 先代の『森のヌシ』**リース**（「くさ/かくとう」、特性「スカイスキン」（「ノ」技を「飛」にして1.33倍）、「しんそく」の使い手）は『ヌシ』と『親玉』を失ったが今も群れのNo.2で、砕蜂は世話になった（「はやてのつばさ」を覚える無理な訓練を教えられた）。
  - 下剋上の日には''邪悪な気配をまとった炎''が暴れ狂ったという噂があり、万丈目はメインウェポンを「**じゃあくなほのお**」（特殊・悪（炎）・単体・130・命中85。「悪」「炎」の2タイプを持ち、有利な相性で判定）と推測した（イカルガ、ルサルカ、モモ、ヤマトに抜群で半減もできない。ロトムは「トリコロール」で受けられる。『対悪』は効くが『対炎』は効かない、イカルガ）。
  - 群れは「むし」「くさ」が大半で、''メダロット''種の''ティレルビートル''（特性「かいりきバサミ」）、''モンハン''種の''エスピナス''（特性「エッジアーマー」。「毒」をぶちまける）、バサギリ（「ステロ」）もおそらく健在。
  - カズマ「「ほのお」や「ひこう」って言う考えで挑むと殺されるってのがよくわかるっす」。（出典: 227）

- 229: 凛のリーフィアが黙って「深度：3」を覗きに行った。ちょっと変わった植物に触れると体力と一緒にたぶんデータも奪われ、群れの一角らしいポケモンがすぐ来た。遠目に見えた『ヌシ』らしいポケモンからは''わざわい''じみた嫌な気配がした。（出典: 229）
