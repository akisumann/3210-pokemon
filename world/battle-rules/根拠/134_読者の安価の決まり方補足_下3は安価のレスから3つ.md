# 読者の安価の決まり方（補足: ユーザーより）: 「下3」は安価のレスから3つ目のレスを採用する、掲示板の安価の普通の決まり（多数決ではない）

↑ [読者の安価の決まり方（補足: ユーザーより）](../../battle-rules.md#読者の安価の決まり方補足-ユーザーより)

- 「下3」は安価のレスから3つ目のレスを採用する、掲示板の安価の普通の決まり（多数決ではない）。議論で大勢が決まっていれば3つ目もそれになるが、割れたままだと誰の案が通るかは位置しだい（032のT4は、直前の投票はすてみタックルが多かったが3つ目の「交代 ルサルカ」が通った）。
