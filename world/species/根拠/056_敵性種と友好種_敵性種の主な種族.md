# 敵性種と友好種: 敵性種の主な種族:

↑ [敵性種と友好種](../../species.md#敵性種と友好種)

- 敵性種の主な種族:（出典: 007, 011）
  | 種族 | 特徴 |
  | --- | --- |
  | **モンハン**種 | ドラゴンタイプが多く、種類が豊富。大型ポケモンが並ぶ。たいていは統率B以上が必要。「統率型」のトレーナーに一番向いている。体力は高い（補足: ユーザーより） |
  | ┗ **古龍** | モンハン種の上位。ダンジョンの深部にすみ、自然現象をも操ると言われる屈指の強豪。プロのBランクでもごくわずか、Cランクにはいない。古龍でなくても''古龍級生物''と数えられるものがいる（《暴食プレデターズ》の''凶暴竜''イビルジョー。地方屈指のパワー、424） |
  | **アラガミ**種 | 強力な種族。上位は古龍に追随するものもいる。「亜人」に強い。オウガテイルはその下位種。プリティヴィ・マータ（こおり/じめん。《暴食プレデターズ》の『アヴェンジャー』）は''アラガミ''の一角（426） |
  | 深海棲艦 | 例: 駆逐棲姫（《血風ドリフターズ》、421）、戦艦レ級（みず/あく。《暴食プレデターズ》の『二枚看板』で『島のヌシ』）。戦艦レ級は「深海棲艦」の中でも顔とも言える種族（天花、426） |
  | 蟲惑魔 | むしタイプを持つと思われる。例: トリオン（むし／じめん） |
  | 使徒 | 454で、《灰翼エグリゴリ》の『エース』が“使徒”種との混血（『ハーフ』）と出た（白い髪で赤い瞳）。456の図鑑で渚カヲル（ノーマル/エスパー）と確定し、『ハーフ』の表示は「人間と「使徒」の混血の『変種』」。種属は『半使徒の〜』で、自陣の「リフレクター」等の壁と組む（『ATフィールド』も）。461の正式データでLv145の『エース』。モズグスは「使徒カヲル」と呼び、カヲルは人間を「リリン」と呼ぶ（461） |
  | 吸血鬼 | 名前だけ登場 |
