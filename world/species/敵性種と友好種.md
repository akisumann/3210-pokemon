# 敵性種と友好種

- **大雑把な危険性のカテゴリ**: 敵性種／友好種は、細かい分類というより「この種族は人を襲いますよ」という大雑把な危険性の目安（補足: ユーザーより）。野生を仲間にするには、友好種でも力で示す必要がある（捕獲は弱肉強食。補足: ユーザーより）。差が出るのは、出会ったときに向こうから人を襲ってくるか（011）と、仲間にしたあと従わせ続けるのに要る「統率」（友好種はC～D、敵性種はB以上。052, 369）。
  - 「友好種」で穏やかな気性の種は、最初にふれあうポケモンとしては悪くない（カナヲ。「ガッシュ」種の評価は''プロとしての道を歩むにはかなり難しい種''だが、369ではガッシュを最初のパートナーにしようとする子が増えている）。（出典: 369）
  - ''同じ種族でも個体によっては大きく変わる''ことがあり（ガッシュは潜在能力がかなり高いらしい）、その性質を引き出すには''ある程度以上の「育成」''が要る。早く「C」で頭角を現したいなら、''晩成型''より''早熟型''、最初から強い選手の方が需要が高い。（出典: 369）
  - **教科書と個体差**（387、配信のコメント欄）: スクールの授業や教科書に書いてあるのは''その種の全部''ではないが、これまでの研究データをもとに''大まかな方向性や特徴を抑えてある''のも事実（コメS・コメT）。カズマ「やっぱり強いヤツもいるし''種族っていう雑多な括り''だけで判断するよりも」。プロに行くトレーナーもポケモンも''選別を勝ち抜いた者''が前提（コメT）。友好種は、「統率」の高くないトレーナーや「育成」で力を引き出せるトレーナーから人気（白野）。マックイーンの活躍で、スクールでも「ウマ娘」へのスカウトがすごく増えている（コメS。369の門下生の話と同じ）。ただしマックイーンを「ウマ娘」の標準にするのは無理がある（白野）。（出典: 387）

（出典: 011, 369, 387）

- 「**ルサルカ**」種の本質は、夢魔に近い。色香と幻覚で惑わし、相手の精力をいただく。純正の「吸血鬼」種ほどではないが、そういう生態もある。見た目を幻覚で盛ることもできる。（出典: 090）
  - 伸び方は、『キラー』『アヴェンジャー』方面（敵性種らしさをガチガチに発揮する）と、『アシスト』方面（拘束・妨害して味方へつなぐ）に分かれる。（出典: 025, 090）
  - 条件しだいで『**アシスト』特化型**（『エースアシスト』の効果を、ほかの『役割』の選手にまで広げる）に伸びることがある。「異性からの愛を受けた「ルサルカ」種」に前例がある（ダージリンが取り寄せた敵性種の資料、凛の育成書）。（出典: 090）
  - 育成指南書: 「彼女たちが人に対し愛を取るか、餌と見なすかで「ルサルカ」種の方向性は決まるでしょう」。（出典: 091）
  - 「ルサルカ」種の『専用』は『キラー』や『チェイサー』がメインで、『アシスト』に『絆』と『専用』の枠を割くのは、思いついても実際にやるヤツはほぼいない（単純な『アシスト』方向の種族ではまず無理）。種族の伸び方は『アシスト』方面か『キラー』方面かと極端。カズマのルサルカも初期は評価が高くなかった。（出典: 387）
  - 実例: カズマのルサルカは、『愛の絆』を得た直後に種族値が上がり（特攻A、特防AA-、体力B-→B+）、『水魔女の魔術』（『絆』がある時、『アシスト』が味方のだれに対しても必ず発動する）を得た。『アシスト』の方向に進んでいたからこそ、ここで一気に伸びた（『エースキラー』ルートなら違う成長だったかも、とカズマ）。「多くのチームで1枠しかない『絆』を『アシスト』に割く」という条件の重さの分だと、ルサルカは見ている。（出典: 098）

- 「**KAN-SEN**」種、「**艦娘**」種: 海の多いホウエンにはたくさんいる。シンオウでは珍しい。例: ベルファスト。「艦娘」種の例に、セシリアの『エース』の戦艦''金剛''（410, 413）。エドの《機鋼アルケミーズ》（ミオの企業がスポンサー）の『エースキラーβ』ビスマルク（「みず/はがね」）も「艦娘」の選手（カズマ「港町だけあって「艦娘」の選手もいたはずだったな」、505。510・513の図鑑で種属は『鉄血艦の〜』）。（出典: 030, 410, 413, 505, 510, 513）

- 「**四大精霊**」: 十八竜に匹敵する歴史を持つ四大元素の一角。例: ウンディーネ（みず／ノーマル）。（出典: 032）
  - 4種族は**イフリート、ウンディーネ、ドワーフ（大地）、エルフ**（479、アカネ・クーデリア）。479の時点で、シンオウリーグに“四大精霊”の4種族の『天賦の才』（頂点の才）がそろった: 「イフリート」は《黒鉄キャバルリィ》の『エース』ホムラ（094）、「ドワーフ」は地の四天王さみだれの手持ちの“法明堂羅刹”（「地」を司る者。調査に興味津々）、「エルフ」はハクタイに来た新戦力の『変貌大妃』（「へんげんじざい」。元はカロスのチームの『エース』。→ [pro-team.md](../pro-team.md) の「スポンサーとしての街」）。羅刹いわく、《アーカイブス》やクロガネのチームと違って、自分のチームの『エース』は（四大精霊ではなく）エレン。推測: 残る「ウンディーネ」の『天賦の才』は《図書館アーカイブス》の『エース』。（出典: 094, 479）
  - 「エルフ」は本来、要「統率」が低い種族（アカネ、479）。凛のティファニアは「エルフ」の『金冠サイズ』（071）。484で、ジータの新入りのネネカ（カロスから来たピンクのポケモン。ハクタイジムに一時的に籍を置いていた）が『エンペラー』として出てきた。479の『変貌大妃』の説明と一致する。（出典: 071, 479, 484）
  - 「ドワーフ」との混血: エドの《機鋼アルケミーズ》の『エースアシストβ』リズベット（「じめん」、Lv155）は、人間と「ドワーフ」の混血の『ハーフ』（513の図鑑。種属は『鍛治娘の〜』で、鍛冶の娘）。（出典: 513）

- 「**シスターズ**」種: エネルの手持ちのミサカワースト（『絆』はなく、エネルのメンバーの中で一番新参の紅一点）。天花の見立てでは、原種に比べると大柄で、『変種』か進化形かそれ以外かはわからない。天花がすぐわかったのは、黒子がすごく気に入っていて、「エーテル財団」にも何人かいるから。ワーストはデータを取るのが得意分野と言う。（出典: 486）489の図鑑でワースト（「でんき/あく」）は『**金冠サイズ**』（「シスターズ」の最大サイズである『固有種』。「体力」種族値に大きな上昇補正を得る）を持っていて、大柄なのはこのため。天花は、「シスターズ」種の体力はさほど高くないが、『金冠』ならざっと2ランク上昇で「A～A+」と見ていた（黒子の話のうろ覚え、488）。（出典: 488, 489）

- 「**ウマ娘**」種: 例: メジロマックイーン、マンハッタンカフェ。全体的に「育成」と相性がいいと言われる。スピードに優れるので、鍛錬で「しんそく」のような技も覚えるらしい。（出典: 020, 129）
  - **メジロ家とサトノ家**（445）: マックイーンは''メジロ家''の分家。メジロ家は人界にもダンジョンにも属さぬ“隠れ里”（ハクタイの南側）の領主の一族で、領主など上は人界とも伝手がある。''サトノ家''はメジロ家と異なり、人界の文化に完全に溶け込む道を選んだ一族で、トバリの出版社“シャングリラ通信”の創業一族（サトノダイヤモンド）。両家には今も交流がある。身内がトレーナーの手持ちになって気がついたらいなくなるのは、この世界では珍しくない（マックイーン）。（出典: 445）
  - **ウマ娘の人気**（445、ダイヤ・サンラク）: 強豪にもウマ娘はいる（ズイの「そだてや」のスズカ、他地方のチャンプの手持ちなど）が、シンオウではマックイーンが屈指の人気で、“隠れ里”からもデビューを目指すポケモンが出てきている。
    - ハクタイの都市チームもそれに触発されて『芦毛の怪物』を引き入れたとか（バーゲスト）。
    - 『愛の絆』（実際は『魂の絆』）持ちのウマ娘が『二枚看板』というのが、同じ種族や似た性質のポケモンに刺さる。
    - （出典: 445）477ではウタいわく、マックイーンは今シンオウの「ウマ娘」界隈でシンデレラストーリーのように言われていて、そのせいでドラマの手持ちに「ウマ娘」種の案も出ている（「友好種」で小さい子もターゲットにできる、カズマ）。
    - 480では山岡いわく、マックイーンはシンオウの「ウマ娘」たちから絶大な注目を集めていて（ズイの「そだてや」の沖野も絶賛）、強いチームの主力というだけでなく「統率」の『二枚看板』という部分がインパクトになり、コトブキのスクールやヨスガのコンテスト関連などから憧れの声が上がっている。
    - マックイーンの食レポ記事は特に「ウマ娘」関連の読者に好評だった。（出典: 477, 480）

- 「**バハムート**」種: 陸の「ベヒーモス」、海の「リヴァイアサン」と並ぶ、要「統率：A」の怪物級の種族。原種ですらモンハン種の古龍のような存在。メリュジーヌはその『天賦の才』（原種とは違う姿で、「原種の姿」にもなれる）。友達に「フェンリル」種の『天賦の才』もいる。（出典: 134）
  - 《騎空ヴァーレリア》（「B」の「統率：AA」のチーム）の『二枚看板』も、空の伝説と言われる「バハムート」（ヴィルヘルム、504）。
    - カズマは（AA内）「メスガキの原種、天子のベヒーモスと同格のポケモンか…」と受け取った（メスガキはメリュジーヌのことと読める）。
    - 505の対策ミーティングで、《騎空ヴァーレリア》の監督はモニカ・ヴァイスヴィントと分かり、ライザがその『二枚看板』を「空の伝説とも言われる「バハムート」……「ひこう/ドラゴン」タイプ」と紹介した（484のモニカの『二枚看板』“バハムート”と同じ）。
    - 514・517の図鑑で、モニカのバハムートは「ドラゴン/ひこう」、Lv155、特性「かたいウロコ」、『高地のヌシ』と『ヌシの特権』を持つ（どこのダンジョンの『ヌシ』だったかは出ていない）。
    - 種属は『空魔竜の〜』3つ。
    - ヤマトは516で「あの腐れロリのボスの原種、だってねぇ？」と言った（メリュジーヌの原種という意味と読める。504のカズマの「メスガキの原種」と同じ）。
    - ライザは、バハムート・ディアウス・ピター・アカムトルムも、本来はクシャルダオラと同じ要「統率：A」の怪物と言った（519）。（出典: 484, 504, 505, 514, 516, 517, 519）
  - 陸海空の三魔獣、フェンリル、ベルゼブブなどの伝説級の種族は → 下の「伝説のポケモン」の「伝説級の魔獣」。

- 「**リザードマン**」種: 例: クロコダイン（先輩の手持ち、『金冠サイズ』）。466の図鑑の『金冠サイズ』の表示は「「リザードマン」の最大サイズである『固有種』」で、タイプは「ドラゴン/いわ」、特性「がんじょうあご」。体力は『金冠サイズ』と『ヌシの特権』でAAA前後と見られる（推測。リー「クロコダインの奴に匹敵する体力」をガブリアス（AAA）に、先輩「こりゃクロコダインより体力ありやがるか」をライナー（S）に。[hp-estimates.md](../hp-estimates.md)）。（出典: 138, 140, 463, 465, 466）

- 「**長尾景虎**」種: 上杉謙信（先輩の『ベテラン』、「こおり/ドラゴン」）の原種。謙信は元『天賦の才』だったが、『ベテラン』になって天凜がこぼれ落ち（390）、466の図鑑では『変種』（「原種である「長尾景虎」種とは異なる生態を持つ」）。（出典: 390, 462, 466）

- 「**グレイモン**」種と「**ガルルモン**」種: 歴史的なつながりがあり、メタルガルルモン（ワイス）は《四天フレイムハート》の『エース』ウォーグレイモンと対になると言われる種族（サンラク、バーゲスト「詳しくはないですが」。どちらも『天賦』ではないはず、467）。（出典: 467, 471）

- 種族値の「**600**」の壁: 素で600を超えると見られるのは、カズマの手持ちではガブリアス、ライナー、ヤマト（アバン談）。
  - クインビーズでは新加入の『金冠サイズ』や深海棲艦の『アヴェンジャー』。
  - （出典: 142）「600」族という言葉が残っているほど、素でその種族値に達しているポケモンは強力（「どのバスケ部にも身長190以上が3人も4人もいるわけでもなし」。黒子、429）。
  - 《暴食プレデターズ》の『エース』イビルジョーと『二枚看板』戦艦レ級も、当然のように種族値は「600」では済まない（カズマ、426）。（出典: 426, 429）。
  - 435の作者: 操祈の手持ちではロータス“アクセル”とベリアルが「600」クラス（ベリアルは素で「600」クラスで、『ヌシの特権』でワンランク上昇）、種族値増強（『金冠サイズ』『尾獣のチャクラ』）のリオハートとキラービーがそれを超える（「このクラスの種族値ですからね「600」って、そういうラインよ」）。
  - 補強なしで「600」族超えが当たり前の環境ではなく、ガブリアスがヤバイ扱いだった時点でスレの基準は出ている。
  - 種族値だけで決まらないが、種族値の高い奴が有利なのも事実で、そういう奴らは要「統率」が高い傾向（出典: 435）

- 「**ロトム**」種: 古代種（実機のポケモン）。家電に入り込める。森の洋館のロトムは家電に入り込むうちにいろいろな姿に変われるようになり、「炎」「水」「氷」「草」「飛」の技が使える。昔アローラでは「ロトム図鑑」も作られていたらしい（天花談）。（出典: 128, 129）

- ほかの系統: 「**ゾイド**」種（例: ブレードライガー。はがねタイプの高速アタッカーで、統率Cで使える）。
  - （出典: 014）いろいろなトレーナーが使う、はがねタイプの鉄板の種族（補足: ユーザーより）。
  - 元々そう多くの技を覚える種族ではない（渚、015。ブレードライガーは最大火力がまだ「メタルクロー」）。
  - 実際に、新人（渚のブレードライガー、014）から「C」ランク（ダージリンのディバイソン077、千束のコマンドウルフ136）、ジムリーダー（イングリッドのアイアンコング117、エミヤのライガーゼロ328）、「B」ランク（万丈目のジェノブレイカー191、ボンドルドのバイオトリケラ264、クラウドのムラサメライガー403）まで、どの層にも出てくる（→ [属ポテンシャル『ゾイド』](../potential-list-genus.md)）。
  - 属ポテンシャル『ゾイド』（「鋼」ポケモンを倒した時、自身の体力を1/2回復する）を持つ。
  - 例: ディバイソン（ダージリン）、ジェノブレイカー（万丈目）、ライガーゼロ（エミヤ）、ムラサメライガー（クラウド。はがね/でんき。天花は見た目から「相手は「ゾイド」種のポケモンになるのかな？」と見て、403の図鑑で『ゾイド』が出た）など（ほかの持ち主は → [potential-list-genus.md](../potential-list-genus.md)）。（出典: 191, 328, 403）
