# 体力の推測：ダメージ表示の目安（推測）

「〇〇のダメージ」が、1発で最大体力のどのくらいかの目安の表だけ。作者の明言（021の「まずまず」）、集計の数え方、場面ごとの計算での確認は [hp-estimates-display-notes.md](hp-estimates-display-notes.md) に全部残している。

入口: [体力の推測とダメージ表示](hp-estimates.md)（決め方・重要な考察・相手チームの一覧）

## ダメージ表示の目安（推測）

根拠: [hp-estimates-display-notes.md](hp-estimates-display-notes.md#ダメージ表示の目安推測)

| 表示 | 1発で最大体力のどのくらいか（**厳密な範囲**。補足: ユーザーより） |
| --- | --- |
| 微々たるダメージ | 1/8未満 |
| 小さなダメージ | 1/8〜1/4 |
| まずまずのダメージ | 1/4〜1/3 |
| 大きなダメージ | 1/3〜2/3 |
| 特大のダメージ | 2/3〜1撃ギリギリ |
| 極大のダメージ | 満タンでも1撃（体力が特に高い相手は例外） |
| 測定不能のダメージ | 満タンの2倍以上（体力が特に高い相手は例外） |
| 深刻なダメージ | 大きさではなく、受けたあと残り1/6以下になった時の表示 |
| 皮一枚のダメージ | 残りを削り切るが体力1で残る |

- この境目は作者の前作のスレの基準で、このスレでも厳密にこのとおり（補足: ユーザーより、2026-10-24）。前は集計から「〜割くらいの幅」として見ていたが、その列は外した（集計の記録は [hp-estimates-display-notes.md](hp-estimates-display-notes.md) に残している）。
- 「＠N」は「同じダメージであと N 発で倒れる」の意味。満タンからなら1発の割合は「1/(N+1)以上、1/N未満」（[計算方法の検証](hp-estimates-kazuma-notes.md)で、この読みで8場面が合った）。逆算では、乱数の幅（下の方〜上の方）を入れて、「＠N」は「受けたあとの残りが、最大の1発のN−1発分より多く、乱数の下の方の1発のN発分以下」、「＠N～N+1」は「乱数の下の方のN発分より多く、最大のN発分以下」と読んでいる。「＠2～」（後ろの数がない形）は「2発以上かかる」とだけ読み、残りが乱数の下の方の1発分より多い、とした（推測。「＠2～3」のように読むと、クロコダイン（465）などが合わなくなる）。
- 「深刻なダメージ」と「皮一枚のダメージ」は、ダメージの大きさではなく、受けた後の残り（「深刻」＝残り1/6以下）を表す表示（入口の [hp-estimates.md](hp-estimates.md) の「重要な考察」）。
- ゲームで回すときは、表示はいつも「最大体力」に対する割合で決める（補足: ユーザーより）。
