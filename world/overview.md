# 世界観の概要

## 作品

- タイトル: 『この素晴らしいシンオウに祝福を！』（出典: 001）
- 構成: 「キャラ作成編オープニング」（000）のあとに本編の第1話（001）が続く。
- 形式: 台詞、【System】ナレーション、ダイス判定（【1D100:xx】）で進むスレ形式の物語。原典はAAを文章に置き換えた「AA意味文変換」版。（出典: 001）
- 【System】のナレーションは作中の事実として扱う。（補足: ユーザーより）
- タイトル、主人公の名前（カズマ）、アルセウスの「腐れ縁」に「ｱｸｱ」、「後輩」に「ｴﾘｽ」とルビが振られていることから、『この素晴らしい世界に祝福を！』のパロディだとわかる。（出典: 000）
- 安価・ダイス・AAの途中茶々など、スレ形式ならではの決まりは → 下の「メタ要素」

## 世界の成り立ち

- 創造神**アルセウス**が、召喚した人間を転生させることがある。→ [characters/pokemon/arceus.md](../characters/pokemon/arceus.md)
- アルセウスの本来の目的は、勇敢な少年少女を召喚して「**ヒスイ地方**」へ使命を与えて送り込むこと。（出典: 000）
- **シンオウ地方**はアルセウスの「お膝元」。（出典: 000）
- カズマが送られたシンオウと、ヒスイ地方へ旅立った「彼または彼女」（ポケモンLEGENDSの主人公）の話は「別の時空」として区別されている。（出典: 000）
- ヒスイ行きは「いい感じの主人公」だけ。外れたカズマはテキトーにシンオウへ → [根拠](overview/根拠/001_世界の成り立ち_ヒスイ行きはゲームポケモ.md)
- ヒスイの話とカズマのシンオウ、どちらが先の時代かは原典で決まっていない → [根拠](overview/根拠/002_世界の成り立ち_ヒスイの話とカズマのシン.md)

## 舞台

- **シンオウ地方**が舞台。（出典: 001）
- 世界には「**八大地方**」があり、シンオウはその一つ。世界で一番栄えた地方というわけではないが、なぜかそう呼ばれている。（出典: 002）
- **カントー地方**は「**はじまりの地方**」と呼ばれ、八大地方の筆頭とも言える。（出典: 002）
- 主な地名はハクタイシティ（ハクタイジムなど）とテンガン山 → [根拠](overview/根拠/003_舞台_主な地名詳しくはplac.md)
- シンオウの地下には、地方全域をつなぐ広大な空間「**地下大洞窟**」がある。「あなをほる」を使わないと行けない。一般にはほとんど知られていない。→ [places.md](places.md)（出典: 009）

## 人界と野生の均衡

人の暮らす世界（''人界''）と、ダンジョンの奥にいる野生のポケモンの群れは、戦力差による抑止で並び立っている（出典: 310。凛とアカネの説明）。ダンジョンそのものは → [dungeon.md](dungeon.md)
- 世界は「街／ダンジョン」の二つに分かれているわけではない: 深度のような区域指定があるのはダンジョンの中だけ → [根拠](overview/根拠/004_人界と野生の均衡_世界は街／ダンジョンの二.md)
- 異界のヌシが怖いのは本拠地と群れの中。外に出ると脅威は格段に落ちる → [根拠](overview/根拠/005_人界と野生の均衡_ヌシの脅威は本拠地にある.md)
- 異界の展開は空間が変わるだけで隔離ではない。外から救援に入れる → [根拠](overview/根拠/006_人界と野生の均衡_異界の展開は隔離ではない.md)
- ヌシの襲撃は地元が粘る間に上位勢が集まり、ダンジョン一つなら鎮圧できる → [根拠](overview/根拠/007_人界と野生の均衡_人界の防衛の段取り.md)
- その戦力差を野生も分かっているので、軍団で人界を攻めることはまずない → [根拠](overview/根拠/008_人界と野生の均衡_抑止で成り立っている.md)
- 防衛の穴は電撃戦、同時攻撃、そしてヌシが単独で個人を攫いに来ること → [根拠](overview/根拠/009_人界と野生の均衡_穴になりうるもの.md)
- 単騎で飛んできて個人を攫う誘拐は止める手段がない。一人の時が危ない → [根拠](overview/根拠/010_人界と野生の均衡_単騎での誘拐は防衛網の話.md)
- 推測: ジムリーダーがダンジョンのある街にいるのは、防衛の最前線だからかも → [根拠](overview/根拠/011_人界と野生の均衡_推測ジムリーダーが全員A.md)
- 人の世界の治安の考え方は → 下の「社会・文化」の「治安」
- 野生の暮らし方（群れ、子育て、名前、人界との行き来など）は個々でばらばら → [根拠](overview/根拠/012_人界と野生の均衡_野生の暮らし方は個々でば.md)

- 戸籍・身分の扱いは、現実と比べて桁違いにゆるい → [根拠](overview/根拠/014_制度協会・戸籍・結婚・年_戸籍・身分の扱いは現実と.md)
- 就職と資格:

  - プロ以外でも、ポケモンは力仕事や運送など一般の仕事で働いている → [根拠](overview/根拠/016_制度協会・戸籍・結婚・年_プロ以外でもポケモンは普.md)

  - トレーナーになるのにも免許はいらない → [根拠](overview/根拠/018_制度協会・戸籍・結婚・年_トレーナーになるのにも免.md)
- 年齢の区切り: 10歳から旅ができる → [根拠](overview/根拠/019_制度協会・戸籍・結婚・年_年齢の区切り.md)

### くらし（医療・食・通貨・道具）

- 「コンビニ」「カップ麺」「雑誌」「マンション」「大家さん」など、現代日本に近い生活がある。「パワハラ対策」という言葉も出てくる。（出典: 000, 001）
- ポケモン関係以外の技術は元の世界より遅れ気味。記録媒体はまだカセット → [根拠](overview/根拠/022_くらし医療・食・通貨・道_技術と文化の差.md)
- 通貨の単位は「円」。ただし日本の円は通じない → [根拠](overview/根拠/023_くらし医療・食・通貨・道_通貨.md)
- 道具: この世界の道具は、値段も高いが性能も元の世界と比べて明らかにおかしい → [根拠](overview/根拠/024_くらし医療・食・通貨・道_道具.md)
- ポケセンでは、登録したトレーナーとポケモンが上限つきで無料で飲食できる → [根拠](overview/根拠/025_くらし医療・食・通貨・道_ポケモンセンター.md)
- 医療はとんでもなく発達している。治せないのは年齢による体のガタ → [根拠](overview/根拠/026_くらし医療・食・通貨・道_医療はとんでもなく発達し.md)
- **ポケモンの給料の使い道**は、ポケモンによって様々（補足: ユーザーより）。
- 喫茶店の定番はモーモーミルク。焼肉も好まれ、お菓子はポフィン → [根拠](overview/根拠/027_くらし医療・食・通貨・道_食文化.md)
- お酒の規制はゆるい（1桁の子はNG）。ポケモンの方が酒に強い傾向 → [根拠](overview/根拠/028_くらし医療・食・通貨・道_お酒.md)

### 死と信仰（危険・弔い・信仰）

- ポケモンは今やとても身近な存在で、同時に危険な存在でもある → [根拠](overview/根拠/029_死と信仰危険・弔い・信仰_ポケモンは今やとても身近.md)
- ゴーストタイプがいるので魂や死後は身近な事実。葬式はきっちりやっていそう → [根拠](overview/根拠/030_死と信仰危険・弔い・信仰_弔い.md)
- 神話では、アルセウスがシンオウの創造神とされている → [根拠](overview/根拠/031_死と信仰危険・弔い・信仰_神話ではアルセウスがシン.md)
- 信仰は利益があるからする: 宗教にとって死後の世界はせいぜい一側面にすぎない → [根拠](overview/根拠/032_死と信仰危険・弔い・信仰_信仰は利益があるからする.md)
- 信仰は土地や人ごとにいろいろ。ヨスガの教会やグレゴリ教などがある → [根拠](overview/根拠/033_死と信仰危険・弔い・信仰_信仰は土地や人ごとにいろ.md)

### メディアと芸能

- テレビ局: コトブキシティのテレビコトブキ → [根拠](overview/根拠/034_メディアと芸能_テレビ局.md)
- テレビコトブキのブリーダー番組が、「育成」型の超人レスリング番組になった → [根拠](overview/根拠/035_メディアと芸能_ブリーダー番組からレスリ.md)
- SNS「**ポケッター**」がある。新聞社もあり、プロリーグのルーキーを記者が追いかける。（出典: 051, 053）
- プロのチームは人気商売で、ファン文化があり子どもたちにも影響を与える → [根拠](overview/根拠/036_メディアと芸能_ファンとプロの影響力.md)
- 歌姫ウタはカズマ由来の歌で大人気。新曲アカシアとPVをシンオウ全体で作った → [根拠](overview/根拠/037_メディアと芸能_歌と芸能.md)
- ポケモンコンテスト: ヨスガシティの名物 → [根拠](overview/根拠/038_メディアと芸能_ポケモンコンテスト.md)
- **ポケスロン**: ジョウト地方で有名なポケモン競技。全10競技で、3匹で3つの競技の合計点を競うチーム戦。参加するポケモンは「ポケスリート」と呼ばれる。（出典: 053）
- ジョウト地方には、虎柄の野球チーム「**エレブーズ**」がある。（出典: 010）
- **ポケモンだいすきクラブ**（PDC）: 全国にある団体。シンオウ本部はヨスガシティ。プロトレーナー（天羽奏）が所属していて、会長はキアラ。（出典: 025, 026, 027, 028）

- ポケモンバトルがプロスポーツとして成り立っている。→ [pro-trainer.md](pro-trainer.md)
- 「トレーナー同士、目が合ったらポケモンバトル」という言葉が今も受け継がれている。（出典: 013）
- 超能力を持つ人間もいる: 「はかいこうせん」を撃ってくる人間もいるらしい → [根拠](overview/根拠/039_バトルと人々_超能力を持つ人間もいる.md)
- 「**メガシンカ**」がある（食蜂操祈のスピアーなど）。使える条件や仕組みは → [species.md](species.md) の「メガシンカ」（出典: 053, 054）
- **オーキド博士**はこの世界の**偉人**。一方、サトシのことは誰も知らない。（出典: 002）
- ナナカマド博士の名は代々受け継がれるもので、今代は碇ゲンドウ。（出典: 039）
- ジョウト地方のエンジュシティには、ポケモンバトルもしない名家がある（禪院家）。（出典: 021）
- ギンガ団は社員や幹部、給料があり、会社のような組織として描かれている。→ [ginga-dan.md](ginga-dan.md)
