# ポケモンの基本

関連: [種族・系統](species.md) / [ポテンシャル](potentials.md) / [ポテンシャル一覧](potential-list.md) / [バトルの細かい仕様](battle-rules.md) / [図鑑](pokedex.md)

## 存在

- 種類は151匹よりずっと多い。「151匹」は「どれだけ昔の話だ」と言われるほど古い知識扱いになっている。（出典: 001）
- 人間と会話するポケモンがいる（ゼットン、ディオスクリア、ガッシュ）。見た目が人間やロボットのようなポケモンもいる。（出典: 000, 001, 002, 003）
- ゼットンは、カズマがコスプレイヤーだと勘違いするほど人に近い見た目をしている。（出典: 001）
- 原作にない名前の生き物も存在する。ゼットン、ディオスクリア、ガッシュ、野生のクシャルダオラなど。（出典: 000, 002）
- ほかの作品（ウルトラマン、モンスターハンター、金色のガッシュ!!など）から来たキャラクターは、ポケモンとして存在する場合と、人間として存在する場合がある。（補足: ユーザーより）
- ポケモンは身近な存在であり、同時に危険な存在でもある。（出典: 002）

## 生まれ方

- ポケモンはすべて**タマゴから生まれる**。（出典: 003）
- **寿命**: ポケモンの寿命は種によってばらばら。何万年も生きられる者も平然といる（補足: ユーザーより）。
- **育つ速さ**: 体が大人になるまでの速さも、人間とは別物と考えられる。ヤマトはおそらく0歳で一人旅をしていた（補足: ユーザーより。→ [overview.md](overview.md) の戸籍の項）。
- 子育て: 種によって全然違う（補足: ユーザーより） → [根拠](pokemon/根拠/001_生まれ方_子育て.md)
- **タマゴの期間**: 「タマゴができるまで」「タマゴを生むまで」「タマゴが孵るまで」の期間は個体差が大きい。亜人はこの3つのうち2つが比較的長いという研究結果がある（先代）。（出典: 303）

## タイプ

- タイプの特徴は第五世代準拠（でんきタイプも麻痺する、ゴーストにも「くろいまなざし」が効くなど）。（出典: 034）
- カズマが知っている頃（初代）より種類が増えていて、見覚えのないタイプもある → [根拠](pokemon/根拠/002_タイプ_カズマが知っている頃初代.md)
- 原作と同じタイプがある。例: ほのお（ゼットン）、でんき（ガッシュ）、くさ（凛のジム）、ゴースト、ノーマル。（出典: 001, 002, 003）
- タイプ相性がある（「ゴーストの技はノーマルに効かない」）。（出典: 001）

## バトルの要素

- 技、「**持ち物**」、「**特性**」がある。持ち物と特性の知識は義務教育レベル。（出典: 002）
- チームの中の**ポジション**（『エース』など）への**適性**が、種族ごとに決まっている。→ [trainer-stats.md](trainer-stats.md)（出典: 002）
- 戦闘は原作ゲームのような流れで進み、特性や持ち物も原作どおりに発動する → [根拠](pokemon/根拠/003_バトルの要素_戦闘は原作ゲームのような.md)

## 図鑑に載るデータ

ポケモン図鑑では、次のような項目が確認できる。（出典: 007, 011）
- 名前、レベル（Lv）、性別
- タイプ
- 特性（効果つき）
- 持ち物
- 技（「技x5」のように、覚えている数も表示される）
- ステータス: 5つの能力が S〜E の文字ランクで表示される（例: すばやさ「AA-」） → [根拠](pokemon/根拠/004_図鑑に載るデータ_ステータス.md)
- **ポテンシャル** → 下の節
- 種族値という概念もある（ガッシュ「合計種族値700が見える」、先輩「600族とかそういうレベルじゃない」）。（出典: 007, 011）

## 持ち物

- 技、特性と並ぶバトルの要素（上の「バトルの要素」）。協会が勧める「もちものセット」、個別の持ち物の仕様、作中に出た持ち物の一覧は → [battle-rules.md](battle-rules.md) の「持ち物」。

## わざマシン

- 昔は技を覚えるアイテムだったが、今は「**わざを繰り出すためのアイテム**」。「もちもの」に分類される。（出典: 018）
- 持たせると、**バトル中に一度だけ**その技を出せる。一度使うとそのバトル中はもう使えない。けっこう高価。（出典: 018）
- わざマシンの「消費」は試合の中だけで、試合後も手元に残る（補足: ユーザーより） → [根拠](pokemon/根拠/005_わざマシン_消費はその試合の中だけで.md)
- ジムをクリアするともらえる（クロガネジムは「わざマシン：ステルスロック」）。（出典: 015, 018）
- ジム以外でも手に入る。凛がクジで当てた「キングシールド」をカズマが賭け試合で得た → [根拠](pokemon/根拠/006_わざマシン_ジム以外でも手に入る.md)

## 技

- この世界には「めざめるパワー」がない（「めざパは死んだ」）。（出典: 012）
- 「**技能拡張**」: 覚えていない技を何らかの手段で出すこと。わざマシンもその一つで、トレーナーの『固有』で出させることもある（エールの「さばきのつぶて」）。（出典: 050）
- 「ダーク」技は自分以外の全タイプにばつぐん。使い手はごく希少（補足: ユーザーより） → [根拠](pokemon/根拠/007_技_自分以外のすべてのタイプ.md)
- 覚えている技の数は4つとは限らない。育成で技の幅が増え、5〜8個の技を持つポケモンもいる（ルサルカは8個）。（出典: 042）
- 技の数の目安（沖野）: 現代種の平均は6、古代種は基本4。8あれば“めっちゃ器用”。沖野も長年の育成で9までしか見たことがなかったが、ロトムは『天電球の拡張』で10（195）。（出典: 195）
- 技の効果は「分類/タイプ/対象/威力/命中/直接攻撃か/追加効果」の形で表示される → [根拠](pokemon/根拠/008_技_技の効果は分類タイプ対象.md)
- 「おいうち」効果: 交代する相手に、交代の前に割り込んで当てる。威力は変わらない → [根拠](pokemon/根拠/009_技_おいうち効果交代する相手.md)
- 「こうかいまひとつ」「こうかはばつぐん」「きゅうしょにあたった」「測定不能のダメージ」などの表示が出る。（出典: 045, 047）
- 「追加行動」を得るポテンシャル（『ナハツェーラー』）でも、交代や「まもる」は他の行動ごと消費するので同時には使えない（例: 交代して同じターンに追加行動で技を出すのは原則不可）。（出典: 042）

## 能力ランク

- 能力ランクは1段階上がると1.5倍（凛から教わった、とカズマ談）。（出典: 011）
- 「ぐーんと上げる」は2段階。（出典: 045）

## 状態

- 「**充電**」状態: 「電」技の威力が2倍になる（「充電」：技2倍）。レヴィの『固有』で場に出るたびに付与された。（出典: 045, 046）
- ターン数に制限のある状態異常が交代で治らなくなること、強制交代では「場に出たとき」系が発動しないことなどは → [battle-rules.md](battle-rules.md) の「状態変化」「交代」。（出典: 045）
- 「しめつける」状態: 4〜5T毎ターンダメージ、『もどれ！』を含む通常交代ができない → [根拠](pokemon/根拠/010_状態_しめつける状態4〜5ター.md)

## 成長と強化

- 進化: フカマルがガバイト（037）、ガブリアス（042、Lv40）へと原作どおり進化した → [根拠](pokemon/根拠/011_成長と強化_進化.md)
- 育成: バトル以外でも、鍛錬でポケモンを成長させられる → [根拠](pokemon/根拠/012_成長と強化_育成.md)
- 育成の効率は、トレーナーの「育成」資質に左右される。（出典: 037）
- 「育成」は魔法ではなく鍛錬。レベル・技・ポテンシャルを伸ばし、一部を変えられる → [根拠](pokemon/根拠/013_成長と強化_育成は魔法ではなく鍛錬.md)
- 大昔には「**努力値**」という言葉もあった。ポケモンは努力で強さが変わる生き物。（出典: 011）
- 今では、鍛錬しだいで**ステータス、特性、タイプまで変わる**例も多く確認されている。（出典: 011）
- それを成し遂げるのがポケモントレーナー。ポケモンがどれだけ成長できるかはトレーナーしだい（先輩のトレーナー論）。（出典: 011）
- 「**進化**」をはじめ、ポケモンを強くする手段はいろいろある（「外法」も含めて）。（出典: 011）

## フィールド

- ポテンシャルやスタジアムで場に展開されるフィールド（《異界/テンガン山》など）は → [battle-rules.md](battle-rules.md) の「フィールド」。

## 捕まえ方

- モンスターボールがある。（出典: 002）
- **人間がボールに入るかどうか**は、はっきりしない。ただ、混血の進んだ今の世界なら、わりと入るのではないか（補足: ユーザーより。確定ではない）。
- カズマはモンスターボールを持っていないまま、ガッシュを仲間にした。（出典: 002）
- 常識として「ひとのポケモンをとったらどろぼう」。（出典: 003）
- 捕まえるのも捕まるのも弱肉強食。負けた方が勝った方につく（補足: ユーザーより） → [根拠](pokemon/根拠/014_捕まえ方_捕まえるのも捕まるのも弱.md)
- 人の姿のポケモンも、世間では「ポケモン」と日本的に割り切る（補足: ユーザーより） → [根拠](pokemon/根拠/015_捕まえ方_ウマ娘や艦娘魔女など人の.md)

## 人間とポケモンの『ハーフ』

- 人間とポケモンが子どもをつくることは普通にある。その混血の存在を『**ハーフ**』と呼ぶ。（出典: 003）
- ハーフには、人間側の血が濃いタイプと、ポケモン側の血が濃いタイプがある → [根拠](pokemon/根拠/016_人間とポケモンのハーフ_ハーフには人間側の血が濃.md)
- トレーナーと手持ちの色恋沙汰でガタガタになるチームも普通にある（奏談）。（出典: 043）
- 人間の伴侶とは別に、ポケモンと“**契り**”を結ぶ人もいる。人間とポケモンの価値観の違いがあるので、関係は一対一とは限らない（ルサルカ）。（出典: 189）
- 『ハーフ』でも『変種』のことがある（《未央レッドオーシャン》の恋は、人間と「呂布」の混血で『変種』。自身と同タイプの技のダメージを半減する）。（出典: 192）

## 姿を変えるポケモン

- 戦闘時に姿を変えるポケモンはそこそこいる（「特撮ヒーローみたいなもの」）。ライナーは巨人の姿と、人間と同じくらいの姿を使い分ける。（出典: 019）

## 名前

- 個体名を持たないポケモンも多く、種族名で呼ばれる（補足: ユーザーより） → [根拠](pokemon/根拠/017_名前_個体名を持たないポケモン.md)
- 名前があるかどうか、誰が付けるのかも、個体ごとにばらばら（補足: ユーザーより）。

## 言葉

- ポケモンによっては、言葉が翻訳されて『』で表示される（ルカリオ、サーナイト、フカマル）。（出典: 028, 029）
- 『』の翻訳は、そういう技術製品があるから。鳴き声しか出さないガブリアスでも、それを通せば話せる（補足: ユーザーより）。なので「言葉を話すかどうか」は、ポケモンを分ける線にならない。
- 「グルル」などの鳴き声が実際の発声で、『』の台詞はその翻訳（補足: ユーザーより） → [根拠](pokemon/根拠/018_言葉_モンスター系のポケモンが.md)
- 翻訳の製品は、聞く側のトレーナーも付けているのかもしれない（補足: ユーザーより） → [根拠](pokemon/根拠/019_言葉_翻訳の製品はポケモンに付.md)

## 化石

- 化石は**博物館**で復元してもらえる（クロガネシティ）。例: 「よろいのかせき」→ライナー・ブラウン。（出典: 019）
- クロガネ炭鉱でポケモンの化石を掘り当てられる。クロガネシティで復元もできる。（出典: 015）
- このように、特定のイベントをきっかけにポケモンを仲間にできる場合がある（System談）。（出典: 015）
