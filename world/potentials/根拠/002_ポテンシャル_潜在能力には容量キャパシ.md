# ポテンシャル: 潜在能力には「容量（キャパシティ）」がある

↑ [ポテンシャル](../../potentials.md)

- **潜在能力には「容量（キャパシティ）」がある**（補足: ユーザーより）。ポケモンごとに才能の量のようなものがあって、それを考えてポテンシャルが付く（育成で付ける）。**重要な考察**（原典を言葉で拾って調べた → [調査メモ](../../../notes/survey-capacity.md)。言い換えで拾えていないものはある）: この話は原典の各所に細かい記載や言い回しがある（「容量」「キャパ」「枠」「潜在能力」「個体のエネルギー」など、言い方はばらばら）。下は主なもの。
  - イカルガ「潜在能力の容量が明確に他のポケモンより高いはずです」（095）。リュカ「『天賦の才』にも匹敵するキャパシティを持つって言われてる」（371）。
  - 容量はポテンシャルと技で分け合うように語られる: モモ「割とポテンシャル群にキャパを割いてますし、「ギガドレイン」なんかは難しい」（238）。442は、モモの『第三階梯』の育成でこの話を正面からしている: 新しく『ダークネスローズ』『桃王女の大輪』などを付けるにあたり、カズマが「『属』別にするなら『クォーターロゼット』の方は……」と、今あるポテンシャルとの入れ替えを相談し、ハクタイ門下生Aが「「こどもだまし」や「ひかりのかべ」は残したいでしょうし、モモ本人も自分の容量を限界まで絞り出すくらいのつもりでやんないとダメかも」と言う。ポテンシャルの習得はイメージと連動し（蜂の針や薔薇のトゲ→「くっつきバリ」）、誰でもできるわけではない（442）。
  - 古代の伝説のポケモンは、この容量（個体のエネルギー）がけた違いと考えられる（補足: ユーザーより）。443でワイスは、フリーザーが普通は専用でようやく付けられる特殊役割『野生ポケモン』を「自身の内に秘めた力で再現出来る……それが古代の伝説級の力。種族値やらで対抗出来る古代種は他にいても、個体のエネルギーが段違い」と説明した。『○○の伝承』も、伝説の存在として独自に専用を持ち、全種族値に+補正を得る（443）。
  - リザードンの育成（『役割』なしの「すっぴん」。281〜）も同じ考え方で読める（補足: ユーザーより）: 『役割』に使うはずの容量を空けて、ほかのポテンシャルのブーストやメガシンカ・独自の専用に回す（→ 下の「『役割』なしの育成」）。
  - **容量は3つの出どころから成り立っていそう**（補足: ユーザーより。推測を含む）: ①ポケモン自身の容量、②トレーナーから分けてもらう分（専用の枠、トレーナーとの関係で生まれる絆、「〇〇がトレーナーの時」の異名など。338では、トレーナーの素養で専用の枠がなくても、ポケモンの潜在能力しだいで独自に専用を持てると言われている）、③特殊な道具によるブースト。③の例は、伝説の肉体の一部とされる道具を使った「育成」: グラードンの爪でライナーの岩の組成が組み変わり、特性「ふくつのたて」と「だいじしん」を得た（→ [battle-rules.md](../../battle-rules.md) の特性、[terms.md](../../terms.md)）、サンダーの羽でガッシュが『金雷児の雷槌』を得た（→ [potential-list-species.md](../../potential-list-species.md)）。マックイーンは、サントアンヌ号のカジノの景品の手綱（キズナのタヅナの模倣品。「統率」型用に作られた道具だったらしい）で『芦馬娘の手綱』を得て、攻がBからA+になった（289, 290, 325）。ガブリアスは、きんのおうかんを使った「育成」で属『オールドクラウン』を得た（307, 323, 325）（→ [mcqueen.md](../../../characters/pokemon/mcqueen.md)、[garchomp.md](../../../characters/pokemon/garchomp.md)）。
  - トレーナーから分けてもらう分は、原典ではっきり「枠」として語られる: 「能力：C」は『固有』が1個で「キャパ的に無理」（099）、『専用』枠（070, 338, 371, 442, 458）、『獣化』に『固有』枠を1つ割く（340, 392）、多くのチームに1枠しかない『絆』（098）。ポケモン自身の潜在能力しだいで、枠がなくても独自に『専用』を持てる（338）。
  - **「グラシデアの花」で容量に余剰ができた**（493, 494）: モモは「グラシデアの花」を髪飾りにして「育成」し、「限界近くまで使ってたキャパに余剰が出来た結果、攻撃技もパワーアップしちゃった」（モモ、493）。ベルゼブモンも「「グラシデアの花」と何やら相性が云々と言っていたが、キャパシティが向上した感じか？」と見た。技が「リーフストーム」「ムーンフォース」「なやみのタネ」から「シードフレア」「はめつのひかり」「テレキネシス」に変わり、特防がBからB+に上がった（イカルガは「体」と「特防」が「B」から「B+」くらいと言った）が、ポテンシャルは変わっていない（485と493の図鑑）。System は「本人的な認識では限界突破かもしれん」（493）。ルサルカも花をもらってすごく調子がよく、気がついたら強力な技2つ（「シャドーレイ」「ひっくりかえす」）を覚えていた（494。こちらはポテンシャルも入れ替わった → [potential-list.md](../../potential-list.md#カズマの手持ちのポテンシャルの移り変わり)）。天花は、ルサルカの「ひっくりかえす」について「『キラー』の性質がまた漏れ出てたりしない？」「「グラシデアの花」でまたちょっと栓が緩んでたりしない？」と言った（494）。上の③（特殊な道具によるブースト）に近い例と読める（推測）。花そのものは → [terms.md](../../terms.md) の「グラシデアのはな」。
  - 『種族』ポテンシャルの数は最大4つ（『第四階梯』）が理論上限で、多くは『第三階梯』で止まる（334, 411, 467）。容量の限界とつながっていそう（推測）。
  - 「おうぎ」級の「技能拡張」の『専用』も、選手側の潜在能力に大分影響される（天花、471）: 「種族としての本質」を「育成」も合わせて引き出せて初めて可能になるかどうかで、最低でも『第四階梯』に到達している選手ばかり。容量という言葉は出ていないが、ポケモン自身の容量（①）の話と読める（推測。→ 下の[専用ポテンシャル](../../potentials.md#専用ポテンシャル)）。
  - トレーナーの側にも似た限りがある: 直哉「キャパ的に無理や、そもそも「能力：C」は『固有』は1個や」（099）。
