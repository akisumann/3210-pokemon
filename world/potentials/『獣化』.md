# 『獣化』

- 混血（『ハーフ』）のトレーナーが、自分のポケモンとしての力を出すための『固有』の類型。トレーナー自身がフィールドに出て選手として戦う。出ている間も『指令』や交代などの監督の行動はできる。例: 天羽奏（シンフォギア種との『ハーフ』）の固有『君ト云ウ 音奏デ 尽キルマデ』。

- 『獣化』を持つトレーナーは、『固有』2つ以上が基本の形（作者）。''『獣化』の『固有』が発現する者は、総じてそれ以外にも『固有』を持つ''と言われている（340、ガッシュ）。例: 奏は『獣化』のほかに『高く奏でる明日の調べ』（味方の『役割』の発動時、場にいる味方の体力を1/4回復）を持つ。聖園ミカも、『獣化』の『調停を司る聖なる祈り手』のほかに『破壊を導く聖なる閃光』（味方が一番最後に「技能拡張：ようせいほう」）を持つ（505・509）。（出典: 340, 505, 509）

- **『セルフ○○』の種類**: 『獣化』するトレーナーは、資質に合わせて『セルフ○○』という属ポテンシャルを持つ（163）。これまでに出たもの:
  - 「統率」型: 『**セルフコマンド**』（自身がPTのトレーナーの時、トレーナーの「統率」が1ランク上がる）。天羽奏（本来「統率：A」で実質「AA」。163, 340, 351）。503でも表示が出て、カズマは「これは「統率」型用ってことらしい」と言った。
  - 「指示」型: 『**セルフオーダー**』（1/試　自身がPTのトレーナーの時、被攻撃時のタイミングで『かわせ！』『よけろ！』を発動することが出来る）。前タワータイクーンのオシュトルの現役時代の『獣化』の『属』別は、「指示」型としての性質のもので、『たえろ！』のタイミングで『かわせ！』『よけろ！』が使えたらしい（ベルゼブモン、503）。
  - 「育成」型: 『**セルフブリード**』（自身がPTのトレーナーの時、自身の『先』『回避』『耐性』『撃』『気合い』を『極』める）。星噛絶奈（265）。
  - 「能力」型の『獣化』トレーナーのヴィルヘルムは、属『**セルフアビリティ**』（自身がPTのトレーナーの時、独自に専用ポテンシャルを保有する）を持つ（395）。同じ「能力」型の聖園ミカ（「能力：A+」）も持つ（505・509）。
  - 効果の原文は → [potential-list-genus.md](../potential-list-genus.md)
- **『天賦』と『セルフコマンド』の併用**（503。トバリデパートでの話）: カズマが、聖園ミカの話からすると『ハーフ』でも『天賦』になれるのか、奏のような『獣化』の『属』別と併用できるのかと聞くと、ミカは「理論上は可能」と答えた。『天賦』による才能での支配力と、指揮官が戦場に立つことによる統率力は**異なるもの**なので、併用すればさらに上がる。もう1体の『天賦』を別に『エース』に据えれば、可能性は十分にある（ミカ（AA内））。
  - 1人でやろうとすれば『天賦』＋『エース』＋『ハーフ』＋『獣化』がそろう必要があるので、二手に分担すれば……という理論上の話で、見る機会はめったにない（マックイーン）。『獣化』は事実上『専用』枠が2つ以上あることも前提になり、条件は相当厳しい。そういう裏技があっても「S」の人は聞いたことがない（綾乃）。リョーマのSP効果でも『エンペラー』だけは絶対に任命できない（綾乃（AA内））。「統率：S」なら『エンペラー』自由みたいなもの（ベルゼブモン）。
  - 理論上は組み合わせられるポテンシャルでも、それを習得できるかはまるで別問題（カズマ）。煉獄やルビーが飲み会（501）で言っていたのもこのあたりの話だろう、とカズマは言った。カズマは、ドラマ用にはプロデューサーにそれっぽい『属』別をでっち上げてもらう方向で行くか、と考えた。

（出典: 163, 265, 340, 395, 503, 505, 509）

- **7体目の選手**（375、《鮮血カズィクルベイ》のアニキ）: 『獣化』の『固有』によっては、''場の味方を「瀕死」にして、7体目の選手としてバトルに介入''できる（瀕死にするのは最初に場に出る時だけ。死に体の味方を捨てて出ることもできる）。『ハーフ』かつ「能力」型で、『獣化』に『固有』枠を1つ使う必要があるので、シンオウ全体でもほとんどいない（レジーナ）。処理は''『輪廻』や『旋回』のタイミングとほぼ同じ''で、無条件で相手の『四式』や『六令』を透かすことはできない。『もどれ！』に合わせることもできるが、最初の1回だけ（うてな）。（出典: 375）
- **聖園ミカの『調停を司る聖なる祈り手』**（505〜509）: ヴィルヘルムの『死森の薔薇騎士』と同じ形（T終了時、場にいる味方を「瀕死」にして7体目としてPTに参加。一度場に出たあとは通常の選手と同じように出せる）。白野は、行動不能の味方を生け贄に死に出しで『エース』が出てこられる、ほとんど『輪廻』みたいな真似で、使えるのは最初の1回だけと説明した（505）。カズマは「一人一殺でも相手実質7体」と受け取った（505）。（出典: 505, 507）
  - **参戦する前に倒しきれば勝ち**（507、天花）: 『エース』（ミカ）は、一度味方を犠牲にしないと強制交代でも場には出てこない。相手が一度でも『固有』で参戦する前に最後の1体まで減らし、その1体を「瀕死」にすれば、7体目が出る前にこちらの勝ちになる。ただしマックイーンは、ヴィルヘルムの時と同じで実際にはほとんど無理と見た。（出典: 507）
  - **弱点は死に出しからの一手の遅れ**（508、オシュトル）: この手の『獣化』は、死に出しから出てくる一手が遅れるので、「バトンタッチ」が狙える。天花は、推定『すっぴん』のグローリアス・ヘイローの「まもる」から『エース』に一気につないでくる可能性が高いと読んだ。509のT12、ヘイローが「まもる」をした裏でオシュトルが「バトンタッチ」でマックイーンに能力変化を渡し、T12の終わりにミカがヘイローを「瀕死」にして参戦した（ミカ「お前を生け贄に代打、私！！！！」）。（出典: 508, 509）
  - **「ここぞ！」の数え方**: ミカが参戦する前に3体が倒れた508で、敵陣は残り3体で「ここぞ！」になった（カズマ「お前が出て来ても結局残り3体には変わらんが」）。（出典: 508）

- **『獣化』トレーナーの専用**（395）: ヴィルヘルムは属『セルフアビリティ』（自身がPTのトレーナーの時、独自に専用ポテンシャルを保有する）で、トレーナーの『専用』枠とは別に自分の専用『紅に染まる吸血庭園』を持つ。種族は『ハーフ』（人間と「ヴラド・ツェペシ」の混血の『変種』）。「能力：A」の『獣化』は「能力：B」までの領域を超えるが、「能力：AA」以上ならノーリスクで「7vs6」ができる（天花、392）。（出典: 392, 395）
- **聖園ミカの専用**（505・509）: 同じ『セルフアビリティ』で、専用『宇宙に座する聖なる天使』（自身の全種族値を1ランク上げ、『星のヌシ』を付与する）を持つ。カズマ「『固有』だから『専用』は別途持ってるってことじゃねぇか」。白野によれば『パンプアップ』で、「能力」型だけあって＋α付き（『星のヌシ』）。種族は『ハーフ』（人間と「ミカエル」の混血の『変種』）。ミカ本人も、『専用』は「能力」型ですら有限のリソースで、『セルフアビリティ』のある自分や『ベテラン』のようなものを除けば分配が難しいと話した（506）。（出典: 505, 506, 509）
