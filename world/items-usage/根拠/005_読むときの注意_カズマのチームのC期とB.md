# 読むときの注意: カズマのチームの「C」期と「B」期（試合数は24と41なので、1試合あたりで比べる）: 「C」期…

↑ [読むときの注意](../../items-usage.md#読むときの注意)

- カズマのチームの「C」期と「B」期（試合数は24と41なので、1試合あたりで比べる）: 「C」期はマックイーンのこだわりハチマキ（11回）とオボンのみ（13回）が中心で、「B」期には大きく減る（ハチマキ11→1、オボン13→7）。代わりに「B」期は、まっさらプレート（169から、マックイーン）、だっしゅつパック（1→18）、こだわりスカーフ（0→13。ロトム・ベルゼブモン・リザードン）、きあいのタスキ・ボコのみが増えた。かえんだま（イカルガ）は両方の期を通して定番。
