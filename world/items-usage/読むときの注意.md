# 読むときの注意

- カズマのチームの「C」期と「B」期（試合数は24と44なので、1試合あたりで比べる）: 「C」期はマックイーンのこだわりハチマキ（11回）とオボンのみ（13回）が中心で、「B」期には大きく減る（ハチマキ11→2、オボン13→9）。代わりに「B」期は、まっさらプレート（169から、マックイーン）、だっしゅつパック（1→19）、こだわりスカーフ（0→13。ロトム・ベルゼブモン・リザードン）、きあいのタスキ・ボコのみが増えた。かえんだま（イカルガ）は両方の期を通して定番。

（出典: 169）

- **こだわり系が少ない理由**（補足: ユーザーより）: ほかに1.5倍の手段が多く、こだわる代償が目立つ。ほかに、四式（『かわせ！』『よけろ！』）で固定した技を読まれやすいこと、技を5〜8個持てるので固定で捨てる幅が大きいことも考えられる（推測）。
