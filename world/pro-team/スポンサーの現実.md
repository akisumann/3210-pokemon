# スポンサーの現実

- **チームの母体と監督**（254、バーゲスト）: 多くの場合は企業こそがチームの母体にして主体で、監督は雇われのケースが多い。トレーナーに全権を委任するのはごく少数で、オーナーがトレーナーを兼ねていても普通はそこまで極端ではない。チームによっては、監督も選手も座を奪われないよう必死になる（ポジション争い）。ミラクルズは、スポンサー（探検堂）が監督のカズマにほぼ全面的に依存し、ポジション争いもない、外から見るとかなり変わったチーム。417のブリーダー番組でも、選手はほぼ全員がカズマ個人と契約しているようなもので（ライザ）、スポンサーからの明確な援助は薄い代わりに全権をふるえる（エール）と話題になり、鉄平に「スポンサーって、そんな簡単に全権委任するもんだっけ…………？」と驚かれた。練習試合の申し込みもBD（スポンサーの娘）に聞かずにその場で受ける。（出典: 254, 417）

- **スポンサーの縛り**（補足: ユーザーより。今後も重要になる）: 大きなスポンサーは選手や資金をくれる一方で、「この選手を使え」「この役割に据えろ」と口を出すことがあり、そのぶんチームの最適な形からずれて弱くなる。企業がチームの母体で監督は雇われ、というケースが多い（254）ことの裏返し。
  - **縛りは理にかなっている**（補足: ユーザーより）: そもそもプロチームは企業の興行であり宣伝なので、企業のイメージに合わない選手は使わせたくない。例えば造船会社のチームが、海難事故を起こしまくるような海洋系のモンスターをたくさん使っていたらイメージが悪い。チーム名に企業名が入り（→ [チーム名](../pro-team.md#チーム名)）、手持ちのタイプや種族が企業の色に寄るのもこのため（推測）。
    - 例えば《多々良クラッシャーズ》でも、もし企業のエンブレムがサイバー・エンド・ドラゴンだったら、それを『エース』にしないわけにはいかない（補足: ユーザーより。たとえ話）。
  - 例: 《多々良クラッシャーズ》（星噛絶奈）。『エース』のサイバー・エンド・ドラゴンと『ベテラン』のクッパはスポンサーからもらった選手で、「勝つだけならアニキ（ナインボール=セラフ）を『エース』に据えるべき」なのに、スポンサーの要望で今の形（「こちとらスポンサー様のご要望なんだっつーの」）。『エース』に自爆装置をつけようとしたらスポンサーにめっちゃ怒られた。（出典: 265, 266）
  - サイバー・エンド・ドラゴンはポテンシャルが元ネタどおりに統一されている（三つの首で相手の攻・防・特防の上昇を無視など）が、そのぶん刺さる範囲が狭く、上昇以外の倍率（ガッシュの『エースアシストα』の技2倍や「充電」の2倍）は止められずに倒れた（268。補足: ユーザーより。読み）。企業がこれを使えと言った分だけ弱い。
  - 資質で見ても損が大きい: 絶奈は「指示C／育成A+／統率B／能力B-」（268）。ナインボール=セラフの『天賦の才』は『エース』になるとトレーナーの「統率」を1ランク上げるので、アニキを『エース』にすれば統率は「B」から「A」（外付け）になっていた。**「統率」のBとAは本当に大きな差**（補足: ユーザーより）で、外付けのAでも『絆』の数、『追加役割』の付与、要「統率」（禁伝は統率Aが必要。統率Aなら理論上どのポケモンも従えられる）は純粋な統率Aと同じになる（『PT』と『エキスパンション』は付かない。206。→ [trainer-stats.md](../trainer-stats.md) の「『天賦の才』で上がった「統率」の扱い」）。スポンサーの指定でサイバー・エンド・ドラゴンが『エース』に座っているので、この1ランクを丸ごと捨てていることになる（推測）。アニキを『エース』にしない明確な事情があるわけでもなく、本人たちは乗り気で、理由は企業の問題だけ（補足: ユーザーより）。統率Bでも、モンハン種のディノバルドを従えている（天花「「統率：B」はありそう」）。
  - 逆に《百代ファンタジーズ》（ジータ）はスポンサーの束縛がかなりゆるく、タイプや選手のバランスが今大会で一番高かった（絶奈）。そのチームがクロガネ杯で優勝した。（出典: 269）
  - ミラクルズの探検堂は、オーナー（地下おじさん、ライザの父）がカズマに任せる形で、この縛りがほとんどないと思われる（推測）。

（出典: 254, 265, 266, 268, 269）
