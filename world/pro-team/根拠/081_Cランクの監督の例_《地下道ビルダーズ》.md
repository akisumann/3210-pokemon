# Cランクの監督の例: 《地下道ビルダーズ》

↑ [Cランクの監督の例](../../pro-team.md#cランクの監督の例)

- **《地下道ビルダーズ》**（478）: “メルキド”の公共化に合わせ、来年（“第四節”以降の新体制）は「B」ランカーのベルナデッタが宣伝を兼ねて監督をする新チーム（所属はハクタイ）で、「C」から再デビューする（降格ではない）。言い出したのはエネル（「いっそのこと、そのチームにあのバカくれてやれ……んで後釜にレヴィを使え」）。ベルナデッタは今のチーム《灯台サンセット》（スポンサーはナギサの“シルベの灯台”）での活動を“第三節”で止め、灯台の方は“第四節”以降、エネルの門下生のレヴィを監督とする新体制への移行期間になる（監督が替わるので新チームとして「C」から再スタート。SPのヨルは、「B」昇格でSPが必要になるまでは身の回りの世話などをする予定）。地下の調査団にいるゴーレムも、来シーズンは《ビルダーズ》に入る予定（作者）。（出典: 478）
