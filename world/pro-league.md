# リーグ制度

プロリーグの仕組み・ジム・スクール・大会・昇格・四天王とチャンピオンなど。チーム運営は [pro-team.md](pro-team.md)、トレーナーの資質は [trainer-stats.md](trainer-stats.md)、入口は [pro-trainer.md](pro-trainer.md)。

## アマチュアとプロ

- 「アマプロ問わず」と言われているので、アマチュアのバトルもある。（出典: 002）
- プロっていうのはトレーナーの中でも一握り（369） → [根拠](pro-league/根拠/001_アマチュアとプロ_プロっていうのはトレーナ.md)

## ジム

- ジムリーダーは**地方のポケモン協会から任命された8人**の強者。得意なタイプのポケモンを使うエキスパート（一部例外あり）。（出典: 002, 003）
- ジムリーダーは協会に任命された立場なので、特定のチームや個人への贔屓は厳禁 → [根拠](pro-league/根拠/002_ジム_ジムリーダーは贔屓が厳禁.md)
- ジムリーダーはプロリーグには参戦していない。ただし実力は全員が**Aランク級**で、中でも最強の者は**四天王**に匹敵する。（出典: 006）
- ジムリーダーはエネルが最強、ロビンマスクとイングリッドが2位争いの「シンオウ三強」 → [根拠](pro-league/根拠/003_ジム_本気のジムリーダー同士で.md)
- ジムリーダー同士の戦績ではメアリが一番下。ただし人気投票は毎回1位 → [根拠](pro-league/根拠/004_ジム_ジムリーダー同士の戦績で.md)
- 毎年「ジムリーダー対抗戦」がある。去年はミオがロビンマスクに勝つ番狂わせ → [根拠](pro-league/根拠/005_ジム_毎年ジムリーダー対抗戦が.md)
- ジムリーダー同士の交流戦もあり、メアリはそこで散々やられている → [根拠](pro-league/根拠/006_ジム_ジムリーダー同士の交流戦.md)
- カズマがまだ挑んでいないのは凛・シア・ミオ・エネルの4人。5つ目はシアに決定 → [根拠](pro-league/根拠/007_ジム_カズマがまだ挑んでいない.md)
- ジムは教育機関でもあるので、ジムリーダーは人格面もテストされる。地方に8人しかいない特権持ち。（出典: 085）
- キッサキジムは地理と気候のせいで、“ジム巡り”で選ばれる率が最低 → [根拠](pro-league/根拠/008_ジム_キッサキジムと“ジム巡り.md)
- ジムリーダーは手持ちをジムのタイプで統一するので、弱点はポテンシャルや持ち物で補う → [根拠](pro-league/根拠/009_ジム_ジムリーダーはジムである.md)
- ジムリーダーの資質: 凛とロビンマスクは純「育成」型。キッサキのシアは「育成／能力」の複合で、資質的にはシンオウ屈指。（出典: 085）
- ジムリーダーはバッジの数に合わせて戦力を制限し、本気で戦うのは8番目だけ → [根拠](pro-league/根拠/010_ジム_挑戦者に合わせた制限.md)
- プロになってからのジム戦には、ジム巡りのような時間制限もデメリットもない。腕試しになるうえ、バッジの数は**昇格の審査基準にも少し入る**（内申点のようなもの）。（出典: 065, 085）
- ジム戦の形式: **1つ目は「2vs2」、2つ目と3つ目は「3vs3」**。（出典: 015）
- 最初のジムは「2vs2」の基礎的なバトル。バッジが増えるほど手持ちも増える → [根拠](pro-league/根拠/011_ジム_最初のジムは2vs2の基.md)
- 序盤（バッジ3つまで）のジム戦には、ドラゴンタイプ持ちの「十八竜」が必ず出る → [根拠](pro-league/根拠/012_ジム_十八竜.md)
- ジムのペースの目安: 普通はもっとじっくり攻略する。約1週間でバッジ2つは、ジムリーダーの想定を上回るペース（凛談）。（出典: 025）
- 最初のジム戦は、先発に古代種を出すことが多い。ジムリーダーの手持ちは挑戦者のバッジの数に合わせて調整されている（バッジ0用なら Lv25）。（出典: 015, 017）
- シンオウのジムバッジは8つ。コールからビーコンまで → [根拠](pro-league/根拠/013_ジム_シンオウのジムバッジは8.md)
- ジムをクリアすると、ジムバッジとわざマシンがもらえる → [根拠](pro-league/根拠/014_ジム_ジムをクリアするとジムバ.md)
- ジムの門下生は、一定の実力を認められると、ジム勝利時の配布わざマシンをもらえる（ライザの「エナジーボール」）。（出典: 042）
- ジムはトレーナーの養成機関でもある。トレーナーへの道はスクールかジムの門下生 → [根拠](pro-league/根拠/015_ジム_ポケモンジムはトレーナー.md)
- 登場人物の年齢は、原典ではほとんど決まっていない。ただ、ジムの門下を終えた人やスクールを卒業した人は、おおむね成人していると見てよい（補足: ユーザーより）。
- 門下生同士の付き合い、交換留学、デビュー前のスカウトなど、ジムの門下生の日常 → [根拠](pro-league/根拠/016_ジム_ジムの門下生の日常.md)
- 現役プロの練習試合は門下生の良い教材。真似は一部のやり方を吸収するくらいで → [根拠](pro-league/根拠/017_ジム_門下生にとってのプロ.md)
- ジムリーダーは、元々の主力以外にも『専用』枠を確保しておくことがある → [根拠](pro-league/根拠/018_ジム_ジムリーダーの専用枠.md)
- ジム所属のポケモンを、プロを目指すトレーナーに付けて送り出すのは日常のこと → [根拠](pro-league/根拠/019_ジム_ジム所属のポケモンとプロ.md)
- ジムにもフィールド効果がある。ハクタイジムは大人しく、クロガネジムは厳しい → [根拠](pro-league/根拠/020_ジム_ジムのフィールド効果.md)
- ジムには大きな試合場がある。（出典: 003）
- ポケモンジムでは、トレーナーが色々と教わることもできるらしい。（出典: 002）
- シンオウの8つのジムと、それぞれのタイプとジムリーダー → [根拠](pro-league/根拠/021_ジム_シンオウのジム.md)

## トレーナーズスクール

- シンオウの大都市**コトブキシティ**にある、ポケモントレーナーの養成機関。（出典: 002, 015）
- 8つのジムと違い、ポケモンバトルもそれ以外のことも体系的に教える学校。単位制。（出典: 014, 015）
- プロを目指して入学する人が多いが、全員がプロを目指すわけではない。卒業すると、プロリーグ関係の企業をはじめ、いろいろな就職に有利。（出典: 015）
- スクールに所属するポケモンも多く、トレーナーとポケモンの出会いの場にもなっている → [根拠](pro-league/根拠/022_トレーナーズスクール_スクールに所属するポケモ.md)
- スクールはプロチームを2つ持つ。一軍は「A」の空条、二軍は「B」中位の鳴上 → [根拠](pro-league/根拠/023_トレーナーズスクール_プロチームを2つ持ってい.md)
- スクールの授業では、《探検堂ミラクルズ》が先生から酷評されることがある（白野。教科書至上主義から嫌われるのは道理）。（出典: 305）
- 卒業生には、いろいろなプロチームの監督をしている人が多い。元スクール所属のポケモンも同じ。（出典: 015）
- 生徒: 潮田渚、食蜂操祈（渚の同期。今年からプロ）。（出典: 015）
- スクールの一軍（空条承太郎）は今やコトブキで№2。ライネスもスクール出身 → [根拠](pro-league/根拠/024_トレーナーズスクール_425スクールの一軍チー.md)
- 校長は**ケイネス・エルメロイ・アーチボルト**。（出典: 039）
- スクールには''ブリーダー科''などの育成部門もある。412のテレビコトブキのブリーダー番組は、スクールの「エルメロイ校長」の打診を受けた企画（プロデューサー）。（出典: 412）
- 教師がクロガネ炭鉱の噂を聞き、たんけんセットを授業などに使うことを検討している。校長も本格導入を前向きに検討中。（出典: 038, 039）
- スポンサーが見つからず、デビューを見送る卒業生もいる（実力はバッジ3つ水準）。（出典: 039）

## スタジアム

- プロリーグの試合は**スタジアム**で行われる。ジムの試合場よりずっと大きく、満員の観客が入る。（出典: 003）

## ポケモンリーグ

### 歴史

- もともとは、ポケモン協会が開いていた「バッジを集めた者たちによる大会」だった。協会には凄腕のトレーナーもいたらしい。（出典: 005）
- 時代が進み、企業やお金が絡んでポケモンバトルが大規模になると、各地方で「**プロリーグ**」が開かれるようになった。（出典: 005）

### 今のポケモンリーグ

- **地方で最強のプロチームを決める頂上決戦**。毎年開かれ、とても盛り上がる。（出典: 005）
- 20チームが5つのブロックで予選を戦い、各ブロック1位の5チームが本戦に出る → [根拠](pro-league/根拠/025_今のポケモンリーグ_20チーム.md)
- **シーズン**制で、シーズンとシーズンの間はオフ。シーズンは4つの「節」に分かれていて、最初の四半節を「**第一節**」と呼ぶ。（出典: 044）
- 042のあとのシーズン開幕は、045の練習試合の翌週。（出典: 045）
- 物語の開始時点はシーズンが終わったばかりで、アカネたちは次のシーズンまでオフ → [根拠](pro-league/根拠/026_今のポケモンリーグ_物語の開始時点はちょうど.md)
- 昨季のシンオウリーグの結果。1位はチャンピオン・ホーネットで3連覇 → [根拠](pro-league/根拠/027_今のポケモンリーグ_先日昨季のシンオウリーグ.md)
- 本戦に出たこの5チームが、ゲンドウいわく「シンオウの現5強」。トレーナーズスクールの所有チームは、テレビコトブキのチームより下だった。（出典: 039）
- 昨年のリーグ本戦の上位: チャンピオン（ホーネット）は「能力」型、2位は「育成」型、3位はジュピター（「統率」型）。（出典: 080） 5位はミオ図書館から出場した小鳥遊ホシノ（094）。
- 20枠のうち7枠を、ギンガ団（3チーム）と四天王（4チーム）が占めている。（出典: 005）

### シーズンの流れ

- シーズンは4つの節に分かれ、第四節がポケモンリーグ（上位20チームの頂上決戦） → [根拠](pro-league/根拠/028_シーズンの流れ_シーズンは4つの節に分か.md)
- シーズンの最初に本部スタジアムで開会式。招かれるのは昨年のリーグの20チームだけ → [根拠](pro-league/根拠/029_シーズンの流れ_シーズンの最初にポケモン.md)
- 1つの節の長さは、カズマたちが第一節でソノオ杯とハクタイ杯に出たくらいの期間。その間にいくつの大会に出るかはチーム次第。（補足: ユーザーより）
- 第一節の開幕戦は、Cランクのルーキーたちのお披露目の場でもある。（出典: 054）
- 第一節の「A」の最後はハクタイ杯で、アカネが優勝。そのあとオフシーズンに入る → [根拠](pro-league/根拠/030_シーズンの流れ_第一節のAランクの最終日.md)

### 大会の仕組み

- 大会は**各街のスタジアム**で開かれる（会場＝街のスタジアム）。開幕戦は、すべての街でCランクから一斉に始まる。（出典: 051）
- チームは出場したい街の大会にエントリーする。参加枠よりエントリーが多いと**抽選**。地元のチーム、特に街の名を冠したチームは抽選で優遇される。（出典: 051）
- 開会式から数日以内に、各大会の組み合わせが発表される。早いところでは翌日。相手がわかれば事前にも大会中にも情報を集められる。（出典: 051）
- 大都市（コトブキ、トバリ、ヨスガ）のスタジアムほど大きい。ソノオスタジアムは小規模だが、観客は多い。（出典: 055）
- 各街のスタジアムを借りるのにもお金がかかる（練習試合はスタジアムを借りず、地下大洞窟でやることにした）。（出典: 062）
- 大会には規模がある。**小規模大会は4〜5チーム、中規模大会は7〜8チーム**。Cランクでは中規模大会はたまにしか開かれない大舞台。（出典: 052, 089）
- 第一節の「C」の中規模大会はC最強クラスが集まり、出られれば昇格はほぼ内定 → [根拠](pro-league/根拠/031_大会の仕組み_特に第一節のCランクの中.md)
- 「B」ランクからは中規模戦も結構行われる → [根拠](pro-league/根拠/032_大会の仕組み_Bランクからは中規模戦も.md)
- 大規模大会は10チーム以上が3日かけて戦う。「B」では一節に数回だけ → [根拠](pro-league/根拠/033_大会の仕組み_大規模大会.md)
- 大会に呼ばれる相手の格は、そのチームの戦績で変わる → [根拠](pro-league/根拠/034_大会の仕組み_戦績によるマッチメイク.md)
- 大会の勝敗が同点のときは地元チーム（【H】）が上位。それ以外の場合は、直接対決の勝者が上位。（補足: ユーザーより）
- 【H】補正の序列は、都市チーム＞その街に所属するチーム＞それ以外 → [根拠](pro-league/根拠/035_大会の仕組み_【H】補正の序列.md)
- 大会には【H】のチームを1つは入れたい。地元同士で枠を譲り合うこともある → [根拠](pro-league/根拠/036_大会の仕組み_大会にはホーム枠【H】の.md)
- 今後はイベントでオート進行の大会も発生する（作者注）。（出典: 089）

### 「B」ランク

- 第二節の開幕戦は前日に組み合わせ発表。「B」は抽選なしで開幕戦に出られた → [根拠](pro-league/根拠/037_Bランク_第二節の開幕戦.md)
- カズマたちは237のあとの大会から「B」中位とぶつかり始める → [根拠](pro-league/根拠/038_Bランク_B中位.md)
- 《召喚サモナーズ》と《電波局ニューホライゾン》は「B」下位の上の方のチーム → [根拠](pro-league/根拠/039_Bランク_B下位の上の方.md)
- 「B」では高レベルの相手に勝つと経験値が大きいが、Lv90を超えると伸びが鈍る → [根拠](pro-league/根拠/040_Bランク_Bの大会は既存Bの高レベ.md)
- プロにとってLv100は通過点。「B」の下位でもLv100に届く選手がいる → [根拠](pro-league/根拠/041_Bランク_プロにとってLv100は.md)
- 「B」ではPTの数や種属、希少技などが増え、戦闘の前提（“環境”）が変わる → [根拠](pro-league/根拠/042_Bランク_Bで変わる“環境”.md)
- 「B」は使えるポテンシャルが増え、防護型の『バウンス』などで環境が大きく変わる → [根拠](pro-league/根拠/043_Bランク_Bの環境.md)
- 「B」ではポテンシャルが増え、「育成」型以外のチームもほぼブリーダーを雇っている → [根拠](pro-league/根拠/044_Bランク_Bではポケモンのポテンシ.md)
- 「C」と比べて、「B」からは『天賦』や『金冠』を持っているチームがぐっと増える（タツマキ）。（出典: 205）
- 『天賦の才』の学習能力は尋常ではなく、ポテンシャルの数は「育成」型に匹敵し、『専用』も「能力」型に比肩する効果、本体性能も段違い（天花）。（出典: 206）
- 第一節から「B」に上がったチームは、中規模戦に出ていないところも含めて周りから警戒される（エニシダ）。今年のシンオウのルーキーは「特にヤバイ」（冬優子）。（出典: 178）
- 「B」では「まもる」と組むポテンシャルが増えるが、相手も貫通や読みで対策してくる → [根拠](pro-league/根拠/045_Bランク_Bのまもる環境.md)
- 「B」上位は「A」直下の戦場で、「統率」型のチームが多い → [根拠](pro-league/根拠/046_Bランク_B上位.md)
- チームの例は → [pro-team.md](pro-team.md) の「Bランクのチームの例」

### フィールド効果

- プロリーグの各スタジアムには、それぞれフィールド効果がある → [根拠](pro-league/根拠/047_フィールド効果_プロリーグの各スタジアム.md)
- 《ソノオスタジアム》は全員の「避」が0.67倍。正面からの殴り合いになりやすい → [根拠](pro-league/根拠/048_フィールド効果_例《ソノオスタジアム》….md)
- 《ハクタイスタジアム》は『オールドタイプ』が受ける技のダメージを0.85倍にする → [根拠](pro-league/根拠/049_フィールド効果_例《ハクタイスタジアム》.md)
- 《トバリスタジアム》はタイプ不一致の「岩」「龍」技の威力を1.5倍にする → [根拠](pro-league/根拠/050_フィールド効果_例《トバリスタジアム》….md)
- 《ナギサスタジアム》はT開始時、低確率で場のポケモンが「充電」状態になる → [根拠](pro-league/根拠/051_フィールド効果_例《ナギサスタジアム》….md)
- 例: 《カンナギスタジアム》…『オールドタイプ』を持つポケモンが相手の攻撃以外で「瀕死」状態にならない。（出典: 206）
- 《キッサキジム》は「氷」ポケモンが受ける「炎」「水」技のダメージを0.75倍にする → [根拠](pro-league/根拠/052_フィールド効果_例《キッサキジム》ジムの.md)
- 例: 《ミオジム》（ジムのフィールド効果）…場にいるすべてのポケモンが繰り出す「鋼」技に「3割：防+1」の追加効果を付与する。（出典: 327）
- 《ナギサジム》は「電」ポケモンの「速/避」が相手によって下がらない → [根拠](pro-league/根拠/053_フィールド効果_例《ナギサジム》ジムのフ.md)
- 《コトブキスタジアム》はT終了時、低確率で場の全員の能力がランダムに上がる → [根拠](pro-league/根拠/054_フィールド効果_例《コトブキスタジアム》.md)
- 例: 《ヨスガスタジアム》…死に出しで場に出たポケモンの能力がランダムに上がる。（出典: 392）
- 《ノモセスタジアム》は「炎」「岩」「地」タイプの「速」が0.85倍になる → [根拠](pro-league/根拠/055_フィールド効果_例《ノモセスタジアム》….md)

### プロになる（チームを作る）ための条件

次の三つがそろえば、最下層の**Cランク**に参加できる。あくまで参加資格で、その先やっていけるかは自分しだい。（出典: 006）
1. **ジムバッジを3つ以上持っているトレーナー（監督）**。最低限の実力を保証するための制限。（出典: 006）
2. **6体以上の所属ポケモン（選手）**。プロは「**6vs6**」のフルバトルが基本で前提なので、それに届かないとチームとして認められない。（出典: 006）
- 抜け穴として、監督の手持ちが6体でなくてもいい → [根拠](pro-league/根拠/096_プロになるチームを作るた_抜け穴として監督の手持ち.md)
   - ただし、ジムバッジを3つ取るには最低3体のポケモンが必要。（出典: 006）
- 3. スポンサー（後ろ盾となり、大会参加費を負担してくれる存在） → [根拠](pro-league/根拠/097_プロになるチームを作るた_3スポンサー後ろ盾となり.md)
   - 例: ギンガ団（企業）がスポンサーのアカネのチーム。「**街**」がスポンサーの元チャンプのチーム。（出典: 006）
