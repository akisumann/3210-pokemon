## ジム

- ジムリーダーは**地方のポケモン協会から任命された8人**の強者。得意なタイプのポケモンを使うエキスパート（一部例外あり）。（出典: 002, 003）
- ジムリーダーは贔屓が厳禁: 協会に任命された立場なので、いろいろな面で特定のチームや個人への贔屓は厳… → [根拠](pro-league/根拠/002_ジム_ジムリーダーは贔屓が厳禁.md)
- ジムリーダーはプロリーグには参戦していない。ただし実力は全員が**Aランク級**で、中でも最強の者は**四天王**に匹敵する。（出典: 006）
- 本気のジムリーダー同士で比べると、**エネル**（でんき）がシンオウ最強で、**ロビンマスク**… → [根拠](pro-league/根拠/003_ジム_本気のジムリーダー同士で.md)
- ジムリーダー同士の戦績では**メアリが一番下** → [根拠](pro-league/根拠/004_ジム_ジムリーダー同士の戦績で.md)
- 毎年「**ジムリーダー対抗戦**」がある → [根拠](pro-league/根拠/005_ジム_毎年ジムリーダー対抗戦が.md)
- ジムリーダー同士の交流戦: ジムリーダー同士で交流戦をしている → [根拠](pro-league/根拠/006_ジム_ジムリーダー同士の交流戦.md)
- カズマがまだ挑んでいないのは、くさの凛（「育成」型）、こおりのシア（「育成/能力」の複合）、はが… → [根拠](pro-league/根拠/007_ジム_カズマがまだ挑んでいない.md)
- ジムは教育機関でもあるので、ジムリーダーは人格面もテストされる。地方に8人しかいない特権持ち。（出典: 085）
- キッサキジムと“ジム巡り”: キッサキジムは“ジム巡り”で選ばれる率が最低（理由は地理と気候） → [根拠](pro-league/根拠/008_ジム_キッサキジムと“ジム巡り.md)
- ジムリーダーは、ジムであるが故に手持ちをジムのタイプで統一しなければならない（補足: ユーザーよ… → [根拠](pro-league/根拠/009_ジム_ジムリーダーはジムである.md)
- ジムリーダーの資質: 凛とロビンマスクは純「育成」型。キッサキのシアは「育成／能力」の複合で、資質的にはシンオウ屈指。（出典: 085）
- 挑戦者に合わせた制限: ジムリーダーは挑戦者の進行度（バッジの数）に合わせて戦力を制限する → [根拠](pro-league/根拠/010_ジム_挑戦者に合わせた制限.md)
- プロになってからのジム戦には、ジム巡りのような時間制限もデメリットもない。腕試しになるうえ、バッジの数は**昇格の審査基準にも少し入る**（内申点のようなもの）。（出典: 065, 085）
- ジム戦の形式: **1つ目は「2vs2」、2つ目と3つ目は「3vs3」**。（出典: 015）
- 最初のジムは「**2vs2**」の基礎的なバトル → [根拠](pro-league/根拠/011_ジム_最初のジムは2vs2の基.md)
- 十八竜: 序盤（バッジ3つまで）のジム戦では、「十八竜」と呼ばれるドラゴンタイプを… → [根拠](pro-league/根拠/012_ジム_十八竜.md)
- ジムのペースの目安: 普通はもっとじっくり攻略する。約1週間でバッジ2つは、ジムリーダーの想定を上回るペース（凛談）。（出典: 025）
- 最初のジム戦は、先発に古代種を出すことが多い。ジムリーダーの手持ちは挑戦者のバッジの数に合わせて調整されている（バッジ0用なら Lv25）。（出典: 015, 017）
- シンオウのジムバッジは8つ: コール／フォレスト／コボル／フェン／レリック／マイン／グレイシャ／… → [根拠](pro-league/根拠/013_ジム_シンオウのジムバッジは8.md)

## トレーナーズスクール

- シンオウの大都市**コトブキシティ**にある、ポケモントレーナーの養成機関。（出典: 002, 015）
- 8つのジムと違い、ポケモンバトルもそれ以外のことも体系的に教える学校。単位制。（出典: 014, 015）
- プロを目指して入学する人が多いが、全員がプロを目指すわけではない。卒業すると、プロリーグ関係の企業をはじめ、いろいろな就職に有利。（出典: 015）
- スクールに所属するポケモンも多く、トレーナーとポケモンの出会いの場にもなっている → [根拠](pro-league/根拠/022_トレーナーズスクール_スクールに所属するポケモ.md)

- スクールの授業では、《探検堂ミラクルズ》が先生から酷評されることがある（白野。教科書至上主義から嫌われるのは道理）。（出典: 305）
- 卒業生には、いろいろなプロチームの監督をしている人が多い。元スクール所属のポケモンも同じ。（出典: 015）
- 生徒: 潮田渚、食蜂操祈（渚の同期。今年からプロ）。（出典: 015）
- 425: スクールの一軍チーム（空条承太郎）は今やコトブキでも№2で、空条が完全に堅守している（… → [根拠](pro-league/根拠/024_トレーナーズスクール_425スクールの一軍チー.md)
- 校長は**ケイネス・エルメロイ・アーチボルト**。（出典: 039）
- スクールには''ブリーダー科''などの育成部門もある。412のテレビコトブキのブリーダー番組は、スクールの「エルメロイ校長」の打診を受けた企画（プロデューサー）。（出典: 412）
- 教師がクロガネ炭鉱の噂を聞き、たんけんセットを授業などに使うことを検討している。校長も本格導入を前向きに検討中。（出典: 038, 039）
- スポンサーが見つからず、デビューを見送る卒業生もいる（実力はバッジ3つ水準）。（出典: 039）

## ポケモンリーグ

### 歴史

- もともとは、ポケモン協会が開いていた「バッジを集めた者たちによる大会」だった。協会には凄腕のトレーナーもいたらしい。（出典: 005）
- 時代が進み、企業やお金が絡んでポケモンバトルが大規模になると、各地方で「**プロリーグ**」が開かれるようになった。（出典: 005）

### 今のポケモンリーグ

- **地方で最強のプロチームを決める頂上決戦**。毎年開かれ、とても盛り上がる。（出典: 005）
- 20チーム: がブロックごとに**予選**を戦い、そのうち**5チーム**が**本戦*… → [根拠](pro-league/根拠/025_今のポケモンリーグ_20チーム.md)
- **シーズン**制で、シーズンとシーズンの間はオフ。シーズンは4つの「節」に分かれていて、最初の四半節を「**第一節**」と呼ぶ。（出典: 044）
- 042のあとのシーズン開幕は、045の練習試合の翌週。（出典: 045）
- 物語の開始時点は、ちょうどシーズンが終わった時期: 先日のリーグ（チャンピオンの3連覇）は終わったばかりで、アカネたちは次の… → [根拠](pro-league/根拠/026_今のポケモンリーグ_物語の開始時点はちょうど.md)
- 先日（昨季）のシンオウリーグの結果: → [根拠](pro-league/根拠/027_今のポケモンリーグ_先日昨季のシンオウリーグ.md)
- 本戦に出たこの5チームが、ゲンドウいわく「シンオウの現5強」。トレーナーズスクールの所有チームは、テレビコトブキのチームより下だった。（出典: 039）
- 昨年のリーグ本戦の上位: チャンピオン（ホーネット）は「能力」型、2位は「育成」型、3位はジュピター（「統率」型）。（出典: 080） 5位はミオ図書館から出場した小鳥遊ホシノ（094）。
- 20枠のうち7枠を、ギンガ団（3チーム）と四天王（4チーム）が占めている。（出典: 005）

### 大会の仕組み

- 大会は**各街のスタジアム**で開かれる（会場＝街のスタジアム）。開幕戦は、すべての街でCランクから一斉に始まる。（出典: 051）
- チームは出場したい街の大会にエントリーする。参加枠よりエントリーが多いと**抽選**。地元のチーム、特に街の名を冠したチームは抽選で優遇される。（出典: 051）
- 開会式から数日以内に、各大会の組み合わせが発表される。早いところでは翌日。相手がわかれば事前にも大会中にも情報を集められる。（出典: 051）
- 大都市（コトブキ、トバリ、ヨスガ）のスタジアムほど大きい。ソノオスタジアムは小規模だが、観客は多い。（出典: 055）
- 各街のスタジアムを借りるのにもお金がかかる（練習試合はスタジアムを借りず、地下大洞窟でやることにした）。（出典: 062）
- 大会には規模がある。**小規模大会は4〜5チーム、中規模大会は7〜8チーム**。Cランクでは中規模大会はたまにしか開かれない大舞台。（出典: 052, 089）
- 特に**第一節のCランクの中規模大会**は、C全体の上位チームや大型ルーキーが選ばれやすく、Cで… → [根拠](pro-league/根拠/031_大会の仕組み_特に第一節のCランクの中.md)
- 「B」ランクからは中規模戦も結構行われる → [根拠](pro-league/根拠/032_大会の仕組み_Bランクからは中規模戦も.md)
- 大規模大会: 10チーム以上が3日をかけて戦う → [根拠](pro-league/根拠/033_大会の仕組み_大規模大会.md)
- 戦績によるマッチメイク: 大会に呼ばれる相手の格は、そのチームの戦績で変わる → [根拠](pro-league/根拠/034_大会の仕組み_戦績によるマッチメイク.md)
- 大会の勝敗が同点のときは地元チーム（【H】）が上位。それ以外の場合は、直接対決の勝者が上位。（補足: ユーザーより）
- 【H】補正の序列: ①【H】の都市チーム ＞ ②【H】の街に所属するチーム ＞ ③それ以外の… → [根拠](pro-league/根拠/035_大会の仕組み_【H】補正の序列.md)

### プロになる（チームを作る）ための条件

次の三つがそろえば、最下層の**Cランク**に参加できる。あくまで参加資格で、その先やっていけるかは自分しだい。（出典: 006）
1. **ジムバッジを3つ以上持っているトレーナー（監督）**。最低限の実力を保証するための制限。（出典: 006）
2. **6体以上の所属ポケモン（選手）**。プロは「**6vs6**」のフルバトルが基本で前提なので、それに届かないとチームとして認められない。（出典: 006）

   - ただし、ジムバッジを3つ取るには最低3体のポケモンが必要。（出典: 006）
- 3. **スポンサー（後ろ盾となり、大会参加費を負担してくれる存在）** → [根拠](pro-league/根拠/097_プロになるチームを作るた_3スポンサー後ろ盾となり.md)
