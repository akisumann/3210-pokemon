## ファンとメディア

- 人気商売の面がある。プロトレーナーは写真だけでお金になる。「人気が出る」「ファン」といった言葉も出てくる。（出典: 001）

### ファン

- 第二節のころには、プロのチームはちょっとした人気商売になっている。
- 非公式のファンクラブが自然にでき、大きくなるとチームと提携して公式になる → [根拠](pro-team/根拠/002_ファン_ファンクラブ.md)
- チームは公式配信を持ち、生配信でファンの質問に答える → [根拠](pro-team/根拠/003_ファン_ファンの文化と配信.md)
- 大会ごとに掲示板の実況スレが立ち、チームや『固有』、選手の人気が語られる → [根拠](pro-team/根拠/004_ファン_掲示板.md)
- **動画サイト**: 選手やトレーナーのMAD動画が作られ、トレーナーの好みのタイプまで憶測が飛ぶ（239）。ポケッターでの実況中継もある（235）。
- 世間の評価は、強さだけでなく見た目やキャラクター、戦い方の面白さでも決まる（235）。
- ファン層の調査では、カズマのファンは「指示」型・「万能」型のトレーナーが多い → [根拠](pro-team/根拠/005_ファン_トレーナーの型ごとのファ.md)

## スポンサーの現実

- スポンサーが大きいほど有利。参加費の心配がなく、選手や設備にもお金をかけられる。（出典: 006）
- 大企業はトレーナーの獲得や育成にも投資している。実績のない新人が割り込むのは、運以前に「ジャンケンに参加する権利がない」レベル。（出典: 006）
- 新人の狙い目は、監督の獲得にも困っている弱小スポンサー。同じプロでもスタートラインは大きく違う。（出典: 006）
- いいポケモンを手に入れるにも、資本が強い → [根拠](pro-team/根拠/010_スポンサーの現実_いいポケモンを手に入れる.md)
- スポンサーが見つからない、利益が出ずに破綻する、チーム内の不協和音で空中分解する、といったことは珍しくない。華やかな舞台の裏は激しい生存競争。（出典: 006）
- 多くの場合、チームの母体は企業で、監督は雇われのことが多い → [根拠](pro-team/根拠/011_スポンサーの現実_チームの母体と監督.md)
- 大きなスポンサーは選手や資金をくれる代わりに、起用に口を出す（補足: ユーザーより） → [根拠](pro-team/根拠/012_スポンサーの現実_スポンサーの縛り.md)

## スポンサーの登録

- プロリーグに参加するチームのスポンサーは、**協会への登録が必要**。年会費もかかる。プロリーグの資金で潰れた企業もある。（出典: 036）
- スポンサー側も待ちの構えではなく、選考がある（エントリーシート、面接、最終選考）。返事に1〜2週間かかることも普通。（出典: 036）
- 実際に、スポンサーが見つからずに舞台に上がれないトレーナーはたくさんいる（凛談）。（出典: 036）
- 例: 探検堂（ライザの店）は、036で登録を済ませてカズマのスポンサーになった。ナナカマド博士の研究所は、エール・モフスのスポンサー。（出典: 033, 036）

## 手持ちの数

- 上のチームほど即戦力が求められ、未知数の新入りをいきなり主力にするのは悪手 → [根拠](pro-team/根拠/021_手持ちの数_新入りと即戦力.md)
- プロのチームは6体より多くの手持ちを抱えることが多い。控えがいると、連戦で手の内がバレにくく、1戦ごとに1〜2体ずつ入れ替えられるので、精神的にも戦略的にも安心。（出典: 044）
- 大会でも試合ごとに、手持ちから出す6体と持ち物、先発を選ぶ → [根拠](pro-team/根拠/022_手持ちの数_大会の選出はほかの試合と.md)
- カズマの場合、最終的に10〜12体くらい、デビュー後の「第一節」の間はもう1体くらいにしておくのがいい（凛の見立て）。いきなり増やすと育成に時間がかかる。（出典: 044）
- ジムの所属ポケモンが、プロのチームへ**移籍**することもある（モモ）。移籍してきたポケモンが本格的にパーティに入るのは、育成の具合しだいで先になる。（出典: 043, 044）
- 結局はお金で、ポケモンにも給料が発生する → [根拠](pro-team/根拠/023_手持ちの数_結局はお金でポケモンにも.md)
- 手持ちの同意なしに仲間を切り捨てるのは常識外れ。同意させるのも「統率」のうち → [根拠](pro-team/根拠/024_手持ちの数_手持ちの同意と統率.md)
- 普通のチームには試合に出られない控えがいるが、直哉とカズマのチームは例外 → [根拠](pro-team/根拠/025_手持ちの数_控え・二軍と統率.md)
- 「B」からは資質の差をSP・BD・『ベテラン』を雇って埋める、いわば金の世界 → [根拠](pro-team/根拠/026_手持ちの数_Bから先は資質の差を編成.md)

## ブリーダー

### BDの仕組み

- プロチームで、トレーナー以外にポケモンの育成を担うスタッフを「**ブリーダー**」と呼ぶ。例: ライザ（カズマのチーム）。ただしバトルで戦うのはトレーナーと選手6体。（出典: 037, 042）
- 作中では「**BD**」とも略される。BDが育成面を受け持つ分、トレーナーは自分の「能力」（『専用』の習得）に集中しやすい。（出典: 070）
- 《随牧スペリオール》の躍進は、今年から入ったBD（ズイタウンの「そだてや」の跡取り）の影響が大きいと言われる。育成型のトレーナーほどの影響はまだないが、ノウハウがある。（出典: 096）
- 「C」ランクには、専属のBDがいないチームも珍しくない → [根拠](pro-team/根拠/027_BDの仕組み_Cランクには専属BDがい.md)
- 他人のポケモンを育てるときは、誰でも「育成」が1ランク下がる → [根拠](pro-team/根拠/028_BDの仕組み_ブリーダーとして他人のポ.md)
- 「B」からはBDがいるのがほぼ当たり前。ただし「育成：AA」以上のBDは希少 → [根拠](pro-team/根拠/029_BDの仕組み_BランクからはBDがいる.md)
- BDにも得意な種類がある（クインビーズのパピヨンは「むし」や蝶） → [根拠](pro-team/根拠/030_BDの仕組み_BDの得意分野と街の後援.md)
- 「育成」型トレーナーはBDより経験値を多くもらえ、BDは『PT』を付与できない → [根拠](pro-team/根拠/031_BDの仕組み_BDと育成型トレーナーの.md)
- カズマはBランクに上がってもライザをBDにすると決め、ライザも「今年いっぱいくらいはただ働きしてあげる」と続投を決めた。（出典: 110）
- BDは表に出ない縁の下の力持ちで、BDに光を当てる番組にも需要がある → [根拠](pro-team/根拠/032_BDの仕組み_BDは表に出ない縁の下の.md)
- BDは「育成」型と勝手が違い、資質を十全には生かし切れない → [根拠](pro-team/根拠/033_BDの仕組み_BDは資質を十全には生か.md)
- 亀仙人のように、1〜3年の契約で「B」以上のチームに雇われるBDもいる → [根拠](pro-team/根拠/034_BDの仕組み_期間限定のBD.md)
- 「育成」型にとってもBDは人手として助かる。選手が多いチームほど必要 → [根拠](pro-team/根拠/035_BDの仕組み_BDを雇う意味.md)
- 番組に出たBDの「育成」は、亀仙人のAAが一番上で、ライザがA+ → [根拠](pro-team/根拠/036_BDの仕組み_BDの育成ランクの例.md)
- 世間はチームの在り方をBDのせいにも見る → [根拠](pro-team/根拠/037_BDの仕組み_チームの評判とBD.md)

### そだてや

- そだてやは、ズイタウンにあるポケモンの育成を代行してくれる店 → [根拠](pro-team/根拠/038_そだてや_そだてや.md)
- そだてやは他チームの育成内容を明かさず、協会が過剰な育成を制限している → [根拠](pro-team/根拠/039_そだてや_そだてやは他チームの育成.md)
- 「そだてや」の名前は「スピカ」。中規模大会に出たチームは先に預けられる → [根拠](pro-team/根拠/040_そだてや_そだてやの名前はスピカ1.md)
- そだてや・スピカの店主は「育成：AAA」の沖野（ハルウララの父） → [根拠](pro-team/根拠/041_そだてや_そだてや・スピカ153店.md)
- 沖野は育成のシミュレーションを用意し、期間を決めて責任を持って預かる → [根拠](pro-team/根拠/042_そだてや_そだてやの預かり方.md)
- そだてやは協会のお達しで、『天賦』以外は『第三階梯』までしか育てない → [根拠](pro-team/根拠/043_そだてや_そだてやの上限.md)
- 技にも**種族ごとの適性**がある。「ウマ娘」は種族として「しんそく」「しょうりのまい」などに潜在的な適性を持つ個体が多い（引き出せるかは個体差）。（出典: 153）
- **ジムは育成機関でもある**（エネル）。門下生以外に育成の知識を提供することもあり、ナギサジムにはロトムの古文書がある。古代種は現代種より育成の歴史が長い。（出典: 154）

## サポーター（SP）

### SPの仕組み

- 「B」から増えるもう一つのスタッフがサポーター（SP）。チームに「統率」の力を及ぼす → [根拠](pro-team/根拠/044_SPの仕組み_Bランクから増えるもう一.md)
- SPはサポート効果と、ランクに応じた『追加役割』の任命でバトルに影響する → [根拠](pro-team/根拠/045_SPの仕組み_SPは持っているサポート.md)
- SPの「統率」は、ポケモンを従えるのに必要な要「統率」には関わらない → [根拠](pro-team/根拠/046_SPの仕組み_SPの統率はポケモンを従.md)
- SPは素人でもでき、アイドルや生徒会長などトレーナー経験のないSPも多い → [根拠](pro-team/根拠/047_SPの仕組み_SPはポケモンの知識がほ.md)
- カズマたちがB昇格後にまず探すのはSP。（出典: 110, 111）
- SPの『追加役割』は、「統率：A+」相当で1つ、「AA」相当以上で1〜2つが目安 → [根拠](pro-team/根拠/048_SPの仕組み_152の話SPの追加役割.md)
- 「B」ではSPの『追加役割』があるので、誰が隠れ『チェイサー』か読めなくなる → [根拠](pro-team/根拠/049_SPの仕組み_Cまでは統率型以外がチェ.md)
- SPやBDを雇っても、純「統率」型や純「育成」型の優位は残る → [根拠](pro-team/根拠/050_SPの仕組み_SPで補えないもの.md)
- SPはバトル中に相手を分析して助言でき、「タイム」の相談にも加われる → [根拠](pro-team/根拠/051_SPの仕組み_SPの実戦での働き.md)
- 人にはSPとして付けられる『追加役割』の診断結果があり、カズマは『エンチャンター』だけ → [根拠](pro-team/根拠/052_SPの仕組み_SPの診断結果.md)
- ポケモン自身がポテンシャルで『役割』を得る抜け道もあるが、割に合わない → [根拠](pro-team/根拠/053_SPの仕組み_ポテンシャルによる役割の.md)

### サポート効果

- SPの力は『追加役割』とサポート効果の2つ。ミラクルズのSPは天花 → [根拠](pro-team/根拠/054_サポート効果_SPのサポート効果.md)
- 「稀に」などのサポート効果は、たまれば使い手がある程度タイミングを選べるらしい → [根拠](pro-team/根拠/055_サポート効果_低確率稀にのサポート効果.md)
