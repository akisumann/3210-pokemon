# ペルソナ系（ペルソナ・女神転生）

原典に図鑑（【名前】から始まるデータ）が出た『ペルソナ』シリーズのペルソナ（と、同じ悪魔で『女神転生』の看板のジャックフロスト）の個体だけを数えた（5体。タナトス、アルセーヌ、ジャックフロスト、イザナギ、ツキヨミ）。原典で「ペルソナ」種のようには呼ばれておらず、名前と種属でまとめた（推測）。体力は図鑑に出ないので `world/hp-estimates*.md` の推定（○△は確かさ）。同じ個体で図鑑が何度も出たものは、最初と最後を別の行にした。傾向は各個体の最後の図鑑で数えている。

- タナトスは104（Lv65）から381（Lv120）まで直哉の手持ち。種族値は同じで、技が「ばかぢから」「ねむる」→「いてつくしせん」「しにがみのかま」に替わり、種属『愚死神の呪詛』と『対悪』2点、『スターター』が増えた。持ち物は「いのちのたま」→「きあいのタスキ」（出典: 104, 381）。
- イザナギの攻「A+（B）」は、属『マハタルカオート』（自身の「攻」の種族値がトレーナーの「能力」と同ランクになる）の表示と、素の値。鳴上は「能力」型（出典: 315）。
- ツキヨミは原典でペルソナとは呼ばれていないが、属『マハスクカオート』（自身の「速」の種族値がトレーナーの「能力」と同ランクになる）がイザナギの『マハタルカオート』と同じ形の『ペルソナ』のスキル名なので入れた（推測）。速「A+（B）」はこの属の表示（冬優子は「能力：A+」）と素の値、特攻「A（B）」は特性「にとうりゅう」（攻と特攻の低い方を高い方と同ランクまで上げる）の表示と素の値（出典: 564）。
- 属の名前はそれぞれのゲームから（『メメント・モリ』は『ペルソナ3』の標語、『ピカレスクロマン』は『ペルソナ5』の副題、『マハタルカオート』と『マハスクカオート』は『ペルソナ』の補助のスキル、『フロスト頭巾』はジャックフロストの頭巾）（推測）。
- 種属は、タナトス『愚死神』、アルセーヌ『愚怪盗』（どちらも主人公の「愚者」のアルカナからか。推測）、ジャックフロスト『氷精霊』、イザナギ『伊邪那岐』、ツキヨミ『月光影』。
- 入れなかったもの: アイギス（ダージリン、385）。『ペルソナ3』のキャラだがペルソナではなく、原典ではロボットの扱いで [ロボット系](ロボット.md) に入れている。

## 傾向

- **性別がない（-）ものが5体中4体**（タナトス、アルセーヌ、イザナギ、ツキヨミ）。ペルソナは人の心の像なので、性別を持たないのだと思われる（推測）。ジャックフロストだけ♂（出典: 170, 208, 315, 381, 564）。
- 出てくる層: 第一節（Lv65〜85）から第三節前（Lv120）までの4体と、第四節準備編のブレーン対抗戦（Lv160）のツキヨミ。トレーナーは5人ともばらばら。原作どおりの組み合わせは、『ペルソナ4』の主人公の鳴上悠とイザナギだけ（出典: 104, 170, 209, 315）。
- 種族値:
  - 4体（タナトス、アルセーヌ、イザナギ、ツキヨミ）が物理寄り。攻はA+（タナトス、イザナギの表示）かA（ツキヨミ）かB（アルセーヌ、イザナギの素）。ジャックフロストだけ特殊寄り（特攻B、特防A）。
  - 防がそろって低い（C〜D-）。体力の推定もC〜B前後で（ツキヨミは推定なし）、打たれ弱い。5体中3体が「きあいのタスキ」を持っていた（タナトス、アルセーヌ、ジャックフロスト。ツキヨミは「いのちのたま」）（出典: 170, 209, 381, 564）。
  - 速はばらばら（アルセーヌAA、イザナギA、ツキヨミA+（素はB）、タナトスとジャックフロストC）。
- タイプ: ばらばら（ゴースト、ノーマル/あく、こおり/フェアリー、でんき、ゴースト/フェアリー）。ゴーストとフェアリーが2体ずつ。
- 技: 5〜7個。搦め手を入れるもの（タナトスの「のろい」、アルセーヌの「ちょうはつ」「ねこだまし」、ジャックフロストの「あられ」「なまける」）が多い。イザナギはスキル名を思わせる「こころのめ」の状態を専用で作る。ツキヨミは「やみのつるぎ」「しんぴのつるぎ」「つるぎのまい」など剣の技が中心（出典: 170, 209, 315, 381, 564）。
- ポテンシャル:
  - 先発・登場時に働くものが多い（タナトス『狩人』とジャックフロスト『魔術師』は先発系の役割、アルセーヌ『愚怪盗の予告』は交代で出た時に挑発、イザナギの専用は場に出た時に「こころのめ」）（出典: 170, 209, 315, 381）。
  - 倒れても置き土産を残す形が2体（タナトス『メメント・モリ』は倒された時に1/8の「霊」ダメージ、ジャックフロスト『フロスト頭巾』は霰の時に攻撃以外で倒れない）。
  - 異名はイザナギの『ハイカラ』（「鳴上悠」の時、メンタル効果を無効）とツキヨミの『斬月』（トレーナーが「能力：A」以上の時、タイプ不一致の「けん」「つるぎ」等の技1.5倍）の2体。専用はアルセーヌ（『エース』が出た時に交代で飛び出す）、イザナギ（場に出た時「こころのめ」）、ツキヨミ（1/試/先行で「おいうち」効果と必中、「おいうち」の時にダメージ2倍）の3体（出典: 170, 315, 564）。
- 役割: ばらばら（先発系2体（『狩人』『魔術師』）、『チェイサー』、『不動のエース』、『エースキラーα』）。
- まとめ（推測）: 性別のないペルソナが中心で、防が低く打たれ弱い代わりに、先発や登場時に仕事をする形が多い。「タスキ」で1回は耐えて仕事をする前提の作り。属の名前にシリーズの言葉が入る。
- 向いているトレーナーと使い方（推測）: 「タスキ」を持たせて先発で場を荒らし、後ろにつなぐ係で、平均的には指示型（直哉のタナトス）。イザナギは属『マハタルカオート』で攻が、ツキヨミは『マハスクカオート』で速がトレーナーの「能力」と同ランクになるので、能力型が一番伸ばせる（鳴上、冬優子）。
