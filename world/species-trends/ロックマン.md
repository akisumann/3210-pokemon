# ロックマン系

- 元ネタはどれも推測。ペンギーゴは属『イレギュラーハンター』（『X』の用語）、ブルースは属『トランスミッション』（『エグゼ』のプラグイン）、ハープ・ノートは属『ブラザーバンド』（『流星』の用語）と種属『電波歌姫』、パンドラは属『ライブメタル』（『ZX』の用語）と種属『災厄嬢』、フォルテは種属『電脳鬼』と属『ドリームオーラ』（『エグゼ』のフォルテの技）、ゴスペルは種属『合成獣』と属『バグのかけら』（『エグゼ2』のゴスペル）から。属の名前に、それぞれのシリーズの用語がそのまま入っている（出典: 060, 194, 224, 247, 489, 533）。
- ブルースは、アスカのチームの「赤」と、付随の『プラグスーツ』（『エヴァ』のネタ）も持つ（出典: 194）。
- ペンギーゴは `species-trends/ロボット.md` では、原典でロボット・機械と言われないので入れていない（「入れなかったもの」）。フォルテは種属『電脳鬼』を持つがデジモンではない（`species-trends/デジモン.md`）。
- 図鑑のない関係者: ギンガ団のプルート（コードネーム。本名ワイリー。研究部門長）は、『ロックマン』のDr.ワイリーと思われる（推測。人間なので数えない）（出典: 133, 284, 524）。086でカズマが、好きな順番でボスを選べるジム巡りを「ロックマン方式」と言った（出典: 086）。

## 傾向

- 第四節に入って足した行（2026-10-28。下の数には入っていない）: オールマインドのVAVA（675、Lv170）。異名『砲火魔』と種属『反乱機の〜』で「だん」「ボール」等の技を強化する特殊寄りの砲台。『回路異常』で「変化技」を覚えられない。作者: 現役時は特性「メガランチャー」に「かえんだん」の『キラー』想定。
- 第四節に入って足した行（2026-10-28。下の数には入っていない）: トールのシエル（681・682、Lv175）。特性「かがくのちから」で死に出しの時に味方の特性を写し、種属『科学者の〜』で解析・能力下げ・「電」の味方の強化。専用『その願いの名はシステマ・シエル』（任意交代で「ねがいごと」）。作者: エネルのとこの「シスターズ」種みたいなもの（種族的に）、シエルのおかげでナギサシティは停電から救われている。

- 出てくる層: 第一節（Lv60）の「C」の相手から、第二節（Lv95）の「B」のチームやジムリーダー、第三節（Lv155〜160）の上位勢の主力まで、どの層にも1〜3体ずついる。トレーナーは6人ともばらばらで、2体以上持つ人はいない（出典: 060, 194, 224, 247, 489, 533）。
- 種族値:
  - 特殊寄りが多い。特攻が攻より高いのは6体中4体（ペンギーゴB、パンドラA-、ハープ・ノートB+、ゴスペルA+）。物理寄りはブルース（攻B）だけで、フォルテは攻・防・特攻がそろってA（出典: 060, 194, 224, 247, 489, 533）。
  - 特防が防より高いのは6体中4体（パンドラ、ハープ・ノート、ゴスペル、ブルース（C対C-））。逆はフォルテ（防A・特防C）だけ。ペンギーゴは防も特防もC-。
  - 速は2つに分かれる。速Aのペンギーゴとブルース（どちらも体力C前後以下の小兵）と、C〜C+のほかの4体。
  - 体力（推定）: Lv95以下はC-〜B（ペンギーゴC-、ブルースC、パンドラC+〜B）、Lv155以上の2体はA前後以上（ゴスペルA前後、フォルテA〜AA。フォルテは『王者の特権』で体力が少し上がる）。どちらも『固有種』で、上位勢の主力。
- タイプ: 「でんき」が3体（パンドラ、ハープ・ノート、フォルテ）で一番多い。「でんき/ゴースト」が2体（ハープ・ノート、フォルテ）重なる。「こおり」も2体（ペンギーゴ、パンドラ）。ほかはひこう・ノーマル・あく・エスパー1体ずつ（出典: 060, 194, 224, 247, 489, 533）。
- 技: 5〜8個。とんぼ技・交代技を持つものが多い（ブルースの「ボルトチェンジ」、パンドラの「ボルトチェンジ」、ハープ・ノートの「ゆうたいりだつ」）。状態異常の技（でんじは2体（ハープ・ノート、ゴスペル）、メロメロ、いばる）や、ほろびのうた（パンドラ）、ものまね・バリアー（フォルテ）など、搦め手の変化技を持つものが6体中5体（例外はブルースの「きあいだめ」「まもる」だけ）（出典: 060, 194, 224, 247, 489, 533）。
- ポテンシャル:
  - 搦め手が中心。相手の状態で効くもの（ペンギーゴ『イレギュラーハンター』は混乱の相手に急所C+2、ハープ・ノートはメロメロの相手にタイプ耐性貫通、パンドラは「死のカウント」で能力を下げる、フォルテは麻痺の相手に必中と1/8の電ダメージ）と、相手を状態異常にするもの（ゴスペル『バグのかけら』の「2割：混乱」、ハープ・ノートの「3割：メロメロ」）が多い（出典: 060, 224, 247, 489, 533）。
  - データ・解析がらみが2体（ハープ・ノート『電波歌姫の楽譜』（交代時に相手を解析）、ゴスペル『スカウター』と解析からの『合成獣の吸収』『合成獣の汚染』）。電脳・電波の出自らしい（推測）。デジモン（11体中9体が解析がらみ）ほどではない（出典: 247, 533）。
  - 支える役割が6体中3体（『エースアシストβ』のハープ・ノート、『エースアシストγ』のパンドラ、『スカウター』のゴスペル）。ハープ・ノートは属『ブラザーバンド』で『絆』持ちに『アシスト』が必ず発動し、専用『電波局より飛び交うシグナル』で場を離れる時に味方の『エース』を発動させる（出典: 224, 247, 533）。
  - 上位の2体は『固有種』で種属が4つ（フォルテ『電脳鬼の〜』、ゴスペル『合成獣の〜』）、異名（『絶雷』『混狼』）も持つ。フォルテはさらに『もどりのヌシ』（異界のヌシ。「もどりのおうぎ」）と『エンペラー』（専用『ウラの世界に座するモノ』で任命）（出典: 485, 489, 533）。
- 役割: ばらばら（なし、先発系『狩人』、『エースアシストβ』『γ』、『エンペラー』、『スカウター』）。『エース』『二枚看板』はいない（出典: 060, 194, 224, 247, 489, 533）。
- まとめ（推測）: 特殊寄りで、相手の状態を作ったり利用したりする搦め手と、交代・支援が得意な種族が多い。下の層では速い小兵（ペンギーゴ、ブルース）、上の層では『固有種』の大物（フォルテ、ゴスペル）がいて、層によって顔つきがかなり違う。属の名前に元のシリーズの用語が入るので、新しく出た個体も属で見分けやすい。
- 向いているトレーナーと使い方（推測）: 指示型か統率型の支え役。交代を回しながら状態異常を積む使い方が平均的に強い。『固有種』の大物（フォルテ、ゴスペル）は統率の高い監督の主力（エネルの『エンペラー』、マユリの『スカウター』）。
