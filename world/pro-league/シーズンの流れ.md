# ポケモンリーグ ／ シーズンの流れ

- シーズンは**4つの節**に分かれる（第一節〜）。年間の4シーズン（春夏秋冬）のリーグで、第二節のクライマックス（ハクタイ杯大規模大会）が折り返し地点の前にあたる（337の作者）。第四節が「**ポケモンリーグ**」（アカネ「第四節、ポケモンリーグが早くも楽しみ」）。（出典: 044, 051, 080）
  - **第四節の中身**（479）: 例年、“第四節”がその年のリーグ20チームの選抜にあたり、''リーグ争奪戦''がすぐ始まる（さみだれ・ルサルカ）。昨年の上位勢や“四天王”、“ギンガ団”も参戦するので、最初の大会からそういうチームとぶつかる可能性も充分ある（極端な話、初手チャンプもありうる）。そうして「その年の上位20チーム」と評価されたチームが、“第四節”のクライマックスの頂上決戦（ポケモンリーグ）でぶつかる（羅刹・クーデリア）。「A」に昇格したチームは、その中で力を示す必要がある。どのチームも“第四節”に向けて最高潮に仕上げてくる（さみだれ）。（出典: 479）
  - **第四節の仕組み**（597、同期会）: 第四節の開幕戦はどの街も“「A/B」混成ランク”の中規模戦。第四節はクライマックスリーグへの予選を兼ねた蹴落とし合いで、勝率・戦績・注目度などを加味して上位20チームがリーグ予選に参加できる（操祈）。規則に「「B」ランクはリーグに選ばれることはない」とは一文も書いていない（先輩）。シードの五強とほぼ確実な四天王で席はざっと半分、五強（煉獄・ジュピター含め）と四天王、ギンガ団でもう10枠、四天王とギンガ団はほぼ確実にリーグ出場権を奪い取る枠。第四節にエキシビションはなく、代わりに「A/B」混成ランク大会がある（作者）。「A」ランカーだけの大会もあり、「B」とぶつかるのは「A/B」混成戦だけ（直哉）。ジムリーダーも「A」相手に手加減する理由はない。（出典: 597）
  - **クライマックスリーグの仕組み**（734、プロデューサーとウタ）: 特殊な大規模戦の扱いで、3日間。会場は3日間ともシンオウ地方ポケモンリーグ本部スタジアム（カントーのセキエイ高原のようなもの。夜コミュイベもそこが舞台）。1日目と2日目で予選リーグ（4チーム×5ブロック、4チームの総当たりで1チーム3戦。全ブロックを同じ会場で行うので時間に余裕がある）。組み合わせは事前発表（ウタが担当）。各ブロックに昨年の5強が1チームずつ配置され、四天王や同じギンガ団のようにスポンサーが同じチームは同じブロックにならず、同じ【H】のチームも同じブロックになりにくい。各ブロックの1位の5チームが最終日の決勝リーグ（新たな5強での総当たり）に進み、その順位が「来年のシンオウ○位」（煉獄の2位やジュピターの3位は決勝リーグの順位）。リーグの時はジムリーダーもジムを閉めて8人全員が見に来る。テレビコトブキが大々的に放映し、ウタが公式応援キャラ。大規模戦を制した3チーム（アンタレス、クインビーズ、ミラクルズ）は注目度で言えば5強と同等以上（プロデューサーの内心）。作者（運営A）: ひとつのブロックに大規模戦を制した3チームを纏めて……！？（出典: 734）
  - **リーグまでの流れ**（749）: 全チームのすべての日程の終了はマサゴ杯の翌週で、その直後にリーグ出場の20チームに正式な案内が届き、リーグ開始の数日〜1週間前に組み合わせが発表される（ルサルカ）。A〜Eの5つの予選ブロックには、すべて昨年の1位〜5位が配置されるので、必ず予選で5強の一角と激突する（マックイーン）。チャンピオンのチーム（ホーネット）はこの3年間クライマックスリーグ無敗で、今年勝てば四連覇（748）。リーグは来月（748のホーネット）。（出典: 748, 749）
  - **リーグの組み合わせと日程**（751〜753）: リーグ出場20チームは753で正式に決まり、協会の通達が届いた。予選リーグの組み合わせは練習試合の直後に発表（発表役はウタ、754）。四天王は4つのブロックに散らばり、全ブロックに昨年1〜5位がいる。リーグ本部のスタジアムにも【H】補正があり、最優先【H】は四天王の4チーム、次ぐ優先【H】は昨年のチャンプ（山岡）。4チームの予選と5チームの本戦なので【H】補正が響く場面はあまりない（カズマ）。リーグの注目度はミラクルズとチャンピオン（四連覇を狙う。記録上ここ100年で達成したシンオウのトレーナーはいない）がトップタイ、次いで操祈とマーズ、煉獄（山岡）。リーグ予選は3試合で、1日目〜2日目はそれぞれ1戦の日と2戦の日がある。1日目と2日目の夜にコミュ枠が3人分ずつ、3日目は決勝リーグの4連戦（作者）。各地方のクライマックスリーグはほぼ同時期で、日程的にシンオウが一番先（イッシュ、カントーより先。ヒナ）。「マスターズリーグ」は、エニシダとヒナの父などが動いて、来年の第二節終了時（シーズンのど真ん中）にイッシュでやろうとしている（ヒナ、753）。（出典: 751, 753, 754）
  - **今年の予選の組み合わせ**（762。リーグの1週間前に、公式応援団長のウタがポケモンリーグ本部から実況で発表）: 予選は例年どおり4チームずつ「A～E」の5ブロックのリーグ戦で、各ブロックに昨年の本戦出場5チーム（昨年の5強）が1チームずつ。各ブロックで勝ち星の一番多いチームが決勝リーグへ。【H】の最優先指定は「四天王」、準【H】補正はチャンプで、ほかは横並び。全ブロックがポケモンリーグ本部のメインスタジアムで、1～2日目が予選、3日目が決勝リーグ（7回勝ったら優勝）。（出典: 762）
    - Aブロック: 《銀河団シリウス》（サターン）、《百代ファンタジーズ》（ジータ）、《求道ジャベリンズ》（“達人”黒木玄斎、「育成」型の古豪、ノモセ最強）、《神凪テスタメント》【H】（チャンプのホーネット、三連覇中）。第一試合はチャンプ対黒木（763のギャリー）
    - Bブロック: 《渚砂ミョルニルズ》（トール）、《蛮食堂ワイルズ》（小林竜胆）、《神殿守ドミネーターズ》（マキマ）、《四天フレイムハート》【H】（四天王筆頭の煉獄杏寿郎、昨年2位、シンオウ最高峰の「育成」型）
    - Cブロック: 《探検堂ミラクルズ》、《進化研ユニバース》（エール）、《四天ニュータイプ》【H】（四天王アムロ、「エスパー」の「指示」型）、《銀河団アンドロメダ》（ギンガ三将星筆頭の“ジュピター”コーネリア、昨年3位、“現”シンオウ最強の「統率」型、『異界のヌシ』の『エンペラー』）。ミラクルズ以外はPC操作。第一試合はミラクルズ対ユニバース（ルーキー同士）。ウタ: 最も注目を集める予選ブロック
    - Dブロック: 《百貨店キングダム》（李牧）、《園生クインビーズ》（食蜂操祈）、《四天アースクエイク》【H】（朝比奈さみだれ）、《電波局ストラッシュ》（アバン、昨年4位）
    - Eブロック: 《四天スパイダーズ》【H】（クロロ）、《学園クルセイダーズ》（空条承太郎）、《銀河団アンタレス》（マーズ、ギンガ三将星の最年少）、《図書館アーカイブス》（ホシノ、昨年5位）。作者: マーズには決勝で行くために自力でORTとルギアを突破してもらいます（運営E）
    - **組み合わせの前の噂**（758, 762）: “昨年の「指示」型トップ（アバン。759の作者）とギンガ団のあの女（推測: マーズ）を予選でぶつけたら面白くない？”という噂があり、ホシノは「私は実質「複合」同士であのおっぱい後輩（操祈）とぶつかるんすか」と頭を抱えていた。トールは運営が予選で煉獄とぶつけようとニヤニヤしているという噂に嫌な顔（762の作者。これは当たった）。ウタの予想「カズマは予選第一戦でvsチャンプ」、「カズマさんのブロックがいっちゃんキツくない？」的な噂は外れ（作者: 全部地獄。運営「この20チームでいっちゃんキツイ予選の組み合わせとか、どうすりゃ良いんですか（半ギレ）」）。（出典: 758, 759, 762）
    - **リーグ前と開会式**（764〜768）: 予選の各ブロックは、1日目の午前に第一試合（A・B・C・Dの順。ミラクルズ対ユニバースは3番目、Dの第一試合は操祈対李牧）、午後に2試合目、2日目に最後の試合（Cブロックではミラクルズ対ジュピターが「統率」型最強決定戦）。全チームは前日の午後までにリーグ本部に現地入り（島の最高ランクのホテルの1フロア貸し切り）。その日から各地のジムやバトルフロンティアは臨時休業、地方全域で生中継。開会式はリーグ会長の挨拶、代表の宣誓（今年は煉獄）、そのあと15分後に第一試合（オープニングマッチはAブロックの《神凪テスタメント》対《求道ジャベリンズ》）。進行は公式応援団長のウタ。（出典: 764, 766, 767, 768）
    - **予選の結果と決勝リーグ**（780, 783, 784）: 予選はA《神凪テスタメント》（チャンプのホーネット）、B《四天フレイムハート》【H】（煉獄）、C《探検堂ミラクルズ》、D《園生クインビーズ》（操祈）、E《銀河団アンタレス》（マーズ）が勝ち上がり、どこも3戦全勝。この5チームが「新たなる5強」。3日目の決勝リーグは5チームの総当たりで、最も勝ち星を挙げたチームが王座に就く。抽選で決まった初戦はミラクルズ対アンタレス。（出典: 780, 783, 784）
  - 「A」の下位と、リーグに出る上位20チーム（リーグ級）の間には大きな差がある（補足: ユーザーより）。「A」に上がること自体より、リーグ争奪戦で20チームに入ることの方がずっと高い壁になる。

（出典: 044, 051, 080, 337, 479）

- シーズンの最初に、**ポケモンリーグ本部スタジアム**で**開会式**が行われる（チャンピオンが宣誓）。招かれるのは去年のポケモンリーグに出場した20チームだけで、多くのチームにとっては儀礼的なもの。関心は第一節の開幕戦と組み合わせにある。（出典: 051）

- 第一節の「A」ランクの最終日程はハクタイの中規模大会（ハクタイ杯）で（156で予告）、アカネの《銀河団アンタレス》が四天王さみだれの《四天アースクエイク》に勝って優勝した。チケットは完売。昨年のリーグ出場者（シンオウ上位20チーム）から2チームが出ていた。これで**第一節が終わり**、一時の休息期間（**オフシーズン**）を経て第二節に入る。オフシーズンは、プロチームがファイトエリアのバトルフロンティアで調整することも多い。（出典: 156, 159, 161）
