# ポケモンリーグ ／ 地方対抗交流戦（502）

- **開催と形式**（502、ウタのコトブキでの大規模ライブの客席で、プロデューサーとメアリがカズマたちに話した）: PVに端を発したプロジェクトが、地方でドラマのほかにもいくつか動かしてきた企画の一つ。**第三節が終わった後**に開かれることになった“地方対抗交流戦”で、開催地は先日**シンオウ地方**に決まった（プロデューサー）。この後のライブで、ドラマと並ぶ目玉として発表される（メアリ）。
  - 中身はガチガチの大会ではなく、各町のスタジアムを解放しての**お祭りに近い**もの（メアリ）。**大規模戦と同じ3日間**、シンオウの**すべての街のスタジアム**を解放して、バトルを何度も行う（メアリ）。
  - 大会形式ではなく、3日間戦いっぱなしでもない。物理的なスペースの問題もあるし、ファンや他地方のトレーナーとも触れ合ってほしい（プロデューサー）。カズマは、勝ち負けも関係ない、あくまで交流戦というスタンスと受け取ったうえで、他の地方との大がかりなバトルイベントなので興行効果はかなり大きそうだと見た。
  - 海外から来るトレーナーを**シンオウ勢が迎え撃つ**形のイベントになり、他の地方へのアピールにしたい（プロデューサー）。カズマいわく、第四節（シーズンのラスト）の前にまた大規模なイベントが企画された形。
  - **カズマの出番**: カズマは「クレバーにバトルを一切せず交流と観戦に充てる」と言ったが、プロデューサーは、カズマは注目株もいいところなので**1日1回、つまり3回はバトルしてもらう**と決めた（AA内「お前自分の影響力わかってんのか、いろんな意味で」）。メアリは、カズマが「A」ランカーになるなら、第四節の前に他地方とはいえ「A」と戦う経験は悪くないし、ジムリーダーと戦えるチャンスもあると言った。相手について、カズマにも選択権は大きくあるはず（メアリ）。
  - System は「交流戦（仮）」と呼び、PV・連動ドラマ・交流戦などのイベント群では、蘇った「グラシデアの花」を大々的に押していくつもりらしい、とした。

（出典: 502）

- **来る顔ぶれ**（502、メアリ・プロデューサー）: 他の地方のランカー（プロチーム）から、ジムリーダー、四天王なども来る。ただしジムリーダーなどは容易に地方を離れられない立場なので（ルサルカの疑問）、他の地方から来るのは**各数人ずつ**で、ジムリーダーは2人も来れば多い方（メアリ）。メインで来るのは**他の地方のプロチーム**（メアリ）。
  - シンオウ側の**ジムリーダーも全面的に参戦**する予定で、場合によっては四天王vs四天王、ジムリーダーvsジムリーダーのようなこともありうる（メアリ）。カズマが他の地方のジムリーダーや四天王と戦う可能性も、もちろんある（プロデューサー）。
  - **バトルフロンティアも一枚噛んで来る**らしい（プロデューサー（AA内））。
- **地方ごとの状況**（502、プロデューサー）: **カントー、イッシュ、ガラル**は一も二もなく乗ってきた。**カロスとジョウトも順調**、**ホウエンとパルデアはこれから**、難航しそうなのは**アローラ**。プロデューサーは、価値観の問題などもあるだろうが、これを機にアローラなどとも交流を深められれば大きな前進になると考えている。
  - すでに来ることを（勝手に）宣言しているのは**カントーの四天王筆頭**（「あのハチャメチャドラゴン遣い」。それがダメなら俺を殺せレベルで暴れているらしい）。カズマは「初日から手加減なしのワタルさんとの全力バトルの可能性も微レ存………？」と言った（カントーの四天王筆頭はワタル（海馬瀬人）→ [regions.md](../regions.md) のカントー地方）。
