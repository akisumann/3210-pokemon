# ポケモンリーグ ／ 地方対抗交流戦（502）

- **開催と形式**（502、ウタのコトブキでの大規模ライブの客席で、プロデューサーとメアリがカズマたちに話した）: PVに端を発したプロジェクトが、地方でドラマのほかにもいくつか動かしてきた企画の一つ。**第三節が終わった後**に開かれることになった“地方対抗交流戦”で、開催地は先日**シンオウ地方**に決まった（プロデューサー）。この後のライブで、ドラマと並ぶ目玉として発表される（メアリ）。
  - 中身はガチガチの大会ではなく、各町のスタジアムを解放しての**お祭りに近い**もの（メアリ）。**大規模戦と同じ3日間**、シンオウの**すべての街のスタジアム**を解放して、バトルを何度も行う（メアリ）。
  - 大会形式ではなく、3日間戦いっぱなしでもない。物理的なスペースの問題もあるし、ファンや他地方のトレーナーとも触れ合ってほしい（プロデューサー）。カズマは、勝ち負けも関係ない、あくまで交流戦というスタンスと受け取ったうえで、他の地方との大がかりなバトルイベントなので興行効果はかなり大きそうだと見た。
  - 海外から来るトレーナーを**シンオウ勢が迎え撃つ**形のイベントになり、他の地方へのアピールにしたい（プロデューサー）。カズマいわく、第四節（シーズンのラスト）の前にまた大規模なイベントが企画された形。
  - **カズマの出番**: カズマは「クレバーにバトルを一切せず交流と観戦に充てる」と言ったが、プロデューサーは、カズマは注目株もいいところなので**1日1回、つまり3回はバトルしてもらう**と決めた（AA内「お前自分の影響力わかってんのか、いろんな意味で」）。メアリは、カズマが「A」ランカーになるなら、第四節の前に他地方とはいえ「A」と戦う経験は悪くないし、ジムリーダーと戦えるチャンスもあると言った。相手について、カズマにも選択権は大きくあるはず（メアリ）。
  - System は「交流戦（仮）」と呼び、PV・連動ドラマ・交流戦などのイベント群では、蘇った「グラシデアの花」を大々的に押していくつもりらしい、とした。

（出典: 502）

- **来る顔ぶれ**（502、メアリ・プロデューサー）: 他の地方のランカー（プロチーム）から、ジムリーダー、四天王なども来る。ただしジムリーダーなどは容易に地方を離れられない立場なので（ルサルカの疑問）、他の地方から来るのは**各数人ずつ**で、ジムリーダーは2人も来れば多い方（メアリ）。メインで来るのは**他の地方のプロチーム**（メアリ）。
  - シンオウ側の**ジムリーダーも全面的に参戦**する予定で、場合によっては四天王vs四天王、ジムリーダーvsジムリーダーのようなこともありうる（メアリ）。カズマが他の地方のジムリーダーや四天王と戦う可能性も、もちろんある（プロデューサー）。
  - **バトルフロンティアも一枚噛んで来る**らしい（プロデューサー（AA内））。
- **地方ごとの状況**（502、プロデューサー）: **カントー、イッシュ、ガラル**は一も二もなく乗ってきた。**カロスとジョウトも順調**、**ホウエンとパルデアはこれから**、難航しそうなのは**アローラ**。プロデューサーは、価値観の問題などもあるだろうが、これを機にアローラなどとも交流を深められれば大きな前進になると考えている。
  - すでに来ることを（勝手に）宣言しているのは**カントーの四天王筆頭**（「あのハチャメチャドラゴン遣い」。それがダメなら俺を殺せレベルで暴れているらしい）。カズマは「初日から手加減なしのワタルさんとの全力バトルの可能性も微レ存………？」と言った（カントーの四天王筆頭はワタル（海馬瀬人）→ [regions.md](../regions.md) のカントー地方）。

（出典: 502）

- **アローラの顔ぶれと、559〜560の見通し**: 547でアローラの参戦が決まった（エーテル財団が金と権力で周囲を巻き込んだらしい）。559の天花の話: チャンピオンやしまキング・しまクイーン（シンオウで言う四天王）は来られず、エーテル財団を中心とした若い衆がメイン。“キャプテン”から2人で、1人は「むし」使いのキャプテン最強のトレーナー（ファンクラブ的な“スカル団”も来る可能性が高い。白野が黒子から聞いた。カズマのライバル筆頭の操祈にかなり興味を持っている）、もう1人は**美柑**（海夢とどちらが行くかの争いは野良試合（ギャラリー大量）にまで発展し、「くさ」vs「みず」の相性がキャリアを覆して美柑に）。今シンオウは全国的にもレベルが高まっていると言われ、アローラは平均的な質ではこの地方より落ちる（最上位層は図抜けている）。アローラから来るチームは一番少なそうで、先に乗ってきた他の地方には四天王が来るところもある（白野）。天花は「ワタルとグリーンの2人が興味を示した」という記事を見た気がする。（出典: 547, 559）
  - **カズマの出番**（559）: 1日1戦の計3戦（以前プロデューサーが言った通り）。ハクタイ側が「3日のうち1日はこの街で」と言っていて、1戦はハクタイ（地元を盛り上げる枠。ライザ: 美柑と戦うのもあり）。お祭り要素が強いので、1日だけSPを組む案（みさきちのSPにカズマ、またはその逆）も出た（実際にやるには相手の了承が要る）。
  - **都市チーム**（560）: 操祈は一戦をソノオタウンでやると決められている（都市チームの監督なので）。先輩とジータも都市チームの監督で、「3つの街はまぁウハウハ」。ダブルバトルはプロでは採用されていないルールなので、交流戦でもやらない見込み（作者「オーレ地方とかならやってるんとちゃいますかね（適当）」）。
  - **ドラマの放映**（560）: ウタのドラマは、他地方のトレーナーたちが来る交流戦のタイミングで放映することになりそう（メアリ）。（出典: 559, 560）

- **566の予定**: 開催は来週から3日間、シンオウ全体のスタジアムを開放したお祭りで、他地方から来るチームやジムリーダーなどと合意の上なら自由にバトルできる（順番待ちもありそう）。気の早いところは明日にでも乗り込んでくる（観光目当ても）、街も歓迎ムード。オシュトル: ブレーン対抗戦よりさらに勝敗の優先度が落ちるホンモノの祭り。作者: 交流戦は各日程でコミュ枠（夜会話的なもの、1〜2人ずつ）が発生する。交流戦の前のフリーイベントで、アローラのグズマ（「おうにーちゃん、最先端のイカしたナウいジャージじゃねぇか？」）、カントーのグリーンとワタル（大物タッグ+α）が来ることになった。バトルフロンティアも3日間開放される。（出典: 566）

- **参加者の上陸（567〜570）**: 交流戦の前から“シンオウ・ラッシュ”と呼ばれるほど続々と他地方から上陸してくる。（出典: 567, 568, 569, 570）
  - **アローラ**（567）: 田舎からの解放とばかりに一番乗り。エーテル財団の代表の今代の“ルザミーネ”（恋）が、財団の最強チーム《神代エーテリオンズ》（キリシュタリア、アローラ2位）、キャプテン最強の「むし」使いのグズマ（とプルメリ、“スカル団”）、美柑、そのほか扇動した若いチームを連れてきた。島キング・島クイーンは来られなかった。
  - **カントー**（569）: グリーン（白石）、天子（第三節に「B」“上位”）、ワタル（海馬。アルトリアが同行）。ワタルは抜け駆けしようとしてグリーンら数人に取り押さえられ、数日遅れた。
  - **ホウエン**（570）: フエンタウンの都市チーム《釜炎ダイナーズ》（秋山醤、「育成」型、第四節から「A」）が屋台を引いて来た。
  - ほかにも、イッシュの四天王になったお嬢様（ギルベルトの「お嬢様」）、ジョウトから来たジムリーダー（スペランカーと対戦予定）など（571）。
- **バトルフロンティア**（568）: 交流戦の3日間、ブレーンも各自の拠点（バトルルーレットなど）で最前線に立ち、海外のトレーナーにフロンティア流を味わってもらう。準備のためフロンティアは数日臨時休園。
- **初日（571）**: 交流戦は“他地方から上陸する野蛮人たちをシンオウの野蛮人たちが迎え撃つ”3日間のお祭り（シンオウのプロモーション企画のひとつ）。コンセプトは“目と目が合ったらポケモンバトル”で、ある程度の実力を前提に、基本的に両者の合意が取れればそのまま街のスタジアムでバトルできる。シンオウのすべての街とバトルフロンティアが舞台のバトルシティのような様相（別名“**シンオウ・ラッシュ**”）。各街の朝同時刻に一斉に開始。協会のHPと街の電光掲示板に、全街のスタジアムの予約状況がリアルタイムで出る（午前の部・午後の部）。初日のクロガネでは、3戦目でルイズ（《宮殿トリステイン》）が東堂に勝ち、4戦目が《探検堂ミラクルズ》（SPは操祈）vs《釜炎ダイナーズ》、5戦目がイッシュの四天王のお嬢様、午前の部のラストがジョウトのジムリーダーvsスペランカー、午前に《クインビーズ》《ファンタジーズ》、午後に《銀河団アンタレス》もエントリー。ウタ主演のドラマの第一話は交流戦3日目に放映（569）。（出典: 569, 571）
