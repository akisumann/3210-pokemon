# エキシビションマッチ（第三節〜）: トバリ杯中規模大会（第三節）

- **トバリ杯中規模大会（第三節）**（501, 503〜518）: 第三節でミラクルズが出た4つ目の大会。会場は“トバリスタジアム”（フィールド効果は、場にいるポケモンのタイプ不一致の「岩」「龍」技1.5倍）。“ギンガ団”のお膝元なので注目度は高い大会になりそう（煉獄、501）。**エキシビションはない**（カズマ（AA内）、504）。505は開催の3日前の対策ミーティング、506で開幕し、開会式のすぐあとに初戦。**ミラクルズが6戦全勝で優勝し、第三節の中規模大会を四連覇した**（518）。
  - **組み合わせと結果**（504〜506、514・517・518の対戦表）: ①《探検堂ミラクルズ》 6勝0敗（優勝）、②《三聖トリニティ》（PC操作） 3勝3敗、③《北鎮ブリゲイド》 1勝5敗、④《百貨店スマッシュ》【H】 1勝5敗、⑤《機鋼アルケミーズ》（PC操作） 4勝2敗、⑥《蒼雷アームドブルー》 1勝5敗、⑦《騎空ヴァーレリア》（PC操作） 5勝1敗（ミラクルズにだけ負けた）。全7チーム。“上位”のチームが3つ出る（綾乃、503）。“上位”3チームはPC操作の②⑤⑦で、505の対策ミーティングでそれぞれの監督と主力が出た。モモは、この3チームに比べるとほかは格落ちだが、油断せず勝ち星を挙げることが大事と言った（505）。
  - **ミラクルズの試合の順**: 1戦目②（507〜509）、2戦目③、3戦目④（どちらも510でダイジェスト）、4戦目⑤（511〜513）、5戦目⑥（514でダイジェスト）、6戦目（決勝）⑦（515〜517）。試合の流れは → [バトル記録](../../../story/battles.md)
  - **②《三聖トリニティ》（監督は聖園ミカ。初戦の相手）**: 「ミカエル」種との混血の『ハーフ』で、『獣化』の「能力」型（509の正式データ: 指示C-／育成B／統率B-／能力A+。SPはアンリエッタ・ド・トリステイン）。固有は『調停を司る聖なる祈り手』（7体目の選手として参戦）と『破壊を導く聖なる閃光』（味方が一番最後に「技能拡張：ようせいほう」による追加行動）。白野いわく「女王蜂並のゴリラ戦法」（505）。スポンサーはリッシ湖・エイチ湖・シンジ湖の3つの湖を守る管理調査団体（ヴィルヘルム、504）。初戦（507〜509）はミラクルズが勝った。System: 方向性は異なれど火力自慢のチーム同士の激突で、パワー＆タクティクスで終始リードした優勝候補が快勝（510）。510では《機鋼アルケミーズ》とも戦い、アルトアイゼンの「パイルバンカー」でミカ本人が『星のヌシ』ごと貫かれた。
  - **③《北鎮ブリゲイド》**: シンオウ北部に拠点を構える古豪の「B」ランカー。「統率」型で、かつて“上位”から陥落したチーム（System、510）。2戦目でミラクルズが勝った（ベルゼブモンが序盤からデータを抜き、大火力の「必中」でペースを渡さなかった。現在の力以上に、チームとしての勢いが差になった。System、510）。監督の名前は出ていない。
  - **④《百貨店スマッシュ》【H】**: 羽咲綾乃のトバリ・デパートの二軍（「B」中位）。3戦目でミラクルズが勝った（「A」ランカーの一軍も客席にいる中、ロトムが「指示」の差だけでは埋め切れないほど相手の動きを阻害した。後半、ロトムが『二枚看板』の帝督に落とされたが、後続の追撃を抑えきれなかった。System、510）。514では、ミーナの解析とディアウス・ピターの「サンダープリズン」で《騎空ヴァーレリア》に敗れた（綾乃「化け物、どもめ」）。
  - **⑤《機鋼アルケミーズ》（監督はエドワード・エルリック）**: 「はがね」のジムの元門下生で、「育成：AA-」の「育成」型（513の正式データ: 指示B-／育成AA-／統率C／能力C+。SPは立花・誾、サポート効果《吼えろ、鋼鉄の十字砲》（味方が「技能拡張」で繰り出す技1.2倍））。
    - 固有『磨き抜かれた機鋼の鉄拳』（PT全員が「技能拡張：バレットパンチ」）。
    - 「-」要素のせいか『PT』を持たない（白野505、カズマ510）。
    - “上位”の「育成：AA-」のチームで、「指示」はミラクルズと互角、推定レベル「155～165」で今大会で一番上（白野・カズマ、510）。
    - 下馬評はミラクルズが完全に上（天花、510）。
    - 513の正式データの6体: 『不動のエース』ゴルドリーオ（Lv165。「ゴルドリーオ」種の『固有種』、はがね/エスパー）、『アヴェンジャー』ハッサム（Lv165）、『エースキラーβ』ビスマルク（Lv160。「艦娘」）、『ベテラン』アルトアイゼン（Lv160。「ゲシュペンスト」の『金冠サイズ』、悪癖『パイル中毒』）、『エースアシストβ』リズベット（Lv155。人間と「ドワーフ」の『ハーフ』）、先発（『硬化』）のシールドライガー（Lv155）。
    - 『ベテラン』以外は全員『極』を持つ（白野、510）。
    - 513の図鑑でもそのとおりで、『ベテラン』以外は種属4つ（『第四階梯』）。
    - 「はがね」持ちが多い（510）。
    - 4戦目（511〜513）でミラクルズが勝った（System: 序盤から激しい激突になったが、『原始天賦』たちが主導権を完全に引き寄せた、514）。
    - スポンサーはミオシティの鉄鋼系の大手企業（絶奈、504）。
    - エドは“女王蜂”（操祈）に負けたことがある（511のエド「あの“女王蜂”にやられた分は」）。
  - **⑥《蒼雷アームドブルー》**: 監督はレヴィの先輩でもあるナギサジムの元門下生（名前は出ていない）で、「指示」型。「モンハン」をも従える高水準な「統率」も併せ持つ（System、514）。5戦目でミラクルズが勝った（「統率」の本領であるチームのパワーで押しつぶし、マックイーンが主力を殲滅した。System、514）。
  - **⑦《騎空ヴァーレリア》（監督はモニカ・ヴァイスヴィント。決勝の相手）**: 「B」で最高位の「統率」型で、「B」の「統率」型チームの現最高峰（奏、514）（517の正式データ: 指示C／育成C+／統率AA／能力B。SPはジョニー、サポート効果《青空を翔ける伊達な快賊》（『エキスパンション（飛）』を付与された味方が相手の「避/命中」の上昇を無視））。
    - 固有『統制された疾風の翼』（味方の『役割』の発動時、T終了時まで味方の「飛」技の優先度+1）と、『PT』2つ（『ヴィントシュナイデン』『スカイコマンド』）。
    - 推定レベル「150～160」でミラクルズと五分からやや下（天花、514）。
    - 主力は『エース』アイズ・ヴァレンシュタイン（Lv160）、『二枚看板』バハムート（Lv155。『高地のヌシ』）、『エンペラー』ディアウス・ピター（Lv155。「ヴァジュラ」種の頂点の『天賦の才』。505では「アラガミ」の「ヴァジュラ」の『天賦の才』とだけ出ていた）で、『第四階梯』は『エース』と『エンペラー』だけ（ライザ、514）。
    - ほかは『アヴェンジャー』バスター・ブレイダー（Lv150）、『スカウター』ミーナ・ディートリンデ・ヴィルケ（Lv155。「ウィッチーズ」種で『絆』持ち）、『トップバッター』アカムトルム（Lv150。ホウエンの「えんとつ山」「深度：3」の元『ヌシ』）。
    - 主力が「ひこう」に偏るが統一ではない（カズマ、514）。
    - 決勝（515〜517）でミラクルズが勝ち、マックイーンの特性「まけんき」が『エンペラー』の天敵になった（517）。
    - 作者: 安定感は相当高く「B」トップクラスに恥じないが、相性や爆発力で突破してくる一部の相手に押しつぶされることがある（パワー負けするとキツイ）（517）。
    - 作者: モニカはナギサで先輩に勝ったあと、エネルにほぼカズマ戦のような神のメンツでやられた（514）。
    - スポンサーはコトブキの航空会社（ヴィルヘルム、504）。
  - **観客**: 506では、トバリの「A」ランカーの李牧（《百貨店キングダム》の監督）とコーネリア（ジュピター）が並んで初戦を観戦した。510ではカイト（サターン）も、トバリの鏑木（虎徹）と一緒に観戦していたと言い、「A」のチームの関係者も何人か（監督本人はまだ）、カズマの同期を含む「B」のチームの監督も数名見かけ、注目度は随一だと言った。コーネリアは、時間があれば“四天王”も誰か来ているかもと言った（510）。514では奏・直哉・ダージリン、518ではエレン・羅刹・ゼットン・さみだれ・アカネが会場で話していた。
  - **優勝の意味**（517〜519）: 中規模大会を四連覇し、名実ともに「B」の「統率」の頂きに立った（System、518）。カズマ「貰って行くぜ？「B」の最高峰の「統率」型の看板……まっ、すぐに返上するつもりだけどな」（517）。「A」昇格の一番乗りは、公的な発表こそまだだが疑う者はいない（羅刹、518）。→ 昇格は [pro-league.md](../../pro-league.md) の「昇格」。第三節の最後の大会（5つ目）はコトブキ（System、518）。
