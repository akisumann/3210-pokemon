# ジョウト地方: アサギシティの“**アサギの灯台**”にはチームがあり、ジョウトの「B」ランカー（レヴィの話）

↑ [ジョウト地方](../../regions.md#ジョウト地方)

- アサギシティの“**アサギの灯台**”にはチームがあり、ジョウトの「B」ランカー（レヴィの話）。491では、そのチームの人がナギサシティの“シルベの灯台”に来ていて、レヴィがジム戦のことを自慢すると「10日くらいしたらまた来るから、よかったら戦ってみたい！」と言い、カズマが練習試合を即オッケーした。灯台どうし、なんか繋がりがあるらしい（レヴィ（AA内）。“シルベの灯台”は《灯台サンセット》のスポンサー）。作者の書き込みでは、アサギはミカンがジムリーダーをしているジョウトの街（美柑とのダブル・ミーニング）。（出典: 491）
  - チーム名は《**灯台カレイドスコープ**》（カズマ、492）。「能力」型らしい。監督は名家の跡取りのお嬢様（カズマが聞いた話）。レヴィからの情報（カズマの話）では、手持ちと2人で電子機器が苦手なせいで灯台の電力を全部落として大パニックにしたり、その借金を返そうと『エース』と結託して手持ちの身体の宝石をパクろうとしたりした。好きなものは宝石。練習試合は《ナギサスタジアム》でやる予定（492）。『エース』は「赤ずきん」種の『天賦』（レヴィのメール、493）。それ以外のデータはなく、ノーデータでのバトルになる。シンオウ最強のジムリーダーを倒したと聞いて練習試合を申し込んでくるくらいなので、ジョウトの「B」ランカーの中では上澄みだろう（モモ）。System の表示では「「能力」型のチームらしいが、まず“上位”級と見ていいだろう」（493）。（出典: 492, 493）
  - **練習試合**（495〜499、《ナギサスタジアム》）: 監督は**遠坂凛**（指示B-／育成C／統率A（B）／能力A+。499の正式データ）、SPは星野瑠美衣。ノーデータからの「6-6」で、序盤は押されたが、カズマのガッシュの1体残しの勝ち（499）。賭けは、遠坂が勝てば“たんけんセット”を9割引き、カズマが勝てば景品の技マシン「キングシールド」（遠坂がラジオ塔のクジで当てたもの。遠坂「超レア」）をもらう代わりに7割引きで販売（495。遠坂の値切り）。作者いわく、遠坂はジョウトの「B」でも屈指の強さで、別地方でも相当なタマ。ただ選手のパワーはカズマに及ばない（496, 499）。手持ちは → [hp-estimates.md](../../hp-estimates-3.md#灯台カレイドスコープ遠坂凛499の公開データ練習試合) と [others-b.md](../../../characters/trainers/others-b-13.md#遠坂凛灯台カレイドスコープの監督ジョウトのbランカー)。（出典: 495, 496, 499）
  - **ジョウトの話**（495, 498）: コガネシティでは値切りが挨拶みたいなもの（遠坂）で、「地下通路」などはまさに戦場（ミホノブルボン）。遠坂はコガネのゲームコーナーに苦い思い出があるらしい（遠坂（AA内）「コガネのゲームコーナー、うっ頭が……っ」）。“スズの塔”の「異界」で目撃情報のあるポケモンが「ガッシュ」ではないかという都市伝説がある（遠坂、495・498）。（出典: 495, 496, 498）
