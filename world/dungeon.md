# ダンジョン

## 基本

- **野生ポケモンがすみかにしている自然の領域**。（出典: 006）
- 入口から「**1層**」「**2層**」「**3層**」…と奥へ進んでいく。この層の深さを「**深度**」と呼ぶ（「深度：1」など）。（出典: 004, 006）
- **奥に行くほど強いポケモンがいる**。1層なら、ガッシュたちとほとんど変わらない強さのポケモンばかり。（出典: 006）
- 最深部が何層かは、ダンジョンの大きさによって違う。深度4は、テンガン山以外のダンジョンなら最深部。（出典: 006, 008）
- 抜け道: ダンジョンには、浅い層から深い層へ直通の隠れた場所がある → [根拠](dungeon/根拠/001_基本_抜け道.md)
- “隠れ里”（ダンジョンに属さない野生ポケモンの集落）: 人界にもダンジョンにも属さない、野生ポケモンの集落 → [根拠](dungeon/根拠/002_基本_“隠れ里”ダンジョンに属.md)
- 「ポケモン図鑑」には、間違って奥のフロアに行こうとするとアラートが鳴る機能がある（凛「大丈夫でしょ、メイビー」）。（出典: 006）
- 奥では命の危険もある（凛「『1層』だし死にゃしないでしょうけど」「ポケモンは危険な生き物なのよ」）。（出典: 006）
- **2層以降**には、その層を支配する集団「**群れ**」がいる。群れはその層で最強の連中。**1層には群れはいない**。（出典: 008）
- 群れを統括し、そのエリアを支配するボスが『**ヌシ**』。テンガン山の深度4のヌシが「テンガンのヌシ」（メリュジーヌ）。群れもヌシも、奥の層ほど強い。（出典: 006, 008）
- ヌシには「代」があり、敗北や下剋上で交代する（テンガンの先代はアシュロン） → [根拠](dungeon/根拠/003_基本_ヌシには代がある.md)
- ヌシは、ポテンシャルの効果で「《異界/テンガン山》」のようなフィールドを展開できる → [根拠](dungeon/根拠/004_基本_ヌシはポテンシャルの効果.md)
- テンガン山の1層に出るのは、ゴルバット、イワーク、イシツブテ、ゴーリキーなど、レベル20くらいまでの野生ポケモン。敵性種のオウガテイルも出る。（出典: 007）
- アカネは、ポケモンリーグで負けた八つ当たりにダンジョンの奥で戦っていた。トレーナーにとっては腕試しやストレス発散の場にもなっている。（出典: 000）
- 『ヌシ』の力（ヌシポテンシャル）は、今その土地のヌシとして生きている個体だけのものではない → [根拠](dungeon/根拠/005_基本_ヌシの力ヌシポテンシャル.md)
- 疑似的な『ヌシ』: 親玉でなくても一部の『ヌシ』ポテンシャルは付けられる → [根拠](dungeon/根拠/006_基本_疑似的なヌシ.md)
- アローラのダンジョン「**ヴェラ火山**」: 天花の元手持ちのグレンラガンが「深度：2」の『ヌシ』（『火山のヌシ』）だった。（出典: 149）
- 『ヌシの特権』: 深度3のヌシは全員持っている（「体」の種族値が少し上がる） → [根拠](dungeon/根拠/007_基本_ヌシの特権.md)
- 廃墟から生まれるダンジョンもある（アローラの“スーパー・メやす”） → [根拠](dungeon/根拠/008_基本_廃墟から生まれるダンジョ.md)

## ダンジョンの環境とタイプ

- ダンジョンの環境で、住むポケモンのタイプにはある程度の傾向がある → [根拠](dungeon/根拠/009_ダンジョンの環境とタイプ_ダンジョンの環境で住むポ.md)
- 凛の挙げた、カズマの手持ちにまだいないタイプの『ヌシ』の候補地: 「ほのお」ならハードマウンテン、「むし」ならハクタイの森、「はがね」ならこうてつ島。（出典: 130）

## 深度ごとの強さ

| 深度 | 群れ | 強さの目安 | 特徴 |
| --- | --- | --- | --- |
| 1層 | いない | ガッシュたちと同じくらい | 1体ずつ出てくる |
| 2層 | 3体（ヌシを含む） | Cランカーがある程度準備すれば踏破は難しくない | ヌシの強さはピンキリ（イカルガは他でも通用する強さ、ハイランダー談） |
| 3層 | 6体 | **Bランク相当** | レベルはハイランダー（Lv60〜70）以上、ポテンシャルもそれより多く、全員『野生』。フィールド効果は野生有利の完全アウェー。詳しいルールは下の「深度：3」の群れのルール（218）。今の《クインビーズ》でも返り討ちの可能性が高い |
| 4層（異界） | ― | 深度3からさらに跳ね上がる。攻略できれば地方屈指の実力者 | ヌシは有利なフィールドを展開する力、「**おうぎ**」と呼ばれる桁違いの大技、『野生』を失ってもなお残る「皇帝」のような威厳を持つ。異界のヌシは統率型でなければ率いられない。詳しくは下の「異界」 |

（出典: 052, 063）
- ランクの目安は「C」≒深度2、「B」≒深度3、「A」上位≒深度4 → [根拠](dungeon/根拠/010_深度ごとの強さ_ランクとの目安.md)
- 「深度：2」と「深度：3」はまったく別物。今のミラクルズでは深度3に手も足も出ないはずで、挑むのはB昇格後にある程度勝てるようになってから（凛談）。（出典: 130）
- 深度3はBランク相当なので、Cランクの間は挑まない。深度4はAランクから → [根拠](dungeon/根拠/011_深度ごとの強さ_深度3は適性レベルがBラ.md)
- 深度3に挑む目安: 協会の見解ではバッジ5つ → [根拠](dungeon/根拠/012_深度ごとの強さ_深度3に挑む目安.md)
- 「3層」の『ヌシ』は全員『第三階梯』持ちで、捕まえれば「B」の即戦力 → [根拠](dungeon/根拠/013_深度ごとの強さ_3層のヌシは全員が第三階.md)
- 「深度：3」の『ヌシ』は中位でも即戦力級で、「統率」型の実力の指標 → [根拠](dungeon/根拠/014_深度ごとの強さ_深度：3のヌシの重み.md)
- 率いる群れ（ヌシ）の数はそのまま強さにつながる。ただしCランクのうちに無理にヌシを集めるのは非効率、という考え方もある。（出典: 063）
- **危なさの感覚**: ダンジョンは深度1の時点で、中で死んでも自己責任のレベル。オウガテイル（アラガミ）に食い殺されても「そんなもん」で済まされる（補足: ユーザーより）。

## 1層と2層以降の違い

| 項目 | 1層 | 2層以降 |
| --- | --- | --- |
| レベル | 低い | 高い（ノモセだいしつげん深度2でLv30〜35） |
| 相手の数 | 1体ずつ | 「群れ」で出てくる（ノモセ深度2は3体） |
| ポテンシャル | なし | 群れのメンバーは『野生ポケモン』（場に出ると任意の能力2段階アップ）、ヌシは『野生の親玉』（全能力2段階アップ）とダンジョン専用の『〇〇のヌシ』を持つ |
| ボス | いない | 『ヌシ』 |

（出典: 034, 035）
- 野生の群れは、ヌシが率いていても野生ポケモンの集まりなので、極端なシナジーはなく好き勝手に動く。そこが勝機（エール談）。（出典: 034）
- 野生の世界はアウェーで、人間のレギュレーション（『役割』の重複禁止など）は関係ない。（出典: 034）
- ダンジョン出身のヌシを従えるには、統率B以上が必要と言われている。ヌシは群れの長としてのプライドがある。（出典: 036）
- ヌシが人間の手持ちになると『野生』（『野生の親玉』）は消える。（出典: 036, 037） 理由は下の「異界」の「野生の力はダンジョンから供給されるエネルギー」（337）。

## ダンジョンアタック

- ダンジョンの層に挑んで突破を目指すこと。「2層を突破したことがある」というのはスポンサーへのアピール材料になる。失敗しても、挑んだ経験は評価される。（出典: 031）
- 統率型のトレーナーなら、2層の群れのボスであるヌシを仲間にできる可能性もある。（出典: 031）
- ケガの危険はゼロではない。（出典: 031）
- 34〜35話でノモセだいしつげん深度2を攻略、232でハクタイの森深度3も攻略 → [根拠](dungeon/根拠/015_ダンジョンアタック_第34〜35話カズマ一行.md)

### 野生の掟と「協定」（225。シア、ブラン、アシリパの説明）

- ダンジョンアタックは**自己責任**が鉄則。スポンサーで推奨するところは少数で、「統率」型以外は挑まないところも多い。それでも挑む者は止められない。（出典: 225）
- 「3層」はヌシ以外もジムリーダー（5つ目）並み。強さはシアと同じか少し下 → [根拠](dungeon/根拠/016_野生の掟と協定225シア_3層の連中はヌシは確定で.md)
- 「5つ目のジムリーダー並み」には、フィールドや乱戦などの環境の落差も込み → [根拠](dungeon/根拠/017_野生の掟と協定225シア_バッジ5つ目のジムリーダ.md)
- 野生の掟: こちらが正々堂々としていれば、向こうも無法極まりないことはしてこない → [根拠](dungeon/根拠/018_野生の掟と協定225シア_野生の掟.md)
- 掟を踏みにじる者: 「統率」が低いのに群れを倒して売ろうとし、やられた者たち → [根拠](dungeon/根拠/019_野生の掟と協定225シア_掟を踏みにじる者統率が低.md)
- 大昔、ポケモンと人間の関係を''人間の支配''と言い切って解放活動をしていた団体がどこかの地方にあった（シア。推測: 原作のプラズマ団）。（出典: 225）
- 一番弱いダンジョンの『ヌシ』はイカルガ（ノモセだいしつげん）だった（ライナー）。（出典: 225）

## 「深度：3」の群れのルール

218で凛がカズマとライザに説明した、「深度：3」の群れ（野生のレギュレーション）。（出典: 218）
- 群れは**6体**。この時点で「深度：2」とは大きく変わる。
- **フィールド効果**が発生する。ダンジョンは相手のホームで、『野生』に有利。ハクタイの森は《ハクタイの森》: 「3」倍数Tの終了時、場にいる『野生』ポケモンは相手の体力を1/8ドレインする。
- 『野生の親玉』『野生ポケモン』は「深度：2」と同じ。トレーナーではないのでステータスはなく、「指示」のランク補正もない（カズマ）。『野生の親玉』は『エース』ではない（ライザ）。
- 人間の「B」からの『付随』と同じで、全員が『野生の親玉』『野生ポケモン』の付随の『**闘争本能**』（野生の時、低確率で相手の攻撃技を無効化する）を持つ。
- 『ヌシ』は『ヌシの号令』（能力2倍）と『ヌシの勅命』（回避）を深度の数だけ使う → [根拠](dungeon/根拠/020_深度：3の群れのルール_ヌシは野生版の指令を使う.md)
- 『固有』と『専用』の野生版もある → [根拠](dungeon/根拠/021_深度：3の群れのルール_固有と専用の野生版もある.md)
- SPに当たるものはない（ライザ）。
- 「深度：3」の群れに属さないポケモンは、練度も強さも劣る → [根拠](dungeon/根拠/022_深度：3の群れのルール_深度：3の群れに属さない.md)
- ダンジョン次第では「深度：3」が最深部。「B」ランク中位以上でも、相性や状況次第で負けることはざらにある。ダンジョンアタックをしないチームが多いのは、こういう野生の強さを危惧してのこと（凛）。

### 群れとの戦い方（230。先代とオシュトルの助言）

- ダンジョンアタックに必勝法はない。群れのレベルは95〜100、群れ以外は80前後と仮定（先代）。その差を理解せず奥に突っ込むバカが痛い目を見る。
- 群れの周りのポケモンは基本手を出してこないが、バトル中は囲まれるので、出ないメンバーは警戒役として外に出しておく。ダンジョンアタックはまず「6vs6」になる（オシュトル）。
- 『号令』『勅命』は『四式』『六令』より上。『号令』は『全開攻撃』3回分にもなる → [根拠](dungeon/根拠/023_群れとの戦い方230先代_ヌシの号令ヌシの勅命は四.md)
- 『指令』を出すのはあくまで『ヌシ』で、『ヌシ』が瀕死になっても使ってくる → [根拠](dungeon/根拠/024_群れとの戦い方230先代_指令を出すのはあくまでヌ.md)
- 負ければ軍門に降るのは、野生のルールに身を委ねて守っているから（どうしてそうなるかは未解明） → [根拠](dungeon/根拠/025_群れとの戦い方230先代_負ければ軍門に降るのは野.md)

## 「異界」（深度4）

- アカネは「『異界』クラス」と呼び、Systemは「''異界''とも言える深い深いエリア」と書いている。（出典: 000, 001）
- カズマが落ちてきたのは、テンガン山の深度4（メリュジーヌのいる層） → [根拠](dungeon/根拠/034_異界深度4_カズマが落ちてきた場所は.md)
- アカネが000で倒したクシャルダオラは、深度4の「群れ」ですらない雑兵 → [根拠](dungeon/根拠/035_異界深度4_アカネが000で倒したク.md)
- メリュジーヌは自分を「異界のヌシ」と呼んでいて、深度4が「異界」にあたることがわかる。（出典: 007）
- 深度4は通称「異界」 → [根拠](dungeon/根拠/036_異界深度4_深度4は通称異界.md)
- 異界のヌシは、ダンジョンの外でも戦場を自分の領地に塗り替えられる → [根拠](dungeon/根拠/037_異界深度4_異界のヌシは自分のダンジ.md)
- 異界は深度3までより段違い（凶悪なフィールド、全員『専用』並み、「おうぎ」） → [根拠](dungeon/根拠/038_異界深度4_異界の難しさ.md)

- 『異界のヌシ』は全員、「威力：200」の単発技「おうぎ」を持つ → [根拠](dungeon/根拠/045_異界の力_おうぎ.md)

- 『異界のヌシ』は『王者の特権』と、『王冠』か『玉座』のどちらかを必ず持つ → [根拠](dungeon/根拠/048_異界の力_異界のヌシの標準装備.md)
- 《異界/テンガン山》のフィールド効果: 『野生』『ヌシ』が受ける「岩」「氷」技のダメージを半減する → [根拠](dungeon/根拠/049_異界の力_《異界テンガン山》のフィ.md)
- 《異界/もどりの洞窟》: 『野生』『ヌシ』の受ける「霊」技を半減し、通常交代以外の交代を封じる → [根拠](dungeon/根拠/050_異界の力_《異界もどりの洞窟》のフ.md)
- 異界の展開は隔離ではなく、外から救援に入れる。ヌシが怖いのは本拠地 → [根拠](dungeon/根拠/051_異界の力_異界の展開とヌシの脅威.md)
- メリュジーヌは群れを外に待たせて「深度：1」に降り、フィールドを展開した → [根拠](dungeon/根拠/052_異界の力_異界のヌシが浅い階層に降.md)
- 野生の力はダンジョンから供給されるエネルギーで、離れると維持できない → [根拠](dungeon/根拠/053_異界の力_野生の力はダンジョンから.md)

## 深度5

- シンオウの深度5は、霊峰テンガン山のてっぺんにあると言われる。「神様」がいるらしいが、姿を見た者はだれもおらず、足を踏み入れたという話も聞かない。この地方の「極点」。（直哉談）（出典: 099）
- ジョウトのシロガネ山にも深度5があるのは事実（「地獄につながっている」とも言われた）。（出典: 099）
- 現実的にトレーナーがたどり着けるのは4層まで。4層のヌシですら「皇帝」と呼ばれる格なので、その奥に本当に「神様」がいてもおかしくない。（出典: 099）
- 推測: テンガン山の深度5の「神様」は、カズマを転生させたアルセウスかもしれない。
- カントーの''ハナダの洞窟''（終局封鎖異界、''地獄の穴''）も、ジョウトの''シロガネ山''と並ぶ「深度：5」を持つ（真冬）。（出典: 278）
- 3つの極点: ハナダの洞窟、シロガネ山、テンガン山（どれも深度5は前人未踏） → [根拠](dungeon/根拠/063_深度5_3つの極点.md)
- テンガン山の深度5を多少知るのはアダムくらい。事実上の頂点はメリュジーヌ → [根拠](dungeon/根拠/064_深度5_テンガン山の深度：5のヌ.md)
- ほかの地方の深度5の有名所は、ホウエンのかいてい洞窟とアローラのポニの大峡谷 → [根拠](dungeon/根拠/065_深度5_ほかの地方の深度：5の有.md)
- パルデアの''エリアゼロ''は「深度：4」のさらに奥があり、''過去や未来につながっている''という言い伝えがある（ホシノ、クロロ）。（出典: 389）

## 地下大洞窟の空間

- 地下大洞窟は、ポケモンを育成するための広い空間としても使える（カズマたちの育成場所）。（出典: 037）
- 072で、地下大洞窟をマックイーンを追いかけて長い距離を移動したあと、たんけんセットで地上に戻ると、ハクタイではなくシンオウ最北端のキッサキシティに出た。（出典: 072）
- シアの仮説は「たんけんセットの未知の仕様」か「地下は距離や空間が違う」か → [根拠](dungeon/根拠/077_地下大洞窟の空間_シアの仮説は2つ.md)
- ナナカマド博士やスクールの校長がたんけんセットに興味津々だったのは、このことに気づいていたからでは、とカズマは考えた。（出典: 072）
- 調査の結果、地下大洞窟は「新種のダンジョンに類するもの」と認定される見込み → [根拠](dungeon/根拠/078_地下大洞窟の空間_調査結果.md)
- オーナーは、GPS（発信器）と歪みの警報をつけた**新型たんけんセット**を一晩で作った。位置データは協会と共有する（マッピングと事故対応のため）。（出典: 094）
- 調査結果は参加組織の連名で各街に報告され、キッサキ以外の街からも問い合わせが殺到している。（出典: 094）
- 調査の現状: 一地方に匹敵する広さと思われる（エール） → [根拠](dungeon/根拠/079_地下大洞窟の空間_調査の現状.md)
- “メルキド”: ハクタイシティ近郊の地下大洞窟にある地下探索拠点の通称 → [根拠](dungeon/根拠/080_地下大洞窟の空間_“メルキド”.md)
- ビルダー: たんけんセットを使いこなして地下で物を作る人たち。初代はオーナー → [根拠](dungeon/根拠/081_地下大洞窟の空間_ビルダービルダーズ.md)
- 資源の扱い: オーナーは「地下は皆のモノ」と考え、闇雲な持ち帰りを是としない → [根拠](dungeon/根拠/082_地下大洞窟の空間_資源の扱い.md)
- 発掘: 掘ると何か出やすい区画があり、「グラシデアのはな」の瓶などが出た → [根拠](dungeon/根拠/083_地下大洞窟の空間_発掘.md)
- ギンガ団も時間や空間を研究していて、ジュピターやマーズは「わざマシン：いじげんホール」を持っている。カズマもお詫びに1つもらった。（出典: 083）
- 推測: 空間の伝説は、空間を司るパルキアのことかもしれない。
