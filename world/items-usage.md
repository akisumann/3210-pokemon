# 持ち物の使われ方

作中の持ち物が、どのくらい使われているかの集計。カズマのチームはこだわりのある使い方（イカルガの「かえんだま」、マックイーンの「まっさらプレート」など）が多く、混ぜると全体の傾向が見えにくいので、**相手チーム（カズマ以外）**と**カズマのチーム**を分けている（ユーザーの希望）。持ち物の効果は [バトルの細かい仕様](battle-rules.md#持ち物)。

## 数え方

- 相手チーム: 図鑑・公開データの持ち物を、ポケモンと持ち物の組ごとに1回と数えた → [根拠](items-usage/根拠/001_数え方_相手チーム原典の図鑑・公.md)
- カズマのチーム: 【戦闘前準備】の持ち物を試合ごとに数えた（65試合） → [根拠](items-usage/根拠/002_数え方_カズマのチーム試合前の【.md)
- カズマのチームで入っていない試合: 準備の記載がない試合と、ダイジェストの試合 → [根拠](items-usage/根拠/003_数え方_カズマのチームで入ってい.md)
- 機械的に数えたもので、「C」期は159話まで、「B」期は160話から（推測の目安） → [根拠](items-usage/根拠/004_数え方_機械的に数えたものでC期.md)

## 読むときの注意

- 原典の言及回数で見ると、プレートの半分以上は「まっさらプレート」（ほぼマックイーン一体）、かえんだまは旧イカルガ。「世界の定番」と「一体の癖」は分けて扱う（上の2つの表を分けたのはそのため）。
- 満タン時に一発を防ぐ系（きあいのタスキ、ボコのみ、マジュのみ）は「C」期から「B」期で大きく増え、いのちのたまは減っている。
- カズマのチーム: 「B」期はハチマキ・オボンが減り、だっしゅつパックやスカーフが増えた → [根拠](items-usage/根拠/005_読むときの注意_カズマのチームのC期とB.md)
- こだわり系が少ない理由: ほかに1.5倍の手段が多く、代償が目立つ（補足: ユーザーより） → [根拠](items-usage/根拠/006_読むときの注意_こだわり系が少ない理由.md)
