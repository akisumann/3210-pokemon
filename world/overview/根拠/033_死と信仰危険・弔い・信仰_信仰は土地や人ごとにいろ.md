# 死と信仰（危険・弔い・信仰）: 信仰は土地や人ごとにいろいろある

↑ [死と信仰（危険・弔い・信仰）](../../overview.md#死と信仰危険弔い信仰)

- **信仰は土地や人ごとにいろいろある**（補足: ユーザーより）。原作のポケモンの各地方に、それぞれの伝説や神話があるのと同じくらい多様。ほかに、孤児院を持つヨスガの教会があり（出典: 355）、歌は娯楽だけでなく宗教的にも使われる（出典: 355）。自称天使のクロエルが、アルセウスを祀る教会（元の名前は「ムナンチョ・ヘペトナス教会」）を乗っ取って“**グレゴリ教**”にし、勧誘もしている。そこではウタのチャリティソング「めざせ！ポケモンマスター」（featウタ）が歌われている（→ [terms.md](../../terms.md)。出典: 483）。地方ごとの伝説は → [species.md](../../species.md)
