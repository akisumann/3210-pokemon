# くらし（医療・食・通貨・道具）: 技術と文化の差

↑ [くらし（医療・食・通貨・道具）](../../overview.md#くらし医療食通貨道具)

- **技術と文化の差**（355の地の文）: ポケモンに関わる技術（ポケモンボックスなど）以外はそこまで重視されず、カズマの元の世界と比べて遅れている部分が多い。記録媒体はいまだにカセットが現役（フォーゼの専用もカセットが条件）。アニメやCGより、生のポケモンがいる分、特撮の人気が高い。シンオウはクルマも少なく、街の間の移動手段としても使いにくい。カズマは半年以上たってもわからないことだらけで、「そんなもんか」と受け止めて過ごしている。
