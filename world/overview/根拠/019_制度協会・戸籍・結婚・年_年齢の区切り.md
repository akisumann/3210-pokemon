# 制度（協会・戸籍・結婚・年齢）: 年齢の区切り

↑ [制度（協会・戸籍・結婚・年齢）](../../overview.md#制度協会戸籍結婚年齢)

- **年齢の区切り**: 10歳から旅ができる。そのかわり、ポケモンが起こした悪さの責任はすべてトレーナーが負う（出典: 005）。「10歳から旅」や「お酒とタバコは二十歳から」（出典: 082）のような区切りは、人間の育ち方に合わせたもの。それすら絶対の境界ではなく、「このポケモンはこのくらいの時期に、このくらいの餌を与えましょう」と同じ種類の**目安のラベル**と考えられる（補足: ユーザーより）。ポケモンにはそうした年齢の制限はないと考えられる（補足: ユーザーより）。お酒の規制のゆるさは → 下の「くらし」の「お酒」
  - たとえばヤマトは、タマゴから一人で生まれて旅をしていたが、仲間になった時はおそらく0歳で、今も1歳くらい（補足: ユーザーより）。それでも企業（探検堂）に入って給金をもらい、プロの選手として働いている。ポケモンが働くことに年齢の制限はかからない（補足: ユーザーより）。（出典: 052, 300, 309）→ 根拠は [yamato.md](../../../characters/pokemon/yamato.md) の概要
  - 人間とポケモンの『ハーフ』でも、人として育てられたなら、おおむね人として扱われると考えられる（補足: ユーザーより）。
  - **ポケモンは早熟**（補足: ユーザーより）: ポケモンは野生で生まれて野生で生きる必要があるので、生まれてから色々できるようになるまでが速くないといけない（草食動物が生まれた時から多少立てるように）。歩くだけでなく、餌を取る、危険から逃げる、技を使う、意思疎通する、群れのルールを覚える、といった力も早く立ち上がると考えられる（推測）。0歳で一人旅をしていたヤマトも、ポケモンの基準ではそれほどおかしくない。
  - **人間の平均も早熟になっていった**（補足: ユーザーより）: ポケモンとの混血が長い年月で進むうちに、人間の平均も早熟になっていったと思われる。そう考えると、原作由来の「10歳から旅」も自然で、この世界の10歳の体力・判断力・自立性は、現実の10歳とは違う可能性がある。それでも「10歳＝成人」ではなく、「この辺まで育てば、だいたい一人旅を任せられる」という目安（推測）。
