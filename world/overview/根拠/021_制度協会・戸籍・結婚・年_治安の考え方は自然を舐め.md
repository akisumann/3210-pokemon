# 制度（協会・戸籍・結婚・年齢）: 治安の考え方は「自然を舐めてはいけない」

↑ [制度（協会・戸籍・結婚・年齢）](../../overview.md#制度協会戸籍結婚年齢)

- **治安の考え方は「自然を舐めてはいけない」**（補足: ユーザーより）。人の犯罪を取り締まる仕組み（ジュンサーさん、国際警察）はあるが（出典: 044, 082, 168, 238）、安全の基本は、自然（野生のポケモン、ダンジョン、ヌシ）を甘く見ないこと。野生の危なさは一般の人には熊くらいで、ダンジョンで死んでも自己責任（→ 下の「死と信仰」）。
  - **国際警察**がある。エージェントはコードネームで呼ばれる（ハンサム、おいろけ、キンニクなど）。ジュンサーさん（警察）もいる。（出典: 044）国がないのに「国際」と付くのは、国があった頃の名残の言葉かもしれない（補足: ユーザーより。→ 上の「制度」）。
  - もちろん、**ポケモンを使った犯罪もいる**（補足: ユーザーより）。そのため、店や施設は自前で対策をとっていて、その対策は相当に多種多様で充実していると思われる（補足: ユーザーより）。
    - 例: サントアンヌ号のカジノは、ポケモンの力を使ったイカサマを封じている。ロトムの通信機能は制限され、カードや用具にはすべて''解析無効''がかかっていた。「そこらの裏カジノ」とは違い、悪評が立てば船全体に響くので、あくどいイカサマは許さない。カズマの運気を分ける『固有』で勝ちまくった後には、「きょううん」禁止の張り紙を貼るか会議があった（出典: 289）。
    - 裏を返せば、そうした対策のない「裏カジノ」もあるらしい（出典: 289）。
