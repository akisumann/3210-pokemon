# くらし（医療・食・通貨・道具）: お酒

↑ [くらし（医療・食・通貨・道具）](../../overview.md#くらし医療食通貨道具)

- **お酒**（391）: どの地方でも、大昔には10才でポケモンを持って旅に出る許可が下りたらしく、その歴史から一人前と見なされる基準が早く、シンオウでもお酒の規制は割とユルい（さすがに1桁の子に飲ませるのはNG）。人間よりポケモンの方がアルコールに強い傾向があるらしい（平均値の話）。バトルフィールドにお酒を持ち込むのはごく一部のトレーナーやポケモンだけ。ミラクルズでは、オーナーもライザもほとんど飲まない（ライザはジュース派）。アローラのお酒は度数の高い蒸留酒もある（天花のおすすめは5%から96%まで）。（出典: 391）
