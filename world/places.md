# 地名・施設

| 名称 | 内容 | 出典 |
| --- | --- | --- |
| シンオウ地方 | 物語の舞台。アルセウスの「お膝元」 | 000, 001 |
| テンガン山 | 霊峰。シンオウを東西に分ける。クロガネとヨスガを行き来するには必ず通る。ハクタイシティの東。シンオウ最大のダンジョンで、シンオウで唯一の深度5がある。雪山。カズマが落ちてきた場所（深度4） | 000, 001, 006 |
| ギンガハクタイビル | ギンガ団のビル。医務室があり、カズマはそこで目を覚ました | 001 |
| アカネのマンション | 幹部らしい良いマンション。物置部屋があり、カズマの寝床になった。カズマが来るまでは足の踏み場もないほど散らかっていた | 001 |
| 八大地方 | 世界の主要な八つの地方。シンオウもその一つ | 002 |
| カントー地方 | 「はじまりの地方」。八大地方の筆頭 | 002 |
| ハクタイシティ | 「昔を今に繋ぐ街」。東西を巨大なダンジョン（テンガン山とハクタイの森）に挟まれている。凜の自宅がある。ギンガハクタイビルとハクタイジムがある。ガッシュが遊んでいた街 | 001, 002 |
| ハクタイジム | くさタイプのジム。ジムリーダーは渋谷凜。大きな試合場があり、門下生がいる。カズマがお試しで通うことになった | 002, 003 |
| ハクタイの森 | ハクタイシティの西に広がるダンジョン。最大深度4。くさ・むしタイプの天国。昼でも薄暗い | 002, 003, 004, 006 |
| 森の洋館 | ハクタイの森のすぐ近くにぽつんと立つ洋館。はるか昔からあるが、誰が建てたかわからない。気味の悪い館として街で有名。ルサルカが住み着いていた | 002, 003, 004 |
| スタジアム | プロリーグの会場。満員の観客が入る | 003 |
| コトブキシティ | シンオウの大都市。トレーナーズスクールがある | 002, 015 |
| 206番道路 | ハクタイシティのすぐ南。自転車でしか走れない「サイクリングロード」が名物。徒歩だとクロガネシティまで1日以上かかる | 010 |
| クロガネシティ | ハクタイシティの南にある炭鉱の街。いわタイプのジム（ジムリーダー: スペランカー）。ファミレスや喫茶店がある。東にテンガン山。カズマが最初のバッジを取った街 | 008, 012, 015, 017 |
| クロガネ炭鉱 | クロガネシティにある炭鉱。ポケモンの化石を掘り当てられる。カズマが日雇いで働いた。たんけんセットの限定的な卸しの契約を結んだ | 015, 016, 018 |
| クロガネシティの博物館 | ポケモンの化石を復元してくれる。ライナーが復元された | 019 |
| クロガネシティの焼き肉屋 | 食べ放題ではない。カズマが払えずに炭鉱送りになった | 018 |
| ソノオタウン | 花畑の街。食蜂操祈のスポンサー（後援会）。「あまいミツ」が特産と思われる | 015, 028 |
| ヨスガシティ | クロガネシティの東。テンガン山を越えた先。ゴーストタイプのジム（ジムリーダー: メアリ・クラリッサ・クリスティ）。名物はポケモンコンテスト。ポケモンだいすきクラブのシンオウ本部がある | 008, 018, 020, 023, 026 |
| ヨスガのコンテスト会場 | ランク別の会場がある（ノーマルランクなど） | 023 |
| ポケモンだいすきクラブ シンオウ本部 | ヨスガシティ。会長はキアラ | 026, 027 |
| ポケモンセンター | 登録トレーナーとポケモンは、ある程度無料で飲食できる | 023 |
| ノモセシティ | ヨスガシティの南東。みずタイプのジム（ジムリーダー: ロビンマスク）。そばにノモセだいしつげん。カズマが3つ目のバッジを取った街 | 008, 031, 032 |
| トバリシティ | ハクタイシティからテンガン山を越えた先にあると思われる（推測）。帰りのルートの候補 | 008 |
| マサゴタウン | ナナカマド博士（シンオウのポケモン研究の第一人者）の研究所がある街。研究所はエールのスポンサー。エールの出身。ハクタイよりクロガネのほうが近い | 009 |
| 地下大洞窟 | シンオウの地下に広がり、地方全域をつなぐ広大な空間。「あなをほる」かたんけんセットがないと行けない。ライザがよく潜っている。ポケモンの育成場所としても使える | 009, 037 |
| 探検堂（ライザの実家の店） | ハクタイシティにある。たんけんセットの店。レンタルとクロガネ炭鉱への卸しで持ち直した。036でプロリーグのスポンサーとして協会に登録し、カズマのスポンサーになった | 009, 016, 018, 036 |
| サイクルショップ | ハクタイシティにある（カズマの推測ではライザの実家だと思われたが違った） | 009 |
| エンジュシティ | ジョウト地方。禪院直哉の実家（名家）がある | 021 |
| 212番道路 | ヨスガシティの南。ノモセシティへ向かうルート。ウラヤマのポケモン屋敷がある | 028 |
| ポケモン屋敷 | ウラヤマの豪邸。門番に挨拶すればたいていのトレーナーは入れる | 028 |
| じまんのうらにわ | ポケモン屋敷の巨大な裏庭。ポケモンたちに開放されていて、古代種も多い。許可を取れば1回につき1匹まで捕まえられる | 028, 029 |
| ノモセだいしつげん | ノモセシティのすぐそばのダンジョン。シンオウで一番弱い | 031, 032 |
| カンナギタウン | ハクタイシティから見てテンガン山の反対側。シンオウチャンピオンの地元 | 005 |
| ガラル地方 | プロトレーナー文化の発祥と言われている | 001 |
| ヒスイ地方 | アルセウスが召喚した者を送り込む先。カズマとは「別の時空」 | 000 |
