# 地名・施設

| 名称 | 内容 | 出典 |
| --- | --- | --- |
| シンオウ地方 | 物語の舞台。アルセウスの「お膝元」 | 000, 001 |
| テンガン山 | 霊峰。シンオウを東西に分ける。ハクタイシティの東。シンオウ最大のダンジョンで、シンオウで唯一の深度5がある。雪山。カズマが落ちてきた場所（深度4） | 000, 001, 006 |
| ギンガハクタイビル | ギンガ団のビル。医務室があり、カズマはそこで目を覚ました | 001 |
| アカネのマンション | 幹部らしい良いマンション。物置部屋があり、カズマの寝床になった。カズマが来るまでは足の踏み場もないほど散らかっていた | 001 |
| 八大地方 | 世界の主要な八つの地方。シンオウもその一つ | 002 |
| カントー地方 | 「はじまりの地方」。八大地方の筆頭 | 002 |
| ハクタイシティ | 「昔を今に繋ぐ街」。東西を巨大なダンジョン（テンガン山とハクタイの森）に挟まれている。凜の自宅がある。ギンガハクタイビルとハクタイジムがある。ガッシュが遊んでいた街 | 001, 002 |
| ハクタイジム | くさタイプのジム。ジムリーダーは渋谷凜。大きな試合場があり、門下生がいる。カズマがお試しで通うことになった | 002, 003 |
| ハクタイの森 | ハクタイシティの西に広がるダンジョン。最大深度4。くさ・むしタイプの天国。昼でも薄暗い | 002, 003, 004, 006 |
| 森の洋館 | ハクタイの森のすぐ近くにぽつんと立つ洋館。はるか昔からあるが、誰が建てたかわからない。気味の悪い館として街で有名。ルサルカが住み着いていた | 002, 003, 004 |
| スタジアム | プロリーグの会場。満員の観客が入る | 003 |
| コトブキシティ | トレーナーズスクールがある | 002 |
| クロガネシティ | ハクタイシティの南にある炭鉱の街。いわタイプのジム（ジムリーダー: スペランカー）。カズマの旅の最初の目的地 | 008 |
| ヨスガシティ | クロガネシティの東。ゴーストタイプのジム | 008 |
| ノモセシティ | ヨスガシティの南東。みずタイプのジム | 008 |
| トバリシティ | ハクタイシティからテンガン山を越えた先にあると思われる（推測）。帰りのルートの候補 | 008 |
| マサゴタウン | ナナカマド博士がいる街。エールの出身。ハクタイよりクロガネのほうが近い | 009 |
| 地下大洞窟 | シンオウの地下に広がり、地方全域をつなぐ広大な空間。「あなをほる」を使わないと行けない。ライザがよく潜っている | 009 |
| ライザの実家の店 | ハクタイシティにある。たんけんセットを100万円で売っている | 009 |
| サイクルショップ | ハクタイシティにある（カズマの推測ではライザの実家だと思われたが違った） | 009 |
| カンナギタウン | ハクタイシティから見てテンガン山の反対側。シンオウチャンピオンの地元 | 005 |
| ガラル地方 | プロトレーナー文化の発祥と言われている | 001 |
| ヒスイ地方 | アルセウスが召喚した者を送り込む先。カズマとは「別の時空」 | 000 |
| マサラタウン | カズマが飛ばされると思っていた場所（実際は違った） | 000 |
| 何もない異空間 | アルセウスが召喚を行う場所 | 000 |
