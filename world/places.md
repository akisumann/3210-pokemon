| 八大地方 | 世界の主要な八つの地方。シンオウもその一つ | 002 |
| カントー地方 | 「はじまりの地方」。八大地方の筆頭 | 002 |
| ハクタイシティ | 「昔を今に繋ぐ街」。ギンガハクタイビルとハクタイジムがある。ガッシュが遊んでいた街 | 001, 002 |
| ハクタイジム | くさタイプのジム。ジムリーダーは渋谷凜。大きな試合場があり、門下生がいる。カズマがお試しで通うことになった | 002, 003 |
| ハクタイの森 | ハクタイシティの西に広がるダンジョン。シンオウでも有数の深度で、昼でも薄暗い | 002, 003, 004 |
| 森の洋館 | ハクタイの森のすぐ近くにぽつんと立つ洋館。はるか昔からあるが、誰が建てたかわからない。気味の悪い館として街で有名。ルサルカが住み着いていた | 002, 003, 004 |
| ゴーストタイプのジム | シンオウにある。場所は不明 | 003 |
| スタジアム | プロリーグの会場。満員の観客が入る | 003 |
| コトブキシティ | トレーナーズスクールがある | 002 |
| ガラル地方 | プロトレーナー文化の発祥と言われている | 001 |
