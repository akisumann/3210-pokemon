# 第二部の登場人物

第二部「ポケの子（？）」の人物。第一部（`characters/`）とは別の世界線で、同じ名前・同じAAでも別人として扱う。出典は（出典: 2-001）の形。同じ人物の別の呼び名・ラベルは [呼び名の対応表](aliases.md)。

## トレーナー

- **できる夫**（転生前は家庭教師の青年）: 主人公。スクール次席の指示型。卒業バトルの雪辱のためジム巡りへ → [詳しい中身](trainers/できる夫.md)
- **藤丸立香**（“ぐだ”）: スクール首席でプロチームの新監督。卒業バトルでできる夫に勝った“あの女” → [詳しい中身](trainers/藤丸立香.md)
- **ルビー**（コーディネーター“RWBY”）: 前世の教え子の少女。カイナのハイパーランクを制した新人コーディネーター（同一人物かは推測） → [詳しい中身](trainers/ルビー.md)
- **古手川**: カナズミのジムリーダー、元スクール首席 → [詳しい中身](trainers/古手川.md)
- **阿慈谷ヒフミ**: シダケで会ったバッジ1個の統率型トレーナー。練習試合の相手 → [詳しい中身](trainers/阿慈谷ヒフミ.md)
- **磯野波平**: キンセツのジムリーダー。ホウエン最年長の「かみなり」オヤジ、「育成/統率」の複合型。エースは“十八竜”のライオット（でんき/ドラゴン）（出典: 2-005）
- **スクールの教師**: 卒業バトルの審判（出典: 2-005）
