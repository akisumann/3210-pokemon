# 第二部の登場人物

第二部「ポケの子（？）」の人物。第一部（`characters/`）とは別の世界線で、同じ名前・同じAAでも別人として扱う。出典は（出典: 2-001）の形。

## トレーナー

- **できる夫**（転生前は家庭教師の青年）: 主人公。カナズミのトレーナーズスクールの卒業前 → [詳しい中身](trainers/できる夫.md)
- **ルビー**（コーディネーター“RWBY”）: 青年の教え子の少女。カイナのハイパーランクを制した新人コーディネーター（同一人物かは推測） → [詳しい中身](trainers/ルビー.md)
- **“あの女”**: スクールの卒業バトルでできる夫と戦う相手。「統率」型、できる夫いわく「原始人」。名前はまだ出ていない（出典: 2-001）
- **ツツジにあたるジムリーダー**: 作者の構想だけで、まだ出ていない。少し石頭の優等生（元スクール首席）（出典: 2-001）
