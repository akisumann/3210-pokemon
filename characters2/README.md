# 第二部の登場人物

第二部「ポケの子（？）」の人物。第一部（`characters/`）とは別の世界線で、同じ名前・同じAAでも別人として扱う。出典は（出典: 2-001）の形。同じ人物の別の呼び名・ラベルは [呼び名の対応表](aliases.md)。

## トレーナー

- **できる夫**（転生前は家庭教師の青年）: 主人公。スクール次席の指示型。卒業バトルの雪辱のためジム巡りへ → [詳しい中身](trainers/できる夫.md)
- **藤丸立香**（“ぐだ”）: スクール首席でプロチームの新監督。卒業バトルでできる夫に勝った“あの女” → [詳しい中身](trainers/藤丸立香.md)
- **ルビー**（コーディネーター“RWBY”）: 前世の教え子で、同じく転生した。トウカジムリーダーの娘、統率AA+。できる夫の新チームのSP → [詳しい中身](trainers/ルビー.md)
- **古手川**: カナズミのジムリーダー、元スクール首席 → [詳しい中身](trainers/古手川.md)
- **阿慈谷ヒフミ**: シダケで会ったバッジ1個の統率型トレーナー。練習試合の相手 → [詳しい中身](trainers/阿慈谷ヒフミ.md)
- **磯野波平**: キンセツのジムリーダー。ホウエン最年長の「かみなり」オヤジ、「育成/統率」の複合型。1つめのジムの相手 → [詳しい中身](trainers/磯野波平.md)
- **野原ひろし**: トウカのジムリーダー、ルビーの父。ホウエン最強のジムリーダーの一人 → [詳しい中身](trainers/野原ひろし.md)
- **カドック**: 《風乃ヴォルフス》の監督。シンオウのキッサキ出身の指示型。ライバル候補 → [詳しい中身](trainers/カドック.md)
- **アナスタシア**（アーニャ）: カドックの幼なじみでSP → [詳しい中身](trainers/アナスタシア.md)
- **クスノキ**（千手扉間）: 海の科学博物館の館長でクスノキ造船所のオーナー。《造船アドバンス》のスポンサー → [詳しい中身](trainers/クスノキ.md)
- **キバオウ**: ジョウト弁の育成型。海の家“グランブルー”の監督になる同期のライバル → [詳しい中身](trainers/キバオウ.md)
- **シエル**: 《博物館サイバーズ》（「B」）の監督 → [詳しい中身](trainers/シエル.md)
- **烈海王**: ムロのジムリーダー。「かくとう」、“本能型”の指示型。2つめのジムの相手 → [詳しい中身](trainers/烈海王.md)
- **月村手毬**（てまりん）: ムロの都市チーム《武露シングアップ》の新監督。ルビーにコンテストで負けた“エリート美少女” → [詳しい中身](trainers/月村手毬.md)
- **桐生**（“堂島の龍”）: 《造船アドバンス》のブリーダー、育成A+ → [詳しい中身](trainers/桐生.md)
- **碇シンジ**: ルビーの幼なじみ。バッジ3つで今年デビュー。指示B／育成B／統率B／能力B → [詳しい中身](trainers/碇シンジ.md)
- **オダマキ**: ホウエンのポケモン博士。シンジの父 → [詳しい中身](trainers/オダマキ.md)
- **虎杖**: できる夫のスクールの知り合い。頭は良くないが「優勝物件」。『先発』の候補（出典: 2-018, 2-019）
- **集会所のマルゼンさん**（マルねぇ）: ムロ集会所の流行の研究家（出典: 2-016, 2-018）
- **カラクリ大王**: 自前で“カラクリ屋敷”を運営しつつプロチームの監督もする（【H】はカイナ）。波平の知り合い（出典: 2-007）
- **スクールの教師**: 卒業バトルの審判（出典: 2-005）
