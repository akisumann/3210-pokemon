# ジェンティルドンナ

> できる夫の3体目で『先発』。自称“貴婦人”の「ウマ娘」。Lv15で特性「ちからもち」の逸材で、チームでダントツ最高火力。

- シダケのコンテスト会場で、トレーナーなしで出ようとして断られていた。できる夫（「謎の紳士」）の「トレーナーになってあげましょうか？そこの鬼婦人」を「貴婦人」と聞いて上機嫌（出典: 2-003）
- 受付の台に指が刺さるほどの「ちからもち」。胸が大きい（アスカ談）（出典: 2-003）
- 要「統率：C」がせいぜいの「友好種」（アスカ）。アスカを「下品な赤」と呼ぶ（出典: 2-003, 2-004）
- ヒフミ戦を観戦して、2-005で仲間に（「良いとも――っ」）。プロのバトルにも興味がある。コンテストはまた今度（出典: 2-005）
- データ（2-005）: Lv15、ノーマル/かくとう、特性ちからもち（自身の「攻」の種族値を「AA+」にする）、技 にぎりつぶす・ばかぢから・なげつける・ビルドアップ、攻AA+（A）防B- 特攻D 特防C- 速A-（出典: 2-005）
- こんな低いランク（Lv15）で特性「ちからもち」を持つのはありえないほどの逸材（補足: ユーザーより、2026-10-31）。第一部で図鑑に「ちからもち」が出たのは、ヤマト（Lv50〜）、パイレートマン（Lv85）、ユーミル（Lv110）、マリルリ（Lv120）、響鬼（Lv165）で、いちばん低くてもLv50（AIの集計）
- できる夫の考え: ジム巡りでは“先発”の鉄砲玉、「こだわりハチマキ」で「ばかぢから」連打も。キンセツには出さず、2つめのムロまでに間に合わせる（出典: 2-005）
- データ（2-012）: Lv27（2-014でLv31、2-018でLv33）、体力B-（90前後）○、ポテンシャル『先発』『貴馬娘の闘志』（互いに「物理技」の時、相手の「防」の上昇（強化）を無視）『プリティーダービー』。体力はできる夫の言葉で、チーム内では最下位（出典: 2-012, 2-013, 2-014）
- サイクリングロードで、できる夫のじてんしゃを縄で引いて往復し（登りも）、すぐ組み手という、できる夫の想定よりハードな育成を1週間こなした（出典: 2-012）
- ジム巡りの間は『先発』。気性は一番の大物狙いで、のちに『エースキラー』への“コンバート”の見込み（アスカが“二枚看板”へ）（出典: 2-012）
- ラグラージ・できる夫の見立て: スクールのウマ娘で「ちからもち」を覚える気配のある者はいなかった。種の中でも肉体的な資質は段違いで、他のウマ娘では適性のないポテンシャルすら受け止める規格外の器かもしれない（出典: 2-012）
- デビュー戦（キバオウ戦）でこぶしのプレートを持って先発し、ヨプのみのバンギラスを「ばかぢから」一撃。ギガマントの「ダブルチョップ」で倒れた（出典: 2-013）
- 勝ちへの貪欲さ、勘の鋭さ、思い切りの良さと、メンタル面でも良い素質（できる夫の内心）（出典: 2-013）
- 2-007から「育成」に入り、『属』の『プリティーダービー』（1/試、「でんこうせっか」を繰り出し、「攻」を最も高い種族値と同ランクにする）を目指す。ラグとアスカ相手のパワーレベリングと、できる夫のマニュアルで強行軍（出典: 2-007, 2-010）
- 『先発』（先発で全能力1.1倍）を任命する予定（出典: 2-010）
- ムロジム戦: きあいのタスキを持って先発し、チャーレムの「ローキック」をタスキで耐え、『プリティーダービー』の「でんこうせっか」で倒した。チャドの「スカイアッパー」で倒れた（出典: 2-017）
- デビューまでに『キラー』にコンバートする予定で、できる夫は“α”にする気（ラグラージ）（出典: 2-016, 2-020）
- 飲み込みが早い（できる夫）。ポテンシャルの『分類』は付かない（出典: 2-007）
