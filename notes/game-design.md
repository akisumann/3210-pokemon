# ゲーム化の設計メモ

原典の世界をゲーム（バトルを中心に遊べるもの）にするための決めごと。ルールそのものは各資料に書き、ここには決まったことの一覧と、まだ決めていないことを置く。

## 遊び方の範囲（補足: ユーザーより）
- プレイヤーは**自分のチームを組んで**遊べる（カズマ側を動かすだけではない）。
- **オリキャラ**（オリジナルのトレーナーやポケモン）も作れるようにする。
- 相手は、[world/opponent-ai.md](../world/opponent-ai.md) の敵AIのモデルで動かす。

## 決まったこと（ゲームで回すとき）
| 項目 | 決めたこと | 書いてある場所 |
| --- | --- | --- |
| ランク→種族値 | 「+」は幅の最大値、「-」は最小値、素は中央あたりからランダム、Sは200超えのどこか | [battle-rules.md](../world/battle-rules.md) ステータスのランク |
| 能力値の式 | 実機の式で、個体値・努力値・性格補正なし | 同上 |
| 体力（マスクデータ） | 耐久が高くなさそうならC、まあまあB、ちゃんとあるA、それ以上は凄そうなもの | 同上 |
| 体力の見せ方 | 数値を見せず、言葉（「大きなダメージ」など）と＠で見せる。表示はいつも最大体力に対する割合 | 同上、ダメージ表示の目安 |
| 倍率の重ね方 | ランクの上昇・強化・威力の倍率は全て掛け算 | 同上、能力の「上昇」と「強化」 |
| 確率 | 中確率50％、低確率1/8、稀に1/16。『気合い』は12.5％×（1−残り体力の割合） | 同上、確率の目安 |
| 同時に起動する効果の順 | 素早い方から。1体の中は特性→『役割』→ポテンシャル欄の上から順 | 同上 |
| 指示の差 | 差1つにつき高い方に急所ランク+1（世界の法則） | [pro-trainer.md](../world/pro-trainer.md) |
| 『全開指令』 | 指示Bは試合前に全開か熟達かを一括選択、指示A以上は指令ごとに分割選択 | 同上 |
| 敵AI | 全ランクが自分の型を持つ。ランクで変わるのは道具・型の外での対応力・カズマ側に漏れるヒントの量 | [opponent-ai.md](../world/opponent-ai.md) |

## 舞台（補足: ユーザーより）
- まずは**「C」ランクの終盤くらい**を想定する（カズマたちでいえば第一節の終わり、コトブキ杯中規模大会のころ）。

## オリキャラのトレーナーの作り方
- **資質は「C・C・B・A」の4つを、指示・育成・統率・能力に1つずつ割り当てる**（補足: ユーザーより。「C」ランクのデフォルトの形。→ [pro-trainer.md](../world/pro-trainer.md) の資質の総合的な高さ）。
- **割り当てはダイスで決める**（補足: ユーザーより）。手順の案: ①1D4でAの資質（1指示・2育成・3統率・4能力）、②残り3つから1D3でBの資質、③残り2つがC。Aになった資質で「〇〇型」が決まる。
- **「+」「-」は最初は付けない**（補足: ユーザーより。めんどいので）。ただし**あとで実装できる余地を残す**（資質のデータに「+」「-」を持てる欄を用意しておき、最初は空にする。「+」は1ランク上の効果の一部、「-」は何かが欠ける、という資料の考え方に合わせる）。
- **『固有』は最初から作れる**（補足: ユーザーより）。原典で分かっている決まり（→ [potentials.md](../world/potentials.md) のトレーナーの『固有』ポテンシャル）に合わせる:
  - 数は、原典では「能力」のランクで決まる（C は1個、B は1〜2個、A 以上は2〜3個）。ただし**ゲームでは、舞台が「C」の終盤なので、「能力：A」でも1個を基本にする**（補足: ユーザーより）。
  - 「能力」が高いほど、発動条件が広くて強い（A なら「味方が場に出たとき」のような広い条件で発動できる）。低いと、自分の資質に合った**条件付け**が要る（カズマの「能力：C」は、統率型らしく『役割』の発動をトリガーにした）。
  - **『固有』の型は、Aを引いた資質（主な資質）で決まる**（補足: ユーザーより。→ [potentials.md](../world/potentials.md) の「資質と『固有』の傾向」）:
    - 統率型 → 味方の『役割』が発動した時（カズマ、観音寺、ダージリン）
    - 指示型 → 『指令』や「タイム」、四式を使った時（直哉、イングリッド、ブリジット）
    - 育成型 → パーティ全員に技を出させる技能拡張、または鍛えた技の強化（ハイランダー、ロビンマスク、一輝）
    - 能力型 → 「場に出た時」のような広い条件で、効果そのものが強い（レヴィ、爆豪、エール）
    - 万能型（Aがない場合） → 条件が広く、効果は汎用（先輩）
  - **強さは「能力」のランク**で決まる（Cなら条件付けが要り効果も控えめ、Aなら広い条件で強い効果）。
  - チームに付与できる『専用』の数も「能力」で決まる: C で3つ、B で4〜5つ、A で6つ（手持ち全員）。
  - **効果は、型と強さに沿って自由に作る**（補足: ユーザーより）。プレイヤーが「統率型で能力Cくらい、「でんき」タイプ系で得になるのが欲しい」のように希望を言い、Claudeが、原典の同じ型・同じくらいの「能力」の『固有』（[potential-list.md](../world/potential-list.md) のトレーナーのポテンシャル、[potentials.md](../world/potentials.md) の表）を参考に「こんなものはどうでしょう」と案を出す。
  - **出力の目安（統率型・能力Cでの試し。補足: ユーザーより）**: 希望「「でんき」タイプ系で得になるもの」に出した3案の評価。
    - 「味方の『役割』の発動時、場にいる味方1体を「充電」状態にする」 → **圧倒的に強すぎ**（次の「電」技の威力2倍を、『役割』が出るたびに配れてしまう）。
    - 「味方の『役割』の発動時、T終了時まで場の「電」タイプの味方の「電」技を1.2倍」 → **しょぼすぎ**。ただし「電」タイプの縛りを外せば（T終了時まで味方の技を1.2倍）**ほどほど**。
    - 「味方の『役割』の発動時、T終了時まで全体の場を「エレキフィールド」にする」 → **だいたいこのくらい**。
  - 実例の型: 技能拡張（パーティ全員がある技を出せる。ハイランダー、ロビンマスク、エール、天花）、場に出た時の強化（先輩、レヴィ）、『役割』の発動がトリガー（カズマ、ダージリン、観音寺）、『指令』や「タイム」や四式がトリガー（直哉、イングリッド、ブリジット）、フィールド形成（万丈目、レナ）など。

## チームのレベル（補足: ユーザーより）
- 「育成」のランクで、手持ちのレベルが上がる: **育成Cを基準に、育成Bなら+5、育成Aなら+10**。原典の「育成型はレベルで差をつける」（→ [battle-rules.md](../world/battle-rules.md) のレベル差。レベル10の差でおよそ全能力1割）に合わせたもの。
- **基準（育成C）はLv70**（補足: ユーザーより）。育成BならLv75、育成AならLv80。コトブキ杯中規模大会（「C」の終盤）の目安（上位チームは最低Lv65・『エース』Lv75くらい、先輩（育成B）は全員Lv75〜80、育成型はLv80〜。200）と合う。『エース』だけ高めにするかは未定。

## ポケモンの作り方（補足: ユーザーより）
- **手持ち6体の合計種族値は、450・500・500・550・550・600を基本にする**（補足: ユーザーより。最初の500・500・500・550・550・600は少し高すぎたので、1体を450に下げた）。
- **「統率」がBなら1体に+50、Aなら2体に+50**（補足: ユーザーより。強いポケモンを従えられる「統率」の力）。例: 統率Aなら450・500・550・550・600・650のように、どれか2体を+50する（どの体に足すかはプレイヤーが選ぶ、と見ている）。
- 合計種族値は、実機と同じく体力を含む6つの能力の合計（推測。原典の「合計種族値700クラス」などの言い方に合わせた）。

## まだ決めていないこと
- オリキャラのトレーナーの作り方の残り（「+」「-」の付け方はあとで）
- オリキャラのポケモンの作り方（種族値のランクの合計の目安、ポテンシャルの数と構成、Lv）
- チームを組むときの制限（ランクごとのLv帯、要「統率」、『専用』や種属のレギュレーション）
