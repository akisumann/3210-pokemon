# 第22話「固有ポテンシャルと練習試合の約束」 → source2/022_第22話「固有ポテンシャルと練習試合の約束」.txt

1. **負けたシンジ**。「プロでリベンジしてやるからな、前歯折る勢いで」。オダマキ「プロになる前に調子に乗るよりはエエじゃろ」、ルビーをSPに誘うが先約済み。シンジは負けるとネガティブになるのは相変わらずで、ルビーがクレープ屋に連れ出す（出典: 2-022）。

2. **オダマキ博士とひろし**。オダマキはこの地方のポケモン博士、“オダマキ”の名を継ぐ男。できる夫はファンで、著作を色々持っていて握手してもらう。トウカとルネは、ホウエンで最も強いと言われるポケモンジム（オダマキは「シンオウ」と言い間違え、作者が訂正）。オダマキ「お前も娘を盗られんように気をつけろよ？」（出典: 2-022）。
   - **ジムリーダー戦の決まり**: 4番目以降のジムリーダー戦は、対プロ仕様のフルバトル。“プロになってからのジムリーダー攻略数は、チームの昇格の加点要素”。年間4つのシーズンのうち最初の第一節で誰か1人は倒したい（できる夫、男なら最速昇格）。トウカの挑戦者は大抵1〜4番の間が多く、7番目や8番目は全力に近くなるので殆どいない（ひろし）。
   - ひろし「よかったら8番目に俺んとこ来て全力でやってみたりしません？」、できる夫「ルビーちゃんとたどり着いた「A」ランクになってからになりますけどね」と笑い合う。System: この冗談が冗談ではなくなるかもしれなくなる。
   - ルビーは指輪を紐でくくって首に下げている（基本は服の中）。
   - できる夫は家族団らんに割って入るのを遠慮して泊まりを断る（オダマキ「さっきまでのチンパンっぷりはどうしたんじゃ？」）。ひろし: ルビーの将来的にも恩人。ルビーはこの夜、お説教でママンに“見つかって”しまった。

3. **レベルアップ**: ラグラージLv34→36、アスカLv37→38、ドンナLv33→35（出典: 2-022）。

4. **できる夫の固有ポテンシャル『可能性を導くペン先』**: 味方に『指令』を発動する時、T終了時まで味方の最も高い種族値を強化（1.2倍）する（「体」が一番高い場合は次点）（出典: 2-022）。
   - 解禁は次のジムを突破してから（アスカ）。
   - できる夫: 大したことはない。「B」あれば「1.33倍」かそれ以上の可能性もあるが、あまり高くても“全開指令”にレギュがかかりかねない。アスカ: 「能力：C」なので出力は高くないが、“ポケモンの長所を引き出す”性質が色濃い、キライじゃない。作者: ポケモンの一番良いところを見つけるせんせーっぷりから生まれた。任意性もなにもない、完全にポケモン側依存の性能（でっきーはちょっと背中を押すだけ）。もうちょっとだけ火力がほしくて、でも他の『指令』を使いたい時などに便利。
   - ラグラージ: 今のところ美遊を含め4体とも“『指令』を撃てば火力が向上する”。めったにいないが、“得意とする種族値が複数ある場合はすべてに適応される”。ドンナ: オブザーバーの加入も喜ぶわけだ。
   - できる夫: 「統率」も「-」付きとはいえ「B」あるのはやはり大きい。

5. **練習試合の約束**。翌朝、トウカの森を抜けて、カドックに電話（「レンタル彼女の期限が切れただけだろ」）。合コン（会場は海の家）と、ムロのクール・ビューティ（手毬）の写真で釣り、デビュー前の練習試合を条件にする。カドック「なるほど、つながった……そのムロのクールビューティーも合わせて3チームでの合同練習試合でもしようっていうことか？」。アナスタシアに“おいしい水”の件がバレる。手毬からもすぐにオッケー。正式にはスポンサーに報告してから（出典: 2-022）。

6. カナズミシティに戻る（出典: 2-022）。
