# 第28話「コンテスト会場と神代璃緒との出会い」 → source2/028_第28話「コンテスト会場と神代璃緒との出会い」.txt

1. **コンテスト会場**。カイナの“ハイパーランク”会場。ランクはノーマル・スーパー・ハイパー・マスターの4つ（マスターはミナモ）。基本はシダケのノーマルから順に上げる。美遊はドンナを“姉さん”と呼び、古手川（唯）の助言でチームの風紀委員として見張る（「一日三モチまでに控えます」）。常識側はラグ、ドンナ、美遊（出典: 2-028）。

2. **ホウエンのトップ3**。チャンプのデボン、2位のマグマ団、3位のアクア団（先日はマグマ団が勝ったが、デボンが両方を下し王座を奪取）。マグマ・アクアともにトップはかなりお年を召している（出典: 2-028）。
   - アクア団総帥“エドワード・ニューゲート”: ホウエンの海の守護者、七つの海を揺らす大海賊。ホウエンの海のほぼすべてを手中に納めた立役者。最近は衰えを見せていると噂されるが“ホウエン3位”。クスノキの旧友。ホウエンにおける「みず」使いとして最強。ラグが大ファン（鳴き声も影響されている）。陸に上げても伝説がいくつもある（地震の噂）。“白ひげ”。
   - マグマ団総帥“バーン”: 相性が悪いはずでも互角の戦績。通称“太陽神”と呼ばれるポケモンを持つ。アスカはマグマ団派（タイプ的に）。
   - 海の科学博物館にはアクア団もよく来る。時に“総帥”も来る。
   - **ルネジムリーダー“神代凌牙”**（通称シャーク）: ルネの民の一族の出身。若いながらホウエンの双璧と呼ばれる「水」のエキスパートで、“白ひげ”に次ぐホウエン第二位の「水」使いとも。コンテストにも参加するトップブリーダーの一角、強い美意識の持ち主でコスチュームが独特。チャンプとも親交がある（できる夫の内心: RSのミクリに当たる）。トウカとルネはどちらもクライマックスリーグ級。
   - **妹の“神代璃緒”**: “ホウエン地方No.1コンテストアイドル”で、コンテスト側のチャンプと言える立場。たまにSPとしてイベントに出る。ルビーがコンテストに興味を持ったきっかけ。できる夫の内心: ルビーをコーディネーター兼任のSPにする考えは、ひろしがルネの兄妹を参考にしたらしい。

3. **ドンナの育成方針**（出典: 2-028）。
   - 「ばかぢから」はしばらくそのまま。“「インファイト」互換の「ノーマル」技”の訓練中。「なげつける」の代わりは「はたきおとす」（対「ゴースト」用）。
   - 作者: このスレでは「はたきおとす」等の持ち物破壊は“持ち物が効果を発揮する前に破壊される”（タスキやゴツメも効果発揮前に落とす。実機と少し違う。バトルが終われば戻る）。
   - できる夫: ドンナほどのパワーのウマ娘は見たことも聞いたこともない。“種族自慢の超速攻撃の分のキャパを攻撃に振ってる”とさえ思う。ドンナも素で「でんこうせっか」を覚えようとすると気が乗らない（「しんそく」もダメそう）。
   - できる夫の内心: 「ちからもち」と「ばかぢから」でパワーをコントロールする術を身につけてもらい、育成次第で種族値も多少伸びる可能性もある……“全種強化”を習得する可能性を高めたい（【AA内】「ﾊﾟﾝﾌﾟｱｯﾌﾟ」）。「ちからもち」との併用は不可だろう。本来“全種強化”はウマ娘との相性は最悪に近い（過剰搭載された筋力で「速」が下がり、「しんそく」すら消える）。種族内でかなり強引にやった昔の選手の話は聞いたことがある。彼女の規格外さを見ると、ボクの中の何かが“逝けるっ！”とささやく。ただデビューまでには間に合わない。近く本人にも説明するつもり。
   - 予定の種族ポテンシャル『貴馬娘の怪力』（場に出て最初に繰り出す「威力：120」以上の技が相手の「まもる」等を貫通）。ドンナの言う“威厳”がもし“あの特性”になれば、「ちからもち」とバトンタッチするのが理想。

4. **エクシアの方針**。ドンナと同じ物理速攻アタッカー。『指令』と相性の良い種族ポテンシャル『七剣頑の操縦』（トレーナーの『指令』を受けた時、T終了時まで自身の「速」を1.33倍）を覚えさせる予定。『狂走』だけでは抜けないこともあるし、“バウンス”後なら他を上げたり。上を取って殴る手段は多い方が良い。できる夫の固有で火力も微増（出典: 2-028）。
   - 美遊「割と寄せ集めに近いのによくそんな色々とすぐにプランを立てられますね」。できる夫「ポケモンバトルってのは、やっぱりポケモンこそが主役」「負けたら監督であるボクが未熟だった……そんなんで良いんですよ」。美遊は初期のポテンシャルが優秀すぎる。

5. **神代璃緒との出会い**。公園でラティアスとポロックを食べていたできる夫のところへ、チルタリスを連れた少女が「ホントにラティアス、みっけ♪」。この前カイナのコンテストで（ラティアスが優勝して）と聞いて何度か足を運んでいた（シダケ、ハジツゲでも噂になっていた）。ラティアスの背中を撫でさせてもらい「おほー………っ」。名刺「でっきーへ♪ 自称“コンテストアイドル”神代璃緒」を置き、ミナモへ。チルタリスはモフり損ねた。名刺を見たルビーは「あ''ぁ''ぁ''ぁ''」と叫び、晩御飯を奢られて元気になった（出典: 2-028）。
   - 作者: カイナ＆コンテス＝ルチア枠。リメイクを知らぬでっきーは存在を認識していない。次のフリーの後にもう1回、メンバーの方向性の情報を投げる予定。
