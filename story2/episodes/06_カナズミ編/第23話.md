# 第23話「カナズミジムリーダー戦」 → source2/023_第23話「カナズミジムリーダー戦」.txt

1. **美遊との対面**。古手川「本当にこの短期間でスポンサーまで見つけて凱旋とは………頼もしい後輩よね」。美遊（「写真そのまま」）は、できる夫の腹をモチモチ、タプタプする。古手川はできる夫のぽっちゃりボディでのフィールディングに感心（出典: 2-023）。

2. **スクールとジムの約束**。美遊はもともと、できる夫がスクール首席になった時用。予定が変わったので、古手川は、できる夫が得るかもしれないスポンサーとのつながりを作りつつ恩を売る方向に切り替えた。約束していたのはできる夫個人ではなく、スクールというスポンサーなので、ぐだのスクールのチームにも移籍させている: 先日手に入れた化石から復元された、非常に珍しい“太古の狼王”（ぐだにもなついている。その潜在能力を全開にできるには時間がかかりそう）。古手川は化石マニアで、できる夫の化石の話に食いつく（出典: 2-023）。
   - 古手川は頭が硬いところもあって「指示：C+」（できる夫）。

3. **3体ともLv35**。3つめのジムバッジの制限範囲ギリギリ。もともと烈海王の「35」がリミットいっぱい（作者）。本来は1つめでポテンシャル習得、2つめで『指令』に慣れ、そこから新しいポケモンをゲットしてジム対策と、もっと時間がかかる。スクールの下地と『指令』の知識経験で、数倍以上のペースで進んだ（ラグラージ）。スクールでもぐだ子のように2つめまでは合間で取っている者もいる（アスカ）（出典: 2-023）。

4. **相手の『エース』**。古手川は“岩にときめく優等生”で「いわ」のエキスパート（アスカの苦手）。『エース』は「いわ」の十八竜“トライノス”: 完全な物理型で耐久に優れ、「体力」もこれまでの十八竜で一番かも。教科書の有名な特性は「いしあたま」。ドンナの相性が良く、ラグとアスカの2体がかりがベスト（出典: 2-023）。

5. **戦闘準備**（20:30〜20:45の安価から3つ、【1D3:3】で①>>696 ②>>697 ③>>703）→ 【安価結果】703: ラグラージ＝こだわりハチマキ、アスカ＝こだわりスカーフ、ドンナ＝だっしゅつパック、先発ドンナ。作者: ジム巡り編でのラストバトル（出典: 2-023）。

6. **バトル**（《カナズミジム》、フィールド効果なし）。先発ユレイドル（いわ/くさの古代種）に図鑑。古手川の『回復指令』を読んで、ドンナの『攻撃指令』＋「ばかぢから」で「測定不能のダメージ」を与え、タスキで耐えられる（古手川「半減実でも一撃じゃないのよ……無茶な火力出してくれるわね」）。『岩壺獣の触手』の「しめつける」を、「ばかぢから」の能力低下で発動しただっしゅつパックで逃れる。アスカの『特攻指令』＋「ねっとう」でユレイドルを倒す。サベージ（「アームスレイブ」種）の「がんじょう」と「ストーンエッジ」でアスカが倒れ、ドンナが『プリティーダービー』の「でんこうせっか」でサベージを倒す（ゴツゴツメットのダメージ）。『エース』トライノスに「ばかぢから」で特大のダメージを与えてドンナは倒れ、ラグラージが『防御指令』＋「じしん」で倒して勝利 → [バトル記録](../../battles/カナズミジム_古手川唯戦.md)（出典: 2-023）。
   - 『指令』は交代先までは効力が及ばない（できる夫、ドンナ）。
   - 作者: 『指令』の宣言は、致命傷だったりわざとだったりしない限りは大抵普通に通る（後からの変更要望も受け付けない）。この辺りは、ドンナとラグラージが圧倒的優位を取れるということでのゲームメイク（『特攻指令』は使ってOK）。
   - 『アームスレイブ』で、古手川の「指示」は今「B+」（この類は基本非表示。作者）。4つめ以降ならもっと速いポケモンを使う（古手川）。鈍足ぞろいに「いわ」の防御面はつらいが、これはもう宿命。
   - 古手川の内心: 座学の成績自慢が持ちネタだけはある、応用も効く、スクール教師陣の評価も高かった所以。半分問題児だけど。
   - トライノスは「防：AA-」の「体：A」（作者）。古手川「もうちょっとで「イバン」＆「ウッドホーン」を打ち込めたのに」。

7. **古手川の資質**: 指示C+／育成A+／統率B+／能力C（出典: 2-023）。古手川「いよいよ貴方は“プロリーグ”への参加権を得たわけだけど……大変なのはこれからよ？」。
