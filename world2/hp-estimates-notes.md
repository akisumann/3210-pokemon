| --- | --- |
| アスカ・ラングレー | できる夫の内心「アスカの体力は「A-」、それもこれから他の種族値と合わせ伸びる可能性あり」（2-004） |
| インコマン | ヒフミの台詞「「図鑑」じゃ見えないけど、インコマンの「体力：B」よりも………」（2-004） |
| ジェンティルドンナ | できる夫「ドンナさんの「体力」は現状「B-」………低いとは言えませんが、チーム内では最下位」（2-013） |
| ギガマント | ドンナ「あら、やはり私より体力は高いようで」（「にぎりつぶす」で@2。2-013）。ドンナのB-より上なので、下限だけ置いた |
| ハイランダ | アスカ（Lv35、特攻A＝110〜135）の「かえんほうしゃ」（一致1.5倍、いまひとつ0.5倍、『エースキラー』1.5倍）を、ハイランダ（Lv35、特防D+、「ここぞ！」で1.33倍）が受けると、1発41〜58。1発目で「大きな」@2（残りが1発分より多い）、2発目で「深刻な」@1（残り1/6以下）、オボンのみで1/4回復、『火竜娘の激昂』（特攻+1）の3発目で倒れた。1発目の後に2発分近く残るので実数値82以上、2発で5/6以上削れたので140以下→種族値でD+〜A。体力の高い方の言及はない（2-017） |
| ラグラージ・ライボルト・バンギラス・チャーレム | 古代種（実機のポケモン）は、図鑑の5つの能力が実機の種族値と全部合う（ラグラージ110/90/85/90/60＝A-/B-/C+/B-/C-、ライボルト75/60/105/60/105＝C/C-/B+/C-/B+、バンギラス134/110/95/100/61＝A+/A-/B/B/C-、チャーレム60/75/60/75/80＝C-/C/C-/C/C）。第一部と同じく、体力も実機の値（ラグラージ100、ライボルト70、バンギラス100、チャーレム60）とした（2-003, 2-006, 2-013, 2-017） |
| アブソル・ユレイドル | 古代種なので実機の体力（アブソル65、ユレイドル86）。アブソルの5つの能力は実機（130/60/75/60/75）と全部合う。ユレイドルも実機（81/97/81/107/43）と合う。特防107はBとAの幅の隙間（105と110の間）の値で、B+と表示されている（2-021, 2-023） |
