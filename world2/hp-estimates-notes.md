## ジム巡り（2-002〜）

| ポケモン | 根拠 |
| --- | --- |
| アスカ・ラングレー | できる夫の内心「アスカの体力は「A-」、それもこれから他の種族値と合わせ伸びる可能性あり」（2-004） |
| インコマン | ヒフミの台詞「「図鑑」じゃ見えないけど、インコマンの「体力：B」よりも………」（2-004） |
| ジェンティルドンナ | できる夫「ドンナさんの「体力」は現状「B-」………低いとは言えませんが、チーム内では最下位」（2-013） |
| ギガマント | ドンナ「あら、やはり私より体力は高いようで」（「にぎりつぶす」で@2。2-013）。ドンナのB-より上なので、下限だけ置いた |
| ハイランダ | アスカ（Lv35、特攻A＝110〜135）の「かえんほうしゃ」（一致1.5倍、いまひとつ0.5倍、『エースキラー』1.5倍）を、ハイランダ（Lv35、特防D+、「ここぞ！」で1.33倍）が受けると、1発41〜58。1発目で「大きな」@2（残りが1発分より多い）、2発目で「深刻な」@1（残り1/6以下）、オボンのみで1/4回復、『火竜娘の激昂』（特攻+1）の3発目で倒れた。1発目の後に2発分近く残るので実数値82以上、2発で5/6以上削れたので140以下→種族値でD+〜A。体力の高い方の言及はない（2-017） |
| ラグラージ・ライボルト・バンギラス・チャーレム | 古代種（実機のポケモン）は、図鑑の5つの能力が実機の種族値と全部合う（ラグラージ110/90/85/90/60＝A-/B-/C+/B-/C-、ライボルト75/60/105/60/105＝C/C-/B+/C-/B+、バンギラス134/110/95/100/61＝A+/A-/B/B/C-、チャーレム60/75/60/75/80＝C-/C/C-/C/C）。第一部と同じく、体力も実機の値（ラグラージ100、ライボルト70、バンギラス100、チャーレム60）とした（2-003, 2-006, 2-013, 2-017） |
| アブソル・ユレイドル | 古代種なので実機の体力（アブソル65、ユレイドル86）。アブソルの5つの能力は実機（130/60/75/60/75）と全部合う。ユレイドルも実機（81/97/81/107/43）と合う。特防107はBとAの幅の隙間（105と110の間）の値で、B+と表示されている（2-021, 2-023） |
| トライノス | 作者の注記「「防：AA-」の「体：A」の相手です」（2-023）。ランクだけなので幅で置いた |
| カービィ | アスカ（Lv32、攻B）の急所の「どくづき」（ばつぐん、急所2倍）で満タンから「特大」で倒れた。計算は88〜164で、上限が決まらない。第一部の同じ種族のカービィ（Lv150、能力が全部B-でそろった『固有種』）の体力B-と、ヒフミの『エース』であることから、Bの幅に置いた（推測）（2-004） |
| ライオット | ラグラージ（Lv32、攻A-）の「じしん」（一致、ばつぐん）で満タンから「特大」で倒れた。計算は94〜150で、上限が決まらない。第一部の同じ種族のライオット（レヴィ、Lv45）の推定C前後に合わせた（推測）（2-006） |
| ダクネス | 急所の測定不能のダメージを「がんじょう」で耐え、オボンのみのあとラグラージの「じしん」で倒れた。逆算で絞れないので、既定の目安（下限B、高い方の言及がないのでAAで止める）（2-013） |
| 茶渡泰虎 | ドンナ（Lv31、攻AA+、『先発』は『巨腕男の防御』で無視）の「にぎりつぶす」（満タンで威力120、一致）で「大きな」@1〜2（52〜73）。残りをアスカ（Lv35、特攻A）の「かえんほうしゃ」（一致、とつげきチョッキ1.5倍）が「大きな」で倒し（48〜69）、アスカ「ギリギリの手応え」。残りが1発分に近いとすると、実数値は109〜142。下限はそこから、上限は計算の幅で（2-017） |
| プラントラ | できる夫「仮に体力がアスカに近ければ……種族値バランス的に見ても体力は近い水準あってもおかしくない」（アスカはA-）。はっきりしない言い方なので△。ドンナの『攻撃指令』＋ビルドアップ（攻+2）の「にぎりつぶす」（135〜159）で満タンから倒れたのとも合う。第一部の同じ種族（ユニ、Lv130）もA◎（2-021） |
| ラム | 満タンから、アスカ（Lv37、特攻A）の「かえんほうしゃ」（一致）で「大きな」@1（48〜69）。1/3〜2/3で、残りが1発以内なので、実数値は72〜138（種族値でC〜A）（2-021） |
| サベージ | アスカの「ねっとう」（ばつぐん）で「特大」、「がんじょう」で耐えた。計算からは上限しか出ない（156以下）。第一部の同じ種族のサベージ（ハイランダー、Lv65）の推定B（95前後）に合わせた（推測）（2-023） |
| カタクリ | できる夫「「体」もアスカ並みにあったりしません？」（アスカはA-）、本人「ママに比べれば俺の体力なんて低いぜ」。はっきりしない言い方なので△（2-030） |
