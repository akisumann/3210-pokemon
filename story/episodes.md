# 各話のあらすじ

## キャラ作成編オープニング → source/000_キャラ作成編オープニング.txt
1. 何もない異空間で、アルセウスがヒスイ地方へ送る勇者を召喚するため、1日1回の無料ガチャ「アルセウス・フォン」を回す。
2. 出てきたのは、トラックにはねられて死んだカズマ。アルセウスは「コモン」だとがっかりする。念のためクイズを出すが、ポケモンの種類を151匹までしか知らないとわかり、「ギルティ」と言う。
3. 元の世界に帰そうとしたが、カズマはもう死んでいた。アルセウスは仕方なく、特典なしでシンオウ地方に転生させる。
4. 何も考えずテンガン山の座標に飛ばしてしまったが、「幸運ステータスだけは妙に高いからなんとかなる」と切り替える。そのあと本命をヒスイ地方へ送る（ポケモンLEGENDSのオープニングへ）。
5. 別の時空。テンガン山の異界で、アカネ（マーズ）がポケモンリーグで負けた八つ当たりに、野生のクシャルダオラをゼットンの「Vジェネレート」で倒す。
6. ディオスクリアとチャンプ（女帝）の話をする。アカネは三将星の使命やジュピターへの不満をこぼす。そこへ地面が砕け、逆さまに突き刺さったカズマが現れる。

## 第1話 → source/001_第1話.txt
1. ギンガハクタイビル。マーズ（アカネ）が気絶した男を連れ帰ったことを、社員二人が噂している。アカネはテンガン山の「異界」クラスのダンジョンにいきなり現れた少年に興味を持っている。
2. カズマが医務室で目を覚ます。アカネに転生したことを話すが信じてもらえず、記憶喪失ということにする。お金もない（漱石の千円札は偽札扱い）。
3. アカネが自分の家の家政夫（ﾄﾞﾚｲ）にならないかと持ちかける。社員たちに止められ、からかわれたアカネは意地になり、カズマを脅して連れて帰る。
4. アカネのマンションはゴミ屋敷状態。カズマは掃除を任され、アカネのパンツを拾ってパンツ・ヘリコプターをする。アカネはゼットンに攻撃を命じるが、ゼットンはカズマの味方をする。
5. ゼットンがプロトレーナー制度を説明する。カズマはゼットンがポケモンだと知って驚く。
6. 部屋はあっという間に片付き、ゼットンは感動して泣く。アカネはカズマを意識し始める。カズマは物置部屋で寝ることになる。アカネはゼットンに泣きつき、ゼットンはカズマを逃がさないように囲う準備を考える。
7. カズマは、自立しなければと思いながら眠りにつく。

## 第02話「ガッシュ、ゲットだぜ！」 → source/002_第02話「ガッシュ、ゲットだぜ！」.txt
1. 翌朝、アカネは眠そうにカズマを避けるようにして出社する。ゼットンがカズマにハクタイシティを案内する。シンオウは「八大地方」の一つで、カントーは「はじまりの地方」。ピカチュウは「古代種」扱いされている。
2. ゼットンの知り合いの幼いポケモン、ガッシュが現れる。ガッシュは「王を目指す種族」なので『エース』以外の適性がなく、トレーナーに断られ続けていた。
3. ガッシュがでんきタイプで、声がピカチュウと同じ（大○育江）だとわかり、カズマは即決で手持ちにする。ガッシュもアカネのマンションで暮らすことになる。
4. カズマは「持ち物」や「特性」も知らず、ゼットンとガッシュはあきれる。ゼットンは、アカネの親友であるハクタイジムのジムリーダー、渋谷凜のもとで学ぶよう勧める。
5. 夜、アカネはいい気になってジム通いを許可する（内心では、昼間に部屋を荒らされずに済むと喜んでいる）。カズマは凜の弱点が「お化け」だと聞いてメモする。ゼットンは何か嫌な予感を感じている。

## 第03話「ジムリーダーはお化けが怖い」 → source/003_第03話「ジムリーダーはお化けが怖い」.txt
1. カズマとガッシュがハクタイジムを訪れる。カズマはジムリーダーの渋谷凜とアカネの愚痴で意気投合する。凜と親しいハーフのティファニア（テファ）にも会う。
2. 凜が「育成型」の教育力でカズマを教えることになる。ジムの試合場を見学し、ガッシュがチャンピオンを目指していることを聞く。約1時間、タイプ・特性・持ち物などの講義を受ける。
3. 古代種と現代種の区分を知る（ピカチュウは古代種の長老、ガッシュは現代種）。人間とポケモンのハーフがいること、アルセウスはシンオウの創造神として神話に語られていることも知る。
4. トレーナーの四つの資質（指示・育成・統率・能力）の説明を受ける。占いの本の結果、カズマの資質は「統率」とされる。超能力を持つ人間もいると知る。
5. カズマが凜のお化け嫌いをからかう。ティファニアに週一で泣いて帰ってくることをばらされた凜は、意地を張って、今晩カズマとガッシュを連れて「森の洋館」に行くと宣言する。アカネは面白がって「イケイケ！」と言う。
