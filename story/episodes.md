# 各話のあらすじ

## キャラ作成編オープニング → source/000_キャラ作成編オープニング.txt
1. 何もない異空間で、アルセウスがヒスイ地方へ送る勇者を召喚するため、1日1回の無料ガチャ「アルセウス・フォン」を回す。
2. 出てきたのは、トラックにはねられて死んだカズマ。アルセウスは「コモン」だとがっかりする。念のためクイズを出すが、ポケモンの種類を151匹までしか知らないとわかり、「ギルティ」と言う。
3. 元の世界に帰そうとしたが、カズマはもう死んでいた。アルセウスは仕方なく、特典なしでシンオウ地方に転生させる。
4. 何も考えずテンガン山の座標に飛ばしてしまったが、「幸運ステータスだけは妙に高いからなんとかなる」と切り替える。そのあと本命をヒスイ地方へ送る（ポケモンLEGENDSのオープニングへ）。
5. 別の時空。テンガン山の異界で、アカネ（マーズ）がポケモンリーグで負けた八つ当たりに、野生のクシャルダオラをゼットンの「Vジェネレート」で倒す。
6. ディオスクリアとチャンプ（女帝）の話をする。アカネは三将星の使命やジュピターへの不満をこぼす。そこへ地面が砕け、逆さまに突き刺さったカズマが現れる。

## 第1話 → source/001_第1話.txt
1. ギンガハクタイビル。マーズ（アカネ）が気絶した男を連れ帰ったことを、社員二人が噂している。アカネはテンガン山の「異界」クラスのダンジョンにいきなり現れた少年に興味を持っている。
2. カズマが医務室で目を覚ます。アカネに転生したことを話すが信じてもらえず、記憶喪失ということにする。お金もない（漱石の千円札は偽札扱い）。
3. アカネが自分の家の家政夫（ﾄﾞﾚｲ）にならないかと持ちかける。社員たちに止められ、からかわれたアカネは意地になり、カズマを脅して連れて帰る。
4. アカネのマンションはゴミ屋敷状態。カズマは掃除を任され、アカネのパンツを拾ってパンツ・ヘリコプターをする。アカネはゼットンに攻撃を命じるが、ゼットンはカズマの味方をする。
5. ゼットンがプロトレーナー制度を説明する。カズマはゼットンがポケモンだと知って驚く。
6. 部屋はあっという間に片付き、ゼットンは感動して泣く。アカネはカズマを意識し始める。カズマは物置部屋で寝ることになる。アカネはゼットンに泣きつき、ゼットンはカズマを逃がさないように囲う準備を考える。
7. カズマは、自立しなければと思いながら眠りにつく。

## 第02話「ガッシュ、ゲットだぜ！」 → source/002_第02話「ガッシュ、ゲットだぜ！」.txt
1. 翌朝、アカネは眠そうにカズマを避けるようにして出社する。ゼットンがカズマにハクタイシティを案内する。シンオウは「八大地方」の一つで、カントーは「はじまりの地方」。ピカチュウは「古代種」扱いされている。
2. ゼットンの知り合いの幼いポケモン、ガッシュが現れる。ガッシュは「王を目指す種族」なので『エース』以外の適性がなく、トレーナーに断られ続けていた。
3. ガッシュがでんきタイプで、声がピカチュウと同じ（大○育江）だとわかり、カズマは即決で手持ちにする。ガッシュもアカネのマンションで暮らすことになる。
4. カズマは「持ち物」や「特性」も知らず、ゼットンとガッシュはあきれる。ゼットンは、アカネの親友であるハクタイジムのジムリーダー、渋谷凜のもとで学ぶよう勧める。
5. 夜、アカネはいい気になってジム通いを許可する（内心では、昼間に部屋を荒らされずに済むと喜んでいる）。カズマは凜の弱点が「お化け」だと聞いてメモする。ゼットンは何か嫌な予感を感じている。

## 第03話「ジムリーダーはお化けが怖い」 → source/003_第03話「ジムリーダーはお化けが怖い」.txt
1. カズマとガッシュがハクタイジムを訪れる。カズマはジムリーダーの渋谷凜とアカネの愚痴で意気投合する。凜と親しいハーフのティファニア（テファ）にも会う。
2. 凜が「育成型」の教育力でカズマを教えることになる。ジムの試合場を見学し、ガッシュがチャンピオンを目指していることを聞く。約1時間、タイプ・特性・持ち物などの講義を受ける。
3. 古代種と現代種の区分を知る（ピカチュウは古代種の長老、ガッシュは現代種）。人間とポケモンのハーフがいること、アルセウスはシンオウの創造神として神話に語られていることも知る。
4. トレーナーの四つの資質（指示・育成・統率・能力）の説明を受ける。占いの本の結果、カズマの資質は「統率」とされる。超能力を持つ人間もいると知る。
5. カズマが凜のお化け嫌いをからかう。ティファニアに週一で泣いて帰ってくることをばらされた凜は、意地を張って、今晩カズマとガッシュを連れて「森の洋館」に行くと宣言する。アカネは面白がって「イケイケ！」と言う。

## 第04話「森の洋館の魔女」 → source/004_第04話「森の洋館の魔女」.txt
1. 3日目の夜。カズマ、凜、ガッシュが森の洋館の前に来る。凜は震えながらも、意地で扉に近づく。
2. 暗がりから魔女ルサルカが現れて脅かし、凜は気絶する。カズマはガッシュに「10まんボルト」を命じ、2発で倒す（ポケモンバトル初勝利）。
3. 目を覚ましたルサルカは、自分はゴースト／みずタイプの「敵性種」で、若い男の生命エネルギーが好物だと明かす。反対の「友好種」の話も出る。
4. 帰ろうとするカズマを、ルサルカが「くろいまなざし」で逃がさない。3発目の10まんボルトを「きあいのハチマキ」で耐え、仲間にしろと迫る。
5. 料理が得意と聞いたカズマは、ルサルカを2体目の手持ちにする。気絶したままの凜を背負って街に帰り、3日目が終わる。

## 第05話「目指せ、プロトレーナー！」 → source/005_第05話「目指せ、プロトレーナー！」.txt
1. カズマがシンオウに来て約1週間。毎朝ルサルカが寝込みを襲い、アカネが怒鳴り込む。ルサルカの料理に胃袋をつかまれたゼットンは、ルサルカの側につく。
2. 朝食の席で、カズマのポケモン図鑑が今夜届くと知る。図鑑は協会から無料で配られ、持ち歩きが義務。ID管理や電話など、スマホ並みの機能がある。
3. ポケモンリーグの説明を受ける。20チームが予選を戦い、5チームが本戦に出る、地方最強のプロチームを決める大会。先日のリーグでは、チャンピオン「女王」（カンナギタウン出身、3連覇）が優勝し、2位は四天王のほのお使い、3位はギンガ団のジュピター（本名コーネリア）だった。アカネは予選敗退。
4. プロのギャラが芸能人以上だと聞いたカズマは、金目当てでプロトレーナーとチャンピオンを目指すと決める。ガッシュは不安に思う。アカネはこっそり図鑑でガッシュとルサルカのデータを確認する。

## 第06話「プロへの道とテンガン山」 → source/006_第06話「プロへの道とテンガン山」.txt
1. ジムの休館日。凜が自宅の汚部屋を片付けられずにいると、門下生に家を聞いたカズマが押しかけてくる。鍵がかかっていなかったので中に入り、ガッシュ、ルサルカと30分で片付ける。凜は泣き、ルサルカが朝食を作る。
2. カズマは、アカネにプロ宣言を笑われた話をする（動機は「金、富、マネー」）。凜がプロになる三条件を説明する。ジムバッジ3つ以上の監督、6体以上の所属ポケモン（レンタルなども可）、参加費を出してくれるスポンサー。
3. バッジ7つでBランクに自動昇格できる特例がある。ジムリーダーは全員Aランク級。大きなスポンサーほど有利で、新人は弱小スポンサーが狙い目。プロの世界は生存競争が激しい。
4. まずは経験を積むよう言われ、ダンジョンの話を聞く。層が深いほど強いポケモンがいる。ハクタイの森は最大4層、テンガン山は唯一5層まであるシンオウ最大のダンジョン。一行はテンガン山の1層へ向かう。
5. テンガン山の深度4。ヌシのメリュジーヌが、以前この層に現れた人間（カズマ）の気配に気づき、その「匂い」に興味を持って1層へ向かい始める。

## 第07話「テンガンのヌシ」 → source/007_第07話「テンガンのヌシ」.txt
1. テンガン山の深度1。カズマたちはゴルバットやイワークなど、レベル20くらいまでの古代種を相手にバトルに慣れていく。
2. 敵性種「アラガミ」の下位種、オウガテイルと戦おうとしたところへ、メリュジーヌが「あくうせつだん」を撃ち込む。オウガテイルは巻き込まれたが、カズマたちは奇跡的に無事だった。
3. メリュジーヌは深度4の『テンガンのヌシ』だと名乗る。カズマから「異世界人の気配」と「山のエネルギーの匂い」がすると言い、奇妙な縁や運の色が濃いと見る。
4. カズマの勧誘を断り、「勝ったら恋人にしてあげる」「1年以内に戦いに来ること」と一方的に約束させる。オウガテイルを担いで深部へ帰る。
5. 図鑑にメリュジーヌのデータが少しだけ載る（ドラゴン／フェアリー、特性マルチスケイル、ポテンシャル『野生の親玉』『テンガンのヌシ』）。一行はテンガン山から逃げ帰る。

## 第08話「一ヶ月の賭け」 → source/008_第08話「一ヶ月の賭け」.txt
1. カズマがメリュジーヌとの遭遇を報告する。アカネは妄想扱いするが、図鑑の「テンガンのヌシ」の記録を見て固まる。
2. ダンジョンの2層以降には、その層を支配する「群れ」がいて、それを統括するのがヌシだと教わる。深度4のヌシを手持ちにしているプロチームは、シンオウでも5チームあるかないか。1年でリーグ級にならないとメリュジーヌに返り討ちにされると知り、カズマは頭を抱える。
3. アカネが「守って」と言われるのを期待するが、カズマは自衛の努力をすると言う。アカネが守ってと言えば一緒に逃げるとも言う。
4. アカネが賭けを持ちかける。「明日から1ヶ月以内にバッジ3つとスポンサーを見つけること」。カズマは旅費を出世払いで借りることを条件に受ける。
5. ルートはクロガネシティ（いわ、ジムリーダーはスペランカー）→ヨスガシティ（ゴースト）→ノモセシティ（みず）。翌日から旅に出ることになる。アカネは、自分の家事が回らなくなることにまだ気づいていない。

## 第09話「旅立ちとたんけんセット」 → source/009_第09話「旅立ちとたんけんセット」.txt
1. 旅立ちの日。カズマは凜とライザに賭けの話をする。凜の家を教えたのはライザだった。
2. ライザの実家は、父親が古文書から復活させた「たんけんセット」を100万円で売る店。地下大洞窟に潜るための道具だが、まったく売れず、来年中にはつぶれそう。カズマがレンタルを提案すると、ライザは衝撃を受けて店で働くよう迫る。
3. カズマは、ライザの家のようなところが狙い目のスポンサー候補だと考える。ライザは電話番号を聞き出す。凜は「夢破れたらごはんくらい奢る」と送り出し、カズマはクロガネシティへ出発する。
4. ハクタイジムに、マサゴタウンから来たバッジ0の新人トレーナー、エール・モフスが現れる。手持ちはラハールとキュゥべえ。「チャンピオンを倒してシンオウの女王になる」と宣言する。カズマとの遭遇はもう少し先。

## 第10話「ポフィン泥棒とさすらいの先輩」 → source/010_第10話「ポフィン泥棒とさすらいの先輩」.txt

2. 白髪の少女が、置いていたポフィンの8割を盗み食いしていた。逃げようとしたところをルサルカの「くろいまなざし」で止められる。「でんこうせっか」で反撃するが、ゴーストのルサルカには効かない。

## 第11話「先輩の教え」 → source/011_第11話「先輩の教え」.txt
1. 206番道路での野営。先輩とその手持ちのザクも一緒。マックイーンが一発芸で「うまぴょい伝説」を踊り、「ウマゴン」と呼ばれる。図鑑でマックイーンのデータを確認する（ノーマル、Lv20、すばやさAA-）。
2. 先輩が「ポテンシャル」を説明する。ポケモンの潜在能力が形になったもので、『』付きの言葉がそれ。バッジを取れるくらい強くなると目覚め、持ち物や特性より影響が大きい。
3. 図鑑でカズマのトレーナーステータスを見る（指示B-、育成C、統率A+、能力C）。先輩はオールBの万能型。統率Aなら理論上どのポケモンも従えられる。
4. 敵性種の話を聞く。ステータスが高い傾向がある。統率型に向いているのはモンハン種で、その上位が古龍。メリュジーヌのステータスは古龍に匹敵する。
5. トレーナー同士のバトル経験がないことに気づき、先輩が相手を買って出る。翌日クロガネシティで戦うことになる。
