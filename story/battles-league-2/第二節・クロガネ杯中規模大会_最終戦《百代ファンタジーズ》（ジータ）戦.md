# 第二節・クロガネ杯中規模大会（Bランク、7チーム、クロガネスタジアム） ／ 最終戦 《百代ファンタジーズ》（ジータ）戦

- 安価なしで進んだ（スキップの）試合で、負けた（補足: ユーザーより）。
- 試合前のLv（クラッシャーズ戦のあと）: ガッシュ111、マックイーン111、イカルガ104、ベルゼブモン110、ルサルカ109、ガブリアス106。カズマは疲労で倒れかける（天花「「B」ランク''中規模戦''………心身にかかる負担も相当のはず」）。

- ほかの結果: スマッシュ●－○アンブラハンズ（帝督がメガバンギラスを倒して一矢報いる）、クラッシャーズ●－○ファンタジーズ（新戦力オグリキャップの大暴れ）。最終戦の前にハクタイの2チームのワンツーが確定し、全勝同士の「統率」型の決勝になった。

- 流れ: シルバーソル（''リオレウス''種の『天賦の才』、『二枚看板』、「ひでり」）の「かえんだん」でベルゼブモンが倒れ、『銀火竜の旋回』でオグリキャップに交代。アティ（''セイバー''種の『金冠サイズ』、『蒼剣』）の「まほうのけん」でヤマトが倒れる（『抜剣者の勝鬨』で満タン）。ガッシュが出て「ここぞ！」（『友情』）。アティ「''3体がかり''、抜けるものなら抜いてみなさい」。

- 観戦していたボンドルドと絶奈の分析: ファンタジーズはレベルの高いメンツで固め、練度の差は小さい。押し込まれた理由は、カズマの疲労と、''明確な弱点のない同等以上の「統率」型との経験不足''（いつかぶつかる''自分たちと同じタイプのチームの相手という壁''）。

- **最終成績: 5勝1敗で準優勝**（ファンタジーズが6戦全勝で優勝）。ルーキーチームが''中位''3チームを破った快進撃に、会場から拍手が送られた。決着後、カズマは廊下に疲労で倒れ込み、満足した選手は一人もいなかった。最終的な星取表: ファンタジーズ6勝0敗、ミラクルズ5勝1敗、クラッシャーズ4勝2敗、アンブラハンズ3勝3敗、スマッシュ2勝4敗、ネプテューヌ1勝5敗、クロスユナイト0勝6敗。作者: PC操作3連勝の結果をひっさげ、先に進む。（出典: 269）
