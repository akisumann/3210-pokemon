## 第45話「レヴィ・ザ・スラッシャー戦その１」 → source/045_第45話「レヴィ・ザ・スラッシャー戦その１」.txt
1. シーズン開始を翌週に控えた某日、ポケモンリーグに最も近い街**ナギサシティ**で練習試合。モモも同行。三雲修と、彼の『エース』ティアナに会う。エネルがキリン（古龍、要統率A）に乗ってレヴィと登場。
2. 1戦目はカズマ対レヴィ（初の6vs6）。カズマの『固有』は十中八九発動できるところまで仕上がっていた。
3. レヴィの『固有』『**雷刃の襲撃者**』（場に出す味方を「充電」状態にする）。カズマも『この素晴らしい仲間に祝福を！』を実戦で初発動する。
4. ガブリアスが『トップバッター』で先発し、ライオットと、「ドラゴンハウル」で引きずり出したケンプファーを倒して倒れる（『戦闘続行』）。マックイーンが『二枚看板』＋「きょううん」の急所でエレキブルを一撃し、『芦馬娘の凱旋』で下がる。ライナーが出て、相手が残り3体になり「ここぞ！」。レヴィの『エース』ブルー・ナイトが登場。
5. 修とモモが心の声でカズマとレヴィの「指示」を推し量る中で、世界の法則が示される: バッジ3つクラス以上（資質の影響が出始めるプロ資格持ちのステージ）では、【相手との「指示」ランクひとつにつき、高い方に常に「C+1」が加算されることになる】。

## 第46話「レヴィ・ザ・スラッシャー戦その２」 → source/046_第46話「レヴィ・ザ・スラッシャー戦その２」.txt
1. ライナーが『エースキラーβ』でブルー・ナイトの「充電」込みの「サンダーランス」を半減して耐え（ブルー・ナイト「半分以下だと」）、急所の「いわなだれ」で「ふうせん」を割る（ライザ: こっちが「じめん」じゃないのもバレたが、あっちの「充電」も解除された）。T7、カズマの『固有』の変更対象を安価で「相手」にし、ブルー・ナイトの「たちさばき」（2割で回避）を「きょううん」に変えて回避を封じ（ライナー「悪いが、回避させてやるつもりはねぇなぁ！！！」）、「アイアンヘッド」を受けてから「だいちのちから」で深刻なダメージ。ブルー・ナイトは『もどれ！』で下がる。ライナーは雷の「ボルトチェンジ」に耐え、ロクショウに「いわなだれ」を当てるが、「ギアソーサー」で倒れる。
2. イカルガが『アヴェンジャー』でロクショウと雷を倒す。ブルー・ナイトと『たえろ！』同士の撃ち合いになり、イカルガが倒れる。自陣が残り3体で「ここぞ！」。
3. マックイーンが『プリティーダービー』の「でんこうせっか」でブルー・ナイトにとどめ。**レヴィに勝利**（残り3体）。
4. レヴィのデータが公開される（指示C／育成C／統率B／能力A）。

## 第47話「三雲修戦その１」 → source/047_第47話「三雲修戦その１」.txt
1. レヴィ戦の経験値でマックイーン、イカルガがLv47、ライナーがLv43、ガブリアスがLv44に。
2. 2戦目は修対レヴィ。修の『固有』『**貫くべき覚悟と信念**』（味方の技が「いまひとつ」のとき威力1.5倍）と、プロ仕様の『**熟達指令**』（効果のターン制限がない『指令』）が出る。修が勝ち、手持ちは全員Lv45以上、『エース』ティアナと『先発』ジャンク・ウォリアーは50に届いているかも（ライザの見立て）。
3. 修がそのまま連戦を申し出て、3戦目はカズマ対修（戦闘準備は安価の案から1D9:1で>>3180）。先発ガブリアスは『トップバッター』（安価で「速」）、ジャンク・ウォリアーは『鬼人』で「攻」。カズマは『固有』の変更対象を安価で「相手」にして「てつのこぶし」を「きょううん」に。T1、ガブリアスの「かえんほうしゃ」を『よけろ！』でかわされ、『熟達攻撃指令』＋「きあいパンチ」で一撃で倒される（『たえろ！』は安価で「しない」）。
4. イカルガが『アヴェンジャー』（安価で「防」）で出て、カズマはまた『固有』でジャンク・ウォリアーの特性を「きょううん」に。T2〜T3の「ねっぷう」2発でジャンク・ウォリアーを倒す（「かえんだま」で自分も「火傷」、「ねつぼうそう」が発動）。T4、『特攻指令』と『エーテルリアクタ』の回復のあと「エアスラッシュ」でイフリートに深刻なダメージ（イフリートは「パワフルハーブ」の「ソーラービーム」）、T5の「とんぼがえり」で倒す。マックイーンが『二枚看板』で出て、修はネルスキュラを出す。**カズマ5体・修4体で続く**（カズマ「こっからは、俺たちのターンだ！！！」）。

## 第48話「三雲修戦その２」 → source/048_第48話「三雲修戦その２」.txt
1. マックイーンがネルスキュラ（むし／どく、モンハン種）に「すてみタックル」で押し込むが（T6）、「しめつける」と『かわせ！』（T7。マックイーンは『回復指令』と「スターのみ」でしのぐ）、『たえろ！』（T8の『プリティーダービー』の「でんこうせっか」）でしのがれ、「どくづき」で倒される。修の四式は『もどれ！』だけに。
2. イカルガが『アヴェンジャー』（安価で「速」）で出て、T9に「かげうち」を受けてから「エアスラッシュ」でネルスキュラを倒す。修が残り3体で「ここぞ！」、『エース』ティアナ・ランスターが出る。T11、イカルガは「ふいうち」を『たえろ！』（安価）で耐えて「とんぼがえり」（『バリアジャケット』で緩和されて特大のダメージ）、ライナーに交代。
3. 修は『もどれ！』でティアナを下げ、ポリゴンZを出す。ライナーが『よけろ！』と「アームハンマー」2発（T12〜T13）でポリゴンZを倒すが、T14にサザーランド（KMF種、ノーマル／じめん）の急所「ドリルライナー」で倒れる。自陣が残り3体で「ここぞ！」。
4. ルサルカが「ねこだまし」（T15）とT16の「だくりゅう」でサザーランドを削り、同じT16（「4」の倍数T）の『ナハツェーラー』の追加行動「のろい」で倒す。T17、ティアナに「イバンのみ」で先制して「したでなめる」で麻痺させ、倒れると『水魔女の束縛』で相手の「速」を下げる。
5. 最後にガッシュ。『不動のエース』と『エースアシストα』が同時に発動し、カズマの『固有』も2回発動（ガッシュの特性と、ティアナの特性「けんせい」の両方を「きょううん」に）。T18、「はたきおとす」でティアナを倒し、**修に勝利**（残り2体）。ティアナの持ち物は「ピントレンズ」だった（「ピントレンズ」破壊：技1.5倍）ので、カズマは「こいつ、もしかして俺の「きょううん」を利用するつもりだった……？」と思う。
6. 修のデータが公開される（指示B／育成B／統率B／能力B）。

## 第49話「統率型の戦い方」 → source/049_第49話「統率型の戦い方」.txt
1. 練習試合2連勝。経験値でガッシュLv48、マックイーンLv48、イカルガLv52、ルサルカLv44、ライナーLv45に。
2. 修、レヴィ、エネルが統率型の強さを語る。『役割』の豊富さがそのまま手札の多さになり、制圧力は他の資質を大きく上回る。他の資質は最終的に『エース』が場を切り開くことが多いが、統率型は『エース』にたどり着く前にパーティ全体の圧力で押し切ることも多い。正面から対抗するには、同じ統率型か、より純度の高い育成型が必要（エネル談）。
3. 圧力で相手の数や『指令』を消耗させ、『エース』や残りの面子で刈り取る――この2戦が今後の統率型の戦い方の指標になった。エネルは「いずれ私と戦うときにそのガブリアスを出すなら本気で殺しに行く」と宣言する。
4. 作者: 練習試合も終わり、いよいよシーズン突入（四つの季節ごとに良い戦績を収め、目指すは最高峰の''ポケモンリーグ''）。シーズン開幕〜デビュー戦までのフリーイベント（3D8:17）: 2「ダージリン、スポンサーゲットしたぞ我ぇ！！！」（→051）、8「エールから夜中に着信が大量に……コッワ！？」（→050）、7「デビュー戦の舞台の街が決まったようだし、下見に……」。

## 第50話「エールの固有」 → source/050_第50話「エールの固有」.txt
1. シーズン開幕3日前の夜、カズマはまだ『熟達指令』を習得できていない。エールから鬼電があり（カズマは出るなり「ぁあああ…！（絶叫）」と叫び返し、エール「耳が、ボクの耳がぁあ…」。外のライザに「何をデカイ声出し取るんじゃ」と怒鳴られる）、先延ばしになっていた打ち上げに呼び出される（奢りはエールのチーム持ち）。タツマキとラハールも参加。
2. エールの統率はC。タツマキ（要統率B-）が従っているのは、「能力：A」以上のトレーナーには必要な統率が1ランク下がるから。資質は成長するものらしい。
3. エールの第一『固有』『**授けられし裁きの権能**』: パーティ全員が「技能拡張：さばきのつぶて」を出せる。「**技能拡張**」は覚えていない技を出すこと。技によっては「能力：C」から持てるが、強力な技や自分しか出せない技は「能力：B」以上が多い。「能力：A」以上になると『固有』を2〜3個持てる（レヴィもこれから増えるはず）。エールの『固有』は「能力」型としては異質で、レヴィのようなのが標準。
4. 自分以外のすべてのタイプに「ばつぐん」を取れる「**ダーク**」タイプの技も存在する（高位の「能力」型が一発だけ、というレベル）。
5. エールのチーム名は《**進化研ユニバース**》（ナナカマド博士が命名。「ユニバース」は森羅万象、「進化研」は初代ナナカマド博士が進化を研究していたから）。『エース』はラハール。翌日、地下大洞窟で『熟達指令』を教わる約束をする。
6. 2回目のフリーイベント（3D8:12。2が重なったので1D6:6で繰り上げ）: 2「じてんしゃ（ライザ号）のサドル整備中、謎の人物の影が…」、8「ハクタイを訪れていた記者さんと遭遇、よっしゃ宣伝のチャンスや！」（→053）、「何やら''ポケスロン''という競技の記事を見ているマックイーン発見伝」。作者: この3つにダー様、デビュー戦の街訪問を、スケジュールを調整しながらデビュー戦に向かう。
