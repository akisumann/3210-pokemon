## 第45話「レヴィ・ザ・スラッシャー戦その１」 → source/045_第45話「レヴィ・ザ・スラッシャー戦その１」.txt
1. シーズン開始を翌週に控えた某日、ポケモンリーグに最も近い街**ナギサシティ**で練習試合。モモも同行。三雲修と、彼の『エース』ティアナに会う。エネルがキリン（古龍、要統率A）に乗ってレヴィと登場。
2. 1戦目はカズマ対レヴィ（初の6vs6）。カズマの『固有』は十中八九発動できるところまで仕上がっていた。
3. レヴィの『固有』『**雷刃の襲撃者**』（場に出す味方を「充電」状態にする）。カズマも『この素晴らしい仲間に祝福を！』を実戦で初発動する。
4. ガブリアスが『トップバッター』で先発し、ライオットと、「ドラゴンハウル」で引きずり出したケンプファーを倒して倒れる（『戦闘続行』）。マックイーンが『二枚看板』＋「きょううん」の急所でエレキブルを一撃し、『芦馬娘の凱旋』で下がる。ライナーが出て、相手が残り3体になり「ここぞ！」。レヴィの『エース』ブルー・ナイトが登場。
5. 修とモモが心の声でカズマとレヴィの「指示」を推し量る中で、世界の法則が示される: バッジ3つクラス以上（資質の影響が出始めるプロ資格持ちのステージ）では、【相手との「指示」ランクひとつにつき、高い方に常に「C+1」が加算されることになる】。

## 第46話「レヴィ・ザ・スラッシャー戦その２」 → source/046_第46話「レヴィ・ザ・スラッシャー戦その２」.txt
1. ライナーが『エースキラーβ』でブルー・ナイトの一撃を半減して耐え、「だいちのちから」で大ダメージ。ブルー・ナイトは『もどれ！』で下がる。ライナーは雷の「ボルトチェンジ」に耐え、ロクショウに「いわなだれ」を当てるが、「ギアソーサー」で倒れる。
2. イカルガが『アヴェンジャー』でロクショウと雷を倒す。ブルー・ナイトと『たえろ！』同士の撃ち合いになり、イカルガが倒れる。自陣が残り3体で「ここぞ！」。
3. マックイーンが『プリティーダービー』の「でんこうせっか」でブルー・ナイトにとどめ。**レヴィに勝利**（残り3体）。
4. レヴィのデータが公開される（指示C／育成C／統率B／能力A）。

## 第47話「三雲修戦その1」 → source/047_第47話「三雲修戦その1」.txt
1. レヴィ戦の経験値でマックイーン、イカルガがLv47、ライナーがLv43、ガブリアスがLv44に。
2. 2戦目は修対レヴィ。修の『固有』『**貫くべき覚悟と信念**』（味方の技が「いまひとつ」のとき威力1.5倍）と、プロ仕様の『**熟達指令**』（効果のターン制限がない『指令』）が出る。修が勝ち、手持ちは全員Lv45以上、『エース』ティアナと『先発』ジャンク・ウォリアーは50に届いているかも（ライザの見立て）。
3. 修がそのまま連戦を申し出て、3戦目はカズマ対修。先発ガブリアスが、『熟達攻撃指令』＋『よけろ！』＋「きあいパンチ」で一撃で倒される。
4. イカルガが『アヴェンジャー』で出て、「ねっぷう」でジャンク・ウォリアーを倒し、『エーテルリアクタ』で回復しつつイフリートも「とんぼがえり」で倒す。マックイーンが『二枚看板』で出て、修はネルスキュラを出す。**カズマ5体・修4体で続く**。

## 第48話「三雲修戦その2」 → source/048_第48話「三雲修戦その2」.txt
1. マックイーンがネルスキュラ（むし／どく、モンハン種）に「すてみタックル」で押し込むが、「しめつける」と『かわせ！』『たえろ！』でしのがれ、「どくづき」で倒される。修の四式は『もどれ！』だけに。
2. イカルガが『アヴェンジャー』で出て、ネルスキュラを倒す。修が残り3体で「ここぞ！」、『エース』ティアナ・ランスターが出る。イカルガは「ふいうち」を『たえろ！』で耐えて「とんぼがえり」、ライナーに交代。
3. 修は『もどれ！』でティアナを下げ、ポリゴンZを出す。ライナーが『よけろ！』と「アームハンマー」2発でポリゴンZを倒すが、サザーランド（KMF種、ノーマル／じめん）の急所「ドリルライナー」で倒れる。自陣が残り3体で「ここぞ！」。
4. ルサルカが「ねこだまし」「だくりゅう」でサザーランドを削り、4ターン目の『ナハツェーラー』の追加行動「のろい」で倒す。ティアナに「イバンのみ」で先制して「したでなめる」で麻痺させ、倒れると『水魔女の束縛』で相手の「速」を下げる。
5. 最後にガッシュ。『不動のエース』と『エースアシストα』が同時に発動し、カズマの『固有』も2回発動（ガッシュの特性と、ティアナの特性「けんせい」の両方を「きょううん」に）。「はたきおとす」でティアナを倒し、**修に勝利**（残り2体）。ティアナの持ち物が「ピントレンズ」で、カズマの「きょううん」を利用するつもりだったと気づく。
6. 修のデータが公開される（指示B／育成B／統率B／能力B）。

## 第49話「統率型の戦い方」 → source/049_第49話「統率型の戦い方」.txt
1. 練習試合2連勝。経験値でガッシュLv48、マックイーンLv48、イカルガLv52、ルサルカLv44、ライナーLv45に。
2. 修、レヴィ、エネルが統率型の強さを語る。『役割』の豊富さがそのまま手札の多さになり、制圧力は他の資質を大きく上回る。他の資質は最終的に『エース』が場を切り開くことが多いが、統率型は『エース』にたどり着く前にパーティ全体の圧力で押し切ることも多い。正面から対抗するには、同じ統率型か、より純度の高い育成型が必要（エネル談）。
3. 圧力で相手の数や『指令』を消耗させ、『エース』や残りの面子で刈り取る――この2戦が今後の統率型の戦い方の指標になった。エネルは「いずれ私と戦うときにそのガブリアスを出すなら本気で殺しに行く」と宣言する。

## 第50話「エールの固有」 → source/050_第50話「エールの固有」.txt
1. シーズン開幕3日前の夜、カズマはまだ『熟達指令』を習得できていない。エールから電話があり、先延ばしになっていた打ち上げに呼び出される（奢りはエールのチーム持ち）。タツマキとラハールも参加。
2. エールの統率はC。タツマキ（要統率B-）が従っているのは、「能力：A」以上のトレーナーには必要な統率が1ランク下がるから。資質は成長するものらしい。
3. エールの第一『固有』『**授けられし裁きの権能**』: パーティ全員が「技能拡張：さばきのつぶて」を出せる。「**技能拡張**」は覚えていない技を出すこと。技によっては「能力：C」から持てるが、強力な技や自分しか出せない技は「能力：B」以上が多い。「能力：A」以上になると『固有』を2〜3個持てる（レヴィもこれから増えるはず）。エールの『固有』は「能力」型としては異質で、レヴィのようなのが標準。
4. 自分以外のすべてのタイプに「ばつぐん」を取れる「**ダーク**」タイプの技も存在する（高位の「能力」型が一発だけ、というレベル）。
5. エールのチーム名は《**進化研ユニバース**》（ナナカマド博士が命名。「ユニバース」は森羅万象、「進化研」は初代ナナカマド博士が進化を研究していたから）。『エース』はラハール。翌日、地下大洞窟で『熟達指令』を教わる約束をする。
