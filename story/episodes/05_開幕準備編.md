## 第36話「スポンサー決定」 → source/036_第36話「スポンサー決定」.txt
1. イカルガが仲間になる（6体目）。ダンジョン出身のヌシを従えるには統率B以上が必要。エールと連絡先を交換し、スポンサーが決まったら打ち上げを奢ってもらう約束をする。
2. イカルガに乗って、テンガン山を避けて南から回り、翌日ハクタイへ。ゼットンに迎えられ、アカネの家へ戻る。アカネは成果に仰天し（「3つめくらいで挫折すると思ってたのに！！？」）、「賭けは賭けだから、もいっこのスポンサーの方はまだ続いてる」としつつ、ハクタイでスポンサーになりそうな企業の候補を教える。ゼットン「なぁマーズ、もうお前の負けで良いんじゃないか？」。
3. 10日間、スポンサー探しで落ち続ける。凜に泣きつくが、「ちきゅうなげ」で放り出される。
4. ライザに呼ばれて探検堂へ。地下おじさんがプロリーグのスポンサー登録を済ませていて、カズマは即採用される。**スポンサーは探検堂**。賭けの条件を両方達成。
5. フリーイベント（3D8:8と繰り上げ1D6:4）: ライザと地下に行く、「あれは……フカマル！！？」、コトブキシティ。作者: カズマさんは半端に人の下で働かされるより、ある程度の権限を与えて自由に動かした方が良い結果を齎すタイプ。フカマル系統に自信ニキと大都市コトブキで遭遇する予定。

## 第37話「育成開始と新たな役割」 → source/037_第37話「育成開始と新たな役割」.txt
1. 約1ヶ月後のシーズン開幕に向け、地下大洞窟で育成開始。フカマルがガバイドに進化する。ライザがブリーダー（育成スタッフ）になる。
2. 目標は6体ともLv50前後（Cランクの下限）。4つ目のジムからはレベルが一気に上がる（ライザ「3つと4つには、深い溝があると心得たまえ」）。カズマは「育成：C」、ライザは「育成：A」。
3. プロでは『役割』がプロ仕様に強化される（『エース』→『不動のエース』）。統率型は倍くらいの種類の『役割』（『二枚看板』『アヴェンジャー』など）を使える。
4. 暫定の配置を決める: エース=ガッシュ、二枚看板=マックイーン、アヴェンジャー=イカルガ、アシスト=ルサルカ、キラー=ライナー、先発=ガバイド。

## 第38話「シンオウチャンピオンとの遭遇」 → source/038_第38話「シンオウチャンピオンとの遭遇」.txt
1. スポンサーが決まったので、カズマはアカネの家を出て、探検堂の物置小屋に住み込む（家賃なし）。「商売敵になったし、男女の同居はマズイ（建前）」。アカネは「なんでぇ！」と取り乱し、最後に「カズマのバカァ！」と叫ぶ。カズマは「3日以内にまた来る」と言い残して走り去る。ゼットンはついて行こうとしてルサルカに止められ、週1〜2の家事をバイト代つきで頼み込む。
2. ライザがたんけんセットをトレーナーズスクールへ納品しに行くので、カズマもついて行く（イカルガが運転手。くじ引きでガッシュとガバイトも同行。留守番はルサルカ、ライナー、マックイーン）。スクールの教師がクロガネ炭鉱の噂を聞いて興味を持ったらしい。
3. 納品はライザ一人に任せ、カズマたちはコトブキシティを見物する。露出の多い美女がガバイトに目を留めてカズマを喫茶店に誘う。カズマは逆ナンと思い込んで浮かれるが、ガッシュが正体に気づく。**ポケモンリーグ3連覇中のシンオウチャンピオン、ホーネット**だった。
4. 作者: シンオウでフカマル系列に反応しそうなキャラといえばまず浮かぶ人物で、前回のリーグでマーズ（アカネ）を下した相手。持ち帰って話すとアカネの機嫌が悪くなりそうだが、もう同じ屋根の下ではない。

## 第39話「有名人とたんけんセット」 → source/039_第39話「有名人とたんけんセット」.txt
1. ホーネットに連れて行かれた部屋には、今代のナナカマド博士・**碇ゲンドウ**、トレーナーズスクール校長・**ケイネス・エルメロイ・アーチボルト**、ナギサジム（でんき）のジムリーダー・**エネル**がいた。四人はこのあとテレビコトブキの番組に出る予定だった。
2. ゲンドウはエールが世話になった礼を言う（「アイツはボッチなんだ」）。ホーネットがカズマを連れてきたのは、今ではかなり珍しいガバイトを見かけたから。ガバイトの進化形は「古代の暴君」と呼ばれた古代種で、昔シンオウで無双したチャンピオンが使っていたという。Lv40を超える頃に進化するかもしれない。
3. 『オールドタイプ』は古代種が持つポテンシャルで、防護ポテンシャル（攻撃のダメージを緩和・無効化するもの）を無視する。カズマは知識がバッジのペースに追いついていないと言われる。
4. エネルはガッシュ種を連れていることに食いつき、ナギサジムの門下生との練習試合を持ちかける。ケイネスもスクールの卒業生（今年はスポンサーが見つからずデビュー見送り。実力はバッジ3つ水準）を参加させる。**後日ナギサシティで、2名と6vs6の練習試合**をすることになる。
5. カズマはたんけんセットを売り込む。ゲンドウがその場で100万円の現金で購入（「化石掘りは男の浪漫」）。ケイネスは名刺を渡し、スクールへの本格導入を前向きに検討すると約束する。
6. 昨季の本戦5チームがわかる（チャンピオンのカンナギタウンのチーム、ポケモンリーグの四天王、ギンガ団、テレビコトブキ、ミオ図書館）。納品を終えたライザには「サボってた」と怒られるが、100万円と名刺を見せると黙った。

## 第40話「コンテスト再挑戦」 → source/040_第40話「コンテスト再挑戦」.txt
1. 地下大洞窟での育成が進み、ガッシュ、マックイーン、イカルガはLv40に到達。残りも数日で40に届く見込み。
2. プロでは『先発』にも発展系がある（『鬼人』『狂走』『狩人』など、先発で出ると能力が1つ上がる）。統率型のカズマなら『**トップバッター**』（先発で出ると任意の能力値をぐーんと上げる）が使える。『アシスト』と『キラー』も発展する。
3. メアリから電話があり、ヨスガに誘われる。カズマはルサルカ、ライナー、マックイーンを連れて行き、残りの育成はライザに任せる（イカルガは送り迎え）。
4. ヨスガでやりたいことの安価（>>821〜823）で、ポケモンコンテストに再挑戦する（カズマ＆マックイーン「コンテストにリベンジじゃぁああ！！！」）。メアリが見た才能（ダイス）は、第一候補がルサルカ（かわいさ）15、マックイーン（うつくしさ）23＋30、ライナー（たくましさ）4。第二候補がルサルカ（うつくしさ）77、マックイーン（かわいさ）38、ライナー（かっこよさ）68。
5. **ルサルカが「うつくしさ」部門で、ライナーが「かっこよさ」部門で、それぞれノーマルランク1位**。マックイーンは出場部門のダイス（1D5:1）で「かっこよさ」になり、適性も4（1D100:4）で4位。メアリに特訓を頼み、「やる気がある子はウェルカムよ、ただしスパルタで行くけどよろしくね？」。メアリはマックイーンが『二枚看板』になっていることにも気づいた。賞金でメアリに昼食をおごることになり、モスバーガーを持ち帰りで買って「ふれあい広場」へ。作者: この一連のイベントとハンサムさんの件が終われば、3回目のフリーから練習試合の予定。

## 第41話「固有ポテンシャルとチーム名」 → source/041_第41話「固有ポテンシャルとチーム名」.txt
1. カズマはノモセジム戦で相手の特性が変わった現象をメアリに相談する。それはトレーナーの「能力」によるもので、トレーナー自身がバトルに影響を及ぼす力を『**固有**』ポテンシャルと呼ぶ。メアリ自身は「能力：AA」。
2. メアリの見立てでは、カズマの「能力」は運と密接に絡んでいる。力がきちんと目覚めれば、味方の特性を「きょううん」に変えることもできそう。ただし敵味方とも、ごく短い時間しか影響しない。
3. 「能力」型はバッジ3つの前後で『固有』が形になることが多い。ほかの型も、プロのステージに立つ頃には大多数が習得している（メアリ「………………応援してるわよ、カズマ」）。
4. プロリーグのチームは、スポンサーの名前を入れた《**チーム名**》を持つ（「戦う広告塔」）。トレーナーやチームの個性を表す名前が多い。ライナーは《探検ライナーズ》、マックイーンは《目白マックイーンズ》を提案して却下される。ふれあい広場でハンバーガーを食べながら、ルサルカと一緒に案を出し合う。チーム名は《探検○○》か《探検堂○○》の○○を安価で募集（作者の独断で決定）。作者: ハン・サムさんの件は次のイベントに持ち越し。

## 第42話「ガブリアス進化とミラクルズ」 → source/042_第42話「ガブリアス進化とミラクルズ」.txt
1. 練習試合の前のフリーイベント（3D8:17）: 6「しぶりんのお宅訪問」、7「ライザ「そういや私、ハクタイジムの門下生だわ」」、4「メアリの次は奏さんが」。週末の練習試合に向けて最終調整。ライザがジムの門下生として持っていた「わざマシン：エナジーボール」をカズマに貸す（渡し忘れていた）。
2. ライザの「育成」で、全員のレベルと技が上がり、ポテンシャルも倍程度に増えた。『役割』がプロ仕様に発展した。『不動のエース』（ガッシュ）、『エースアシストα』（ルサルカ）、『エースキラーβ』（ライナー）、『二枚看板』（マックイーン）、『トップバッター』（ガバイト）、『アヴェンジャー』（イカルガ）。
3. **ガバイトがガブリアスに進化**（Lv40）。『エキスパンション（龍）』込みで体力はAA-くらい。レベル以外はほぼ手つかずなのに、合計種族値はイカルガと同格以上。
4. 6体のデータがそろう。ガッシュ Lv45、ルサルカ Lv40、マックイーン Lv45、ライナー Lv40、ガブリアス Lv40、イカルガ Lv45。
5. チーム名は《**探検堂ミラクルズ**》に決定（ルサルカと相談し、ガッシュが賛成）。カズマは運が絡む部分が大きいらしいので「ミラクル（奇跡）」。

## 第43話「固有ポテンシャルとしぶりんの依頼」 → source/043_第43話「固有ポテンシャルとしぶりんの依頼」.txt
1. 天羽奏が探検堂に遊びに来る。奏は「シンフォギア」種のポケモンとのハーフで、人間側の血が濃いタイプ（ティファニアはポケモン側の血が濃い）。「トレーナーと手持ちの色恋沙汰でガタガタになるチームも普通にある」。
2. 統率型の奏に『固有』の相談をする。「能力」のランクは強さだけでなく**発動のしやすさ**にも影響し、「能力：C」のカズマには**条件付け**（難しく、才能に合った発動トリガー）が必要。統率型のトリガーは多くの場合『役割』。
3. カズマの『固有』の形が見える: 『**この素晴らしい仲間に祝福を！**』（味方の『役割』の発動時、ターン終了時まで場のポケモン1体の特性を「きょううん」にする）。ノモセジムで発動したのはガッシュの『エース』に反応したものらしい。「能力：C」で敵味方を選べるのは珍しい。統率型の『固有』には「もう少し先」がある。奏に昼食（パスタ）を奢ってもらう。
4. 翌日、凜の散らかった部屋に呼び出される。掃除の報酬として、①カズマのチームに興味があるハクタイジム所属ポケモンのリスト、②凜から見た育成プラン、③デート（凛のデート意識度は1D100:73。最低でも割り勘、後日）を約束させる。その夜、くさタイプのポケモンのリストが届く。作者: ジム所属の「くさ」ポケモンを安価で募集（参戦はデビュー戦の後の想定。それまではお手伝い的なポジション）。

## 第44話「モモと国際警察」 → source/044_第44話「モモと国際警察」.txt
1. 凜とのデート（笑）に、リストから選んだ**モモ・ベリア・デビルーク**（くさ／フェアリー）がついてくる。ハクタイジムから探検堂へ**移籍**し、7体目になる。しばらくは店とライザの手伝い。
2. 凜いわく、手持ちは最終的に10〜12体くらい、デビューしてからシーズンの四半節「第一節」の間はもう1体くらいでいい。
3. 統率型が任命できる『役割』は現状9つ。基本役割（『エース』『アシスト』『キラー』『先発』。ただし『トップバッター』は統率型のみ）と、統率型だけの追加役割（『二枚看板』『アベンジャー』『**エンチャンター**』『**チェイサー**』『**スカウター**』）。モモの適性は『エンチャンター』か『チェイサー』。
4. 練習試合の相手が判明: ナギサジムの門下生で「能力」型の**レヴィ・ザ・スラッシャー**（10〜11歳、バッジ3つクラス）と、スクール卒業生で「万能」型の**三雲修**（スポンサー未定）。
5. ギンガハクタイビルを見ていた国際警察のエージェント「**ハンサム**」（コードネーム）と出会う。口止め料として「ボコのみ」「マジュのみ」をもらう。
6. ギンガ団の社長は**先代シンオウチャンピオン**。コードネーム「**アカギ**」、本名**アダム・ヴァイスハウプト**。夜の公園で酔って全裸で前転しながら叫んでニュースになったことがあるが、強さは本物。最後にテンガン山の深度4を攻略した人で、先代の『テンガンのヌシ』を持っているはず。ハクタイの森の深度4も踏破済み。ギンガ団のチームはチャンピオン奪還を狙っている。
7. 凜いわく、深度4に挑むならせめてAランクになってから。ハンサムはいつの間にか消えていた。凜と昼食を取ってデート（笑）は解散。
