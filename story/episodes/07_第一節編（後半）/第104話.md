# 第104話「呪相カースメーカー戦その３」 → source/104_第104話「呪相カースメーカー戦その３」.txt

1. 直哉は『もどれ！』でカフェを下げ、『エース』玉藻の前を出す。玉藻の『愛の絆』で直哉の指示はAA+（カズマとは2ランク差）。

2. 直哉が「タイム」を使い、玉藻の専用『**水天日光天照八野鎮石**』（「タイム」使用時、全能力値1.5倍）が発動。『良妻狐の令呪』（特攻+1）、『固有』（速2倍）、『キャスター』（特防の上昇を無視）の急所「じんつうりき」を、マックイーンは『たえろ！』で皮一枚耐える。

3. マックイーンの専用『貴顕の使命を果たすべく』の「なぎはらう」を、玉藻は『たえろ！』で耐える。カズマは『もどれ！』でガッシュ・ベルを出す（『不動のエース』と『グッドラック』で特攻+2）。

4. 玉藻の「じんつうりき」を「特大@1」で耐え、『必中追尾』＋『バオウ・ザケルガ』の「でんじほう」で玉藻を倒す。最後のカフェの『プリティーダービー』＋『エースキラーα』の「でんこうせっか」を皮一枚耐え、「10まんボルト」で勝利。

5. 《呪相カースメーカー》の公開データ（指示A+／育成B-／統率D+／能力B。玉藻、ジバニャン、カフェ、ノロイダー、ジゼル、タナトス）。
