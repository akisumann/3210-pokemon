# 第143話「進化研ユニバース戦その1」 → source/143_第143話「進化研ユニバース戦その1」.txt

- **戦闘前の感覚**（142の投下後から143の戦闘準備まで。ユーザーが貼った読者のレスより）:
  - 前提: エールのチームは前の練習試合（067〜068）のデータがあり、『専用』6体でこの大会はメンバー固定と言われていたので、相手の6体と先発ドダイトスはほぼ読めていた。読者は専用まで一覧にして予想した（ラハールは『三角』、タツマキは追尾、キュゥべぇはタイプの書き換え、ドダイトスは「まもる」貫通、シンリュウはプレートがらみ、双子は場に出ると締め付ける形）。前の手持ちは攻めの種族値が高いぶん、耐久はドダイトスと双子が上限で低め、とも見ていた。
  - **解析班の気づき**（この試合の準備でいちばん大きかった読み。補足: ユーザーより）: 物理型のドダイトス（特攻C）が、特殊の「さばきのつぶて」を撃ってくる可能性に気づいた。気づきは4つの事実をつなげたもの。
    - 物理の効かないヤマト（『ギガントマキア』）に対して、エールは特殊に切り替えてくるはず（1937）。
    - 「さばきのつぶて」はプレートでタイプが決まる特殊技。
    - ドダイトスの専用は「草」技を強化する。なので、みどりのプレートを持たせれば、つぶてが「草」になって、一致と専用の1.5倍が両方乗る（2014、2016）。
    - そこに第二『固有』の「闘」が足されれば、「草/闘」の複合でヤマトの弱点を突く。
    - この読みのおかげで、ヤマトの持ち物は「物理は平気」から、特殊への備え（チョッキ・タスキ・マジュ）を比べる話になった。本番のT1でドダイトスは、まさにみどりのプレートと専用で「草/闘」のつぶてを撃ってきた（カズマ「こいつ、いきなりか………っ！！！」）。マジュのみで半減して耐えた。
  - 先発はヤマトで一致した。ドダイトスには一致の氷が4倍で、『ギガントマキア』で物理（攻の上昇）は怖くない。割れたのはヤマトの持ち物で、議論の中心になった。
    - とつげきチョッキ派: 『特防指令』と合わせれば、草プレートのドダイトスが専用（1.5倍）で撃つ「草/闘」のつぶても、ぎりぎり1発耐える、という計算が出た。
    - きあいのタスキ派: チョッキと特防指令を両方使ってHPが残らないのはもったいない。タスキなら特防指令を温存できる。ヤマトにはT3あたりで倒れてもらい、モモの「ひかりのかべ」につなぐ、という段取りの案もあった。
    - マジュのみ派: 体力の多いヤマトにタスキはもったいない。マジュ（2倍）は耐えきれない可能性もあるが、中間の択として出た。採用は、このマジュのみ。
  - エールの第二『固有』のタイプ予想が、もう1つの軸だった。読者が手持ち全員の耐性表を作り、候補は3つに割れた。
    - 氷: ガブリアス・モモ・イカルガに刺さる。
    - 闘: 前回暴れたヤマト・ライナーと、異名持ちで硬いマックイーンに刺さる。「ヤマトを対策しないはずがない」という読みで、これを推す声もあった。
    - 地: ガッシュに刺さる。
    - 結論は、始まるまで分からないので、どれでも対応できるように準備する。そもそも持ち物で変えられるのはヤマトとマックイーンくらいで、どれかを対策されても他が暴れるのがこのチームの形（142のアバンの解説）だ、という意見に落ち着いた。
  - ライナーを入れるかでも割れた。推す側は、ハードロック（弱点を緩和）で、壁やチョッキと組めば崩されにくい、と見た。退ける側の理由は3つで、退ける側が通った。
    - 相手は特殊が多く、ライナーは遅いので上から殴られる。
    - 交代のポテンシャルがないので、キュゥべぇに特性を書き換えられると止まる。
    - ガッシュがいるので『エースキラー』の必要が薄い。
    - 代わりに、闘を無効にしてキュゥべぇやラハールの小細工にも強いルサルカと、旋回でキュゥべぇから逃げられ、闘を1/4で受け、上から殴れるイカルガが選ばれた。
  - マックイーンは、こだわりハチマキかチョッキかで割れた。ハチマキ派は、キュゥべぇにタイプを変えられて『エキスパンション（ノ）』が乗らなくなっても火力を保てる、と見た。チョッキ派は、壁があるので火力は足りる、と見た。好みの範囲として、ハチマキに。キュゥべぇにはガッシュの「とくせいガード」。
  - 結果: エールは「闘」を選んだ（推していた読みが当たった）。ヤマトのマジュのみが、特殊の「草/闘」のつぶてを半減した。（出典: 142, 143）

3. マックイーン（『二枚看板』、『固有』で「きもったま」を「きょううん」に、『グッドラック』速+1）。「タイム」でゴースト交代かタスキを読むが、エールはウルゥル＆サラァナ（ノーマル/ゴースト）に下げて「なぎはらう」を無効にする。T6にマックイーンの専用「なぎはらう」は「測定不能」だがタスキで耐えられ、「ノ/闘」の「さばきのつぶて」と、双子の新しい専用『ふたりでひとつの鎖の巫』（「さばきのつぶて」の威力半減の追加攻撃）でマックイーンが倒れる。

（出典: 143）

4. 死に出しのモモが「こどもだまし」で双子を倒す（4-4）。シンリュウ（特性「トレース」で「いたずらごころ」をコピー、新しい専用『何色にも染まる無垢なる竜』でこうてつプレートの鋼タイプを足す）。モモは先に「ひかりのかべ」（ねんどで8T）を張り、「鋼/闘」の「さばきのつぶて」で@1になるが、『クォーターロゼット』の「やどりぎのタネ」でルサルカへ。ルサルカは「シャドーボール」でシンリュウを@1にし、「りゅうせいぐん」を壁で2割に抑え、「すてゼリフ」でイカルガへ（『アシストα』、『固有』、『グッドラック』攻+1、火傷）。4-4で次へ。
