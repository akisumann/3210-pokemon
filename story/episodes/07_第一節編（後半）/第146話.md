# 第146話「園生クインビーズ戦その1」 → source/146_第146話「園生クインビーズ戦その1」.txt

1. 決勝。選出: ガッシュ（だっしゅつパック）、マックイーン（こだわりハチマキ）、ルサルカ（ボコのみ）、ヤマト（ゴツゴツメット）、イカルガ（かえんだま）、先発ガブリアス（わざマシン「ステルスロック」）。作者によると、ホムラやカタクリなど敵の『エース』を片端から倒してきたことが『友情』につながった。
   - **戦闘前の感覚**（145の投下後から146の戦闘準備、開戦まで。ユーザーが貼った読者のレスより）:
     - 見えているのは5体で、先発（『トップバッター』）だけ情報がない。読者の予想の表は、不明の先発・砕蜂（スカウター？）・リオハート（ほのお/ドラゴン？、チェイサー）・ヲ級（みず、アヴェンジャー）・ロータス（でんき/ゴースト、二枚看板、専用『必中追尾』）・スピアー（むし/どく、エース、メガシンカ、タスキ）。先発の情報がないのでガブリアスは確定、ルサルカ・ガッシュ・マックイーンも確定、スピアーを確実に刈れるヤマトもほぼ確定で、問題は最後の1枠（イカルガ・モモ・ライナー）だった。
     - 最後の1枠: イカルガはアタッカー兼ガッシュへの回し役で一番無難。ただ『旋回』はほぼ敵を倒した後に出るので、マックイーンの『凱旋』と変わらず、狙った相手にガッシュを当てるならモモ（「ドレイン輪廻」）、という反論。ライナーは二枚看板のロータスを正面から潰せる（ロータスは「結構な鬼門」）が、それで終わり。三者とも、操祈の手持ちに明らかに不利な相手がいる。
     - ガッシュの持ち物で長く割れた。レッドカード案は、「こうげきしれい」の追撃をきあいで耐え、統率型の役割（アヴェンジャー・エース・二枚看板）を発動させずに、出てきた誰かに必中の「でんじほう」を当てられる、という理由。反対は、必中追尾は倒したい相手を逃がさないための戦法で、レッドカードはその相手を逃がしてしまう（アンチシナジー）、交代させた相手には追尾が乗らない、外れの相手（ロータスやスピアー）が出たら上から落とされる、というもの。結局は、ガッシュを倒したい相手（ヲ級かリオハート）にどう出すか、の話に移った。ルサルカの「すてゼリフ」から回すには、相手の速さが分からないのがつらい。
     - スピアーは、ほぼタスキで、ルサルカは死にかけでも『ストーキング』で捕まえられるので、「死ぬ直前のルサルカをスピアーの前に置けばいい」という声。ヤマトは4倍数T以外なら勝て、「たえろ」を使われても相討ち、とも。
     - 相手の持ち物の読み: 鈍足で高耐久のヲ級（アヴェンジャー）はレッドカードがかなり有り、リオハートは金冠を活かすオボンかゴツメ。除去技は、エースと二枚看板にはなさそうで、持つならヲ級（「あらいながす」）か砕蜂。だから金冠とエースに刺さるステロを撒きたいが、相手の火力が高くて撒く余裕がない、という悩みが続いた。
     - 操祈の『固有』で、こちらがかわしても「こうげきしれい」が飛んでくるので、今回はタスキもガッシュのきあいも死んでいる。アッキのみなら、こちらの四式のあとの「こうげきしれい」で確実に発動する、という案も出た。
     - 候補は3つ（>>4915 モモ・レッドカード／ルサルカ・オボン、>>4921 イカルガ・ステロ、>>4924 ライナー・オボン／ガブ・アッキ）。最後の1枠がライナー・モモ・イカルガのちょうど3択に分かれ、「過去1意見がバラバラ」。ダイスで>>4921（ガッシュ・だっしゅつパック、マックイーン・こだわりハチマキ、ルサルカ・ボコのみ、ヤマト・ゴツメ、イカルガ・かえんだま、先発ガブリアス・わざマシン「ステルスロック」）。>>4897、>>4903のステロ案を、>>4909がイカルガ（かえんだま）にしたもの。
     - 採用のあと: 『トップバッター』は攻上げで、速攻をかける（長期戦は相手の土俵）。図鑑次第だが、初手は『かわせ！』か『よけろ！』からステロが第一候補。除去を持つならヲ級か砕蜂。二枚看板のロータスはマックイーンかガッシュでないと厳しく、ガッシュはきあいが死んでいるので、序盤に『かわせ！』を切る運用だと落とされる危険がある。「ここまで圧力高くて詳細がわからなくて対応策も全然足りない戦いは初めて」。

2. 先発は『トップバッター』同士のガブリアス対砕蜂（むし/かくとう、『森のヌシ』）。砕蜂は専用『隠密機動部隊の心得』で「みがわり」を作り、「どくびし」と操祈の『固有』の「こうげきしれい」。ガブは「ほえる」でリオハート（桃色の巨大なドラゴン、『金冠サイズ』らしい）を引きずり出し、操祈は『もどれ！』。ガブは「ステルスロック」。

3. ブラック・ロータスの専用『必中追尾』＋『黒剣』の「アイスブレード」でガブが倒れる。死に出しのガッシュは「どくびし」で毒（死に出しなので『友情』は発動しない）。ロータスの「つじぎり」を『かわせ！』、専用『必中追尾』の「りゅうせいぐん」でロータスを倒す（5-5）。特攻が下がって「だっしゅつパック」でルサルカへ（先輩直伝。ルサルカも毒だが『ド根性』で1回目を無視）。

4. 再び出た砕蜂を「かげふみ」で縛り、「タイム」。『熟達回避指令』で「かげぬい」を外させ、「こうげきしれい」はボコのみで「微々たる」。急所の「ねっとう」で砕蜂を倒す（5-4）。死に出しの空母ヲ級（『アヴェンジャー』攻+2、新しい『深海空母の怨念』でルサルカの特性をT終了まで「よわき」に）から『エイヴィヒカイト』でドレイン。操祈は「これまで戦った誰よりも強い」と認める。
