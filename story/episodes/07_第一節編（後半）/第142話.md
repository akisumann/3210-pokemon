# 第142話「中規模大会後半戦展望」 → source/142_第142話「中規模大会後半戦展望」.txt

1. テレビコトブキのイメージガールのウタと解説のアバン（去年4位、指示型）が大会後半を展望。優勝争いは全勝のミラクルズとユニバース、1敗のスペリオールとクインビーズの4チーム。

2. クインビーズは『役割』『専用』『固有』は高水準だが、統率型としては種族値の高くない選手が多い「未完成のチーム」。ユニバースは『専用』持ち6体、唯一の第二『固有』、強力な技能拡張で「はまれば強い」が安定感は劣る。

3. ミラクルズは「チームワークを意識した統率型のひとつの形」。交代・『アシスト』・『エンチャンター』で単体の強さに+α。選手層は屈指で戦力が平均化し、誰かを対策してもほかが暴れる。ガブ、ライナー、ヤマトは素で600超え。『固有』が一見強くなく言動のせいでわかりにくいが、スペリオールに勝ったのも頷ける。育成の方向も「アタリ」。

4. 次は全勝同士の「新星激突」、ミラクルズ対ユニバース。
