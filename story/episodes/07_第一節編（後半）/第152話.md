# 第152話「中規模大会お疲れ様会」 → source/152_第152話「中規模大会お疲れ様会」.txt

1. お疲れ様会。千束とサムス（スーツの下は女性）、先輩とBB、エールとタツマキ、操祈とロータス、エレンとキャプテン・アメリカ、左門と才人、カズマとマックイーン（食べまくる）。エールは「友達が増えた」とご満悦。カズマは優勝者として調子に乗るが、先輩にはすぐ態度を変える。

2. Bから「指示：B」以上のトレーナーが使える『**全開指令**』: 1試合1回・先行で、1Tの間、対応する能力が2倍（『全開回復指令』は行動をスキップして体力1/2回復）。『熟達指令』より爆発力があり持続しない。これがBで「まもる」持ちが増える理由。試合前に『熟達』か『全開』を選び、純「指示：A」以上なら指令ごとに選べる「混成習得」。『絆』での指示A相当では不可。「指示：AA」以上にはさらに別の武器がある。

3. SPは「統率：A+」相当で『追加役割』1つ、「AA」相当以上で1〜2つ。何を付けられるかはSPの気質しだい。元統率型や、別の職業で統率の高い人もSPになる。「C」までは統率型以外の『チェイサー』は珍しかったが、Bでは読めなくなる。ポテンシャルで『役割』を得る「抜け道」もある（ポテンシャル1枠を使い、習得も難しい）。

4. 翌日、先輩はクロコダイン、エールはタツマキ、カズマはマックイーンを「そだてや」へ預ける。
