# 第115話「トバリジムへの挑戦」 → source/115_第115話「トバリジムへの挑戦」.txt

1. カズマ、ルサルカ、ガッシュがトバリジムに押しかける（「ジムバッジをよこせぇ！」）。イングリッドと、夜一、カタクリ（常識人）。

2. カタクリと夜一の4つ目仕様のデータ。残り4体はLv65くらいのかくとう統一。

3. ルサルカの専用『**魔女の与える鉄槌**』（『ストーキング』型）が完成。トバリジムのフィールド効果は「闘」技で相手を倒すと攻と防が上がる。

4. イングリッド「1〜2体に偏った強さのチームなど、そいつらを絡め取れば終わり」。有名になると戦い方も知られる（夜一に「カウンター」殺しをネタにされる）。
