# 第127話「ひみつきちと天花の元手持ち」 → source/127_第127話「ひみつきちと天花の元手持ち」.txt

1. カズマがホウエンの「**ひみつきち**」の文化を知り、自分も作りたくなる（ライザのロマン理解度 1D100:69）。候補地は（今考えた）「森の洋館」。

2. ライザいわく、森の洋館には第一節が始まったころから「見たことないポケモン」がいるという噂があり、最近は「違う姿」も目撃されている。カズマは「ひみつきち計画を脅かす悪霊戦士」と勝手に敵視し、ガッシュ、ライザ（書類仕事は天花に押しつけた）と洋館へ向かう。

3. 天花がアローラ時代の元手持ちに連絡。「ほのお／じめん」の『ベテラン』**グレンラガン**（『異名』持ち。「故障」があったが現役を続けられそう）と、「はがね／みず」の『スカウター』**エンタープライズ**（天花を「司令官」と呼ぶ）。2体とも財団を離れてからフリーで、レベルは落ちている。決めるのはカズマ。

4. 天花は書類の山に向かう。
