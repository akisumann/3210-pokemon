# 第154話「ナギサジムで育成相談」 → source/154_第154話「ナギサジムで育成相談」.txt

1. カズマがガッシュ、ガブリアス、ロトムを連れてナギサジムへ。レヴィは「じめん」タイプも「電」技で倒したい。エネルはガッシュの進化と『異名』を見抜き、自分がアローラで捕まえた「超がつくほど珍しい古代種」を見せる。ロトムのデータを見たエネルは「くれ！！！」（「コケコ」と同等以上かもしれない希少さ。「でんき」の『天賦』）。ジムにあるロトムの古文書を貸してもらう（ジムは育成機関でもある）。

2. ガッシュの育成について、エネルは「大声の独り言」として話す。技「**スタンガード**」（変化・電・自分。優先度+4の「まもる」系。相手の直接技を防ぐと麻痺させる。じめんタイプは麻痺しないが、「ちくでん」「ひらいしん」は無視する）。ほかに「かみなりあらし」の名前も出た。特性「**おうごんのからだ**」（相手からの変化技を無効にする。設置技や自分が対象でないもの、「みちづれ」「こころのめ」のような自分への状態変化は防げない）は、サイヤ人などが持つ特性で、ガッシュ種にも適性があるらしい（研究段階で何体か習得。個体差あり）。

3. エネルの「統率」論: 真っ向勝負に絞るより、相手の動きを制限し、自分は手札を持つ方がいい（ミラクルズではルサルカがその型）。『友情』で場に出る回数が増えるほど、「おいうち」や設置技や変化技にさらされる。

4. Bの「環境」: はがねタイプで防の高い『バウンス』が多く（「どんだけクソウザいか」）、『○○○の防衛』（攻撃していない時、相手の攻の上昇を無視）のような防護ポテンシャルを持つ。バウンスは『全開指令』の1Tを受ける対策でもある。Cから上がったトレーナーは「環境」の洗礼を受けることが多い。
