# 第221話「統率の頂点『エンペラー』」 → source/221_第221話「統率の頂点『エンペラー』」.txt

1. 週末のキッサキジム戦に、ガッシュの第三階梯『金雷児の帯電』（1/試/自動。体力1/2以下で「充電」状態）と『対地反撃』が間に合う（図鑑: Lv97、かみなりあらし／ゴールドラッシュ／インファイト／はたきおとす／でんじほう／スタンガード）。マックイーンとルサルカの「育成」はジム戦に間に合いそうにない。

2. カズマの懸念: ライナーとヤマトの超成長を見ると、ハクタイの森「深度：3」の『ヌシ』は基礎スペックで同格でもおかしくない。『野生の親玉』相手にはルサルカの『ストーキング』もライナーの『エースキラー』も発動しない。ただ逃げる対策（たんけんセットと「テレポート」）はある。

3. ロトムが受けたマーズからの電話で、翌日ギンガハクタイビルへ（ギンガ団社員A・Bと再会、実は優秀）。迎えたのはアダムの手持ちのカリオストロ（『錬金術師』、最古参）とアシュロン（『エンペラー』、先代『テンガンのヌシ』、「マムクート」種の『金冠サイズ』）。アダムは応接間で全裸でロトムを歓迎し、ロトムは''ギンガ団''創始者''アカギ''の友だったポケモンの系譜だと語る。

4. 『タイトエンド』と聞いたマーズは賭けでカズマごと引き込むことを考える。アシュロンが『エンペラー』（場に出た時、相手の任意の能力を下げる。相手の全能力値を0.85倍）と付随『キングオーダー』を見せる。任命には普通「統率：S」が要り、例外は『天賦の才』『異界のヌシ』古代の''伝説''（相応のリソースが要る）で、トレーナーの元々の「統率」A以上も必要。現役のリーグ所属ではシンオウに10体もいない。ジュピターの『異界のヌシ』が持ち、エネルの手持ちにもいる。詳しくは [world/potentials.md](../../../world/potentials.md)。

5. カズマが思い当たるのはメリュジーヌ（「バハムート」の『天賦』、今の『テンガンのヌシ』）とキーラ。アシュロン「''アイツ''なら完全に条件を満たしているな」。メリュジーヌはアシュロンの''後釜''で、クシャルをいじめているらしい（「俺の教育が間違っていたのか…………？」）。

6. System: いよいよ5番目のジム戦、vsキッサキの「こおり」使い''キジマ・シア''。作者: 次回はシアとのバトル前イベント。『エンペラー』とは第二節でぶつかることはまだない。
