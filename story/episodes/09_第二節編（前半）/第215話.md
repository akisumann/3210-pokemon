# 第215話「カンナギ杯優勝と番犬ガブリアス」 → source/215_第215話「カンナギ杯優勝と番犬ガブリアス」.txt

1. 決勝のレベルアップ: ガッシュ94→97、マックイーン92→94、モモ90→91、ルサルカ92→93、ガブリアス90→92（イカルガは経験値だけだったが、最後に作者が「シェオルも『異名』持ちだったしええやろ」と93→94に）。System: 終盤、ガッシュが『天賦の才』を退けて勝利を決定付けた。

2. 観戦歴の長い観客が「このバトルを決定づけた選手」と見たのはガブリアス。「ステルスロック」で、重要戦力の『三点防護』を持つバウンス（芳佳）がほぼ封殺された（「真っ先に倒れてなお、戦場に傷跡を残し続けた選手が影のMVP」）。ガブリアスに異名『**番犬**』（『先発』に任命されている時、相手からの強制交代を受けない）。System「''ナギサ杯''に続き、2つめの大会に優勝した《探検堂ミラクルズ》」。

3. ガブ『えっ！！？俺の『異名』って''「ステルスロック」の優先度を+1する''とかじゃないですか！！？』、カズマ「誰が喜ぶか、そんなもん」。ルサルカ「ヤマトのアイデンティティを返してあげなさい、犬っころは一匹で十分なのよ」、ガブ『でも姐さんなんかこの前「あ～、カズマのメス犬になってみてぇな私もな～」とかなんとか』。マックイーン「これでなんやかんや『異名』持ちが倍増しましたわ」、ガブ『自分、不器用ですから（技幅4）』。

4. うてなとレジーナが追いかけてくる。レジーナ「今からもっかい勝負しなさいよ！！！こっちは「ラムのみ」でなあっ」「じゃあ今度またヨスガに来なさいよ！！常識人の知り合いは貴重なのよ！！！！！」。うてなは電話番号の交換を申し出る（「（半分は）レジーナちゃんの希望ですよ、うへへへへへへ」）。「あつぞこブーツ」で走って足をくじき、下からパンツをのぞこうとして叩かれる。System: ガッシュに常識人の友達が増え、カズマに変態の知り合いが増えた。

5. 作者: カンナギ杯はこれで終了、5番目のジム戦に向けたフリーイベント。読者案から3D8で、4「しゃあっ、うなれメジロの剛速球！！」（マックイーンが「そだてや」での経験を活かして育成メニューに野球を混ぜ込む）、6「なにっ、ウチにいつのまにかファンクラブが？！」、1「しぶりんさぁ、ちょっとダンジョンアタックについて……しぶりん？」（作者「やきうユニフォームAAもあるしぶりん、貴様、ここでダンジョンアタック前に存在感を示すつもりか……？」）。
