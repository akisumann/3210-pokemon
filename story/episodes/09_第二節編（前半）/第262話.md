# 第262話「博物館アンブラハンズ戦その１」 → source/262_第262話「博物館アンブラハンズ戦その１」.txt

1. クロガネ杯の2戦目、《博物館アンブラハンズ》（ボンドルド）戦。戦闘準備はダイスで2番目の案（先発ガブリアス、全開）。ボンドルドのSPは石神千空（《博物館のDr.STONE》）。ライナー「俺を復元してくれたことは礼を言うが、それはそれとして勝たせてもらうぜ」。

2. 先発ガブリアスは、ボンドルドの固有で「岩」タイプにされてタイプ一致を奪われ、アニ・レオンハートの専用で「とおせんぼう」。「げきりん」で削るが、必中の「ばくれつパンチ」と「じしん」で倒れる（アニ「タイプ一致を奪われれば、技の威力は実質0.67倍」）。

3. 死に出しロトムが『天電球の共鳴』『ジョーカー』の「ハイドロポンプ」でアニを倒す（ボンドルド「やはり、天才でしたか………っ！！！！」）。アンティーク・ギア・ゴーレム（『金冠サイズ』）にステロを除去され、千空のサポート効果で「たつじんのおび」を見抜かれる。

4. ゴーレムの『もどれ！』でバイオトリケラ（タテトプスが『適応種』に進化）。ロトムは「トリック」でレッドカードを奪い、「アイアンヘッド」を『気合い』で耐えてレッドカードでバンギラスを引き出し、天花のサポート効果の「テレポート」でヤマトに交代（ヤマト「どんだけボクにばっか「メガシンカ」の相手押しつけてんだよ」）。5-5。作者: 天才がかき乱したので、まぁ有利と言って良い。
