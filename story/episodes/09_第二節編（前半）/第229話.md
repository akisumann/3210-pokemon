# 第229話「異界への道」 → source/229_第229話「異界への道」.txt

1. 時はさかのぼって、キッサキジム戦の少し前（218の「''おはなし''」）。ライザは凛の気持ちに見聞色の覇気で気づいたが、ダイス8で「ハクタイジムの師弟の絆」は崩れず（「喧嘩するよりは良いっしょ」）。ライザ「下手すればシンオウジムリーダー女性陣の中で一番残念じゃん」、凛「イングリッドさんよりはマシじゃ！！！！」。

2. 凛の最古参の『アシスト』リーフィアも登場。凛のライバルとして、衣食住を共にする『愛の絆』持ちのルサルカは強敵。ハクタイジムで最初に教えるのは丸太を持てるようになること（モモの「防：A」もそのおかげ）。

3. 凛は（カズマのポテンシャルの抜けを察しつつ）シア戦前のカズマに口を出しすぎたと思っている。リーフィアは内心、黙って「深度：3」を覗きに行ったことを思い出す（植物に体力とデータを奪われ、『ヌシ』らしいポケモンから''わざわい''じみた気配）。

4. ハクタイの森の「深度：4」の話: ジュピターが踏破した頃の群れにはベルゼブブ、オオナヅチ、バトルウルフ。今代の『ヌシ』は穏やかだが暴れると手がつけられない。「深度：4」の『ヌシ』はもれなく『第四階梯』。異界を制するトレーナーは地方最上ランクで、カズマにとってはリーグ直前の壁。

5. 凛「もし私がカズマの8番目の相手になるなら……その時は全力でぶつかるだけだよ」「カズマの道は、きっとその先に続いてるはずよ？」。作者: 次回から''ダンジョンアタック''、《探検堂ミラクルズ》vs《ハクタイの森：深度3の群れ》編。
