# 第03話「ジムリーダーはお化けが怖い」 → source/003_第03話「ジムリーダーはお化けが怖い」.txt

1. カズマとガッシュがハクタイジムを訪れる。カズマはジムリーダーの渋谷凛とアカネの愚痴で意気投合する。凛と親しいハーフのティファニア（テファ）にも会う。

2. 凛が「育成型」の教育力でカズマを教えることになる。ジムの試合場を見学し、ガッシュがチャンピオンを目指していることを聞く。約1時間、タイプ・特性・持ち物などの講義を受ける。

3. 古代種と現代種の区分を知る（ピカチュウは古代種の長老、ガッシュは現代種）。人間とポケモンのハーフがいること、アルセウスはシンオウの創造神として神話に語られていることも知る。

4. トレーナーの四つの資質（指示・育成・統率・能力）の説明を受ける。占いの本の結果、カズマの資質は「統率」とされる。超能力を持つ人間もいると知る。

5. カズマが凛のお化け嫌いをからかう。ティファニアに週一で泣いて帰ってくることをばらされた凛は、意地を張って、今晩カズマとガッシュを連れて「森の洋館」に行くと宣言する。アカネは面白がって「イケイケ！」と言う。
