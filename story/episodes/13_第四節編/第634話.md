# 第634話「呪相カースメーカー戦その1」（整理用タイトル） → source/634_第634話「呪相カースメーカー戦その1」.txt

ノモセ杯1戦目、直哉の《呪相カースメーカー》戦（T1〜T3）。先発ベルゼブモンがタナトスを倒すが、「のろい」と、マンハッタンカフェの『霊馬娘の黒影』の「混乱」で自滅。死に出しのリザードンがメガシンカ。

1. 戦闘準備（1D3:1で>>2821）: ガッシュ（だっしゅつパック）、マックイーン（マジュのみ）、オシュトル（とくせいガード）、リザードン（きあいのタスキ）、モモ（わざマシン「キングシールド」）、ベルゼブモン（おんみつマント）。先発ベルゼブモン、『全開指令』。フィールドは《ノモセスタジアム》（「炎」「岩」「地」の速0.85倍）。サポート効果は天花《戦場に舞う天御鳥命》と、直哉のSP花開院ゆらの《ジョウトから来た陰陽娘》（T終了時、低確率で相手を2T「かなしばり」）。天花: 「B」ランカーとはいえウチとの経験値は高い相手。ゆら「呪霊になっても直哉くんのことは好きでいたるさかい安心しぃ！！！！」。（出典: 634）
   - **戦闘前の感覚**（633の投下後から634の戦闘準備まで。ユーザーが貼った読者のレスより）:
     - 会場の《ノモセスタジアム》（「炎」「岩」「地」の速0.85倍）は、ガブリアス・リザードン・オシュトルに重い。ただ、相手は指示型で投射呪法（『指令』で速2倍）もあるので、マックイーンとイカルガ以外は上を取られる前提で考えよう、で落ち着いた。スカーフのリザードンで上を取る案も出た。今大会で唯一、平均レベルがこちらより大きく下の相手、というのも確認された。
     - 議論の中心はタナトス。「しにがみのかま」（相手の体力を半分）と『愚死神の呪詛』の「のろい」で、どんな大型にも削りを入れ、『愚死神の輪廻』で下がっていく。前の試合では先発を捨てる勢いで対処して不利になったので、早めに落としたい、で一致。
     - 先発で割れた。マックイーン案（ノーマルなので「しにがみのかま」が効かない。「プレッシャー」の速下げで「まけんき」が発動し、メジロ化でそのまま狩れる）、ガブリアス案（「ひかりのこな」と『トップバッター』の回避上げで、「げきりん」でタスキまで削りつつステロを撒く。接触の「しにがみのかま」には「さめはだ」）、オシュトル案（「しらはどり」で、タナトスからの打点が「ムーンフォース」しかない有利対面）、ベルゼブモン案。
     - マックイーン先発には、直哉もマックイーンが来ることは読んでいるはず、マックイーンは対エース（玉藻）に取っておきたい、という声も出た。王道の案（先発マックイーンにゴツゴツメット、イカルガ・ルサルカ・ライナー・ベルゼブモン・ガッシュ）は「大体これで良さそう」とされた。そのうえで変化球の案も考えよう、という流れに。
     - 変化球の一つが、だっしゅつパックのベルゼブモンを先発にして、「いかくしゃげき」と相手の「プレッシャー」の打ち合いのあとマックイーンへつなぐ案。ただ、ベルゼブモンを経由すると、相手の特性を「きょううん」にした時に急所が当たりやすくなるのが難点（先発・指示の差・きょううんでC+3）。
     - 採用された>>2821は、前の晩に書かれた「割と変化球」の案（>>2732）をそのまま持ってきたもの。提案者の意図は次のとおり。
       - ベルゼブモンは「おんみつマント」で、初手の「タイム」からの怯みを防ぐ。先発を殴り倒して、2番手を解析するまでが目標（前回のガブの役割）。
       - オシュトルは、「タイム」のために必ずいるベテランのマタムネか、ブラックサレナを持っていく。「とくせいガード」は、ジゼルの特性消しや、マタムネの「しらはどり」対策への備え。
       - メインは、モモで壁を張りつつ、必中が効かないリザードンで燃やすこと。リザードンはタスキで一撃を防ぎ、『かわせ！』などは遠慮なく使う。モモは技マシン「キングシールド」で強打に備える。
       - ガッシュはだっしゅつパックで緊急脱出の遊撃。この特殊の3体（リザードン・モモ・ガッシュ）で、データの見えていない相手を倒す。
       - 玉藻は『たえろ！』からの「ミラーコート」がきつい。そこで、マックイーンで「わざわいのおふだ」を逆に利用する（「まけんき」）。リザードンに『四式』を惜しまず、マックイーンを見せずに玉藻までたどり着くのが大事。
     - ダイスの候補は、>>2821（ベルゼブモン先発・モモ入り）、>>2827（ガブリアス先発）、>>2832（ガブリアス先発。クリアチャーム）。【1D3:1】で>>2821。直哉相手にモモを出すのは初めてで、ルサルカ抜きは久しぶり。
     - 採用のあと: T1は解析と必中の「じゃあくなほのお」でタナトスを沈め、次の相手も解析し、モモで場を整える、という流れで一致。サレナが死に出しで来たら、モモではなくリザードンか（ただ、オシュトルより先にリザードンを出すと晴れの扱いが難しい）。『かわせ！』を使わせる役がいないので、終盤のマックイーンが動かしづらい、という心配も出た。マックイーンは玉藻用で、「マジュのみ」と残した『よけろ！』で何とかする、という答えだった。
     - 玉藻との対面の計算も出た。マックイーンの「しんそく」は、『全開攻撃指令』と専用まで入れれば、「わざわいのおふだ」・防+2・「リフレクター」の上からでもワンパンできる。玉藻の特性で「まけんき」が発動して攻+2になるので、リフレクターを張られても行ける。相手の特性を「きょううん」にすると、急所の「とびげり」でマックイーンが落ちかねない。サレナの「とびだすなかみ」は、設置や「火の海」で削っておきたい。

2. T1: 先発ベルゼブモン（「いかくしゃげき」でタナトスの攻-1、タナトスの「プレッシャー」で速-1）対タナトス（『狩人』でC+1、『スターター』）。直哉「いきなり変則登用を………！！！」。ベルゼブモンの『スカウター』でタナトスを解析、『魔王虫の照準』で「ロックオン」、『魔王虫の魔銃』で防/特防0.85倍、カズマの固有の『グッドラック』で特攻+1。直哉: 自力が足りない奴らならそこまで怖くない『固有』に『PT』だが、どいつもこいつも並じゃない。（出典: 634）

3. 指示「じゃあくなほのお」: タナトスは『熟達回復指令』（満タン）と直哉の固有（投射呪法で速2倍）で先に「しにがみのかま」（ベルゼブモン@1/2）。「じゃあくなほのお」（ばつぐん、『対悪耐性』）の測定不能を「きあいのタスキ」で耐え、『愚死神の呪詛』で「のろい」をかけて**タナトスが倒れる**。ベルゼブモンは「呪い」。直哉「――――――決まっとる！！！来いや、カフェ！！！！！」でマンハッタンカフェ。天花: 『必中追尾』持ちの『エースキラー』で「呪い」のベルゼブモンを確実に仕留めに来た。（出典: 634）

4. T2: 指示「スカウター」は、カフェの『霊馬娘の黒影』（1/試/自動。データ解析を無効化し、相手を「混乱」）で無効、ベルゼブモンは「混乱」（『役割』も不発扱い）。続けて指示「全開回復」: ベルゼブモンは@3/4。カフェの『熟達攻撃指令』と「しんそく」（『Creeping Black』で「霊」タイプ、専用『差し迫る漆黒の幻影』で『必中追尾』）で大きなダメージ@1。「呪い」のダメージのあと、『スカウター』でカフェ（ゴースト/あく、特性「ほろびのボディ」、技「ポルターガイスト」「おいうち」「しんそく」「ナイトヘッド」「みちづれ」「ほろびのうた」）を解析。固有の『グッドラック』で攻+1。カズマ: ダージリンが正統派なら、こいつはトリッキータイプ。（出典: 634）

5. T3: 指示「むしのさざめき」。直哉は『もどれ！』でカフェを下げ、ベルゼブモンは「混乱」で自分を攻撃して**倒れる**（マタムネ「ようやく落ちましたか………まったく、想像以上の出費を…………！！」）。出てきたのはマタムネ。天花: これだけリソースを吐かせたなら充分有利、カフェのダメージはレベル差「10」以上なら火力増強系の持ち物か。死に出しはリザードン（「『もどれ！』を使ったこと、後悔させてやれ！」）: 専用『天衣無縫の焔の翼』でメガシンカ、『超炎龍の覚醒』で全1.5倍、「ひでり」で晴れ、『超炎龍の獄炎』で「火の海」。直哉（内心）: やっぱりこいつらの圧力は尋常じゃない、一体一体の重さがウチとは違う。作者: 『役割』含め、カフェではマックの火力にはまるで届かない。（出典: 634）
