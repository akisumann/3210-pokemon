# 第598話「ロトムの第四階梯構想とアローラ勢との別れ」（整理用タイトル） → source/598_第598話「ロトムの第四階梯構想とアローラ勢との別れ」.txt

フリーイベントの1つ「アローラ組にご挨拶」。帰りたくないとぐずるスカル団たちと別れ際に、美柑・恋（ルザミーネ）・紫・キリシュタリアたちに、ロトムの『第四階梯』の方向を相談する。「育成」型以外のレベルの到達点は「200」と聞く。

1. 帰りたくないアローラ組: 蓮（プルメリ）「アローラに帰りたくないぃいい！！！」、スカル団「あっちはデパート、こっちはスーパー！！！！」、グズマ（ドフラミンゴ）「（アローラ基準で）最先端の流行のジャージもこんな安く買えるんだぜっ」。蓮はゲーセンで借金でAV女優コースも見えた。美柑は最終日に凛と戦って負け、爽やかにお別れしたところだった。キリシュタリア: カプ・コケコはあのジムリーダー（エネル）の手持ちにいる限り帰ってこない（天花「守り神にも長期休暇は必要」）。グズマ「お前が「グズマ」の名を継げ……スカル団を率いてみる気はねぇか？」。恋は黒子に週一の「報告書」（黒子「ミラクル団の活動報告書ですね」）。ロトムが蓮にロトムフォン試作品その151（シンオウ産ソシャゲがプレイ可）を渡し、また借金コースに片足突っ込むことに。（出典: 598）

2. ロトムの『第四階梯』の相談: ロトム「隕石食ってからこう、やっぱりこういうデータ系の出力が上がってる気がする」。カズマが美柑にこっそりデータを見せる（美柑「『原始天賦』に『タイトエンド』に「トリコロール」……？」「あの、なんですかコレ？」）。恋: 「指示」型ならまずチームの中核に欲しい、狙う相手は『基本役割』の4種。ロトムが前に持っていた『ロトム図鑑』（1/試。相手のデータを解析）の話から、蓮の案は『共鳴』と連動して「同じ『役割』と対峙した瞬間、相手のデータを解析する」、美柑の案は「タイプ変換」（キリシュタリア「タイプが変わった時、同時に相手のデータを奪い取る」。「へんげんじざい」の選手ですら中確率だった）。恋: 器用さの極み、データ・電子系の生態、それらを合わせて使う容量が要り、出来るポケモンはほぼいない。カズマ「ロトムくん、じゃあ後者の方が難易度高いみたいだけどそっち頑張ってね」、ロトム「天才じゃなきゃ自信ないとこだけど頑張ってやるロト」。カズマ: 初手は「図鑑」が定石、欲しいのは後続のノーデータへの解析（美柑も同意見）。美柑（心の声）「せっかくの『第四階梯』をそんな簡単に……？」、凛にも「あいつだけは真似するな」と言われている。（出典: 598）

3. レベルの到達点: キリシュタリア: 『第四階梯』に加えチームの練度も「160」を超え、アローラならキャプテンやリーグ参戦級、“上限”もそう遠くない。恋: 美柑と同じレベルのチームはシンオウの「A」でも少なくない、リーグ級や五強を見たところ「育成」型以外なら「200」がある種の到達点、全員が「200」オーバーは地方屈指の高位「育成」型くらい、「深度：4」の『異界のヌシ』ですら「200」を超えていたという証言は聞いたことがない。グズマ: あるラインまで行けばレベルの上がるスピードは落ちる、それは「完成」に近づいている証明。カズマ「「育成」型以外が「200」超えを持ってたら、それはもう超級選手の証明に近い」「煉獄さんの全力全開はまず全員「200」はある」。キリシュタリア: 君たちの練度なら近く群れを撃破出来る「異界」も多いのでは。美柑は「異界」は絶対ゴメン（「ラナキラマウンテン」「ポニの大峡谷」「スーパーメガやす跡地」）。（出典: 598）

4. 別れ: 恋「今度来たらエーテルパラダイスで歓迎してあげるから、死んだりしちゃダメよ？」。美柑「いつかまたシンオウにきっと来ます、その時はリベンジするつもりなんで……負けないでくださいね？」（凛にだけは負けて良い）、カズマ「ダメだ、しぶりんにも勝たせて貰う」。グズマ「スカル団に入りたければいつでも言いな」。財団組は黒子経由、プルメリにはロトムフォンで連絡が取れる。このあと、スイーツ断ち中のマックイーンを「育成」していたライザに、ロトムの件を正式にお願いしに行った。作者: ここにきていよいよ上限値が明確になり最終章的な感じ、「やっぱグリーンさんって今戦って良い相手じゃなかったんやなって、ねぇ煉獄さんよ」。（出典: 598）
