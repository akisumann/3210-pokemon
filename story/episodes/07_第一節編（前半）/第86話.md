# 第86話「キッサキとたんけんセット」 → source/086_第86話「キッサキとたんけんセット」.txt

1. シアが探検堂に来る。イカルガとは「ロボット系」好きで気が合う。シアの育成のイメージは「機体の換装・改造」（凛は植物の飼育、ロビンマスクは肉体の鍛錬）。

2. キッサキシティ（町長など）が、たんけんセットに往来・物流・避難の3つの用途で興味を持っている。キッサキはテンガン山で隔てられた極北の雪の街で、交通手段の確保が難しい。ダンジョンなど危険な場所での緊急避難アイテムにもなりうる（ダンジョンで使えるかは未確認）。山岳救助隊のハイランダーも乗り気。本格的な話はオーナーの帰還と調査結果しだい。

3. バッジ3つで挑むなら、シアは『固有』を1つに絞り、Cランク上位仕様で戦う。ジムリーダーが本気で戦うのは8番目のジムだけで、ランクに影響するのはバッジ7つまで。順番は自由なので、シンオウ三強（エネル、ロビンマスク、イングリッド）は後回しにされがち。シアの手持ちのユキノオーが勝手に出てくる。

4. シアは終始上機嫌で帰る（カズマへの初期好感度1D50:37＋たんけんセット補正50）。そのあとルサルカが、練習試合のあとの**デート**を取りつける（ホテル検索中）。
