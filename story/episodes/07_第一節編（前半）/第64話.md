# 第64話「祝勝会と育成プラン」 → source/064_第64話「祝勝会と育成プラン」.txt

1. 探検堂で、少し遅れてソノオ杯準優勝の祝勝会。大会後、たんけんセットのレンタル客が早くも増えている。

2. モモとヤマトは練習試合に間に合いそう。ルサルカとマックイーンは特性の変更を求める（ルサルカは「あついしぼう」、無理と却下）。

3. ライザは古参のガッシュ、ルサルカ、マックイーンを優先して育成する。特性の変更に加え、ガッシュには新しいポテンシャル『**金雷児の魔力**』（自分の能力変化の＋に比例して、該当する種族値を1.1〜1.6倍にする）を予定。『エース』の発動だけで全能力が1.1倍になる。

4. カズマは「能力：C」で付与できる最大3体の『専用』枠を、ガッシュ、ルサルカ、マックイーンの古参3体に与えるつもり（「一番息が合う連中と使うのがベスト」「古参ならパーティ内で面倒な争いも起きにくい」）。ルサルカは「簡単に取り外しできるものじゃない」と念押ししつつ受け取る。
