# 第82話「アカギと異界のヌシ」 → source/082_第82話「アカギと異界のヌシ」.txt

1. ジュピターに呼ばれて、トバリシティのギンガ団本部《トバリギンガビル》へ（ハクタイのビルは支社。ギンガ団は四天王を除けばシンオウ最強の軍団のスポンサー）。呼んだのは、カズマとアカネの痴話げんかの写真を見て大爆笑した社長の**アダム**（全裸）。

2. アダムは先代テンガン山の深度4、『テンガンのヌシ』を持つ男。カズマが今代のテンガンのヌシ（メリュジーヌ）と接触したと聞いて興味を持ち、「「異界」へのチャレンジは「A」ランカーになってから」と釘を刺す（カズマが会ったのは深度1）。

3. 深度とランクの目安: Cランク≒深度2、Bランク≒深度3、Aランク上位≒深度4、Aランク≒深度4の群れのメンバー。深度2と3ですら別世界で、群れの攻略は深度3からが本番。深度4のヌシ（**異界のヌシ**）はどれも要「統率：A」で、従えられるのは統率型の特権。今のシンオウリーグで持っているのは片手で数えられるほど（ジュピターもテンガン山とは別のダンジョンの深度4のヌシを持つ）。

4. アダムは「統率／能力」の複合。助言はあっさり投げてジュピターに任せる。ジュピター: 統率型だからといって決まった戦い方はない。教科書通りでは同型の格上に勝てず、クセやノイズが個性になる。カズマもマーズと仲良くできるくらいだし型にはまるタイプではない。

5. Cランクの上位とぶつかるために、いずれ必要になるのは『**絆**』と『**PT**』（ジュピター）。
