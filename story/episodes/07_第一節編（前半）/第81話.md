# 第81話「人力ハードラック」 → source/081_第81話「人力ハードラック」.txt

1. 祝勝会で太ったライザとマックイーンを、ハクタイ南のサイクリングロードで走らせる（カズマ「久しぶりにじてんしゃを返してあげるからさ」）。

2. カズマは以前、《サイクルショップじんりき》にもスポンサーの応募をして、最終面接で落ちていた。そのとき一緒に面接を受けて採用された同期が、強面の**一条武丸**（《人力ハードラック》、「育成」型）。最近「ウマ娘」種が加入し、クロガネ杯で準優勝した。

3. ライザの煽りで、武丸と**10日後に練習試合**をすることに（ライナーとガブリアスの育成が間に合いそう）。サイクリングロード10往復で「太り気味」が解消された。2つ目のフリーイベントの募集（3D8:12(7+1+4)。7「シアさんが「たんけんセット」に興味」、1「裸族「やぁ、ウチのマーズが世話をかけているようだね」」、4「ジュピターことコーネリアさんからのコール」。作者「元チャンプことアカギさんに会いに行こう」→082）。
