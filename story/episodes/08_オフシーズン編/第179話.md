# 第179話「天花との夜会話と天賦の才」 → source/179_第179話「天花との夜会話と天賦の才」.txt

1. 天花が自然にカズマの部屋に来る（ライザはオルガマリーの“ブリーダー談義”に連れて行かれ、エールがさらに2人を引っ張って行った）。誘い先は1D10:6でホテル上階の展望ラウンジ（混浴もあるらしいが今日は使えない）。天花は星座をすらすら挙げる。エーテル財団時代にウルトラホールの観測部署とも関わっていたので、天体や空間観測に詳しい。ウルトラホールから来る別の空間のポケモンを“ウルトラビースト”と呼ぶ（カズマは自分もそうなのではと内心で思う）。天花の「テレポート」や、元『エース』の得意技「いじげんホール」も近いものかもしれない。

（出典: 179）

2. 天花の元チーム: 元SPは優秀だが「統率」型ではなく、好みや声色などクセの強い女性（作者注「未だ天花さんロスから抜け出せない元SP」。名前などは未公開）。元『エース』は異名『**亜空**』の**八雲紫**（「私には過ぎた『エース』だったかなぁ………」）。今は引退してアローラをふらふらしていて、時々連絡が来る。ミラクルズへの紹介もできたが、紫本人が「天花がトレーナーじゃない、どこぞの馬の骨のチームでこき使われるのなんてごめんなのよぉ」と拒否。今は『絆』を持った『エースアシスト』で、現役時代の身体の負担から、グレンラガンのように『悪癖』が出ているかもしれない（天花の推測）。長く『エース』で『絆』持ちの選手を入れるのは、要「統率」だけでは測れないリスクで、ルサルカがいちばん怒るだろう。

（出典: 179）

3. 天花の話の核心は「『**天賦の才**』は劇薬だ、処方を間違えば何もかもが変わってしまうほどに」という格言。『天賦の才』は『エース』にするとトレーナーの「統率」を上げるので、既存の『エース』を入れ替える選択肢が生まれる。穏やかでトレーナーを立てる『天賦』（ホムラ、ミラクルズの“自称天才”）なら問題は少ないが、唯我独尊型の『天賦』が「俺を『エース』にするなら従う」と言い、上がった「統率」でしか従わない高要統率のポケモンを増やせば、“敵性種に群れの主導権を引き渡すようなもの”（カズマはアクシズ教団にたとえる）。元『エース』の『絆』持ちが「自分が身を引けば勝てる」と苦渋の決断をし、トレーナーも止められない、という“最悪に最悪を重ねたケース”を語る（「情けないのは、どっちかな？」。知り合いにそういうことがあったらしい）。「統率」型なら比較的リスクは小さい。「C」では『天賦』が入ることはほとんどないが、「B」ではこうしたチームに出会いやすいので心の準備を、と伝える。

（出典: 179）

4. 天花は、個性がバラバラでも“根っこ”が繋がっている今のミラクルズを「好きだな♪」と言い、ファンレターの「『エース』を変えろ」などは有名税で、決めるのは監督だと言う。「そういうのを支えるのもサポーターの役目だからね」。現役時代に届かなかった「A」へ「私のことも一緒に、連れて行ってくれるんだよね？」、カズマ「連れてくなんてカッコイイんじゃなくって、情けないけど一緒に着いてきてくださいよ？」、天花「そっちの方が私好みだ………」。作者余談（旧版の原典にあった投下後の作者コメント。作り直した版では変換方針で外されている）: ロトムは『エース』の適性も意欲もない（「サイコソーダ冷えたロトよ、飲む？」）。みさきちは地元ファンに『エース』変更などを言われてストレスを溜めている。

（出典: 179）
