# 第171話「エニシダとバトルルーレット」 → source/171_第171話「エニシダとバトルルーレット」.txt

1. ライザ「見たかカロス女、何がボンジュールじゃいっ！」。エールはBでのリベンジを考え、オルガマリーは「選手の質が高い上に長所を伸ばしてきてる」。テイオーは「しんそく」を覚えると言い、マックイーンは「「そだてや」でウチの電球野郎と一緒にしごかれてくると良いですわ」。ルイズは負けを認め、魔理沙は「はかいこうせん」をうわごと。カズマは新体制で一番大きいのは"サポーターの存在"だと実感。天花は今後「タイム」にも参加できる（「タイム」の精度が上がる）。

（出典: 171）

2. 「怪しい影」はバトルフロンティアのオーナー**エニシダ**（テイオー「オーナーのおっちゃんだ！」）。エール「バトルの分野ならシンオウで三指に入るくらいの権力者」。バトル好きでフットワークが軽く、天花がエーテル財団のチームを率いていたこと（「今代のルザミーネ女史はご健勝かな？」）やルイズ（カロスのバトルハウス）も知っている。どこまで覚えているか（1D10:10）は、シンオウの全プロチームのトレーナーと中核選手、カントー〜ガラルまでの情報（この台詞だけ原文の話者表記が【ムスカ】）。ライザ「バケモンかな？」。財力はウラヤマ以上、さらに上にはベルリッツ財閥（オルガマリーの見立て）。

（出典: 171）

3. エニシダが案内を買って出る（常連いわく「恒例行事」）。フロンティアはバトル以外にも日替わりイベントがある。五大施設（バトルタワー、ルーレット、キャッスル、ステージ、ファクトリー）からダイス（1D5:2）で**バトルルーレット**へ。フロンティアブレーン（ジムリーダーや四天王にも匹敵）のうち、ルーレットゴッデスの**黛冬優子**（カズマたちと同じくらいの年の少女）と、ファクトリーヘッドの"錬金術師"が顔見せ。一泊二日なので施設には挑戦しないが、施設に隣接した同じフィールド効果のスタジアムは使える。エニシダは、イッシュから来た「B」ランクルーキーの少年（ルイズと同等かそれ以上）を紹介するつもり。

（出典: 171）
