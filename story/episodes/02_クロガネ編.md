## 第9話「たんけんセットと旅立ち」 → source/009_第9話「たんけんセットと旅立ち」.txt
1. 旅立ちの日。カズマは凜とライザに賭けの話をする。凜の家を教えたのはライザだった。
2. ライザの実家は、父親が古文書から復活させた「たんけんセット」を100万円で売る店。地下大洞窟に潜るための道具だが、まったく売れず、来年中にはつぶれそう。カズマがレンタルを提案すると、ライザは衝撃を受けて店で働くよう迫る。
3. カズマは、ライザの家のようなところが狙い目のスポンサー候補だと考える。ライザは電話番号を聞き出す。凜は「夢破れたらごはんくらい奢る」と送り出し、カズマはクロガネシティへ出発する。
4. ハクタイジムに、マサゴタウンから来たバッジ0の新人トレーナー、エール・モフスが現れる。手持ちはラハールとキュゥべえ。「チャンピオンを倒してシンオウの女王になる」と宣言する。カズマとの遭遇はもう少し先。
5. 作者: これでオープニングからジム巡りに移行。旅立ち直後とクロガネシティで1回ずつフリーイベントを挟み、最初のジム戦（2vs2、初操作）へ。フリーイベント（3D8:14(6+4+4)、被り分1D6:3）は「先輩トレーナーと遭遇し、野営の手ほどきを受ける」「自分と同じ新人っぽいトレーナー」「途中でポケモンと遭遇」の3つ。先輩も新人も1D2:1で男（作者「ようやく男の人間が出てきよったぜ」）。中身は読者の募集安価で決める。

## 第10話「メジロマックイーン加入と先輩遭遇」 → source/010_第10話「メジロマックイーン加入と先輩遭遇」.txt
1. 旅の初日。206番道路を徒歩で進むカズマたち。自転車で走るサイクリングロードを横目に、ルサルカ特製のポフィンで休憩する。
2. 白髪の少女が、置いていたポフィンの8割を盗み食いしていた。逃げようとしたところをルサルカの「くろいまなざし」で止められる。「でんこうせっか」で反撃するが、ゴーストのルサルカには効かない。
3. 正座、石抱き、脚つんつんの刑を受けた少女は、メジロマックイーンと名乗る。ポフィンとエレブーズとおしるこを愛する令嬢。罰として荷物持ちになり、仲間に加わる（データは未完成）。作者: こんな奴でも将来的には「じょおうのいげん」とか似合いそう。
4. 夕方、野宿を前にした一行の前に、バッジ4つのCランク監督「さすらいの先輩」が現れ、新人への「指導」を申し出る（バッジ数は1D8:4）。
5. 作者: このキャラの名前は以後ずっと''先輩''。噛ませオーラ全開でも、今のカズマでは逆立ちしても勝てない。手持ちはまだ思いつかない。資質のイメージは、指示⇒油断しまくり、統率⇒人望ある…？、育成⇒練度低い（確信）、能力⇒かませ。

## 第11話「先輩の教えとポテンシャル」 → source/011_第11話「先輩の教えとポテンシャル」.txt
1. 206番道路での野営。先輩とその手持ちのザクも一緒。マックイーンが一発芸で「うまぴょい伝説」を踊り、「ウマゴン」と呼ばれる。図鑑でマックイーンのデータを確認する（ノーマル、Lv20、すばやさAA-）。
1.5 夜のコミュイベント（読者の募集安価から作者が候補を選び、ダイス）: メイン1D5:5「先輩、後輩に胸を貸すべく練習試合を受けて立つ（初バトル）」、サブ1D5:3「カズマさんの資質と、今後のポケモンに関する先輩談」。
2. 先輩が「ポテンシャル」を説明する。ポケモンの潜在能力が形になったもので、『』付きの言葉がそれ。バッジを取れるくらい強くなると目覚め、持ち物や特性より影響が大きい。
3. 図鑑でカズマのトレーナーステータスを見る（指示B-、育成C、統率A+、能力C）。先輩はオールBの万能型。統率Aなら理論上どのポケモンも従えられる。
4. 敵性種の話を聞く。ステータスが高い傾向がある。統率型に向いているのはモンハン種で、その上位が古龍。メリュジーヌのステータスは古龍に匹敵する。
5. トレーナー同士のバトル経験がないことに気づき、先輩が相手を買って出る。翌日クロガネシティで戦うことになる。
6. 作者: 先輩には後輩が付きもの。ほかの新人トレーナーとの遭遇は、突如発生した先輩風でクロガネシティへ持ち越し。まずは先輩で初のトレーナー戦になる。「バッジ8個だったらこいつがサターンだっただけだよ」。

## 第12話「初バトルの準備」 → source/012_第12話「初バトルの準備」.txt
1. 旅の2日目の午前、クロガネシティに到着。先輩とのバトルは昼食後になる。ファミレスでマックイーンがスイーツ食べ放題に大はしゃぎする。
2. アカネとゼットンの餞別に「もちものセット」（第八世代基準の持ち物ひととおり）が入っていた。ポケモン図鑑はバトル中に1回、相手のデータを解析できる。
3. 先輩との模擬戦は2vs2。先輩は昨日捕まえた同格のポケモンを使う。そのうち1体は、先輩が乗っていたイャンクック（ひこう／ほのお、モンハン種の下位種）と予想する。
4. 図鑑で手持ち3体のデータを確認し、準備を決める。出すのはガッシュ（オボンの実）とマックイーン（ノーマルジュエル）で、先発はマックイーン。

## 第13話「先輩戦」 → source/013_第13話「先輩戦」.txt
1. クロガネシティ郊外。新人トレーナーの潮田渚と手持ちのジャックが、カズマと先輩のバトルに気づいて見に来る。
2. 初めてのトレーナー戦。先輩の先発レオパルドン（ノーガード、防御E）を、マックイーンがノーマルジュエルの「すてみタックル」で一撃で倒す。
3. 先輩の2体目イャンクックが、マックイーンを「はじけるほのお」で倒す。ガッシュがオボンの実で耐え、「10まんボルト」でイャンクックを倒して勝利。カズマはバトルの楽しさに気づき始める。

## 第14話「潮田渚戦」 → source/014_第14話「潮田渚戦」.txt
1. ガッシュがLv21になって「ドラゴンクロー」を覚え、マックイーンはLv22になる。のぞき見していた渚が、序盤のジム戦には「十八竜」（ドラゴンタイプ）が必ず出ると教える。凜も「くさ／ドラゴン」持ちだった。
2. 渚の手持ちジャックが露出の多い服を着ていて、渚は変態扱いされる。ジャックに「ビッチ」と言われたルサルカが怒り、渚とのバトルになる。マックイーンがアメでジャックを買収し、渚のもう1体（ブレードライガー）を聞き出す。
3. マックイーン（こだわりハチマキ）が「にどげり」でジャックを倒し、ライガーを瀕死寸前まで追い込んで倒れる。ルサルカがライガーを倒して2連勝。

## 第15話「クロガネジム攻略会議」 → source/015_第15話「クロガネジム攻略会議」.txt
1. 先輩はテンガン山へ去る。一行は負けた渚を喫茶店に連れて行き、コーヒー代を払わせる。
2. 渚がクロガネジムの情報を教える。スペランカーは元Bランクのプロで、負傷で引退した。ゴツゴツメットが大好き。十八竜はトライノス（いわ／ドラゴン、防御A、鈍足）。レベルは25くらい。
3. トレーナーズスクールの説明を聞く。プロチームを2つ持ち、1つはAランカーの空条承太郎のチーム。渚の同期の食蜂操祈は、すでにバッジ3つでソノオタウンをスポンサーにプロになる。
4. クロガネ炭鉱で化石を掘れること、2つ目と3つ目のジム戦は3vs3であること、クロガネジムのわざマシンは「ステルスロック」であることを聞く。渚が店を出たあと、ライザから電話がかかってくる。

## 第16話「じてんしゃとたんけんセット」 → source/016_第16話「じてんしゃとたんけんセット」.txt
1. ライザの店がレンタルを始め、初日に10人くらいの客が来た。大口の取引先を相談されたカズマは、クロガネ炭鉱との契約を提案する。
2. お礼に、ライザのお古のじてんしゃをもらう約束をする。ライザは翌日、自分で乗ってクロガネシティまで届けに来る。
3. ライザはカズマにサドルを渡すことを意識して悶える。父の地下おじさんは何かの賭けに出ることを決め、「君が来るのを待ち望み、準備をしている」とカズマへの伝言を頼む。
4. カズマはクロガネジム戦の編成を決める。ガッシュ（こだわりハチマキ）とルサルカ（しずくプレート）で、先発はルサルカ。

## 第17話「クロガネジム戦」 → source/017_第17話「クロガネジム戦」.txt
1. 旅の3日目。クロガネジムでスペランカーに挑む。
2. 先発ルサルカの前に、いきなり強そうなラムパルドが出る。ルサルカの「みずのはどう」で混乱させ、ラムパルドは自滅して倒れる。
3. 2体目の十八竜トライノスには、ルサルカが「のろい」をかけて倒れる。ガッシュが「ドラゴンクロー」2発でトライノスを倒す。
4. カズマは最初のジムバッジを手に入れる。

## 第18話「祝勝会とたんけんセット」 → source/018_第18話「祝勝会とたんけんセット」.txt
1. カズマは「コールバッジ」と「わざマシン：ステルスロック」を手に入れる。ガッシュはLv24、ルサルカはLv25になり「おにび」を覚える。わざマシンは今は「バトル中に一度だけ技を出せる持ち物」。
2. スペランカーが、次のヨスガジムのジムリーダーはメアリ・クラリッサ・クリスティだと教える。ヨスガにはポケモンコンテストがあること、数日以内にポテンシャルが目覚めることも教える。
3. 祝勝会で、同じくジムを突破した渚を連れて焼き肉屋へ。食べすぎてお金が足りず、渚には逃げられ、翌日クロガネ炭鉱で日雇いバイトをすることになる。
4. 炭鉱にライザがたんけんセットを持って現れる。説明できないライザに代わって、カズマがスペランカーに売り込む。1週間後、炭鉱と限定的な卸しの契約が結ばれる。

## 第19話「よろいのかせきとライナー」 → source/019_第19話「よろいのかせきとライナー」.txt
1. ライザがカズマに約束のじてんしゃと、炭鉱で掘り当てた「よろいのかせき」を渡してハクタイへ帰る。
2. 博物館で化石を復元すると、鎧の巨人が現れる。巨人種のライナー・ブラウン。人間サイズの姿になり、4体目の仲間になる。
3. カズマはアカネに電話でバッジを自慢する。アカネの家は4日で荒れ始めていた。アカネは「帰ってこい」「週3で添い寝する」と言うが、カズマは断る。
4. カズマはライザ号でヨスガシティへ向かう。
