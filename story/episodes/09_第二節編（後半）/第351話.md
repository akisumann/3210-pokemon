# 第351話「ハクタイ杯2日目とPDCフェニックス戦前分析」 → source/351_第351話「ハクタイ杯2日目とPDCフェニックス戦前分析」.txt

1. 大会2日目。初日に勝ち星を伸ばした優勝争いの4チームは''勢い''が違い、ほかのチームは不安や躊躇いの''ブレーキ''で勢いを殺されている。

2. 4戦目《花畑ハピネス》（ソノオの花畑の町民の非営利団体がスポンサー）は『魔獣』が大暴れして勝ち。5戦目《爆薬ファイアワークス》（クロガネの「だいばくはつ」使い）は、ロトムがかわいそうなくらい刺さって勝ち。有言実行で出撃したイカルガは、試合後に何かに燃えていた。レベルアップ: イカルガ109→110、ヤマト108→110、ロトム110→112。

3. 6戦目、中盤の山場は天羽奏の《PDCフェニックス》。本人が『獣化』で戦う『二枚看板』で、『セルフコマンド』により「統率」は今大会最大、常時「命中+1」。もう1つの『固有』『高く奏でる明日の調べ』と、回復に連動する『PT』2種（『逆光のリゾルヴ』『ツヴァイウィング』）。推定レベルは「110～120」で練度は互角。一夜あったので、スピリット・オブ・ファイア（『金冠サイズ』の『エース』、専用『大気を焦がす大炎精霊』）、天羽奏、グングニール（専用『邪悪を貫く聖なる氷槍』）の主力3体のデータを取れた（3体ともLv120）。

4. マックイーン「なんやこの『二枚看板』っ！」。ライザ「私がスーパーな「育成：S」のBDだったらお前ら全員『第四階梯』や『極』をつけてやるよ」。ガブは「こおり」相手で相性は悪いが「五分以上にやれる」、ライザいわく明日のファイナルはチームの評価としてこれ以上の相手。ガッシュ「「統率」が上の相手だろうと、このチームならば崩してみせようっ」。カズマ「奏をここで撃破し、6戦全勝で最終日に突撃じゃいっ」「この山場……''テンガン山''に比べればどうということはないっ」（ルサルカ「比較対象が大山脈なんですが」）。

5. 作者: 練度はお互いほぼ「110～120」の「統率」型同士の重量級対決が2日目のPC操作。
