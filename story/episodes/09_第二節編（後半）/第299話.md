# 第299話「リージョンフォームと技術交流」 → source/299_第299話「リージョンフォームと技術交流」.txt

1. 8番道路の''エーテルベース''で、''ハウオリ''のスクールの''オーキド校長''（天花の母校の校長）に会う。カズマは「カントーでポケモンを最初に151匹と定義づけた''オーキド博士''を襲名する博士」かと目を輝かせるが、''フリット・アスノ''翁が継いでいるのは''ナリヤ・オーキド''の名（''オーキド・ユキナリ''の従兄弟とされる偉人）。今の''オーキド''とは血縁もないが仲は超良い（「ピカチュウとミミッキュくらい別モンだ」）。カズマが''古代種''に詳しいのを見て「じっちゃん結構評価高いよジャージの小僧」。

（出典: 299）

2. 連れていたのは「ほのお」のガラガラと白いキュウコン（''リージョンフォーム''）。黒子いわく、初代ナリヤ・オーキドは''古代種''の時代に、地方ごとに違う姿に適応したポケモン（リージョンフォーム）を研究するためアローラに来た。天花「現代で言う『変種』とかの走り」、環境がポケモンに与える影響の研究として今も続く一大学問。シンオウ（超古代の名は''ヒスイ''）でもリージョンフォームのようなポケモンの化石や痕跡が見つかっている。

（出典: 299）

3. ロトムを見たフリットは「分解と改造させて」と迫り、天花に浅瀬へ「テレポート」させられる（『タイトエンド』で『原始天賦』と聞いて、''ウラウラ島''の「でんき」小僧と''ホクラニ天文台''の青びょうたんにも連絡しようとした）。ロトムは「育成」で電子スペックも上がったと言い、''ボクのスペックを劣化移植したスマホ''（''ロトムフォン（仮）''）を''もりの洋館''のガラクタで暇つぶしに試作していた。夜な夜なカズマのスマホも改造していた（成功率は3割だったが、コツを掴んだので今は100%。ついでにカズマ名義で有料サイトに登録）。100%音声起動・ホログラム付きで、ネットでできることの9割を網羅し、アローラにいながらジョウトの特番が見られる。全機能をアプリ化して無料配布する野望がある（天花「現機種だとスペックも容量もまるで足りない」）。中枢は''ISコア''のようなブラックボックスで、試作品はサラっと黒子に渡した。

（出典: 299）

4. フリットはエーテルパラダイスの''ザオボー''や''ビッケ''、さらに総帥にまで連絡すべきだと言い、「一年くらいこの子アローラで借りて良い？」。モモ「こんな技術力を要する企業が、半年前まではハクタイの歴史の闇に消えるところだった…………？」。ライザの素朴な疑問「''たんけんセット''に機能搭載とか出来ないの？」から、ロトムフォンを中枢にして''たんけんセット''を定期的に無料アップデートし、進んでいる地下のマッピングと地上を連動したGPS機能を…という話に（ベルゼブモン「売ったら利益とかとんでもないことになりそう」）。天花「今のシンオウでシンデレラストーリー真っ最中の元零細企業」。

（出典: 299）

5. ''ウルトラホール'': かつてアローラに生まれた時空の歪みで、今も稀に観測される。「''時間も空間もこの世界のものじゃない''」とも。''ダンジョン''、特に''異界''の研究ともリンクしていて、''異世界からの侵攻''というおとぎ話もある。そこから出てくるポケモンもいて、財団はずっと研究を続けている。カズマは「''異世界''から………………ねぇ？」と神妙な顔（ライザ「どうせまたチート能力の妄想」）。天花いわく、''時空の研究''ではエーテル財団が全国でも最高峰で、''地下大洞窟''のデータの収集は避けて通れない。ルサルカ「初期の''探検堂''なら技術力だけ吸い上げられてグッバイだったかもだけど、こっちは既にシンオウの協会がバックにいる」。

（出典: 299）

6. フリットの見立ては、まず''シンオウのエーテル財団の支部''との部分的な情報・技術交流から。アローラの民として携わりたいと言った黒子は、''試される大地''シンオウの支部は一部で左遷部署扱いだと必死に拒むが（ライザ「シンオウを愚弄するかぁ」）、パワハラまがいの総帥（現総帥、通称''ルザミーネ''）のフットワークと、エーテルベースの同僚という目撃者の前に、本部に一報を入れて5分後に突っ伏す。''白井黒子のシンオウへの単身赴任''（最低でも半年）の辞令が即日交付された。フリット「ロトムを捕まえてワシの所に送るんだよ？」、黒子「うるせぇジジイ！！！！」。マックイーンは常識人お嬢様言葉キャラの座を奪われないか警戒し、モモは苦労系常識人枠の知り合いを待ち望む。

（出典: 299）
