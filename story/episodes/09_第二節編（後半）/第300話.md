# 第300話「八雲紫と探検堂のチーム事情」 → source/300_第300話「八雲紫と探検堂のチーム事情」.txt

1. 黒子はわめき疲れて眠った（マックイーン「お嬢様の同志として嘆かわしい」）。黒子が出航するエーテル財団の支部は''ミオシティ''にある。カズマは「''ライドポケモン''万歳」と叫んでケンタロスで遠乗りに出て、ライザが追いかけた。

2. 残ったガッシュ・ルサルカ・マックイーンは、背後に''穴''を開けていた女に''スキマ空間''へ引きずり込まれる。天花のアローラ時代の元『エース』、『亜空』の''八雲紫''（「エスパー/ゴースト」タイプ。「ゴースト」と「あく」が4倍弱点）。''スキマ''は''ウルトラホール''ではないらしく、他の地方の''やぶれた世界''に近いのかもしれない（紫もアクセスできる生態なだけでよく知らない）。何の準備もないとダメージが大きいので、トレーナーではなくポケモンの3人を選んだ。紫は「この空間を''フィールド形成''出来れば、『スキマのヌシ』とかになりてぇなぁ」。目的は、天花が連れてきた後輩たちをからかって先輩風を吹かすこと（昨日からスキマでのぞき見していた）。マックイーンの「なげつける」を食らい、「ゴースト」「あく」の技はやめてと懇願。

3. 紫は素直なガッシュを「攫っちゃいたい」と言い、より良い''座''を求めて違うチームに移ることもあるのでは、と聞くが、3人は想像すらできない（ガッシュ「カズマの『エース』以外を任じられたこととか想像出来ない」、ルサルカ「''女をやめるか人間をやめるか''ってレベルの質問」）。マックイーンは「今のポテンシャルを全部保持した上で、今のチーム以上のエクスタシーを与えてくれたら」。紫の「「統率」型ならチームの主導権はトレーナー。方針の差が生まれたら？」にも、カズマが変わることなど想像できない（ルフィがシャボンディの偽ルフィになるようなもの、ウソップから嘘つき属性を奪うようなもの）。

4. 3人の覚悟: ガッシュ「代わりに、カズマを絶対に''シンオウリーグ''まで連れて行く。それが我らがカズマに対する答え……''責任''と言っても良いか」。ルサルカ「私らのせいでこけたら''全部カズマのせい''みたいになる、それは許せん、''証明''しないとダメ」。マックイーン「ダメならこっちから首を差し出しますわ」。紫「''ランセ地方''みたいなこと言うとるわ」。カズマには言っていない（重荷になりたくない、全部終わった後の笑い話か墓まで）。紫（天花への心の手紙）「私の後輩達が想像以上にトレーナーに対して重い感情があるようです。ラガンやエンプラを薄情に感じたこともありましたが、私もここまでではなかった」。System: 探検堂にはこいつらに引きずられるか、今のスタンスに異を唱えるつもりのないやつしかいない。ライザは「育成：A+」の『絆』の影響か、これを薄々察している。

5. 報酬の話: 紫いわく、企業に属する監督（トレーナー）と選手（ポケモン）は対等と言われるところが多い。
   - 探検堂では、オーナーからの報酬をカズマが代表して受け取り、手持ちで**等分の山分け**（「飛信隊精神」。控えという概念があったら無理）。
   - カズマはお小遣いを集られるが、オーナーに上乗せをおねだりするのでバランスは取れている（オーナーはおねだりされてお小遣いをあげるのがうれしくて仕方ない）。
   - マックイーンの食費は探検堂持ち。
   - ヒトカゲは第三節まではカズマのポケットマネーから（本格参入したら同額）、オシュトルは準備金と地下探索の手伝い分も合わせてそこそこ出ている（『ベテラン』差別もない）。
   - 天花は同額の話もあったが固辞。
   - ライザはオーナーの身内なのでお小遣い制（口座には天花がちゃんと振り込んでいるが、本人は通帳を見ない）。
   - 同じ頃シンオウでは、オーナーがはくのんのバイト代をカズマへの報酬（山分け済み）と同額振り込んで一悶着あった。
   - ロトムの技術でシンオウに戻ってから見込める利益も、報酬に上乗せして山分けの予定（ロトムの給料の使い道はニ○動のプレミアム会員や有料動画サービス。発明の機材はオーナーから借りる）。
   - マックイーン「チームどころか''探検堂''全体もう家族」。

6. 紫は常識が崩れる音を聞いて3人を蹴り出す。ダイス2「帰る前に天花からいろいろ聞いてみよう……流石に誇張だろ」で、帰る直前に見送りがてら天花に真実（笑）を聞くことに（黒子がキャプテン2人に悲しいお知らせをするのと同じタイミング）。作者: 描写されるほどヤケクソ染みた''探検堂''。''探検堂''に必要なのはナミさん（ルサルカに託したいがもう無理、ガッシュとマックはほぼ両翼）。開放的なはずのアローラの女達が、慎ましやかなシンオウの女より常識的。
