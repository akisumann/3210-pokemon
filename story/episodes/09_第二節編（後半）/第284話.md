# 第284話「ミス・ゴールデンボール」 → source/284_第284話「ミス・ゴールデンボール」.txt

1. 金玉橋の水着コンテスト。司会の「ゴールデンボール」にレナがキレて、固有『**青き海の竜宮城**』で全体の場に《深海楽園/リュウグウノシロ》を展開し（毎T終了時、「水」タイプの体力を1/8回復）、固有『**冥海に渦巻く大波嵐**』（1/試/先行。味方の攻撃命中時、「技能拡張：おおなみあらし」（特/水/単/200/90、ダメージの1/2の反動）による追加行動）で野郎共を吹き飛ばす（ハリベルが外しておいた）。もう一つの固有『**青き雫と波の音色**』は、リュウグウノシロの時に味方の「水」技のタイプ一致の強化倍率を2倍にする。ルサルカ「前に戦ったルイズが霞むポテンシャル」。天花「やっぱ怖いすね、「能力：AA」は」（フィールドを問答無用で変える）。真冬の見立てでは、レナはまだ潜在能力を全部発揮できていない。

2. 優勝賞品はトレーナー側が''サントアンヌ号のディナーチケット''、ポケモン側が''アローラのホテル宿泊券''。上位入賞の賞品に''なんか雷を纏った羽''、''水晶みたいな透明の欠片''（ハリベル「あの、それ確かサン――」「ジョウトで手に入れたスイ――」）、ジムのわざマシン。野郎共はレナとハリベルを応援する完全アウェイ。隠れていた真冬もマックイーンに見つかって舞台に引き出され、司会は新聞局に連絡する。

3. トレーナー側（ダイス）: ライザ68、アカネ28、真冬14+20（カントー補正）、レナ5+30（ハナダ補正）、モブ40・46・30で、ライザが優勝（「ハナダに伝わるホットパンツの伝説……伝説のカスミ」）。ポケモン側: ルサルカ25、ゼットン53、ハリベル30+30（ハナダ補正）、モブ19・54・52で、ハリベルが優勝、ゼットンが3位（景品はダイス8で''なんかビリビリしてる羽''。明らかに「でんき」のオーラ）。ルサルカ、アカネ、真冬、レナは失神。

4. ゼットンの話: 持ち帰ると''プルート''（本名''ワイリー''。現在の''ギンガ三将星''の「育成」を一手にまとめる「育成：AA」の凄腕BD）の手に渡って帰ってこない可能性が高い。プルートのおかげで三将星のポケモンは全員''実質「育成：A」相当の鍛錬''を受けているが、なんでも思い通りにしたがり、想定外のプランが嫌い。ギンガ団はトレーニング設備も充実していて、サブBDのような助手もいる。ゼットンはライザに「準備ゼロからここまで上がってる時点でお前もかなり優秀だ」「お前らのパターンは唯一無二過ぎて参考にならん」。

5. 羽と引き換えに、ゼットンはライザのグループ用ディナーチケットで''サントアンヌ号''に連れて行ってもらう約束を取りつける（アカネとアドルフも）。ハリベルの案内で、天花の「テレポート」でハナダジムへ。''ミス・ゴールデンボール''はライザとハリベル。

6. 作者: クチバに来たからにはサントアンヌ号に乗りたいというカズマの叫びが通じたのかも。次はジムに行って、そのあとシオンあたり。このあと魂の故郷アローラにも行く（カントーより短め）。「こいつとのバトルも全然想定してないとこから重要な一戦になっちゃった」。

   - ダイスは全部ランダムだが、偶然とはいえ、水着コンテストらしい筋の通った結果になった（補足: ユーザーより）。綺麗な人コンテストではなく水着コンテストなので、健康的で運動的な体つきが評価されがち。勝ったのはライザ（太もも、肉体派）、ハリベル（恵体）、ゼットン。負けたのは、体型が貧相寄りのレナとルサルカ、生活がだらしない汚部屋のアカネと真冬（真冬の「クールビューティー」は水着では生きない）で、原作のキャラ付けから見てもそのとおり。Systemの「恵体コンビ……ある意味順当かもしれん」も当たっている。
