# 第301話「アローラとの別れ」 → source/301_第301話「アローラとの別れ」.txt

2. 紫が見送りに来て、天花に「またアローラでチーム組みましょうよ」とすがる。天花「今は''エーテル財団''の職員じゃなくて''探検堂''の職員」「あっちの気候はキミには厳しい」。紫はカズマを「聞けば聞くほど珍獣っぽい話しか出てこない監督……名前はウソップだっけ？」と呼び、第一印象は**ダイス14**。天花は財団のSPでも充分やっていけた人材なのに、雪国の馬の骨のSPなのが認められない（「返してっ、天花を私に返してよぉ」「元SPまでNTRされる」）。後輩（仮）たちがジャージ男にガンギマリなのも納得できず、アローラでカズマのアンチ・スレを建てると宣言（ハンコック「アローラはインター・ネット後進地方」、他の地方のサイトはすぐ落ちる）。黒子には「私の後輩共の欺瞞を暴いてくるんだ」とアンチの燃料集めを頼む。カズマは第二『固有』で嘘を現実に変える能力が欲しい。ライザ「なんか空気感ウチに似てません？」。

（出典: 301）

4. 『天賦』のヒトカゲでチーム内のパワーバランスが変わるのでは、と聞く美柑に、カズマはヒトカゲを『役割』なし（''すっぴん''）にする「育成」法を語る（美柑「すいません、今ちょっとよく聞こえませんでした」、紫「これ以上嘘つくのやめてもらって良いですか？」、天花「何か問題でも？」）。ハンコック「アローラどころか「統率」という領分ではかなり異質」。美柑いわく、『役割』を変えるだけでもそれ用の「育成」が必要で、「統率」で言うなら『エキスパンション』も同様。ハンコック「監督のその日の気分で昨日はセンター、今日はピッチャー、明日はキャッチャーとか地獄を超えた地獄」「わらわはそんな「指示」に不純物混ざるのやりたくない」。カズマ「選択肢ってのは多ければ良いわけじゃない」「このために練習試合で勝利し態々報酬を指定したくらいに真面目」（このスレの省エネスタイル）。

（出典: 301）

6. 外からの評価: 美柑「王道を征くような正統派キャラで売り出すべき、凛さんのように」。ハンコック「プロチームの監督というのは''華''や''話題性''も重要な美点」「端から聞いてイミフなこやつのバトル、何も知らん我々でも興味出ないと言えば嘘になる」。紫「ポケモンバトル自体がこの世界で屈指のエンターテイメントとして扱われてる」。内情が理解できないなら戦績で評価するしかなく、ハンコック「ええやんけ」。海夢「ここまでこのチーム、負けた回数が5回以下」。天花「カズマくんはね、不思議なことに近くで見れば見るほど純粋に尊敬する気が失せるんだ」。ライザ「カズマは基本誰とでも仲良くなれる方だけど、こいつ自身はアホ、カスマ」。

（出典: 301）

7. 天花「やっぱ、今はとっても楽しいよ？　だから、きっとまた今年の''第四節''が終わったらまた帰ってくるよ…''シンオウチャンピオン''のSPとしてね」。カズマ「ウチは選手もSPも頼もしくって嬉しい限りっすわ」。紫「その時は掌グルンって返してあげるわよ………やれるもんならやってみなさい」。天花「その時は''元チームのみんな''にも教えないと……あの時私たちが諦めたてっぺんの景色はどんなものだったのか」「彼……ううん、''私たち''なら超えていけるさ………あの高くそびえる''テンガン山''だって」。テンガン山は「深度：4」の攻略、つまりメリュジーヌ（『テンガンのヌシ』）のこと（補足: ユーザーより）。

（出典: 301）

8. 見送ったあと。紫はシンオウには行かない（今の天花は''あいつのチームの一部''なので、自分は''傍観者''。偶に顔を出すくらいは考える）。美柑「デビューした年に一地方の頂点を取るって宣言して帰りました」。海夢「地元のジムリーダーからかわいがられてる感じなの分かった気はする」。ハンコック「周囲を巻き込むことに関しては天性の才がある男」「有言実行の英傑か、口先ばかりのほら吹きか……どちらにしても、好ましい若者だな」「勢いと熱意のある若い力が、いつの世も時代の歯車を回すのかもしれんな」。

（出典: 301）
