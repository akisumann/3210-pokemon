# 第16話「たんけんセットの販路とジム戦準備」 → source/016_第16話「たんけんセットの販路とジム戦準備」.txt

1. ライザの店がレンタルを始め、初日に10人くらいの客が来た。大口の取引先を相談されたカズマは、クロガネ炭鉱との契約を提案する。

2. お礼の希望を募る安価（ダイス1D10:4）で、カズマはライザのお古のじてんしゃを要求する（「お前のその太ももに挟まれて良い感じにサドルが摩耗したお古でいいからさ」）。1ヶ月のタイムリミットのため切実。ライザのじてんしゃ発言への意識度は1D100:92。ライザは翌日（ジム戦の後）、自分で乗ってクロガネシティまで届けに来る。カズマが「お前んちでプロチームとか――」と言いかけたところで電話が切れる。

3. ライザはカズマにサドルを渡すことを意識して悶える（「ライザちゃんだって女の子なんだぞ」。サドルを替えようとして、結局アルコール消毒で妥協）。レンタルは15件に。父の地下おじさんは何かの賭けに出ることを決め、「君が来るのを待ち望み、準備をしている」とカズマへの伝言を頼む。

4. カズマはクロガネジム戦（2vs2）の編成を決める。安価>>2679でガッシュ（こだわりハチマキ）とルサルカ（しずくプレート）、先発はルサルカ。作者: 実機でのレベルはわりかしガン無視しているスレ。

- **クロガネジム戦の戦闘前の感覚**（015〜016。ユーザーのスクショより）: 渚の情報で、スペランカーは「ゴツゴツメット」を必ず使う。
  - 読者は、接触技と連続技のマックイーンは無し（すてみタックルもいわに半減）、タスキやがんじょうもゴツメで潰される、事前に分かるなら非接触技で殴れ、と見た。
  - 十八竜は「いわ／ドラゴン」のトライノス（防Aの物理型、速E+〜D-）で、「ドラクロ2発入りそう」「ガッシュもルサルカも先手確定なのはありがたい」。
  - もう1体は不明だが、最初のジム戦は初手に古代種を出すことが多い（渚。イシツブテ系、イワーク、化石、ズガイドスなどの予想）、レベルは2体とも25と見られる。
  - 「フカマル早く捕まえてぇ」という声も。
  - 選出は>>2679で、ガッシュ（こだわりハチマキ。物理の「ドラゴンクロー」用）とルサルカ（しずくプレート）、先発ルサルカ（古代種の先発に「ねこだまし」も打てる）。
  - 選出のあとも読者の読みは続き、トライノスは鈍足高火力なのでルサルカで「ドラゴンクロー」1発で落とせるところまで削る、ドラゴンが防Aだからこそ一致特殊のルサルカの一撃が大きい、ガッシュは耐久が薄いので最初の「ドラクロ」で倒しきれないときつい、ルサルカの技は等倍なら「シャドーボール」が威力でわずかに上、追加効果（混乱）まで見るなら「みずのはどう」（プレート込み）、どちらも間違いではない、という形に。
  - レベル25で古代種の「ラムパルド」や「バンギラス」が暴れる心配や、「見えてる情報からあーでもないこうでもないと考えるのも醍醐味」という声も出た。
