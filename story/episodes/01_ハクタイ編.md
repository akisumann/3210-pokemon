## 第1話 → source/001_第1話.txt
1. ギンガハクタイビル。マーズ（アカネ）が気絶した男を連れ帰ったことを、社員二人が噂している。アカネはテンガン山の「異界」クラスのダンジョンにいきなり現れた少年に興味を持っている。
2. カズマが医務室で目を覚ます。アカネに転生したことを話すが信じてもらえず、記憶喪失ということにする。お金もない（漱石の千円札は偽札扱い）。
3. アカネが自分の家の家政夫（ﾄﾞﾚｲ）にならないかと持ちかける。社員たちに止められ、からかわれたアカネは意地になり、カズマを脅して連れて帰る。
4. アカネのマンションはゴミ屋敷状態。カズマは掃除を任され、アカネのパンツを拾ってパンツ・ヘリコプターをする。アカネはゼットンに攻撃を命じるが、ゼットンはカズマの味方をする。
5. ゼットンがプロトレーナー制度を説明する。カズマはゼットンがポケモンだと知って驚く。
6. 部屋はあっという間に片付き、ゼットンは感動して泣く。アカネはカズマを意識し始める。カズマは物置部屋で寝ることになる。アカネはゼットンに泣きつき、ゼットンはカズマを逃がさないように囲う準備を考える。
7. カズマは、自立しなければと思いながら眠りにつく。

## 第02話「ガッシュ、ゲットだぜ！」 → source/002_第02話「ガッシュ、ゲットだぜ！」.txt
1. 翌朝、アカネは眠そうにカズマを避けるようにして出社する。ゼットンがカズマにハクタイシティを案内する。シンオウは「八大地方」の一つで、カントーは「はじまりの地方」。ピカチュウは「古代種」扱いされている。
2. ゼットンの知り合いの幼いポケモン、ガッシュが現れる。ガッシュは「王を目指す種族」なので『エース』以外の適性がなく、トレーナーに断られ続けていた。
3. ガッシュがでんきタイプで、声がピカチュウと同じ（大○育江）だとわかり、カズマは即決で手持ちにする。ガッシュもアカネのマンションで暮らすことになる。
4. カズマは「持ち物」や「特性」も知らず、ゼットンとガッシュはあきれる。ゼットンは、アカネの親友であるハクタイジムのジムリーダー、渋谷凛のもとで学ぶよう勧める。
5. 夜、アカネはいい気になってジム通いを許可する（内心では、昼間に部屋を荒らされずに済むと喜んでいる）。カズマは凛の弱点が「お化け」だと聞いてメモする。ゼットンは何か嫌な予感を感じている。

## 第03話「ジムリーダーはお化けが怖い」 → source/003_第03話「ジムリーダーはお化けが怖い」.txt
1. カズマとガッシュがハクタイジムを訪れる。カズマはジムリーダーの渋谷凛とアカネの愚痴で意気投合する。凛と親しいハーフのティファニア（テファ）にも会う。
2. 凛が「育成型」の教育力でカズマを教えることになる。ジムの試合場を見学し、ガッシュがチャンピオンを目指していることを聞く。約1時間、タイプ・特性・持ち物などの講義を受ける。
3. 古代種と現代種の区分を知る（ピカチュウは古代種の長老、ガッシュは現代種）。人間とポケモンのハーフがいること、アルセウスはシンオウの創造神として神話に語られていることも知る。
4. トレーナーの四つの資質（指示・育成・統率・能力）の説明を受ける。占いの本の結果、カズマの資質は「統率」とされる。超能力を持つ人間もいると知る。
5. カズマが凛のお化け嫌いをからかう。ティファニアに週一で泣いて帰ってくることをばらされた凛は、意地を張って、今晩カズマとガッシュを連れて「森の洋館」に行くと宣言する。アカネは面白がって「イケイケ！」と言う。

## 第4話「森の洋館とルサルカ加入」 → source/004_第4話「森の洋館とルサルカ加入」.txt
1. 3日目の夜。カズマ、凛、ガッシュが森の洋館の前に来る。凛は震えながらも、意地で扉に近づく。
2. 暗がりから魔女ルサルカが現れて脅かし、凛は気絶する。カズマはガッシュに「10まんボルト」を命じ、2発で倒す（ポケモンバトル初勝利）。
3. 目を覚ましたルサルカは、自分はゴースト／みずタイプの「敵性種」で、若い男の生命エネルギーが好物だと明かす（カズマ「おっぱいふくらましてから出直してこいや」）。反対の「友好種」の話も出る。ダイス: カズマさんの生命エネルギーの美味さ1D100:80、ルサルカ的なカズマさんのストライク度1D100:94。
4. 帰ろうとするカズマを、ルサルカが「くろいまなざし」で逃がさない。3発目の10まんボルトを「きあいのハチマキ」で耐え、仲間にしろと迫る。
5. 料理が得意と聞いたカズマは、ルサルカを2体目の手持ちにする。気絶したままの凛を背負って街に帰り、3日目が終わる。
6. 作者: これ以降のポケモンはまったく決まっていない（ガッシュとルサルカだけは確定で決まっていた）。今はオープニングムービーのようなもので、フリーのイベントも進めつつ、データありの本格始動を目指す。

## 第5話「プロトレーナーを目指して」 → source/005_第5話「プロトレーナーを目指して」.txt
1. カズマがシンオウに来て約1週間。毎朝ルサルカが寝込みを襲い、アカネが怒鳴り込む。ルサルカの料理に胃袋をつかまれたゼットンは、ルサルカの側につく。
2. 朝食の席で、カズマのポケモン図鑑が今夜届くと知る。図鑑は協会から無料で配られ、持ち歩きが義務。ID管理や電話など、スマホ並みの機能がある。
3. ポケモンリーグの説明を受ける。20チームが予選を戦い、5チームが本戦に出る、地方最強のプロチームを決める大会。先日のリーグでは、チャンピオン「女王」（カンナギタウン出身、3連覇）が優勝し、2位は四天王のほのお使い、3位はギンガ団のジュピター（本名コーネリア）だった。アカネは予選敗退。
4. プロのギャラが芸能人以上だと聞いたカズマは、金目当てでプロトレーナーとチャンピオンを目指すと決める（プロを目指すモチベ1D80:77＋俗物補正20＝97。「せっかくの異世界転生、一旗揚げてやるとしようか」）。ルサルカ「おもいっきり金目当ての上…私はアンタに付いて行くわ」。ガッシュは「\」マークの目を見て不安に思う。System「元の世界のことはいいの？」。アカネはこっそり図鑑でガッシュとルサルカのデータを確認する。
5. 図鑑データ（最初の公開）: ガッシュ（Lv20♂、でんき、せいしんりょく。技: 10まんボルト、しねんのずつき、スピードスター、じゅうでん。攻B／防C／特攻A／特防C-／速C）、ルサルカ（Lv20♀、ゴースト/みず、のろわれボディ。技: シャドーボール、みずのはどう、ねこだまし、のろい、トリック、くろいまなざし。攻D-／防C／特攻B+／特防A／速D）。カズマのトレーナーステータス（文章）: 頭の回転は速いが油断する癖／元引きこもりだがやるときはやる／変な奴らを率いるカリスマ性（笑）、天敵同士でも仲裁できる／妙に幸運値が高い「強運」。作者: 合計種族値はガッシュが500ちょい、ルサルカが500弱。
6. フリーイベント安価（オープニングでのイベント、3D8:19（5+8+6））: 作者は「しぶりん………（遠い目）」で5を見送り、「草むらで謎の（？）ポケモンと遭遇」に。場所はハクタイの森かテンガン山（→006）。

## 第6話「プロへの道とテンガン山」 → source/006_第6話「プロへの道とテンガン山」.txt
1. ジムの休館日。凛が自宅の汚部屋を片付けられずにいると、門下生に家を聞いたカズマが押しかけてくる。鍵がかかっていなかったので中に入り、ガッシュ、ルサルカと30分で片付ける。凛は泣き、ルサルカが朝食を作る。
2. カズマは、アカネにプロ宣言を笑われた話をする（動機は「金、富、マネー」）。凛がプロになる三条件を説明する。ジムバッジ3つ以上の監督、6体以上の所属ポケモン（レンタルなども可）、参加費を出してくれるスポンサー。
3. 滅多に最初からBにはなれないが、バッジ7つでBランクに自動昇格できる特例がある。ジムリーダーは全員Aランク級。大きなスポンサーほど有利で、新人は弱小スポンサーが狙い目。プロの世界は生存競争が激しい。
4. まずは経験を積むよう言われ、ダンジョンの話を聞く。層が深いほど強いポケモンがいる。図鑑には、奥のフロアに行こうとするとアラートが鳴る機能がある。ハクタイの森は最大4層、テンガン山は唯一5層まであるシンオウ最大のダンジョン。一行はテンガン山の1層へ向かう。
5. テンガン山の深度4。ヌシのメリュジーヌが、以前この層に現れた人間（カズマ）の気配に気づき、その「匂い」に興味を持って1層へ向かい始める。
6. 作者: メリュジーヌは、このスレにおける伝説のポケモンとかの領域の奴。テンガン山のボス格なので当然「ドラゴン」持ち。戦うことはまだない（2秒で死ぬ）。次回はメリュジーヌ襲来イベント。

## 第7話「テンガンのヌシ・メリュジーヌ」 → source/007_第7話「テンガンのヌシ・メリュジーヌ」.txt
1. テンガン山の深度1。カズマたちはゴルバットやイワークなど、レベル20くらいまでの古代種を相手にバトルに慣れていく。
2. 敵性種「アラガミ」の下位種、オウガテイルと戦おうとしたところへ、メリュジーヌが「あくうせつだん」を撃ち込む。オウガテイルは巻き込まれたが、カズマたちは奇跡的に無事だった。
3. メリュジーヌは深度4の『テンガンのヌシ』だと名乗る。カズマから「異世界人の気配」と「山のエネルギーの匂い」がすると言い、奇妙な縁や運の色が濃いと見る。ダイス: カズマさんのストライク度1D75:47＋異世界人補正25＝72、アルセウス神への信仰度1D100:5（【悲報】シンオウの創造神、興味なし）。
4. カズマの勧誘を断り、「勝ったら恋人にしてあげる」「1年以内に戦いに来ること」と一方的に約束させる。オウガテイルを担いで深部へ帰る。
5. 図鑑にメリュジーヌのデータが少しだけ載る（ドラゴン／フェアリー、特性マルチスケイル、ポテンシャル『野生の親玉』『テンガンのヌシ』）。一行はテンガン山から逃げ帰る（ガッシュ「合計種族値700が見えるポケモン」）。
6. 作者: 原作でも魔王軍とのエンカ率が高い（このすば）。オープニングのフリーイベント第一弾は3つまとめてこの形で、もう一度フリーをやってからジム巡りへ。このタイミングでメリュジーヌと戦ったら余裕でゲームオーバー。

## 第8話「一ヶ月の賭けとジム巡り」 → source/008_第8話「一ヶ月の賭けとジム巡り」.txt
0. フリーイベントのダイス（3D8:16(7+7+2)、被り分1D6:3）で、「マーズ、俺ジム巡りの旅に出るからお金ちょうだい」「ジムの門下生で仲良くなった相手（ネームド）」「あのメスガキ、有名だったりするんすか？」の3つに決まる。
1. カズマがメリュジーヌとの遭遇を報告する。アカネは妄想扱いするが、図鑑の「テンガンのヌシ」の記録を見て固まる。
2. ダンジョンの2層以降には、その層を支配する「群れ」がいて、それを統括するのがヌシだと教わる。深度4のヌシを手持ちにしているプロチームは、シンオウでも5チームあるかないか。1年でリーグ級にならないとメリュジーヌに返り討ちにされると知り、カズマは頭を抱える。
3. アカネが「守って」と言われるのを期待するが、カズマは自衛の努力をすると言う。アカネが守ってと言えば一緒に逃げるとも言う。
4. アカネが賭けを持ちかける。「明日から1ヶ月以内にバッジ3つとスポンサーを見つけること」。カズマは旅費を出世払いで借りることを条件に受ける。
5. ルートはクロガネシティ（いわ、ジムリーダーはスペランカー）→ヨスガシティ（ゴースト）→ノモセシティ（みず）。翌日から旅に出ることになる。アカネは、自分の家事が回らなくなることにまだ気づいていない。
6. ダイスで、ジムで仲良くなった門下生（女）がライザリン・シュタウトに決まる（1D2:2。もう一人の候補はモモ・ベリア・デビルーク）。仲の良さは1D100:71（作者「それなりに男女の意識はある感じ」）。「私がつくってカズマが売る、これだねっ」。作者: ライザは育成型（モノ作り的なイメージから）。次回登場。
