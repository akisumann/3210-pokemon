# 第37話「育成開始と新たな役割」 → source/037_第37話「育成開始と新たな役割」.txt

1. 約1ヶ月後のシーズン開幕に向け、地下大洞窟で育成開始。フカマルがガバイドに進化する。ライザがブリーダー（育成スタッフ）になる。

2. 目標は6体ともLv50前後（Cランクの下限）。4つ目のジムからはレベルが一気に上がる（ライザ「3つと4つには、深い溝があると心得たまえ」）。カズマは「育成：C」、ライザは「育成：A」。

3. プロでは『役割』がプロ仕様に強化される（『エース』→『不動のエース』）。統率型は倍くらいの種類の『役割』（『二枚看板』『アヴェンジャー』など）を使える。

4. 暫定の配置を決める: エース=ガッシュ、二枚看板=マックイーン、アヴェンジャー=イカルガ、アシスト=ルサルカ、キラー=ライナー、先発=ガバイド。
