# 第25話「メアリとの夕食」 → source/025_第25話「メアリとの夕食」.txt

1. レベルが上がり、「わざマシン：ゴーストダイブ」をもらう。メアリに夕食に誘われる。

2. 凛に電話で報告。約1週間でバッジ2つは想定以上のペース。次のノモセジムはLv33〜35。アカネの独り言が増えていること、ライザの様子がおかしいことを聞く。

3. メアリとの夕食。メアリの「瞳」の能力で、『役割』（エース・アシスト・キラー・先発の4種）の適性がわかる。マックイーンはエースと先発、ルサルカはアシストとキラー。ルサルカ種の渇望は「愛」。メアリ「（まぁ、なんだか現状の''なつき''具合を見てると『アシスト』方向な気はするけどね）」。カズマ「まともな女の子と話したのでオレのSAN値が回復した気がする」。

4. 凛の部屋の散らかり具合はダイスで41（「アカネよりはマシだからセーフ」）。凛いわく、メアリはシンオウのジムリーダーの中でも多分ファン数トップ（「クッソ隙だらけだけども」）。

5. ヨスガ出発〜ノモセシティまでのフリーイベントをもう1回とり（3D8:7と繰り上げの1D6:4）、「ヨスガジムの門下生がバトルを挑んできた」「ポケモンだいすきクラブ」「ポケモン屋敷に雨宿り」の3つに。ここにみさきち（024の''女王蜂''）のイベントも入る。作者「門下生とのバトルともう1戦はジムリ戦前に入る」「バトルに関しては……ポケモン屋敷の方でいいかな？」。
